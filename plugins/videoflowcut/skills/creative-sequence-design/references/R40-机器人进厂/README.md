## 首次研究的原速对照

通过 `open_web_workbench` 取得当前 Runtime 地址，原速看完 `/teaching/r40/R40完整预览.mp4`。阅读 `角色指令逐段拆解.md` 的“与最终效果对应的完整编排”。用 `read_creative_case` 读 016-c01，用 `read_motion_mechanism` 读 026-m07、032-m09，沿 `preview_url` 亲看对应原片与机制，打开 `教学素材/入片源段/README.md` 对照实际进入成片的素材。

回看 016-c01 约 9.5–10.95 秒前景字带穿过多幅画面的过程，再看 R40 的 F564–764。指出原片主体、字带、遮挡、方向和运动分别由本片哪份影像、哪一层字承担。观察实拍是不是在前景字带经过时仍然活动。结合本页的 026 点群和 032 活动画面越框，分清整体编排与局部机制各自解决了什么。

创意作者再读 `角色指令逐段拆解.md` 的“从旁白写出第一轮创意查询”，比较历史实际查询与教学推导，选本片一句旁白按同样方法形成第一条查询。视觉作者指出自己在本片要核的构图、保持或跨场接点，再用本片原片与源段验证。历史首次稿、教学重建和本片当前稿分别用于追查历史、学习方法和正式制作。

同一任务中，同一作者已完整看过同版教学，后续沿用本人实际观察。资料更新、上次中断或某一判断没看清时，补对应文件和区间。换了本片参考，打开新原片。

## 验收一条指令，应该看哪里

![R32 与 R40 的 F105、F265、F500 同帧画面对照](教学素材/首版与返修同帧对照.jpg)

- **F105，3.50 秒。** 看扫描线与点阵是否抵达机械臂画框。仅让左侧点阵运动，主体之间依旧分离。
- **F265，8.83 秒。** 观察结论出现时，实拍和大数字的相对位置。R40 中工厂画框倾斜靠左，聚成的数字占右侧；判断散开到聚合是否连续，需要播放这一段。
- **F500，16.67 秒。** 首版主要靠两条文字分支表达处理方式。R40 将两段真实画面接到分支下，观众能看到人员与生产动作。右列的底部普通字幕来自最终合成。

当时交给 OD 的前两条反馈修正绑定结构和漏绑的视频槽。第三条才是针对可见画面的返修，使用 R32 抽帧指出了上述问题。读返修时先看原画面，再读准确指令，最后打开 R40 同段视频检验变化；静帧适合比较布局，运动重叠、快慢和停留须以连续画面判断。[R32 前半抽帧](教学素材/05_项目版本与检查/返修前抽帧表_前半.jpg) · [R32 后半抽帧](教学素材/05_项目版本与检查/返修前抽帧表_后半.jpg) · [R40 完整视频](教学素材/成片/R40完整预览.mp4)
