# 书籍展开与翻页（返修候选）

## 用途与来源

本项目新设计。详细来源与许可见 [SOURCES.md](../../SOURCES.md)。当前不是正式推荐示范。

## 物件怎样造出来

固定书脊连接刚性封面；32 条等弧长曲面条带组成纸页，正文与图案共用 pagePoint 投影，正反面采用不同图案。两张页保留身份从右侧翻至左侧。
源码：[source.tsx](source.tsx)。组合实例时传入不同且稳定的 instanceId。

## 动作怎样发生

0.20–0.90 秒封面展开，至 1.08 秒收势；两张页分别于 1.18–1.96 秒、2.25–2.95 秒翻转。
[本版预览](preview.mp4)：240 帧 / 60 fps，无声。

根层读取当前局部帧；直接使用时 startFrame 默认为零。外层 Sequence 已提供局部帧时，子组件 startFrame 传零，事件解析器使用外层偏移，避免画面重复减起点。

## 复现与改写指令

读取完整 source.tsx 作为 MotionSubmission.source，其余字段取 demo-props.json。本例无外部图片、音视频、字体依赖。不携带生产项目 ID。
在仓库根运行 `npx tsx scripts/render-object-drawing.ts book-open`，沿现有受管编译与渲染器输出到隔离验证目录；齐套校验后整目录替换，替换失败回滚旧目录。改造型和尺寸时需重新检查接触、遮挡、转轴与承载关系。

## 验证与边界

几何重建已完成，真实连续翻书参考尚未核看；纸面遮挡和真实翻页质感仍待连续判断。
技术产物见 verification.json；版本观察见 reviews.json。静帧检查、哈希与编译不代表连续效果认可。新版渲染不能继承旧版认可，当前状态 rework。
