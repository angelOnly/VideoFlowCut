# 超现实拼贴 · Token：怎样把内容变成连续场面

本页供当前视觉作者学习原作的具体做法，并迁移到不同内容。先看[原生完整作品](完整场面_无声.mp4)，再按本片问题查下面的画法与动作。

原作约 21.20 秒；[受管源码](managed/source.tsx)只覆盖原作 8.10—14.00 秒，177 帧。它提供实现参考，固定八个单元，部分卡片与页眉是静态贴片。[同阶段对照](comparison.html)和[版本观察](managed/reviews.json)记录其覆盖与差异。原作采用、受管版本验证、新片效果分别判断；无需为开始新片重新制作原参考。

## 先追踪完整作品里的同一个内容

打开[原 Canvas](scene/index.html)及 [timeline.js](scene/timeline.js)，结合视频观察下表。沿“输入句子—纸条—分出的单位—被找到的重点—结论”追踪身份，不把每一段理解成互不相干的特效。

| 范围 | 实际变化与观看作用 | 代码入口 |
|---|---|---|
| 0—2.18 秒 | 海报材料建立基调，聊天卡片盖入，观察转到输入位置；环境先给输入行为一个来处 | drawCover、pasteTex、drawCard、camAt |
| 2.18—4.33 秒 | 文字输入并发送到对话区，成为可操作纸条；内容获得实体形态 | TYPED、SENDMSG、stripShape、cardToWorld |
| 4.33—7.73 秒 | 同一纸条保留，批注、叠层和 Prompt 标题取得或让出注意；命名围绕已有对象发生 | drawDeck、drawPromptArrow、drawPromptTitle |
| 7.73—8.94 秒 | 海报被撕开，石雕升起，纸条沿弧线进入开口；换空间时仍能追踪原内容 | drawTear、headDy、stripPose、W2D、D2W |
| 8.94—11.81 秒 | 镜头进入内部，工具到位、空剪、连剪，纸片错峰翻落为骨牌；输入、作用和结果一起演出 | toDive、drawInterior、drawStrip、drawScissors、domino |
| 11.81—13.79 秒 | 单位留在石阶，数量指认、逐个轻跳和 Token 命名接续；动作后给结果辨认空间 | domState、drawDiveNotes、slam、shakeAt |
| 13.79—18.99 秒 | 纸条遮满后回到较大空间，材料被搜索和标记；红蓝身份仍延续 | drawSweep、drawSlips、slipPose、drawDataNotes |
| 18.99—21.17 秒 | 太阳改变位置，材料响应，前面的重点骨牌再次并置，结论出现在腾出的区域 | sunAt、drawPair、pairPose、drawConclusion |

把这个经验用于新片时，先确定哪些对象需要被观众继续认出。给它们保留相容的形态、颜色或内容线索，场面变化后继续使用其结果。若本片内容需要的是归位或组装，就设计归位或组装的后续，不继承原作的分词、搜索和旅行结论。

## 从原作具体学美术与材料

### 纸面：先有大尺度变化，再有纤维和边缘

读原作 PAPER：它在 1920×1080 纸底中组合尺度为 90 和 22 的明暗网格、轻微暗角和短纤维。GRAIN 另提供固定种子的透明颗粒，用在对象局部表面。纸底有低对比的大变化，纸片有自己的边缘和层叠，二者并非统一盖一层噪点。

本片采用该纸感时，可取 [paper.png](managed/resources/paper.png) 和 [grain.png](managed/resources/grain.png)，按实际尺寸与透明度放在承载面或对象局部。先看整幅明暗是否舒服，再检查正常尺度的纤维，别为了“看见纹理”把纸面调脏。

读 tornRect、makePiece、stripShape，核对边缘、裁切和偏移影。分开的纸片沿原纸面保留纹理连续；新对象是金属或陶瓷时，重新画它的边缘，不继承撕纸轮廓。

### 实体：按形体建立材质，区分表面与投影

剪刀读 scissors：刀面、连接柄、朱橙握柄和轴钉分层，两半围绕共同支点旋转；金属亮暗带在局部横向 -16 到 16 的范围内变化。迁移时先保留新工具的轮廓、支点和器形，再把反射带放到对应表面。受管 Scissors 的 userSpaceOnUse 渐变说明了局部坐标的用法，默认包围盒渐变不能直接视为相同效果。

石雕读 headPath、HEADTEX、drawInterior：侧脸轮廓负责识别，形体大明暗、斑驳和颗粒负责石材，开口前缘、暗腔与石阶负责内部空间。需要新容器时，重画容器的开口、壁厚、内部和承载面；根据新材料处理表面，不把石雕图片缩放后当成新主体。

骨牌读 domino：左侧面压暗，顶面提亮，正面有纵向明暗和印刷颗粒，底边与石阶对应。新对象有厚度时，把可见侧面和背面画出来；翻面时检查这些面如何出现，不只横向压缩一张正面图。

原作的部分光影是为固定朝向设计的近似。新主体转身、起跳或离开表面时，重新检查自身暗面、接触处与投影，不能把原作固定底影当成适用于任何姿态的光照算法。

### 颜色、文字和留白：围绕当前关注分工

对照 drawCover、drawDiveNotes、drawConclusion：米灰纸面承接大面积，深色轮廓与石材形成分量，橙色笔刷和重点字制造重音；红蓝对象在不同场面继续指向同一内容。具体色板沿[拼贴风格页](../../../surreal-collage.md)。

本片先决定哪件主体需要最大观看面积、哪些颜色用于身份、哪些用于当前强调。主体行动时让辅助字和背景为其保留空间；需要命名或判断时再给文字重音。换内容后重新定义颜色用途，不自动让两个词永久变红蓝。

需要手写指认或笔刷时，读 makeBrush、brush、handText、handArrow；可参考 [brush0.png](managed/resources/brush0.png)，同时确定它指向谁、何时揭示、何时退出。不要只拿走橙色横线。普通字幕继续本片已有规范，原品牌、页眉和字幕不是新作品素材。

## 逐段理解纸条—剪刀—骨牌怎样成立

观看原作 8.10—14.00 秒和同阶段对照。受管第 f 帧对应原作 8.1 + f / 30 秒；这些数值用于对照，不用于规定新片时长。

### 纸条转入空间：路径、姿态和镜头共同对位

读 stripPose、cardToWorld、W2D、toDive，以及受管 Strip、Camera、Dive。8.10—8.82 秒的纸条沿弧线移动，同时改变缩放和角度；之后观察向开口内部推进。原对象并未在切镜后换成另一个图标。

借用时，把对象起点、入口和内部目标放到可转换的坐标关系中。先摆出起点、跨越边缘和到位姿态，确认对象能沿路径进入；再设速度。推进中检查开口与内部对象是否滑脱，前缘是否遮住正确部分。字幕等屏幕层不跟着内部镜头一起缩放。

本段必要依赖是 `BUBBLE`、`CARD.rot`、`DIVE` 与 `HOVER`：`cardToWorld → W2D → stripPose` 把卡片坐标转入内部坐标，`toDive` 同步相机。纸面由 `stripShape` 继续绘制，不能只复制曲线而丢失同一纸条。起终点和弧高可按新空间改，坐标转换与对象身份必须相容。以上为 [原源码](scene/index.html) 定位，连续观感沿已有观察边界。

### 工具到位：区分准备、执行与跟随

读 drawScissors、scissors 和受管 scissorsState。原作约用 0.42 秒让工具从右上到位并略超调，整体角度同时收回；随后约 0.22 秒空剪建立行为。真正作用发生在后面的连剪事件。挂签有自己的相对运动。

新工具先明确活动轴、作用边缘和被作用物的关系。在打开、首次接触、作用结束三个相关姿态检查部件与前后遮挡；对于剪刀，刀刃应交错越过，切线位于有效作用范围，不能让两个宽刀面相向挤压来代替剪切。原作是二维图形化表现，不作为所有机械关系均正确的证明。

借它的果断节奏时，分别安排到位、准备和主要动作；轻附件在当前主体启停后产生跟随，刚性部件保持结构。不要把原作挂签的衰减正弦原样贴到新片开头，就声称完成了所有动作的惯性。

`scissors` 的两半共享支点，`drawScissors` 通过 `SCX(0)` 对准第一切线，`tIn = M(分词器)-0.06` 决定进入。采用时须连同刀面、柄、轴钉及局部渐变一起处理；挂签与字体是可选附件，不是机械结构。材料依赖见上文“实体”，不能把固定贴片作为新的可编辑文字。

### 连剪：同一事件驱动刀位、切口和结果

读 CUTS、SCX、BOUND、PIECE、cutOff、drawStrip。原作的七次作用间隔约 0.07 秒，切口间横移约 0.035 秒；刀刃闭合、切口闪光与纸片偏移围绕同一组时刻发生。前面的空剪不释放纸片。

本片需要切分时，用实际绘制字体重新测量内容，计算各段边界与中心，再安排对应作用位置和事件。文字、边界、裁切、纹理、分离偏移与后续落点一起更新；数量变了，就重新计算事件与位置，不保留七刀和八块的假设。

把刀口和切线转换到同一场面坐标检查，受作用物在接触事件后才改变。动作很短时，在本片帧率下核对是否有可辨的接触和结果，不能只看浮点秒数正确。无需让每次快速作用都停下来阅读，整体节奏仍应连贯。

`SCX(k)=HOVER.x+BOUND[k]+2` 将刀位与字宽边界绑定，`cutOff` 在同一 `CUTS[k]` 后分离两侧；`drawStrip` 的切口亮线也读取该事件。必要依赖是 `TOK`、`SF`、`tw`、`BOUND`、`PIECE` 与纸纹裁切；题材、字体、数量和时长可改，事件到边界的对应不能丢。

### 翻落：同一身份跨过薄面中途，再留下结果

读 domFall、domLand、drawStrip、domState 和受管 pieceState、Domino。原作各片以约 0.05 秒错峰开始，一次翻落约 0.42 秒；先轻抬再加速，纸片收窄到侧面后显出骨牌，落定约 0.14 秒内发生短促压缩和展宽。

新对象先决定正面、侧面和背面分别是什么，以及身份如何延续。查看最薄中途、背面开始可见和接地姿态，避免正反面同时存在或凭空换内容。厚物与柔软纸片使用适合自身材料的响应，不把原作的压扁幅度套给所有硬物。

统一落点、底边、承载面和接触影。飞行状态与落定状态在同一时刻接管同一对象，避免碎片与成品重复显示。只在本片需要的对象之间使用错峰，不机械地让所有物件排队。

`drawStrip` 在 `t >= domLand(j)` 停画飞行片，`drawHead` 从同一时刻接管静置骨牌；`DOMX/DOMY` 与 `drawInterior` 的石阶共同确定承载位置。`cos(πp)` 的符号切换纸面与骨牌面，纹理依附各自局部面。它是本例纸片转骨牌的表现设计，不能宣称任意物件都能用横向压缩完成真实转身。

### 辨认和接出：动作的结果要参与后面

读 drawDiveNotes、domState、slam、drawSweep。原作落定后让观众逐个辨认，Token 命名用约 0.13 秒的强落点形成重音；随后斜纸条遮挡为下一观察范围提供切换依据。连续关系包含动作之后的观看时间。

本片先确定结果要被看清、命名、比较还是继续操作，据此安排停留与文字参与。接到下一场时保留仍有意义的对象或关系；需要遮挡转场再用遮挡，并把两侧内容一起设计。不要因为参考有笔刷、震屏和扫纸，就让每个结果都复制这套组合。

本段依赖 `TOKEN_T/TOKEN_HIT`、`IMPACTS` 与 `SWEEP_C`：命名的落点、场面响应和遮满时刻共同组织接出。全片 13.79—18.99 秒继续通过 `drawSlips/slipPose` 搜索材料，18.99—21.17 秒用 `drawPair/pairPose` 复现重点身份。若只借内部动作，则不必携带太阳、结论贴片或原品牌；若借跨段结果延续，就必须为新片建立对应身份。

## 换了内容，按实际关系取用

本片若表现“内容进入容器并再次取出”，优先借内部／前缘分层、共同坐标和身份延续。先画新容器及物件；按开口确定路径，经过前缘时改变遮挡，进入内部后落在可解释的承载处。取出时继续沿用同一对象和位置关系。石雕外形、剪切和骨牌翻面无需一起出现。

本片若表现“一项输入分为多项结果”，才进一步借边界、分离和结果组织。先确定新内容的真实分界与后续用途，再决定是否适合使用工具和物件比喻。

只借材料时，可以选纸纹、颗粒或笔触，同时按本片主体重新设计轮廓和光影。案例未提供的新器形或视角，需补真实结构依据并在本片检查；不能由一个原作推出所有物件的通用画法。

把选择写成能够指导绘制的一段当前稿。例如：“同一件工具被放入抽屉，前缘依进入深度遮挡它，内部位置在下次打开时保持；借原作内外空间与身份延续，重做抽屉结构、工具材质及本片节奏。”这只是决定写法示例，不规定新片必须有抽屉或某件工具。

## 带着完整依赖进入受管实现

按本次采用项读取 [resources.json](managed/resources.json)、[demo-props.json](managed/demo-props.json) 与 [source.tsx](managed/source.tsx)，一起检查几何、局部坐标、状态、资源和实例 ID。纸条相关函数依赖字宽和边界，镜头相关函数依赖空间变换，翻落依赖面、身份和承载位置；不能只取一个入场缓动。

原作静态材料可以复用，核心部件和场面状态保持可编辑。当前示范有固定八单元、原词和静态卡片贴片，不是任意内容组件。选取必要部分整合到本片源码，资源通过正式项目导入与绑定，不整包注入隔离验证的图片，也不照抄旧项目身份。

正式实现读取[受管制作](../../../../../opendesign-video-production/SKILL.md)与其当前合同。编译可接受、资源就绪和渲染成功分别核对；实际槽位、字体和 API 以当前能力为准。

## 在新输出中检查并继续修订

先看本片主次、材料和字形，再看接触、跨边缘、薄面、接地等实际采用的危险中途，最后以正常速度看连续演出及相邻接点。加入真实声音和字幕后，检查重音、阅读和动作是否彼此支持。

只有静帧或源码依据时，保留该范围的结论，不填写未完成的连续观看。将发现的问题定位到载体、结构、材料、状态、节奏或接续，沿本片同一源码修订。既有受管示范的差异见版本观察，不把差异当作原作标准，也不为修新片重新制作原参考。

交回实际视频、同版源码和采用说明，写明已经检查和仍未知的范围。技术成功与新作品效果分开报告。
