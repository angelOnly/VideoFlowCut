# 机票退改费：仅用本包内容，从零创作

## 1. 任务

在本机当前 VideoFlowCut 正式制作环境中，用本包的准确正文、声音、客舱视频和规则资料，重新设计并制作一条约30.25秒的竖屏解说片段。画布768×1344、24fps，时长服从已给音轨与真实阅读需要，不增加无用途等待。

本任务从零形成画面设计与源码，不是修订某个现成作品。只使用本包列出的内容输入，不读取历史动画、历史设计、历史项目或其他试作。正常制作所需的项目方法、通用机制库和运行工具按下面的明确范围使用。

直接完成设计、实现、正式生成、实际查看与必要修改，最后交付可播放视频。不以改写任务书或提交一份设计方案结束，也不需要用户逐镜批准。美术、动效和实现由同一视觉作者连续负责；分工已经存在时共享同一材料、同一批参考和同一份当前设计。

先以本文件所在目录为输入根目录，读取 `文件清单.json`。允许的内容文件只有：

## 3. 从当前内容独立作设计

先完整读取正文、字幕与声音，查看本包实际图片和视频。它们决定事实、声音边界与可用材料，不决定镜头数量、版面、配色、动画路径或机制组合。

自行决定怎样让观众看懂：同一张规则表中的两种比较、空座与剩余时间的关系、取消与更换安排，以及改签可能涉及的两项费用。这些是语言内容，不是要求做成三张说明页，也不要求使用柱状图、四块图形、某条路线或固定费用卡片。

从项目通用机制库寻找适合当前需要的参考，查看图像和必要视频，同时决定外观和动作。美术与动效共用这些结果；缺的是正文就读详情，缺的是连续过程就看片段，不按角色重复搜索。只有当前候选确有不足才定向补查。

先确认素材能被怎样操作，再做对应：完整照片或视频窗口可以移动、缩放和改变观察范围，不代表画面里的座椅已经被分层或抠出。没有真实背面、内部结构、遮罩或跟踪结果时，不制造假的物体运动。准确数据可以自绘为编辑图形，但不能伪装成官网页面或真实订单。

结合本片材料，同时决定各段开始时、中途与结果时的构图。主角怎样变化，文字与辅助内容怎样回应，空间怎样重新分配，下一内容为什么进入，都要有具体安排。用本次简短设计稿承接这些决定，然后编写全新源码。不要先完成静态页面，再给它增加局部入场效果。

## 4. 本片的美术与动效目标

### 画面有明确性格，而不是极简资料页

采用有表现力的编辑拼贴式解说设计：实景、资料局部、准确图形、带造型的花字和注释贴片共同表达内容。画面丰富来自对象关系、主次与材料配合，不是堆叠装饰数量。

背景可以变化，主体可以取得整幅画面，也可以按阅读需要形成局部或并置关系。不要默认全程米白或深蓝底，再反复放几行字和几根线；也不要为了变化随机切换色板。统一字形观感、强调方式、边缘与材料处理，而不是统一全部背景、标题位置和素材容器。

本片不设置常驻章节标题区。不管是不是同一个组件，每段都在相同上方位置更换大标题、把主体限制在下方，仍属于固定说明页。原件准确标题与必要对象标签可以保留；信息该附着于当前对象时，就与它一起设计，完成作用后退出或重新安排。

### 画内花字是对象，不是把普通字放大

重点短语采用适合中文的有分量字形，按真实背景选择清楚描边、贴纸轮廓、承托形或克制偏移影。轮廓和文字、相关图形共同进入、收稳、让位或退出，让花字回应当下内容，不是独立漂浮的装饰。

普通标签跟随其对象，费率和时间条件优先正确易读，不把所有小字都做成强烈花字。描边不能堵住中文笔画，贴片不必每次都是同一矩形。字体只用真实可用的登记字款，不分发或猜测不存在的字体文件。

具体短语、出现时机和造型由本次设计决定。不要给每句旁白另外复制一行主标题；底部普通字幕仍然稳定。

### 实景、图形和动作一起工作

客舱源视频应承担真实观看内容，不只是固定图形下的背景。讲述变化时，合理使用取景、素材窗口、图形关系和花字；不要把连续几秒没有新视觉内容的实景作为等待下一动作的空档。真实观察、必要呼吸与读清可以稳定，不要求每秒都有特效。

数据比较、时间缩短和费用区别各自需要合适的对象及动作。背景、主角、文字与辅助层共同构图；不是只有框、线和小字在动，也不是把整个根容器一起放大就宣称整幅设计。

参考须适配实际材料。设计阶段可以改变方向、幅度、路径和出入关系；已经确定的本片主要过程，需要在实现中兑现，不能再次缩写成“突出、让位”后只做淡入或变色。

## 5. 事实、声音与字幕

规则字段与原文图相互核对，保留真实舱位、百分比、含／不含条件。全部行列只是资料，不预选某一组数据作为强制设计。图中文字不清时使用已核对字段，不能去查历史动画拿答案。

本文档资料限定在包内给定版本与正文，不更新规则，不把它扩大为任何航班通用条件。不虚构具体票价、航班号、订单、损失金额或费用比例；图形大小和动画变化不能暗示没有提供的实际金额或中间费率。

保留“可能”“只能解释一部分”“不等于每笔费用都是实际损失”等准确限制。制作备注、来源获取说明、内部对象名、机制编号不显示到成片；必要内容限定由自然旁白、准确字幕与必要画内文字承担。

直接使用包内旁白音轨与局部SRT时间，不重配、不加速、不重复平移。客舱文件自带的音轨不要自动与旁白叠加；只在确有必要且确认内容后使用。

普通字幕全段采用同一字体、字号、颜色、底板规则和底部位置；背景按实际排出的行数计算，一行是一行高，两行才向上增加高度，没有字幕时不画底板。不得预留空行、逐词跳动、缩放或跟随主画面移动。

核对当前正式工具能力，不读取历史工单或旧任务了解接口。若现有声音或字幕接口不支持要求，报告本次实际缺口，不擅改平台、不另写一套渲染器掩盖问题；能独立完成的视觉候选继续制作，明确尚未合成的内容，不能声称完整声画通过。
