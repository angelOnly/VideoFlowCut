# 视频美术方法

本页教同一持续视觉作者从内容与材料形成整场构思，共同设计背景、布局、排印、材质和演出，并在当前作品中预排、实现与返修。章节是互相影响的工作方法，不是先冻结静态美术、再追加动作的顺序。

## 默认设计与整场发展

用户只给主题也主动完成整幅画面与观看过程。默认的是设计完成度，不是固定外观或效果清单；花字、强排印、丰富材料、大幅运动和安静观察都可使用，由本场作用决定。没有花字不自动判为缺项，已有花字也不证明美术完成；不按每段、每个重点配齐效果，不把克制统一解释为少字少动。用户明确要求的表现继续落实。

同一作者持续决定主角、空间、美术与演出，并接回实际输出修订。可以兼任相邻工作，不因进入动作或编码阶段重新选择一套视觉。当前稿保存本片采用的决定，用户要求沿原偏好字段传递；作者的字款、色板和构图不写成个人偏好。机械改字、保留原片或只导出按实际范围处理。

主体取得或让出注意时，同时安排相关文字、背景与辅助内容怎样响应；不要求所有层一起运动。源动作、稳定参照、阅读停顿与清楚切镜都能完成观看。采用依据来自本片实际画面及过程，不来自装饰数量、机制编号或运动面积。

## 视觉导演怎样决定整幅画面

### 从可见关系选择过程

先读完整句群、真实材料与相邻画面，决定本段让观众观察、理解或感受什么，再选值得观看的主体与关系。主体可以是人物、环境、实际行为、材料细节、图形或文字；它们也能共同承担。把想法落成包含空间与观看方式的构思，而不是先为每句旁白分配一张配图和一组字。

例如，尺度与距离可以改变压迫感，同一载体展开可以显露内部关系，排印的聚散可以表现情绪。借这些例子理解如何从内容形成画面，不将它们固定为类型或模板。只写“电影感、丰富、强调”尚未决定画面；只有“播放素材、前景补字”时，继续决定这一组合是否足以承载当前观察，以及关注变化后整幅画面如何发展。

事实与形式分别处理：原文、单位、条件、身份和源时间保持准确，显示面积、位置、观察范围与主次由本片决定。已核对字段可形成编辑图形，但不冒充官方原件；不可辨数据不猜，单图不假装可拆层，源内没有的行为不伪造。材料未齐先保留候选构思，依赖的实际内容接回后再采用。

### 用参考参与选择，同时决定美术与动作

在构思未固定时共用已有候选正文、分镜与必要原片，看主体比例、文字轮廓、背景作用、空间展开和注意交接怎样共同成立，再放回本片材料适配。参考可以改变初始构思，也可以解决局部难点；不先锁死页面，再只寻找它容得下的动作。外观适合时可与动作共同借鉴，不为分工重复检索。

只借局部时，具体完成本片其余的主体关系、空间组织和前后接点。“其他自行设计”不是交接；同样，不因容易编码，只留下文字显隐而删去原本承担表现的主要变化。参考不是现成答案，是否采用仍看本片实际效果。

### 按产品目标采用，并对结果负责

把实际材料、准确文字、正式可用字体与真实时钟放进当前作品源码，形成与后续作品同源的预排。构图与主要动作在其中一起推敲，观察当前最难成立的组合和变化：观众先看哪里，接着能否跟随，哪里拥挤，结果有没有足够表现。按风险选范围，不固定状态图数量、两版比较或独立练习片，不增加逐镜批准。

用这个实际画面与过程作采用依据，不以完整设计说明、色卡或生图证明实现。草图、生图可以帮助构思，但不得重绘证据、虚构数字或冒称受管源码已兑现；素材或声音未到的范围明确是候选。后续沿同一源码、对象和源时钟继续制作，形式选择仍可修改。

选择明确且实际成立就继续。表现偏弱时改变真正影响效果的主体、观察距离、空间、材料用法或文字关系；无需凑方案数。采用理由简写可见收益和材料、阅读或实现代价，不采集私下推理。输出不成立时区分选择偏弱、设计未完成和实现遗漏，回到对应工作；“已采用”不等于用户认可。

## 设计判断：把选择落实到本片

需要选择气质与外观时参考[美术方向](art-directions.md)相关部分，用实际画面判断，不把方向名称自动变成配色、素材范围或运动力度限制。先决定本场的主张，再让明暗、形体、排印、材料与动作共同表达；复杂和安静都需要具体组织。

从首轮与导演、文案和素材作者共同工作。实际文件的主体、光线、纹理、方向与行为可以改变原构思；材料不支持所需观看时，提出具体缺口并补材，或与导演改表达。不得先固定模板再让素材争空位，也不把作者上轮的形式建议当成不能改变的事实。

同一场面中的丰富内容可以共同指向一个体验，焦点清楚不等于只剩一个物体。决定是否保留某项表现，看它对当前观察、情绪和节奏的作用；不默认最少处理最好，也不靠增加效果掩盖尚未形成的构思。

## 构图：让主体成立，再安排文字与辅助层

### 从材料中找画面的结构

打开实际文件与采用范围，观察主体轮廓、朝向、视线、动作、明暗、远近、边缘及可裁空间。实拍从这些关系形成构图；编辑场面则决定主体怎样被承载、与周围空域有什么尺度和方向关系。空间可以有体积，也可以是平面编排，不统一使用房间、桌面、卡片或网格。

用主要形体、明暗块与准确文字共同安排视觉重量、疏密、边界、方向和留白。确定观众离主角多近、哪些细节值得看、哪些关系需要并读，再分配面积；不预留固定标题区、素材区和说明区后逐项填空。物体的开口、部件与边缘既形成身份，也可以提供后续展开的依据。

背景与主体同时形成：它可以提供真实环境、光色气氛、承载、方向、尺度或安静对比。纯色背景仍要通过比例、正负形、边缘和空间分布完成画面；丰富背景则组织细节的密度与地位。没有根据地添纹理和直接删掉环境都不等于背景设计。构思依赖摄影、插画或模型时，选择能承载它的实际材料，不先扩建组件库。

### 横屏是素材事实，横窗是使用选择

来源尺寸、实际可见内容、声音与源范围如实保留；全屏、窗口、局部、并置、跨镜剪接及 cover/contain 都是使用选择。需要保留空间关系时先说明哪项关系重要，再决定取景与接续。不能不看裁切损失就强制铺满，也不因源是横屏就一直缩成横条。

材料返回后一起校准取景、字位、路径和接点。缺口沿[取材与材料反馈](../../production-director/references/asset-briefing.md)交回，说明缺哪项行为、细节或范围，不让预设容器、来源网站和机制形态反过来限制候选。

### 文字和资料与主体共场

依据准确正文决定哪些文字需要上画面，以及它与当前主体的关系：成为主角、共同构形、形成对照、显露结果，或作为独立的编辑声音介入。关系可以通过比例、排列、共同基线、遮挡与时序成立，不要求所有字贴到物体上；也不由“这是重点句”自动取得最大面积。

按这个关系组织准确短语、必要条件与资料。共同阅读的内容保留对应参照，非同等地位的文字拉开视觉重量，普通字幕在最终画幅保持自己的阅读职责。画内只呈现面向观众的内容；来源、制作方法、检索与研究备注留在记录，不自动添加栏目、页码、印章和说明板，删除后重新分配空间。

原件身份、原文数字与条件保持准确，编辑内容不伪装来源的一部分；必要假设自然交代，不把假设说成实测。已建立身份的证据可以进入有效局部，真实署名或披露义务另按当前要求处理。

## 配色：先组织明暗与面积，再确认色彩

### 让配色成为当前画面，而不是一张色卡

从材料与当前表达中选出基底、主体和强调的关系，将颜色放回实际面积里判断。先看哪里最亮、最重、最密，主角能否与周围分开，再看冷暖与情绪。素材取色是一项依据，不是结论；需要改变面积、明暗与边缘时，不能只替换色号。未处理原片不声称完成调色。

用本片准确文字、实际素材与字幕预排，检查相邻表面是否融在一起，强调是否分散成许多抢眼小块，白底原件与环境怎样衔接。可调整主体面积、阅读区域、局部承载或整体明暗，不默认给每份原件套大卡，也不靠叠加影、光和颗粒解决主次。

### 统一颜色的用途，不统一每一块背景

同一关系跨镜保持可追踪，字形、材质与颜色语气可以延续；背景明度和颜色面积随实际环境、主角与观看变化。检查相邻画面的视觉重量与明暗交接，不为求变化机械轮换色板，也不将一致性做成同底色、同标题和同窗口。

不预设米白、深蓝橙、黑金或其他色板，不规定强调色数量和饱和度分数。多色与冷暖共存可以服务复杂关系；用清楚归属和对应维持理解。用户否定整幅美术时真正调整画面，换色后仍是原布局不能称为重构。

## 中文排印与字幕：在同一幅画面中设计

### 用真实字形而不是字体名称判断

将实际中文、最长条件与数字放进本场，先组织整组文字的轮廓、重心、断行、字间、行间与阅读尺度，再决定字面、轮廓、承托、厚度或其他造型。主读可以大胆并占大面积，标签体现对象归属，普通字幕稳定可读；不用同一套描边、偏移底字和斜切角复制所有短语。

花字用于本场需要的表现，造型与进入、读清、退出共同设计；可以由文字自身承担表演，也可以与其他主体协作。采用后完成其实际作用，不把粗体、放大、换色或“已有动画”当成任何效果都成立的证明；未采用花字的场面仍要通过选定的材料、构图和演出达到完成度。

字太细先核对字体回退、真实字重与面积，字太宽先调整布局、选字款或准确断行。不要横向挤字、用厚影补错误字款，或以 CSS 字重冒充不存在的字体文件。实际绑定和加载沿[组件合同](../../remotion-production/references/remotion-component-contract.md)，指定字体缺失沿[字体与提交操作](../../remotion-production/references/submission-and-recovery.md)；普通设计先用正式可用字款。

### 字幕外观归美术统筹，准确时间归字幕作者

首次将真实字幕放入本片不同背景，确定字体、字号、字重、字色、底板、透明度、圆角、内边距、描边或阴影、位置、行高、行数与框尺寸规则。用实际效果选一套覆盖本片的规范，不逐镜临时换样式。阴影、描边和底板各有作用，不默认全部叠加。

首次决定单行或最多双行等规则，maxLines 是上限，不冒称用户已指定。底板按实际行数向上增高、底部固定，无字幕无底板；不缩放或逐词强调普通字幕。后续明确修订时统一更新全片。

字幕作者负责准确分卡与时序，普通字幕在最终画布独立显示，不参与主画面相机、缩放、旋转、平移或裁切。冲突优先调整主画面；需改语言或分卡时与相应作者协调，不能为塞版面删事实。只承诺实际接口支持的效果，设计为无阴影而仍有黑影须回实现处理，不虚填字段。

## 材质与空间：细节属于对象，而不是通用滤镜

根据主体形态与空间决定边缘、厚薄、表面和光线。摄影本身的光线纹理可以直接形成质感；原创形体按表达选择材料语言，平面图形不强加假体积。卡通质感来自比例、正负形、轮廓、承载与动作性格，不只是圆角；复杂材质也不能代替主体与空间组织。

需要体积时兑现光向、厚薄与接触关系。曲面高光随形体，薄片边缘不被渐变画成鼓块；文字、图案、边缘与阴影属于同一物体，随姿态、透视和遮挡变化。接触影按承载面、距离和环境调整，不复制固定黑影；可靠附着不能实现时，由原作者调整形体或观察方式，不让文字永远正对镜头却声称已附着。

用尺度、遮挡与清晰度建立远近，焦点转移响应相应深度，不用整图模糊冒充景深。运动模糊用于快速变化，阅读与展示保持可辨。主角有明确空间不等于必须加入透视网格；网格、纹理、粒子等只有参与当前环境或表现才使用。

视频、附着标注与裁切共用正确坐标，固定点只适用于源内相对稳定的目标。全屏转窗口、同源局部、跟踪与持续播放沿[素材坐标与时间](../../remotion-production/references/material-space-and-time.md)落实，不伪称已经跟踪。用户明确不要纯色主背景时落实其要求，原件自身白底不等于必须擦除的缺陷。

## 从美术画面交到连续机制组合

主要行为从观看变化产生，不在固定页面上逐个加入场。决定为什么变、观众跟随什么、读清后注意移向哪里；行为可由源素材、物体、排印、镜头及其协作承担。同一次注意转移中，安排旧参照保持或退出、辅助字让位、新内容取得面积、背景关系延续，不把它们变成互不相关的动作清单。

新旧同时出现时，先安排谁取得注意、谁供比较，再落实路径与时机。载体取得可读空间后再显示需要阅读的内容，避免文字在混叠中抢读；有意使用交叠时以实际观看判断。动作有足够幅度、行程与时间表达所选意图，停顿让关系成立；不以微移敷衍，也不持续扰动已读清内容来维持“有动画”。

按[机制主方法](../../motion-case-library/references/mechanism-retrieval.md)探索与适配，保留对象、坐标、源时间及阅读连续。相关层依据作用响应，不等于全层同时缩放；源视频继续自己的时钟。美术和演出在同源预排中互改，不为沿用组件悄悄改变主要选择。

前后画面共同设计注意交接。可由同一对象、方向、动作或空间继续时利用其联系；需要换观察方式时可直接切镜，仍安排前后的视觉重量、尺度、位置与明暗。不能把交接等同变形转场，也不机械安排每场先全幅再缩侧栏。结尾利用已建立的关系完成最后一次观看，不自动新增总结页；实际声音参与时机，详细节奏沿[时机方法](../../effect-timing/SKILL.md)。

## 预览与返修

用实际观看尺寸看整幅，再看主要变化及必要前后语境。构图静帧、连续动态和声音各自记录真实覆盖；同源预排是采用依据，正式合成还要确认材料、字体、字幕与声音共同成立。不能用设计说明、解码成功或播放字段代替观察。

| 实际问题 | 返回哪项创作工作 |
|---|---|
| 只有花字变化，主体与空间没有承担本段表达 | 重新选择整场构思、材料用法与主要行为，不给现有字继续加效果 |
| 主体被说明挤小或多个对象无序争抢 | 重新分配视觉重量、对应关系、面积与阅读顺序，允许保留有组织的丰富内容 |
| 色彩脏、表面粘连或质感像通用滤镜 | 调整明暗、边缘、材料与承载关系，再确认颜色和细节 |
| 中文细糊、拥挤或花字与主体脱节 | 核对真实字款、字组轮廓与阅读尺度，重新设计文字的作用与归属 |
| 两端成立，中途挤乱或动作像没发生 | 改接管时刻、显露顺序、行程与层次，不把整段统一放慢 |
| 场面反复同构、接续生硬 | 回到相邻范围统筹观看方式、空间与注意交接，不只换色或套转场 |
| 材料不支持所需行为 | 调整真实源范围、补材或与导演改表达，不让动画伪造事实 |
| 具体设计被字体、裁切、父变换或时钟破坏 | 修实现与绑定，保留成立的选择，不反向迎合错误默认值 |

只处理实际问题，不要求逐项填表。原作者接回具体范围与观察，返回真实画面变化；主要内容或跨段含义改变与导演协调。允许改构图、背景、字形和主要动作，保护事实、用户锁定项及无关的成立部分，不用“已采用”挡住重选。当前稿与源码同步，历史修订留在已有记录。

只检查交付画幅，不永久空出整条字幕带；确需多画幅时分别调整主体、路径、字幅和负空间，不能机械缩小全图。交回同源预排、源码及素材范围、字体、颜色用途、字幕规则和接点，说明已观察与待核范围。正式操作沿[共享交接](../../_shared/PROJECT_REVISION_AND_HANDOFF.md)和[场面操作](../../scene-planning/references/scene-operations.md)，不另设审美评分或审批门禁。
