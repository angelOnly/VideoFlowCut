# 物体与排印共同接管：参考生成说明

选择当前内容真正相关、轮廓清楚且能形成局部到整体变化的主体。它可以是卡体、包装、部件、票据或产品。部件分离必须有合理归属，动作只承担展示或图解时，不伪造现实功能结果。

先在局部坐标中画完整主体：外轮廓、薄厚特征、识别细节、主次部件、切口/槽位和真实字形。精细区域集中在当前需要靠近的局部。材质和光向统一，边缘、侧面、落影共同说明空间；简单平面风格也可以成立，不必所有物体都金属化。

入口从有辨识细节的局部开始，经过一次清楚的观看距离变化，露出部件与整体关系。变化前后保留至少一个可追踪的轮廓或纹理，避免观众只看到一块颜色突然换成整物体。

需要离槽的部件先从接触状态抬起：初段露出侧边，接触影变成向同一光向偏移的柔影；随后沿浅弧移到前上方。主体留下对应的空位，部件的细节、文字与侧面一起移动。不要把离开简化为一个平面矩形从整体上滑走。

部件尚在收势时，让本片的大字进入前景。文字与物体初始方向呼应，接近阅读位置后趋于稳定。主物体在其后通过转向、降低对比和适量退远让位；保持足够体量成为文字背后的结构，不很早缩到角落。

第二项结论与第一项组成同一个排印块。结论、部件、整体形成前后共同重心，重要小部件不压到中文字轮廓。根据本片语义选一句或多句主读，不固定绿色第一行、白色第二行，也不强求“不等于”结构。

阅读与运动收势有交叠。当前物体已经认清且结论已读完时及时结束或进入下一段；末尾稳定时间由当前语言和阅读决定，不补满历史样例长度。时间数据以本片秒级计划与实际fps转换。

在正常播放尺寸下检查：局部能被辨认；部件来自原位置；离开中途光影和归属清楚；文字和物体不是分别占空位；结束画面能停住。交付可编辑源码、实际时序、事件和本版检查结果。
