# 深化稿与粗剪的采用和返修

## 接回完整深化稿，重新协调前后声画

接收当前作品的实际预排及必要上下文，先沿前一段、本段、后一段观察画面，再读作者理由与原分镜。只有文字方案时继续交原视觉作者落实预排；有实际画面后再判断主体、背景、文字与动作的共同选择。纸面推演只支持候选方向，动态或声音才能回答的部分保留实际观察边界。

检查观看前提和信息顺序：观众凭什么认出主体和差异，结论是否抢在过程之前，比较参照是否保留。具体决定提前、推迟、保留或删除什么。再看整片节奏：本段是否重复建立前段已讲清的对象，是否打断重要结果，相邻段是否都用同样的展开与收尾。调整实际过程、观察位置与接点，不统一加速或轮换效果凑起伏。

同时协调画面、讲述、字幕与声音的分工。反馈定位到具体画面状态或真实时间范围，写清当前发生什么、造成什么观感、需要调整的过程与保持项，以及受影响的相邻声画。内容、讲述顺序或跨段含义改变时由整片导演协调完整稿；纯视觉的主要画面重选由原视觉负责人返回完整修订，不将其权限缩成局部造型和曲线。

交回吸收深化结果的统一分镜、给原作者的具体续接要求、仍需判断的内容。设计不成熟就继续设计，动态未知就试作；“采用”表示整片选择已经协调，不能代替专项把画面做好，也不能仅返回“更高级、节奏更紧”。

## 三个生产 Gate

以下 Gate 用于专业阶段安排，不新增平台审美门禁。AI 感知不足、尚未审阅或待复核不单独阻挡技术上可执行的制作与导出，但不能据此将确定的设计缺失或实现遗漏记为完成。完整视觉解说片同时对照[默认整场设计](../../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)及本片当前稿检查必需表现；未知保留实际范围，确定缺失继续由原作者返修。技术与用途条件、专业观察、创作完成和用户定稿按[共享规则](../../_shared/PROJECT_REVISION_AND_HANDOFF.md#技术检查辅助审阅与人工定稿)分别报告。

### Gate A：主线与关键声画试排

从初步表达方向与关键未知开始，经必要素材探索、导演实际查看和修订，形成整片叙述、段落与分镜初稿，再按共同方法安排事实核实、定向补材、关键声画试作和全片粗剪。完整剧本不是前期探索的门票；占位与计划不能证明关键材料已经取得。导演明确本轮哪些变化或接点会影响主线，主任务据此分派与提交。动画本身承担叙事时先做主要运动；声音形成节拍时先有可试听材料，不等一条脱离画面的主线先被锁定。

Presenter 用采用的真实语义、人物反应和主要画面试排；Explainer 用实际对象、必要依据与可见变化试排；Vlog 用事件、Selects、现场声和观察过程试排。预排包含真实材料、准确中文、实际字体、字幕占位、主要背景关系与关键动作，短片可整条粗排，复杂片先做最有风险的连续范围。其源码与后续精修保持同一作品；尚未实现的部分注明未知，不能靠灰框、标题占位或只听讲稿宣布声画成立。

主任务回传实际粗剪后，导演连续观看讲述、实际材料与主要动作是否共同成立。规则画面过密先查是否缺行为和体验；材料好却被缩小、裁错或听不见，回使用方修改；素材不合适继续选材；讲法仍像说明书，回导演与文案改正文。已有事实原件不能自动关闭生活画面需求，动画产物也不算外部视频补齐。定位内容、顺序、辨认、反应和接续问题，返回局部修订及影响范围，不新增评分门禁。采用当前版本继续制作，未知明确保留；AI 辅助观察缺口不单独阻止可执行制作和导出，不伪造观看通过。

### Gate B：包装成立

依据当前分镜和实际粗排观察，由原视觉作者在同一作品中精修构图、美术与演出。优先解决影响风格、关键中途和前后接口的范围，回传实际声画给导演；其他段落按各自内容发展，不复制统一入场、展示和退场时间槽。主要布局或背景关系不成立时先重选，再深化细节。临时粗稿只支持已实际做出的部分，不能代替最终美术与听感判断。

代表段要包含本片需要验证的完整发展及实际声画文字，不只展示一个精致入口。独立作品与合成样段使用同一固定源码、参数与内部时序，再加入本版讲述、字幕和前后镜头，以便判断问题来自原设计、实现还是合成；各自生成不同版本不能作为同一作品的对照。

每次接回代表段及阶段合成，都返回可用于后续的设计、需要修改的段落、下一项具体制作范围、整片未完成内容与依赖。样片属于整片任务的一项工作，不能在一个样片处宣告整片完成；其余段落仍按自身内容深化，经导演协调后由原作者实现。

扩大制作前核对当前采用的主线、关键事实、声音约束和完整分镜，优先处理已有明确依据、会影响全片的设计问题，避免批量复制尚未解决的同一缺陷。前期选材、声音构思、动作粗稿与可行性试作可以先做，它们本身用于形成和检验主线。

区分探索与定向补齐：前者检验方向并发现有表现力的材料，后者按采用分镜找具体镜头，都可能在精修前发生。候选回原导演形成采用决定，才继续依赖该选择的制作；其余不依赖部分正常推进，不因“尚未到包装阶段”推迟全部外部选材。

未审、failed、inconclusive 和审美意见不直接转成统一的导出禁令。导演须区分：缺少观察证据的范围保留未知；实际输出已经确认的设计缺失或实现遗漏交原作者修订；工具或依赖问题按技术合同恢复。每次反馈写明实际范围、未成立的观看关系及需保留的内容，不以局部无遮挡、文字可读或作品已生成关闭其他必需表现。主线、材料或声音变化时更新同一完整稿，不只更换版本号码。注意力有主次不等于全片低强度，安静阅读也不免除整片应完成的表现要求。

Gate B 同时防止表现过度与表现不足。克制指注意力有主次，不是视觉和声音始终低强度；人物作为叙事锚点，也允许重点排印、对比图形或短暂重构图成为瞬时视觉中心。完整制作任务应由主工作流主动设计显著性、记忆、情绪和节奏，不等用户逐项要求主画面动效、画内排印与音效；普通字幕在独立层按[本片统一规范](../../captions/SKILL.md)呈现，阅读期间稳定，不用它弥补主画面表现。纯 Cleanup、正式记录或用户明确的低刺激风格保持原范围。

视觉与声音先联合 Spotting，再分别实施。主工作流需确认代表性连续段包含语义铺垫、主要事件、可读停留和恢复，并实际检验图形与 SFX 的感知落点；无声动效样片不代表声音包装完成。用户提供的音效先审阅选型，不因文件可用而全部铺入，也不因担心干扰而全部弃用。

### Gate C：交付成立

技术与用途条件满足后，可生成指定 Revision 的文件，主任务核对 Artifact 并交用户观看；不要求完成固定五轮观察才允许导出。文件生成只证明对应技术结果，不结束确定缺失的设计与实现工作。导演交清哪些观看关系已由实际结果支持、哪些仍需原作者修订、哪些因观察能力受限尚未确认；可执行的返修继续推进。用户决定效果与人工定稿，批准只属于其明确确认的具体文件。

## 质量问题如何退回

主体薄弱、背景争抢、布局重复或演出不成立时，先看实际作品，再对照当前视觉决定。选择本身偏弱，由原视觉负责人重新选择受影响范围；设计没有完成，由其补具体过程；设计明确却实现遗漏，才修对应源码。不要预先限定“几何、字形和时序保持不变”，保护事实、用户明确锁定项与无关的已成立内容；“已采用”“可读无错”不证明美术无需调整。准确但不好讲回原文案，缺可剪选择回原素材作者。编排阶段同样可返修；普通背景替换不无条件连带声音返工。

导演实际复看重要过程和相邻画面，不能只审批设计理由。静帧已可确认的主次、花字造型与重复布局立即处理，动态和声音按实际覆盖说明；新增来源、页码等明确违规直接纠正，但这些局部修复不能代替整片视觉评价。

导演从当前完整声画判断问题是否涉及主线、材料用途、观看顺序或结尾；这些主要关系由导演与原文案协调。构图、美术、演出和接点问题回同一视觉作者，作者按根因重选设计或修实现；声音、人物、字幕与素材使用分别回原专项。具体判断与标准统一沿[专业返修方法](../../quality-verification/references/professional-review.md#根因而不是症状)，不另设一套相反规则。

## 反馈与修订

派回原负责人时携带当前稿、实际片段与范围、要保留的效果、观察到的问题和需同步的前后关系。针对当前层修改，不因为局部缺陷重做全部素材、字幕或配音；也不因技术检查更容易通过就撤掉原设计的组合目标。

当前作者完成修改后，先看受影响的连续范围和接点；主要顺序变化再看回整片。若修订实际更换了表达方式，明确记录为重新设计，并确认主要含义仍成立，不把删除动作等同于修好了动作。

## 退出条件

本 Skill 完成时，主要工作流应已收拢本次范围、适用阶段已实际处理、质量问题已有负责人、未完成的创作与观察范围明确。正式交付还必须由 `quality-verification` 与 `export` 完成；文件生成不自动结束尚未完成的视觉设计与返修责任。
