# 取材需求与材料反馈

## 内容目标与素材探索协作

导演交当前准确句群、段落在整片中的作用、必要前后关系，以及画面还需要补充的表达。初步构图和表现可以作为建议，不把尚未取得材料时设想的来源、媒介、主体组合、机位或动作路径写成唯一搜索目标。用户明确指定或已经采用的来源与范围直接传递。

素材作者根据这些上下文构思可寻找的内容方向，自主生成查询、选择入口、比较候选与推荐范围。导演不必先写完整关键词清单或文件规格，也不要求一个候选同时满足多种备选构思。探索可以在最终分镜和时长确定前开展。

有价值的材料可以在当前任务授权内先取得供比较，不把每个下载都变成最终采用审批；已有明确获取决定立即执行。导演保留整片论述、最终内容采用与主要编排权，素材作者的推荐不自动成为成片选择。

材料返回后，与文案、视觉决定采用、改稿、调整局部画面或继续探索。持续参照和前后意义写进同一份稿；具体取景、字位和机制形式根据实际材料再深化。候选可以使初步构图改变，不只是填入预先完成的版式空位。

### 用材料更新同一份稿

素材作者依据当前完整稿或相关更新、本段准确句群、前后画面和取材目的，返回实际文件、建议范围、值得使用的内容及互补候选。推荐与导演已经采用的选择分清；最终使用哪个来源和范围、对应哪句话、是否改变主要编排，由导演负责。已有明确选择直接承接，不重复要求批准。

导演把选择写回同一份稿，并与文案、视觉更新受材料影响的措辞、观看顺序、取景、字位、路径和声音。范围推荐不等于整片编排权；采用方向内的精确切口和局部构图由原作者细化，改变主要对象、事实或跨段关系时再协调。

取材首先服务当前内容，来源和媒介保持开放。主体、行为、环境、细节及声音中仍有未完成的用途时继续相应寻找，不以已经取得同类资料或已经生成图形自动关闭缺口。材料的横竖比例是文件事实；横窗、全屏、并置和裁切是可以随设计调整的用法。

## 素材选择与直接使用

看片、比较和选段属于创作，不形成素材资格审核。已经看过并选定的同源范围，在下载后直接承接；尚未看清的部分在实际文件或可播放代理中继续定位，不重新提交满覆盖证明或“已审”认证。

导演明确采用后，主任务将真实素材、合法源范围和原声策略写入现有时间线或作品绑定。文件是否存在、能否解码、源身份和时间范围是否正确，由执行层检查；辅助分析缺失不等于素材不可用。分析笔记保留真实精度，不为使用素材补造观察记录。

真实内容与当前讲述不符时，说明具体差异，继续换范围、换候选或由导演与文案修改表达。来源事实与编辑解释分开；不能把未核实设想说成已发生事件。专业选择仍留在当前稿与创作决定中，不新增采用资格对象。

# 从实际素材到混合场面：执行方法 v3

此文件补足主题生产中的“看见具体材料，再写可实施场面”。由现有导演、素材和视觉作者按职责共同完成，不增加代理、数据库、MCP字段或用户表单。纯原创解释、情境B-roll、人物表演和清楚切镜仍有独立价值。

## 何时进入素材到场面方法

用户只给主题，导演直接形成初步角度，研究、文案与材料探索并行。初稿允许描述待找的画面，最终采用的混合场面则必须回到实际文件。只对真正要使用的材料深入观察，不要求穷尽所有搜索结果，也不等全片素材到齐才开始创作。

下面是帮助理解用法的关系示例，不要求每场先分类为原创或复用，也不是新API枚举或必须依次升级的等级。先写本场准确句群、需要看见什么和怎样使用材料，再按实际内容深化。

| 当前关系 | 制作要点 | 可以保持什么 |
|---|---|---|
| 素材内观察 | 指认、裁近或比较源文件中真实存在的部位、状态、文字 | 同源时刻、轮廓、实际位置、原句 |
| 素材与解释共场 | 现实材料提供语境/形体，另层解释抽象关系 | 现实参照、关注位置、已建立条件；明确原创身份 |
| 情境或情绪引用 | 素材提供处境、体验、气氛、反应 | 语义、视听方向、完整真实动作；不硬造几何连接 |
| 独立原创 | 模型或物体自身承担解释与表现 | 自身逻辑、空间、部件与文字关系 |

一次场面可转换关系，例如真实全貌→局部→明确图解。转换点说明是什么改变了，而不是让虚构细节看起来来自实拍。别为“融合比例”把无用素材永远缩在角落；别把所有场面都改成放大镜或沿轮廓描线。

## 导演把材料变成具体场面

导演读候选实际发现后，先决定它能改变正文中的什么：让一个抽象名词变成可观察部位、让一条规则成为可读原句，或使片子更适合日常观察而非知识讲解。必要时交原文案修改全文；素材不只是填入已锁死的画面空格。

在现有场面正文中补这一段，作者直接继承：

```text
当前用途：[素材内观察/素材与解释共场/情境引用/独立原创；按本片实际说明]。
我们先看：[实际文件和源范围中的具体内容]。
随后发生：[图形/窗口/文字依据哪个实际点，怎样改变观看]。
一直能追踪：[同源时刻、位置、轮廓、原句、比较基线等必要参照]。
新内容的身份：[编辑标注、解释层、引用、原创结构；观众怎样辨别]。
下一步为什么来：[当前观察完成了什么，下一画面接住什么]。
改变材料后需重做：[实际受影响的焦点、裁切、标签、路径、时序和语言]。
```

“基站局部→原创资源池”还不够。要说明局部是什么，是否继续可见，模型用的是这个部位的形体还是只保留语义参照，资源池是否新概念，为什么此刻需要它。没有实际几何联系可以明确切镜；切镜不是失败，但不能登记为同源局部延展。

对声明为素材内观察的场面，换成构图不同的同题文件，目标点与路径通常应重算。若全都不变，检查是否实际只是背景图。这个反事实问题不用于否定普通B-roll、独立排印和完整表演镜头。

## 谁交给谁，以及少了什么回哪里

首次主要表达由素材作者交原件、观察与创作机会，导演与文案改稿，同一视觉作者深化源上构图，导演统筹完整采用稿；协调者提交后将实际版本与预览交回原作者，审片作者检查前后上下文。已采用方向内的普通选段、构图和切口由原作者继续，主要对象、事实或跨段关系改变时再回导演，不为每次局部修改重复采用。

只缺某个目标点或源时间：回素材/视觉作者测定；缺为什么看这里：回导演；设计正确而圈漂移：回原作者；工具拒绝输入由主任务按[写入恢复](../../production-coordinator/references/project-writes.md#失败与不确定结果)核对，只有确认平台自身 Bug 阻断工作才报独立修复工单。协调者不把完整交接压成“做个高级观察圈”，也不自己发明原片没有的细节。

同一场的“结合说明”是采用稿的一个段落。可以同时用于素材、视觉、时机和审阅，避免复制成四份互不相同的表单。最终总长、配音、风格和比例由本主题的实际内容决定，不继承历史样片条件。

## 材料与表达的共同修订

交接必须能说明材料中实际观察到什么，以及它对当前观看任务有何贡献。来源只有题材相关不算源内观察完成；来源可核事实也不代表它已完成整片情境与行动表达。

未看材料时可以提出镜头方向，实际源动作、裁切和遮挡随取得的内容确定。换材或改范围时，回当前稿确认表达怎样被接住，以及哪些设计需要更新。保留真实来源、源范围、用途和技术绑定，不保留素材资格审阅、满覆盖证明或重新认证义务。
