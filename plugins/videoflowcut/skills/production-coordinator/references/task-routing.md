# 任务范围、真实分派与原负责人续接

本页只解决交给谁、交什么、何时接回。项目定位沿[项目基础](../../project-basics/SKILL.md)，正式操作沿[项目写入](project-writes.md)；角色身份、版本和完整交接字段以[共同交接约定](../../_shared/PROJECT_REVISION_AND_HANDOFF.md#代理角色与交接)为唯一依据。

## 按用户实际范围分派

完整视频由主任务以宿主 `spawn_agent` 启动持续负责的[总导演](../../production-director/SKILL.md)，导演只选一个主要视频流程并提出专项范围与依赖。局部创意直接交相应作者，不重跑整片。用户指定“字幕上移 20 像素”可由主任务执行；“放哪里更舒服”需要字幕作者判断。指定文件导入、客观转写和媒体参数读取可直接执行，素材采用、原话删留和表演选择仍是创意判断。

尚无 Project/Revision 时，把用户需求和真实建项状态交导演形成建项建议；主任务依明确参数创建后读回版本，再交导演确认。探索没有最终 Scene、Beat 或精确时长也可继续，不为交接字段编造对象。

| 当前判断 | 原负责人按需使用 |
|---|---|
| 主线与跨段取舍 | [总导演](../../production-director/SKILL.md) |
| 原创解说、声画初稿或原话剪辑 | [文案](../../narration-writing/SKILL.md)、[语义剪辑](../../semantic-continuity/SKILL.md) |
| 取材探索、候选比较与辅助镜头用法 | [画面取材](../../visual-asset-sourcing/SKILL.md)、[辅助镜头](../../cutaway-planning/SKILL.md) |
| 关键画面与场面任务 | [视觉美术](../../visual-treatment-planning/SKILL.md)、[场面规划](../../scene-planning/SKILL.md)、[空间层次](../../depth-composition/SKILL.md) |
| 动作发展、实现与时机 | [完整演出](../../motion-brief-writing/SKILL.md)、[动画实现](../../remotion-production/SKILL.md)、[落点](../../effect-timing/SKILL.md) |
| 证据、配音、人物或字幕 | [证据表达](../../evidence-visualization/SKILL.md)、[配音](../../voice-production/SKILL.md)、[人物表演](../../avatar-performance/SKILL.md)、[字幕](../../captions/SKILL.md) |
| 音乐音效与专业审片 | [声音取材](../../sound-asset-sourcing/SKILL.md)、[混音](../../audio-finishing/SKILL.md)、[审片](../../quality-verification/SKILL.md) |

这不是人数或阶段清单。同一授权视觉作者可连续负责美术、演出、源码和修订，不为案例、关键帧或另一项 Skill 新建代理。子代理不递归分派，新增专业需求返回主任务调度。独立审片尽量交未主导该内容的合适作者；确需复用时说明熟悉稿件的局限。

## 让材料与预览回到当前完整稿

导演与文案先共同发展完整讲述和声画草稿；材料回来后共同改稿，声画试排回来继续调整叙事。取材请求带准确句群、前后画面、材料角色、需要的细节和搜索起点，写法查[材料反馈](../../production-director/references/asset-briefing.md)。不压成主题词，不把“可比较”改成额外硬条件，也不要求最终分镜已锁定才能研究。

作者返回完整产物、参数、理由和证据请求。缺设计或缺全文用 `followup_task` 回原作者补齐，主任务只补真实 ID 和无歧义装配。完整场面的深化稿正常交原导演协调，返回吸收设计的完整分镜及差异，再续接原作者实现；局部确定参数不用逐项重新送审。取消材料或动作时，核对原观看任务是否已被具体表现接住，不能以“简化”为由只交摘要。

候选材料及观察交原导演、文案和相关作者，导演确定采用、改稿或继续搜索，再推进依赖这项选择的制作。已有观察随文件和源身份回传；材料、源范围或用途变化只补核对受影响部分，不因新增 Asset 清空已有选段。得到明确获取决定后，主任务继续取得实际文件，不以“后续可下载”结束需求。

作品、代表段和粗剪的真实预览回原作者修订，跨段问题回导演，最终专业观察交审片作者。完整视频不以一个样片结束；等待一项依赖时继续其它无依赖工作。真实稿件留在宿主消息、附件及已有产物中，CreativeDecision保存采用决定与引用；长稿缺失回负责人补齐，不用摘要或擅造接口字段代替。

用户指定或当前稿已采用参考时，传真实入口、原片范围、借鉴与不照搬部分；未指定且确需参考才进入[案例库](../../motion-case-library/SKILL.md)。查不到合适参考可继续创作，不默认指定历史案例，不要求每位作者重读全库。参考作品不自动成为本片素材，链接或拆解文字也不证明看过原片。

## 名额不足时续接与接替

分派前用 `list_agents` 核对实际列表和上限是否包含主任务。`completed` 不证明名额释放；`interrupt_agent` 不用来清理名额。宿主没有关闭能力时，不编造调用或调整全局上限。

原负责人仍在列表且空闲时用 `followup_task` 续接；正在工作时等待该项依赖，不再创建重复负责人。原负责人不存在时，有空位才尝试恢复。列表未满仍被拒绝，保留调用前后列表、上限说明和原始错误，不自行推断计数泄漏或反复重试。

名额已满时优先由现有、职责合适且已结束当前工作的代理接替；合适作者都忙就只等待这一项依赖。按[接替与结果接收](../../_shared/PROJECT_REVISION_AND_HANDOFF.md#负责人接替与结果接收)确认新负责人、版本与完整材料后接续；旧负责人迟到结果不直接提交。恢复失败先诊断，不能回退为主任务创作。

## 工具或观察材料不足

首次分派和续接后，作者检查本轮实际工具表，区分工具不可见、Schema不匹配、调用失败和材料不足。主任务记录实际工具缺口，必要时用自身可用的正式只读 MCP 补事实；专业判断仍由原代理或确认接任者完成。主任务转交 Schema 不等于子代理工具可调用，主任务成功交接、子代理直接 MCP 访问恢复是两个结论。

需要观看的预览、帧或音频必须由接收者实际打开。请求应说明对象、版本、范围和缺失项；输入变化带差异回传，不能只更换版本数字。缺连续画面或声音只保留相应待审范围，不把静帧当连续观看，也不因辅助审片未完成阻止其它制作或技术条件满足的导出。素材审阅分流查[源素材审阅](../../visual-asset-sourcing/references/source-review.md)，故障与未知结果查[写入恢复](project-writes.md#失败与不确定结果)。
