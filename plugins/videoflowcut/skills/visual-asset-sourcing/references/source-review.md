# 素材构思、搜索与使用建议

本页帮助作者从当前文本和画面作用产生素材方向，再比较候选和推荐用法。取得操作见[素材查询与本地化](acquisition-operations.md)。素材作者推荐，导演决定最终内容采用和主要编排；不形成素材使用资格。

## 从文本形成可寻找的内容

先读相关句群与前后关系，判断画面可以直接呈现、补充、对照或增强什么，再提出可查询的内容方向。不同来源和媒介都可参与，不为所有任务预设同一种材料类别，也不把每句话拆成一个名词搜索。

查询使用当前内容的辨识线索。一条查询服务一种寻找方向，多个可能分别探索，不把它们合成必须全部满足的条件。需要更准确时补充与当前意思真正有关的信息，不自动叠加拍摄身份、审美词、源比例或全部上游建议。

结果过少，调整自行添加的限定或改变表现方向；结果同质，改变内容关系而不只换同义词；大量无关，再补辨识线索。零结果、部分结果、获取失败分开处理，换入口不丢弃已有候选。新查询产生新的发现，不撤销旧资源。

## 比较后反馈，不以链接结束

比较候选中可实际利用的内容、构图、变化、文字和声音怎样服务本段。静态与动态、不同表现手段各有用法，不用一种材料的评价替代全部选择。画面需要运动时寻找能够承担变化的内容，或者提出当前素材怎样与图形共同完成，而不以一组图片自动认定动态需求结束。

有价值的候选尽早取得并返回建议范围、理由、互补内容和可能改善当前稿的发现。推荐不是最终采用；导演决定主要用法，对应作者在采用方向内细化切口与构图。一份文件下载成功不结束尚有缺口的任务；材料足够也不为数量继续搜。

## 观察完整过程，再确定可用范围

没有观察时先了解全貌，再看可能采用的连续范围与必要前后文。已看过候选就从对应范围继续。精确切口、短暂动作、口型或微表情会改变选择时，才补最小必要的密集观察；不因技术上能多取帧就全片重看。

先恢复事实顺序：事情怎样发生，人物何时知道什么，回答针对哪个问题，反应属于哪个事件。之后可以设计观看顺序，但重排不能制造不存在的因果、同时性、知情状态和人物关系。

选择范围时同时考虑最短不失真边界与自然观看边界。动作的准备、主相位、结果和反应是否完整，呼吸、目光、手势和环境声是否需要余量，切口是否留下半音节、半动作或突然情绪变化，都影响入出点。句号、静音、镜头边界与音乐拍点是线索，不自动等于切点；说完一句之后的吸气、笑声或目光可能才完成这句话。

查看目标画幅下的实际清晰度与可裁范围。原字幕、水印、黑边或配乐是否遮住重点，主体会不会出画，原动作是否已被切断，所需原声能否保留。长文件的总时长不能证明其中有完整可用的短动作。

同一句台词、服装、邻近文件或相似构图不证明 Take 可以互换。比较替代或 Coverage 时，结合完整性、表演、声音、动作、视线、空间及接点；最后一遍不一定最好。真实访谈和证据内容不能由两段残句拼成说话者未表达过的结论。

## 清楚区分事实、解释与未知

技术探测证明文件、编码、时长、帧率和音轨；转写提供语言候选；抽帧支持采样时刻的画面；多模态描述提供事件线索。它们各有精度，不能互相替代。拿到可播放代理也只说明能播放，仍需实际观察。

重要陈述分清直接声画事实、用户明确提供的身份或背景、专业解释与使用建议，以及未知和替代解释。“人物停止操作并看屏幕”是观察，“适合在这里停顿”是用法，人物动机不能凭姿态补出。照片没有动作时间，作者估计的位置不能记成已有测量。

需要局部设计时，交清源内可辨认的部件、区域或原句，实际位置与源时刻、清晰度及遮挡变化。可靠定位不足就标估计或未知，不声称逐帧跟踪。不同地点、时间或来源的近似画面不能称为同一连续过程。详细坐标与播放语义由[实现方法](../../remotion-production/references/material-space-and-time.md)处理。

定向观察可以问：当前确实看清哪些结构与文字，位置和遮挡怎样变化，哪里有前后余量，哪些信息仍看不清。保留源动作，不让预期分镜变成观察结论。有宿主视觉与播放能力时作者直接观察；模型复核只在补具体缺口时使用，不要求每条素材新增分析任务。

## 比较候选怎样服务当前段落

比较候选实际提供的内容及其在当前段落中的作用：主体与信息能否看清，构图和变化是否有表现力，文字、动作或声音能否与当前稿配合。按材料本身判断照片、视频、插画、录屏、图表或其他内容的价值，不以同一拍摄标准评判所有形式。内容同样贴合时选择观感更好的；有独特意义的内容不因外观普通就自动排除，漂亮但无当前用处的材料也不强行采用。

高影响选择仍不确定，或当前选段不能完成任务时，比较真正有关的替代：其他 Take、前后范围、早晚切口、原声保留、硬切或不插入。已确定且有依据的选择直接使用，不为每个候选补一份反事实论证。

把候选放进相关前后内容比较。需要组合时，寻找能承担不同作用又可以共同观看的材料，允许同源或异源，不固定配齐某种分类或景别。说明这些内容怎样支持讲述、形成差异、延续关注或进入下一段。不同来源的内容不能伪装成同一事件，连续出现的材料作用重复而无发展时删并或换更有用的范围。

返回可以试排的推荐及有价值的替代，说明共同观看多完成了什么、还有什么缺口。最终故事与主要用法由导演采用；具体裁切、全屏/PiP、切口和声音由对应作者细化，搜索相关不等于可以自动放置。

## 将观察变成可继续设计的反馈

返回实际文件、建议范围、片段发生什么、哪里值得看、怎样支持当前句群和前后关系，以及有价值的替代。需要在素材上继续设计时，补充实际动作、方向、边缘、空间和声音机会；不把标题或未见内容当作观察。技术信息沿已有媒体结果携带，不新建评分或资格证明。

推荐与已采用选择分清。导演负责最终来源、范围和主要编排；视觉或剪辑作者在采用方向内细化取景、精确切口和声画接点。材料带来更好的讲法时，交导演与文案更新同一稿，素材作者不独立重排整片。

材料尺寸、主体位置、实际源时间和裁切损失作为事实提供；横窗、全屏、并置等只是当前使用建议，不变成永久条件。来源或范围改变时，只更新受影响的观察与设计。已经取得资料，不代表尚缺的行为、环境和声音用途同时完成。

已有选择在取得文件后直接承接；未选定范围则在实际媒体中继续选段。不提交满覆盖证明、审核通过或重新认证请求。技术就绪且范围合法的素材可以试排，辅助分析未完成不赋予素材不可用身份。真实内容不适合时指出差异，继续换范围或换候选。

## 不匹配与证据不足时继续哪里

媒体读取失败按[审阅诊断](acquisition-operations.md#审阅与诊断分流)处理；保留有效内容，不产生素材资格。

| 当前问题 | 继续方法 | 必须同步的影响 |
|---|---|---|
| 只有较短的真实动作 | 组合建立、细节观察、清楚切镜或图形接续 | 连续源范围、稿件和时间，不虚构更长动作 |
| 只有可辨照片 | 明确资料图片，设计静态整体与局部观察 | 媒体类型及不再适用的动作时长 |
| 全貌清楚、细节模糊 | 换源、换关注点、收窄主张或进入明确原创示意 | 原创局部不称为实拍放大 |
| 移动目标无法定位 | 选择短稳定范围、合适静态材料或正式登记源帧 | 冻结/恢复位置，不暗补帧或循环 |
| 只有名词相同 | 有理由地作情境引用，或继续寻找 | 不保留无作用的装饰窗口 |
| 来源不支持台词 | 继续核实，或由原文案与导演改准确说法 | 动画不能“证明”缺失事实 |
| 辅助读取只返回部分内容 | 继续使用已取得的原件与有效范围；只补当前选择真正缺少的信息 | 如实记录未看未听的部分，不产生素材资格或使用阻塞 |

换成照片或原创模型后，旧实拍过程已不存在，必须重排观察与接续。停止一个候选与取消镜头任务不同，普通无结果继续调整策略。空输出或超时不能证明素材损坏；平台故障由主任务依诊断处理，不绕过正式工具或重放未知下载。

## 放进场面以后复核

候选单独成立不代表在成片里成立。对当前采用范围及前后接点，连续声画检查动作、语言、空间、注意与事实关系；接缝或环境声不清楚时单听，主次或视线不清楚时静音看。只做本次判断必要的检查，不让每张照片自动经过整片审片流程。

内容缺失回选材；内容合适而裁切、声音或接续有问题回使用方；主线不适合这组材料回导演。实际未听或未连续看过的范围如实保留。交接与版本恢复统一沿[共享约定](../../_shared/PROJECT_REVISION_AND_HANDOFF.md)，不以文件存在、分析成功或已放入 Timeline 代替本次表达的完成。
