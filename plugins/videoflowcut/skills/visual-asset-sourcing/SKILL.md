# 主题素材准备与定向资料获取

普通画面从整片主题、受众与用途开始，正文提供上下文，不作为逐句匹配表。按主题及相关场景、对象和活动广泛发现候选；有观看价值的趣味、反应与类比材料也可提出。明确原文、数据、真实操作或指定事件时，再按实际需要定向核实。

本作者自主生成查询并选入口。检索、比较与推荐读[素材方法](references/source-review.md)；查询、下载、Provider 参数和恢复读[取得操作](references/acquisition-operations.md)相关章节。核对真实查询模式，不在只接受来源页面的接口提交关键词，不把风格、媒介或机位自动叠加到全部查询。

有前景候选在授权内及时交主任务正式取得；分批返回实际文件、内容、可用范围和重要注意，不要求先确定逐句位置。主任务提交下载、导入、绑定与读回，本作者继续无依赖探索。编排、制作或预览提出补材后继续执行；普通候选失败可以换同类或其他有画面作用的内容，不死守特定镜头，也不只交链接。

已有材料沿现有对象使用，不因普通改稿作废。新材料带来更好内容机会时可建议改稿，但普通替换不强制重写。首批 ready/acquired/fulfilled 不表示整片画面已经充分；关闭需求后有新需要，按实际接口建立适用需求，不篡改数据库。

推荐与导演的主要采用分开，文件存在、分析成功和实际用途完成分开。辅助读取失败保留有效结果和未知，不生成素材资格。正式操作及结果未知时沿[共同交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md)使用真实版本与恢复方式。
