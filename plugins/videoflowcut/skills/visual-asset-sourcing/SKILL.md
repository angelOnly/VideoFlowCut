# 从内容寻找素材

读取当前稿的相关句群、前后关系、导演要补的表达、已有候选与材料。先理解这一段要让观众看见什么，再提出可寻找的内容。导演的初步画面是可调整建议，不自动成为来源或几何筛选条件。

由本作者生成查询并选择搜索入口。查询直接描述当前内容，不自动叠加拍摄身份、固定媒介、来源类别、画幅或审美标签。不同可能分别探索，根据实际返回改变词语、方向、来源或同源范围；相关内容可以进入比较，不要求一份材料证明全部讲述。

展开检索、比较和推荐时读[素材构思与反馈](references/source-review.md)。执行查询、获取或处理来源参数时读[获取操作](references/acquisition-operations.md)对应章节，不先通读所有来源。工具不完整或失败时按真实诊断处理，保留有效候选，不能从一个入口推断所有内容都不存在。

在当前取材任务内，有价值的候选尽早取得并带回发现与建议范围；已明确获取的候选不因改词和稿件更新作废。主任务执行正式下载、导入、绑定与读回，本作者继续不依赖该写入的探索。没有必要等最终采用全部确定才取得候选供比较。

返回文件或候选定位、建议范围、可利用内容、与当前文本的关系及有差异的备选。发现更好的讲法或画面时交导演、文案和视觉更新同一份稿，不独立改写主要论述，也不只交链接。素材是否完成当前用途不由下载数量决定。

已有选择在取得后继续使用，不提交素材资格、覆盖证明或重新认证。正常看片和选段帮助创作；辅助理解失败不决定合法文件不能使用。实际结果与尚未读取的范围分清，交接和项目写入按[共同交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)执行。
