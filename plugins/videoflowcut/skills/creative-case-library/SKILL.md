# 创意参考检索与观看

先圈出本片已具备代表素材、可以开始研究的观看问题。要找整片组织时，留意空间、明暗、排印、视觉中心怎样跨场变化；要找完整场面时，追到一次建立、发展与收束；只补局部时，定位动作前、关键中途和接回。一个作品可能同时提供几种观察。参考数量由本片问题和实际观看结果决定。

首次在本任务参与创意研究时，按本人职责完成 `../creative-sequence-design/references/R40-机器人进厂/README.md` 的“首次研究的原速对照”。已在角色入口完成的作者直接用本片材料查询。当前已锁定完整参考而本次只改素材时，读同版本片稿、原片及受影响的映射段。

## 根据当前内容和材料写查询

**一、先想这段给观众什么体验。** 打开本场代表素材和全片可选素材。视频看主体动作和前后状态，静图看整幅和可取的局部。结合本场在整片的位置，想清观众进来时先注意什么，随后在哪一刻会产生期待、看出反差、感到舒展或愿意多看一眼，以及这种感受由什么引起。文案、原话和事件经过用于定位场面并核准内容。素材中的动作、色形、人物反应和景别也可以给出值得发展的观看角度。

**二、找出让这种体验成立的对象关系。** 回到本片素材，找出观众需要跟住谁、拿谁和谁比较、哪一次变化会影响其他对象，或者哪处细节在前后出现时有不同意味。试着拿走一个对象或调换两个状态的先后，判断想要的感受在哪处消失。将这个关系留进查询。人物与环境、动作与反应、局部与整体、影像与字组都可以共同承担这种关系。

**三、把对象关系翻成镜头表达。** 决定先给观众看什么，暂时留住什么，何时让其他对象进入，在哪里揭晓或停留。比较时想清哪些对象需要同屏或在相近状态下先后出现；希望观众感到意外时，先建立能被后一拍改变的预期；希望观众认回主体时，先让其可辨特征被看清。用文字、图形、遮挡或镜头变化引导观看，把具体版式、字形和转场做法留给候选启发。已有明确的画面要求时带入查询。

**四、写成跨题材的自然语言查询。** 保留对象关系、观看先后和最后的感受或发现。将专有题材名换成其他场景也会出现的对象和动作。只写情绪词时，补上引起感受的可见变化。已经写成窗口、列表或按钮布局时，回到上一层，说明这组布局原本想让观众看到什么。同场有不同的观看机会时，可以分别查询，每条集中探索一种表达。用 `../creative-sequence-design/references/R40-机器人进厂/角色指令逐段拆解.md` 中的“从旁白写出第一轮创意查询”对照怎样从期待、因果或对比推到可查找的画面。

**全片美术查询。** 观察一条片怎样在不同布局、明暗和景别中协调各类素材、背景、花字与重点色。比较候选中不同构图的场面，交回实际时刻和可沿用的美术做法，由视觉作者亲看后选定。

例如，文案讲“一次操作成功，反复运行时仍会出现异常”，实料能看到一次完整操作、若干次结果和看护者。可以查“先让人跟住一次完整动作，再让前面出现的结果持续在场，随后由一个不同的结果或人物反应改变观众的判断”。查询保留先后、累计与例外，给候选留出不同表现形式。

## 取得并比较候选

核对实际 MCP 工具定义。用当前项目的 `search_creative_cases` 提交自然语言 `query`。空查询用于浏览目录，已有编号用于精确定位。对从零选片，读回并比较实际语义候选后再定段。

返回语义任务时，通过 `track_job` 跟进原 `job_id`。任务完成后使用返回的 `readback.tool` 和 `readback.arguments` 读取候选页，再按 `next_offset` 继续。核对检索方式，确认为实际完成的 `semantic_used=true` 结果。主任务代为执行时，将当前页候选、分页信息和诊断交回原创意作者继续读卡、观看和比较。

遇到排队、失败或来源版本变化时按实际状态续查原任务，保留已取得且仍适用的候选。待语义结果实际返回再比较。来源过期时读新指纹和新正文，重新定位受影响的原片区间。

## 看过视频，再决定选哪一段

用 `read_creative_case` 读取候选 ID 与来源指纹对应的正文、原片入口和分镜。需要定位仓库卡时，从仓库根目录的 `references/motion-cases/skillry/creative-index.json` 取出该卡记录的 `card`，相对该索引所在目录定位正文。通过案例库播放器的 `preview_url` 原速连续看原片。研究整片时先看完整作品；借一段时从主体可被辨认之前看到结果交出；借动作时看发起、经过、落定及接回。声画共同起作用时打开原声，快动作需要辨认才慢放或逐帧。只看到构图就只记录构图，速度、声音和尚未辨清的遮挡回到对应时段补看。

**先看候选实际给了观众什么。** 找到愿意回看的时刻，指出前一拍让观众注意了什么，哪一个可见细节兑现或改变了预期。精彩处也可能来自稳定构图中人物、环境与文字的呼应，或动作方向恰好接上下一镜。沿观众的视线跟住素材，看文字、图形、遮挡或镜头怎样改变素材与其他对象的关系。优先比较几次变化各有作用、前一拍为后一拍铺垫的素材与动效混编原段。各种片型按实际画面判断。主要看点在控件反馈的片段可作局部动作参考。

**比较有竞争力的演法。** 分别说清各段最精彩的区别，以及会把本场带向什么感受。比较采用另一段时观众会少经历什么。候选带来了更贴合本片素材的表达时，可以更新原先设想，写清实际发现。若候选集中在相似页面和控件，检查查询是否提前规定了界面布局，再回到实际材料，从另一种动作、对照或镜头关系发起查询。整场组织仍然欠缺时，继续找完整场面，已找到的局部动作按实际用途保留。

拿同一批本片实料比较最有竞争力的候选。靠同一主体跨镜成立的，检查可辨特征；靠累积成立的，看新素材进入时早先的材料能否仍被认出；靠字与影像同场成立的，把准确中文放进目标画幅。向前找到看点如何建立，向后看到结果读清与接手完成。截取后看点消失，调整区间、补材或换候选。

把实际查询、卡或原片来源、实看起止、关键时刻、本片试用的文件和源段，以及选择或放弃的理由写入原研究。只作美术参考时标明色彩、字形或层级的用途。决定采用完整原段时，在本次研究里记下亲眼看到的入口、中途与出口，标出源时刻。创意作者试过本片源段后，把所借的关系和本片演法写入本片稿，逐拍制法见完整迁移专项。
