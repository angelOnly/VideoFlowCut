# 动效时机、语义落点与媒体事件

读取本次采用的场面、准确声音与时间精度、前后接点，以及同时在场的人物、字幕和其他声音。只改一个切口就核对该范围；新演出尚未决定对象与过程时先由原作者完成[演出设计](../motion-brief-writing/references/performance-design.md)。专业判断与正式提交沿[角色交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。

## 先决定何时要看懂，再反推启动

开始出现、开始可辨、达到可读状态与读完是不同时间。先沿实际观看过程判断：哪句话到来时新重点应已认清，当前动作或阅读何时完成，下一关注最早何时进入，何时真正接管。这些关系写在同一场面稿里，不新增四个必填字段。

由所需可读时刻反推旧重点退让、新对象建立与显露。文字刚淡入、投影很小或仍被遮挡时不算已经开始阅读；动作收势和阅读能够交叠就不重复增加等待。先让对象进入再说名称、看见结果后解释、语言先铺垫再出现结果，都取决于当前观众已知和信息顺序。

讲述句群、字幕卡、视觉场面与技术作品不同。一段自然语音可以有多张短卡，同一对象跨句发展，作品中也能有多个镜头；换字幕不重建场面，作品边界不应截断语义或重播源动作。

## 用语义关系描述落点

| 关系 | 适用的观看安排 | 需要核对 |
|---|---|---|
| anticipate | 提前建立待识别对象或预期 | 重点到来前能认清，且不提前泄露答案 |
| land_on | 动作完成或可读状态与结论、数字、结果共同落定 | 同步的是主要变化，不只是动画开始 |
| react_after | 在包袱、结果或反应后回应 | 不抢先泄露，留出实际释放 |
| hold_through | 解释、比较、阅读或操作期间维持参照 | 语句结束是否真的意味着用途结束 |

这四种关系不是每句话必须填齐的阶段。已有 semanticAnchor 的具体类型、目标与参数读取当前 Schema；没有真实目标或 Timing，不制造精确锚点。

不同内容也不决定唯一顺序：

- 数字作为比较基线时可先出现；承担揭晓时安排到当前语义落点。单位与基线清楚，阅读期间数值可辨，不让无意义计数抢走时间。
- 逐步发现列表时随讲述进入或聚焦；先理解整体再比较时先给结构，再指认当前部分。
- 原件身份尚未建立时提供必要上下文；前文已经明确来源、本段只看细节时直接进入有效范围。是否再给全貌取决于观众是否仍能认出来源。
- 因果与流程可以原因先行、结果先行或往返观察，按论述需要组织；动画顺序不能暗示证据不支持的因果。
- 比较需要延迟披露时保留先前参照再引入差异；需要整体判断时同时建立双方。必要条件不为反转隐去。
- 笑点通常保护包袱后再回应；行动入口在观众具备行动理由后给足辨认和操作时间。已知语境可以直接进入，不强迫每段重新铺垫。

## 初始节奏与预览修订

创意探索时，先说明画面与讲述的先后、重点需要何时看清，以及动作之间怎样交叠。具体时间尚未确定时，标明估计性质。

进入实际制作后，使用当前文案对应的声音和素材源范围安排时序。先确定重点出现、结果形成和阅读的时刻，再安排动作从什么时候开始，以及前后内容怎样接上。

参考中的快慢变化、短促动作、停顿和交叠参与本片时序设计。根据配音调整启动位置、动作交叠、文字数量和阅读面积，继续完成所选场面的节奏。

实际配音返回、正文修改或素材更换后，重新核对重点出现、结果形成、阅读时间、素材可用范围和相邻接点。当前场面无法支撑新的讲述长度时，交视觉与创意继续安排后续画面，涉及正文或声音修改时由导演协调相应作者。

作品形成连续范围后，查看动作速度、读字、素材变化和前后声画。根据实际问题调整对应过程，再查看修订版本。真实声音和源事件的时间精度按实际资料记录。

只有用户明确锁定的讲稿、声音、总长与边界构成对应硬约束。当前稿和首版配音可以由导演与文案、声音、创意及视觉作者按职责共同调整。重配后以实际声音重新校准，专项修改按已有授权执行。

## 时间精度决定能承诺什么

segment_exact 只保证 SpeechSegment 起止，sentence_exact 只保证已有句段范围。适合段首、段尾、Scene 切换与完整短语，不能按字符均分变成词级点。chunk_coarse 只用于定位和低频变化；无时间证据时不做正式同步。真实 word_exact 也不要求每词跳动。

需要更细的感知落点时，在支持调整的 Cue 上连续声画复核，并说明这是感知校正，不是 ASR 词时间。不要只为强调重建已确认语音或强拆原声字幕；稳定卡边界仍按[字幕合同](../captions/references/caption-operations.md)。字量、画面与可修改讲述有冲突时回原作者共同处理。

拿到实际声音后，核对文字、读音和句群，再安排提前、共同落定、回应或持续。配音方向要说明怎样说、哪里展开或收紧，不只列“不要夸张”等禁令；标了重音也要真实回听。

## 阅读、保持和无用途等待

观众可能需要认出对象、读文字、比较、理解，再回人物或下一场。稳定是达到有效阅读条件，不要求所有层静止。复杂页面或陌生名词读不完时，改字量、字幅、观察步骤或密度，不靠缩小字体与加速解决。

看第一重点当前是否仍有任务。阅读、比较、表演、源声、空间与情绪可以支持保持；背景人流、漂浮或字幕换卡不能自动证明主要内容在发展。疑似空等按原因修订：

1. 合并无用的重复建立、缩短过慢推进；
2. 在允许的收势区间提前下一关注，保持主次；
3. 需要时重排边界，把时间留给真实过程或反应；
4. 句群仍重复或与画面冲突时，回文案改准确全文；
5. 同步声音、源范围与接点，再看当前合成。

换材料后重新计时。实拍换成静态主体，原来的操作或移动已不存在，不能沿用原搜材时长让模型等待。定格、回看或解析有具体用途可保留，不能隐式冻结、循环或长尾慢放补足旧长度。

## 人物、字幕与声音怎样同时发生

检查当前手势、字幕换卡、其他效果、Cutaway、音乐强拍与音效。服务同一事件的文字落定和短音效可形成统一重音；服务不同焦点才需要延后、减弱、拆开或删除。不能把所有同步峰值机械判为冲突。

SFX 的文件起点、可听起音、主要攻击和尾音不同。渐强声可以先起、攻击再落在动作上，短攻击可以直接确认结果。检测或波形只提供候选，实际声画决定感知偏移。要把起音、主攻击和视觉事件换成 Item 时才读[事件与声音绑定](references/event-and-audio-binding.md)。

## 四时钟与修改范围

分清本版语音时间、Timeline 全局帧、作品局部帧、源媒体时间；预览文件还有自己的零点。作品动画与命名事件共用当前 schedule，实际源时钟独立于外层布局。完整公式与跨 Sequence 行为见[素材坐标与时间](../opendesign-video-production/references/material-space-and-time.md)，不凭源原生帧号猜作品偏移。

Cue 的入口接上真实前画面，只有连续关系才允许首帧已在运动中；结束不留下无归属残影。短场面容纳不下时先改内部编排或简化，只有授权允许才延长边界。固定作品内部时序改变要生成新版本，不能裁放置长度冒充内部修订。

返回当前范围的起止、事件意义、落点依据、阅读条件、时间精度与复核请求。整体平移与内部改动分清；改稿、换材或重配后仅重做受影响作品和接口，字幕、声音同步复核。网页感知微调记录原精度、目标 Revision、原因与观察范围，主线重编后重新确认。字段有效、源码事件存在和技术渲染均不能证明节奏成立。
