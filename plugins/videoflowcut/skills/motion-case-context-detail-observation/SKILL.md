# 整体定位与局部观察

## 1. 何时使用

材料内有值得指认的部位，需要进入局部，同时让观众保留它属于哪个整体的参照。先由导演确定当前内容与主要观看任务，再由同一视觉/动效作者学习本例；不新增代理，不要求用户先提供参考视频。

## 2. 资料与实际验证范围

[原片观察视频](assets/observed-preview.mp4) · [教学生成指令](references/generation-prompt-v1.md) · [实现定位](references/implementation-notes.md) · [来源与状态](case-record.json)

本例来自用户提交的r92作品。原片先用全塔视频建立现实情境，再切到原创浅银灰设备结构；观察圈放大的是同一原创Device中的连接件，而非真实视频里的细节。圈随后向右上让位，为关系图腾出空间。

本片不能用作“真实天线同源动态跟踪已验证”案例。真实视频局部圈分支需要当前实际素材重新验证；设备示意的观众身份说明仍要清楚。 新教学指令未重新渲染；原片反馈不能替新指令背书。

## 3. 应迁移的设计

读完整教学指令，明确借鉴的观看关系、美术组织和中间过程。回到当前主题重做主体、真实材料、准确文字、配色、声音与节奏；案例历史时间只用于定位视频，不复制到新片默认。

## 5. 返回当前制作任务

学习后输出当前场面的完整执行正文、关键造型/构图、路径与遮挡、可见文字、有效时间、实际绑定和中途检查点。继续完成实现与合成，而不是读完案例就结束。

原片、教学指令、当前新片各有独立版本与观察记录。平台工程校验与主观观感分开；无法连续观察的部分保留真实未知。
