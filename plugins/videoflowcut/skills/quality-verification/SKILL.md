# 审片与交付核验

接回作品先核对项目、Revision、作品、冻结版本与实际可播放的根帧范围。从目标动作前播放到结果已被读清且后场接住，再定位复看问题。检查素材本身是否仍在运动、旧主体还有没有被认回、关键层出现时原有层是否仍在、落点和旁白或同期声能否听看为同一次变化。完整新制取得全片后，在现有工作台原速连续看听整片，专门覆盖场间接口与无旁白区间。原片同状态图只支持构图结论，音轨存在或波形只支持技术判断。未实际听到的部分记为待核。

## 全部视觉单元和参考的完整覆盖

普通完整新制不得只审代表片段，也不得预先猜测全片哪一段最危险。

必须完成：
1. 完整首版的整片连续声画观看。
2. 全部正式主要视觉单元的逐项检查。
3. 所有正式采用创意参考的逐条对照。
4. 所有正式采用动效机制的逐条对照。
5. 所有场间接点的检查。
6. 所有需要后续回收的视觉关系的成对检查。

每项正式采用的参考必须有对应实际观察记录。

未观察的范围保持待审，不得根据相邻片段、源码、静态截图或作者说明推断通过。

## 视觉表现兑现检查

审核统一使用 [visual-treatment-planning/SKILL.md](../visual-treatment-planning/SKILL.md) 中的七项视觉表现标准，不另建一套审美清单。

对照同版视觉导演稿，检查：
- 主体表现是否成立。
- 构图组织是否成立。
- 多素材组织是否成立。
- 连续运动是否成立。
- 花字与排印是否成立。
- 美术统一与变化是否成立。
- 视觉节奏是否成立。

不得仅凭参考已登记、素材已绑定、源码已生成或研究状态完成判定视觉完成。

每项问题必须定位实际作品版本和目标帧范围，说明预期视觉表现与本片实际表现的差异。

## 参考视觉表现简化审核

对照创意作者已经确认的必须保留特征。

逐项判断：
- 原片的整幅构图是否被简化。
- 原片的视觉状态差异是否消失。
- 多素材共存是否被拆成依次播放。
- 连续运动是否被拆成独立动画。
- 旧层是否提前退出。
- 花字是否退化为普通标签。
- 视觉高潮和结果停留是否被删除。
- 真实素材是否失去主体作用。

结合完整参考迁移中的反向检验记录，判断差异是否造成实际视觉损失。

未经确认的删除、弱化或替换不能仅凭作者说明“适配本片”通过。

## 返修责任

参考理解错误：创意作者。

创意理解正确，但视觉设计被简化：视觉作者。

视觉稿正确，OD 未实现：OD。

单场成立，但整片组织不成立：主导演和视觉作者。

声音、旁白、阅读时间不匹配：声音作者和视觉作者。

新版必须复查原问题及必要的相邻接点，并关联原研究决定、原作品版本和实际帧范围。


在同次观察中分清各人的结论。创意作者指出参考关系在成片兑现的具体位置；视觉作者指出构图、素材辨认、字形、关键中途及场间衔接是否成立；声音或时序负责人报告在真实播放中实际听到的落点与留白。只引用他人结论时写明来源，各人只确认自己实际观察的范围。

采用机制时，原机制负责人对照源片和作品，确认发起、保持、接手和出口。视觉作者汇总需要转给 OD 的具体画面反馈，导演判断讲述主线、事实与跨场关系。在现有职责核验记录中对应实际分派、采用决定、观察区间和实际结论。

一次真实观察记录一次，写作品版本、观察方法和实际区间。同次观看可以分别写创意、机制、美术及声音的具体结论。按已发布记录里的 confirmed、issue、inconclusive 填对应判断，问题附影响及原负责人。最终文件使用现有 record_export_artifact_review，单项参考分别登记。复查新版本关联原 finding_id，并重看原问题与相邻接点。阶段回件只有局部时，结论限于真实返回的范围。

给返修写清本片位置、预期、实际所见所闻、造成的影响和原负责人。创意前提本身缺失回原创意作者，设计使主体不可辨或跨场断开回视觉作者，源材缺动作回素材作者，已有设计被漏做回 OD，旁白或接点错位回时序与原视觉作者。新版从原问题前看到后一个对象接住，再记录是否解决。

采用参考的逐条观察填写 reference_reviews，写真实类型、编号、指纹、原片时段、本片场面与目标范围、观察方法、original_relation、actual_implementation、difference 及 outcome。只在相应实际证据范围确认。

画内文字以冻结稿确认的字组及已确认字幕为核查依据。连续观看实际回件，逐场检查新增文字、素材自带文字、图内小字、片头片尾和转场。快速入退、叠化或一闪而过的文字按对应帧停看。检查禁用字样、同类说明标签、额外字组及素材处理后的残留。

发现问题时记录作品版本、字样、帧段、所在位置和所属图层。冻结稿已有违规字组，交原视觉作者修订后由导演重新核对。稿外新增文字或约定的素材处理未兑现，交原制作作者修订。新版回件后查看同一帧段和前后接点，确认违规文字已经去除，构图、内容花字和连续运动仍然成立，再关闭问题。

最终文件用 `record_export_artifact_review` 对同一 Artifact、Run、观察者和真实范围登记一次。外层 `outcome` 表达此次文件观察，`reference_reviews` 每条另填各自结论；参考 `issue` 自动登记对应必修问题。阶段工作台记录仍属于阶段版本。原片核心仍未知由原研究负责人补看。缺成片连续画面或同期声复核由审阅者取得相应输入。已确认实现偏差由视觉组织 OD 修订。主任务从完成评估读取这份最终文件证据，按已有 `nextActions` 续派。复查新版时在参考记录写原 `finding_id` 和 `confirmed`，再用该观察证据关闭原问题。

导演明确要求精确卡点时，在声音计划的对应意图写入 `requiredSyncReview` 成片帧范围。成片审阅用 `event_sync` 登记该事件，`subject_id` 为声音计划 ID 加冒号加意图 ID，并以 `event_measurement` 引用实际测量；无法测量时保留待核。普通声音按实际听感审阅，无须一律做精确测量。

`inspect_motion_frames` 的结果只证明固定作品所列根帧在指定访问顺序下的像素一致性；核对失败帧与差异证据，不把它当成整片连续观看、听审或创意通过。作者的阶段采用回执与最终文件分别按各自版本检查。

审片先继承已采用路线和实际可见对象，检查内容、动效、声音、字幕及连续性中的可验证错误；原视觉、声音和导演负责人对实际作品的美术、节奏、自然度及完整声画负责。只有已采用人物范围才额外观察数字人或真人表演、口型、人物源时间、出入场、重复人物、唯一对白与真实 Mask。`visual_explainer` 没有人物不构成缺项，也不因人物生成失败或人物审片未做而阻塞其原交付路线。技术可核的 ID、时序、音轨与版本由确定性检查负责，感知结论须有真实声画观察。

完整人物混合解释同时读取[人物专项检查](references/mode-specific-rubrics.md#presenter)与其引用的效果特点；锁稿核对原文保持与完整视觉兑现。

对照当前采用稿和实际作品，检查错字、重叠与遮挡错误、裁切越界、缺失素材、错误绑定、源时钟、音画同步、意外空白或冻结、动作截断与源码/资产版本不一致。具体范围与证据实际记录；静帧只支持其可见状态，未连续观察的动态和未听到的声音保留未知。设计选择或体验问题交原创意与视觉负责人自行判断，不由审片补写创意；实现遗漏交原作者修复，事实及跨段含义改变交导演协调。

完整新制与主要视觉重做时，按[材料与参考迁移检查](references/material-integration-review.md#6-创意参考迁移与素材主导效果检查)第 6 节，对照实际作品、参考、简报和素材映射；设计判断交原创意与视觉负责人。

逐条采用参考在工作台连续观看本片目标范围并对照原片，记录参考身份与原片范围、实际作品版本及目标范围、观察方式、原片关系、本片实现、差异和负责人。视觉作者检查整体构图与连续运动，审阅作者检查整片声音、字幕、节奏和场间衔接。发现问题沿原作品返修并在新版复查；项目与文件复用同一次真实观察证据。

核对输出文件、对象依赖或准备导出时读取[技术交付](references/technical-delivery.md)；区分 ready、stale、证据不足与交付状态时读取[证据状态](references/evidence-status.md)。确认的实现遗漏列为未完成并交原负责人；修订后核看受影响范围及必要上下文。确实无法观察的部分说明限制，不写通过，不据未知无限返工。

读取本次 Run 和范围的 `read_production_status`，核对采用作品、评估版本、有效观察、待审范围及未解决问题。进入工作台检查待审部分，问题记录带实际版本、对象、范围、现象、影响及严重程度。主任务按问题续接原负责人。新版接回后，使用原 Finding ID 在工作台定位结果版范围，实际观察后保存复查证据并记录处理结果。视觉计划变更涉及画面和声音时，分别检查对应影响。

声音范围按[声音意图收尾](../audio-finishing/SKILL.md#声音意图收尾)对照当前计划、需求、实际音轨与复核记录，区分已采用、导演留白和未完成。生成 Job 成功不代表已经采用，音轨存在不代表重点能听到；核对需要跟随动画的声音是否使用当前事件及真实源偏移。缺少候选、采用或同步继续回原声音作者，混合中的攻击、旁白遮蔽与尾音按实际听到的范围判断；没有听觉输入保留未知，不伪造通过或新增统一导出门禁。

按采用的声音意图和对应画面动作核对同版实际混合。连续听看音效是否存在、重音是否落在约定动作、尾音是否接得上、旁白是否清楚。缺声、错声、错拍和混音比例分别写明具体帧段及实际现象。候选生成、音轨存在和波形峰值分别作为技术依据，听感以实际复听为准。返修后复核同一段和前后接点，最终导出按实际文件再听。

返回版本、真实观看范围、观察方式、定位到对象/时间的问题、严重程度与返修责任。同版截图、预览和问题清单共享；主任务合并同一问题后交唯一原负责人。复看真实变化和接点，已有材料观察持续承接，依赖变化只复看受影响部分。独立审片由主任务真实分派，审阅者在工作台保存自己实际执行的观察、问题和复查结果，主任务接回记录并组织返修及制作收口；遵循 [共享交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。

先读 project.profile 与本次 completionScope，再读 productionReconciliation 和实际声画。structuralGaps 是具名结构缺项，交对应原作者；observationNeeds 如实保存。人物检查源时钟和口型等可核问题；Vlog 保护事件、动作与现场声，不因缺人物或外部资料失败。素材数、人像比例和动画数不作通过条件。
