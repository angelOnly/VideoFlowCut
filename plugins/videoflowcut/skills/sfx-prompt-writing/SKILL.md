# 音效提示词编写

## 输入与责任

读取当前 SoundPlan、SoundIntent、音频需求及已知动作事件，理解声音为什么出现、要强调什么、单次还是持续，以及同段旁白、音乐和留白。保留 soundPlanId、soundIntentId、planVersion、requestId；已有动画时带当前 Cue、事件和作品版本，不为早期探索编造对象。

本技能产出生成指令和检查重点。正式提交由主任务协调；原音频检查与候选选择交回[声音取材](../sound-asset-sourcing/SKILL.md)，时间绑定和混音交[声音编排](../audio-finishing/SKILL.md)。一个声音作者可以连续承担这些工作，不要求新增代理。

导演尚未指定声源时，根据实际动作与整片风格给出明确方案。缺少会改变方向的信息才向导演补充；不因尚无最终动画帧而停止早期选声，也不把估计时间写成实测。

## 把感受转成声音

将“高级、震撼、轻快”等抽象要求落实为可听的材料、动作、攻击、主体、变化、尾音和空间。例如“合计出现要有确认感”可以转成“单次短木质轻敲，起音清楚、主体温暖、快速衰减”，再结合整片风格选择，不把这个例子固化为所有金额的音色。

提示词通常用一到两句英文，按需要表达单次或持续、声源与材质、动作过程、起音与衰减、距离与混响。推荐 `TrackType: SFX`；不堆砌相互冲突的形容词。中文设计说明保留选择理由，英文只表达希望实际听到的声音。

一条指令优先描述一个独立音效或一个连贯动作。多个需要精确落点的声音拆开生成和编排；重复强调可以复用一个合适的单次声。连续动作则保留起势、维持与释放，不强拆成每个元素一个提示音。

不要把故事主题、字幕正文、旁白台词或视频绝对时间当成声音描述。旁白避让、目标动画帧、最终音量和采用理由留在制作交接单，不伪装成模型参数。

## 形成生成指令

生成前读取[模型与提交方法](references/stable-audio-3.md)，并查看当次正式工具 Schema。`submit_sfx_generation` 的 `max_duration_seconds` 映射到工作流 `duration_seconds`，表示生成最大长度。模型工作流只接受 `prompt`、`duration_seconds`、`seed`。

为短音留出自然衰减，持续声按实际可用范围设计。声音可以短于生成窗口，不为填满时长补静音。不要增加未公开的负面提示词、CFG、参考音频或精确攻击时刻参数。

交回声音需求引用、中文声音设计、英文 prompt、最大时长、种子建议、候选检查重点和已知不确定性。主任务通过当次可用的 `submit_sfx_generation` 提交；生成成功先作为候选 Asset，不自动上时间线。工具尚不可用时保留完整指令并回主任务核验能力，不改走音乐生成来绕过合同。

## 根据真实反馈修改

需要比较时先试少量不同种子，数量按关键程度和实际结果决定。几个候选都偏向错误声源时改提示词，而不是继续盲换种子。针对一次明确反馈调整主要问题，保留原请求与结果，避免同时改动多个无关维度而失去比较依据。

声音正确但有前导空白时，交给选段和对齐处理；太重、尾音过长、出现多余动作时，针对声源、包络或空间改写，具体方法见[候选反馈](references/stable-audio-3.md#候选反馈与调整)。同类动作优先复用已采用声音或少量同风格变体，不用统一极低音量掩盖选型不合适。

生成质量不合适时可回到现成素材分支，或由导演明确调整声音设计；不能悄悄删除意图后宣布完成。声音设计本来需要留白时不为展示生成能力而增加音效。

## 交接与边界

提示词完成不等于生成完成，文件生成不等于听感通过。真实文件的可用范围、可听起音、主要攻击和尾音由候选检查取得，不能从提示词或请求时长推算。

文件观察统一注明原文件时间和观察方法；交给[事件与音频映射](../effect-timing/references/event-and-audio-binding.md)时按选定源范围换算为片段相对偏移。持续声没有单一攻击时如实说明，不把最大波形峰值自动当作感知重音。

只有实际听过才能记录听感判断；模型观察和波形候选保留自己的证据范围。无法听审时标记待听，不改写成已确认，也不删除需求。

HTTP、Job、Run 的失败沿[项目基础](../project-basics/SKILL.md)与正式接口恢复。结果未知时不换种子或幂等键重发，已有 Run 继续原任务；明确执行失败与声音不好听分开处理。
