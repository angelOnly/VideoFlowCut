## 原片范围

母片SHA-256：`a2a93ae4323f4ee14639b509ace735e3f281939445382dc96c908d737aeb6a50`。展示的是母片全局半开范围 `[0, 98)`，历史帧率24fps；派生片局部0对应母片第0帧。

## 已核对实现

关键入口：`Street()、Phone()、Scene()中的split/depth/focus及px/py/pw/ph`。

原片左右窗口使用同一街景源时钟的不同裁切，中间是原创终端；窗口错位后中央取得较大尺度，左右退为窄条。不是三个独立现场，也不是三个视频源同时实拍。
