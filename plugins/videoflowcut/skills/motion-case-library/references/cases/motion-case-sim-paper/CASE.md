# SIM 群体 → 手机页面 → 撕纸 → 使用场景

## 1. 适用场景与表达目标

本案例让观众沿一条问题线观看：看起来相似的对象，为什么受到不同处理；去说明页找适用条件，再把问题放回具体的使用环境。五张卡先建立群体，E 卡获得注意，手机中的同一页面被推近并撕开，后面的基站和手机场景接过讲解。

适用于“群体—选中—说明—使用场景”的解释段落。单纯展示一件产品不必走完整条路线；需要核对真实规则时，应使用当前真实条款与来源，重新安排阅读和揭示方式。撕纸是本例的表达选择，不是每段说明都需要的动作。

本例的 A—E、“优先处理”和服务说明均为机制演示，不代表真实套餐等级。页面标明“演示页面 / 非运营商原文”，选择 E 的同时保留“优先处理 ≠ 凭空增加带宽”。基站中的汇聚点表示观察负载，不作为测量结果。

本案例供现有 [remotion-production](../../../../remotion-production/SKILL.md) 在构思与设计时使用。主工作流提供当前内容、真实旁白、素材、画幅与前后画面，本例帮助完成段内设计。

## 3. 具体美术设计，以及为什么这样设计

### 3.1 颜色、光向与画面分区

| 元素 | 本例的具体设计 | 设计作用 |
|---|---|---|
| 背景与排版 | 深墨 `#151716`；顶端细眉题、两行粗标题，下方一句解释。 | 上部提出问题，中部留给物体，下部保留限定句，建立清楚的观看层级。 |
| 产品舞台 | 浅灰绿共同平面，中心偏左更亮；统一左上光、右下投影。 | 五卡处在同一空间，距离与遮挡可信，不像五张独立 UI 卡片。 |
| SIM | 暖银白卡体、窄灰侧边、暗金接触面及细分区线。 | 先靠轮廓与材质建立物体身份，再用动作呈现差异。 |
| 注意强调 | 黄绿 `#bcff42` 依次用于 E 卡、目标句、裂口问题和结论。 | 同一强调色串起问题线，每次只有一个主要阅读重点。 |
| 页面与后景 | 暖纸白 `#f5f3e9`，深墨正文；后景使用低饱和蓝灰、暖灰与少量黄绿。 | 纸面提供可读环境，后景保持同一视觉语气并带来空间变化。 |

本例以 4:7 竖幅为设计依据。眉题约在宽度 6%、高度 4.5%；主标题从高度 11% 起，两行分别写“看起来相似，”与黄绿的“待遇未必相同。”，字号约为画宽的 7.5%。产品舞台位于高度 29%—80%，底部解释约在高度 84%，字号约画宽的 3.4%。这些区域服务本例内容，换画幅时重新构图。

### 3.2 五张 SIM 的物体感与选择关系

卡体长宽比约 1.3:1，右上有适度裁角，圆角很小。芯片约占卡面宽度 64%、高度 47%，用中间接触区、左右分区与上下引线建立结构；两三段宽缓明暗表现暗金反射，细线暗于金面。卡体、侧边、芯片、编号与标签共用一个斜视投影，投影随离地高度变化。

A、B 分居左上与右上，C、D 在左下与右下，E 在中央稍靠前；保留不同平面转角和少量遮挡，让五个身份都能辨认。上缘编号为 SIM / 01—05，下缘为方案 A—E。选中的始终是 E，它上抬时卡体与窄黄绿轮廓一起运动，投影与卡面距离增大；其它四张稍退后、降对比，维持群体关系。

标签位于各卡上方且不挡芯片，常态为深灰底白字“接入请求”，E 选择时改为黄绿底深墨字“优先处理”。它们属于卡片所在空间，不能镜头只推进卡而把标签留成屏幕字幕。

### 3.3 同一页面、拼合纸边与接管场景

手机是窄深灰边框、轻圆角的竖向设备，入场带轻微侧转与约 -7 度画面倾斜。手机内的暖白服务说明页保留页眉、标题、编号小节和细线，内边距约为页宽的 7.5%。正文全文见完整指令；主要阅读对象是“接入请求可能有不同优先级”及下一行限定条件，其余小字提供页面层级。

手机内页、推近后的纸面、撕开的上下半页共用同一布局。推近将第二小节送到中央偏下，手机边框逐渐退去，页面横向位置稳定。黄绿底条在文字背后展开，文字不改写、不跳字，也不因缩放重新换行。

撕裂线约在页面高度 53%，用约 60—90 个固定细节点形成多尺度纸纤维边，上下半页共享完全相同的拼合坐标。未撕开时只绘制完整页面；撕开后上下分离并各带约 1—2 度反向转角，边缘有窄落影。下半页仍带原高亮，后层问题“忙的时候 / 谁先被处理？”从开口出现。

纸后先准备好原创基站景：通信塔位于宽度约 64%，塔顶在高度约 27%，有三角桁架、交叉梁与三组浅灰天线；灰蓝楼顶、低饱和天空及左上柔光交代环境。一次短线汇入并排成三点的事件表示观察负载。下一景是浅暖灰桌面上的深墨手机，宽约画宽 62%，中心约在 (52%, 46%)，侧边与右下投影保持实体感；同一网页随触点上滑约屏高 18%，底部结论接入。场景细节承担解释，不用循环光点或桌面漂浮填时间。

## 4. 以秒表达的参考节奏、动作交叠与接续

**下表是首版节奏的参考用时，不是必须填满的时间槽。先据此完成设计和实现，再连续观看成片，按实际动作、阅读与前后衔接调整。**

表中用时主要针对局部动作，相邻动作有意交叠，不能直接相加得到总长。文字、尺度、运动距离或旁白改变后，应重新安排相关动作及后续接点，不要求赶回原计划时刻。

| 阶段 | 首版参考用时 | 具体动作与接续 |
|---|---|---|
| 堆叠展开、标签建立 | 展开约 1.3—1.6 秒；卡片启动错开约 0.13—0.17 秒；每个标签约 0.3 秒；身份辨认约 0.5—0.7 秒。 | 首帧已有堆叠。最后两卡尚在收势时标签接入，五个身份都清楚后保留必要辨认，再选 E。 |
| E 上抬获得注意 | 约 0.8—1.0 秒。 | E 提起、放大并靠向中心，标签与窄轮廓在上抬期间改变。确认选中对象和限定句后直接靠近，不返回群体原位。 |
| 芯片靠近、手机进入 | E 靠近约 0.9—1.2 秒；手机进入约 0.8 秒；交叠约 0.4—0.6 秒。 | 靠近后半程手机已从下方进入，舞台与旧标题退让时纸白页面建立，不先清空画面。 |
| 页面认识、推近与高亮 | 页面认识约 0.4 秒；推近约 1.2—1.5 秒；高亮约 0.35 秒；稳定后阅读约 1.1—1.5 秒。 | 推近最后约 0.25 秒开始高亮。目标句与限定条件都到可读尺度后计算有效阅读，读完便撕裂。 |
| 同页撕开、问题建立 | 初次撕开约 0.9—1.1 秒；问题清楚后阅读约 1.2—1.5 秒。 | 中央缝隙达到预期开口的一半时问题起势，纸面继续分离至约画高 25%—30% 的空隙；阅读期间不循环缩放。 |
| 继续打开、基站接管 | 纸面继续离开约 0.9—1.1 秒；汇聚示意约 1.4—1.8 秒。 | 后景预先在场，纸边未出画时新说明已进入。基站成为重点后完成一次负载示意，说明读清便准备换景。 |
| 斜擦转入手机场景 | 斜擦约 0.6—0.8 秒。 | 基站事件收势接上由右向左斜擦，最满时遮住切点，手机场景已在下层就位。 |
| 页面滚动、结论与结束 | 滚动约 1.0—1.3 秒；结论清楚后先按约 1.2—1.5 秒安排阅读。 | 结论在滚动后半程进入。页面收势、结论已读清后结束或接下一画面，已充分阅读时收掉多余尾巴。 |

页面和纸边共享坐标，E 与标签共享变换，后景在开口扩大前完成放置。每次交接检查位置、尺度、方向与速度的连续性；沿用历史实现时，局部帧、外层素材入点和透明范围必须一起调整。

设计说明使用秒，代码按当前 fps 将本次确定的时序落实为事件帧，渲染前确定总帧数。正常播放后，若前一阶段已讲清而后续迟迟未起势，就提前接入或缩短中间空白；若条款读不清，先修正字号、构图与运动干扰，再补对应阅读。修改相关接点，不把全段统一加速或减速。

已有旁白或锁定总长时，在约束内调整内部覆盖、交叠及后续画面，不能擅自改短主声音或整片。最终以实际成片表达、可读性和观看节奏验收。

## 5. 换内容时保留什么、重新设计什么

用于真实素材时，可保留“对象引出规则，规则再交回现实”的关系：原物品或
真实界面先建立观察，实际规则页取得阅读位置，随后通过明确的边缘／开口
或切镜交回已取得的现实画面。文字和高亮持续属于那张真实页面，不用假横线
和自制条款代替来源。撕纸是可选表现，不是所有规则解释的标准出口。

完整指令中原创几何、不依赖外部实拍等要求属于该独立测试条件；正式任务
需要真实操作时，应使用已取得材料。所选 24 秒版本含外层素材接管，不说明
历史TSX已经内部绑定视频；新作品使用TimelineVideo，按本片源范围、作品startFrame/endFrame和作品根时钟重新实现，不沿用旧入口。

| 设计层面 | 可以保留的方法 | 需要按当前内容重做 |
|---|---|---|
| 观看顺序 | 从群体发现差异，到说明中找条件，再观察使用环境。 | 当前差异、选择理由与最终结论；没有这层关系时重新构思。 |
| 主体与空间 | 固定对象身份，选中者从原群体获得重点。 | 对象数量、轮廓、材质、布局、光向与真实素材。 |
| 页面与揭示 | 同一布局由小变大，揭示动作保留此前阅读对象。 | 页面全文、真实来源、高亮位置及适合内容的揭示方式。 |
| 动作 | 旧场退去时手机已进入，纸面打开时后景已接管。 | 距离、速度、动作长度、阅读和后景事件，不能复制历史 24 秒。 |
| 事实 | 强调改变注意，不伪造规则、负载与测量结论。 | 套餐、条款、数据、限定条件和证据，示意须保持明确。 |
| 合成 | 背景、文字与声音依次接力。 | 旁白、人物、字幕、安全区、媒体范围及当前交付规格。 |

例如讲不同保修方案，可以让产品群体中的一件获得注意，进入真实保障说明，再回到维修使用环境。需重做产品外观、真实条件和后景事件，不继续使用 SIM、网络负载或“优先处理”的结论。

历史源码按画布与事件区间写定，props.title 不负责实际文案；只换参数不会自动重排。独立示例的竖幅与无声输出服从当前任务规格。人物同屏时按真实脸部、手势和字幕区域重构图；空间不足可安排全屏段落与前后承接，不把复杂页面硬缩进人物旁。落卡、撕裂、斜擦可提供配声意图，实际声音按当前可见事件与旁白对齐。

## 6. 如何根据实际成片检查和调整

先检查[群体](assets/preview-090.png)、[页面](assets/preview-255.png)、[撕裂](assets/preview-350.png)、[基站](assets/preview-440.png)、[换景遮盖](assets/preview-480.png)、[手机](assets/preview-535.png)的参考构图，再检查当前作品对应事件的实际帧。历史第 480 帧展示的是遮住切点的黄绿擦除层，不是后景素材本身。

| 检查位置 | 应看到的结果 | 不成立时怎样修正 |
|---|---|---|
| 五卡到 E 上抬 | 五个身份成立，E、标签、芯片与投影始终对应。 | 校正固定 ID、共享投影与遮挡，先减少竞争，再调整选择启动时机。 |
| E 靠近到手机页面 | E 仍可辨认时页面已出现，视线自然交给手机。 | 调整两个主体的距离、尺度与交叠，避免先清空一屏。 |
| 推近到条款阅读 | 目标句与限定条件稳定可读，页面未横向跳动或改排。 | 校正同页布局、焦点和高亮位置，再决定需要多少阅读时间。 |
| 完整页面到裂口 | 未撕先无缝，上下边能拼合，问题从同一裂口出现。 | 固定纸边，未撕时只画整页；检查裁切坐标、纸边阴影与后层顺序。 |
| 开口到后景、斜擦到手机 | 开口内一直有正确场景，擦除最满时覆盖切点。 | 校正素材或插画入点、透明范围及斜擦宽度，不延长空黑帧。 |
| 手机滚动到结尾 | 同一网页连续滚动，结论读清后收势结束。 | 修正内容身份与底部留白，补必要阅读或删无用尾巴。 |

历史修订把页面横坐标从 112→−10 的移动改为固定 64，纸边从粗齿改为固定多尺度细边，并在撕裂前只渲染完整页面。这些修正的是构图与遮罩；历史 298—326 帧的稳定段服务阅读，不能为了消除静止而抖动正文。该源码含 CSS 3D，过去得到视频不保证换环境后同帧仍一致；出现同帧差异时按[停顿与顺滑经验](../../timing-continuity.md)区分渲染与编排问题，不能关闭一致性检查。

静帧用于构图与排版，正常速度连续播放用于速度、接续与阅读。将当前作品放回真实剪辑，连同前一句、完整动效、后一句及声音一起看；需要合成才能判断的部分，先使用既有待审草稿取得证据，再复核。源码、画幅、素材或配音改变后，对应旧审阅失效。

把当前完整制作指令、作品与放置版本、动作事件、素材范围、实际审阅结果及待处理问题交回 [remotion-production](../../../../remotion-production/SKILL.md) 和当前主工作流，继续原剪辑任务。独立预览和资料存在均不代替整片验收。
