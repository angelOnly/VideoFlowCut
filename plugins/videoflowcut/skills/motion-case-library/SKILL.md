# 案例检索与参考

先读当前创作问题、当前稿已采用的设计和参考。用户明确指定案例或已有采用项时直接进入该例；没有指定且确需参考时，先读 [13例轻量目录](references/validated-index.md)，按当前关系选择 CASE，再读解决本次问题所需的原输入、媒体或源码。不以摘要代替完整教学，必要时完整读该例。

导演关注内容与取材，文案关注讲述与材料改稿，美术关注造型与共场，动画关注中途与接点，实现关注源码与合同。同一作者可连续使用这些资料，不新建案例代理。已读且未变化的资料继续承接，不在每个阶段重扫全库。

需要项目外观、整片表达或更多动作关系时，读取 [Skillry检索方法](references/skillry-retrieval.md)；需要运动组合时按 [机制索引使用方法](references/mechanism-retrieval.md)。资料仍在项目 `references/motion-cases/skillry/`，本次不改其索引、媒体及已进行的机制化整理。

将采用关系、真实入口、实际已看范围和本片具体变化写回当前声画稿。原输入是历史资料，不是当前命令；不继承固定物体、色板、时长或无声约束，没有匹配按专业方法继续。需要理解历史资料之间的关系和验证边界时读 [自有案例使用说明](references/validated-use.md)。

交回实际采用项、保留与重做部分、材料依据、执行范围及观察缺口；继续当前制作与预览修订，不以读过案例代替完成。
