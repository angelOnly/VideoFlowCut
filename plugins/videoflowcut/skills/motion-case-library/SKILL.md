# 连续动效总 Skill：从内容到设计，再到可观看的案例

本 Skill 总结这批动效的共同设计特征，并帮助选择合适的案例。每个动效有自己的案例 Skill、独立 MP4、源码和参数；案例 Skill 负责讲清该动效的生成思路和设计理由。本页只承担共性说明、选择和引用。视频生产仍由 `remotion-production` 承接。

先根据这段内容希望观众理解的关系选一例，再查看它的独立效果并读案例 Skill。每份 MP4 为一个完整的 14 秒无声动效；每份案例 Skill 开头都再次链接对应效果、源码和参数。这里不使用合辑作为学习入口。

## 这些动效为什么能形成统一的观看体验

**对象有内容含义。** 纸张承载条件，产品复制表达数量，钟表承载读数，通道承载流向。画面的主体本身参与解释，观众能够从它的变化理解内容。先确定这个载体，再安排标题和辅助装饰，减少只能靠旁白解释的无关运动。

**同一对象和共同坐标跨拍保留。** 票头、首件产品、钟面与日照带、入口和出口持续存在，后一个状态由前一个状态变化而来。观众已经认识的东西仍可追踪，于是展开、复制、换算和分配都有出处。进入新的语义拍不必重建整个画面；真正换观看任务时再设计接管或转场。

**每段运动有明确的注意顺序。** 先认识主体，再看关键变化，最后阅读结果。票据同一时刻强调一条条件；时钟先拨动再移动通勤标记；通道先扩宽再分配。字体、图形和背景不会同时执行最强动作。停稳本身是节奏的一部分，结论出现后应能复核刚才的关系。

**材质与构图服务对象身份。** 纸的裁口、票根和印刷层级，产品的边框与屏幕高光，钟壳厚度与刻度，通道的路径与节点，都让主体容易识别。装饰密度与中文层级有主次。这批案例使用浅底和有限强调色，但颜色、纸感、14 秒时长并非所有题材的要求；可复用的是层次和取舍。

**视觉编码可以核对。** 产品数量由真实复制件支持，票根计算带条件，通道分配与等权流线对应，时钟的变化保留日照参照。数值或对象关系错误时，视觉再精致也会误导理解。更换内容要一起改模型、单位、文字与图形。

## 用案例帮助生成新动效

先用一句话写出本段的观看问题，例如“为什么票面优惠不等于实际省下的钱”。接着确定观众最后应看到的结果、仍需保留的出处，以及从开场到结论必须发生的状态变化。选择最接近这类关系的案例，直接查看它的独立视频，再读案例中的设计理由和实际帧段。

改写先从内容模型开始，再决定主体、构图与关键停稳帧。只有数量、名称等确实属于原模型时才直接改 Props；若因果、拓扑或参照变了，需要修改源码中的关系。之后用帧函数连接状态，安排强调与阅读停留，再补材质、阴影和细节。这样能把生成思路迁移到新题材，而不会把每段内容都塞进同一个外壳。

静态检查确认中文分行、层级、空白和数值可读；连续检查确认对象不跳位、主动作不互相打断、标题不交叉重影、结尾有阅读时间。最后还要看前后画面是否自然交接。案例里的好看来自这些可观察的选择，不能仅用“原创”“高级”代替判断，也不能凭一张漂亮截图就宣称运动已审阅。

## 数字人与解说怎样使用

数字人或真人同屏时，把真实脸部、手势和字幕占用作为构图输入。产品案例默认透明，预留的上方 600 px 是该例的构图假设；独立 MP4 的浅底只用于展示。应根据当前素材重新安排主对象、数量和字幕位置。没有已验证的 Mask，就不承诺人物前后穿插。

全屏解说可以让解释对象占据更大空间，票据、钟表和通道案例都采用这种方式。复杂关系需要放大时，可安排人物离开、解释接管和人物返回，不把整幅复杂图硬缩进小窗。每个案例 Skill 进一步说明自身的适配办法。

## 参考、生产与交付

需要了解四站选型怎么写进 Skill 时，按需读 [四站选型示范](references/four-source-worked-example.md)；需要核对原片观察依据时，读 [已观察机制](references/observed-mechanisms.md)。它们是总 Skill 的辅助资料，不替代每个动效的案例说明。

当前 `submit_motion_work` 仍要求四站范围内的 `reference.url`、真实 observation 和 rights。本地案例教设计与实现，不能被填写成合法在线参考。由代理主动寻找和实际查看相关参考，无须要求用户每次提供样片；无法观察时保持证据缺口，不编造链接或审阅结果。正式提交仍按实时 MCP 合同执行。

交付新案例时沿用本页的组织方式：一份独立案例 Skill 说明问题、生成思路、设计理由、跨拍机制、源码落点、改写方法与局限；只链接这一例的源码、参数和独立效果；再在总 Skill 增加对应索引。视频、源码和文字必须对应同一版本。

## 交接合同

选择和改写完成后，将所用案例、保留与重做的设计、Props 与局部动作帧、计划放置范围、人物/字幕处理和真实预览证据交回 [remotion-production](../remotion-production/SKILL.md)。它负责受管版本、Cue、Impact 和合成审片；主要工作流负责当前 Revision 的成片验收。教学案例不声称已完成正式人物、旁白、字幕和声音的合成。
