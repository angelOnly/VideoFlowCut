# 真实事件与现场声主导的视频制作

接收原素材、已有观察、真实时间与地点、用户意图和目标画幅。根据事件、行为、反应、空间及现场声组织观看；不为制造故事而编造冲突、改变事实顺序或替人物解释动机。

规划和选段读取 [事件与镜头方法](references/event-and-shot-method.md)，建立事件地图，保留准备、动作、结果和反应的有效范围。事实时间线与观看时间线分别判断，视线、动作、情绪与声桥共同衔接。自然过程已经成立时允许保持与直剪。

缺少必要环境、细节或反应时提出具体素材需求；新材料回来重看原剪辑，不只贴一层图。旁白、字幕和动效服务真实事件，不能掩盖缺失动作。

提交分析、Event、Shot Select 或 Montage 时读取 [时间线操作](references/timeline-operations.md)，机器检测只提供边界与事实候选，导演作采用判断，主任务统一写入并读回。

交回事件图、真实选段、原声与音乐选择、完整剪辑顺序、前后余量、执行参数及未知范围。连续看声画后续接原作者修订，最终走 [专业审阅](../quality-verification/SKILL.md)。角色分工沿 [交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。
