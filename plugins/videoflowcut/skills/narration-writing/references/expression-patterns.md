# 六种讲述方向：先理解特点，再选择用法

共同底线是准确、清楚、完整且值得听。同一份知识可以有不同口吻；方向名称不决定字数、段落数、事实深度、素材类别或动画。没有命名方向也可以按实际需求写作。

<a id="narration-light-humor"></a>
#### 轻松有梗

**核心特点：** 与观众站在一起发现一个有点好笑的落差，让复杂内容听起来像一次明白、有意思的交流，而不是把严肃信息改成段子。

**内容组织：** 从可理解的经验、预期或具体观察进入，尽早给解释。可以在原因讲清后用短反应收住，再继续下一层；不规定必须先误导再反转。

**语言特点：** 使用具体动词、贴切比喻、有分寸的夸张和长短句变化。幽默落在事实已支持的反差上，调侃事物或共同困惑，不靠虚构经历和强烈嘲讽制造热闹。

**迁移与修正：** 在任何主题中先找“大家容易怎样想，实际哪里有意思”，再选择是否幽默。正文只剩笑话时补因果；只有开头活泼时重排后半段；笑点不成立可以直说，不强求每段一个梗。知识仍须讲清。

<a id="narration-warm-company"></a>
#### 温暖陪伴

**核心特点：** 理解观众面对的处境，用平等、不责备的方式解释信息，让人获得理解和选择能力，而不是只获得安慰。

**内容组织：** 承认真实困难或感受后，直接进入能提供帮助的知识；原理、区别和选择逐步讲清。没有具体处境的主题也可用温和、耐心的解释，不编造一个悲伤故事。

**语言特点：** 称呼自然、句子完整，必要的专业内容说得明确。少用训诫式提醒和替观众下判断的语气；可以坚定、有观点，不靠大量抚慰词或缓慢语速表现温暖。

**迁移与修正：** 从“观众哪里困惑、需要理解什么”出发。泛泛安慰就补实际信息；替观众决定情绪就改叙述立场；过于软弱冗长就收紧重复，但不删掉解释本身。

<a id="narration-curiosity"></a>
#### 悬念探索

**核心特点：** 让观众愿意追随问题的答案；悬念来自真实的未知和发现，不来自故意藏住理解所需的前提。

**内容组织：** 建立一个清楚的问题，较早给出第一层有用答案，再沿尚未解释的原因、条件或结果深入。需要多少层由内容决定，不把知识目录全部改成问号。

**语言特点：** 关键疑问简洁，解释有喘息。一次说明一个新的关系，称呼与比较条件稳定；不是连续抛多个金额、否定和转折让观众猜谜。

**迁移与修正：** 在主题中寻找真正值得追问的现象或差异。问题太多就先回答；节奏拥挤就拆开复杂条件并减少旁支；已经解释清楚就收束，不追加没有依据的新谜题。

<a id="narration-clear-punchy"></a>
#### 理性爽快

**核心特点：** 结论明确、推理可跟随、解释不拖泥带水。专业来自把关系讲透，不来自术语多或语速快。

**内容组织：** 可以先给关键结论再解释依据，也可以从一个清楚比较得出判断。删掉重复定义和不影响答案的旁支，但保留必要前提和边界。

**语言特点：** 具体称呼、明确动词、直接收句。复杂部分给完整解释，不把几步推导挤成半句；用一次恰当总结帮助观众形成认识，而不是每段重新喊口号。

**迁移与修正：** 检查听者能否复述核心答案。只有结论就补推导；一口气塞太多条件就放开篇幅；只有数字比较就补原因。没有幽默也可以有吸引力，关键是发现和判断有价值。

<a id="narration-playful-objects"></a>
#### 奇趣卡通

**核心特点：** 以容易想象的对象、类比或俏皮口吻降低理解门槛。拟人和对白可以选用，但不是必需条件，也不等于受众一定是幼儿。

**内容组织：** 先让人认识对象和规则，再解释一次变化及结果；借类比时说明对应关系，及时回到真实主题。不能为了角色表演增加一条与知识无关的剧情。

**语言特点：** 主语明确、动作具体，一句话尽量承接一个关注。专业词出现时当场解释，避免给抽象概念换一个可爱名字后继续抽象地讲。幼龄受众需要更基础的铺垫，不只需要更多语气词。

**迁移与修正：** 找一个能降低理解成本的形象即可。类比反而难懂时去掉类比；对白使身份混乱时改回单人旁白；真实机制与比喻冲突时修比喻，不修事实。

<a id="narration-immersive"></a>
#### 沉浸叙事

**核心特点：** 让观众跟随一个过程、观察或选择进入内容，解释属于正在发展的关注，而不是与故事分离的课堂。

**内容组织：** 交代必要的起点，在遇到问题、发现或决定时引入知识，结尾回到原来的关注并给出答案。可以按观察推进，也可以按事件推进，不要求复杂人物或固定故事结构。

**语言特点：** 具体、可感知，叙述视点稳定；细节服务理解和投入，专业解释仍清楚。慢读、少字和长停顿并不自动构成沉浸，必要处可以直接、紧凑。

**迁移与修正：** 优先确认跟随什么以及为何值得跟随。只有氛围就补发展；讲完经历却没回答主题就补解释；真实素材不支持某个动作就改叙述或明确假设，不为匹配旁白无限寻找同款演员。

### 规律与示例的关系

先依据当前主题写作，使用相关方向的规律修正表达。仅在需要看一份完整示范、比较讲法或出现具体写作困难时，再读 [案例索引](examples/README.md) 的索引并选择一个相关文件。普通任务不默认读全部六篇，不把示例的专名、金额、故事、结尾或段落顺序变成下一主题的模板。

示例学习后，返回当前题目与当前资料，保留可迁移的原则，重新写实际正文。采用方向不同，不要求资料、素材或动效生产另起一套流程。
