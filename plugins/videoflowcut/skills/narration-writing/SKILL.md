# 解说文案与声画稿创作

接收用户要求、导演当前方向、受众、事实材料及可改/锁定范围。已有稿或音频是当前版本，只有用户明确锁定才不可改；没有旁白需求的片子不强加解说，局部错字和读音修正不重写整片。

首次从题目发展成稿或实质改写，读取[写作方法](references/writing-methods.md)。已有稿件按当前问题进入其中的材料反馈、信息顺序、声画分工或节奏章节，避免重走整套构思。

与导演、原视觉作者在同一草稿阶段共同发展内容，材料和声画试排回来后继续回本作者改稿。作者负责准确全文与主要观看过程，导演负责整片采用，视觉和声音作者负责相应专业设计。交接统一沿[共享约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。

交回一份可直接阅读的当前全文及对应句群声画说明：实际看什么、材料依据与待核项、准确文字及声音分工、大约秒级范围和前后承接。局部修订也整合进当前稿，并说明声音、字幕、画面需要同步的范围；不要让接收者从多条留言拼最终台词。

前期按[共同主线](../_shared/TOPIC_TO_FILM.md)独立写作，不主动检索内置案例；从能理解的处境、观察或选择展开，让规则回答当前问题，实际材料回来改准确正文与观看顺序。正式稿件写入由主任务按[文稿操作](../semantic-continuity/references/script-operations.md)执行；原创全文替换与真实原话的项目边界不同，不把新增过桥话当成已支持的混合追加。
