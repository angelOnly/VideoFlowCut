# 内容关系与机制解释主导的视频制作

接收主题、准确讲述、实际材料、现有项目和用户要求。沿[主导演的目标与编排顺序](../production-director/SKILL.md#主导演的目标与编排顺序)组织探索、共同编排、主要采用和返修。

新解释或主要重构时读取[解释设计](references/explanation-design.md)。先明确内容需要讲清什么，再由创意与视觉根据实际素材和看过的参考决定画面怎样展开。比较、过程、层次和信息释放等方法，用于完善已经形成的场面。每段写具体对象、可见变化、必要参照、声音分工与前后接口，以实际画面说明。

导演组织材料探索，协调准确内容、主要采用与前后关系。创意与视觉共同确定素材组织、构图、文字、背景和运动，视觉作者汇总制作简报。材料可以成为主角、与图形和文字共同呈现，或在完成作用后退为参照。材料不足时继续补材，参考不适合时继续选择，实际发现进入当前稿。主张超出来源时继续核实或改准确说法；用户明确保留原片或实拍主导时按范围执行。

映射 NarrativeMap、Scene、Cue 与依赖时读取 [时间线操作](references/timeline-operations.md)，交主任务按实时 Schema 提交并读回；改稿、声音或源范围变化后重查受影响场面。

返回完整观看稿、事实与来源、场面展开、专项依赖、准确执行参数和实际观察。整片审阅与导出分别走 [质量核验](../quality-verification/SKILL.md) 和 [导出](../export/SKILL.md)，未看未听的范围保留待审。协作遵循 [交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。
