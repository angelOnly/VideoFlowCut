# 连续演出：关键中途、动作关系与返修

本页供已选机制的适配、关键中途、速度与返修使用。新建或实质重构主要动画先沿[动效入口](../SKILL.md)完成选型与组合；详细映射与连接只维护在[机制检索与组合](../../motion-case-library/references/mechanism-retrieval.md)。读取当前声画稿、已选美术、实际源范围、准确文字、前后画面及锁定条件；缺什么只请求影响本场的输入。已有机械改字、固定偏移或直剪按局部范围完成，不通读无关碰撞教学。字形、材质与构图见[视觉美术](../../visual-treatment-planning/references/art-direction.md)，此处沿同一套选择深化变化。

## 1. 变化表达什么，什么继续存在

从当前完整观看稿确定主行为：它由哪个实际对象承担，改变什么理解、关注或感受，前后的内容为何相接。材料自身已经有表现力的过程继续使用，额外机制围绕它组织，不用低信息图标替掉可观看材料。

将内容身份、准确文字、部件归属和必要比较依据，与可以变化的距离、姿态、层级及可见范围分开。前者在演出中可追踪，后者用于推动观察和注意。图解中的形式变化不暗示来源没有的事实或物理因果。

选型和连接沿[机制主方法](../../motion-case-library/references/mechanism-retrieval.md)完成，本页负责把已选关系落实为实际状态和曲线。先用当前素材与准确文字做一段可运行连续粗排，让主变化、支撑层和出入口真实发生，再精修材质；不是先完成若干静态页面，最后补转场。

相邻句群需要持续对象、源过程或注意转移时，共同设计它们的入口、主要阅读状态、中途和出口。主要段的丰富度来自对象、观察、文字与接管协作，不只是同一页面逐行显示，也不是所有层一起运动。静止和切镜可以承担明确作用，不能代替尚未设计的变化。

未取得材料只提出实际缺口，不预写不存在的源动作。材料或范围改变时同步更新裁切、字位、路径、遮挡和声音；主要内容改变回导演，局部演出由原作者继续。

## 2. 先定入口与目标，再设计最危险的中途

入口包含哪些已熟悉对象，目标状态里新主体与必读内容怎样共场，先明确这两个状态。如果两端的字形和构图本身不成立，先修美术。

接着找最容易丢失主次的时刻：新旧并存、遮挡刚解除、结果开始响应、前景替身接管，或文字第一次能读清。关键中途不一定在时间的50%，也不能由两端位置自动插值代替。

用连续正文交清这个时刻的实际状态：

- 谁仍在场，身份、源过程和比较参照怎样延续；
- 位置、轴心、姿态与投影面积，哪段路径经过画面边缘；
- 谁挡住谁，遮挡解除到什么程度，哪些字此时可见；
- 第一关注是谁，旧重点让出多少对比和面积，附属层怎样支持；
- 速度正在起势、通过、减速、收稳还是穿出；
- 当前声音和源内动作怎样继续，新内容是否已到达所需可读条件。

这些是解决中途问题的观察角度，不要求每镜六栏表。大位移中可暂不摊开小字，到有效投影和字幅后再读；阅读来不及时先改字量、面积、显露与交接，而非把所有动作放慢。

对照过程动词核对对象：移动要抵达接收位置，揭示要通过遮挡解除或观察位置变化，比较要保留共同参照，回收要处理先前对象。粗稿中就实现这些主要过程，次要纹理可稍后精修，静态卡加旁白不能证明连续关系已经成立。

## 3. 连接状态：路径、速度与对象依赖

明确发起、跟随、显露和接管的对象，再划分共同父层与局部控制。文字、图案、边缘和影子随所属对象计算；场面层负责整体观察，对象层负责自身运动，局部层负责显露。重叠时同一属性的贡献和计算顺序清楚，不由后一个机制抹掉前一个状态。

路径落实到接收位置、经过区域、轴心、姿态与投影面积；速度围绕辨认、阅读和反应选择起势、通过、减速与退出。不同对象可有不同延迟和收势，不统一套一条曲线。长距离大主体与轻标签按实际需要分别处理，离场对象不必在边缘人为停稳。

连续观察不在每个机制边界归零重启。需要读清时收稳，不需要停顿的节点保留通过关系。位置与速度分别核对；空间、曲线及源坐标的具体计算沿[素材坐标与时间](../../remotion-production/references/material-space-and-time.md)。

需要延续的对象跨层或跨作品时，在接管区保持身份、内容、位置、尺度、朝向和源时刻一致；遮挡、字位和视点变化在同一过程内完成。输出文件不是视觉起点，不复制一张片尾图冒充状态延续。确需明确转题时，仍设计其观看与声音的接入，而不是由文件边界决定。

真实视频独立计算源时间。同源分区使用同一源状态，外框移动、局部 Sequence 或拆件不使素材从头播放。没有可靠跟踪或可分离条件时，调整实际范围或表达，不伪称能力；时钟或定位错误直接修对应实现。

## 4. 从可辨、可读时刻反推声画交接

先依据当前实际句群或源事件，决定新重点何时应可辨、何时必须读清，再安排启动、旧重点退让、内部显露和收势。不是先给所有对象分配相同时长后依次排队，也不等旧对象全部退出才开始新内容。

首版用相对秒数表达尺度与交叠，真实声音回来后按可靠精度校准，正式作品再按 fps 落帧。句级证据只支持句级设计，不按字数均分制造词时间。语义关系、有效阅读、锁定时长和空等处理统一见[时机方法](../../effect-timing/SKILL.md#秒级初始节奏与预览修订)。

讲述句群、字幕卡、视觉场面和技术作品是不同单位。一段自然语音可有多张短卡，同一对象可跨句；问题、标签与普通字幕各按作用保持，不同时清空。单行字幕不要求切碎配音、挤字或隐藏内容。动态画内文字在作品内，普通字幕沿 Caption 链，在同一合成里检查。

声音可以预示下一处观察、与动作共同落定、事后回应或保持空间；不必每个运动元素都有独立音效。依赖声音的关键粗稿应有可试听候选。把要同步的动作命名，动画与事件共用当前时序；区分相对视觉的感知偏移、音源内部起音与主攻击，具体换算见[事件与声音绑定](../../effect-timing/references/event-and-audio-binding.md)。

动作收势可与阅读交叠，稳定窗口内源动作也可继续。停留有阅读、比较、反应、情绪或材料欣赏用途就保留；背景粒子或持续漂浮不能替没有发展的第一重点辩护。

短源片可以与前置建立、明确回看、细节解析和接续组成更长段落，新增时间须有观看内容。真实定格使用可追溯且正式登记的源静帧，原创图形可以直接保持状态；回放标清观察用途，不制造第二次事件或自动重复原语音。不冻结、循环、统一变速补满长度。

## 5. 在实际产物中观察并返修

复杂场面以[执行稿结构](execution-brief-template.md)组织同一份完整正文，简单场面短写即可。沿已选对象、关系和时间落实[受管实现](../../remotion-production/SKILL.md)，不把完整设计再缩成一句提示词。组件能兑现设计时复用，不能时反馈具体能力与表达损失，不让默认组件反改主要分镜。

先用当前源码、准确文字、实际素材与字体取得有风险的关键状态；动态判断再看入口之前、完整变化、读清之后和下一画面的连续范围。概念草图只证明意图，静帧只证明对应构图。作品独立成立后仍要看人物、字幕、证据、声音和前后镜头共同合成。

| 实际问题 | 优先检查和修改 |
|---|---|
| 主体弱、像等权表格 | 标题是否挤小主体，轮廓、面积、字级与对比是否等权 |
| 两幅画面互不相干 | 对象归属、共同空间、比较尺度与前后参照 |
| 中途拥挤但终帧好看 | 风险中途的投影面积、可见文字、遮挡和主次 |
| 动得顺却发飘 | 发起与跟随关系、姿态变化、加减速分布及收势 |
| 新重点太晚 | 建立、可读与语言的关系，动作先后与交叠 |
| 薄物像厚块 | 厚度、间隔、边缘与接触影 |
| 源内容跳位或重播 | 父子变换、真实源时钟与拆件映射 |
| 设计照做仍平淡 | 回到观看过程、美术和演出；改变主线时交导演 |
| 稿具体而画面漏层或错裁 | 修源码与绑定，不删除原设计来补写合格依据 |

把成立的选择保留，按原因修问题，不能统一加弹性、阴影、whoosh 或延长指令。主线改变需要整片复看；局部曲线修改只复看受影响范围与前后文。实际未看或未听的部分保留未知，技术渲染不代替专业判断。

交回当前演出正文、准确参数与源码、素材/字体/声音引用、事件与放置接口、修改影响、实际观察和待核请求。首次主要表达及主要对象、事实或跨段关系改变沿[共享交接](../../_shared/PROJECT_REVISION_AND_HANDOFF.md)回导演，已采用方向内的路径、曲线与切口修订由原作者继续；提交、Job 与版本恢复不在本页重复。

## 按需分支：非球体接触、衰减与积累

只有场面需要可信接触或堆积时读本节。对象有长度或不对称轮廓时，先判断哪一端、边或面接触承载面，再决定转动与反弹。接触点、姿态、投影和阴影一起核对，不能当成圆点做等幅直上直下弹跳。

弹起、翻滚与滑动逐渐损失能量。不同初始姿态和接触产生不同收势；落稳对象持续存在，后续对象与它形成可信遮挡、接触和局部堆积。新增对象停下时，空中的对象仍应完成运动，余下滚动逐渐收束，不能突然删物或一帧全定住。

是否需要完整物理模拟取决于表现，简单可控轨迹也可成立。渲染必须支持任意帧重建，固定种子只固定初值，不能修复依赖上一播放帧的模拟；按时间求值或预计算状态的实现与乱序取帧验证见[确定性合同](../../remotion-production/references/remotion-component-contract.md#随机与碰撞的任意帧重建)。数学一致仍需观察接触、遮挡和收势。
