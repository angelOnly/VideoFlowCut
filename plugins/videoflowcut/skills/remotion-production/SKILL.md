# 受管 Remotion 实现与修订

本页是同一视觉作者使用的实现方法。接收当前视觉选择、实际素材、准确文字和声音、已有源码、目标 Scene 与前后接口；从可运行粗排持续修订同一作品至最终输出，不等待全部美术静态完稿。主任务负责正式项目写入、生成和渲染提交。

实现当前主体、背景、材料、画内文字与接点的关系，再用实际画面判断选择。缺主体、材料用法与空间选择时，由原视觉作者回[视觉入口](../visual-treatment-planning/SKILL.md)；内容已明确但运动过程不完整时，直接回[连续演出方法](../motion-brief-writing/references/performance-design.md)；演出明确而漏做时修对应源码。已经成立的局部改字、裁切或时钟修复不重启参考构思。不能为了得到可提交作品临时补成固定素材窗和普通标签。技术条件迫使改方案时说明具体表达损失，由同一负责人调整当前选择，不默默删去难实现的关系。

## 按修改范围进入

新建或实质重构时，在当前源码中先实现能检验主要选择的连续范围，依据[美术方法](../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)将本片必需表现及其配合落实到实际材料、准确文字、正式字体和前后接点，再随同版正式渲染结果扩大或修订。同版实际画面与源码一同交回；文字稿、机制编号和语法通过不是设计完成。短片可以直接形成完整粗排，长片先处理主要困难所在的范围，临时细节如实保留，不另建一条脱离正式实现的样片链。

接到已采用的人物混编场面时，同一受管视觉作品须基于真实人物源、材料源、当前声画稿和字幕占用设计连续变化；需要全屏转缩窗、分屏重排或资料扩大时，人物与材料是共同运动对象，不能各做独立页面硬拼。使用已发布的 `videoBindings`／`TimelineVideo` 和真实源起止范围，人物或材料容器改变不重置源时钟；外层 Presenter 与内部作品的可见职责明确，避免重复人物；同一句话只有一个有效讲述声源，普通字幕留在最终画布层。非人物路线继续现有 Remotion 方法，不加入人物必选参数。

场景首次呈现、元素可见时刻和段间接点按当前演出显式实现。每个可见元素都须兑现已设计的动态参与，主要动作保留准备、发力、通过、惯性和收势，场间完成可见交接。

配音分段提供时钟输入，不直接决定完整视觉状态的替换。连续对象、相关层与观察按演出关系求值，需要交叠或延续时保留状态，真实素材源时间独立延续。核对挂载窗口、条件分支和作品边界是否截断动作；不得在段尾清空后重建，不得用硬切掩盖状态或时序问题。以上沿[默认整场设计](../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)的适用范围执行，局部任务与用户锁定内容保持原范围。

绘制组件负责外观，场面逻辑按[对象依赖方法](../motion-brief-writing/references/performance-design.md#3-连接状态路径速度与对象依赖)控制启动、路径、跟随、反馈与接管，不能用统一入场进度抹去错峰和抵达关系。

连续范围适合一件受管作品时直接实现；必须拆件时，共用同一场面状态函数，按“段落时间＝输出块偏移＋块内时间”计算各块，分别换算真实素材源时间，不让后块重建空场。偏移用现有实现变量或已支持 Props，不发明 MCP 字段。不要按每段旁白或每个机制生成一个独立成品。只改既定文字、颜色、位置或切口时处理当前源码与受影响范围，不重启主线和全库检索。

写图片、真实视频、字体、Props 或命名事件前，读取 [受管组件合同](references/remotion-component-contract.md) 对应章节并核对实时 `read_motion_capabilities`。素材必须通过真实绑定，字体使用登记身份；不凭历史版本说明推断当前会话能力。

裁切、局部观察、附着标注或跨段视频接续，读取 [素材坐标与时间](references/material-space-and-time.md)，使用完整 cover/contain/fill、点映射和源时钟公式。修漂移或重播直接进入这里，不重新搜全库或重写故事。受管源码直接从 `@videoflowcut/motion` 导入 fitSource、focusCover、sourcePoint、parentPoint、frameMapping、previewRange；沿用平台纯函数，不逐片内联重写。

提交、查询、Review、Cue 放置或异常时，主任务读取 [提交与恢复](references/submission-and-recovery.md)，固定当前输入和版本，获取真实 Job 与输出再读回影响。已结束失败、结果未知和无副作用参数拒绝分开处理，不重放不确定写入。

按本场已可见的设计落实字体、材料、颜色用途、构图、画内文字与连续变化，未锁定的构图可由原作者随演出完善。普通字幕沿正式 Caption 内容与本片统一规范，在最终画布的独立字幕层呈现。需要字幕动效时，通过正式字幕能力实现已确定的进入、换卡和退出，阅读期间稳定，不随主画面相机或对象变换漂移。

主画面作品不复制整句普通字幕或另画其底板。预览与导出使用同一字幕内容、样式和动效，核对没有重复渲染。当前能力无法兑现时，指出具体缺口，不把静态呈现报告为已完成的动效，也不绕过正式字幕链路。

当前稿安排的重点花字必须落实：字形、承托、轮廓与影子归属同一对象，共同进入、读清与交接，组内可以错开；它与相关文字和辅助层按当前演出重排。花字要求沿[美术方法](../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)，不为满足组件形式增加无作用装饰。素材时钟与窗口动作分开，普通字幕不进花字父层。允许作品内复用绘字函数，不要求新增平台 FlowerText；函数名、描边属性与组件数量不是作品验收。

公共代码共享数学、字体和确有用途的绘制方法，不顺带复用每场的背景、位置、规模及入退时刻，不自动添加栏目名、页码和固定标题。内部对象名、获取渠道与制作方法不自动生成可见标签。

## 验证与返回

每次主要预排或返修回传前，原视觉作者先看同版实际整幅画面与相关接点，再对照当前稿：观众实际先看谁，背景与主体是什么关系，变化是否确实带来下一关注。没有碰撞、元素齐全或文件可提交不能替代这轮判断；忠实实现仍不成立就重选受影响的视觉关系。设计尚未交清具体过程时，由原视觉作者补完设计；过程明确但进入、发力、惯性、退出、元素参与或场间交接遗漏时，修订对应源码与时序。已确认的缺失须实际返修，不能留为“观感待审”。

尚未观察的节奏、力度和听感分别保留未知，随后用同版实际连续范围复核。忠实实现仍不成立时，由原作者调整设计；讲述与声画顺序问题交文案和导演协调。

实际绑定、正文、声音或时长改变后，先由原作者按[演出方法](../motion-brief-writing/references/performance-design.md#4-从可辨可读时刻反推声画交接)重排受影响的语义落点、阅读窗口与接点，再按正式版本提交并读回影响，同步更新相关声音、字幕、事件与前后位置。不能只替换 Props 中的段长、整体缩放时序或直接改缓存。普通背景更换不自动重配无关声音。

关键状态必须来自当前源码、素材和字体；动态与声音检查实际连续范围。构图与字形、关键中途与注意交接由同一视觉作者分别使用美术、演出方法处理，漂移、重播、范围和绑定错误沿本方法修复。缺连续感知时保留对应未知，已能从实际帧确认的主次和布局问题仍须修订。保留成立的选择，不因局部问题重新加载全部资料。

返回同版实际预排或预览、完整 TSX、Props、绑定、命名事件、放置参数及失效范围，简述本次实际改变的画面关系和仍未看未听的部分。按 [角色交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md) 续接原负责人直至交付；参数齐全只表示可以提交，不表示视觉设计已完成。

人物主场面接管操作沿[时间线操作](../presenter-motion-director/references/timeline-operations.md#主场面接管)，先查实时 Schema。外层像素接管不重置 TimelineVideo 源时钟，也不改变唯一声音。纯解释片既有 ExplainerScene / fullscreen ManagedMotion 与 Vlog 原片路线不要求人物声明。
