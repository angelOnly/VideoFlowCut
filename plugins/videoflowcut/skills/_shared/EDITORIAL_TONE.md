# 叙事表达与气质选择

本页补充既有导演、文案、视觉与审片的共同判断，用于主要表达设计或相应返修。它不指定统一风格，不改视频类型、既有偏好入口或专业制作流程；局部机械修改继续原任务。各作者只读取与当前职责相关的内容。

<a id="selection"></a>

### 先沿用本片方向，不由题材自动选风格

**视频类型决定制作路线，表达方向决定讲法与感受，具体视觉参考提供做法。三者不能互相替代。**

视频类型继续采用现有 project.profile 的 presenter_motion、visual_explainer、vlog、hybrid，由原类型路由（`.agents/skills/production-coordinator/references/video-type-routing.md`）管理。本页不重新分类，也不将任一类型绑定为严肃调查。

讲述与美术继续分别使用已有讲述方向（`.agents/skills/narration-writing/references/expression-patterns.md`）和已有美术方向（`.agents/skills/visual-treatment-planning/references/art-directions.md`）。轻松有梗、温暖陪伴、悬念探索、理性爽快、奇趣卡通、沉浸叙事均保持可用；两者可以协调组合，也可以按内容采用其他具体做法，不要求同名一一对应。不要复制这两份方法另建一套分类。

当前明确要求优先；已有项目没有改风格要求时，保留当前有效采用。新片未明确的部分承接用户主动保存的默认，仍未确定的部分由导演根据内容、受众、参考与材料自主选择。无需新增问卷。只把本片选择写进当前稿，不回写为永久偏好。

是否包含真实事件、风险、数据、人物或科技内容，均不足以自动选择严肃调查。事实准确与表达轻松、温暖或明快不冲突。没有指定风格，不等于默认严肃调查；单段有紧张目标，也不等于全片需要统一压暗。

#### 严肃调查参考的使用范围

只有当前稿明确采用了严肃调查的呈现态度，并说明是全片还是某个连续范围，才读取[可选的严肃调查视觉参考](../visual-treatment-planning/references/editorial-visual-tone.md)。采用可以由用户提出，也可以由导演在现有授权内作出；不能覆盖用户已确定的其他方向。

只借用其中的资料定位、光线、空间或其他局部做法时，说明借用内容与适用范围，保持本片原方向；不同时继承该参考全部配色、运动和声音倾向。采用范围结束后按已设计的衔接继续，不把局部选择扩散到其他段落。相关作者只读取已选范围，不要求所有作者预读可选风格全文。

<a id="principles"></a>

### 从参考提炼的共同特点

这些特点约束内容与表达的关系，不指定观众必须紧张、不安或震惊。具体感受由本片已采用方向决定。

| 特点 | 在本片中怎样落实 |
|---|---|
| 内容有分量 | 真实主张有可追溯依据；材料和细节让内容具体起来。纯形式表达按其观看价值设计，不强制每个镜头出现报告或新闻。 |
| 观看持续发展 | 让行为、关系、论述、观察或形式有实际发展；前面形成的结果和参照在仍有用途时继续影响后面。 |
| 感受有依据 | 通过可看、可听、可理解的内容与变化支持本片感受，不用情绪形容词替代设计，不用夸大事实补刺激。 |
| 强弱服务内容 | 根据当前作用安排重点、阅读、反应和接续，让对比有意义；不统一加粗、加速、加声，也不统一减弱。 |
| 材料丰富且有作用 | 材料提供不同的观察、语境、细节、趣味或解释价值；不按下载数量、媒介比例或唯一机位收口。 |
| 整体态度一致 | 素材姿态、颜色面积、材质、空间、排印、运动与声音相互支持；统一的是表达关系，不是全片同色、同速、同布局。 |

<a id="director"></a>

### 导演：采用什么方向，为什么这样呈现

与文案、素材、视觉和声音从起稿阶段共同工作。在现有声画稿开头，写清本片表达重点、已采用的讲述与视觉方向、希望提供的观看感受，以及支撑这种选择的内容或形式。不另建风格状态表，不只抄方向名称。

对关键范围，明确观众先看什么、值得继续观察什么、哪些变化或细节承担表现、结果怎样被看清，以及如何接到下一关注。语言、真实材料、图形、排印和声音可以分别或共同成为主表现，按本段作用采用。

具体做法由原专业作者深化，导演判断组合是否符合本片方向。局部有新材料或更好的构思时允许调整；改变主要含义、全片气质或跨段关系时回到同一稿共同确认，不为每个参数增加审批。

当某项结果仍在影响后文时，后续保留这种影响；当内容需要轻松、舒展、收束或转向时，也应真实完成变化。不要把未解决的压力强加给所有段落，亦不要用漂亮转场掩盖尚未处理的前后关系。

真实判断的力度与证据匹配；来源、观点、本片分析和未知清楚区分。表达可以有观点、有情绪，不能通过删除必要条件或捏造行为实现。用户锁定的文字、声音与编辑范围继续保护。

<a id="writing"></a>

### 文案：按已选方向组织内容与口吻

继续使用原写作方法与本片所需的讲述方向，不从“事实驱动”推导出调查口吻。选择能够建立认识的事实、行为、细节和关系，说明重要判断的依据；情绪词、程度副词和口号不能代替内容。

安排语言与画面的先后：需要先看清的内容不抢先讲完；需要先说明的条件也不故意隐藏。使用明确主语、动词与指代，让理解、趣味、体验或判断真正向前发展。普通背景与气氛材料不必逐句证明知识。

准确性是共同底线，幽默、温和、直接、俏皮或沉浸的讲法由本片选择。不要把所有方向都改成悬念开场、风险升级和开放式问句结尾，也不要把所有句子削成短促判断。

交付原有完整文稿与声画说明，把关键语句需要的画面前提和强调位置写在对应段落。纯旁白与制作说明分开，不新增情绪报告。实际素材带来更好的讲法时向导演反馈，锁定稿件则先在允许范围内协同画面。

<a id="visual"></a>

### 视觉作者：让本片方向落实到整幅画面

先使用本片已采用的美术方向（`.agents/skills/visual-treatment-planning/references/art-directions.md`），再在实际画面中共同决定主体、材料、颜色面积、光线、字形、观看距离与运动性格。方向用于提出选择，不自动变成固定色板、素材筛选或动作参数。

把配色落实为背景与主体的明暗、相邻颜色的面积和用途；把材质落实为真实轮廓、边缘、表面与必要的光影；把运动落实为对象怎样变化、如何响应、在哪里读清与接续。采用图形化、平面或卡通表现时按其本身逻辑完成，不强制全部实体化或摄影化。

明快颜色、强排印、弹性、夸张和轻巧动作不是通用缺陷。它们是否适合，要看本片方向、对象和实际观看作用；同样，低饱和、低亮度、慢镜头和少效果也不是通用优点。完成度继续沿原有美术和连续演出规则判断。

原件承担阅读时定位相关内容并保留必要语境；真实过程承担观看时保留行为与空间；形式承担感受时把细节、变化和节奏做完整。材料可以共同呈现或接续，既不统一小窗，也不强制全屏。

同一视觉负责人持续完成美术、演出、源码和返修。复杂主体继续按既有参考方法保留造型、部件、遮挡、中途和响应；普通字幕、重点花字、源时钟及已采用表现照常交接。气质调整改变具体选择，不作为删减已验证能力的理由。

只有符合本页选择规则时才加载可选的严肃调查参考。未采用时不按它限制彩度、材质或动作；只采用局部方法时也不更换整片气质。

<a id="support"></a>

### 素材与声音：执行本片的具体选择

导演在原有完整声画稿中交清所需材料的用途和声音作用。素材继续开放探索，候选不必单独承担整段表达；题材相关、身份正确或文件可用不等于本段适用。核对实际姿态、行为、细节、源范围和声画语境，再由原作者选择用法。

声音作者继续原配音、取材、生成和混音方法。根据本片方向安排讲述重点、环境、音乐、动作声及强弱变化；不因加载共同方法就统一低沉、低密度或取消轻快声音。声音的回应与收束应配合实际过程，不能提前关闭尚在发展的关注。

同一句话到来时需要看见什么、哪次声音支持哪项变化、何时可以离开画面，仍写在现有段落中，依真实声音、源范围与作品事件校准。只有相关范围变化才续接对应作者，不增加额外交接体系。

<a id="review"></a>

### 审片：按本片采用的方向判断，不按统一风格打分

先记录实际作品的观看印象，再对照当前稿的采用方向与适用范围。共同特点检查内容和观看关系；视觉气质检查只使用本片真正采用的标准。不能因为作品明快、可爱、温暖或有弹性，就按严肃调查标准判错；也不能只因暗色、冷光和低饱和就判好。

检查内容是否提供本片所需的具体感受、关键变化或细节是否有观看空间、局部表现是否支持整体方向。局部借用只检查采用项，不把参考全文当成隐含要求。缺少方向说明时先读取当前稿与已有决定；仍缺失就向原负责人补齐，不能由审片者默认套严肃调查。

返修定位到内容选择、素材适用性、视觉与声音用法、实现遗漏或相互配合。已实现但不合适时改具体选择；不要为通过新检查降低原有动作、字幕和声音标准。专业判断不冒充已经测得的观众反应。

气质检查并入原专业审阅（`.agents/skills/quality-verification/references/professional-review.md`）：按同版实际覆盖复用证据，保留作者、导演与独立审阅者的责任区别；不逐层重复整片观看。局部返修核对受影响范围和必要接点，旧观察不得改记为新版。未看、未听的范围如实保留未知，不新增统一导出门禁。
