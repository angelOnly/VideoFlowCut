# 场面执行正文：导演到视觉作者的同一份交接

这是已有交接文本的格式，不是新增 Scene 类型或 API。内容按当前任务写，不要求无关栏目齐全。简单镜头可用短段落写完；复杂场面使用下列栏目。交接必须是当前内容的具体设计，不把标题当答案。

## 1. 导演交出的正文

同一份当前声画稿分清纯旁白、依据与素材引用、画面和演出、制作反馈四区；简单任务短写即可，不新增项目字段。素材清单引用现有文件，不在每次交接复制全部资产。TTS 只取纯旁白与实际支持的表演参数，来源和作者分析不朗读。

本稿从主题阶段由导演、文案、素材、视觉共同形成。初始可以只有主题、用户要求、初步问题和已有资料，素材作者不等待准确全文即可探索；材料发现、正文和视觉建议互相更新。导演按[主线方法](../production-director/references/story-and-shot-design.md)采用主要内容，材料参与方式沿[共同取材](../production-director/references/asset-briefing.md)落实。

进入某一连续范围制作时，交当前准确句群、前后关系、实际采用材料与源范围、已经看见的内容、主要观看过程，以及素材中还需解释的关系。主要画面以材料为基础形成，不把待取得内容登记成已经完成的模型容器；源内细节未知时如实保持未知，不造参数。

入口、主行为、持续参照、注意转向、读清时机和出口说明同一过程怎样发展。导演交表达目标、内容与跨段取舍，动效作者负责具体连续演出；图形与画内排印补关系，机制在制作阶段适配材料。未锁定的构图、大小、位置、层级和观察方式可由作者重组，不把第一张静帧变成终稿；主要内容或跨段含义变化回导演。内容句群、连续范围与输出文件分开，不将技术拆件当切镜安排。

导演本轮自主选择的口吻、美术、运动、背景和声音在同一稿里简要说明。用户未选偏好照常执行，只承接其明确要求与主动保存的默认；不派发博主学习或逐镜问卷。三类文字明确分开：普通字幕引用同一全片样式与准确卡文/时间；画内文字写实际观众用途；制作方法、内部对象名、来源渠道和研究备注留在制作资料，不自动上屏。必要内容限定保持准确，必要署名或披露按实际要求处理。美术首次确定字幕规范，后续交接引用同一份，不为每场复制一套可变样式；历史字幕接管、语组位移等要求仅作历史，不覆盖当前固定字幕路线。

## 2. 视觉作者回传的完整深化

编排中发现正文太密、缺铺垫或更好的声画表达，可返回具体改稿建议；材料不足或同质可提出补材。写清实际位置、理由、建议调整与保持项，原文案交准确新稿、原素材作者交文件和范围，视觉据此继续本场。普通背景更换不自动要求改字，反馈不是新增 MCP 参数。

在导演正文上深化同一场面，不另起与材料断开的“动效清单”。同一视觉负责人读取[默认整场设计](../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)和[完整演出写法](../motion-brief-writing/SKILL.md)，共用已有参考，同时决定美术、动作、真实对象映射和连接，再实现同一稿。传递产品默认要求、真实可选调整与本片决定，不只交空偏好对象，也不把静态美术锁成不能修改的页面。返回：

- 本场实际使用的原件、范围、已查看内容与关键未知；
- 准确台词、画内主读与对象标签的作用，以及独立普通字幕的同一规范引用；
- 已选主体轮廓、比例、材质、光向、真实字形与颜色角色；
- 关键构图中第一关注、观察尺度、前后层级和有用途的负空间；
- 变化发起、路径/轴心、速度、中间状态、遮挡、落读和交叠；
- 与当前声音/源事件的对应，语音、字幕卡和场面的不同时间单位；
- 出口由什么接住，技术拆件时持续对象的源时刻、投影与声音接口；
- 主要实现位置和必须实际查看的中途，不把字段齐全当设计成熟。

复杂场面写成可直接实施的连续正文，简单直剪无需凑所有装饰。首次主要表达及主要对象、事实或跨段关系改变按[共享交接](PROJECT_REVISION_AND_HANDOFF.md)回导演；已采用方向内的局部修订由原作者继续；摘要与已填栏目不能替代已经作出的设计。实际生成的字形、源材料和预览用于判断，不拿另画的概念图当成已经实现。

## 3. 展示文字与制作记录分别交付

当前稿明确准确旁白、普通字幕、画内主读以及必要的对象文字，说明其作用、归属与阅读时间。没有必要的类别不强行填写，更不为每镜配齐栏目、页码和身份条。

素材来源、示意身份、文件名称、场次、内部研究与未采用理由保存在制作记录中，不自动生成“示意、示例、图片来自网络、非当事”等角标或印章。删除旧提示时同时取消无用底框并重排空间。

会改变理解的假设和条件在相关讲述或真正需要的原件中准确交代，来源沿既有记录与交付清单保留。原文不被改造成项目结论；必要的真实署名或披露按对应要求处理，不与模型自行添加的提示混为一谈。

## 4. 交接不合格时怎样处理

只写“展示资料/增加科技感/加运镜”时，由导演或原视觉作者补成上述正文。缺少真实参数，由协调者读回项目事实；缺关键创意，由原作者继续设计；缺某理想素材，按素材适配规则决定可得载体。所有路径都继续同一生产任务，不将专业问题转交用户填写。

## 视觉回传的关键中途与连续演出

视觉回传沿 [同一执行稿模板](../motion-brief-writing/references/execution-brief-template.md) 交付准确讲述、实见材料、美术、危险中途、当前声音和版本。中途说明姿态、轴心、遮挡、第一注意、速度与源时钟，不只写移入或缩放。保留本页导演正文、来源身份与可见文字职责；全文作为同一版制作依据，按共享交接的影响范围协调。
