# 从主题到素材主导的完整成片

本页是完整解释视频的共同制作主干，适用于 visual_explainer，以及
presenter_motion 中的完整人物混合解释；不重新判定 project.profile。
人物任务沿同一文案、取材、视觉、机制、声音与返修方法推进，只在对应环节
叠加人物化讲述、原话权限、表演源和人物共同编排要求。
复用本页不调用纯解说导演的全部类型专属操作，不强制人物项目建立 NarrativeMap
或 ExplainerProgram；也不向纯解说增加人物输入。Vlog、原片清理和局部包装按
其根路线与授权范围调用所需章节，不自动继承完整解释任务。
完整解释的素材和视觉从首轮参与；实际文件分批返回，声画稿持续更新，
不把正式 API 的依赖顺序误当成整片串行创作顺序。
制作范围为完整解释时，即使正文或正式声音锁定，取材、整场设计与连续制作仍完整执行；
只保持被锁定的内容，不把不可改字误译为只能给人物加局部包装。

材料从首轮提供真实观察、语境和事实依据，不是动画完成后的可选插播。素材可以来自用户文件、已有资源或外部检索，形式由内容决定；“素材主导”不规定固定拍摄类别、显示面积或主次。人物任务在对应环节增加[人物入口](../presenter-motion-director/SKILL.md)的方法，不加载纯解说导演作为第二主导演。

完整新制或主要视觉重做时，导演交准确内容与前后关系，创意与视觉将可采用的参考写入[制作简报](../opendesign-shot-brief/SKILL.md)。视觉作者沿[整场设计方法](../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)交导演稿及真实资源。OD 制作首版，原作者接回实际作品。普通字幕独立合成，尊重已锁定的正文与原音。

## 整幅视觉创作的持续责任

完整视频从主题阶段并行探索。原视觉作者持续负责真实素材、参考迁移、构图、美术、排印、镜头和运动设计，交 OD 实现后继续负责视觉反馈与复查。

创意作者提供完整参考的创意方法，素材作者提供真实材料，主导演负责准确内容和跨段关系。它们不分别形成互相独立的最终视觉方案。

不同视频类型可以增加人物、Vlog、声音或其他专门方法，但不另建第二套完整视觉创作生命周期。

## 同一轮启动导演、文案、素材、创意与视觉

主题到达时，同时启动文案、素材、创意和视觉探索。文案作者研究内容并形成初稿，素材作者寻找相关材料，创意与视觉参与讲法构思及参考探索；导演交清用户要求，协调主线。文案初稿、实际材料和参考发现及时交给其他作者，允许它们改变初步讲法。

创意作者交回看过的参考范围、具体表现和结合本片材料的采用意见。主任务续接原视觉作者，双方共同确定本片场面，由视觉作者汇总制作简报、完整请求和实际资源。

视觉交回导演稿、时间计划和有据的素材、参考。主任务先准备交付清单，导演沿[主要场面采用](../production-director/SKILL.md#主要场面采用)确认本次可制作范围。派回补材、改稿或补看时，独立范围继续。

当前范围的主要采用确定后，主任务沿[任务路由](../production-coordinator/references/task-routing.md#视觉派发与接回的完成口径)提交完整制作请求。

共同草稿沿[导演主线方法](../production-director/references/story-and-shot-design.md)发展；文案、创意、视觉和声音作者各自提出专业选择，导演协调主线与跨段关系。

导演与视觉开始构思关键动作时，同步明确持续负责的声音作者，可以由现有作者兼任。先确定哪些动作值得发声、声音怎样起势和收尾、哪些范围需要留白；由[声音取材](../sound-asset-sourcing/SKILL.md)选择现成或生成来源，定做声音时续用[音效提示词](../sfx-prompt-writing/SKILL.md)。动画未定稿也可先形成声音候选，正式采用前再用真实作品事件和实测音频校准，不能把声音任务留到画面全部完成才开始。

## 用实际材料形成画面和准确文案

普通画面从整片主题、相关场景、对象和活动广泛准备，可以承担语境、氛围、变化、趣味或节奏，不必逐句演出知识。明确原文、数据、真实操作、指定事件或直接指认对象时，才按事实需要定向核实。有希望的候选及时取得，创意主动提出材料条件与声画需要；首批发现及时交创意、视觉、文案和导演，既可支持也可推翻原构思，由导演协调主要采用；材料的新发现可以推动当前稿，但普通背景替换不自动要求改写正文。

创意检索、参考观看和初步构思可以从主题阶段开始。素材分批返回后，及时进入文案、创意与视觉的共同设计。

将有依据的参考落到真实素材和讲述上，明确观众会看到哪些材料，它们怎样共同变化。完整新片默认用创意库研究并落实适用关系。候选不适用就调整查询、选择其他场面或重组素材。确无适用的局部机制可以依依据原创，保留具体范围与理由，继续满足整片约定。

导演查看这些具体内容，再判断本段是否适合进入制作。参考编号、观看记录和素材附件用于追溯，编排依据写在本片实际画面过程里。素材或参考尚未核实的部分保留待验证，其他具备实际条件的范围可继续推进。

具体采用与补材判断沿[主导演方法](../production-director/SKILL.md#主导演的目标与编排顺序)执行。经过实际检索和比较仍无适用参考时，创意与视觉根据已查看材料共同设计该范围，交清完整过程。

含旁白的正式时间编排使用当前稿对应的实际音频。纯图形或数据范围使用已确认的内容与所需资源。已经具备条件的范围可以推进，其余范围继续准备。

材料可以阶段性成为主角，与花字、准确编辑图形共同呈现，或在作用完成后退为参照。不得用无依据图形替代事实，也不得把真实性扩大为原窗口、原位置或固定显示面积；主要画面由视觉负责人整体选择。用户明确保留原片或实拍主导时按实际范围执行，只有用户明确改任务才改变这些边界。单个候选不合适可以放弃，未完成的取材任务继续换范围、换源或重组。不可辨数据不猜，单图不假装可拆层，源内不存在的行为不伪造；编辑图形保留与已核对字段的对应，不冒充官方页面。

## 声画共创与连续制作

素材与准确台词形成后，结合当前声画构思生成或修订相应范围的正式配音。需要与旁白同步的具体时间编排使用返回的实际音频，声音返回前继续构思和准备资料。

更早的读稿或试音作为当前制作成果，用户明确锁定项继续有效。正文准确但难讲、过密、缺铺垫或存在更好的声画顺序时，由导演协调原文案及相关作者调整，再按实际新声音校准。

创意与视觉按连续内容共同编排本片，沿[参考与素材落地](../creative-reference-to-sequence/SKILL.md)确定选中场面怎样使用实际素材和准确文字。完整新制或主要视觉重做时，视觉作者按[视觉入口](../visual-treatment-planning/SKILL.md#先进入本次工作)完成美术安排，主动使用[机制方法](../motion-case-library/SKILL.md)研究运动与连接；研究结论和是否采用均如实交回。

动效查询返回异步任务时，跟进原任务并取得实际候选，交回原视觉作者继续读取、观看和选择。采用的参考视频、完整过程与本片用法进入同一份制作简报。实际观察范围照实记录。

视觉作者将真实材料、准确文字、字体、字幕位置和关键动作写入统一导演稿。正式声音可用后校准时间。OD 直接制作首版，优先交可代表主要关系的连续范围。视觉负责人和导演观察实际画面，真实材料或声音变化时更新受影响的安排。技术拆件沿同一根时钟和源时钟。

作者明确交出可检查的连续范围后，按实际已发布的冻结与局部生成能力接回；可用范围的真实观察与后续无依赖制作并行。正在编辑的文件不当作固定版本，候选素材或估计时长也不当作正式事实。前后场面、共享元素或声音变化可能扩大影响范围；完成全片后仍需同版整片合成及真实声画审阅。

编排、制作和预览都可发起改稿、补材或重做设计：讲述不清回原文案与导演；整体创意普通、期待或情绪回报不足回原创意与视觉共同重选讲法，画面少或同质回原素材作者，构图与动作不成立回视觉，设计明确但实现遗漏回源码作者。返回实际新稿、文件、设计或源码，合并到同一份当前声画稿；按真实工具返回更新受影响的声音、字幕、绑定、时序和预览，保留不受影响工作与用户锁定项。技术生成、设计兑现和实际观看分别报告，不新增逐镜审批。六种表达方向只用于讲述与美术参考，不控制素材类别或动效参数。

代表段把声音候选与实际旁白、音乐和动作一起比较，选定后再写入正式音轨。声音作者沿[声音意图收尾](../audio-finishing/SKILL.md#声音意图收尾)交回采用、导演留白或未完成项，导演在粗剪与交付前核对；只有声音计划、无声动效或生成文件，均不能代替实际声音制作。

## 当前稿与正式对象

沿现有完整消息／附件、CreativeDecision 和项目绑定保存当前准确正文、实际材料、连续场面、声音方向与变更。来源和内部分析留在记录，展示文字由作者明确；不自动把制作说明渲染到画面。主任务负责真实参数、版本与正式提交，不将完整创作压缩成几个标签。材料、声音或设计变化只续接受影响范围，不另建剧情库、投票表或审核对象。
