# 从主题到完整成片

本方法的正常起点是用户只给一个视频主题。导演带领团队完成研究、角度、解说稿、选材、分镜、美术、配音、声音、动画、合成和交付。下列栏目由团队自己生成，不是用户问卷；本文件不增加 API 字段或新项目数据库。

## 1. 导演先形成可验证的探索方向

用户只给主题时，导演先提出能通过材料研究的具体关注、候选角度和可能的观看过程。三句话可以说明从什么对象开始、希望观察什么变化、可能带走什么认识；未查清的事实与未见画面保持候选身份，不把预设反应、原句位置和源内动画当成已采用。

事实研究与素材探索并行，实际候选可以改变主线和开场。导演负责内容价值与全片发展，文案与视觉作者分别看与自己决定有关的材料。普通网页打不开、理想机位没有命中，不自动变成平台故障或用户上传任务。

按本场依赖推进，相关材料已足够即可形成具体声画稿，其他场面继续查找，不要求全片素材齐备。画幅、声音方向和初估规模读取既有配置并按内容决定，没有用户明确锁定时可随实际声画修改；不用历史试片时长、人物或配色代替本片判断。

## 2. 文案与画面一起发展

文案作者返回完整朗读正文，同时在每个句群旁写主要观看过程。正文放入关系、动机、判断、态度和必要条件；画面承担能被观察的动作、比较和变化。字幕转写本版正文，画内文字承担指认、强调或关系，不把正文复制成每句一张说明卡。

材料改变判断时改稿；画面已经讲明的重复可压缩；关键过程需要更多观看时，重排句群或调整配音停顿。由原作者返回一份自洽的最新全文，不让下游拼接多份修改留言。

## 3. 从连续观看叙述产生场面

先写“观众实际看到怎样的展开”，再映射 Story/NarrativeMap 和 Scene。技术作品数量由资源预算和接点决定，既不等于句子数，也不决定整片时长。

一个场面可以跨句、包含明确切镜，也可以让一个对象保持。不同场面在内容需要时形成尺度、方向、明暗、材质或注意路径的变化。人物表演、实拍过程、稳定比较和安静观察都有价值；不设每场必须多少动作或全片必须多少种转场的配额。

进入具体制作时，导演给每场交出 [场面执行正文](SCENE_DESIGN_HANDOFF.md) 所列内容。视觉作者据此继续深化，不重新猜主要对象与关系。

## 4. 实际材料、声画内容与美术共同形成

素材负责人按 [素材到场面方法](MATERIAL_TO_SCENE.md) 取得实际候选，返回原件、范围、可见对象、动作、原话、位置变化、上下文和使用条件。题材与文件名不代表画面已被理解。导演看故事删留依据，文案看语言依据，视觉作者看将被操作的画面；范围按职责缩小，不要求所有人重复看完整候选库。

原始拍摄、已剪成片、录屏、照片和页面都按具体用途判断。已有包装可能是内容也可能竞争，不能因素材类别强制contain或短引用。实际材料支持什么就据此重写声画，必要主体、事实或关系发生变化时明确决定，不悄悄换题。

本场源依赖的具体构图、裁切、源动作、原句和动画在相关材料看清后采用；未看材料时可以探索，不能提前完成正式动画再只验证素材能否装入。换材后原作者重新确认字、焦点、路径、时间与声音影响，而非只换Asset ID。

有实际内容与观看关系以后，按需读取内部案例。案例提供已验证范围内的做法，不代替新素材与新设计；普通无参考任务不要求用户提供参考视频。

## 5. 同一作者交付具体美术和完整演出

在当前画幅、实际素材及已发布字体中选择本片主体、字形、字幅、颜色角色、明暗、比例、负空间和运动语气。整片一致不等于每场同一版式，阅读与物体表现需要有真实构图，不用“科技感、高级、丝滑”替代决定。

需要原创运动的场面，同一视觉作者读取 [完整演出写法](../motion-brief-writing/SKILL.md)，在 [场面执行正文](SCENE_DESIGN_HANDOFF.md) 上深化。写清内容为什么发展、谁发起、路径/轴心、遮挡、动作中途、落读、交叠和出口，并将当前准确声音与字幕放在同一稿中。

导演统筹主要表达与相邻场面后回原作者实现。采用不是美术通过，字段齐全不是设计完成；主要关系只剩效果名称就补设计。实际源码、字体与素材共同预排，对需要动态判断的关键过程查看连续范围，不用另画的理想化概念图代替实现。

## 6. 声音是完整生产的一部分

主题驱动的解释片通常由完整解说、实际配音与字幕共同组织。导演按题材选择语气与说话节奏；音效、音乐和源声按具体内容服务观看，必要时保持干净。配音回来后，以真实句段边界校准动作和阅读，不能把首轮 TTS 时长反过来固定全部创作。

遇到画面任务过早完成，优先删并重复话语、调表演停顿、改动作接续和段落边界；返回相关原作者并同步重配、字幕和音效。整片总长由这次音画共同完成后的实际结果确定，不继承任何教学样片的秒数。

## 7. 一次任务内完成成品检查

原作者先检查自己的关键动作与共同构图，再由独立审片按正常顺序查看实际合成。分别记录文件/引用正确、设计是否实现、实际观看是否成立。按实际可用的播放、抽帧和媒体分析能力记录范围；静帧不能替快速动作或听审背书。

发现问题回原负责人；同类问题合并处理。用户接收本次任务的完整成片和准确状态，不承担找素材、补分镜、逐帧找错这些生产工作。内部有限修订是生产的一部分，不把“首次面向用户的成片质量”理解为取消必要的渲染检查。

## 8. 当前采用稿与正式对象

复用现有宿主完整消息/任务附件和 CreativeDecision 引用保存全文与版本，不新增通用剧情数据库。完整交接集中为：本版主题角度、最新朗读全文、实际材料、场面执行正文、声音方向、采用差异、正式写入参数。

协调者只做版本/引用/权限/确定性装配，不把全文压成“做高级动画”，也不为通过字段上限静默截断。当前工具需要参数时，由原作者给出已核对值。发现接口不能表达当前决定，保留原产物并沿项目修复入口处理。

项目中已有其他任务类型时维持其路由。本方法直接覆盖“只有主题”的普通原创生产，不改写用户真实给定的特殊任务，也不改平台安全和版本校验。
