# 从主题到完整成片

本方法的正常起点是用户只给一个视频主题。导演带领团队完成研究、角度、解说稿、选材、分镜、美术、配音、声音、动画、合成和交付。下列栏目由团队自己生成，不是用户问卷；本文件不增加 API 字段或新项目数据库。

## 1. 导演先作出创作决定

读取主题后，先确定一个足够具体、能被材料支撑的讲述角度，用三句话写清：从什么处境或对象开始；中途让观众看到哪些值得观察的变化；结束时带走什么认识、感受或行动。受众与表达方式由主题和发布环境推定，推定写在内部制作决定里。

并行发出事实研究与画面探索：前者核实主张，后者寻找实际可用的动作、细节、比较和反应。初步方向可以因此变化。一个网页打不开或一个理想机位未命中，不等于主题不能制作。

导演自行决定有无出镜人物、画幅、初始节奏、声音方向、预计内容规模。已经有项目发布配置时读取并使用；配置不足时选择合理方案并记录理由。初始长度服务内容展开，不是必须填满的目标；整体音画可以随制作继续调整。无需先向用户索要解说稿、固定秒数、参考片、素材包或逐镜设计。

## 2. 文案与画面一起发展

文案作者返回完整朗读正文，同时在每个句群旁写主要观看过程。正文放入关系、动机、判断、态度和必要条件；画面承担能被观察的动作、比较和变化。字幕转写本版正文，画内文字承担指认、强调或关系，不把正文复制成每句一张说明卡。

材料改变判断时改稿；画面已经讲明的重复可压缩；关键过程需要更多观看时，重排句群或调整配音停顿。由原作者返回一份自洽的最新全文，不让下游拼接多份修改留言。

## 3. 从连续观看叙述产生场面

先写“观众实际看到怎样的展开”，再映射 Story/NarrativeMap 和 Scene。技术作品数量由资源预算和接点决定，既不等于句子数，也不决定整片时长。

一个场面可以跨句、包含明确切镜，也可以让一个对象保持。不同场面在内容需要时形成尺度、方向、明暗、材质或注意路径的变化。人物表演、实拍过程、稳定比较和安静观察都有价值；不设每场必须多少动作或全片必须多少种转场的配额。

进入具体制作时，导演给每场交出 [场面执行正文](SCENE_DESIGN_HANDOFF.md) 所列内容。视觉作者据此继续深化，不重新猜主要对象与关系。

## 4. 实际选材、材料发现与美术共同发展

素材负责人按 [素材到场面方法](MATERIAL_TO_SCENE.md) 先看实际候选的对象、区域、原句和动作，再返回原件、源范围、可辨细节、位置变化、事实边界与创作机会。题材、文件名和许可只能说明候选的一部分，不能替代实际观察。

导演可以先构思，材料不必全到齐；最终采用混合场面时，用这些实际发现回写当前完整稿和场面：动画指向哪一处，如何改变观看，什么参照仍在，何时交给下一步。来源的事实边界不预设必须独占全屏后退出；镜头呈现由导演与视觉作者决定，真实许可限制仍然保持。

理想材料未取得时，优先利用可得材料重组同一任务。导演内部采用后，协调者更新需求、当前采用和绑定；视觉作者同步重排焦点、裁切、动作与时间。照片和静态原创不会自然继承长实拍的过程；原片不足不能由隐式循环补齐。

材料不支持预设主张时继续核实或改准确表述/角度。日常空间已有可观察过程时，允许其改变泛化知识稿；不因为图标容易做就放弃现场内容。普通搜材未命中不转为用户上传，权限与付费仍走现有授权路径。

## 5. 同一作者落实美术、运动与时序

在当前画幅和真实字体下确定主体轮廓、比例、细节分布、光向、文字主次、有效留白与投影尺度。为关键入口、一次主要变化、一次重要阅读、出口画面形成实际构图；检查时把真实字幕和人物占用也放进去。

写清状态之间怎样变化：哪个层发起、绕哪一处转、沿什么路径、谁被遮挡、谁保持、下一重点何时接手。不同对象按重量和任务分配速度，文字达到可读状态后计阅读时间。作者从设计时就去掉重复建立与无用驻留，而不是先交一版低质量片让用户指出。

## 6. 声音是完整生产的一部分

主题驱动的解释片通常由完整解说、实际配音与字幕共同组织。导演按题材选择语气与说话节奏；音效、音乐和源声按具体内容服务观看，必要时保持干净。配音回来后，以真实句段边界校准动作和阅读，不能把首轮 TTS 时长反过来固定全部创作。

遇到画面任务过早完成，优先删并重复话语、调表演停顿、改动作接续和段落边界；返回相关原作者并同步重配、字幕和音效。整片总长由这次音画共同完成后的实际结果确定，不继承任何教学样片的秒数。

## 7. 一次任务内完成成品检查

原作者先检查自己的关键动作与共同构图，再由独立审片按正常顺序查看实际合成。分别记录文件/引用正确、设计是否实现、实际观看是否成立。按实际可用的播放、抽帧和媒体分析能力记录范围；静帧不能替快速动作或听审背书。

发现问题回原负责人；同类问题合并处理。用户接收本次任务的完整成片和准确状态，不承担找素材、补分镜、逐帧找错这些生产工作。内部有限修订是生产的一部分，不把“首次面向用户的成片质量”理解为取消必要的渲染检查。

## 8. 当前采用稿与正式对象

复用现有宿主完整消息/任务附件和 CreativeDecision 引用保存全文与版本，不新增通用剧情数据库。完整交接集中为：本版主题角度、最新朗读全文、实际材料、场面执行正文、声音方向、采用差异、正式写入参数。

协调者只做版本/引用/权限/确定性装配，不把全文压成“做高级动画”，也不为通过字段上限静默截断。当前工具需要参数时，由原作者给出已核对值。发现接口不能表达当前决定，保留原产物并沿项目修复入口处理。

项目中已有其他任务类型时维持其路由。本方法直接覆盖“只有主题”的普通原创生产，不改写用户真实给定的特殊任务，也不改平台安全、素材权利和版本校验。
