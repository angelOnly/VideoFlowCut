# 从主题到完整成片

本方法的正常起点是用户只给一个视频主题。导演带领团队完成研究、角度、解说稿、选材、分镜、美术、配音、声音、动画、合成和交付。下列栏目由团队自己生成，不是用户问卷；本文件不增加 API 字段或新项目数据库。

## 内容先行，动效阶段组合机制

用户只给主题是正常输入。导演、文案、素材、视觉、声音与审片共同完成研究、草稿、取材、设计、制作与内部修订，不要求用户补专业分镜、找素材或逐镜审批。

导演、文案、素材与视觉作者使用通用专业方法，根据研究、实际材料和当前反馈形成完整声画稿。前期不主动读取项目内的历史案例、整片参考卡或运动机制目录，不为匹配库内形式预先决定题材、分镜、材质或版式。导演与文案按 [共同构思方法](../production-director/references/story-and-shot-design.md#从实际声画构思主线段落与分镜) 形成完整朗读草稿与粗分镜，原视觉作者在同一草稿阶段提出能改变讲法的对象、行为或空间构思。每镜写准备讲什么、看什么、如何发展、还需什么材料；未见的动作与未核实的结论保持候选。

事实核对与生活画面探索在草稿阶段同时进行。材料回来后共同改写文案、试接镜头；导演与视觉写清本场实际看什么、选段里有什么变化、使用哪些材料、关键句意到来时应看见什么、出口怎样接下一镜。进入该场动画制作后，由当前作者使用 [120库运动机制](../motion-case-library/SKILL.md) 完成选型、对象适配和组合，再落实受管源码。材料足够的场面先推进，不以全片资料齐备为前置。

机制改变局部路径、速度与显露时由原作者继续；影响主要内容、关键素材或跨段关系时回导演。真实素材不足仍继续补材或修改具体镜头，不能因机制容易实现就取消素材任务。材料与试排可以推动改稿，库内现成外观不替代上游主题与美术。用户明确要求研究历史作品、复现旧源码或分析整片参考时才进入相应历史分支，旧任务权限不转成本片授权。

素材作者按粗镜头任务取得并观察真实文件，返回源范围、直接发现、可演出机会和使用条件。区分事实依据、情境材料与原创对象；参考库视频不自动成为生产B-roll。材料回来后，导演、文案和相关视觉作者重新判断改词、换镜头、重排或继续取材，不只给旧稿加来源。材料已足够的场面可以先深化，不等全片齐备。

当前整片声画稿仍用现有全文或附件，包含准确正文、逐镜观看、实际材料、已选美术、中途演出、声音和采用差异。参考借鉴直接体现为本片选择；例如借鉴“同一结果持续”以后，写清本片是哪一个主体、保留什么、怎样发生变化，而不只登记案例编号。正文版本与Project Revision区分，旧稿保留历史。

同一视觉作者在实见材料上完成造型、字形、关键构图、动作中途、源码与修订。首次主要表达由全文回导演统筹后继续；已采用方向里的普通比例、路径和曲线由原作者决定，主要对象、事实含义、讲述順序及跨场风格变化回导演。按 [场面正文](SCENE_DESIGN_HANDOFF.md) 和 [完整演出写法](../motion-brief-writing/SKILL.md) 工作，材料沿 [素材到场面](../production-director/references/asset-briefing.md) 回传。

试排使用本片当前准确文字、实际材料、已登记字体、真实声音和主要动作。先看完整语境，再按风险取帧定位；不能拿另画的理想图证明实现。已发现的设计问题可推动改稿、重配、换材和重选美术，第一版TTS不构成用户锁定。

分别判断文件正确、设计是否实现、实际观看是否成立。参考只用于比较相关关系，不拿“像原片”代替事实、可读与整体设计，也不拿静帧证明连续流畅或声音表现。未知保留，已知问题回原作者；技术可导出不等于专业定稿，审美未知也不变成所有导出的禁令。

历史自有案例保留原件与已验证范围，具体入口仅在用户明确请求的历史分支读取；不作为机制缺少源码时的自动回退。

## 当前采用稿与正式对象

复用现有宿主完整消息/任务附件和 CreativeDecision 引用保存全文与版本，不新增通用剧情数据库。完整交接集中为：本版主题角度、最新朗读全文、实际材料、场面执行正文、声音方向、采用差异、正式写入参数。

协调者只做版本/引用/权限/确定性装配，不把全文压成“做高级动画”，也不为通过字段上限静默截断。当前工具需要参数时，由原作者给出已核对值。发现接口不能表达当前决定，保留原产物并沿项目修复入口处理。

项目中已有其他任务类型时维持其路由。本方法直接覆盖“只有主题”的普通原创生产，不改写用户真实给定的特殊任务，也不改平台安全和版本校验。
