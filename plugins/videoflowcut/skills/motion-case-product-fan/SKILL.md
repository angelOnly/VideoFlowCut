# 产品扇开 → 数字突出 → 回收与箭头接力

## 1. 适用场景与表达目标

本案例先让观众认出一组产品，随着四台平板扇开，后层数字获得空间并成为重点；读清规模含义后，同一组产品收回，黄绿箭头接过视线，引向画面下方。连续感来自原四台的遮挡、位置与尺度变化，不需要切换到单独的数字页面。

适合产品集合、多个版本或选择项的展示，以及向下继续浏览的引导。逐项比较优劣时，应补充真实的共同尺度与阅读设计；需要精确点数时，应建立实际可数阵列，不能用本例四台示意物证明七十件数量。

本例“70”的完整含义是“演示目录共 70 款”，四台仅展示其中四例。颜色用于追踪对象，不代表折扣、销量或优先级；箭头表达观看方向，不表示视频里有可点击的真实按钮。

本案例供 [remotion-production](../remotion-production/SKILL.md) 在段落构思与设计时使用，当前产品、真实文案、旁白、画幅与前后画面由主工作流提供。

## 3. 具体美术设计，以及为什么这样设计

### 3.1 色彩、舞台与注意顺序

| 元素 | 本例的具体设计 | 设计作用 |
|---|---|---|
| 舞台 | 深蓝灰 `#19232D`，中央仅有很弱亮度差；下方深色柔椭圆投影。 | 托出浅色机身并建立共同地面，不用额外标题框分割观看。 |
| 四台机身 | 浅紫 `#B7A5CF`、乳白 `#EEE8DF`、浅蓝 `#A9C8DC`、中灰 `#747982`。 | 颜色、左右顺序与前后关系保持，观众能追踪展开前后的同一组。 |
| 大数字 | 白色 `#F4F5F2`、极粗无衬线数字，与单位和辅助行组成一组。 | 比机身更强的面积与对比，让规模信息在展开后成为重点。 |
| 最后箭头 | 黄绿 `#B5FF35`，实心、无描边发光。 | 后段才引入独立色彩重音，明确向下的观看方向。 |

本例以 960×540 横幅设计。地面影中心约在 (50%, 83%)，初始宽约画宽 54%、高约画高 9%，颜色接近 `#101820`，边缘柔和。影子随集合展开、缩小而变化，从属于产品，不独自呼吸循环。

### 3.2 产品轮廓与扇形几何

每台以约 206×282 的内部尺寸绘制，圆角约 15，近黑外轮廓和 2—3 像素浅灰金属边。内面缩进约 6 像素，右侧或下侧露窄深边。左上单镜头用近黑外环、蓝灰内环和极小高光；背面中心有低对比的对称叶眼状细线，提供细节而不冒充品牌标志。机身、边线、镜头、装饰和自身微影是一个共同变换的对象。

浅紫、乳白、浅蓝、中灰按固定顺序绘制，中灰在最前。叠放时中心基本重合，只露后排窄顶边和侧边；落位中心约 (50%, 59%)，单台宽约画宽 21.5%、高约画高 52%。展开后四台中心横坐标约为 30.5%、43.5%、56.5%、69.5%，角度约 -19.5、-6.5、+6.5、+19.5 度，仍有相互覆盖。

横向位移与角度共用展开进度，离中心越远转角越大。回收则沿原关系归中、归正并缩至原尺度约 62%，保持四色与绘制顺序；后排自然被遮住，仍露一点边缘。不能删掉四台再换成一台灰色物体，也不能先平移后旋转形成两次独立动作。

### 3.3 数字与箭头的空间交接

“70”位于产品后层，字号约画高 39%，从中央偏下的位置向上露出，终点上缘距离画顶约 3%—5%。数字与机身可以前后遮挡，但最终 7 和 0 的主要轮廓都应完整。数字无描边、发光或独立卡底，依靠面积和上抬方向得到注意。

小单位“款”放右侧空白，“演示目录 · 展示其中 4 例”以约 18—20 像素字放附近留白，不能缩成难读小点或压住机身边缘。三者共同移动、稳定和退出，完整信息到位后才计阅读。

箭头的直杆约宽 60、头部约宽 130、总高约 125，起始位于数字下方与缩小产品上方的空白。箭头和产品中轴均为画宽 50%，下移时尖端与产品顶部留约画高 5%—8% 的间距。它边建立边向下，不先完全显现、停一拍再移动。

## 4. 以秒表达的参考节奏、动作交叠与接续

**下表是首版节奏的参考用时，不是必须填满的时间槽。先据此完成设计和实现，再连续观看成片，按实际动作、阅读与前后衔接调整。**

相邻动作有意交叠，用时不能直接相加为总长。产品数量、路径、字宽、画幅或旁白变化后，重新安排对应部分与后续接点，不要求维持历史 10 秒。

| 阶段 | 首版参考用时 | 具体动作与接续 |
|---|---|---|
| 堆叠产品从下方进入 | 每台约 0.9—1.1 秒；相邻启动错开约 0.10—0.13 秒。 | 第一台从底部附近上移，后续保持叠放关系。前半较快、落位前收速，不给每台不同的随机弹跳。 |
| 入场接上扇开 | 扇开约 1.2—1.5 秒。 | 第一台进入约 55% 路程时扇开已启动；位置与角度一起展开，后排通过遮挡变化逐步露出。 |
| 数字露出与上抬 | 显现约 0.4 秒；上抬约 1.0—1.2 秒。 | 扇开约四成时数字已从后层显现，上抬与向两侧展开互补，单位和辅助行随同稳定。 |
| 完整信息阅读 | 先按约 0.8—1.1 秒。 | 数字、单位、辅助行和四台都清楚后开始计阅读，读清“70 款、展示 4 例”就回收，不额外等整数秒。 |
| 同一组产品回收 | 约 0.9—1.2 秒。 | 位移回中、角度归正、尺度缩小同时组织，原四色与前后关系连续。 |
| 数字退让、箭头接手 | 数字组退出约 0.4—0.55 秒；箭头显现约 0.3 秒。 | 回收约七成时数字退去，箭头可开始建立并下移，不挡仍需阅读的数字。 |
| 产品与箭头共同离场 | 下移约 1.0—1.4 秒；箭头约晚 0.10—0.15 秒跟随产品。 | 回收最后一小段产品已下移，两者保持间距与相近速度趋势；最后可见物出画后结束或交接。 |

代码按当前秒数和 fps 换算事件帧，渲染前确定本次总帧数。历史指令中最后 2—3 帧仅是独立输出的自然余量，不作为需要补足的空背景。若当前剪辑需要提前由下一画面承接，按实际出口设计对齐。

连续预览中，读数已经完成而回收未启动，就调整回收接点；数字读不清，先检查顶部裁切、遮挡与辅助行字号，再延长对应阅读。离场太慢则检查距离、间距和起势，不为凑长度拖慢收尾，也不全段统一倍速或添加机身微动。

已有旁白或锁定总长时，在约束内调整内部覆盖、交叠和后续画面，不能擅自改短声音或整片。最终以当前成片的表达、可读性和观看节奏验收。

## 5. 换内容时保留什么、重新设计什么

| 设计层面 | 可以保留的方法 | 需要按当前内容重做 |
|---|---|---|
| 观看顺序 | 认出集合、理解规模、把注意回收并交给下一步。 | 当前展示目的、规模含义与行动方向，未必需要数字或箭头。 |
| 产品与美术 | 固定身份，颜色分工，轮廓与细节随对象共同变换。 | 真实产品、材质、尺寸、数量、颜色和合法素材。 |
| 空间与动作 | 位移和转角同时扇开，沿原关系回收。 | 新数量对应的角度、间距、遮挡、路径、尺度和局部用时。 |
| 数字事实 | 数字、单位与限定说明作为完整信息组。 | 真实数值、单位、来源及阵列是否承担点数，四台不能自动代表 70 台。 |
| 结束与合成 | 上一重点退让时下一方向已建立。 | 当前出口、前后画面、旁白、人物与字幕占用。 |

例如展示三个订阅版本，可以保留展开与回收，但要按三个对象重新排扇形，并用真实版本差异代替“70 款”。如果要逐项比较，就为相关说明安排可读构图，不让高速扇开承担全部阅读。

历史源码只暴露 mode，产品数量、颜色、数字、路径和时序在实现内部。改内容、横竖幅或人物同屏均需重新布局，不能只替换标题。独立指令的无声横幅属于示例；当前数字人任务按真实人物和字幕空间决定同屏还是全屏接管。先规划展开、数字突出或向下引导所需配声，再按实际事件对齐，不机械给每个动作加同一种音效。

## 6. 如何根据实际成片检查和调整

先对照[展开中](assets/preview-050.png)、[数字可读](assets/preview-120.png)、[回收交接](assets/preview-190.png)、[向下接力](assets/preview-255.png)理解构图，再检查当前作品对应事件。连续播放时重点观察入场到扇开、数字阅读到回收、回收到箭头三处。

| 检查位置 | 应看到的结果 | 不成立时怎样修正 |
|---|---|---|
| 入场到扇开 | 同一组从堆叠打开，机身、镜头、边线无滑动。 | 校正共同对象变换、固定顺序和展开起点，不用透明度开关代替遮挡变化。 |
| 扇开到数字阅读 | 四色可辨，70、款及展示说明完整，主次清楚。 | 调整数字抬升、顶部留白、产品遮挡与字宽；必要时延长完整信息可读段。 |
| 阅读到回收 | 数字含义已明确，四台沿原关系合拢。 | 校正阅读终点、回收位移角度和尺度，不删成单台，也不在读完后空等。 |
| 回收到箭头 | 数字退让时箭头获得注意，产品已准备下移。 | 调整交叠和重音顺序，避免数字、机身与箭头同时抢阅读。 |
| 共同下移到出口 | 箭头不穿进机身，运动方向一致，离场后自然结束。 | 调整间距、路径和速度趋势；收掉空背景尾巴，或接上已规划的下一画面。 |

历史 v1 的 fan 在第 100 帧结束、gather 第 150 帧才启动，曾定位到 4.03—5.23 秒近静止和后段静止。v2 在同一总长内将 gather 提前为 125—195（原 150—210），drop 改为 200—295（原 222—288），箭头显现提前为 180—211，移动延续为 180—298、y=130→425。经验是修正具体接点与观看方向；当时保持 10 秒并不要求新片也填满 10 秒，检测阈值也不是通用停留上限。更多诊断见[停顿与顺滑经验](../motion-case-library/references/timing-continuity.md)。

静帧检查构图，正常速度播放判断接续与节奏。通过既有生产流程放回真实剪辑，连同前一句、完整动效、后一句、人物字幕和声音检查。需要合成才能判断时先用既有待审草稿取证，再完成复核；替换产品、数字、画幅或声音后，对应旧验证失效。

把当前完整指令、作品与放置版本、素材来源、实际事件、审阅结果及待处理问题交回 [remotion-production](../remotion-production/SKILL.md) 与主工作流，继续原剪辑任务。独立无声预览不能代替整片声画验收。
