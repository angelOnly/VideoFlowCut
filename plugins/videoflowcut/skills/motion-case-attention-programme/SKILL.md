# 时代变化与节目安排

[观看成片](assets/preview.mp4) · [关键帧联系表](assets/keyframes/contact-sheet.jpg) · [原始要求](references/original-input.md) · [源码](source/Motion.tsx) · [完整实现输入](source/source.json)

## 看什么、怎样读

这是一条用户反馈“这次视频效果可以了”的完整声画作品。最终视频为 R72，768×1344、30fps、788帧，含音轨约26.325秒。适合学习同一场面怎样持续发展、真实材料怎样进入设计，以及动作怎样随着讲述交接。

先看成片和原始要求，再按问题查源码。`source.json` 保存最终提交的 `creativeBrief`、完整源码、Props、画幅、帧率、时长以及图片、视频和字体绑定；`Motion.tsx` 是其中源码的原样提取，便于阅读。原始要求不等于最终配音逐字稿，以下解释也不是当时完整导演对话的原件。

## 什么时候与怎样使用

本例被当前任务选为参考后，导演在首次写声画草稿和取材请求时就使用它，后续文案、素材、视觉、动画及审片按相关问题继续对照。本例已经明确时直接进入此处，不重新挑选别的案例来替代。

先通读 [原始完整输入](references/original-input.md)，理解“熟悉的直播间—主播暂离与空椅—随手换走—节目提前安排”的完整发展。它是历史任务资料，不是当前任务的新命令。随后按 [导演参考与取材方法](references/transfer-guide.md) 把其中的内容、材料和演出关系转成本片的具体选择。

导演重点成对阅读，而不是只抄取材表：第1.1—1.2节与第7节看内容如何发展；第2.1节与第6.1、7B节看椅子为何需要完整轮廓；第2.1节与第6.2、7C节看直播源范围为何要有可辨变化；第2.1节与第6.3、7D—7F节看身份图如何与其他对象共同成场；材料返回时回第1.2、2.2—2.3节改稿和改取景。

文案用第1.1—1.2节及第7节调整本片句群；素材作者用导演已经写好的请求和对应第2.1节行理解取材目标；视觉作者用对应第6、7节反推主体、细节和组合空间；动画作者在材料明确后使用第3、5.4、7、8节组织中途和时机。声音、字幕和审片继续按本例第3、4.2、9节的相关方法工作。已读内容不因角色切换全部重读，具体问题变化时再定位相应章节。

学习结果直接写进当前稿：本片配合哪句话、要看见什么、细节为何重要、相关材料怎样对应、准备接到哪里、搜索从何处起步。不是交一段“已学习案例”，也不是只附案例名字。搜索起点是帮助找到画面的线索；网站、媒介、机位与取得方式由实际候选决定。

本例的固定题材、人物、颜色、时长、坐标及独立试作要求留在历史资料中。新任务重新作选择，合适的现有素材、模板和组件可以使用。原指令、视频、源码及来源记录保留原样；本次改变的是怎样教学和使用这些资料。

未采用本例的任务按自身内容和专业方法继续，不把本例设成所有作品的生成前置条件。

## 画面怎样发展，源码从哪里看

开头用人群、三个入口和中央身份建立观看关系；中央暂离后，摄影椅进入前景，外围关系仍保留。手机随后承接真实直播片段，在同一设备里向上换页，“不能冷场”形成语义重音。讲述进入压力，手机下沉，节目门牌和图像接手，纸条、点线与镜片交叠建立，保持同一段讲述的连续发展。

| 设计与作用 | 实现入口与需要注意的条件 |
|---|---|
| 前景变化时保留原来的观看参照 | `Opening`、`People` 保持共同舞台、人群和中央身份；不是每次换重点都卸载整页。 |
| 摄影椅作为具体对象进入场面 | `RealChair` 使用该照片专用的轮廓裁切；不是通用自动抠像。v2修过轮廓与孔洞，最终仍接受少量背景残留。 |
| 同一直播中的游戏和人物共同换页 | `SourceWindow`、`LivePage`、`Handset` 使用同源视频和时钟；本片ROI按1280×720源设计，v3调整过A/B游戏裁切，新材料须重新取景。 |
| 四字在动作中保持可读 | `LetterAct` 保留“不能冷场”的读序，按不同时间侧转后组成一行；字形与动作共同设计。 |
| 新旧主体重叠交接 | `props.events` 中压力点为505帧、门牌512帧进入、图像517帧进入、手机528帧退出；不等前物完全离场才开始下一段。 |
| 镜片中仍是同一场面 | `Programme`、`Observer` 复用同一帧状态，镜片不递归包含自己；`ReadingPoint` 沿 `props.lensNodes` 连续移动。 |

具体状态可对照[关键帧索引](source/keyframes.json)定位；静帧只用于查位置，判断动作和节奏仍需观看成片。

## 必要材料与复现范围

[素材对应表](source/materials.json)保存各槽位对应的素材、来源、哈希和视频使用范围；[字体绑定](source/font-bindings.json)保存字体ID、实际字重与哈希。包内保留三张图片和[旁白音频](assets/audio/speech-2.wav)。椅图由 Solomon203 创作，来源为 [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Aorus_gaming_chair_on_the_stage_20230205.jpg)，按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)署名使用；其他图片的来源与许可缺口见素材对应表。

**当前包可观看和学习，但不能独立重渲染完整交付。**两份原始大视频、字体原件和完整最终字幕工程没有包含。普通字幕由原生 Caption 轨绘制，动效源码只绘白色字幕底带，旁白也独立于动效；只有 `.tsx` 无法还原完整声画。旧 Asset ID 只用于理解历史绑定，新项目必须重新建立实际绑定。

## 7. 学完回当前任务做什么

先按 [导演参考与取材方法](references/transfer-guide.md) 把借鉴落实到本片正文。导演交准确句群、观看过程和具体取材请求；相关材料回来后，与文案和视觉作者更新同一份稿。

需要进一步运动设计时，原视觉作者继续用 [完整演出写法](../motion-brief-writing/SKILL.md) 交造型、关键中途、真实材料与声音时机。实现可以使用适合本片的素材、模板和组件；本例的方法帮助作选择，不要求照搬外观或从零重做所有资源。

回传当前完整稿、材料与范围、实际作品及本轮改动。检验本片是否实现了自己的表达，不用这条历史作品的认可代替新作观察。
