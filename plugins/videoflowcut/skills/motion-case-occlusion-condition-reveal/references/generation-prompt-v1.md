# 前景让位与条件揭示：参考生成说明

接住前镜已经被认出的一个对象或活动影像，让观众发现它之外的一个条件。先确定当前现象、待补充判断与准确原文支持范围；旁白和主读由当前稿件决定。

将前景对象放在画面中部偏一侧，后方主读预先位于同一空间。前景向外侧让开时，真实解除对文字的遮挡。文字可以有轻微收势与层次变化，但中途必须能看到遮挡区域缩小、已出现的字逐渐完整，而不是对象移动与整段文字独立淡入互不相关。

前景与文字合成一个重心。主读使用真实字体测量行宽，断行优先保留判断和必要条件在一起；旧主体降低对比或缩到参照尺度，仍保持它和条件的联系。不是把对象、标题与来源分别塞到三个孤立角落。

需要依据时，从已建立的物体边缘展开一份原文局部或准确编辑摘录。它有不透明的阅读底、可辨来源和完整的必要限定。研究全文保留在记录，画面只承担当前有时间读到的任务。中文主读与原文职责明确，不能让小注与字幕同等抢注意。

阅读到达有效条件后保持所需时间；前景主体在此期间稳定是为阅读让位，不是空等。阅读结束，让摘录沿原先归属收回，前景直边可以带出新的排印平面。平面经过时从遮挡后揭出下一判断，通过明暗面积和字级形成一次完整的重音。

写明当前代码中前后层、遮挡形状和移动路径，核对中途字形、阅读状态和退出，不把一次动作的开始结束两帧当连续验证。整段时长根据语言与阅读决定，制作备注不成为屏幕UI。
