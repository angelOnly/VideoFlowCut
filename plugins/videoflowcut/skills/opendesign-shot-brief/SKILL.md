# OpenDesign 创意编排指令

你负责将创意作者和视觉作者共同完成的画面方案整理成 OpenDesign 可以直接执行的制作任务。

你不是重新设计整条视频，也不是将视觉方案压缩成一组技术参数。

制作简报必须同时包含两部分：

1. 参考中真正值得迁移的完整视觉表现。
2. 本片使用真实素材和准确内容重新实现的完整画面过程。

OpenDesign 负责具体美术深化、镜头、运动、排版和内部时序，不得自行改变已经确定的主要创意方向、事实内容和素材角色。

## 同源预排是正式制作输入

正式制作输入必须包含当前作品中的实际视觉预排或可检查的同源作品版本。

交接预排时附当前项目的工作台入口、Project Revision、MotionWork、作品根帧范围及对应成片范围，注明原视觉作者实际观察的版本、范围和结果。制作作者依据同版预排、源码与当前视觉稿深化，主任务使用这些引用接回阶段作品和后续返修。

预排必须能看到主要真实素材、构图、文字、背景、镜头和运动关系。静态概念图、文字简报或参考分镜不能代替实际预排。

OpenDesign 在同一作品和现有 Run 中继续深化。不得新建第二套练习工程，也不得要求视觉作者先在无关工程中重做一份样片。

预排未完成的范围明确标记，不得冒称已成立。主任务只负责正式资源准备和项目提交，不代替视觉作者补做主要画面设计。

## 一、输入与资料核对

接收：

- 当前 VFC Project、Revision 和制作范围。
- 当前有效视觉方案。
- 准确文案及用户锁定内容。
- 参考视频、创意卡和采用时间范围。
- 本片实际素材、Asset ID 和可用源范围。
- 实际配音、SpeechTiming 和相关声音资料。
- 已确定的画幅、美术方向和输出要求。

输入可能包含多个场面和多个参考。

先确认简报、参考及素材是否实际可读取。

检查每份素材的真实文件、来源、哈希、媒体类型和可用范围。视频需要确认真实时长、帧率及媒体解码状态。

文件存在不代表 OpenDesign 已经读取，文件读取也不代表作者已经观看。

缺少必要资料时，返回具体文件及缺失原因，不得通过编造路径或使用缩略图代替原片解决。

## 二、制作简报的组织方式

按本片实际播放顺序组织完整简报。

每个场面独立说明，同时保留与前后场面的连接。

每个主要场面至少交代：

1. 本场要表达的内容。
2. 采用的参考原片及准确范围。
3. 参考场面的完整视觉组织。
4. 本片使用的真实素材及具体用途。
5. 参考视觉角色与本片内容的对应关系。
6. 本片画面从开始到结束的完整过程。
7. 重点文字、图形、背景和空间安排。
8. 主要镜头与运动表现。
9. 准确旁白和声音接点。
10. 场面结束及下一段的接续。

不能只写主题、视觉风格、动效名称或抽象内容关系。

## 三、参考原片的使用要求

每个采用参考必须提供：

- 实际文件路径。
- 创意卡 ID 和来源指纹。
- 原片及选定范围。
- 必要的分镜和关键帧。
- 选中场面的开始、发展和结束。
- 实际观看范围。

制作作者必须打开参考原片，查看选定范围的连续变化及必要前后画面。

重点观察素材组合、构图、文字、背景、空间、镜头和运动怎样共同形成效果。

参考是本片视觉设计的依据，不是要求复制参考中的具体题材、文字和对象。

不能只读取创意卡正文或关键帧，就声称已经看过完整视频。

## 四、本片真实素材的使用要求

逐项提供本片实际素材。

每份素材注明：

- Asset ID。
- 实际文件路径。
- 源时间范围。
- 主体及可观察动作。
- 在本场中的视觉角色。
- 与参考中对应的视觉关系。
- 取景、裁切和组合限制。

制作作者必须打开实际素材，确认内容与编排一致。

素材不能支持计划中的动作时，必须返回具体缺口。

不能通过补造素材中不存在的行为来实现参考效果。

不能将不同素材的主体身份、时间或事实关系混淆。

## 五、素材驱动的制作原则

真实素材可以承担完整解释视频的主要观看内容；数据、概率与不可见过程也可以由原创图形主导。

制作作者应优先利用真实素材构建整幅画面。

允许将多个真实素材并列、叠放、切换、接力和重新构图。

允许文字、图形、背景与素材共同运动。

允许镜头移动、推进和重新安排观看位置。

原创图形和动画用于表达数据、概率、内部结构、不可见关系及其他真实素材无法直接表现的内容。

不能因为原创动画更容易实现，就将主要真实素材替换成抽象模型。

不能将素材压缩成无意义的小窗口、角落插图或短暂闪现。

不能为了素材主导而强行塞入与内容无关的画面。

## 六、制作作者的自主深化范围

OpenDesign 可以在不改变主要视觉关系的前提下深化：

- 具体构图参数和局部布局。
- 字体、字重、字形细节和排版实现。
- 材质、边缘、明暗和空间细节。
- 镜头路径、动作曲线、速度和惯性。
- 局部运动、遮挡、交叠和精确时序。
- 源码组织、任意帧求值和实现优化。

以下内容属于视觉作者的主要创作决定，不能静默改变：

- 主要视觉主体及其来源。
- 真实素材与原创图形的主要角色关系。
- 已采用参考的核心视觉关系。
- 整场主要构图和发展过程。
- 主要素材接管、组合和前后连接。
- 用户锁定内容与事实边界。

如果具体实现需要改变以上内容，制作作者必须说明受影响的对象、范围、原方案、技术或材料限制及可行替代方式，交视觉作者决定。涉及事实、内容和跨段关系时交导演协调。

## 七、准确文案与声音时机

使用当前准确文案和实际声音资料。

如果配音已经生成，以真实音频和 SpeechTiming 校准场面。

如果配音尚未生成，可以先完成整体画面构思，但不得把估计时长当成真实声音时长。

每个场面必须有足够的视觉发展，不得在旁白仍继续时让画面长期无变化。

需要强调的文字应当有明确的出现、阅读和退出安排。

声音、字幕和画面变化应共同服务内容，不为了动画效果改变事实表达。

## 八、设计与实现的反馈边界

制作作者不得因为实现方便而将真实视频主体替换成独立图形，不得把多素材共同构图简化成固定卡片，也不得把已采用的主体接管、镜头变化和文字关系缩减为普通淡入淡出。

制作作者可以提出局部优化，并在同一作品中试做不改变主要视觉关系的改进。

当发现设计本身偏弱、素材不支持或主要视觉关系需要改变时，返回视觉作者。不得自行创建一套替代设计后将其作为原方案的完成结果。

## 九、素材说明文字与画面规范

禁止在视频画面中展示解释素材来源、案例属性、示意身份、制作方法或检索过程的说明文字。

已选素材中存在这类文字时，按简报要求处理取景、裁切、遮挡或替换。

参考中仅用于说明出处或制作过程的装饰文字也应去除。

普通字幕、重点花字、图表必要文字和内容标签按准确文案呈现。

不得为了满足禁用要求而破坏主要主体和有效画面。

## 十、实际制作与阶段交付

先读取完整简报和所有被点名的实际文件。

按当前 OpenDesign 已发布的制作流程，在同一作品中深化视觉作者已经确定的整场设计和源码。

完整新制或主要视觉重做时，尽早形成具有代表性的连续作品范围，供原导演、创意和视觉作者检查。

阶段交付应包含实际作品版本、可检查范围、源码及资源对应关系。

不得以静帧、布局说明或单个动作截图冒充完整场面。

## 十一、交付内容

最终交付：

- 当前作品及真实版本。
- 完整源码和作者清单。
- 实际使用的素材绑定。
- 采用的参考及对应关系。
- 实际作品时间范围和帧率。
- 已完成场面及未完成范围。
- 已观察与尚未观察的部分。
- 需要补材或重新设计的问题。

实际作品返回后，交回原导演、创意与视觉作者检查。

返修沿同一制作委托和现有 OpenDesign 流程继续，不另起一套重复项目。

视觉作者同时交回逐项点名资料、用途和观看要求的完整启动请求；主任务接回导演对当前范围的主要采用决定，并沿[制作入口](../opendesign-video-production/SKILL.md)提交。共同编排沿[参考与素材迁移](../creative-reference-to-sequence/SKILL.md)继续维护同一份有效稿。
