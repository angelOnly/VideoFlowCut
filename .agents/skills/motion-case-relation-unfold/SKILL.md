# 保持参照与关系拆层

## 1. 何时使用

解释一个有依据的组成、对比或相对关系，需要先建立共同部分再揭示被忽略的部分。先由导演确定当前内容与主要观看任务，再由同一视觉/动效作者学习本例；不新增代理，不要求用户先提供参考视频。

本例来自用户提交的r92作品。原片分子和分数线先建立，两个遮挡平面向左右退开，分母“干扰功率＋噪声功率”出现；完整关系保持后上下平面收拢，留下金色开口进入D。

样例是一个特定质量指标的概念化表达，不等于手机格数公式或所有网络质量。原片的密集文字与保持时间不自动适合新内容；来源与事实范围必须重新核实。 新教学指令未重新渲染；原片反馈不能替新指令背书。

## 3. 应迁移的设计

读完整教学指令，明确借鉴的观看关系、美术组织和中间过程。回到当前主题重做主体、真实材料、准确文字、配色、声音与节奏；案例历史时间只用于定位视频，不复制到新片默认。

## 5. 返回当前制作任务

学习后输出当前场面的完整执行正文、关键造型/构图、路径与遮挡、可见文字、有效时间、实际绑定和中途检查点。继续完成实现与合成，而不是读完案例就结束。
