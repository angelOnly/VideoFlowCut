# OpenDesign 制作、返修与交回

继续负责同一作品。先执行[场景创作简报](../opendesign-shot-brief/SKILL.md)，
取得表达目的、可见事件和必要边界；局部修订沿用有效稿并更新受影响范围。
主任务负责 VFC 正式登记、提交和放置，OpenDesign Run 属于你的作品制作过程。

## 发送前准备实际可读输入

核对你实际能调用 OpenDesign MCP，沿用本机成功的视频技能与模型配置。
读取本机工具 Schema；skill/skills 只填写 list_skills 返回的 OD 已注册 ID，
不能把 VFC 的镜头 Skill 名称或路径当作 OD 技能参数。

先确认本作品的 OD 项目：新作品先用 create_project 取得 project ID，
返修复用现有项目与源码，再准备并传送以下资料。

视频不使用固定用途、时长或画幅的选择卡。用户明确的要求直接传入；
未指定画幅时由视觉作者依据作品选择，不能写成用户已选择。已生成
旁白时以实际 SpeechTiming 安排完整作品，未生成时先按完整内容构思，
真实时长返回后校准；不设 60 秒上限或将项目默认值当作用户要求。

将创意与视觉共同采用的完整视觉导演方案、时间编排和场景简报放在当前项目可读取的权威文件中，调用时提供文件身份、表达目的、关键锁定项和本次真实差异；作者必须实际读取完整文件及必要材料。缺少主要事件、素材角色或时间编排时返回具体缺口；创意不另开并行项目或 Run。
准确正文、素材、声音、必要参考和运行规范实际放到 OD 可读取位置，
并在 prompt 中点名文件及其用途；私有路径和缺失文件不能当作已交付。
文本可用 write_file，大文件沿现有授权文件交接，保留与 VFC 资产的对应。

逐项交付采用的创意卡、完整片段、原片必要上下文、主分镜与补图，机制正文、视频与分镜，以及本片真实素材；按真实读取结果保留相对目录与链接，不能按编号猜文件或复制整库。共用文件只交付一次，清单保留各用途。记录项目与输入 Revision、参考 ID 和库来源指纹、原路径或 Asset ID、OD 实际路径、文件 SHA-256、MIME、大小、视频时长与帧率、源范围和用途。库指纹不代替实际文件哈希。核验文件读取与视频解码；无法核实时如实记录，不能把路径存在、静帧或写入成功称为 OD 观看了视频。

可访问 VideoFlowCut 源仓库时，按 `docs/development/OpenDesign参考交付准备.md` 使用 `scripts/opendesign-reference-package.mjs` 准备本地资料与核验清单，再通过实际 OpenDesign 文件接口交付；脚本不创建 Run，也不替代实际读取证据。部署环境没有该脚本时沿实时文件交接能力执行相同合同，不假定路径存在。

prompt 点名权威导演指令、时间编排、每份实际交付文件及其用途，区分参考与入片素材，写明必须保持的核心事件、素材角色、顺序和时间范围，以及可自由深化的范围。要求无法读取或无法实现核心设计时返回具体缺口，不静默删减。交付、请求引用、运行记录证明读取、作品保留设计是不同证据；没有读取证据只能报告已交付可读文件。

将本次适用的物件、美术、排印、动作因果、层次、运镜与接续标准短写为质量目标，
实际传入并点名遵守。质量目标说明应达到的效果，不预定唯一拍法。
区分必须保持的准确内容、用户锁定项与可调整的初步构思。
参考提供可选方法，不把旧详细执行稿整体当作质量标准重新发送。
只传当前有效决定和必要依赖，历史稿保留在记录，不让旧题材与旧时间进入当前依据。

读[项目源码规范](references/hyperframes-contract.md)及 read_motion_capabilities，
附本轮已经发布的输出约定。规范尚未发布时，可在 OD 制作观察，但不声称已接回 VFC。
明确交回项目中可读取的完整源码入口及作者清单，不假定默认 artifact 就是 HTML 源文件。已发布冻结能力时由作者明确交件、固定源码与清单，主任务按同一冻结身份接回；能力缺失不得声称已经冻结。

## 调用与续接

调用 start_run 前生成并保存本次 requestId 和完整请求，返回后记录 runId；
请求使用已确认的 project ID、当前正文与实际已注册的视频技能。
保存本次交付清单及输入 Revision；输入或素材变化时重新核对文件身份。回收同一 Run 的源码、资源清单、实际设计变化和未完成项；核心事件、材料角色或主要顺序的变化交创意与视觉负责人确认。
相同调用结果未知时核对原 Run，重试复用同一请求，不重复发起制作。
普通返修复用同项目和当前源码，使用新的 requestId；resume:true 不是普通续修开关。
不添加未发布的 sourceOnly、render:false 或 profile 参数。
按返回状态读取结果；只有解释或计划而无作品文件时继续原任务，不能报告制作完成。

完整新制或主要视觉重做时，首个具有代表性且可连续检查的范围形成后，就由同一 Local Codex 作者在本 Run 内明确完成该范围，使用
`od motion-work stage --source <项目内HTML> --manifest <项目内作者清单>` 发布阶段冻结版，
回传得到的 `frozen_version` 与实际可检查范围，再继续修改工作件。该命令由作者当前 Run
授权，外层不能凭文件变化假装作者交件。以实时能力为准；没有阶段入口时只能等正式 Run
结束后按完整交件冻结，不能宣称边写边看已实现。阶段预览用于尽早发现风格、时序和素材绑定问题，不新建重复 Run，也不设置逐镜审批或等待全部结果的门槛；已有条件的其他工作继续。

核对实际运行采用的 Skill、任务路由、加载规则和产物。
默认由 OD 交源码、VFC 生成正式媒体；通过 OD 正式路由选择 HyperFrames 源码交付，
motion-design 仅提供适用的美术与动效方法，不再额外创建 MP4、播放器或声音。
独立视频任务仍沿其自己的视频交付规则。必须从实际 Run 核对所选路线和交付身份。
HyperFrames 源码交付 profile 不等于已注册 Skill ID；存在配置文件不证明路由激活。
记录实际采用路线和交付结果；仅一句“不渲染”不能证明生效，
不修改 OD 私有工作副本伪装永久配置。明确按本片美术与连续演出制作，
不采用与本任务冲突的固定切镜、统一幻灯片或无关结尾结构。
使用 OD 内部适用的制作指南深化实现；实际是否遵循，以作品和源码为准。
不因等待制作而由外层作者绕过 OD 另写一份替代成品。

## 观察与返修

沿镜头 Skill 的[同一制作与检查方法](../opendesign-shot-brief/references/shot-construction.md)
检查当前真实预览。发现缺设计、漏实现或接入差异时反馈到对应对象和过程，
具体画面或实现问题在同一作品继续修订，保留已成立部分；整体吸引力、期待或情绪回报不足回原创意与视觉重选讲法，核心创意改变共同更新同稿，事实与跨段顺序由导演协调。未观察的动态或声音如实说明。
已有预览优先复用，按问题补充必要观察，不增加固定样片或逐镜审批。

## 交回原项目

一件作品交回固定 HyperFrames HTML/CSS/GSAP 源码，由主任务登记 MotionWork 并正式采用；先在工作台观察同版源码，文件按实际用途由 VFC 生成。
已有 OD 视频只在来源、源码、Props、实际绑定与源区间、字体、画幅、帧率、帧数和输出用途
均有可验证的同版身份时采用；无播放器、重复字幕或声音。登记路径按实时 Schema 核对，
派生媒体必须关联真实 workId、根范围和字节身份，不把普通导入视频宣称为已验证作品缓存。
按已发布规范整理依赖、真实图片/视频/字体对应、作品职责、实际时长与帧率、
同源动作事件及已观察范围。作者清单只保存这些真实决定，不手工复制完整源码；正式提交由平台按固定源码及清单组包并重新核验。必要时适配资源与入口，保留原美术和动作。
透明叠加保留 alpha，完整主画面明确外层哪些内容由它接管。

普通字幕、旁白、原声、音乐和音效继续原流程；预览参考声音不重复烧入正式画面。
由主任务完成正式提交与时间线放置，再把真实合成反馈交回你继续修订。
时序或材料变化时更新受影响的事件与声音，设计变化写回当前稿；
只改普通字幕、声音或制作说明不提交新 motion Job；源码和真正影响作品像素的输入改变才更新相应资产。

局部画面返修保留完整源码与作品根时钟，由原作者明确真实影响范围；
沿[局部校样与正式范围](references/submission-and-recovery.md#同源局部校样与正式范围)登记新 workId，由主任务原子采用既有 Cue 的目标范围，工作台复查；需要文件时另生成局部或完整媒体。
首版保持画幅、作品总时长、作品 fps 和事件时序；缓存命中与校样采用不代替实际审阅。

需要补设计时沿原[整场美术](../visual-treatment-planning/references/art-direction.md)、[演出方法](../motion-brief-writing/references/performance-design.md)与[执行稿](../motion-brief-writing/references/execution-brief-template.md)继续；人物范围按[人物剪辑语法](../presenter-motion-director/references/presenter-editing-grammar.md)处理。素材取景读[空间与源时钟](references/material-space-and-time.md)，正式写入读[提交与恢复](references/submission-and-recovery.md)，责任边界读[共用交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。
