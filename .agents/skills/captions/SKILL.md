# 字幕、语义分卡与屏幕文字

## 字幕、主读与句群分别组织

参照当前共同作品理解正文字幕、画内主读与标签分工，再按本片字款和画幅作设计。字幕卡、自然句群与视觉场面不同粒度，不因换卡重建画面。单行或双行来自本片采用，不照搬旧例；不缩字、挤字或切碎TTS来机械通过。切点依据实际声音精度，改稿后全文与字幕同步。

主读、标签、UI、出处与制作备注按 [场面正文](../_shared/SCENE_DESIGN_HANDOFF.md) 分开。受管字体不自动控制原生 Caption 轨；背景、字级、字族和位置按当前能力核对，maxLines 不是已发布参数。主视觉预排即放入字幕，拆件不能重播或漏句；新版语音同步失效范围。

当前声画协作沿 [主题到成片](../_shared/TOPIC_TO_FILM.md)；参考仅按当前稿已采用的范围使用。

## 执行角色与代理交接

当前授权作者完成专业判断，主任务统一正式提交；输入、完整产物、依赖变化与原作者续接沿 [角色交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。

## 字幕首先是信息层

普通字幕准确呈现实际语言；画内题目、问题、名称、数值、来源与重点排印分别支持定位、思考、指认、比较、证据、强调或情绪。规划阶段就结合完整场面安排主次、位置与先后，正式生成、分卡与精确时间依当前可播放声音及真实对齐，不在初稿阶段精修全部卡片。

文字不共享同一个结束时刻。普通字幕更新当句，题目和问题可以跨句保留，标签随对象保持，来源原文按必要上下文显示；各自完成作用才退出或让位。相同措辞在字幕与画内分别承担作用时可以共存，不能因重复自动删除。稳定字幕和固定外框可以支持复杂画面，不把频繁变样式当作丰富度。

是否全程显示普通字幕由用户目标、交付要求和本片构图决定；需要完整字幕时不能把关键词花字冒称完整转写。安全边距区分平台实际裁切或 UI 遮挡与本镜为阅读、人物或证据安排的空间：前者按交付条件保留，后者随构图选择，各画幅分别复核。不要先为全片永久空出一大块字幕带，也不强制每镜移动。

## Caption Card 是阅读单位

观众不是按标点自动阅读。每张 Card 应是一个能在短时间理解的完整短语，保护主谓、否定与对象、数字与单位、专名、因果和转折。过长 Card 让阅读追不上，过短 Card 造成频繁闪动和机器感。

例如“不是钱不重要，而是我把生活推到了以后”不应拆成“不是钱不重要 / 而是 / 我把生活 / 推到了以后”，因为“而是”单独出现没有意义。可以按视觉和语气拆成“不是钱不重要 / 是我把生活推到了以后”，但必须保持完整对比。

## 换行

换行应保护语义和视觉重心。避免数字与单位、姓与名、否定词与对象、介词与核心名词分开。两行字幕不必字数完全相同，但视觉重量要平衡。中文标点通常不单独留在下一行。

在人物近景中，字幕位置应避开嘴、手和重要道具；UI/证据 Scene 中应避开操作和原文。9:16 和 16:9 需要不同宽度和行数，不是简单缩放。

## 稳定字幕与动态字幕

人物、MG 和 B-roll已经有高动态时，字幕保持稳定短句。Kinetic Caption 只在画面简单、时间精度可靠、文字本身承担主要节奏时使用，而且应限制在少量关键词和重复视觉语法。全程逐字弹跳会与人物口型、手势和视觉对象竞争。

当前只有 `segment_exact` 时，可以按 SpeechSegment 或稳定 Card 显示；不能按字符平均做逐字高亮。句中短语强调优先利用可验证的短语边界，或在实际工具允许的独立 Cue 上通过连续声画复核时机并标明来源；不由字幕专项自行改变采用声音或强拆原声 Card；可修改讲稿需要调整时回导演共同判断，再按新版真实声音重新对齐。

## 强调

强调不是把所有“重要词”变色。它应帮助发现结构：数字、对比、否定、行动、关键词或结论。一次 Card 通常只有一个主要强调；同一风格中颜色、字重、尺寸和运动应有稳定语义。强调按导演采用的信息时机呈现，不把需要后置的笑点、转折和结论提前说完。

### 基础字幕与重点排印的角色分离

分镜阶段交当前准确文案、语音范围与精度，以及普通字幕、问题、标签和来源文字在本场面的作用、空间与保留跨度。动态短语、跨句问题和对象标签用 `remotion-production` 的受管作品；普通字幕沿现有 Caption 链，二者使用同一版内容和真实合成复核。

大字可以成为持续被讨论的对象，也可以承担瞬时重音。选择字级、层级和出现方式要考虑目标画幅、人物、源素材内部动作及其他文字的阅读顺序，不能仅因同义就删去，或让所有层同时争夺互不相关的重点。

已实现的 `edit_captions` 合同可保留原文与真实对齐，单独控制本卡显示范围及静态百分比位置。普通字幕需要给表情、操作或证据让出空间时，据完整场面决定显隐、范围与位置；受管文字仍不会自动让普通字幕避让，也不提供任意重定时或逐词动画。使用前核对当前连接 Runtime 的实时 Schema，按下文“当前工具与能力”提交并读回显示设置；缺少所需字段就反馈能力缺口，不删转写 token、用透明字或遮罩绕过合同。

## 字幕与其它画面的分工

根据本镜主要观看过程选择文字安排：表情、操作或证据需要辨认时，调整位置、字量和出现时机；文字本身承担问题或比较时，可以成为主视觉；环境与真实动作已经有表现力时，不必逐项加标签。普通字幕可稳定，画内文字可按作用变化；减字、隐藏、移位不是按题材自动执行的规则。需要完整字幕的任务保留对应内容要求，需要未发布显示操作就反馈能力缺口。

## 字体、层级和可访问性

字体选择应优先可读、字形完整和渲染稳定。中文缺字、字体回退、过细字重、低对比和复杂背景会在 Render Worker 出错。字幕不是品牌海报，过度装饰会损害速度。主字幕、强调、说话人和补充说明需要有限层级。

## 阅读速度与时长

新增重点排印的动作与阅读先以秒给出大约范围，按 [秒级初始节奏与预览修订](../effect-timing/SKILL.md#秒级初始节奏与预览修订) 在完整声画预览中调整；基础字幕仍依实际语音和已确认卡边界。动画初稿不能改写真实对齐或用户锁定范围；可读性冲突在完整场面内比较画面、文字与可修改讲述，再依采用版本重新对齐。

不能只用字符数公式，但可以作为风险提示。判断观众是否能在自然播放中读完，尤其在复杂画面、陌生专名和数字时。若读不完，优先简化 Card 或减少同步视觉；只有当前字幕合同和真实语音边界允许时才延长对应阅读范围，不用缩小到难读或伪造时间掩盖问题；可修改旁白由导演决定，字幕专项不自行裁声或改写原意。

## 说话人和访谈

多人内容需要真实 Speaker 证据。当前无 Diarization 时，不凭 ASR猜姓名。可以通过画面、用户说明或明确标签建立说话人；不确定时使用中性字幕，不错误归属。

## 标题、注释和字幕

章节标题、证据来源、UI 标签和对白字幕是不同文字角色。不要全部使用同一位置和动画。标题可以在 Scene Entry，来源靠近证据，字幕随声音，注释指向对象。

## 实际画面与阅读验证

字幕没有指定位置时使用默认底部布局，指定 placement 时使用自定义位置；bottomPercent 和 horizontalInsetPercent 只控制字幕自身的距离与宽度，不约束其他内容。预览不绘制固定安全框，平台不输出安全区相交提示。至少检查近景、手持物、最大文字、最长行、竖/横画幅和平台 UI。一个代表性帧通过不代表整片，人物和 Cutaway变化会改变背景与碰撞。

## 验证

质量门禁认可当前完整旁白的有效 Alignment / Program / Card 链，不要求再给每个 SpeechSegment 补一张字幕。若仍报缺失，先查来源是否为当前 SpeechAsset、Program 是否完整、真实时间与双向引用是否有效；静音间隙不需要补卡，结构通过仍须回到实际声画验证。

完整播放检查：文字是否与声音一致；Card 是否有足够阅读时间；换行是否自然；强调是否帮助而不是干扰；近景、产品、证据和 UI 是否被遮；静音时观众能否理解必要内容；有声时普通字幕与画内文字是否各有作用、是否争夺阅读。

## 交接合同

输入是最终可播放语音、Script、Timing、画幅、人物/Scene 和 Style。输出是 Caption Card、布局、强调和精度声明。它会影响 Preview 和 Quality。验证是阅读速度、语义分卡、遮挡、同步和整片疲劳。完成后返回主要工作流。

## 字幕与源声画证据

字幕首先承担信息任务：语言可读、身份、时间地点、步骤、数据、证据或强调。决定文字内容和时机前，要检查最终 Script、真实声音、人物表情、关键动作、UI、证据页面和已有画内文字；声音和画面已经清楚完成任务时，字幕可以保持稳定或省略重复强调。

需要后置的信息不被字幕提前说完；结果先行的分镜按导演采用的顺序呈现。字幕不能通过删掉“我觉得”“在这个条件下”等限定，把主观意见改成事实。分卡和换行保护否定、条件、数字单位、专名、问题/回答和完整短语；没有真实 word_exact 时，不制作伪精确逐词效果。

源素材审阅尤其用于判断字幕与人物、动作和环境声的关系。例如人物在一句话结束后有重要表情反应，字幕可以先稳定退出，让观众看反应；UI 或证据已经包含关键文字时，协调字幕与原文的作用和阅读顺序，避免实际遮挡或无作用的竞争。横竖屏分别检查人物、产品、UI、证据、平台控件与实际字幕位置。字幕位置是排版配置，不划定动效禁入区域。

任何字幕修改若改变语气、对象、事实或上下文，应退回 SemanticUnit/Script；显示层不能用更顺的文案替换原内容。
