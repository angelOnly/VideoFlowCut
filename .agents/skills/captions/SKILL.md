# 字幕、语义分卡与屏幕文字

你负责准确转写、语义分卡、可靠时间对齐和普通字幕的稳定阅读。接收当前实际声音、准确文稿、真实对齐、目标画幅、已有文字与全片字幕规范。局部纠错只处理相关卡；样式确需修订时统一更新全片，新卡继承同一规范，不逐卡另设外观。新字幕按下面的方法确定读法，再按[字幕操作](references/caption-operations.md)生成或修改。专业判断与提交沿[角色交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。

已有可信原SRT时沿[字幕操作](references/caption-operations.md#用户已有-srt)正式导入，不重新识别或虚构词级时间；原毫秒与来源保留。背景按实际行数向上增高，底部固定，无字幕不留底板。

## 先分清文字承担什么

普通字幕准确呈现观众听到的语言，在最终画布中独立于主画面变换显示；画内问题、数值与标签帮助定位、思考、比较或指认，可由主画面作者设计运动。来源网址、获取渠道与研究记录不默认上屏，必要署名或披露按实际要求处理。需要完整字幕时不能用关键词花字冒称转写；用户要摘要或标题时明确它的角色。

规划主视觉时就把实际字幕放进构图，精确分卡依本版可播放声音。字幕卡是阅读单位，讲述句群是声音单位，场面是观看单位；同一对象可跨句，一段自然语音可有多张卡，换卡不重建画面。

文字各按用途持续：字幕承接当句，问题可跨句，标签跟随对象，来源保留必要上下文。同义文字承担不同作用时可以共存，无作用的重复强调才让位。制作备注不自动进入画面。

## 语义分卡与换行

一张卡应能在短时间理解。保护主谓、否定与对象、数字与单位、专名、条件、因果和转折；连接词单独闪现通常无法完成意思，应与它引出的短语一起读。卡过长会追不上，过短会频繁闪动；按实际声音和字幅调整，不按标点机械切分。

换行保护语义，也照顾视觉重量。数字和单位、姓和名、介词和核心名词尽量不拆，中文标点不独占下一行。单行或双行服从本片采用的布局，不为达成单行而切碎 TTS、缩到难读或非等比挤字。

当前只有 segment_exact 或 sentence_exact 时使用可靠边界，不能按字符平均制造逐词高亮。重分屏所需的 token 证据和合法编辑范围在操作参考中核对；缺精度就保留当前可靠分段或请求补充，不猜切点。

## 普通字幕统一呈现，阅读期间稳定

普通字幕准确呈现当前可播放语言，使用全片统一的字体、位置、字形与样式规则，在独立字幕层承担阅读。画内标题、数值和对象标签由主画面作者设计，两者在真实合成中协调。

执行完整新制或主要视觉重做的视觉解说片[全元素动效要求](../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)时，普通字幕采用统一的进入、换卡与退出动效，阅读窗口保持位置、字形和样式稳定。不同字幕卡继承同一规范，动作不挤占必要阅读时间，不依赖未经核实的词级时码。

其他未要求字幕动效的任务沿原固定字幕方式处理。用户明确指定的字幕表现优先，在实际能力范围内执行。

提交前核对[正式字幕能力](references/caption-operations.md)。不能表达已确定动效时，交回具体能力缺口与受影响范围；不得通过复制字幕进主画面、隐藏原字幕、删改正文或虚填字段绕过。

按当前信息顺序呈现，不能用字幕提前说完需要后置的包袱或结论。不能删掉主观语气或限制条件，把意见改成事实。改字会改变语气、对象或事实时回文稿/语义作者，显示层不另写一个意思。

普通字幕沿现有 Caption 链；跨句问题、跟随对象的标签和动态短语由受管作品实现。两者共享同一版内容，在真实合成里协调，受管文字不会自动让普通字幕避让。单卡显隐和静态位置是否可用，读取实时 Schema 与操作参考，不用透明字、删 token 或遮罩绕过。

## 字形、画幅与阅读条件

准确转写、分卡和时序由字幕作者负责；字体、字号、字重、字色、底板、位置、行高、行数及框尺寸规则由[美术设计](../visual-treatment-planning/SKILL.md)首次在本片不同背景上确定，之后全片固定。双行规范明确最多两行与固定底部锚点，底板按实际行数绘制；单行规范按可靠语音边界分卡，不缩字、挤字、删条件或猜时间。接口无法表达某项选择时交回明确能力差异，不把未实现的呈现写成已完成，也不绕回动画作品重画字幕。

用实际文案检查中文缺字、字体回退、笔画、对比、长行及复杂背景；主字幕、说话人和辅助说明保留有限层级。受管字体绑定不会自动控制原生字幕轨，当前字幕可调范围见操作参考。

首次定位考虑嘴、手、道具、操作、原文与平台 UI 裁切；后续重要内容与固定字幕冲突时优先改主画面构图或取景，不逐镜挪字幕。字幕位置不划定其他动效的永久禁入区域。只验证本次要求的画幅；确需横竖多个版本时分别确定并固定该版本的字宽、行数和位置，不能简单缩放。

字符数只能提示风险，最终以自然播放能否读完为准。读不完时先减少同时竞争的信息、改善字幅或按可靠语音边界重新分卡；必要延长必须在当前真实边界及工具合同内。可修改旁白回导演与文案协调，字幕作者不自行裁声或改变锁定时长。

多人内容依据真实说话人证据，不从 ASR 猜姓名。身份可以来自明确画面、用户说明或已有标签，未知时用中性归属。

## 在当前合成里复核并交回

检查改动卡及前后卡：文字与声音是否一致，换行是否自然，阅读是否够，长短句和不同背景是否遵守同一规范，有无意外运动、异常语组间距或重复字幕，人物、产品、UI 和证据是否被挡。代表帧只能回答布局，背景变化和切换还需连续观察；需要时分别静音看阅读、带声看同步，不把打开播放器称为已听审。

交回准确卡文、同一字幕规范引用、时间精度、受影响范围和实际观察。只有当前操作涉及来源链、生成失败或 stale 时才进入[字幕操作](references/caption-operations.md)相应章节，技术来源检查不在创作正文重复。新声音回来后重核对受影响字幕，旧版结论不自动用于新版。
