# 三排封面流 → 选中封面接管 → 内部图形展开

## 1. 适用场景与表达目标

本案例先让观众感到内容集合的丰富与秩序，再从中认出重点《山海之间》。三排封面在共同水平空间内流动，选中项从当时位置接到前景，外框尚在收势时，内部圆与山形继续完成构图。标题随版面展开变得可读，最后留下清楚的一项。

适合内容目录、作品集或系列展示后的单项聚焦。滚动阶段负责集合感，不要求读完所有标题；需要逐条比较或核查具体作品时，应进入相应可读画面，不强迫观众在快速滚动中逐字阅读。

本例八张封面均为原创几何与示意名称，不是真实节目或已授权海报。新片介绍真实作品时，应使用实际封面、正确名称和来源，并保留缩略图与重点项的同一身份。

本案例供 [remotion-production](../remotion-production/SKILL.md) 在构思与设计阶段使用，主工作流提供当前集合、重点项、旁白、画幅及前后画面。

历史视频为 960×540、30 fps、300 帧，与固定源码配套。历史前景封面是另画的对象，从画外接入，不是墙中某张真实沿路径放大；完整指令要求从选中项实际位置接管，逐项匹配内容、位置、尺寸与裁切。因此参考视频用于观察语气和实现，不能覆盖当前指令的身份要求，也不能称为该指令的逐项输出。

先读本页判断集合到重点的观看关系，再完整阅读指令、查看视频，按需读源码。为当前内容另写主体、美术、封面排印、秒级动作、阅读和出口齐全的制作指令，通过既有流程实现与合成。只写“很多封面滚动后放大一张”不足以保留本例的设计深度。

## 3. 具体美术设计，以及为什么这样设计

### 3.1 色块、间隙与共同空间

| 元素 | 本例的具体设计 | 设计作用 |
|---|---|---|
| 背景与边界 | 深墨绿 `#101610`，上下约 3—4 像素黄绿 `#AEFF50` 细线。 | 清楚的背景缝隙与边界建立版面秩序，焦点接管时一起退让。 |
| 缩略图底色 | 土红 `#BE5438`、灰蓝 `#647A9B`、暖黄 `#D8BA68`、灰绿 `#6D8570`。 | 低饱和色块形成丰富但克制的节奏，避免高饱和平均竞争。 |
| 缩略图图文 | 深青黑 `#203331` 主图、暖白 `#FFFBE8` 标题，直角无框。 | 轮廓、排印与色块承担识别，不用重复阴影和发光制造悬浮卡片。 |
| 重点封面 | 浅橄榄 `#B7BC81` 外框，深青 `#263D3C` 圆、灰绿 `#567265` 山形。 | 从集合色彩延续到单项构图，用前后遮挡形成“圆在山后”。 |

本例以 960×540 横幅设计。缩略图为 184×164，横向步长 196、纵向步长 176，保留约 12 像素缝隙；三排顶部约 -2、174、350，边缘自然裁切。中排横坐标相对上下排错开约四分之一张封面，不做竖缝全部对齐的表格。上下排向右、中排向左，共同方向中的变化建立层次。

### 3.2 八张封面应有区别，也像同一套作品

| 名称 | 具体图形与底色 |
|---|---|
| 深空来信 | 土红底、深青圆形星体与偏心细轨道。 |
| 山海之间 | 灰绿到浅橄榄配色、深青圆与前后两层山形；固定为重点项。 |
| 城市切片 | 暖黄底、三块不同高度的建筑切面与一处圆形光源。 |
| 隐秘世界 | 灰蓝底、偏心大圆与较小月牙负形。 |
| 时间之外 | 灰绿底、斜向切面穿过圆盘。 |
| 蓝色星球 | 灰蓝底、较大深色圆与两条有间距的弧线。 |
| 声音档案 | 暖黄底、五条宽窄不同的竖向节奏块与低弧。 |
| 旷野日记 | 土红底、低地平线、错开的斜坡与小圆。 |

每张最多一个主图与两三个辅助形；标题左对齐，距左边约 14、底边约 16 像素，字高约 21—23 像素，使用清楚粗无衬线字体。名称、图形与颜色绑定固定 ID，不随行列或滚动位置变化。长标题按实际字宽排版，不横向压扁。画外对象覆盖本次有限旅程，不能在可见区域突然换图，也不必建立无限图库。

### 3.3 从缩略图展开为完整竖版

《山海之间》最终外框约 364×464，居中，顶部约 y=38；直角外框保持平面编辑设计。主圆最终半径约 102，圆心在封面横向中点、距顶部约 170 像素。左山升向封面宽度 35%、高度 43% 的位置后落向中右，另一山坡从较低处接到右边缘中部；山形遮住圆的一小部分并延至底部。

标题约 46 像素粗暖白字，位于底部中央，距下沿约 40 像素，借山形明暗获得对比。由缩略图到竖版时分别调整标题基线、字号、圆心和山形顶点；外框可改变比例，圆仍是圆，中文字保持正常比例，不能拉伸整个封面图片来完成布局。

独立前景层接管时，首帧与被选缩略图的实际位置、尺寸、裁切、颜色、字体和内部状态一致，同时停止绘制墙中原实例。接管处只看见一张封面，没有双标题、双圆或一帧闪失。背景退让由墙上、前景下的一层独立深色遮罩承担，最后保留约 8%—12% 墙面可见度；不把重点也放入共同淡出组。

## 4. 以秒表达的参考节奏、动作交叠与接续

**下表是首版节奏的参考用时，不是必须填满的时间槽。先据此完成设计和实现，再连续观看成片，按实际动作、阅读与前后衔接调整。**

多数用时针对局部动作，竖向进入与横移、外框与内部图形有意交叠，不能直接相加得到总长。阅读在标题已清楚时开始，不必等全部运动结束再重复追加一整段停留。

| 阶段 | 首版参考用时 | 具体动作与接续 |
|---|---|---|
| 内容墙进入并横移 | 竖向进入约 0.8—1.1 秒；横移以每秒约 65—85 像素为起点。 | 首帧已有一到两排局部可见。墙从下方约 180—230 像素处上移，横移从开场已进行；纵向收稳后继续共同流动。 |
| 集合感建立、准备选中 | 三排形成后稳定流动先按约 1.2—1.8 秒。 | 看到邻接关系与色块节奏便准备聚焦；提前按路径使中排重点项来到中央附近，不能瞬间传送或整墙急停。 |
| 选中项接管、背景退让 | 前景展开约 0.9—1.2 秒；背景可继续运动约 0.25—0.4 秒再收稳。 | 前景从真实坐标接出，继承横移速度趋势，随后向中心收束。前景面积增加时遮罩已退暗背景。 |
| 外框收势接内部构图 | 主圆生长约 0.65—0.9 秒。 | 外框进入最后三分之一时圆从约最终半径 60% 开始生长；山形配合展到终点，标题在外框接近最终尺寸时已可读。 |
| 名称确认与结束 | 全部落稳后先按约 0.65—0.95 秒检查阅读余量。 | 将收势期间已获得的清楚阅读计入，名称与圆山关系确认后结束或接下一画面；不另起慢推镜或副标题。 |

三行速度差可在约 15% 内起步调整，同一行各封面保持共同速度。接管起点从事件当时屏幕坐标确定，外框、图形与文字各有连续路径；检查方向和速度收束，不能在图层切换处归零后重新起步。

设计用秒，代码根据当前 fps 换算实际事件帧，渲染前确定本次总帧数。预览发现集合已成立却还滚动，就提前聚焦；接管突然则校正起点、裁切与速度；名称难读则先修排印和背景对比，再补阅读。调整相关前后动作，不统一倍速，不用循环横移、慢放大或黑场补历史长度。

已有旁白或锁定总长时，保持约束，通过内部编排和后续画面承接；不能自行改短声音或整片。最终以实际成片的表达、可读性和观看节奏验收。

## 5. 换内容时保留什么、重新设计什么

| 设计层面 | 可以保留的方法 | 需要按当前内容重做 |
|---|---|---|
| 观看任务 | 先感知集合，再明确关注其中一项。 | 是否需要逐项比较、重点选择理由与接下来的内容。 |
| 美术与版面 | 色块、稳定间隙、共同方向和字号层级。 | 当前作品的封面、真实名称、配色、画幅、行数及排列密度。 |
| 身份与接管 | 从选中项当前坐标接出，同一时刻只显示一个实例。 | 实际图片、裁切、标题、图形状态与前景素材绑定。 |
| 内部展开 | 外部收势时内部仍推进，图形与文字各自布局。 | 可编辑内容及展开方式；真实海报可保持比例并调整裁切，不随意重画其内容。 |
| 节奏 | 流动接聚焦、外框接内部、已可读时间计入阅读。 | 当前速度、距离、标题长度、阅读与出口，不复制历史 10 秒。 |
| 合成与事实 | 重点清楚，来源可核对，前后画面连续。 | 当前来源权利、旁白、人物、字幕与交付规格。 |

例如介绍课程库，可用真实课程封面建立集合，再让选中的课程从原处接管，继续解释课程内容。需同步修改墙中缩略图与前景，不能名称选 A、接管却显示 B。非可编辑海报不强行拆圆山图形，应依据当前素材另设计内部接续。

历史源码只暴露 mode，名称、颜色、速度、行距与前景标题在内部定义；换素材和比例要重新排版。独立示例的横幅无声输出不是新任务的默认交付要求。人物同屏时按脸部、手势和字幕重新分区，空间不足可全屏接管后返回人物；未验证 Mask 时不承诺在人后穿行。声音按接管等必要重音设计，共同横移不要求持续叠加 whoosh。

## 6. 如何根据实际成片检查和调整

先对照[铺开末段](assets/preview-060.png)、[多排流动](assets/preview-150.png)、[前景接管](assets/preview-210.png)、[内部变化](assets/preview-280.png)理解历史构图，再检查当前事件帧，尤其是接管前后相邻两帧及其连续播放。

| 检查位置 | 应看到的结果 | 不成立时怎样修正 |
|---|---|---|
| 首帧到三排流动 | 开场有内容，边缘持续补位，间隙和字形稳定。 | 调整起始位置、有限旅程的画外对象与行速度，避免空等入场或可见换图。 |
| 墙中选中到前景 | 内容、位置、尺寸、裁切一致，只见一个实例。 | 校正实际屏幕坐标和绘制切换，避免双影、闪失、换封面。 |
| 缩略图到竖版 | 圆形与字形比例正确，山在圆前，标题基线连续。 | 分开外框、图形、文字的布局插值，不能拉伸整幅图来凑外框比例。 |
| 外框收势到内部变化 | 圆的生长已接上，标题可读，背景及时降对比。 | 调整内部启动时机与独立遮罩，去掉“外框停住后再动一次”的等待。 |
| 最后确认与出口 | 只剩一个清楚重点，名称读完后自然结束。 | 补必要阅读，或收掉重复等待、慢推近与循环尾巴。 |

历史曾出现重复定位同一帧得到不同画面：先移除前景旋转、量化平移仍未解决，随后取消封面组与前景组 opacity，改用独立深色矩形退暗后，当时 probe4 和完整 v1 检查通过。证据支持该次实现调整有效，不足以推断所有 GPU 的底层根因，也不能泛化为 SVG 禁止 opacity。历史墙与前景在 163—183 帧交叠，前景与内部圆在 222—236 帧交叠，属于节奏接续；同帧确定性需另行验证。相关方法见[停顿、掉帧和确定性](../motion-case-library/references/timing-continuity.md)。

静帧用于构图与排版，正常速度播放判断路径、速度与阅读；通过重复帧检查不等于审美通过。把作品放回真实剪辑，连同前一句、完整动效、后一句、人物字幕和声音一起检查。需要合成才能判断时先用既有待审草稿取证，再复核；素材、身份、画幅或声音改变会使对应旧审阅失效。

把当前完整指令、素材绑定、作品与放置版本、动作事件、实际审阅结果及待处理问题交回 [remotion-production](../remotion-production/SKILL.md) 与主工作流，继续原剪辑任务。
