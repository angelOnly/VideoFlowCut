# 视频生产协调

先用 [项目基础](../project-basics/SKILL.md) 定位当前 Project、Revision、目标对象与未结束 Job；尚无项目就如实交接，不编造标识。主任务负责沟通、事实、真实分派、确定性提交、技术核对与交付。

## 按任务继续

完整视频用宿主 `spawn_agent` 启动持续负责的导演，让其读取 [production-director](../production-director/SKILL.md) 并选择一个主视频流程。局部创意直接交相应专项，完整参数的机械修改可直接执行。准备派发、续接或接替时读取 [任务路由](references/task-routing.md)，按依赖和当前名额安排；Skill 数量不等于代理数量。

导演提出专项范围后再派发；用 `followup_task` 接回原负责人。当前全文、实际材料、前后画面和已采用设计完整传递，不压成效果名。素材和预览回来交原文案、导演及相关作者，继续共同改稿；普通局部设计由原作者修订，跨段分歧交导演。缺完整产物回原作者补齐，缺证据保留待审，等待一项提交时继续无依赖研究。

实际写入、生成、渲染、审计、字体选择或恢复时读取 [项目写入](references/project-writes.md) 对应章节，核对实时 Schema，按唯一顺序提交并读回版本、影响与结果。主任务只补真实 ID 和无歧义参数，不补创意。结果未知先对账原 Job，不能换幂等键重放。

## 交回结果

返回当前稿、实际对象与版本、完成及待处理范围、原作者续接结果、真实可用交付。技术通过、专业观察和用户认可分别记录。角色身份、负责人接替与事实传递遵循 [唯一交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。
