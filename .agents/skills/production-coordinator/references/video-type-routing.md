# 视频类型路由与链路隔离

最高优先级：新增人物制作能力不得改变已采用的其他类型的默认方法、编辑权限、生产依赖和审片条件。共享技术能力不等于共享所有业务规则。

先综合本次用户要求、完整稿与补充需求、已有项目及明确有效的采用决定，分别判断：整片主叙事路线、当前内容范围路线、制作范围、人物来源、声音来源、正文改写权限及确实锁定的画面内容。类型采用现有 project.profile 的 presenter_motion / visual_explainer / vlog / hybrid，不增加第二个路由系统。

- visual_explainer：沿原视觉解释导演、NarrativeMap、素材／文案并行、整场美术、连续动效、声音和审片路线；不新增人物生成、Mask、口型、可见范围的必选前置。
- presenter_motion：由同一主导演使用[人物入口](../../presenter-motion-director/SKILL.md)。完整人物混合解释与 visual_explainer 共用[完整解释主干](../../_shared/TOPIC_TO_FILM.md)，从首轮组织文案、材料和整场视觉；人物专项提供真实表演源，不预先固定人物面积和视觉中心。数字人与真人只是人物来源分支。
- vlog：沿既有事件、动作和原声主导路线。
- hybrid：仅用于确有不同叙事路线的内容范围；必须说明各范围采用哪条子路线及交接。人物＋素材＋动画不自动等于 hybrid，也不得拿 hybrid 兜底分类失败。

制作范围与正文／原声权限独立：完整解释即使锁稿仍执行完整取材和视觉制作；只有委托本身是原片清理、选段或局部修改才按局部调用。提供全文不自动锁稿，原片也不自动代表只做清理。一个主导演负责采用与跨段取舍，不并行采用两套根导演规则。Vlog 保持事件和原声主线。

如果仅配色、镜头位置、动效强弱等专业细节未知，交导演自主判断；如果是否需要出镜讲述者、人物来源、保留原声或改稿权限会实质改变制作，而现有依据仍无法确定，暂停受影响的正式操作，由协调者只询问用户当前最关键的差异。类型已确定但缺参考图、声音或 Provider 能力是资源缺口，不得静默改片型。等待期间可继续不依赖该选择的研究与取材。

确认后，在同一当前稿和已有项目记录中保存采用依据；新分派、续接、接替和恢复都要携带整片主类型、范围有效路线、人物／声音来源、锁定项、正文权限与有效对象引用。下游不得根据局部素材重新归类；改变任务目标或用户明确要求改片型时才由原导演协调影响范围。

人物专属规则只按人物范围加载；原解释片的完整方法与类型专属操作保持，不增加人物前置。正式人物生成、编译及导出前，核对真实项目类型、当前采用、输入版本和对象合法性；自然语言 Skill 不冒充已实现的程序级硬校验。新人物链和原解释片回归均通过，才算路由改动完成。
