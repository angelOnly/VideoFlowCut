固定目标是完整文稿、成片规格、条件性事实表述，以及四种不同的观看经历：活动窗口重排、影像让位揭字、从整体进入局部并展开关系、SIM微距与离槽收束。

一、要做成怎样的一段片子
观看过程是：
多个真实观察窗口同时展开 → 从多个观察窗口中选出一个近处主体 → 画框让开，露出它没有告诉我们的条件 → 从设备整体进入可辨认的局部 → 把一个质量关系拆开看 → 银灰SIM与大字完成视觉收束。
四个场面分别依靠不同的内部动作成立：
大约时间	主要观看经历	段内动作	主构图
0—4.10秒	由环境的“多”转向一个具体观察对象	活动视窗展开、不同源画面同时播放、视窗重排与近远错位	活动画面展开为多个视窗，再聚焦一个偏右的近景

统一感来自同一套颜色、字体、边缘精度、照明方向与动作语气。不同场面使用不同大小、方向、明暗分布和图形组织。SIM在最后一段承担通信主题的视觉签名，前面的段落由真实对象、文字和信息关系自行成立。

二、自主选材：先解决观看任务，再确定源片规格
1. 搜索、筛选与采用由本次任务完成
先确认当前实际可用的素材搜索、网页访问、下载、媒体读取和素材导入入口。已有本地素材可以列为候选，并核对其真实内容、来源和使用范围。外部检索从主体或动作开始，逐步收窄到构图；例如先找“使用手机”，再观察能否做近景，而不是一次检索同时限定自然光、完整手机、固定机位、手部姿态和长时连续动作。
每个主要角色先尝试两组不同的主题或动作查询，查看少量实际候选片段。优选镜头未命中时，扩大场景、机位或载体范围；一个来源入口不可用时，尝试当前可用的其他合法入口。已有素材足以完成观看任务时就采用，停止围绕更理想的拍摄条件反复搜索。
优先选择适用用途、来源和使用条件能核实的材料。特定文件许可不清时，更换候选或自行绘制明确的概念对象；署名按该文件实际要求保存。没有因本任务获准制作，就自动获得第三方素材使用许可。真实影像的观看内容与概念图形的表达分开登记。

3. 源片长度按真实使用跨度计算
19.46秒是最终作品时长。每条源视频只需覆盖它在成片中的实际连续显示跨度；一场可以由多个实际源段与原创动效共同完成。
先确定每条源片在何时真正可见，再取覆盖该跨度的连续区间和必要的接点余量。视窗的动画时钟与内部视频的源时钟分别记录。照片的清晰度按放大后的实际结果判断，不套视频秒数条件。
例如只有一条约3秒的合适手机源段，可以让它在成片约1.2—4.1秒参与窗口展开和近景；开场先用人群实拍。场面B使用另一段可用的终端镜头，或在前景遮挡时切到同一长源的另一个区间。只有2秒可用的设备近景时，它可以完成场面C前部的现实观察，之后由关系图继续发展，设备视频不必覆盖整个C场。
换源是剪辑，不假装跨素材仍为同一个实际操作。每一段正在展示的真实动作正常推进；合适的停格可以明确作为静帧观察，但静态延长、循环播放和慢放都不登记成新取得的连续实拍。
两处不同裁切可以同时展示同一视频，前提是观众看到的是同一场景的编辑并置，不把复制出来的影像说成独立事件。模型按实际内容决定是否适合采用。
4. 找不到优选素材时，镜头如何继续
手机角色可按“放宽完整轮廓与握姿 → 更换相关使用镜头 → 改为已取得影像与原创手机共同构图”推进。天线角色可按“天线群/基站整体 → 清楚的合法照片 → 已取得的手机局部 → 原创设备结构示意”推进。按当前最早可用、最符合画面质量的方式选择一种，不需要依次生成所有替代版本。
素材变更后，同步改写本任务的镜头对象、源区间、裁切、素材需求和采用绑定。通过已有正常接口，使记录反映实际制作方案。例如C场采用照片加原创关系图后，其设计需求应记录这种实际输入，而不是仍等待一条必需的5秒天线视频。素材要求的适配不是关闭平台校验，事实、使用权限和实际绑定仍按正常流程核验。
A/B/C/D场可以分别推进。个别源段尚在获取时，其他场面的造型、排印、关系图和转场继续制作；取得材料或确定替代后，在同一任务内合成全长。交付时，源片、照片、原创图形及尚未完成项据实记录，完整片不保留未说明的占位。
5. 仅在真实权限或环境阻断处请求最小操作
普通选材不匹配由你选替代，不转为请用户寻找或上传生产素材。网页打不开、某一服务未配置与所有合法来源都不可用是不同情况；按实际错误分别处理。
可改用无需付费或登录的合适来源时先改用。确实必须使用用户账户、额外网络权限、付费额度或修复渲染环境时，说明具体工具错误、已尝试路径及最小所需操作，请求相应授权；已获同范围授权的步骤无需重复询问。并行推进不受影响的部分。平台仍然无法运行或所有可用取材途径确实受权限阻断时，诚实报告状态，不伪造材料或声明已交付。

三、美术与画面组织
颜色与明暗
暗场：背景#08110D，局部受光#192A21；暖白#F3F1E6；银灰#D7DCCF；金色#E7CF8C；主强调薄荷绿#55F59A；干扰强调为克制的琥珀色#C99143。
0—6.8秒以真实影像和暗场为主。约6.8—9.0秒由暖白色的排印平面取得较大面积，制造一次明暗变化。9.22秒由选定设备观察画面中的浅色部位或原创浅色编辑平面承接；关系图使用暖白底上的深色与绿色文字。最后经金色触点微距回到暗场。明暗变化由画面平面进入、实拍裁切和真实遮挡形成，不使用无目的闪屏。
光源来自左上，阴影向右下。实拍优先保留人、手、设备的受光；仅将边缘、字幕背后或已退到后景的部分压暗。图形实体用清楚的轮廓和薄侧边，阴影主要说明接触与离开。
排印
选定本机可用的一款中文粗黑体用于大字，同族正常字重用于字幕及来源，记录实际字体名称。
主读约76—110px，关系图约56—70px，图解补充词26—32px，来源22—24px。大字与主体共享画面重心，进入与退让同时设计。大字完整可读后再承接下一重点。
所有坐标均以768×1344画布为基准，表示投影设计起点；以旋转、字体和真实素材后的可见结果为准。前景主体可以局部出画，必读字和重要接点保持在有效范围内。
SIM造型，仅在结尾展开
本地造型为520×840的修长薄托卡，右上切角约70×65，薄侧边约5—7px。托卡正面是平缓银灰明暗。上半部槽口约220×290，中心约(260,285)，主要由窄切边和接触阴影体现。下半部有少量SIM印刷、小字号副标和条码式装饰作为尺度参照。
小卡约145×200，右上切角，金色触点约115×145，暗金细线分成不同大小的接触区；触点、基体与侧边保持同一透视。小卡离开后保留实际空槽。法线位移、平面内位移和相对转动分开控制，投影随分离距离变化。此物体是通信主题的编辑性视觉载体，抬起动作不表示信号读数改变。
四、完整分镜与连续动作
四场边界约为0、4.10、9.22、14.90、19.458秒；内部动作按字幕与可用片段适配。为每场选择一个可行的实际载体后再落实源片入点，不把纸面构想当作尚未找到的素材已经存在。
场面A｜0—4.10秒：真实影像展开，再聚焦一个主体
0—0.55秒：从实际发生的动作开场。
选定手机使用或人群视频，占据主观看区域约x=0—768、y=100—1150。以该片段真正的视觉主角决定裁切：有清楚的手与设备就从使用动作开始；手机片段较短或暂不适用，就先从人群方向和运动开始，随后引入终端近景。画内保留小号“情境画面”。
