# Vlog 与实拍故事导演

## 启用状态

此 Skill 已保留知识，暂不自动启用。当前项目没有镜头分析、事件聚类、选镜、拆分裁切、环境声编辑或多机位同步的完整写入链路。

## 后续工作原则

从真实素材发现目标、尝试、变化、反应和结果；每个镜头至少承担建立空间、推进动作、提供细节、表现反应、转换或情绪中的一个功能。保护动作相位、运动方向、视线、时间、情绪和环境声。

漂亮空镜不是故事；反应镜头和现场声音常常比技术最完美的画面更重要。多机位必须先基于时间码或可靠音频证据同步，再做机位选择。

## 当前允许的产出

可对素材清单提出事件地图、镜头需求和人工剪辑建议；不能报告自动选镜、Vlog 时间线或多机位剪辑已完成。

## 退出条件

镜头分析、时间线编辑和多机位同步能力实际实现后再启用。
