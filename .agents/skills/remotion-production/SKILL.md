# 受管 Remotion 实现与修订

接收当前完整采用稿、实际素材、准确文字和声音、已有源码、目标 Scene 与前后接口。作者负责具体实现与修订，主任务负责正式项目写入、生成和渲染提交。

## 按修改范围进入

新建或实质重构时，先读完整连续稿、实际素材、美术和已适配的机制协作。缺设计由原作者沿[视觉美术](../visual-treatment-planning/SKILL.md)和[演出设计](../motion-brief-writing/SKILL.md)完成，不把编号当源码。美术、文字、材料与动作在同一当前稿中共同决定；可运行粗排检验该设计，不用固定页面替代设计再补效果。参考允许局部采用，其余发展由本片补齐；确需改方案同步改稿，不无说明删动作。连续范围适合一件受管作品时直接实现；必须拆件时，共用同一场面状态函数，按“段落时间＝输出块偏移＋块内时间”计算各块，分别换算真实素材源时间，不让后块重建空场。偏移用现有实现变量或已支持 Props，不发明 MCP 字段。不要按每段旁白或每个机制生成一个独立成品。只改既定文字、颜色、位置或切口时处理当前源码与受影响范围，不重启主线和全库检索。

写图片、真实视频、字体、Props 或命名事件前，读取 [受管组件合同](references/remotion-component-contract.md) 对应章节并核对实时 `read_motion_capabilities`。素材必须通过真实绑定，字体使用登记身份；不凭历史版本说明推断当前会话能力。

裁切、局部观察、附着标注或跨段视频接续，读取 [素材坐标与时间](references/material-space-and-time.md)，使用完整 cover/contain/fill、点映射和源时钟公式。修漂移或重播直接进入这里，不重新搜全库或重写故事。辅助数学函数在 [scripts/material-math.mjs](scripts/material-math.mjs)，不能假定受管 TSX 可导入本地模块。

提交、查询、Review、Cue 放置或异常时，主任务读取 [提交与恢复](references/submission-and-recovery.md)，固定当前输入和版本，获取真实 Job 与输出再读回影响。已结束失败、结果未知和无副作用参数拒绝分开处理，不重放不确定写入。

按本场已可见的设计落实字体、材料、颜色用途、构图、画内文字与连续变化，未锁定的构图可由原作者随演出完善。普通字幕沿正式 Caption 内容与统一样式在最终画布独立叠加；主画面作品不另写 Captions、不从 Props 复制整句普通字幕或重画其底板，不将字幕放入主画面相机、缩放、旋转、平移或裁切层。标题、数值、对象标签仍可动画化。预览与导出使用同一字幕解释，合成时核对普通字幕没有重复渲染。

公共代码共享数学、字体和确有用途的对象样式，不自动添加栏目名、页码、统一背景和固定标题位置；内部对象名、获取渠道与制作方法不自动生成可见标签。预览与设计不一致先查具体默认值或实现遗漏；设计忠实实现仍不好看，回原美术重做对应选择，不用更多运动掩盖美术问题。

## 验证与返回

对照当前采用稿：设计明确但进入、惯性、退出或图层遗漏，修源码与时序；忠实实现仍不好看回原视觉改设计；讲述或声画顺序有问题回文案与导演，画面选择不足回素材。修改实际绑定、正文和时长后按正式版本读回影响，再更新相关声音、字幕、事件与前后位置，不直接替换缓存。普通背景更换不自动重配无关声音。

关键状态必须来自当前源码、素材和字体；动态与声音检查实际连续范围。构图与字形问题回美术，关键中途与注意交接回演出，漂移、重播、范围和绑定错误回实现。保留成立的选择，不因局部问题重新加载全部资料。

返回完整 TSX、Props、绑定、命名事件、放置参数、对应版本、失效范围和实际观察。记录真实未看未听部分；按 [角色交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md) 续接原负责人直至交付。
