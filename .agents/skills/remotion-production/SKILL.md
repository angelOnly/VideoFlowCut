# 受管 Remotion 实现与修订

本页是同一视觉作者使用的实现方法。接收当前视觉选择、实际素材、准确文字和声音、已有源码、目标 Scene 与前后接口；从可运行粗排持续修订同一作品至最终输出，不等待全部美术静态完稿。主任务负责正式项目写入、生成和渲染提交。

实现当前主体、背景、材料、画内文字与接点的关系，再用实际画面判断选择。主要设计尚缺时，由原视觉作者沿[视觉入口](../visual-treatment-planning/SKILL.md)和[演出方法](../motion-brief-writing/SKILL.md)继续，不能为了得到可提交作品临时补成固定素材窗和普通标签。技术条件迫使改方案时说明具体表达损失，由同一负责人调整当前选择；不默默删去难实现的关系。

## 按修改范围进入

新建或实质重构时，在当前源码中先实现能检验主要选择的连续范围，使用真实素材、准确文字与实际字体，再随正式渲染结果扩大或修订。同版实际画面与源码一同交回；文字稿、机制编号和语法通过不是设计完成。短片可以直接形成完整粗排，长片先处理主要困难所在的范围，临时细节如实保留，不另建一条脱离正式实现的样片链。

场景首次呈现、元素可见时刻和段间接点按当前设计显式实现；不能由组件挂载或配音分段默认所有内容同时出现、同时消失。直接切镜、静态排印和复杂演出都可成立，代码只兑现实际选择。冲突先核对状态、归属和接管关系，不以全退全进作为通用修复。主体变化时，相关材料、背景和文字按同一空间关系求值。

连续范围适合一件受管作品时直接实现；必须拆件时，共用同一场面状态函数，按“段落时间＝输出块偏移＋块内时间”计算各块，分别换算真实素材源时间，不让后块重建空场。偏移用现有实现变量或已支持 Props，不发明 MCP 字段。不要按每段旁白或每个机制生成一个独立成品。只改既定文字、颜色、位置或切口时处理当前源码与受影响范围，不重启主线和全库检索。

写图片、真实视频、字体、Props 或命名事件前，读取 [受管组件合同](references/remotion-component-contract.md) 对应章节并核对实时 `read_motion_capabilities`。素材必须通过真实绑定，字体使用登记身份；不凭历史版本说明推断当前会话能力。

裁切、局部观察、附着标注或跨段视频接续，读取 [素材坐标与时间](references/material-space-and-time.md)，使用完整 cover/contain/fill、点映射和源时钟公式。修漂移或重播直接进入这里，不重新搜全库或重写故事。辅助数学函数在 [scripts/material-math.mjs](scripts/material-math.mjs)，不能假定受管 TSX 可导入本地模块。

提交、查询、Review、Cue 放置或异常时，主任务读取 [提交与恢复](references/submission-and-recovery.md)，固定当前输入和版本，获取真实 Job 与输出再读回影响。已结束失败、结果未知和无副作用参数拒绝分开处理，不重放不确定写入。

按本场已可见的设计落实字体、材料、颜色用途、构图、画内文字与连续变化，未锁定的构图可由原作者随演出完善。普通字幕沿正式 Caption 内容与统一样式在最终画布独立叠加；主画面作品不另写 Captions、不从 Props 复制整句普通字幕或重画其底板，不将字幕放入主画面相机、缩放、旋转、平移或裁切层。标题、数值、对象标签仍可动画化。预览与导出使用同一字幕解释，合成时核对普通字幕没有重复渲染。

采用花字时，字形、承托、轮廓与影子归属同一对象，共同进入退出，组内可以错开；它与相关文字和辅助层按当前稿重排，不为满足组件形式而新增花字。素材时钟与窗口动作分开，普通字幕不进花字父层。允许作品内复用绘字函数，不要求新增平台 FlowerText；函数名、描边属性与组件数量不是作品验收。

公共代码共享数学、字体和确有用途的绘制方法，不顺带复用每场的背景、位置、规模及入退时刻，不自动添加栏目名、页码和固定标题。内部对象名、获取渠道与制作方法不自动生成可见标签。

## 验证与返回

每次主要预排或返修回传前，原视觉作者先看同版实际整幅画面与相关接点，再对照当前稿：观众实际先看谁，背景与主体是什么关系，变化是否确实带来下一关注。没有碰撞、元素齐全或文件可提交不能替代这轮判断；忠实实现仍不成立就重选受影响的视觉关系。设计明确但进入、惯性、退出或图层遗漏，才修对应源码与时序；讲述或声画顺序有问题回文案与导演，画面选择不足回素材。

修改实际绑定、正文和时长后按正式版本读回影响，再更新相关声音、字幕、事件与前后位置，不直接替换缓存。普通背景更换不自动重配无关声音。

关键状态必须来自当前源码、素材和字体；动态与声音检查实际连续范围。构图与字形、关键中途与注意交接由同一视觉作者分别使用美术、演出方法处理，漂移、重播、范围和绑定错误沿本方法修复。缺连续感知时保留对应未知，已能从实际帧确认的主次和布局问题仍须修订。保留成立的选择，不因局部问题重新加载全部资料。

返回同版实际预排或预览、完整 TSX、Props、绑定、命名事件、放置参数及失效范围，简述本次实际改变的画面关系和仍未看未听的部分。按 [角色交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md) 续接原负责人直至交付；参数齐全只表示可以提交，不表示视觉设计已完成。
