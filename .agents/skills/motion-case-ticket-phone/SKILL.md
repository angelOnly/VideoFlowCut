# 机票价格 → 手机条款 → 日期聚焦

## 1. 适用场景与表达目标

本案例让观众依次完成三件事：看到价格，理解订单限制，回到原票核对日期。票面始终存在，手机暂时接过注意力，最后把视线交回原票。连续感来自同一空间中的对象关系和动作接续。

适用于票据、订单、套餐等“吸引点—限制条件—凭证核对”的解释段落。只需要强调一个数字时，可以使用更简单的表达；需要展示真实条款证据时，使用实际页面和文字，按当前证据重新设计。

本例采用演示内容：纽约到北京，总价 ¥6409，日期为 2026 年 10 月 1 日，限制为“不支持退票，不支持改期”。末位 9 只做一次短暂下探后归位，总价保持完整；这个动作引导注意，不表达降价或退款。

本案例供现有 [remotion-production](../remotion-production/SKILL.md) 在构思与设计时使用。主工作流提供当前内容、真实旁白、素材、画幅及前后画面，本案例帮助完成段内设计。

## 3. 具体美术设计，以及为什么这样设计

### 3.1 颜色与注意顺序

| 元素 | 本例的具体设计 | 设计作用 |
|---|---|---|
| 背景 | 右上附近为深松绿 `#123328`，向四周过渡到近黑绿 `#060B08`；亮区宽而柔和。 | 托出浅色票面与设备轮廓，让空间有层次；背景不承担新的注意重点。 |
| 纸票 | 乳白纸面 `#F6F8EF`，右侧约四分之一为蓝紫票根 `#2616BD`，用点状撕口分隔。 | 扁长外形、票根与印刷细节共同建立机票身份，避免变成普通文字卡片。 |
| 价格 | 薄荷绿 `#17FFAE`，极粗、宽度稳定的数字；价格与纸票拥有各自的缩放关系。 | 先让观众记住标价，再通过对比度退让把注意交给手机。 |
| 手机限制 | 黄色 `#F4D448` 的短句，配合从左向右展开的暗金透明底条。 | 黄色只在限制条件阶段成为重点，形成清楚的注意转移。 |
| 日期 | 在原票的日期下展开薄荷绿强调底条，日期文字保持原样。 | 呼应开场色彩，并把结论落回一直在场的凭证。 |

颜色的职责从头到尾保持一致。界面正文使用清晰的无衬线字体，数字、中文与英文统一基线、粗细层级和间距。背景不额外加入粒子、波纹或无关装饰。

### 3.2 票面、价格与初始构图

以下尺寸是本例接近方形画幅的设计依据；迁移到其他画幅时重新构图，不直接拉伸。

票面内部比例约为 540∶218，圆角适中，落位时宽度约为画幅的 76%，中心约在画面宽度的 50%、高度的 55%，逆时针倾斜约 8 度。纸面投影较弱，并随整张票统一移动、旋转和缩放。

保留蓝紫色 BOARDING PASS 标题条、左右航点、点状航线与简化飞机符号。日期位于航点下方偏左，底部用小字段建立票据层级；票根有少量白色字段。装饰细节帮助认出物体，日期等重点才承担阅读任务。

大价格位于票面上方，宽度约为画幅的 80%。票面上缘可以与数字略微遮挡，但不能影响辨认。价格下方的小字“演示总价 ¥6409”在数字动作期间持续可读。

画面先形成“大价格与横向纸票”的整体关系，手机随后以竖向轮廓进入，带来方向和尺度的变化。无需清空背景或另起一张页面来说明进入下一阶段。

### 3.3 同一部手机与可读界面

手机初始内部比例约为 245∶456，窄边、圆角约为机身宽度的 11%，带淡灰绿色细边和轻微侧厚。背面为灰白壳，保留三个镜头圆环；正面为近黑绿屏幕。

正面按“航线—舱位—价格—限制”排出层级。限制行使用短句，其他内容降低对比，不在小屏幕里堆满需要逐字阅读的正文。推近后让限制行进入视觉中心，而不是只把某一行复制成漂浮字幕。

正反面共用同一外轮廓、中心和设备坐标。翻面最窄处仍保留约 3%—5% 的宽度，并在侧面交接正反内容。保持文字方向正确，避免两套界面同时可见、镜像字或中心跳动。

手机成为重点后，价格降低亮度，原票保留可辨认的边缘。手机退出后，仍由这张票的日期接过重点。

## 4. 以秒表达的参考节奏、动作交叠与接续

**下表是首版节奏的参考用时，不是必须填满的时间槽。先据此完成设计和实现，再连续观看成片，按实际动作、阅读与前后衔接调整。**

表中用时大多针对单个动作，相邻动作有意交叠，不能直接相加得到总长。新内容的文字、距离、构图或旁白改变后，应重新安排相关动作及后续接点。

| 阶段 | 首版参考用时 | 具体动作与接续 |
|---|---|---|
| 票面进入、价格建立 | 票面约 0.8—1.0 秒；价格约 0.5 秒；完整构图认读约 0.6—0.9 秒。 | 票面从略低的位置上移并收住倾角。入场进行约三分之一时价格已开始显现、轻微上移；票与价格接成一个开场，认读完成后进入下一动作。 |
| 数字下探并归位 | 下探约 0.18 秒，归位约 0.25 秒。 | 末位 9 下移自身高度约三分之一并轻微倾斜，然后回到原基线；只做一次。小总价保持可读，9 开始归位时手机已经进入。 |
| 手机边进入边翻面 | 入场约 0.75—0.9 秒；翻面约 0.6—0.7 秒。 | 手机背面从下方偏右进入，前半加速、后半收势。入场进行约六成时开始翻面，不先落稳再翻转。 |
| 翻面接上推近 | 推近约 0.8—1.0 秒。 | 翻面进入最后三分之一时，同一部手机开始放大并向左上轻移，把限制行送向画面中心；后面的票面部分仍可辨认。 |
| 条款高亮与阅读 | 高亮约 0.25—0.35 秒；可读后先按约 1.0—1.4 秒安排阅读。 | 推近进行约七成时，高亮沿限制行展开。手机和高亮稳定、文字清楚后才开始计算有效阅读，读完便后撤。 |
| 手机后撤、原票靠近 | 手机后撤约 0.65—0.8 秒；后撤开始约 0.1—0.2 秒，原票便开始靠近。 | 手机向右下缩退，原票同步向左上重构图。票面的靠近速度按当前距离和尺度设计，保持两者交接，不能等手机彻底离场再启动原票。 |
| 日期高亮与结束 | 高亮约 0.3 秒；日期高亮完整且构图稳定后，先按约 0.8—1.1 秒安排阅读。 | 票面减速收势时高亮已开始展开。日期读清、手机离场并完成出口衔接后结束；实际需要更短或更长时，调整对应部分。 |

原票靠近时，整个票面约放大到原来的 1.55—1.65 倍，倾角由约 -8 度收至约 -5 度。日期、航点和部分票根保持可见，观众能够认出是同一张票。日期高亮改变强调状态，不改变日期文字。

手机的平移、翻面和缩放共享同一个设备中心与连续变换；票面、票根、文字、日期和投影随同一票面变换。相邻动作接续时检查位置、尺度、方向和速度，避免各段插值重新起步造成跳动。

设计说明以秒表达；代码根据当前帧率落实为具体帧和事件，画面与声音使用同一份实际时序。渲染前需要确定本次总长度，预览后仍可重排并生成修订版本。

**按成片修正节奏：**

- 前一动作已交代清楚而下一动作迟迟未开始，提前接入或缩短中间空白。
- 文字还读不清，先检查字号、排版和运动是否妨碍阅读，再调整对应停留。
- 所有信息已表达完整，结束或进入下一画面，不补无意义的慢缩放、漂浮或静帧。
- 修正某个接点时调整相关前后动作，不把所有阶段统一变速，也不为追赶原计划时刻突然加速。

已有旁白或锁定总长时，在这些约束内重新安排覆盖、交叠和后续画面。不能依据案例的自然长度擅自改短主声音。最终以实际成片的表达、可读性和观看节奏验收。

## 5. 换内容时保留什么、重新设计什么

| 设计层面 | 可以保留的方法 | 需要按当前内容重做 |
|---|---|---|
| 观看顺序 | 先建立吸引点，再发现条件，最后回到可核对的凭证。 | 当前真正需要解释的条件与结论；内容不具备这一关系时换用合适构思。 |
| 主体与空间 | 主凭证持续存在，另一对象暂时接管注意，最后返回。 | 凭证轮廓、设备或页面形式、内容密度，以及实际素材的使用方式。 |
| 美术 | 颜色承担不同职责，横竖轮廓形成对比，重点依次转移。 | 适合当前主题的色彩、字体、材质、尺寸和留白，不要求所有题材都用绿底紫票。 |
| 动作 | 入场与翻面交叠，翻面接推近，退出与返回交叠。 | 运动距离、方向、速度和阅读用时；没有意义的数字动作可以省去。 |
| 事实 | 同一对象承载相同事实，强调改变不伪装成数据变化。 | 真实名称、金额、日期、限制及来源。 |
| 合成 | 重点清晰，前后画面有接续，声音跟随实际表达。 | 当前人物区域、字幕占用、画幅、主声音和动效覆盖范围。 |

例如改为演出票，可以保留“海报或票面吸引注意—订单页查看场次条件—回到票面核对开演时间”的关系。重做票面风格、真实演出信息和页面布局，不沿用航点、退改条款，也不必保留末位数字下探。仍要给出完整的造型、构图、秒级动作与阅读安排。

数字人口播中，先依据真实人物和字幕空间决定同屏展示还是全屏接管；空间不足时重新安排段落，不把整幅复杂界面缩到脸旁。全屏解说中，可以让票面与手机承担主要画面，但进出仍要接上前后的讲解。

完整指令中的画幅与无声输出属于该独立示例。新作品服从当前任务规格；先规划主要动作的配声意图，再根据实际事件对齐声音。手机推近、翻面和日期强调各有作用，不在每次运动上机械叠加同一种音效。

## 6. 如何根据实际成片检查和调整

先检查价格建立、条款阅读、日期聚焦三个关键构图：每个阶段是否只有一个清楚的第一重点，文字是否可读，票面或设备是否保持可识别的比例与细节。

再以正常速度连续观看以下接点：

| 检查位置 | 应看到的结果 | 不成立时怎样修正 |
|---|---|---|
| 数字归位到手机进入 | 9 回到基线，完整总价没有改变；手机接过视线。 | 修正数字终点、总价层级和手机启动时机；不能留下 ¥640 的误读。 |
| 手机进入、翻面、推近 | 同一设备连续移动，前后面在侧面交接，靠近顺势发生。 | 校正共同中心、尺度和交叠；去掉多余停顿或重复起步。 |
| 推近到条款阅读 | 限制行成为唯一重点，稳定后有足够阅读时间。 | 调整屏幕尺度、文字排版、高亮和阅读安排，不能靠缩小字硬塞。 |
| 手机退出到票面日期 | 原票在手机退让时已经靠近，日期始终属于原票。 | 修正票面变换及回接时机，避免重新生成一张日期卡或突然切画面。 |
| 最后收势与下一画面 | 日期能够读清，结论得到确认，随后自然结束或交接。 | 删除无用途的尾巴；必要阅读不足则补对应时间，不统一裁短所有停留。 |

静帧用于检查构图与排版，连续播放用于检查速度、交接和节奏。出现问题时区分：是设计本身缺乏主次，还是代码没有实现设计，或是放回剪辑后被人物、字幕和声音干扰；针对原因修正。

通过现有生产流程把作品放入真实剪辑，连同前一句、完整动效和后一句一起检查。需要合成才能判断的部分，先使用既有待审草稿取得证据，再完成复核。独立预览成立不代替整片声画检查。

最后把当前完整制作指令、作品与放置版本、动作事件、实际审阅结果和需要主工作流处理的问题交回 [remotion-production](../remotion-production/SKILL.md) 及当前主工作流，继续原有剪辑任务。
