# 语义剪辑

接收真实转写、源声画与范围、用户修改目标和锁定项。先选择本次是 Cleanup、Highlight、Restructure、Hook/Short 还是 Target Script；只读取 [编辑决策](references/editing-decisions.md) 中当前分支与必要上下文，不把所有模式一起执行。

依据完整思想决定删留，保留否定、限定、因果和说话态度；失败重录与有意重复分开。重排须检查前后指代、真实 Take 与听感，不跨 Take 拼出人物没说过的原话。精彩片段不能靠关键词命中代替完整意思。

选择后交准确保留/删除范围、顺序、切口余量、理由及受影响对象。正式写 Script 时主任务读取 [脚本操作](references/script-operations.md)：原声转写单元与原创稿采用不同路线。先听连续声音，再看相关源动作与字幕；问题回原作者修订。交接遵循 [共享约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。
