# 注意力预算

## 主事件

每个 Beat 指定一个主事件：

- 人物表情；
- 字幕关键词；
- 数字；
- 产品；
- 图表；
- 镜头运动；
- 音效；
- 证据高亮。

其他元素保持辅助或稳定。

## 冲突组合

谨慎同时使用：

- 逐词字幕 + 大数字计数；
- 人物强手势 + 前景产品；
- 文档高亮 + 快速镜头；
- B-roll + 大段 MG；
- 音乐强拍 + 重要对白 + SFX。

## 安静区

安静不是缺少设计，而是：

- 给观众理解；
- 建立人物关系；
- 恢复注意力；
- 突出下一高潮；
- 保留真实情绪。

## 密度审查

静音看整片，标出视觉变化。若每一秒都在变化，通常没有层级；若长时间没有语义或画面变化，可能单调。
