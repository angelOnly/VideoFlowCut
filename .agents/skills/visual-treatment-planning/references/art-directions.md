# 美术方向：从气质到配色、布局与风格

理性、简洁、克制改变造型性格与强调力度，不降低整幅画面与观看过程的设计完成度。完成标准沿[默认设计](art-direction.md#默认设计与整场发展)：花字、强排印与丰富运动按本场作用采用，不逐段必交，也不把减字、减动当作通用美术方法。

无偏好时也主动设计主体、背景、布局、排印、材质和演出，在当前作品同源预排中一起判断。下面的方向帮助形成选择，不替代具体构思，也不将拼贴或极简设为唯一默认。

以下方向用于理解气质怎样影响对比、布局、字形和材质，不提供默认色板。方向可以组合，也可以由实际材料形成其他外观；采用与否以当前作品的整幅画面和连续过程为依据。方向名称不自动决定素材、运镜、动效力度或配乐。

<a id="art-light-humor"></a>
#### 轻松有梗：机灵、明快、有编辑感

**配色思路：** 用明快的对比和有选择的局部变化形成机灵感，让醒目的颜色承担明确作用，其他颜色通过面积、明暗与归属维持整体秩序。

**布局与排印：** 可尝试不对称排版、大小反差、局部出格但整体有秩序的编排。正文阅读区保持清楚，少量手写或非规则字形增加机灵感，不把所有文字变成同一种夸张标题。

**造型与材质：** 现代编辑海报、拼贴、手绘批注或略不规则边缘都可作为候选。趣味来自视觉性格与对比，不依赖表情包和装饰堆叠。

**适用与调整：** 适合希望亲近、活泼但仍清楚的内容。严肃主题可以降低外观的嬉闹感而保留利落感；失控杂乱时先恢复层级，不通过统一缩小全部内容解决。

<a id="art-warm-company"></a>
#### 温暖陪伴：亲近、舒展、成熟

**配色思路：** 用冷暖呼应、相邻表面的协调和清楚的文字边缘形成亲近感；重点仍具有充分面积和有力对比，使舒适观看与明确表达同时成立。

**布局与排印：** 区块间有适当呼吸，边界关系清楚；字形可舒展、柔和但有骨力。可以使用稳定对齐和较自然的非对称布局，留白服务舒适观看，不把主要画面缩成小装饰。

**造型与材质：** 生活编辑、自然质感、适量纸感或柔和表面都可尝试，也可以完全平整现代。成熟、克制装饰不等于压低清晰度或内容面积。

**适用与调整：** 适合希望降低距离感、陪伴理解的内容。需要强调时可以有强对比和大面积主读，不因温暖就一味变淡；过度柔焦、滤镜或空白使画面发虚时，恢复清楚的轮廓与主次。

<a id="art-curiosity"></a>
#### 悬念探索：层次分明、线索清楚、有发现感

**配色思路：** 用明暗和颜色关系区分环境、线索与结果，让当前线索取得注意，同时保留理解其来源和前后关系所需的视觉参照。

**布局与排印：** 阅读顺序明确，重点与辅助信息之间有可辨差别。可采用调查编辑、研究笔记或清楚的版面分区；字形和小标记有秩序，不让装饰符号成为另一套难懂编码。

**造型与材质：** 精细线条、层叠纸面、干净的几何边界或现代信息编辑风均可作为候选。神秘道具、聚光灯或放大镜不是该方向的必要外观。

**适用与调整：** 适合需要观察、比较、发现的内容。外观神秘但难读时，先恢复文字与背景的明暗分离；版面变成等权资料墙时，重新组织主次。

<a id="art-clear-punchy"></a>
#### 理性爽快：清晰、利落、有分量

**配色思路：** 用明确的明暗块、颜色职责和面积差异形成利落结构，让判断、对照与结果容易辨认；单色或多色都围绕清楚的信息关系组织。

**布局与排印：** 对齐有秩序，字级和面积差异果断，重要信息有足够存在感。可参考现代信息海报和编辑设计；无衬线、衬线或混合排印都要看实际中文字形，不固定一种字体家族。

**造型与材质：** 干净的几何、清楚边界、少而有作用的材质层次。可以大胆、厚重，也可以轻巧、精细，取决于整体视觉判断，不等于白纸黑字或取消装饰。

**适用与调整：** 适合重视解释、比较和清晰判断的内容。压得太密会损害爽快，应删弱信息、放开间距；太空则增加有意义的面积和构成，而不是持续复制标题页。

<a id="art-playful-objects"></a>
#### 奇趣卡通：轮廓鲜明、比例有性格、容易辨认

**配色思路：** 让颜色、轮廓和正负形共同支持形状识别，通过相邻色面的分离、对象身份的延续和局部对比形成鲜明性格。

**布局与排印：** 大小、正负形与形状关系有趣，字形饱满或带手绘性格，准确阅读区仍清楚。布局可以自由而有秩序，不强制居中和等大卡片。

**造型与材质：** 纸片、手绘、平面插画、黏土感或玩具感是不同候选。选择一种有一致性的材质逻辑，不是所有物件都加脸，也不必增加复杂角色和三维模型。

**适用与调整：** 适合形象化、轻趣味或低理解门槛的表达，年龄气质要与受众相符。幼龄受众可以更简洁，大众内容可更成熟；可爱掩盖重点时减少装饰，轮廓相似时调整形状和比例。

<a id="art-immersive"></a>
#### 沉浸叙事：有空间、触感与整体氛围

**配色思路：** 从环境光色、冷暖、材质与远近关系形成整体气氛，让主体、局部重点与周围空间相互呼应；场景明暗可以改变，光色与材料关系保持可信和连续。

**布局与排印：** 画面空间可以更舒展，文字像整体构图的一部分，不额外盖上一层无关课件。字体、间距和画面边缘之间有呼吸，必要信息保持实在清楚，不以少字或小字作为目标。

**造型与材质：** 摄影感、真实纹理、插画空间、触感纸面或统一的图形环境均可尝试。空间层次来自前后、明暗和面积关系，不是统一模糊背景。

**适用与调整：** 适合希望观众投入一次经历、观察或氛围的内容。画面漂亮但无重点时重新安排注意；过度滤镜导致细节丢失时恢复材质；统一气质不等于所有场面同色、同布局。

### 在同一场面中选择外观与动作

视觉负责人在同一稿中共同选择颜色、布局、字形、材质、取景与动作，并通过实际表面、动作中途和前后连接检验。气质影响表现性格与强调力度，完整设计仍须兑现[美术方法](art-direction.md#默认设计与整场发展)中的整场要求。配色、造型与连接服从当前作品，场间交接沿[演出方法](../../motion-brief-writing/references/performance-design.md)完成。

需要重做配色或布局时，读取相关方向和通用美术方法即可，无需读取六篇旁白案例。文案主语、某组数值或具体镜头内容不是本页的规则。
