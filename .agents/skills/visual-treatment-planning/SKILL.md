# 整场视觉创作：美术、材料、文字与动作

你负责整片可感知的视觉品质，不是逐镜选色或给已有卡片换皮。根据题材、实际素材与表达气质建立统一的明暗关系、色彩用途、字体语气、边缘、材质与空间层次，让实拍、原件和原创图形在同一视觉语言中成立。输入是导演当前声画稿、实际素材与选段、准确文字、相邻画面、已有设计和用户明确要求。输出写回同一份场面稿，并附本次真实制作的设计画面和实现所需选择。

你负责这一连续范围实际可观看的完整视觉作品，并持续完成源码与正式输出修订。无偏好时也执行[默认设计与整场发展](references/art-direction.md#默认设计与整场发展)，完整解说主动选择承担问题、反差、转折或结论的短语并完成花字，不以全部重点只有粗体、放大或换色作为完成；具体外观由本片决定，不能伪填用户偏好。美术和动作共用同一份可修改的当前稿，机械小改按原范围处理。

## 先进入本次工作

| 当前任务 | 从哪里开始 |
|---|---|
| 新场面或整幅美术被否定 | 阅读[美术方法](references/art-direction.md)中的设计判断、构图和配色，完成新的具体画面；只补读本次涉及的排印、材质与交接章节 |
| 原设计成立，只改字、颜色、位置或取景 | 打开当前实现和实际素材，处理受影响部分；不重新选整片风格 |
| 设计稿好看，但实现变成标题页或字幕不一致 | 对照实际设计与渲染，按[预览与返修](references/art-direction.md#预览与返修)定位丢失的选择 |

## 正常工作

需要确定气质、配色、布局、字体和材质时，参考[美术方向规律](references/art-directions.md)相关部分，并落实到当前画幅。它不决定素材搜索条件或动作力度，无需读取六篇旁白案例来完成配色排版。

先用一句话判断本段的视觉任务：主角是什么，观众怎样看它，材料提供什么条件，本段需要什么情绪与变化。不要先把“高级”解释成某套颜色、巨大标题或固定页面。

将实际素材、准确中文与普通字幕放在同一画幅里设计。先确定主角面积、观察距离、共同参照和阅读次序，再决定颜色、字形、边缘与材质。材料可以成为主画面；标题是否出现及其位置由本段决定，根容器不自动添加栏目名、页码和说明板。

构图与主要运动共同形成，关键画面是过程状态，不是不可改的终稿。制作本片可观察的设计结果，再继续实现。可用当前代码预排、真实素材合成，或明确标注用途的设计图；记录实际使用的方法。生图用于表达设计意图时，不重绘事实原件、编造数字或冒称已经由受管源码实现。设计与实现应能逐项对应。

统一的是本片的明暗、颜色职责、字形语气、材质和空间逻辑，不是所有镜头同底色、同标题位置、同卡片。首次用真实背景确定普通字幕的字体、字号、字重、字色、底板、位置、行高、行数和框尺寸规则，之后全片使用同一规范；不逐镜改变外观、底部锚点或行数上限。实际背景随内容行数向上增高，无字幕无底板；具体单行还是最多双行由本片首次设计决定，不默认冒称用户已选单行。字幕作者负责准确分卡与时序，独立字幕层落实外观；画面冲突优先调整主画面。用户明确改字幕样式时统一修订全片，只承诺实际接口能支持的效果。

主要对象通过面积、取景、明暗与色彩取得明确地位，辅助材料不平均争夺注意。浅底、白原件、浅色块、重复粗边与说明字堆叠却没有主角时应重做关系，不能只换色号或加纹理；也不将修订自动变成全片深色、黑金或颗粒。画内文字只表达面向观众的内容，制作方法、内部对象名和检索记录留在幕后，准确原件与必要内容条件保持。

视觉设计阶段就可共用本场已有机制正文、分镜及必要视频，观察美术与动作怎样共同发生；缺资料继续读取，缺实际作用才补查，不因切换职责重搜相同需求。沿[演出设计](../motion-brief-writing/SKILL.md)在同一稿中安排变化，美术并非不可改的静态页面。事实研究和普通取材不要求调用机制。

需要理解美术、素材、文字与动作怎样共同重排整幅画面，或实现反复退化为局部加效果时，按需读取[整场画面协作参考](references/whole-scene-collaboration/REFERENCE.md)。先看与当前问题有关的实际视频，再读对应源码；不把案例题材、配色、造型和原试作限制当作默认输入。

## 交回与继续

编排中发现正文过密、缺必要铺垫或有更好的声画顺序，向文案提出具体位置、改法与保持项；画面选择不足则请素材作者补材。准确也可以改写，材料与新稿回来后继续当前设计，不重建无关部分。

交回实际画面及对应的素材范围、字体、色彩用途、布局、字幕呈现和重要接点；不再让下游从一串风格形容词猜设计。只记录支持后续制作的决定，不填多份同义设计表。

看预览后按原因修：主体弱先改尺度与关系，颜色脏先改明暗与边缘，文字不清检查字款与分离效果，场面重复改观看方式。用户已经否定整幅美术时重新设计，不拿旧“已采用”状态拒绝修改。局部美术由原作者继续，主要内容或跨段关系改变回导演；正式提交沿[交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)由主任务完成。
