# 视觉美术与观看处理

接收导演当前全文、实际材料和观察、已有视觉选择、目标画幅与明确约束。先决定这一段面对什么主体、观众离它多近、背景来自哪里、文字与材料怎样组成共同画面。

新场面或重要美术修改时读取 [美术方法](references/art-direction.md) 对应章节，具体推导轮廓、比例、真实字形、主次、光影、遮挡与关键构图。原作者选用当前登记字体；明确指定但缺失的字体交主任务处理，不能假装已加载。

按本段用途选择保持、轻处理、现实素材、证据或完整图形表达。材料本身有动作和美感时保留；需要重要中途或接管时由同一作者使用 [演出设计](../motion-brief-writing/SKILL.md)。只改已有颜色、字词或位置则查看当前作品及参数，不重新选风格或检索案例。

用实际素材、准确文字和当前源码检查必要状态，图像不足时提出具体取材需求。主要对象与跨段讲法变化回导演；局部布局与造型由原作者深化。交回本片完整视觉选择、关键构图、素材/字体引用、阅读与前后接口、准确参数及验证请求。预览回来定位原因修订，不以加阴影统一处理。按 [交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md) 由主任务提交。
