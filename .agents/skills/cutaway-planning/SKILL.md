# B-roll、Cutaway 与主画面交接

## 执行角色与代理交接

本 Skill 的创意工作在专项子代理中执行，负责素材采用、源范围、全屏/PiP、裁切及进入返回。主任务通过 [production-coordinator](../production-coordinator/SKILL.md) 真实分派；同一授权子代理可按需读取相关 Skills 并直接创作，不递归分派。涉及整片主线或跨段风格的决定交导演子代理。

执行前读取 [代理角色与交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md#代理角色与交接)：输入带 Project、输入 Revision、对象、事实证据、硬约束和前后接口；返回完整产物与参数、选择理由、影响/失效范围和证据请求。下文的项目写入、生成提交及审阅保存由主任务统一执行，子代理不直接写正式项目。收到实际对象和真实 Preview 后由原子代理审阅修订，不能以摘要、工具成功或等待证据代替完成；输入变化先重新确认，不能只换版本重发。

## Cutaway 的本质

Cutaway 是把主视觉暂时交给另一种证据。它可以解释、证明、具体化、建立地点、表达情绪、展示操作、遮盖必要切点或完成笑点。它不是“画面太久没变”的自动补丁，也不是素材搜索成功后的默认下一步。

`visual-asset-sourcing` 负责找到并本地化候选；本 Skill 负责判断是否使用、使用哪一段、全屏还是 PiP、持续多久、人物声音是否继续、怎样离开和返回。两者不能合并，否则搜索相关性会被误当作剪辑合理性。

## 接收已采用方向与选材结果

先接收导演当前采用的故事与分镜、实际候选范围、观察依据、建议组合和限制。素材专项负责找到和比较，导演决定其在整片的表达作用；本专项据此细化具体使用范围、全屏或 PiP、裁切、进入返回及原声。只有主题词或文件名时，请原负责人补齐依据，不自行重新搜索另一套画面。

结合前后主画面和声音查看候选，检验源范围是否足以保留所需动作与余量、裁切后重点是否成立、原声是否与主声音接得上。用法可以在既定范围内调整；必须换材料时提出缺少的具体动作或构图，交原素材专项继续，改变主要分镜或跨段节奏则回导演决定。

实际放置由主任务按完整参数执行。收到当前版本的声画粗剪后连续检查进入、完整片段和返回；素材本身不合适回选材，切口、遮挡、裁切或声音问题回对应使用方，故事没有发展回导演。修订后检查新版本范围，不能把源视频看过当作成片接续已通过。

## 先判断为什么离开主画面

### 解释

抽象机制、流程和关系通常更适合 ExplainerScene，不一定使用现实 B-roll。

### 证明

真实页面、数据、产品和现场行为需要证据，观众要有时间确认来源和内容。

### 具体化

口播提到真实对象、地点或动作，B-roll 可以让抽象语言落地。

### 情绪呼吸

高密度解释后，一段真实环境或人物行动可以恢复注意力。但情绪画面必须符合语境，不用泛化 Stock 替人物制造感受。

### 遮盖切点

B-roll 可以覆盖 A-roll 跳切，但同时应与内容相关。若整片依赖大量 Cutaway 隐藏人物段落不连续，说明上游 A-roll、数字人或声音需要修复。

### 操作和 CTA

用户需要看见 UI、产品或行动入口时，画面证据比人物更重要。

### 笑点

短梗图或反应可在包袱后接管，但不应提前解释笑点。

## Fullscreen、PiP 还是保持人物

Fullscreen 适合需要完整阅读、复杂 UI、宽构图、现实行动、证据和强模式切换。PiP 适合辅助例子、对象展示和人物关系仍重要的段落。ExplainerScene 适合关系、状态和渐进机制。保持人物适合坦白、信任、重要反应和搜索不到真正相关素材时。

选择不能只看素材本身。先检查目标人物画面：脸、嘴、手势、字幕、产品、视线、负空间和切点；再检查源 B-roll：主体、动作、文字、Logo、边缘、方向、音频和可用时长。

## Fit、Crop 和 Reframe

`cover` 只有在裁切不损失主体、文字、Logo和动作路径时使用。文档、UI、海报、两侧人物和证据通常需要 `contain` 或重新构图。竖屏使用横版素材时，应判断主体能否安全裁切，是否有可移动的取景窗口，或需要背景填充；不能批量对所有素材中心裁切。

Reframe 不能制造不存在的摄影机运动。若源素材静止，后期缓慢推移只能作为画面处理，并需要保护真实空间和边缘。

## 时长与进入返回

初稿以秒标明大约的进入、停留与返回范围，同时写清动作怎样接续，按 [秒级初始节奏与预览修订](../_shared/EDITORIAL_FOUNDATIONS.md#秒级初始节奏与预览修订) 连续看完实际合成后调整。选择仍基于真实源范围；读清后可提前回人物，读不清则延长对应画面或重排承接，明确锁定的声音与总长保持；可修改旁白需要调整时回导演共同决定，Cutaway 专项不自行裁改采用版本。

从段落共同设计读取入场/返回状态、源范围和主视觉交接。Cutaway 遮盖期间底层作品仍按局部时间运行；安排返回时的可读状态，不能让关键解释在遮盖中播放完。层级选择要以实际 front/fullscreen 合成顺序验证。

观众需要识别、理解/感受，再回到主线。复杂页面、UI 和动作需要更长；氛围空镜可以较短，但仍要有开始和结束。快闪复杂证据等于没有展示。

进入点优先完整语义、动作边界、新对象或证据引用。人物声音可通过 L-cut 延续，让关系不中断；新环境声可以 J-cut 提前建立空间。返回人物时检查新姿态、景别、情绪和句子，避免突然跳到不连续状态。

## 声音归属

B-roll 自带声音是否保留取决于任务。展示真实动作和环境时，适量现场声建立可信度；证据或 UI 通常保持旁白；无来源环境声不能伪造现场。人物声音继续时，Cutaway 是视觉替换，不是说话人改变。

## 相关但不该使用的素材

旁白说“自由”，海边相关但可能只提供泛化情绪；说“压力”，夜晚城市相关但不解释压力来自哪里；说“技术”，代码屏幕相关但可能没有任何事实联系。判断当前需要的是机制、证据、具体生活还是情绪呼吸，再选择画面。

## Source Range 的选择

B-roll Asset 往往比实际使用长。选择范围要包含动作准备、可识别主体、主动作和自然退出。只截动作中间会显得突然；从太早开始又浪费时间。对循环环境画面，选择运动连续且无明显重复点的区间。

## 目标范围的选择

Cutaway 可以覆盖完整一句，也可以只覆盖人物跳切。若只遮切点，进入和返回都要在自然音节和动作上；若承担解释或证据，应覆盖完整观众任务。不要因素材只有三秒就强行把复杂说明压成三秒。

## PiP 的大小和位置

PiP 要足够看清主体，又不能抢人物。位置由人物脸、手、字幕、原画文字和视线决定。固定右上角可能挡产品或平台 UI。PiP 的边框、阴影和运动应符合 Style，不默认悬浮卡片。

## 多条 B-roll 组合

一段旁白可能需要多个现实镜头，但每条应有不同功能或动作，不连续使用近似 Stock。组合时保持地点、方向、色彩和运动节奏；声音可以用同一旁白和适量环境建立连续。

## 返回人物的意义

回人物不仅是恢复默认画面。它通常让人物给结论、反应、下一问题或 CTA。选择人物返回帧时检查表情和姿态；如果人物画面跳变严重，可以在自然 Scene 边界回，而不是在句中硬切。

## Cutaway 不足和过度

不足：跳切暴露、具体对象没有画面、证据只能听不能看。过度：人物关系消失、每个名词配图、现实与生成混杂、观众不断重新定位。整片审查要看比例和节奏，而不是单个 Cutaway 是否漂亮。

## 当前能力

当前 MCP 已实现 `manage_cutaways`：它只接受已就绪、本地化的视频，创建或调整时会原子写入 Cutaway、CutawayScene 和 `Cutaway / Fullscreen` 顶层 Item。`fullscreen` 接管画面，`pip` 必须给出安全区锚点和 0.2～0.6 的缩放；`continue_dialogue` 与 `mute_source_audio` 不播放素材原声，只有 `include_source_audio` 才会输出现场声。替换某一条素材使用 `replace_scene_asset`，必须同时给出新的源范围，不能直接修改 Asset URL。主线 Scene 变化后，系统会停用并标记相关 Cutaway 为 stale；先重新判断相关性、进入和返回，再通过 `manage_cutaways` 重新确认，不要把旧 B-roll 自动贴到新句子上。

解释片的原生 Program 与所属 ExplainerScene 的 `fullscreen` Cue 共同承担底层主视觉，Cutaway 在它们之上接管；明确的 `front` 包装和基础字幕仍可显示，PiP 只覆盖自己的区域。不要把应临时离开的完整模型放在 `front`，也不要缩短完整作品来模拟接管。返回时模型沿原局部时间继续，不会自动重播被实拍遮住的入场；需要观众看见的关键变化仍须由导演安排并连续复核。

## 案例：读书口播“陌生的城市和海”

如果人物在讲实际旅行和生活选择，城市与海的现实 B-roll 可以具体化；人物声音继续，先城市行走，再短海面，最后回人物结论。若这句话只是抽象比喻，使用海边会让观众误以为真的旅行，应改为文字/关系 Scene 或保持人物。素材选择必须依据上下文，不只依据名词。

## 交接合同

先按本段要看清的动作和对象确定素材面积，再处理适配。不要把 contain
误当成所有素材都必须完整缩进同一个居中窗口；也不能用 cover 裁掉关键证据。
素材需要在同一场面内持续变为比较窗口时，将实际源范围与接点交原动效作者，
由受管作品统一编排，不让外层 Cutaway 与内部视频同时重复播放同一画面。

输入是 NarrativeBeat、人物/主画面、候选素材、声音和画幅。输出是是否使用、模式、源范围、成片范围、Fit/Reframe、声音延续、进入和返回策略。它会影响 Timeline、Audio 和 Preview。验证是源/目标画面、连续播放、语义相关性和权利。结果交回主要工作流。

## Cutaway 两端同时审阅

Cutaway 的判断同时涉及主画面和候选素材。先看当前成片范围：离开人物或主场景会失去什么，人物表情、动作、证据、空间关系或笑点反应是否仍需保留。再看候选源范围：实际发生什么，哪一段完整、构图和方向是否匹配、进入和退出是否有余量、声音是否需要延续。

标准流程是：

```text
读取当前成片范围
→ inspect_asset 查看候选源范围
→ 比较保持主画面、PiP、全屏三种方案
→ 确认 source range、构图、声音和返回策略
→ 写入 Cutaway
→ 连续播放进入、停留和返回
```

B-roll 至少承担解释、证明、具体化、地点建立、动作覆盖或情绪呼吸中的一种明确任务。候选“漂亮”或与关键词相关，不代表它适合离开人物。个人坦白和重要反应可能更需要保留人物；教程、证据、产品操作和地点建立则可能需要全屏接管。

验证时不能只看 Cutaway 中间一帧。必须播放进入前、完整停留和返回后的连续范围，检查 Dialogue、现场声、字幕、构图、动作方向和注意力是否自然。
