# 沉浸叙事｜同题旁白参考

**教学主题：** 机票改签为什么可能贵。此处保留一个有明确来源的知识解说样本，不将其当作所有主题的生产模板。数字在旁白中已明示为举例；实际新片须核实当次适用事实。

**先理解通用方法，再读例文：** 让必要知识在一次持续关注中逐步出现，结尾同时回收经历与主题答案。迁移的是稳定视点和解释进入过程的方式，不是固定夜景、行李、人物动作或慢读节奏。

**旁白正文**

> 想象这样一个晚上。行李已经放在门边，你却临时收到消息，原定的出发时间赶不上了。你打开机票订单，准备改到第二天。
>
> 航班还有，经济舱也还有位置。可下一页写着：还要补几百块。
>
> 你停在这里。没打算升舱，只是晚一天走，为什么像是又买了一次东西？
>
> 点开明细，先看见的是票价差额。你买原票的时候，买到的是当时那一班适用的价格。现在换到另一班，需要重新确认价格，不一定还能沿用原来的低价。
>
> 空座和低价，不是同一件事。航空公司会安排不同价格的票各卖多少；某个低价不再适用时，飞机仍可能有座位，但能给你的票价已经不同。所以，坐的还是经济舱，也可能需要补钱。
>
> 明细里还有一项：变更手续费。国航的国内自愿改期规则，将它和票价差额分别规定。这项费用和你买的票的条件有关，不只是页面上完成了一次修改。
>
> 买票时，最显眼的是价格。真正临时要走的时候，退改条件才变得具体。同样坐经济舱，有的票更灵活，有的票买得较便宜，却带着更严格的变更条件。价格和灵活性一起形成了不同的票价产品。
>
> 有人行程很确定，愿意少一些改动自由；有人时间常变，更愿意为方便付钱。航空公司通过这些不同条件区分需求，但你这张票究竟怎样，仍要看实际条款，不能只凭价格猜。
>
> 用一个简化例子看看眼前这笔钱。假设新航班比原票贵200元，这次另有100元变更费，页面就会显示补300元。金额只是举例。现在你知道，那300元不是一笔模糊的操作费，而是两种不同原因形成的费用。
>
> 有些票还会随着起飞临近，适用不同的变更费用。座位的销售有期限，临时释放后重新安排的时间更少。但经营上的原因，不能代替一张具体账单应有的依据。
>
> 你再确认了一遍：这次是自己的时间变了。要是航空公司自身原因让你不得不改行程，按规定安排的非自愿改期或签转，不应收取客票变更费，不能照这套主动改期费用处理。
>
> 最后，你重新看回订单。该问的问题清楚了：新航班贵了多少？变更费按哪条条件收？显示的金额和这张票的规则是否一致？
>
> 改签贵，不只是因为日期变了，而是新航班的价格和原票的变更条件一起生效。行程还得重新安排，但这一次，至少不再面对一串不知道从哪来的数字。

**本例的知识依据，不朗读**

[文稿规则依据][IM1]：国航国内客票自愿退票和自愿变更实施细则，2026年04月资料范围。用于区分票价差额、变更费、票种及时间条件，不代表所有航司统一收费。  
[非自愿变更依据][IM2]：民航局《公共航空运输旅客服务管理规定》，重点是自愿与非自愿变更的条件区别，不能扩大成任意改期均免费。  
[一般原理依据][IM3]：MIT 航空收益管理教学资料，用于解释差异化票价、限制条件与价格可售数量，不用于证明具体订单的定价动机或某费率公平。
