# 解说文案与声画稿创作

<!-- topic-film-v2-narration-writing:begin -->

## 用实际材料写完整内容，而不是为动画凑句子

<!-- material-scene-v3 -->
按 [素材到场面方法](../_shared/MATERIAL_TO_SCENE.md) 接收具体发现；台词里的“这里、这一步”对应实际可指认对象，照片不能支持未经核实的人物动机。

主题初期依据导演问题研究和试写方向，实际候选与上下文可以改变语言及观看顺序。尚未核对的原话、动作、人物动机不写成已经发生；按相关材料逐场推进，不等全片全部搜齐。

写出连续口播和句群声画：当前具体关注是什么，材料提供什么，下一步为什么值得出现，最后获得什么认识或感受。例子、判断、比喻、反应和必要条件服务本片，不强制每段悬念、反转和固定环路。真实画面已经表达的进度不机械复述。

与导演、视觉作者一同确定主读的作用。普通正文、字幕与画内强调不同职责，词相同也可能合理共存，但不是每句抽一个词做大字。用 [完整演出写法](../motion-brief-writing/SKILL.md) 的输入要求交准确全文和材料依据，不代写所有局部像素。

实际声音与预览显示讲述过密或过空时，依据内容重排、改写和必要重配，不用删掉主要论述来配合已经做完的动画，也不用短语音撑固定长时槽。每次修订返回完整当前稿、准确变化与影响，不让下游拼留言。

## 执行角色与代理交接

本 Skill 运行在专项子代理中，由主任务通过 production-coordinator 真实分派，并遵循 [代理角色与交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md#代理角色与交接)。输入包含真实 Project、输入 Revision、对象与源范围、用户约束和已有事实；尚无对象时如实说明。

文案作者返回完整产物与参数、选择理由、影响范围和必要材料请求。正式项目写入、生成提交、渲染和审计保存由主任务统一执行；本作者不直接改正式项目。需要其他专项时交回具体工作请求，不递归分派。实际声音与 Preview 经主任务回传后由原作者修订，输入发生变化时先核对差异，不仅更换版本号码重发旧稿。

## 何时使用

用户只给主题或剪辑需求、需要新增解说，或允许实质改写既有稿件时使用。总导演提出本片方向和写作范围，主任务将该范围交给文案作者；完整稿回总导演用于整片分镜和采用决定。

用户锁定原稿或原声时，保留锁定部分，只在允许的范围调整讲述组织、补充说明和画面配合。不为没有旁白需求的观察片强加解说。只有错字、术语读音等局部修正时，不重写整片。

纯原创旁白与已有真实口播的项目合同分开。apply_authored_script 用于完整原创稿，不能拿它向真实原话 Script 里追加一句过桥话；本次没有可用混合写入 Schema 时，只交回拟增加的内容与能力请求，保留原话项目，不宣称已完成放置。素材里的环境声与动作声继续按现有音频用法处理。

本 Skill 负责准确台词和可供导演深化的主要画面过程。镜头、美术、运动与声音专项继续完成各自设计；作者不代替总导演决定整片最终采用稿，也不擅自执行正式项目写入。

## 先读取当前任务

读用户要求、总导演当前方向、目标观众、必须回答的问题、可改与锁定范围，以及已采用的事实和材料。已有稿件和配音必须区分当前版本与硬约束；存在一份音频不代表其长度不可调整。

材料充分时先看实际内容，找出完整动作、重要差异、具体条件和真实反应。材料不全时可以开始构思，同时交回具体研究与素材请求。不要等待“所有素材齐全”，也不能把想象中的资料和操作写成已取得证据。

首次需要从题目发展成稿，或当前稿件主要是并列知识点时，读取 [写作与改稿方法](references/writing-methods.md)。
采用“提出疑问—实际操作—按结果判断”的讲述方式时，完整读取 [浏览器核对教学例](references/browser-investigation-example.md)。
以人物或日常行为为主体时，完整读取 [日常观察教学例](references/daily-observation-example.md)。
借鉴示例的判断与改稿过程，按当前材料重新写作；不要只替换对象名，也不要把示例中的假设结果当作事实。

## 先找到可以展开的内容

把主题写成观众能跟随的一项具体关注：要完成什么操作、辨清什么差别、核对什么说法、跟随怎样的经历，或认识怎样的人与空间。接着试写实际开场与紧随其后的发展，确认第一段能带动下一段，而不是只产生一句吸引人的标题。

对重要材料明确：实际出现了什么；它回答了哪部分问题；它改变了什么判断或产生了什么下一步。由这些发现安排主线。可以使用条件变化、层层深入、行动结果、有效比较、逐步积累或空间发现，不强制疑问、反转、冲突与升华。

向研究与素材专项提出具体任务，例如“取得从点击到加载结果的连续操作，屏幕内容可辨认”，而不是“找手机视频”。注明这份材料将支撑哪句话或哪次画面变化。候选回来后重新判断主线：新发现值得展开就改稿，原结果不成立就改结论；不要仅给旧稿填入一条素材链接。

## 写完整解说，并同步安排主要画面

先写从开头到结尾的连续口播。每段都要有实际内容发展，不能将知识目录加上连接词直接当作成稿。

写作时同时决定观众大致看什么、哪项变化值得被看见、旁白补充什么。画面能演出的动作可以交给画面；旁白主要补充关系、动机、条件、理解方向和意义。字幕可保留必要复述，重点文字按当前观看任务安排，不把整段答案提前铺满屏幕。

让同一对象、操作或场面承接多句，必要时一句跨多个镜头；句号不决定镜头和 Scene 的边界。所需素材可为连续实拍、录屏、照片、真实页面、原理示意或组合，按表达与事实要求选择，不预设“实拍负责情境、动画负责解释”。

主要画面说明写到导演能继续做分镜的程度：当前看什么、发生什么、重点怎样改变、前后怎样接；不用在此提前规定每个像素或缓动参数。

## 做实际改稿

沿初稿执行以下修改，不只给原稿加修饰词：

- 将缺乏作用的并列介绍删、并或重排，把时长留给本片最有价值的实际过程。重要的“影响、提升、处理”等抽象词，要展开为观众能理解的前状态、变化与结果。
- 将专业术语放在它第一次帮助解释的位置。一个句群需要多个前提时，先建立必要前提，避免旁白在解释新机制、画面却同时要求阅读陌生条款。
- 连续几句都在下定义、列原因或重复结论时，检查是否该进入操作、比较、例证、结果或人物反应；有积累作用的重复保留。不要把所有句子改成反问与感叹。
- 连读口播，把难以一次听懂的长句分开，明确代词指向，删掉空泛铺垫，保留决定含义的条件、单位和限定。不要用夸张语气掩盖内容空缺。
- 将相邻段落首尾放在一起读，修正接不上的关注、重复建立的背景和没有根据的“所以”。并列内容可以直接按共同维度组织，不制造不存在的因果。
- 结尾落在本片真正完成的认识、选择或感受上；必要回顾保留，已经看懂的知识不再完整重讲。没有后续材料时，不承诺下一步即将揭晓。

## 用声音与画面修订节奏

整片决定哪些过程展开、哪些背景压缩；段落安排前提、变化与结果；句群调整口语呼吸和信息落点。用秒表达首版参考节奏，并说明时间主要用于说话、操作、阅读、反应还是体验。秒数不是必须填满的时间槽。

读稿和初步画面能够判断时先修订，必要时由主任务组织临时配音或代表段试排。实际声音回来后，检查口语是否自然、关键画面是否有时间发生、文字是否已经可读、声音与画面是否争抢注意。技术合成成功不能代替这些判断。

需要修改时交回准确的新台词及受影响句群，并说明材料或画面要怎样一起调整。未锁定的稿件和配音可以局部重写、重配或重排；不能自动删掉主要视觉过程以服从第一版 TTS 的长度。已经锁定的声音按授权边界处理。

## 交接合同

交回一份自洽的当前稿，不让导演从多条修改留言拼出最终台词：

1. 完整可读的解说正文；明确无旁白、现场声接管及必要读音说明。
2. 与正文对应的句群声画说明：准确台词、主要画面过程、重要文字与声音分工、当前材料依据和待补项、秒级初始节奏、前后承接。
3. 影响采用的事实与材料缺口，以及缺口会怎样改变台词或主线。已有依据与待查事项分清，不用一份脱离正文的清单掩盖正文里的断言。
4. 本轮具体取舍与修订范围，供总导演统筹；不要求另建评分、句型配额或镜头数量表。
5. 实际输入版本、对象及影响范围；采用后准备符合当前工具合同的完整产物与参数，由主任务提交。声音、画面与稿件已经观察到哪里、哪里仍未知，按真实证据说明。

主任务完整回传给原总导演；总导演决定整片采用、主要分镜和下一轮素材/制作安排。素材发现、专项设计与配音结果改变表达时，继续回本作者修订稿件，再由总导演协调相关场面。不能让下游各自删句、换结论或补画面来掩盖同一份稿件的问题。
