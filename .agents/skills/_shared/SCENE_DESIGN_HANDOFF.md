# 场面执行正文：导演到视觉作者的同一份交接

这是已有交接文本的格式，不是新增 Scene 类型或 API。内容按当前任务写，不要求无关栏目齐全。简单镜头可用短段落写完；复杂场面使用下列栏目。交接必须是当前内容的具体设计，不把标题当答案。

## 1. 导演交出的正文

同一份当前声画稿分清纯旁白、依据与素材引用、画面和演出、制作反馈四区；简单任务短写即可，不新增项目字段。素材清单引用现有文件，不在每次交接复制全部资产。TTS 只取纯旁白与实际支持的表演参数，来源和作者分析不朗读。

本稿从主题阶段由导演、文案、素材、视觉共同形成。初始可以只有主题、用户要求、初步问题和已有资料，素材作者不等待准确全文即可探索；材料发现、正文和视觉建议互相更新。导演按[主线方法](../production-director/references/story-and-shot-design.md)采用主要内容，材料参与方式沿[共同取材](../production-director/references/asset-briefing.md)落实。

进入某一连续范围制作时，交当前准确句群、前后关系、实际采用材料与源范围、已经看见的内容、主要观看过程，以及素材中还需解释的关系。主要画面以材料为基础形成，不把待取得内容登记成已经完成的模型容器；源内细节未知时如实保持未知，不造参数。

入口、主行为、持续参照、注意转向、读清时机和出口说明同一过程怎样发展。导演交表达目标、准确内容、声音与跨段取舍，视觉负责人选择完整画面；素材、图形和文字的主次不预先限定。未锁定的构图、大小、位置、层级和观察方式可由原视觉负责人重选，不把第一张静帧变成终稿；主要内容或跨段含义变化回导演。内容句群、连续范围与输出文件分开，不将技术拆件当切镜安排。

导演本轮自主选择的口吻、美术、运动、背景和声音在同一稿里简要说明。用户未选偏好照常执行，只承接其明确要求与主动保存的默认；不派发博主学习或逐镜问卷。三类文字明确分开：普通字幕引用同一全片样式与准确卡文/时间；画内文字写实际观众用途；制作方法、内部对象名、来源渠道和研究备注留在制作资料，不自动上屏。必要内容限定保持准确，必要署名或披露按实际要求处理。美术首次确定字幕规范，后续交接引用同一份，不为每场复制一套可变样式；字幕入退与换卡按[当前字幕规则](../captions/SKILL.md)交接；历史字幕接管与语组位移不自动成为当前要求，也不以历史固定字幕口径否定本片已确定的动效。

物件表达沿同一份声画稿合作：导演写明表达目的、关键变化、效果要求和前后关系；
视觉作者依据[物件效果标准](../visual-treatment-planning/references/object-drawing/object-effect-targets.md)，
主导具体轮廓、观看面、结构、材料、动作及空间的描述，并完成制作。
导演提出的明确形象与用户锁定项继续保留，未指定的细节由视觉主动设计。

美术、物件制作、动效与镜头属于同一持续视觉作者，不按名称增加作者或轮流交接。
采用参考时，视觉保留相关画面范围、借用效果和必要代码／资源依赖，
回传当前主体、源码、资源、实际预排及未完成处，不缩成风格名或组件名。
creativeBrief 仍是摘要，不能代替原稿中的完整表达与具体物件描述。

素材作者和资源工具提供真实内容与机械加工；主任务沿原权限提交和管理版本，
不在转述时重新设计或简化物件。只有说明变化不改渲染输入；
资源、几何、状态或时间实际变化时，才更新相应作品与依赖。

## 2. 视觉作者回传的完整深化

编排中发现正文太密、缺铺垫或更好的声画表达，可返回具体改稿建议；材料不足或同质可提出补材。写清实际位置、理由、建议调整与保持项，原文案交准确新稿、原素材作者交文件和范围，视觉据此继续本场。普通背景更换不自动要求改字，反馈不是新增 MCP 参数。

在导演正文上深化同一场面，不另起与材料断开的“动效清单”。同一视觉负责人读取[默认整场设计](../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)和[完整演出写法](../motion-brief-writing/references/performance-design.md)，共用已有参考，同时决定美术、动作、真实对象映射和连接，再实现同一稿。传递产品默认要求、真实可选调整与本片决定，不只交空偏好对象，也不把静态美术锁成不能修改的页面。

导演正文提供表达意图，不自动成为物件的完整制作指令。视觉概览说明主线、
色彩和机制，也不自动替代详细设计。本范围采用主要物件或连续交互时，
由同一视觉作者按[执行稿](../motion-brief-writing/references/execution-brief-template.md)
形成当前造型、部件、材质、动作因果、关键中途、结果及全场配合。

完整内容留在一份有效正文中：直接写入当前稿，或由当前稿引用已有视觉文件的
准确章节。主任务传递这份正文及必要前后关系，不仅转述其概览或 creativeBrief。
精确技术值可引用源码，但不能用一条源码链接代替主要设计。

探索阶段可先交合法代码生成预排；接回时照实说明设计、实现和观察分别做到哪里。
事后整理的通用规则、案例分析或资料汇总不能冒充当时已执行的本片指令。

回传内容按实际范围覆盖：

- 本场实际使用的原件、范围、已查看内容与关键未知；
- 准确台词、实际需要的画内文字及其字形、面积和位置，以及独立普通字幕的同一规范引用；有重点造型时说明它与主体的关系，不强制每场增加花字；
- 已选主体轮廓、比例、材质、光向、真实字形与颜色角色；
- 关键构图及危险中途中第一关注、姿态、轴心、观察尺度、前后层级、遮挡和有用途的负空间；
- 主体、文字和辅助层如何共同进入、变化、读清、退出，下一内容实际接收哪里；发起、路径/轴心、速度、中间状态、遮挡与交叠具体到本片对象；
- 参考真实引用、借用的造型与协作、因材料改变之处，以及本片自行补完的部分；
- 与当前声音/源事件的对应及独立源时钟，语音、字幕卡和场面的不同时间单位；
- 出口由什么接住，技术拆件时持续对象的源时刻、投影与声音接口；
- 当前作品中可访问的实际预排、源码版本、已观察范围和未完成处；主要实现位置与需复看的中途，不把字段齐全当设计成熟。

在现有“画面与演出”正文中保存当前连续范围与表达目标、事实和素材边界、已选视觉过程、美术与排印、参考取舍以及需要协调的缺口。可合并成连续正文，不要求每段填六行或填“无”凑格式。开始看谁、变化与其他内容怎样配合、结果怎样读清并接向后续，必须具体到当前对象；参考只借局部时，本片其余主要过程也须已有做法。

视觉决策由原视觉负责人形成并作为实现依据。主任务完整转交相关范围，只补真实资产、时钟、版本和无歧义参数，不把主要画面缩写成局部动作任务。creativeBrief 的 6000 字符只保存提交摘要，不能代替完整当前稿；缺参数核对材料与合同，缺主要创意续接原视觉负责人，不自行采用基础布局补空。首次主要表达及主要内容、事实或跨段含义变化按[共享交接](PROJECT_REVISION_AND_HANDOFF.md)协调；同一作者可边设计边验证代码，但最终当前稿与实际方案须一致。实际生成的字形、源材料和预览用于判断，不拿概念图当实现通过。

当前采用稿只保留有效决定，修改经过留在既有制作记录。更新受影响段落，不在末尾累积互相冲突的“当前设计”，也不删除历史记录。

## 3. 展示文字与制作记录分别交付

当前稿明确准确旁白、普通字幕、画内主读以及必要的对象文字，说明其作用、归属与阅读时间。没有必要的类别不强行填写，更不为每镜配齐栏目、页码和身份条。

素材来源、示意身份、文件名称、场次、内部研究与未采用理由保存在制作记录中，不自动生成“示意、示例、图片来自网络、非当事”等角标或印章。删除旧提示时同时取消无用底框并重排空间。

会改变理解的假设和条件在相关讲述或真正需要的原件中准确交代，来源沿既有记录与交付清单保留。原文不被改造成项目结论；必要的真实署名或披露按对应要求处理，不与模型自行添加的提示混为一谈。

## 4. 交接不合格时怎样处理

缺准确事实、锁定范围或表达含义时，由导演与相应作者澄清；
表达已清楚而造型、结构、材料、动作或结果未具体时，续接原视觉作者深化。
缺真实参数和资源身份由主任务读回事实；代码与资源齐备但尚需检验时，
沿原提交路径生成探索性预排，不以缺效果认可阻挡合法探索。

只收到方向概览、参数或部分代码时，记录当前缺口，不将该范围记为已完成详细设计。
原视觉作者补齐后继续同一任务，不新增物件作者，不要求用户填写结构或动作问卷。

文字方案即使已写齐颜色、字体、布局和机制，仍不能替代实际预排。协调者接回后续接原视觉作者，把真实材料、准确文字、字幕占位和关键动作落实到当前作品，导演看实际结果再协调主要选择。预排与最终沿同一源码发展，不强制额外交独立设计图，也不另建练习作品；其他无依赖工作继续。

主要物件和连续过程按[同一执行稿结构](../motion-brief-writing/references/execution-brief-template.md)
深化；简单范围可以短写，已明确技术内容可精确引用。
当前相关正文必须作为同版制作依据，不被提交摘要替代。
