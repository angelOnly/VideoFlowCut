# 从主题到素材主导的完整成片

本页是主题解释类视频的默认生产路线。素材是主要画面与观看发展的制作基础，不是动画完成后的可选插播。素材可以来自用户文件、已有资源或外部检索，形式由内容决定；不把“素材主导”改写成一种固定拍摄类别。用户明确指定其他生产任务时沿相应业务入口处理，不将此路由擅自切换为整片纯图形。

## 同一轮启动导演、文案、素材与视觉

拿到主题和用户实际要求后，由主任务同时建立或续接导演、文案、素材、视觉的工作责任。导演提出初步关注与内容问题；文案写可改的开头和发展；素材作者直接根据同一主题、当前文本与可用信息开始寻找；视觉参与判断实际材料能形成怎样的画面。没有完整旁白、Scene ID 或精确时长不阻止首轮探索。角色可以兼任，但素材反馈不能等待文案、配音和字幕全部结束。

共同草稿沿[导演主线方法](../production-director/references/story-and-shot-design.md)发展；文案直接使用[本地写作方法](../narration-writing/references/writing-methods.md)，不在普通制作中研究博主。导演按内容自主判断表达方向；没有用户偏好不发问卷，工作台默认只承接用户明确保存的部分。

## 用实际材料形成画面和准确文案

素材作者从相关完整内容提出查询方向，持续返回有价值的候选、可用范围及表达机会，不只填导演事先画好的空位。有希望的候选在已有任务授权内及时取得，不逐份新增批准。导演与文案、视觉依据这些实际材料共同确定进入点、主过程、文字分工和前后接续，材料的新发现直接改变当前稿。

依赖某份材料的主要场面，先有该材料的可读内容和实际选择，再确定其主要构图；同范围完整演出使用真实文件与范围。尚未取得时可以研究和草拟，但不能先采用一套完整图形页面，再把材料放到剩余时间。按连续范围推进，不等待整片素材全部齐备，也不通过数量、审核标记或固定比例批准开工。

本路线交付的主体必须由实际采用的材料承担可见内容。图形、排印和机制解释材料中需要说明或延展的关系；局部抽象表达可以使用独立图形，但不能将整片替成文字与模型后仍报告素材主导完成。单个候选不合适可以放弃，原来的材料任务继续换范围、换源或重组；只有用户明确改任务，才转到不同生产路线。这个选择写在业务方法与当前稿，不写成根规则的画面限制。

## 声画共创与连续制作

素材、准确台词与粗画面共同成形后，生成或修订相应范围的正式配音。更早的读稿或试音是试作，不自动锁定全片总长。已有旁白时，先在同一时段重组材料与必要解释，再判断是否需要改稿重配；“没有额外插播时间”不是材料不能承担主画面的理由。

内容句群、连续画面与渲染文件分别决定。同一视觉负责人先在实际材料上完成可运行的连续粗排，再深化美术、文字、声音与运动。进入动画制作后按[机制方法](../motion-case-library/references/mechanism-retrieval.md)使用现有全文与向量召回、整段重选、对象适配和机制协作。候选顺序不是时间线；技术拆件承接同一状态与源时间，不为后一个文件重新建立空场。

预览回原负责人修改。缺材料回素材与导演，缺讲法回原文案，构图与演出回视觉，状态或绑定错误回实现；不能为了快速结束把材料和已采用的协作删掉。技术可生成、设计已实现与实际观看成立分别报告，不新增素材使用资格或用户逐镜审批。

## 当前稿与正式对象

沿现有完整消息／附件、CreativeDecision 和项目绑定保存当前准确正文、实际材料、连续场面、声音方向与变更。来源和内部分析留在记录，展示文字由作者明确；不自动把制作说明渲染到画面。主任务负责真实参数、版本与正式提交，不将完整创作压缩成几个标签。材料、声音或设计变化只续接受影响范围，不另建剧情库、投票表或审核对象。
