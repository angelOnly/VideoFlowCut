# 从主题到完整成片

本方法的正常起点是用户只给一个视频主题。导演带领团队完成研究、角度、解说稿、选材、分镜、美术、配音、声音、动画、合成和交付。下列栏目由团队自己生成，不是用户问卷；本文件不增加 API 字段或新项目数据库。

## 内容先行，动效阶段组合机制

用户主题是正常输入。导演与文案、视觉使用通用方法发展内容和初步声画，素材作者根据文本、画面作用和前后关系探索可用内容，不预设固定材料类别。前期不以历史案例或机制目录决定题材、配色和页面；表达推导仍以[导演分镜方法](../production-director/references/story-and-shot-design.md#沿观看过程形成具体分镜)为主维护位置。

素材作者自主生成找法，提供候选、推荐范围与可利用内容；导演负责最终采用和主要编排，文案与视觉随发现更新同一份稿。已有明确获取或采用直接继续，不创建素材资格审阅。当前文本和画面作用尚未被材料接住时继续相应探索，不用文件数或动画完成自动替代，也不把初步构图变成素材必须满足的规格。

内容段落、视觉连续范围与渲染文件分开决定。相互依赖的持续对象和注意转移，由同一视觉负责人先完成连续粗排；在同一过程上深化美术、文字和运动。必要拆件只拆实际输出范围，不为后一件重新生成空场和背景。

进入动画制作后，由当前作者按[机制方法](../motion-case-library/references/mechanism-retrieval.md)将导演稿转换成动作需求，使用全文词法与现有向量能力召回、结合整段重选，必要时用原片理解补运动信息。机制必须映射到本片对象、空间、声音和连接，不把候选顺序直接当时间线。语义能力以真实工具状态为准，不让 Skill 文本冒称功能已实现。

同一作者继续美术、机制组合、源码和局部返修。主要内容、事实或跨段关系改变回导演；普通创作不逐镜等待用户批准。看片、试听、试排与返修帮助作品变好，不赋予素材采用资格。实际未观察的范围如实保留，技术可导出与专业满意分别说明。

用户明确要求历史研究或复现时，进入相应资料分支。已验证案例和机制原件保持，生产方法不预置某条作品的场景、文案、素材或参数。当前稿与正式对象继续按下节保存，不新建平行剧情或组合数据库。

## 当前采用稿与正式对象

复用现有宿主完整消息/任务附件和 CreativeDecision 引用保存全文与版本，不新增通用剧情数据库。完整交接集中为：本版主题角度、最新朗读全文、实际材料、场面执行正文、声音方向、采用差异、正式写入参数。

协调者只做版本/引用/权限/确定性装配，不把全文压成“做高级动画”，也不为通过字段上限静默截断。当前工具需要参数时，由原作者给出已核对值。发现接口不能表达当前决定，保留原产物并沿项目修复入口处理。

项目中已有其他任务类型时维持其路由。本方法直接覆盖“只有主题”的普通原创生产，不改写用户真实给定的特殊任务，也不改平台安全和版本校验。
