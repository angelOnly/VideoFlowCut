本页是完整解释视频的共同制作主干，适用于 visual_explainer，以及
presenter_motion 中的完整人物混合解释；不重新判定 project.profile。
人物任务沿同一文案、取材、视觉、机制、声音与返修方法推进，只在对应环节
叠加人物化讲述、原话权限、表演源和人物共同编排要求。
复用本页不调用纯解说导演的全部类型专属操作，不强制人物项目建立 NarrativeMap
或 ExplainerProgram；也不向纯解说增加人物输入。Vlog、原片清理和局部包装按
其根路线与授权范围调用所需章节，不自动继承完整解释任务。
完整解释的素材和视觉从首轮参与；实际文件分批返回，声画稿持续更新，
不把正式 API 的依赖顺序误当成整片串行创作顺序。
制作范围为完整解释时，即使正文或正式声音锁定，取材、整场设计与连续制作仍完整执行；
只保持被锁定的内容，不把不可改字误译为只能给人物加局部包装。

材料从首轮提供真实观察、语境和事实依据，不是动画完成后的可选插播。素材可以来自用户文件、已有资源或外部检索，形式由内容决定；“素材主导”不规定固定拍摄类别、显示面积或主次。人物任务在对应环节增加[人物入口](../presenter-motion-director/SKILL.md)的方法，不加载纯解说导演作为第二主导演。

完整新制或主要视觉重做的视觉解说与完整人物混合解释，必须执行[默认整场设计](../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)中的六项表现要求。导演交准确内容、表达重点与前后关系，同一视觉作者决定各项由哪些连续范围、对象和变化承担；本场用途决定具体形式与力度，不决定整片是否省略。没有用户偏好仍执行完整设计，不把“克制”或“素材主导”作为省略理由。普通字幕独立，出处、原件页码和研究备注不自动上屏。不新增逐镜批准或独立样片前置。已有正式原音提前作为时钟，用户锁定的正文与原音不能擅自删改、变速或静止补长；局部机械任务保持原范围。

## 同一轮启动导演、文案、素材与视觉

拿到主题和用户实际要求后，由主任务同时建立或续接导演、文案、素材、视觉的工作责任。导演从题目阶段持续负责表达目标与主要取舍；文案研究、试写与整片主题取材并行。素材不等待完整稿、逐句位置、Scene ID 或精确时长；视觉同步探索观看方式。角色可以兼任，实际文件分批交回，已具备条件的部分先编排。

共同草稿沿[导演主线方法](../production-director/references/story-and-shot-design.md)发展；文案直接使用[本地写作方法](../narration-writing/references/writing-methods.md)，不在普通制作中研究博主。导演按内容自主判断表达方向；没有用户偏好不发问卷，工作台默认只承接用户明确保存的部分。

导演与视觉开始构思关键动作时，同步明确持续负责的声音作者，可以由现有作者兼任。先确定哪些动作值得发声、声音怎样起势和收尾、哪些范围需要留白；由[声音取材](../sound-asset-sourcing/SKILL.md)选择现成或生成来源，定做声音时续用[音效提示词](../sfx-prompt-writing/SKILL.md)。动画未定稿也可先形成声音候选，正式采用前再用真实作品事件和实测音频校准，不能把声音任务留到画面全部完成才开始。

## 用实际材料形成画面和准确文案

普通画面从整片主题、相关场景、对象和活动广泛准备，可以承担语境、氛围、变化、趣味或节奏，不必逐句演出知识。明确原文、数据、真实操作、指定事件或直接指认对象时，才按事实需要定向核实。有希望的候选及时取得，导演与视觉选择位置；材料的新发现可以推动当前稿，但普通背景替换不自动要求改写正文。

确实依赖抠像、跟踪、精确标注或原件内容的部分，先确认相应材料及范围；普通背景尚未选定时，独立图形、排印与主要运动可以探索。按连续范围推进，不等整片齐备；构图与运动共同形成，不把首次静态页面锁成终稿，也不通过数量、审核标记或固定比例批准开工。

材料可以阶段性成为主角，与花字、准确编辑图形共同呈现，或在作用完成后退为参照。不得用无依据图形替代事实，也不得把真实性扩大为原窗口、原位置或固定显示面积；主要画面由视觉负责人整体选择。用户明确保留原片或实拍主导时按实际范围执行，只有用户明确改任务才改变这些边界。单个候选不合适可以放弃，未完成的取材任务继续换范围、换源或重组。不可辨数据不猜，单图不假装可拆层，源内不存在的行为不伪造；编辑图形保留与已核对字段的对应，不冒充官方页面。

## 声画共创与连续制作

素材、准确台词与粗画面共同成形后，生成或修订相应范围的正式配音。更早的读稿或试音不自动锁定全片总长；正文准确但难讲、过密、缺铺垫或存在更好的声画顺序时，也可以改稿，不必等事实出错。“没有额外插播时间”不是材料不能承担主画面的理由。

内容句群、连续画面与渲染文件分别决定。完整新制作进入主要视觉设计时，视觉作者先沿[视觉入口的当前工作分支](../visual-treatment-planning/SKILL.md#先进入本次工作)读取美术与演出核心，再沿[机制方法](../motion-case-library/references/mechanism-retrieval.md)完整观察选定整片参考的观看发展，并在正式采用机制前核读其完整动作及必要前后连接；已有示例沿[视觉入口](../visual-treatment-planning/SKILL.md)规定的时机读取。观察方式与缺口如实记录，正文、分镜、联系表或模型分析不冒充原速连续观看。六项表现的本片对象、主变化、观察转移、阅读状态和接点写回同一当前稿，不另建表现清单数据库。

同一视觉作者用真实材料、准确文字、实际字体、字幕占位和关键动作在当前源码中形成连续粗排。短片可整条粗排，复杂片先处理最有风险的连续范围，再沿同源作品精修。颜色、字体、机制编号和文字方案不代替实际预排；生成结果回来后，原作者观察修订，再交导演判断主要选择。真实声音或材料改变时，原负责人更新受影响的观看发展、阅读时间、协作和接点，不只改段边界或百分比动画。技术拆件承接同一状态与源时间，不为后件重新建立空场。

编排、制作和预览都可发起改稿、补材或重做设计：讲述不清或不吸引人回原文案与导演，画面少或同质回原素材作者，构图与动作不成立回视觉，设计明确但实现遗漏回源码作者。返回实际新稿、文件、设计或源码，合并到同一份当前声画稿；按真实工具返回更新受影响的声音、字幕、绑定、时序和预览，保留不受影响工作与用户锁定项。技术生成、设计兑现和实际观看分别报告，不新增逐镜审批。六种表达方向只用于讲述与美术参考，不控制素材类别或动效参数。

代表段把声音候选与实际旁白、音乐和动作一起比较，选定后再写入正式音轨。声音作者沿[声音意图收尾](../audio-finishing/SKILL.md#声音意图收尾)交回采用、导演留白或未完成项，导演在粗剪与交付前核对；只有声音计划、无声动效或生成文件，均不能代替实际声音制作。

## 当前稿与正式对象

沿现有完整消息／附件、CreativeDecision 和项目绑定保存当前准确正文、实际材料、连续场面、声音方向与变更。来源和内部分析留在记录，展示文字由作者明确；不自动把制作说明渲染到画面。主任务负责真实参数、版本与正式提交，不将完整创作压缩成几个标签。材料、声音或设计变化只续接受影响范围，不另建剧情库、投票表或审核对象。
