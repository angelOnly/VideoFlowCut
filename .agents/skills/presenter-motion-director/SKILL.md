# 人物讲述主导的视频制作

接收源人物/当前稿、真实转写或最终语音、表演证据、目标画幅和用户锁定项。先判断剪原话、原创旁白还是数字人，再建立自然连贯的讲述主线。只有本片由人物或讲述驱动时使用本流程。

规划与精修时读取 [人物剪辑语法](references/presenter-editing-grammar.md) 相应部分，依据真实表情、手势、停顿与负空间选择重点文字、证据、素材或图形。人物可以临时让位于全屏内容，返回有理由；不把所有材料永久缩成小窗。

先形成可观看主线，再与文案、素材、视觉和声音共同试排。实际素材与预览能够推动改稿，源动作不能靠旁白或文字补造。把具体专项范围交主任务分派，原作者继续局部修订。

要应用 Script、人物、语音、Scene 或 Cue 时，主任务读取 [时间线操作](references/timeline-operations.md)，按当前对象依赖顺序提交、读回与检查失效。只改已有文字或位置时直接处理受影响对象。

交回准确主线、完整声画稿、源范围与原声选择、具体制作参数及当前未知。代表段与整片连续预览用于修订，最终专业观察按 [审片](../quality-verification/SKILL.md) 进行；正式项目写入沿 [交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。
