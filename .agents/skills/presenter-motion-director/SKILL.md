# 人物讲述与共同编排

仅对已采用 presenter_motion 或明确 hybrid 人物范围生效。
完整人物混合解释沿 [完整解释共同主干](../_shared/TOPIC_TO_FILM.md) 制作，人物不天然占据视觉中心。
本入口增加讲述者作用、真实原话权限、人物源和共同编排要求，不另述完整生命周期。

先与文案、素材和视觉形成当前问题、准确讲述和观看过程。导演说明人物在其中
承担的提问、带读、回应、澄清、判断或情绪作用，不把这些动作机械等同于全屏露脸。
读取 [人物与材料编排](references/presenter-material-choreography.md)，把人物与其他材料一起构图。
按当前表达难点读取 [人物表达与原片方法](references/presenter-editing-grammar.md) 的重音、比较、重构图、视觉标点、
声画协同或密度章节；这些是完整人物制作的有效方法，不只供原片和局部任务使用。

生成型人物依 [人物源交接](references/presenter-shot-plan.md) 取得准确声音与合法生成源；已有真人依
原片方法整理真实 Take 和源范围。两者返回原视觉作者共同制作，不生成完即收口。
最终构图与实际可见安排按真实源校准，未锁定的页面布局可以重选。

先分别确认制作范围与改稿权限。完整制作即使正文／声音锁定，仍完成共同主干中的
素材与整场视觉工作，只保持锁定内容不变。仅清理、访谈选段或局部修改时，
按实际范围调用方法，不启动无关整片创作，也不能拼造本人没说过的话。

要应用 Script、人物、语音、Scene 或 Cue 时，主任务读取[时间线操作](references/timeline-operations.md)，按实时接口提交与读回。正式人物生成前读取人物源交接；源返回后续接原视觉作者，完成共同主干中的实际作品及返修。

交回准确主线、当前完整声画稿、真实源范围、主声音、源码与绑定、实际观察及未完成用途。生成 MP4 只完成人物素材，不能据此收口。审片沿[质量核验](../quality-verification/SKILL.md)，正式写入与原作者续接沿[交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。
