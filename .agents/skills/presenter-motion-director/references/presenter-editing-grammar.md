# 人物短视频剪辑语法

## 使用条件与导演判断

用于知识、观点、读书、产品等人物短视频的完整制作，以及既有人物主线的表现力精修。数字人只是素材形态，不是独立审美风格。先看源人物的表演承载力、语音韵律、可用景别和负空间，再选择这里的方法；用户只要求清理、准确字幕或保留记录原貌时，维持其范围。以下术语是专业方法，不是新的 MCP 类型、枚举或必选组件。

区分叙事主体与瞬时注意中心。人物可以持续承担讲述者身份，重点文字、图形、对象或声音则在关键时刻接管感知。完整制作中的克制是层级、时机与密度有组织，不是所有对象都小、弱、慢。评价一个处理是否值得采用，应同时看理解、注意、记忆、情绪与节奏收益及其代价；事实信息相同，不表示观看效果相同。

阅读路线：确定重点时看“语义重音排印”；讲差异时看“对比式视觉组织”；画面单调或空间不足时看“动机性重构图”；安排转折与声音时联合看“视觉标点”“声画重音协同”“密度对比”。主工作流选好方法后，将当前 Beat 的具体意图交给相应专项，不要求每个专项重新制定整片风格。

## 语义重音排印：Semantic Accent 与 Kinetic Typography

选择能改变命题或记忆重点的最小完整语义单元，例如限制条件、反问核心、反转后的判断、数字及其单位。重音不等于关键词命中；“并非有效”中的否定不可在放大时丢失。用字级、字重、占屏比例、对比色和空间位置建立排印层级，基础字幕维持完整语言，重点排印负责视觉重音。两者可以同时存在，但不能以同等字号、同等运动和同等对比要求观众读两遍。

短语可以整体揭示、由遮罩显露，或通过紧凑的尺度变化进入稳定状态。揭示控制发现顺序，位移建立方向，有限过冲表达弹性；在没有这些任务时不叠加效果。先设计停稳后的中文分行、字面密度、负空间与人物关系，再设计进入。以真实语音的语义边界或经复核的重音定位揭示，预进入不泄露答案，稳定阶段留给识别与记忆，退出让位于下一语义任务。不能用持续弹跳弥补停稳画面没有层级。

在目标观看尺寸下比较普通字幕与画内主强调的实际显著性。若正常播放仍需寻找重点，应调整主画面的信息量、尺度、位置或对比。普通字幕由 captions 按首次确定的全片样式稳定显示，不承担逐卡静态或动态强调；独立画内排印由 remotion-production 负责，不能伪造逐词同步。

## 对比式视觉组织：Visual Juxtaposition 与渐进揭示

先确定真正被比较的维度。人物说“响应很快，但经常答错”，比较的是速度与可靠性，不是两个人物卡片。可用同一坐标下的标签、符号、状态、距离或方向建立对比；颜色与位置保持语义一致，关键差异由对象之间的关系表达。象征性图形是解释，不是事实图表；没有数据不能画暗示精确比例的柱长。

信息具有先后或反转时，先建立 A，再随第二个论点引入 B，保留 A 供比较，最后突出决定性差异。概览式比较可以同时建立双方，再依次聚焦；不要把“先 A 后 B”变成所有对比的硬规则。对象在揭示之间应保持身份与坐标，避免每句重置一张卡片。人物两侧的轻量并置适合短标签与简单关系；长文本、多维关系或实际空间不足时才由全屏接管。

卡片适合有边界的条目、证据或 UI，但抽象观点并不自动需要容器。先验证去掉外框后层级是否仍成立，必要时用字级、对齐、间距和共享轴组织画面。选图标时确认辨识性与情绪适配；图标不能替代观众必须读懂的限定条件，也不能将严肃叙述无依据地喜剧化。

## 动机性重构图：Motivated Reframing

重构图可以改变叙述距离、强调反问、建立关系空间或从解释返回人物，不只用于掩盖切口。先检查源画幅到输出画幅的裁切：主体占比、头顶与肩部余量、手势、字幕和可用负空间。源人物已经是大近景时，继续放大通常不能解决单调；应评估能否利用源画幅恢复较宽构图，或选择不依赖两侧空间的表现方式。

区分 Cut-in 与连续 Push-in。Cut-in 在语义或表演转折上建立明确的新景别，前后差异应被理解为有意选择，而非位置微跳；Push-in 在一段话内连续改变心理距离，需要稳定焦点和停止动机。保持眼线、主体重心、运动方向与源帧连续，避免小幅往复缩放造成呼吸式抖动。图形需要空间时先重排人物与文字的视觉重量，再决定是否可以同屏。

无 Mask 不等于只能放角落小字：可以在实际可用区域做前景排印、改用上下结构或短暂全屏。不可用的重新构图、追踪或遮挡能力必须退回可执行方案；替代方案仍要保留原来的重点或比较任务，不以不可读的缩小对象作为成功降级。

## 视觉标点：Visual Punctuation

视觉标点标记反问、否定、反转、段落转换与结论，使语义韵律变得可见。它可以是重点短语、局部高亮、构图切换、对象翻转或短促反应；不必新建 Scene，也不以转场特效覆盖每个切口。铺垫建立预期，主事件改变预期，停稳提供识别，释放将注意交还人物或下一对象。

包袱和悬念需要延迟披露，反应放在结果之后；明确的章节转换可以提前建立方向；结论则让关键判断稳定落下。一次语义事件可由文字与短音效共同标点，但无关的字幕弹跳、相机缩放和背景运动不能各自制造第二个高潮。判断的是是否形成同一个感知事件，不是机械禁止声画同时变化。

## 声画重音协同：Audiovisual Accent 与 SFX Spotting

音效是叙事标点和运动的听觉形态，不是画面完成后逐项勾选的附件。在确定视觉动作时同时决定声音的功能：预示型以起势或掠过建立运动期待；落定型以短攻击确认文字、对象或关系成立；反应型在反转或包袱之后提供情绪回应；连接型以合适尾音或过渡连接段落。音色、攻击、持续与衰减共同决定语气，不能仅凭“Whoosh”“Ding”名称决定用法。声音专项负责实际选音、声源范围和混音。

建立少量一致的音色家族，让类似动作听起来属于同一作品，再根据重要性选择轻重、干湿和尾长。主结论需要的可能是清楚而短的落定，不一定是低频轰击；细小文字切换可能不需要独立声音。一个视觉事件的多个子动作可以共享一个包络完整的声音，不必逐元素发声。事件少不表示听觉无组织，事件多也不必然廉价；重点在功能、对比与疲劳。

用户给出的音效包优先作为候选来源。先听完整文件，再比较与目标事件匹配的源范围，识别可听起音、主要攻击、持续与尾音；同时判断是否带语音、旋律、强情绪或特殊情境。文件名、峰值和静音检测只提供线索，不代表实际听感。已提供素材不代表必须全部使用；未选某条声音，要能说明是音色、时长、情绪、遮蔽还是来源问题。

同步的是感知事件，不是文件开头。渐强掠过的起音可以先于运动落点，主攻击与动作完成相合，尾音在阅读或恢复中释放；短促提示可直接落在确认时刻。由 effect-timing 区分可听起音与攻击峰值，再由 audio-finishing 使用实际素材偏移放置。听觉重音可以比视觉提前或滞后以承担预示或反应，但需明确叙事理由与可复核时序。

对白是口播的可懂度中心。先用音色和包络避让语音，再调整增益，避免短攻击遮住辅音、长尾覆盖下一句话、低频能量在普通设备上只剩不清楚的闷响。所有声音都压到几乎不可感知并不构成克制；无声与有声版本若没有可感知收益，重新选择、调整或取消该事件。不得为了制造声音重音改动已经确认的原话或拼接重复声音。

## 密度对比：铺垫、强调、停留与恢复

以语义推进组织注意力曲线，而不是按秒轮换模板。人物提出问题时建立预期，对比逐步展开时提高视觉活动，关键判断形成重音，随后给观众阅读、理解或观察人物的恢复空间。安静段可以有字幕与表演，但主注意不被新事件频繁重置；强调段可以很鲜明，同时维持一个清楚的感知中心。

在相邻完整论述内比较人物景别、排印角色、图形组织和声音包络。多个转折已经发生，但四者都没有可感知变化且人物表演也没有承担变化，是表现不足的证据。反过来，信息未变化而形式不断翻新，则可能过度包装。用当前、最小处理、更强处理或不使用的实际连续范围比较收益；不要提前规定整片最多几次 Punch、每隔几秒一个特效或所有结论必须安静。

## 从方法到已验证成片

共同主干组织完整场面的首轮共创与返修。同一视觉作者把观众任务、语义范围、机制、空间与时序落实到当前完整作品，主任务沿既有 VisualTreatment、Creative Decision、Scene/Cue/Caption/Audio 提交；这些描述不是新数据库字段。接回实际作品、失效范围与同 Revision 的 Preview，不只返回“已按手法执行”。

先审阅包含前后语境的代表段，再扩展与审阅整片。重点能否自然被发现，比较能否追随，返回人物是否连续，声音是否可感又不压字，恢复是否成立，均需实际播放。抽帧只支持画面采样，波形只支持信号事实；没有声音输入或未完成复听时，声音结论保留 inconclusive，不从字幕、动画或音效文件名想象听感。基础校验、计划检查和一次样段通过均不等于用户批准。

## 原创段落的落地

从完整观看任务进入 [Remotion 原创流程](../../remotion-production/SKILL.md)：内容构思与关键状态、creativeBrief、受管提交、Job/Asset 读回、作品审阅、覆盖 Beat 与 Cue 放置，最后回到真实人物/字幕/声音的连续合成。代表段成立后继续整片，不能只提交单个效果结束。

## 适用范围和边界

适用：真人单人口播、双人或多人访谈中的主讲段、播客视频、课程与教程、数字人主持、产品发布、促销口播、个人经历、读书反思，以及人物贯穿、局部插入 Explainer/B-roll 的混合视频。

整片路线继承协调者已采用结论，不能因材料或图表暂时接管而重新分类。没有人物画面但用户要求从零生成数字人时，仍由人物路线统领；生成依赖沿[当前时间线操作](timeline-operations.md)和[声画交接](presenter-shot-plan.md)，实际 Provider 能力交给 `avatar-performance` 按实时 Schema 核查。缺能力只保留相关缺口，不私自换成无人像解释片。

## 开始前先判断任务分支

### Cleanup / 内容清理

用户想保留原结构，只去掉口癖、错误重启、长等待和重复。主工作流先调用 `transcription`/`semantic-continuity`，主声音通过后再检查字幕和必要跳切遮盖。不要为了“看起来做了很多”自动加入全套效果。

### Highlight / 精彩片段

从长访谈、课程或播客选择完整观点。要保护问题—回答、例子—结论和说话者身份；视觉包装应服务选中观点，而不是把多个关键词命中片段拼成一条快剪。

### Restructure / 重组

当内容有价值但顺序不清，先重建 Story 和观众问题。重组可能导致大范围声音、字幕和 Effect 失效，因此应在包装前完成。

### Hook / Short Version

为短视频建立真实承诺和更紧的结构。Hook 不等于第一个大数字；它可以是人物直视镜头提出的问题、一个具体结果或真实反差。短版应创建平行版本而不是覆盖长版；当前代码若尚未支持 Sequence，应明确限制。

### Target Script / 对齐文稿

用户给定准确 Script 时，检查源素材是否能真实覆盖。真人 A-roll 无法组成的句子不能跨 Take 拼造；数字人/TTS 可以按最终 Script 生成，但仍需自然 SpeechSegment 和表演计划。

### Existing Avatar Assembly

表演承载力不足时可以由完整解释段承担关系变化，实际素材的构图、手势和 Mask 是硬边界，增加小效果不能修复弱表达。

已有数字人视频和最终声音时，重点是 AudioMode、段间连续、Scene、字幕、前后景和 Cutaway。不要重复调用 OmniVoice 或再次叠加 Dialogue。

若用户要求完整成片，而非仅组装或清理，还要判断源人物的表现承载力：语音韵律、眼神、手势、姿态与构图是否实际提供变化。表演弱、景别固定的素材，需要通过语义重音、对比组织、动机性重构图和声音标点补足表达；不能凭“数字人”一词虚构表情证据，也不能自动套高密度效果。

### Motion Finishing

主线已经稳定，只需要视觉包装。先读取当前 Revision、Story、SpeechTiming、人物状态和已有效果，禁止顺手改 Script。若发现上游语义问题，退回人物导演核对主线，而不是继续用包装遮盖。

## 影响剪辑的关键变量

平台和画幅改变构图与字幕；目标时长改变内容选择而不是只改变播放速度；受众和语气决定解释深度；人物角色决定目光、手势和视觉密度；声音来源决定口型和时间；Style 决定视觉语言但不决定每个 Beat 的效果。“高完成度”既要求真实预览和完整审片，也要求观众实际感知重点、跟随关系、感受节奏并记住结论，不能仅以流程完整代替观看结果。

在开始前应写清：目标平台、画幅、时长、受众、人物角色、主声音来源、是否允许重组、材料用途与主要观看任务、字幕策略、风格和交付目标。只有会实质改变结果的缺失信息才需要询问；其它可以做明确假设并记录。

## 短视频完整制作的专业默认

当任务是数字人或人物知识、观点、读书类短视频的完整制作，或用户希望改善平淡的观看效果时，进入视觉规划前读取 [人物短视频剪辑语法](presenter-editing-grammar.md)。这份资料说明语义重音排印、对比调度、动机性重构图、视觉标点、声画重音和密度对比的选择依据与完整案例；不是每条视频必选的效果清单。纯 Cleanup、只换字幕或保留原貌的任务不自动加载整套包装。

先判断这次需要怎样的表达，再检查能否执行。主工作流为高价值 Beat 建立视觉与声音的共同落点，包含观众应发现什么、谁承担重点、人物保留何种作用、音乐/SFX 的动作与释放，以及无效时返回哪一阶段。实现选择交给专项，不要求用户给字号、缓动、音效名或固定频率。

## 原片与声音专项约束

### 已有真人 Take 审阅

人物口播不能只从 Transcript 选内容。转写可以帮助定位观点、问题和重录，但两次文字完全相同的 Take，仍可能在准确性、可信感、语气、眼神、手势、呼吸、环境声、可用余量和前后衔接上明显不同。人物承担信任或情绪时，表情和停顿本身就是内容证据；教程和产品演示中，UI、对象和操作画面则可能比人物更重要。

先用 `browse_assets` 确认候选 A-roll，再用 `inspect_asset overview` 了解素材结构。对可能采用的 Take 使用 `range` 查看完整声画；当决定取决于句首句尾、停顿、微表情、手势、跨 Take 切口或人物反应时，再对最小短窗口使用 `dense`。审阅完成后才进入 transcription、semantic-continuity 与 `assemble_presenter_track`。

主工作流对每个高影响 Take 至少记录：为什么选它；另一个 Take 为什么被拒绝；是否为了表演、呼吸或环境声保留了额外余量；切口是否需要 B-roll、CameraPunch、声音桥或保持原样；选择在只听声音、静音看画面和完整声画播放中是否都成立。

个人坦白、读书反思和价值判断通常优先保护人物的眼神、呼吸和停顿；促销或教程可能更重视产品、数字、UI 和动作清晰度。判断来自当前观众任务，而不是固定认为“最后一次重录最好”或“人物超过五秒就应该离开”。

### 源素材和 A-roll

先使用 `asset-import` 将明确 A-roll 进入项目，查看来源、状态、画面和声音。正式组装使用 `assemble_presenter_track`，不要用按素材数量猜 Scene 的兼容 `create_presenter_timeline`。真人口播需要选择完整 Take、自然表情和可用切口；已有数字人段落需要检查角色、姿态和音频是否连续。

### 语义内容

从主题起步或允许优化尚未锁定的解说稿时，由 narration-writing 发展完整讲述及初步声画，导演采用后完成语义核对，并由主任务沿现有原创 Script 入口提交。已有真实口播的删留、重组和切口由 semantic-continuity 负责，保护真实原意；不能为了文案更有吸引力替人物制造没有说过的话。只做包装或用户锁稿时，保持相应内容范围。

调用 `semantic-continuity` 区分任务模式，建立 SemanticUnit 和最终 Script。已有口播的删留、重组与切口保护真实语义；从零创作时，总导演依据整片主线同时发展讲稿与主要画面，允许画面承担关系、证据和体验，不要求旁白复述全部视觉内容。

正式字幕与依赖准确台词的生成使用该范围当前采用稿；素材与整场视觉从首轮共创，不等待全片语义稳定才开始。纯声音检查真实原意、残句、错误重录与自然连接；画面承担的过程、指认与比较放回合成判断，不要求旁白脱离画面后独自讲完所有内容。具体边界按 `semantic-continuity` 的声画方法执行。

### 最终声音

人物表演与动效制作前，用 `manage_sound_plans` 确定段落主声音、旁白重音/停顿、动作功能、音乐走向和留白；计划不替代实际生成音频。实际语音稳定后再核对时长与动作。需要音乐或音效时进入 [sound-asset-sourcing](../../sound-asset-sourcing/SKILL.md)（`sound-asset-sourcing`），默认在线取得有限候选与原文件采用依据，再交 audio-finishing 完成合成。人物进入全屏动效再返回时，旁白所有权保持唯一；如果段内演示声音需要被听见，计划明确主导区间，让音乐退让。

真人原声、人物视频自带最终声音、OmniVoice Dialogue 或纯视觉人物必须明确。需要 TTS 时调用 `voice-production`，使用真实 SegmentAsset 时长生成 `segment_exact`。没有 word_exact 时，不把句中每个词当作精确动效锚点。

### Story 与 PresenterScene

StoryBeat 不是每两个视频一组。它应对应一个问题、观点、证据、转折、例子、CTA 或结论。使用 `manage_story` 保存 Beat，再用 `compile_presenter_scenes` 让 A-roll Item 被明确 Scene 覆盖。Scene 边界应跟随认知、人物状态或视觉模式变化，不只跟随素材边界。

### 人物表演

先读回 Project，确认目标 A-roll Item 已归属 PresenterScene，再调用 `avatar-performance` 登记或审查 ActorPerformance。尚未归属 Scene 时先完成 `compile_presenter_scenes`，不能直接重试人物登记。当前实际工具 `manage_actor_performance` 能保存 imported/generated、MaskMode、AudioMode、MaskAsset、SpeechAsset 和 note；自动姿态和手势仍是后续能力。没有 Mask 时，后景穿插不能伪装成立，应降级到左右安全区、前景或 Fullscreen。


## 人物何时具有当前观看价值

人物不仅传递文字。个人坦白时，眼神、呼吸和停顿是真实性证据；专家解释时，人物建立责任和信任；产品主持时，人物提供尺度、指向和行动关系；幽默内容中，反应可能比梗图更重要。因此不能仅因为人物画面持续了五秒，就自动切 B-roll。

离开人物前应判断观众任务是否已经从“相信/感受人物”转为“理解机制、查看证据、观察对象或执行操作”。实际表情、停顿或反应正在承担意义时，人物本身就是主画面。人物、材料与图形可以从场面开始共同承担观看任务，不默认人物先占主画面；不能按台词名词自动配图。

教程中的真实操作可以取得主要画面，人物退为旁白或小窗；重要承诺与实际对象也可协同增强。具体语义与源表演共同决定视觉中心。

## 人物视觉与声音的专业方法

### Visual Treatment 和 AttentionCurve

调用 `visual-treatment-planning`，依采用分镜判断各 Beat 的保持、轻处理、Remotion、证据、B-roll、Cutaway 与必要安静区；确认后用 `manage_visual_treatment` 写入当前 Revision。AttentionCurve 记录本片实际强度发展，不预设高—中—低—恢复的固定循环。安静区有具体作用时记录理由和范围，例如个人反思、关键结论、高密度后恢复和人物反应。

高密度不等于所有元素一起动。人物做关键手势时，字幕、前景对象、CameraPunch 和音乐重音应退让；一个 Scene 模式切换本身已经是强事件，进入后不应立刻再叠第二个主动作。

同一语义事件的文字揭示、构图变化和短音效可以协同形成一个声画重音；冲突来自各自争夺不同重点或峰值错位，不是“同时出现”本身。安静段要有可观察的表演、阅读或恢复价值；相邻多个转折都只剩相同人物与小字幕时，重新检查表达是否不足。

### 人物层级：Rear、Actor、Front、Fullscreen

Rear FX 适合规模、背景状态、评论环境和章节，但需要可靠 Mask，强度不应压过脸。Actor FX 适合短 Punch、表情落点和有理由的构图变化，不能持续 Zoom 造成不安。Front FX 适合产品、证据、CTA 和封面，需要与手势、视线和空间支撑关系一致。Fullscreen 适合复杂解释、完整证据、UI、现实 B-roll 和强中断，并需要清楚的离开与返回。

### Remotion

动效交接给出大约的秒级初始范围、动作交叠和字幕阅读安排，先做完整首版，再连同人物、旁白及前后句观看修订，沿用 [秒级初始节奏与预览修订](../../effect-timing/SKILL.md#秒级初始节奏与预览修订)。动画比旁白短时安排人物或实际画面承接，不把示例总长当作配额，也不自行裁短主声音。

需要比较、状态变化、关系解释、重点排印或视觉记忆时，总导演先决定主要对象、可见过程、人物怎样参与、信息何时揭示，以及怎样接入和返回。将具体分镜、实际旁白范围与精度、相关 Beat、人物构图、普通字幕与画内文字的作用和范围、本片视觉语言、已有素材与待补需求交给[原创动效专项](../../remotion-production/SKILL.md)。不能只给一句观看目标，也不先拆成逐句效果或把 Registry 名称当作设计。

动效专项据此细化关键画面、美术、连续变化与运动接点，选择能完整实现设计的作品或现有组件。实拍二次加工、花字、画面推近与返回、画中画等同样属于候选表达，按当前实际能力选择；“窗口会动”与“窗口内视频持续播放”分别验证。素材未齐先返回具体需求，总导演协调补全；主要画面或发现顺序需要改变时，带具体收益与代价交回总导演判断。

段内可以保持人物同屏，也可以让图形接管画面，再返回人物。动效专项先设计关键画面、对象变化和交接，再选择受管原创作品或能够完整实现设计的现有组件。需要独特连续表达的段落直接进入原创作品流程，不要求先找网站参考或遍历组件作为前置门槛。

人物与全屏的选择须由内容和真实构图决定。不能固定每段都执行“人物—全屏—人物”，也不能因为人物是叙事锚点，就将核心图形缩到角落。没有可靠 Mask 或手势证据时，使用可实现的同屏构图与全屏交接，不能假装人物能够把图形拿在手里。

交接主画面控制权时，记录离开人物前的状态、解释段起始状态、关键变化和返回人物的句子/姿态。若连续对象需要贯穿这些阶段，先共同设计其身份、位置和尺度，再按当前 Scene、层级与作品时长约束实施；语义上同一段设计，不代表一个 Cue 已经支持任意跨 Scene。

### 外部素材和 Cutaway

由 `visual-asset-sourcing` 提供真实候选与文件，导演与视觉按当前完整场面共同采用。普通素材可直接以真实绑定进入受管作品，不必先离开人物或建立 Cutaway。确需独立 Fullscreen/PiP 插入及返回时调用 `cutaway-planning`，再沿 `manage_cutaways` 写入 CutawayScene 和顶层 Item；单条源替换使用 `replace_scene_asset`。候选相关不等于最终采用。

### 字幕

调用 `captions`。普通字幕默认始终按全片固定规范显示，不因人物动效多少而改样式或逐字弹跳。字幕分卡跟随完整短语，不拆开否定、条件、数字单位和专名；可靠时间缺失时不猜切点。

普通字幕按本次需求呈现实际语言；画内排印可以承担瞬时重音，也可以让问题、判断或标签跨句持续存在。二者按作用共同构图，需要完整字幕时保留对应要求，不因画内同义大字自动删除。重点交给 Remotion 成为独立视觉对象，普通字幕保持统一字色、字号、位置和版式。不能为了不重复字幕而删掉动效的语义主体，只留下难以识别的细线或点。

### Audio Finishing

用户允许线上音效时，把 `browse_sound_sources` 与本地音效包一同交给声音专项作为候选，不预选固定提示声。交接到具体 Cue 内的动作（例如标题进入还是结论落定），由 `audio-finishing` 用 effect_event 绑定当前视觉版本；视觉作品换版后读回 stale 音效并重新选音/定位。整片声画 Spotting 不能由“加了几条音轨”代替，须检查每个重点是否实际得到预期强化。

调用 `audio-finishing`，保持 Dialogue 清楚、人物声音唯一，处理 Room Tone、停顿、BGM、SFX 和 Cutaway 的声音连接。音乐不能填满所有空白；个人坦白和关键证据可能需要音乐退出。SFX 绑定视觉或叙事事件，不能给每个动画都加 Whoosh。

声音意图在 Visual Treatment 阶段就与视觉联合 Spotting，混音在稳定画面后收口。给音频专项交付的是事件及其感知落点、希望的音色与包络、后续阅读/语句空间，而不只是“加点音效”。优先审阅用户提供的音效候选，区分预示型、落定型、反应型与连接型功能；同一声音族形成一致语气，变化由事件承担。检查过弱而无感、攻击压字、尾音拖入下一句和重复使用疲劳，不能把低音量当作声音设计完成。


任务恢复或完成一个样段后，重新读当前 Project、未完成 Job、`read_quality_report` 与原 ProductionRun。沿 `productionReconciliation` 检查每拍的计划和明确绑定的有效对象，再结合 `editorial.openFindings`、逐轮 coverage 决定下一步；不能从聊天里“已经到字幕精修”推断视觉和声音都完成。stale 计划、未放置作品与未复核声音都保留为待办，不改称主动留白。既有原声与已完成去重不属于包装返工范围，除非新的真实证据证明主线仍有问题。

先把一个连续代表段做完整，检验构图、重点排印、基础字幕与声音之间的关系，成立后再将同一设计判断贯彻到尚未兑现的 Beat，最后检查整片的重复、密度变化和收束。局部结果通过只返回它覆盖的范围；不因样段好看而关闭后半片的问题。若原素材近景没有可用空间，先在真实样段比较现有布局；只有确定现有能力无法实现所需构图，才向修复任务报告具体能力缺口，不要求用户补专业参数。

## 不同 Presenter 类型的具体策略

### 哲学、读书与个人反思

人物和声音承担信任；认知反转、反问和核心判断可以用鲜明的排印、空间对比与声画标点建立记忆，不需要先变成复杂机制图。真实眼神、呼吸和停顿成立时保护它们；源人物缺少这些变化时，不能用题材标签为单调辩护。B-roll 应是具体生活经验或情绪呼吸，不能用主题名词机械联想画面。音乐与 SFX 的密度来自情绪弧线，可在论证处支持、在坦白处退让、在结论处形成有分寸的落点。全屏与人物同屏的选择由阅读空间和叙事任务决定。

### 促销、产品发布与 CTA

信息密度可以提高，数字、产品、作品墙和 CTA 具备真实任务。人物手势可以与对象协同，但无姿态证据时使用标准安全区。高强度效果应落在真正承诺和行动上，中间仍需人物恢复，避免全片像广告模板。所有产品、评论和作品必须绑定真实 Asset。

### 教程和课程

屏幕、操作和步骤常是主要证据。人物可以作为开场、解释、过渡或 PiP；已登记的 UI、文档或截图素材应在 `ExplainerScene` 或 `CutawayScene` 中呈现，不能把 `DocumentScene` 当作当前可创建类型。字幕不能遮界面；镜头和动画应让观众看到状态变化，不只重复口播。错误反馈和关键按钮要留足阅读时间。

### 访谈和播客

问题和回答关系优先，反应镜头必须真实属于语境。B-roll 不应覆盖重要表情和思考；重组要保护人物知情和问答。多机位能力未实现时，不假装已同步；可以制定切换计划并说明缺口。

### 幽默和吐槽

包袱前保持信息清楚，笑点后短促反应、Punch 或梗图；不要在包袱前用字幕或动效提前泄露。人物表情常是最强反应，FullScreenMeme 只有在真正增强而不是解释笑点时使用。

正式写入与版本读回沿[时间线操作](timeline-operations.md)，不在本参考重复完整工具生命周期。

## Effect 选择的具体问题

### MetricBackdrop

数字是否是这一拍观众必须记住的核心？有无单位和比较语境？人物是否仍应是主视觉？如果数字只是铺垫，不使用；如果是里程碑，可后景或全屏。哲学内容中的“更多钱”未必需要具体 Metric。

### ProductFan / PortfolioWall / ContentCarousel

是否有真实素材？观众是需要看数量、类别还是单个细节？多对象应有选择和排序，不是把全部 Asset 堆满。人物是否做了可配合的手势？没有则用安全区或全屏。

### CommentCloud

评论是社会反馈环境、具体证据还是装饰？若需要阅读具体评论，背景云不够；若只是表达“反馈很多”，低对比后景可能适合。虚构评论不可当真实证据。

### EvidenceCard / DeviceShowcase

内容能否在人物旁边读清？复杂页面和操作应 Fullscreen。来源、条件和 UI 状态必须真实。

### CameraPunch / FullScreenMeme

Punch 是否对应人物表情、包袱或结论；Meme 是否在笑点后增强，而不是提前解释。频繁使用会消耗信任。

### GlowCTA / EndCard

观众是否已经知道为什么和怎样行动？CTA 应在行动语句内保持，EndCard 需要收束而不是塞入新信息。

## 人物画面变化与跳切

真人 A-roll 的跳切可以通过选择更好的 Take、适量 Punch、Cutaway 或画面重构处理，但不应每个切点都用 B-roll。数字人段落的姿态重置更明显，可能需要重新生成、在自然语义边界切换 Scene、使用 Fullscreen 解释，或让人物保持标准构图。

当两个 A-roll Clip 景别差异过小、人物位置跳变时，硬切会显得失误；可以改变到明显不同景别、在动作上切、用 Cutaway、或保留一次有意义的 Punch。Transition 通常不是第一解决方案。

## 自主风格设计与可选参考

无参考时根据本片内容、受众和真实人物自主建立排印、色彩、构图尺度与运动语气。有参考时再拆解成视觉密度、人物占比、背景/前景语法、字幕角色、Scene 切换、运动语气和声音结构。不要直接复制其品牌、素材或每秒效果。先用一个代表性 Beat 验证 Style，再批量。

例如参考视频每 2～3 秒变化，但原因可能是信息点密集、人物动作和产品演示；把同样频率应用到哲学口播会错误。复用的是“价值变化触发视觉变化”，不是固定秒数。

## 实际观察

沿[质量核验](../../quality-verification/SKILL.md)按具体风险选择静帧、连续画面与声画，复用当前有效输出；不为每个重要效果另设固定渲染工序。判断人物作用、资料阅读、解释发展与交接，未观察部分保留未知。

## 常见失败

- 同时加载所有专项 Skill，却没有主流程决定顺序；
- 使用兼容 Timeline Builder 按素材数量猜 Scene；
- 主线没通过就开始堆效果；
- 所有 Script 使用同一组 11 种 Effect；
- 无 Mask 仍承诺 behind_actor；
- B-roll 只匹配关键词；
- 人物原声与 Dialogue 同时播放；
- 字幕、手势、产品和 CameraPunch 同时成为主动作；
- 局部 Preview 正确就宣布整片完成；
- `loadedSkills` 代替实际交接和项目对象。
