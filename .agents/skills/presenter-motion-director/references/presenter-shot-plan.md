# 人物口播声画规划与执行交接

这是本次当前声画稿的内容要求，不是第二份 Script、Scene 数据库或逐句固定模板。

导演从第一轮起交清：当前准确台词和说话人、当时观众要完成的任务、人物显露或退让的理由、主要材料与图形职责、关键连续变化及返回理由；完整台词、制作说明和表演要求分区，不能把导演指令送入 TTS。简单镜头短写，复杂连续段才展开，不要求所有句子都填表。

在相关范围进入生成前，按实际声音与素材校准人物可见区间（包括全屏、缩窗、分屏和过渡）；区分内容范围、SpeechSegment、可见区间、Avatar Provider 生成段和受管视觉作品范围，不按字幕或动画文件拆分。缺资源时记录真实缺口；人物和素材作者不得补造已就绪对象。

当前出镜需要保存到原 VisualTreatment 的 `presenter_uses`，不新增第二份计划；主任务依[人物执行操作](../../avatar-performance/references/actor-operations.md#当前执行)查询复用、提交 v2 缺口并在回收后按当前范围采用。

人物专项接收真实参考、SpeechAsset／原声、能力、当前可见范围、段内时间证据和源缺口，交回可用人物视频及口型、Mask、姿态限制。视觉作者接真实人物与材料源，在同一连续场面完成主次、构图、花字、进入和出口。主任务按实时 Schema 提交、读回版本和影响；声画不一致时回到原负责作者修订，不私改路线。

生成型人物先解析工作台照片和音色（用户明确指定＞本片已选＞全局默认），由主任务固定项目副本。导演交表演意图，人物专项按生成段写 LTX 正向提示词，主任务提交照片、该范围真实台词音频与可选 prompt。全屏素材接管且人物完全不可见时可只保留声音；不默认生成覆盖全片的超长人物视频。换照片只重生受影响人物，换音色先重配并复核时序，再重生口型；失败不切 H3。

人物生成供应当前分镜缺少的真实视频源，不决定最终布局。先按本批的台词、画面
与正式声音确定哪里需要人物，包括动态头像、剪贴、分屏、容器和进退过渡。
查看现有源，合用就复用，只为仍缺的必要连续范围裁音频并生成。

完整配音可持续用于全片，不自动触发全文人物视频。音频片段来自同一版正式声音，
不为人物显隐重新 TTS。语音段用于来源追溯，不要求人物生成覆盖整段；段内时间
使用真实证据。长段无人画面不并入，短时连续性和自然起止需要的余量据实保留。

人物方式可以在制作中继续改变，后来新增出镜也可补源。已经生成不等于必须用，
第一版分镜不限制后续创作。每个 Job 固定自己的声音、照片和参数，新的分镜不
篡改在途输入。完成后先交回源与实际限制，再按当前画面需要使用，不按旧位置自动上屏。

窗口、纸片与设备内框的移动和裁切交给视觉作品，不烧进人物生成视频。人物提示
描述具体的交流语气、自然动作和适合的取景，使用工作流实际支持的输入，不许诺
精确逐词手势。未知结果先查原 Job／Run，下载或登记失败优先恢复已有结果。
