# 人物前后景与空间合成

## 使用范围

人物口播、Mask、前后景 EffectCue、全屏切换或多图层发生遮挡时使用。

## 必须执行

1. 读取 ActorPerformance、Mask、Scene、EffectCue、字幕、目标画幅和 Preview。
2. 按背景、后景效果、人物、人物效果、前景效果、全屏、字幕的语义层级检查画面。
3. 保护眼睛、嘴、关键表情、手势、字幕、证据文字和平台 UI 区域。
4. 检查进入、稳定、退出与完整运动路径，而不只看稳定帧。
5. 每个重要决定比较保持原状和至少一个替代方案。

## 专业判断

- 人物遮住背景数字可以建立深度，但不能遮掉关键信息。
- 前景产品需要和手势或空间有可信关系，不能穿过身体或像无支撑贴纸。
- 多个大对象同时运动时，应减弱或延后次要对象，保持一个主视觉中心。

## 当前能力边界

当前渲染器只有固定轨道层级和有限 Cue 视觉，没有姿态锚点、通用坐标、自动手部检测或多画幅重新布局能力。发现无法安全解决的遮挡时，应改为左右安全区、全屏或不做该效果。

## 退出条件

真实连续预览中没有不可接受的遮挡、越界或多主视觉竞争，人物和关键信息均可读。
