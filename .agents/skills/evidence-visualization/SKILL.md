# 证据、文档与数据可视化

## 启用状态

此 Skill 已保留知识，暂不自动启用。当前本地导入不支持通用文档资产和来源/版权持久化，也没有文档聚焦、图表或署名清单的项目对象。

## 后续工作原则

每条证据必须绑定主张、来源、相关片段、限制和署名。画面顺序应为先建立完整页面/来源，再聚焦，再高亮；裁切不得删除否定词、条件、日期、单位、样本或反例。

生成画面只能做说明或隐喻，不能冒充法规、新闻、官方文件、历史资料或真实数据。

## 当前允许的产出

可审查用户提供图片的可读性、来源说明和风险；不能将其报告为已经完成的证据 Scene，也不能替代正式权利审查。

## 按需读取

- 证据真实性与来源：references/evidence-integrity.md。
- 页面建立、聚焦和阅读时间：references/document-reading-order.md。
- 数据、坐标和比例诚信：references/data-and-chart-ethics.md。

## 退出条件

只有资产来源、文档/图表渲染和导出署名链路落地后，才能自动启用。
