# 已认可案例的使用与验证

## 局部案例共同使用步骤

1. 明确观众在当前段落需要先看到什么、接着理解什么。整片已采用的参考按导演稿核对完整范围和前后接续。需要解决局部观看问题时，从[案例目录](validated-index.md)按观看任务选例，读取对应 CASE、原片和所需资料。
2. 用本片真实素材确定画面主体、素材源段和具体动作。明确哪些观看关系可以迁移，哪些构图、排印、源时钟、运动和进出场需要按当前素材重做。需要整理连续演出时，读[完整演出写法](../../motion-brief-writing/SKILL.md)。
3. 连续查看当前作品的实际预览，核对主体是否清楚、动作是否承接、文字是否读得完，以及段落如何进入和退出。遇到停顿、掉帧或同帧不一致时，查阅[时序与连续性诊断](timing-continuity.md)并比对实际源码和视频。

## 验证边界

- 原片与历史审阅只支持其对应版本和实际审阅范围。R92 的范围见[案例目录](validated-index.md#r92-案例组的验证范围)，各例的素材缺项和状态见对应 CASE。
- 后写的教学指令需要重新渲染并审阅，才能记录新生成结果。迁移到本片后的素材融合以当前版本的预览为依据，完整声画还要连续核对人物、旁白、字幕和声音。

## 制作交接

把采用的案例及范围、保留和重做的设计、真实素材与源段、局部动作帧、计划放置范围、人物与字幕处理，以及实际预览和对应版本交给 [OpenDesign 视频制作](../../opendesign-video-production/SKILL.md)。制作方负责受管版本、Cue、Impact 和合成审片，主工作流按当前 Revision 验收成片。预览缺失或审阅范围有限时，交接时明确记录待复查的内容。
