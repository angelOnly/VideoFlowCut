# 自有案例的采用与验证范围

## 共同参考与局部技法分开

先识别本次已采用的整片共同参考。它参与最初构思及各专业工作，不能被“局部效果按需选读”规则跳过。随后按当前材料和具体问题，选择需要深入的局部技法与源码。

现有案例保留各自已验证范围；一条成片内的多个章节不算多次独立成功。原件与后写教学分开。没有相同题材，也可以借鉴相近的观看关系，但不把无关的物体、配色或动作菜单强套到本片。

## 依据当前材料选例，并分开记录验证能力

本次已采用共同参考从首次构思参与；导演依据实际材料和内容确定具体场面，同一视觉作者再结合[实际材料设计方法](../../production-director/references/asset-briefing.md)选读案例。历史六例、r92组及已完成迁移案例都保留原媒体与状态，不以本次新指令覆盖旧记录。

先读当前材料的实见对象、源范围和创作机会，再选相关局部方法，写出当前对象/部位/原句与示例动作的对应。整体案例帮助组织不同观看任务；局部案例帮助实现某一次变化。案例名称、颜色、场数、主体或历史时长不决定新片，不把五例当五段成片模块。

分别记录：图形内部过程；实际素材内观察；素材与动画的上下文融合；完整主题声画成片。它们是不同能力的证据，不是审美排名，也不要求所有片都同时覆盖。纯图形成功不能作为真实材料跟踪或完整主题的通过证据。

迁移返回本片完整执行稿、原材料对应关系、关键构图和实际参数，并继续正常生产与审阅。无法找到可用实拍就适配实际照片、页面、其他观察点或明确图解，记录改变；不能用全原创小物体替代材料分支测试后仍写“材料融合验证通过”。

原有完整场面与局部案例继续从 [r92混合场面案例索引](r92-family-index.md) 进入。

本索引与各个 `motion-case-*` 是案例资料；已采用共同参考由各相关作者持续使用，其他局部技法按需读取。由已获授权的当前作者直接学习并完成负责范围，不为索引或每个案例再创建代理；实际产物、版本和 Preview 修订遵循 [代理角色与交接](../../_shared/PROJECT_REVISION_AND_HANDOFF.md#代理角色与交接)。

本库保留用户于 2026-09-08 最终选定的以下六项，并通过上方入口增加r92混合场面教学资料。历史原版MP4、固定源码、参数与关键帧保持原对应关系；各组验证范围分别记录。本页按观看任务路由，不一次加载全部案例；生产仍由 `remotion-production` 承接。已退出运行目录的旧教学案例不恢复为默认范本。

## 新增完整案例：时代变化与节目安排

[案例入口](cases/motion-case-attention-programme/CASE.md)包含用户已认可的最终R72视频、原始完整输入、最终v3固定源码、Props/字体/素材绑定与简短实现说明。它是一条完整作品，不拆成多次成功验证。

本次采用本例为共同参考时，各相关作者从首次工作开始阅读完整作品与原指令；材料和观看任务明确后，由原视觉作者深入具体技法。先看用途与状态，再看视频和原输入，需要时看完整实现输入与源码。本包缺少两份原大视频、字体原件、完整字幕工程与v1/v2源码；可以学习，不冒称一键完整复现。迁移方法尚无独立的新主题验证结果。

学习后使用 [完整演出写法](../../motion-brief-writing/SKILL.md) 为当前内容重新设计，不把手机、椅子、五纸条、绿色与历史时码当默认。原六例与r92资料和状态保持不动。

## 这些动效为什么能形成统一的观看体验

**对象参与内容。** 卡片表达群体选择，纸面承载规则，票与手机引出条件，封面流建立集合，弹幕收束讨论。主体本身发生变化，而不是永远只有固定标题与中央图解。

**身份与空间持续。** 卡片与标签共同推进，页面变成同一张撕开的纸，手机退开后原票仍在。封面与弹幕的前景接管是另外绘制的对象，合集是横移混合转场：应说明实际连续到了哪一层，不能把所有接力都叫真实几何变形。

**动作有主次、有交叠。** 后一动作可以在前一动作收势时起动，镜头可以在标签建立时靠近，背景退让与前景入场可以同时发生。但读条款、辨认对象和理解反转需要停稳；“顺滑”不是所有元素从头动到尾。

**美术服务当前对象。** 银灰 SIM 与高亮标签、纸面印刷层级、深底产品与大数字、低对比弹幕与红色重点分别服务各自任务。共享的是清楚的主次和动作语气，不是统一配色、固定时长或统一卡片组件。

**事实边界可核对。** 这批选择是视觉偏好，不是业务模型认证。四台不等于70台，飞走一个数字不能证明优惠计算，示意评论不代表公众共识。换内容要同时改文字、单位、数值、图形关系和真实来源。

## 秒级节奏怎样使用

六例第四节用“阶段、首版参考用时、具体动作与接续”说明局部秒级安排。相邻动作有意交叠，不能把各行用时直接相加为总长，也不能只保留动作条件而丢掉节奏尺度。先实现完整首版，再按连续预览调整各动作、阅读和后续接点；清楚可读的收势时间计入阅读，不重复追加等待。

## 用案例帮助生成新动效

迁移时分清三类内容：值得借鉴的设计决定；需要为当前材料重做的具体实现；
只属于当时测试的条件。对象留场、尺度与注意变化、动作接续值得学习；主体
造型、颜色、构图、源范围与节奏要为本片重新决定；历史画幅、无声、指定时长、
不依赖外部实拍等测试条件，不能覆盖当前视频实际需要。

涉及真实视频共同编排时，继续读取 remotion-production 的混合素材教学例。
它用于连接设计和实现，不新增一项已经选定的视频案例。六个历史选定视频、
源码、fixture 与完整指令保持原对应关系；新指令与旧视频不是同一次生成时，
不能改写验证状态或用旧成片为新输入背书。

案例 Skill 是设计与实现教学，不是内置 Registry 组件的别名。读取产品扇开等
案例之后，先确认所选组件是否实际实现本段需要的内部关系变化，不能只因名称
相近，就把连续展开、聚合和回收替换成一张固定排列卡片的整体进出场。

现有组件能够完成简单强调或当前表达时继续使用。需要对象持续、观察尺度变化、
真实视频共同运动，而现有组件不能兑现时，沿受管原创作品路径实现。不要为了
修正这一差别，重做所有组件、强迫所有原片进入 Remotion 或新建动效引擎。

代表段交回实际采用的路径、对象／源码及预览。审阅核对内部过程、默认尺寸与
当前观看目标，而不只检查读过哪个 Skill；布局不适合时改构图，不补无关装饰。

先理解当前段落要让观众看懂什么，再按内容关系选择一个主要案例。
不要只按机票、手机、产品等题材词选例；没有合适案例时自主设计。

选中案例后，先读它的 SKILL.md，再完整读取该例
references/generation-prompt-v1.md。完整指令中的造型、配色、构图、
主体关系、动作起止、交叠、阅读与检查要求共同构成示例，不能只读摘要。
视频和源码用于理解实际效果；注意所看视频属于历史版本还是新版指令的结果。

已有用户通过反馈的指令可优先用于相同内容关系，但不能因此强套不匹配题材。
其他新版指令可以用于相应试验，不能称为已验证输入。

阅读后，为当前讲稿重新写一份完整动画指令。明确保留了示例的什么方法，
以及当前主体、文案、美术、构图、动作和时长分别怎样重新设计。
不要只替换标题和总时长，也不要只写“参照此案例做得高级流畅”。

材质、排印、明暗、形状和空间关系应与动作一起设计，不能先拼完动作，
最后再加阴影或发光来补美术。具体编写要求由 remotion-production 执行。

只加载当前需要的案例。读完示例不是任务完成：继续写当前指令、实现源码、
渲染并检查实际结果，再交回剪辑流程。

## 数字人与解说怎样使用

数字人或真人同屏时，以真实脸部、手势和字幕占用重新构图。产品、封面和弹幕选定版均为不透明横版测试，不是已预留人物区域的透明 Overlay；24 秒源码则在后段退为透明以露出底层素材。没有已验证的 Mask，就不承诺人物前后穿插。

全屏解释可以让对象占据更大空间。人物可在段前提出问题、段后承接结论，也可以按实际画面重排；不把整幅复杂图硬缩进小窗。真实旁白与音效按可见动作重定时序，本库无声样例不能代替混合声画验证。

## 参考、生产与交付

需要诊断停顿、掉帧或同帧不一致时，按需读 [停顿与顺滑的实际经验](timing-continuity.md)；需要核对历史原片观察依据时，读 [已观察机制](observed-mechanisms.md)。它们不替代各案例的实际源码和视频。

当前 `submit_motion_work` 要求非空 creativeBrief，reference 可选。四站只在需要在线参考研究时使用；本地案例用于学习机制，不能伪装成已观察在线参考。没有参考时自主设计；没有动态观察时如实记录证据缺口。

视频与代码从原渲染快照固定归档，不引用可继续变化的临时 motion.tsx 冒充所选版本。fixture.json 是案例说明，不是可整包发送的 MCP 参数；assets 下的完整历史源码有时含未使用分支，实际只采用指定 mode。校验哈希、链接与语法只能证明包完整，不代替实际合成审美。

## 交接合同

选择和改写完成后，将所用案例、保留与重做的设计、Props 与局部动作帧、计划放置范围、人物/字幕处理和真实预览证据交回 [remotion-production](../../remotion-production/SKILL.md)。它负责受管版本、Cue、Impact 和合成审片；主要工作流负责当前 Revision 的成片验收。教学案例不声称已完成正式人物、旁白、字幕和声音的合成。
