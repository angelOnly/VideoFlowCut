# 物体微距、部件离开与大字接管

## 1. 何时使用

内容相关物体具备可分离部件或清楚局部，希望以物体表现和排印形成一个有记忆点的完整画面。先由导演确定当前内容与主要观看任务，再由同一视觉/动效作者学习本例；不新增代理，不要求用户先提供参考视频。

## 2. 资料与实际验证范围

[原片观察视频](assets/observed-preview.mp4) · [教学生成指令](references/generation-prompt-v1.md) · [实现定位](references/implementation-notes.md) · [来源与状态](case-record.json)

本例来自用户提交的r92作品。原片从金色触点近景拉开，显示托卡和嵌入小卡；小卡抬起离开槽口，托卡转向退为后景；绿色第一行与第二行结论在前景交叠进入。

此片段本身约4.54秒，而非早期独立试作的5.83秒；两者不是同一个源。例中静音、画幅、SIM载体和结论语句只属历史样例，不能变为每条成片的尾段模板。 新教学指令未重新渲染；原片反馈不能替新指令背书。

## 3. 应迁移的设计

读完整教学指令，明确借鉴的观看关系、美术组织和中间过程。回到当前主题重做主体、真实材料、准确文字、配色、声音与节奏；案例历史时间只用于定位视频，不复制到新片默认。
