# 弹幕穿行 → 文字收束 → 原重点句与气泡

## 1. 适用场景与表达目标

本案例先让观众感到多种声音在讨论，再把注意从文字群体引向一条“这下看懂了”。前半段不要求读完每句，收束阶段表现注意转移，最后由一个红橙气泡承载清楚、稳定的重点回应。主体是排印与文字路径，气泡只在重点建立时出现。

适合疑问归纳、讨论氛围和集中回应。需要逐条证据阅读或精确引用时，应改用可读的真实材料与来源说明；不能用热闹的文字流代替证据。聚合表示注意集中，不表示所有人变成同一观点或普遍赞同。

本例所有短句是原创示意，不代表真实用户评价。预先选定的“这下看懂了”从原位置连续运动到重点位置，保持同一身份；不是等背景全退后临时生成一句结论。

本案例供 [remotion-production](../../../../remotion-production/SKILL.md) 在段落构思与设计时使用，主工作流提供当前讨论内容、重点回应、来源性质、旁白、画幅与前后画面。

历史视频为 960×540、30 fps、300 帧，配套源码中气泡是独立前景对象，并未严格追踪某条原弹幕。完整指令要求选定句保持身份，若另用前景实例，接管当帧匹配内容、字形、基线、位置、透明度与运动方向。因此参考视频与源码用于学习效果，不是完整指令的逐项输出，也不能覆盖当前身份与自然结束的设计。

先读本页判断是否适合讨论到回应的关系，再完整阅读指令、查看视频，按需读源码。为当前内容写包含句子、排印、美术、路径、局部秒级动作、阅读和出口的完整制作指令，通过既有生产流程实现与合成。不能把全文简化为“弹幕聚合成一个气泡”。

## 3. 具体美术设计，以及为什么这样设计

### 3.1 排印本身就是主体

| 元素 | 本例的具体设计 | 设计作用 |
|---|---|---|
| 背景 | 暖奶油 `#EEE9DE`，无明显纹理与颗粒。 | 留出稳定阅读环境，密度与路径承担前段变化。 |
| 常态文字 | 深灰绿 `#303735`，同套中文无衬线，字重约 700—800。 | 大小与行距有层级，保持短句轮廓清楚，不给每条套卡片。 |
| 重点气泡 | 红橙 `#ED482D` 的唯一实心色块，无描边阴影。 | 在重点阶段引入强重音，背景文字随后退出阅读区。 |
| 重点文字 | 暖白 `#FFF8EB`，约 60—64 像素、字重约 800—900。 | 与气泡形成稳定对比，最后只要求读这一条。 |

本例以 960×540 横幅设计。六行字高约 26、32、38、26、32、38 像素，同一行保持一致，不能每个字随机缩放。长句按实际字宽增加间距或重新排布，不能压扁字形。前段不添加头像、点赞数和消息框，避免把示意排印伪装成真实评论截图。

### 3.2 内容、行距与固定对象

八条短句是“原来如此”“这下看懂了”“等一下”“还有这种操作”“重点来了”“为什么呢”“再看一遍”“还有疑问”，每条最多重复三次，形成约 24 个固定 ID。重复项保持不同身份；重点只有预先选定的一条，其它同句对象在收束时更早退让。

六行基线约在 y=58、145、232、319、406、493，每行两到三条完整或部分可见，相邻短句净空约 65—95 像素。行起点错开约 25—65 像素，避免竖直整齐的文字墙。首帧至少十二条完整或部分可见，左右自然裁切，画外留后续对象。

各行共同向左，速度以每秒 95—135 像素为起点，相邻行差异不超过约 20%，同一行保持共同速度。预先安排重点对象在收束时位于中央附近、y=220—320。收束目标散布在 x=130—830、y=135—395 的区域，有间距、有不同到达顺序；不让所有字冲到同一个像素点。

路径从收束事件起点的真实屏幕坐标接出，先保留向左趋势，再转向目标区域。不要每帧把持续漂移的起点与终点简单混合，否则容易出现追赶或折返。外围文字可以短暂交叉，但在重点建立前已开始降低对比，不能把中央堆成黑色墨团。

### 3.3 气泡围绕原句建立

最终气泡矩形约 526×170，中心约 (480, 250)，圆角约 12—15。下边缘偏左接同色三角尾部，根部在中心左侧约 45 像素，尖端再向左下延伸约 45 像素。尾部与气泡无接缝、无重叠透明造成的深色三角，也不是单独飞来的箭头。

文字水平居中，按实际字体校正视觉中心而非仅依赖字体框；左右留足内边距，不碰圆角。气泡在字后从短而圆润的底形向四周展开，文字与外框同步接近终点尺寸，不让大字等小底框追上来。

前景接管时只绘制一份重点句：新实例首帧匹配原 ID 的内容、字体、字号、基线、位置与透明度，随后停止旧实例。气泡取得足够覆盖面积时字色从深灰转暖白，过渡中保持对比，避免浅字落在奶油底上的失读时刻。外围字提前腾出空间，气泡下不透出清楚黑字。最终只留一个红橙块、一句重点和大面积奶油留白。

## 4. 以秒表达的参考节奏、动作交叠与接续

**下表是首版节奏的参考用时，不是必须填满的时间槽。先据此完成设计和实现，再连续观看成片，按实际动作、阅读与前后衔接调整。**

表中用时主要是局部动作，相邻动作有意交叠，不能相加成固定总长。重点句从第一次清楚可读时开始获得阅读时间，不等一切停稳后再机械追加完整一段。

| 阶段 | 首版参考用时 | 具体动作与接续 |
|---|---|---|
| 多行文字穿行 | 氛围建立先按约 1.4—2.0 秒；行速度约每秒 95—135 像素。 | 首帧已有文字按共同方向穿过，看到六行层次与不同声音便准备收束，不等逐条阅读。 |
| 穿行转向收束 | 收束约 1.0—1.35 秒。 | 各对象从事件当时位置出发，保留部分向左趋势再弯向中央区域；重点句保持清楚与连续。 |
| 外围退让、前景接管 | 先从收束进行约一半时启动退让。 | 优先降低靠近重点字面的文字对比；其余收束运动仍在继续，气泡建立早段已有阅读空间。具体退淡用时按密度与覆盖调整。 |
| 气泡围绕句子展开 | 外框展开约 0.45—0.65 秒；重点整体建立约 0.7—0.95 秒。 | 原句或对齐后的唯一前景实例继续移动，气泡在字后生长；字色与覆盖面积配合，字号与外框共同到位。 |
| 尾部接上、主体收势 | 尾部约 0.15—0.25 秒。 | 外框展开约三分之二时尾部伸出，同一填色相接；一次明确收势，不反复弹跳。 |
| 重点阅读与结束 | 全部落稳后先按约 0.6—0.9 秒检查阅读余量。 | 把末段已经清楚可读的时间计入。短句读清、气泡落稳后结束或按当前出口接续，不追加慢放大或新弹幕。 |

动作说明使用秒，代码按当前 fps 将本次确定的时序换算为事件帧，渲染前确定总长度。主体、字体状态与收束路径按当前帧稳定计算，图层接管保持方向和速度，不能因换实例重新起步。

完整预览中，氛围已成立却迟迟不收束，就提前起势；聚合拥挤先减少竞争文字、调整目标与外围退淡，再决定是否需要加时。句子读不清先校正字重、字号、对比与气泡空间，再补阅读。不要为保留约 24 条对象牺牲画面，也不要给所有动作统一加速或减速。

独立例结束在稳定气泡上；慢放大、漂浮和新句子不能用于补足旧 10 秒。已有旁白或用户锁定总长时，保留约束，通过内部编排、覆盖和后续画面承接，不能自行改短声音或整片。最终以实际成片表达、可读性和观看节奏验收。

## 5. 换内容时保留什么、重新设计什么

把讨论氛围收束到一个值得回答的问题时，选定的问题取得可读尺度和唯一重点，
其他文字降低竞争，而不是全部停止后再弹出一张无关结论卡。真实评论需要保存
来源和上下文；示意文字明确为示意，不能伪装成真实公众反馈。

可让讨论发生在真实视频或页面周围，随后保留该对象继续回答问题。标签与
正文各有职责，评论数量和移动速度不作为丰富度指标。历史大气泡是前景重绘，
新作若要做对象接管，应实际核对起终点和中途，不能仅因文字相同就宣称身份连续。

| 设计层面 | 可以保留的方法 | 需要按当前内容重做 |
|---|---|---|
| 观看任务 | 氛围、注意收束、重点阅读分工明确。 | 真实问题、回应及是否适合归纳，不把集中注意画成全部赞同。 |
| 内容与事实 | 固定重点身份，真实引用与原创示意区分。 | 当前短句、真实作者或来源、完整原意及必要限定。 |
| 排印与空间 | 同行共同速度、稳定字形、不同目标的松散收束。 | 字长、对象数量、行距、净空、路径和当前画幅。 |
| 重点与美术 | 原句持续，背景提前退让，气泡围绕文字建立。 | 重点句、字号、行数、气泡宽高、配色和尾部形状。 |
| 节奏 | 收束接退让、气泡接尾部、末段已读时间计入。 | 当前密度、距离、阅读用时与后续承接。 |
| 合成 | 同时只有一个主要阅读层。 | 人物、字幕、旁白、来源标记和声音占用。 |

例如从课程提问中集中到“这个条件什么时候成立？”，可以保留多行问题向该句收束的方法。重点变长后，应减少同屏条数、重排路径和气泡行数，重新计算阅读，而不是把长句塞进五字气泡。真实提问保留来源与原意，不能用统一“这下看懂了”替代不同意见。

历史源码的 words、重点句、数量、行距与速度在内部定义，Props 只有 mode。更换内容会影响布局与时序，不能只换文案。独立例的横幅和无声输出服从当前任务规格；人物同屏时按实际脸部、手势与字幕重排，当前参考没有人像层或 Mask 验证。声音可以强调气泡获得注意的一个必要节点，不必每条文字一声提示；实际起音应对齐可见动作，而非只贴齐音频片段头。

## 6. 如何根据实际成片检查和调整

先对照[穿行](assets/preview-045.png)、[开始汇聚](assets/preview-130.png)、[气泡交接](assets/preview-190.png)、[重点聚焦](assets/preview-260.png)理解构图，再检查当前事件帧。接管前后两帧与其连续片段都需看，静帧相近不代表速度衔接成立。

| 检查位置 | 应看到的结果 | 不成立时怎样修正 |
|---|---|---|
| 首帧到多行穿行 | 立即有讨论密度，行节奏与净空清楚，无可见换词。 | 调整初始可见对象、字宽、画外余量和共同速度，不空等文字远处入场。 |
| 穿行到收束 | 从真实位置柔和转向，各自目标有间距。 | 固定事件起点、校正速度趋势和目标分布，避免跳位、追赶或同点拥堵。 |
| 原句到前景重点 | 同一“这下看懂了”持续可追踪，无双影或闪失。 | 校正固定 ID、字形、基线和绘制切换，保持唯一实例。 |
| 外围退让到气泡 | 重点区已腾空，字色与底色始终可读。 | 提前退淡竞争字形，调整气泡覆盖与换色时机，不让黑字透在白字下面。 |
| 外框到尾部、收势 | 比例正确、文字视觉居中，尾部同色无缝相接。 | 按实际字体修正内边距，校正尾部路径与填充，去掉重复弹跳。 |
| 最后阅读与出口 | 重点读清后自然结束，无慢放大和新消息补时。 | 计入已获得阅读，补不足或删多余尾巴；按当前剪辑出口衔接。 |

历史探测曾将第一批初始横坐标放在 1080 之外，开场还看不到文字；选定版把它们移进可见区。这是开场信息密度问题，不是编码掉帧。历史 gather=119—210、气泡=164—220、外围退淡=175—229 的交叠可用于定位接力；最后 218—295 帧的尺度 0.75→1.12 是旧版选择，不是新作品的强制结尾动作。本例没有独立“卡顿版→修复版”全长对照，不能借用产品或合集的历史数值冒充证据。诊断参见[停顿与顺滑经验](../../timing-continuity.md)。

静帧检查字形与层级，正常速度完整播放判断密度、转向、退让和阅读。通过既有生产流程放回真实剪辑，连同前一句、完整动效、后一句、人物字幕与声音检查；需要合成才能判断的部分先用既有待审草稿取证。出现问题区分排印设计、路径实现与合成干扰，针对原因修正；句长、数量、声音或人物改变后，对应旧审阅失效。

将当前完整指令、文字与来源、作品及放置版本、动作事件、实际审阅结果和待处理问题交回 [remotion-production](../../../../remotion-production/SKILL.md) 与主工作流，继续原剪辑任务。历史选择与资料完整均不能代替当前成片验收。
