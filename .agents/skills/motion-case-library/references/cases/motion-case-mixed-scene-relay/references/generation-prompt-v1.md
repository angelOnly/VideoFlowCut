# 混合场面接力：参考生成说明

在当前导演的主题、已采用稿件和实际材料上，设计一段完整混合表达。把“叙事的不同观看任务”组织在一起，而不是按“实拍、网页、图形、结论”的文件类型轮播。

先用连续语言写出入口处境、主要发展与结束。选择合适的现实动作作为入口；内容需要从多处观察聚焦一项时，让活动窗口展开、重排、聚焦，主体的源过程仍在发生。主要条件被揭示时，让前景对象让开、改变尺度或换观察角度，使信息从真实遮挡或新观察中进入，而不是另开一张卡。

事实依据在需要时进入当前构图，中文主读、原文、来源各有明确任务。真正讨论文档时可以让纸面主导；只是支撑判断时让它完成引用后退让。转入机制或关系时，保留必要参照，展开当前有依据的关系；不为使用某种动效硬加公式或流程。

为不同场面选择互补的主构图：多个活动窗口可以变成一个近景；深色影像可让位给一段明亮排印；局部观察可以展开为开放关系；一个内容相关物体可与大字共同收束。是否使用这些具体方式由当前内容决定，重要的是每次变化有观看任务，统一来自字体、色彩、精度与运动语气，而非同一布局重复。

重要原创主体先做轮廓、比例、关键部件、细节集中和受光。把真实文字及字幕占用放入当前画幅，再安排前后关系。入口、主要变化、阅读和出口都要形成完整构图，中途不能只靠淡化替代空间关系。

镜头时间由当前稿件、真实源过程、阅读和声音决定。模型或图片替代实拍后重排有效观看时间；被认清且没有后续任务的主体及时交棒。阅读、比较、反应或有美术表现力的细节展示可以保持，不以持续微动凑时。

需要连续主体就建立真实源时钟和跨场投影；需要切镜就明确切镜。若受管预算要求拆作品，导出每块的入口/出口和全局偏移，共用的状态计算保持一致；场面设计不会因技术分块丢失。

在一次任务内完成全部原创代码、获取与绑定、配音/字幕/声音合成、实际预览和必要修订。回传完整当前指令、源码、素材记录、事件、设计兑现位置和实际观察范围。素材与作品不伪装成已取得、已验证；不把本教学例的画幅、总长、主题物体或静音沿用为默认。
