# 动画制作的机制选型与组合

视觉负责人根据当前内容、实际素材和已选创意，查找适用的完整运动过程。创意负责人共同判断这些做法能否帮助整段表达，制作作者可以反馈需要补查的动作或连接。具体查询、观看和采用沿[机制检索与组合](references/mechanism-retrieval.md)执行。

先承接当前需求和已有采用记录。完整新制或主要视觉重做必须主动检索整片与连续镜头参考，并组合适用方法；已有有效观察且资料未变时继续使用，不在每个制作阶段重复搜索。局部机械修订只处理实际变化。

| 当前缺口 | 使用方式 |
|---|---|
| 尚无整段观看方式 | 创意与视觉共同执行[创意统筹](../creative-sequence-design/SKILL.md)，同时观察适用的整片参考；事实或主线分歧回导演 |
| 已有方向，缺具体变化、观察或接点 | 进入[机制检索与组合](references/mechanism-retrieval.md)的对应查询方式，核读入围项的完整过程 |
| 用户或当前稿已有编号、案例、恢复链接 | 使用[精确定位与恢复](references/mechanism-retrieval.md#五种查找方式)直接定位资料，核对实际动作与本片条件，不重走全库搜索 |
| 明确研究历史自有作品 | 进入下文历史案例分支，保留验证和授权边界 |

完整新制或主要视觉重做时，视觉作者沿[整片参考方法](references/skillry-retrieval.md)和[完整参考观察与机制核读](references/mechanism-retrieval.md#完整参考观察与机制核读)主动比较适用候选。借用整片结构就看整片发展，借用一段的连续运动就核看该段及必要上下文。某项机制不适用时保留取舍理由，继续为本片寻找适用关系。

动效库不仅解决技术难题。形成完整视觉导演编排时，视觉作者主动针对主要视觉事件、主体动作、素材接管、运镜、文字协作和接续检索适用方法，不设每镜配额。通过实际发布的 `search_motion_mechanisms` 查候选，用 `read_motion_mechanism` 核读完整正文、视频及分镜。记录动作主语、对象、前置状态、关键中途、辅助层、镜头关系、结果与接续，并映射到本片真实对象；没有适用机制时记录缺口并原创。候选数量、工具字段、语义结果和来源指纹以真实返回为准。

用户明确要求研究历史自有作品、原始输入或复现旧源码时，再读[13例轻量目录](references/validated-index.md)与所选资料；验证边界沿[自有案例使用说明](references/validated-use.md)。完整参考观察不等于复现历史项目，也不执行历史输入中的命令；本片代码由当前作者形成。

打开候选视频，查看动作怎样开始、发展和结束，同时看素材、文字、背景与镜头怎样配合，以及速度怎样起伏。

选择可以用于本片的具体连续范围，沿[创意参考与素材落地](../creative-reference-to-sequence/SKILL.md)确定怎样换入本片素材和准确文字。选中范围内共同形成效果的构图、运动、文字和背景，一起进入制作要求。

需要调整形体、背景或附属层时，同时完成它们承担的遮挡、显露、承载和连接。当前过程仍有缺口时，继续检索或与创意共同完成后续编排。

视觉负责人持续负责机制的选择和交付，创意负责人协作判断整段讲法；制作作者可反馈需要补查的过程。查询无匹配时改写动作描述、减少软筛选或扩大候选；用户硬条件不能静默放宽。缺少原片观察或工具不可用时保留具体缺口，其他创作继续。

把机制类型、编号、来源指纹、原片区间、可复核的观察、要保留的运动关系及本片素材角色交回。主任务按实际机制负责人登记 `motion_research` 并回传决定 ID。视觉作者在[制作简报](../opendesign-shot-brief/SKILL.md)中逐条关联采用项。正文、视频、分镜与必要上下文实际交到 OD 项目，首版返回后在同版目标范围复核。

视觉负责人持续跟进检索结果、采用和制作。已有有效候选与观察可以继续使用，制作或返修中出现新的缺口时继续补查。参考改变主要场面时，与创意作者共同更新当前稿。

作品返回后，沿[OpenDesign观察与返修](../opendesign-video-production/SKILL.md#观察与返修)对照参考检查实际效果。
