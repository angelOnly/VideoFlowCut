# 动画制作的机制选型与组合

服务视觉负责人对完整场面的选择，共用实际可见的美术与动作资料；事实研究和普通取材无需调用，不提供固定整片讲法或美术模板。流程时机遵循 [共同主线](../_shared/TOPIC_TO_FILM.md)。正常生产使用120个视频拆出的机制资料，参考可参与并改变构思、美术与动作，当前视觉稿保存最后采用的决定。

先承接当前需求和已有采用记录，按尚未解决的问题进入；已有参考且资料未变时继续使用，不在每个制作阶段重新搜索。

| 当前缺口 | 使用方式 |
|---|---|
| 尚无整段观看方式 | 进入[整片参考方法](references/skillry-retrieval.md)，从内容关系选择整片参考，按规定观察选定整片，再深入有用机制 |
| 已有方向，缺具体变化、观察或接点 | 进入[机制检索与组合](references/mechanism-retrieval.md)的对应查询方式，核读入围项的完整过程 |
| 用户或当前稿已有编号、案例、恢复链接 | 使用[精确定位与恢复](references/mechanism-retrieval.md#五种查找方式)直接定位资料，核对实际动作与本片条件，不重走全库搜索 |
| 明确研究历史自有作品 | 进入下文历史案例分支，保留验证和授权边界 |

完整新制或主要视觉重做的视觉解说片，沿[完整参考观察与机制核读](references/mechanism-retrieval.md#完整参考观察与机制核读)完成选定整片的观看发展观察与正式采用机制的完整动作核读；查询分支不取消这两层观察。已有教学示例沿[视觉入口](../visual-treatment-planning/SKILL.md)规定的时机读取。同一参考与已有有效观察可共享，不重复建立任务。

围绕当前观看变化，覆盖观察与运镜、场内发展与场间连接、花字演出、局部协作四类作用。通过实际发布的 `search_motion_mechanisms` 查候选，用 `read_motion_mechanism` 读正文与分镜，再核看实际媒体。候选数量、工具字段、语义结果和来源指纹以真实返回为准；检索结束需要本片主要过程已有具体办法，不能以取得编号收口。

用户明确要求研究历史自有作品、原始输入或复现旧源码时，再读[13例轻量目录](references/validated-index.md)与所选资料；验证边界沿[自有案例使用说明](references/validated-use.md)。完整参考观察不等于复现历史项目，也不执行历史输入中的命令；本片代码由当前作者形成。

根据候选的起始条件、动作关系、结束状态和真实分镜，决定本片可借哪一部分、哪些需要改造。构图尚未成立时，不把第一种布局当查询硬条件；入围后同时看运动和实际画面，适合的字形、配色、材质、取景与动作可以联合借鉴。局部采用后具体补齐本片剩余主要过程，不以搜索成功证明方案成立。采用后把真实 ID、来源指纹、借用关系、本片补做与实际观察范围写入当前声画稿；候选链接可随稿保存。不直接搬用原题材事实与旧时间，参考媒体也不自动成为可用生产素材。

当前导演、视觉或动画作者连续完成选择与迁移，不为案例资料创建代理。查询无匹配时改写动作描述、减少软筛选或扩大候选；用户硬条件不能静默放宽。缺少原片观察或工具不可用时保留具体缺口，其他创作继续。交回实际采用项与未解决的连接，再继续本片制作和预览修订；读过资料或检索命中不代表新片完成。
