# 案例检索与参考

先承接当前需求和已采用的设计，明确画面现在有什么、想怎样变化、结束后留下什么，以及必须保持或避开的动作。用户给出机制编号、案例或候选恢复链接时直接定位；尚无参考时，从当前问题选择下面的入口，不先读全部目录。已有参考且资料未变时继续使用，不在每个制作阶段重新搜索。

找可自由组合的小机制时读[机制检索与组合](references/mechanism-retrieval.md)。它覆盖五种工作：把自然语言拆成运动阶段查找；依据当前画面和保持条件查找；从一个机制找相似演法；根据起止状态找前段或后段；保留候选、预览比较、排序采用并恢复清单。通过实时 MCP Schema 中的 `search_motion_mechanisms` 召回摘要，再用 `read_motion_mechanism` 按需读取入围项的完整指令与分镜。检索工具不承担最终的语义判断和组合设计。

需要整片讲法、材料组织或美术参考时读[整片参考方法](references/skillry-retrieval.md)。明确寻找历史自有作品、原始输入或实现源码时，再读[13例轻量目录](references/validated-index.md)，选中后按该例入口深入；需要理解其验证范围时读[自有案例使用说明](references/validated-use.md)。机制资料只解释运动，美术依据应看原片或对应自有案例。

根据候选的起始条件、动作关系、结束状态和真实分镜，决定本片可借哪一部分、哪些需要改造。采用后把真实 ID、来源指纹、保留的关系、需要重新设计的连接和实际观察范围写入当前声画稿；候选链接可随稿保存。参考里的旧主体、色板和原片时长不成为本片约束，参考媒体也不自动成为可用生产素材。

当前导演、视觉或动画作者连续完成选择与迁移，不为案例资料创建代理。查询无匹配时改写动作描述、减少软筛选或扩大候选；用户硬条件不能静默放宽。缺少原片观察或工具不可用时保留具体缺口，其他创作继续。交回实际采用项与未解决的连接，再继续本片制作和预览修订；读过资料或检索命中不代表新片完成。
