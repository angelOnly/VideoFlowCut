# 创意参考检索与观看

由当前制作路线中承担创意职责的作者执行。收到本场内容范围、成片要求、本场素材和全片可选素材入口后，先打开素材，再检索参考。

实际素材指本片已取得、作者能打开并判断如何入画的材料。用户拍摄或网上取得的照片与视频、截图、录屏、档案、插画、生成画面和人物表演均可参与编排。承担事实证据、原话或现场记录时，按其用途核对来源和内容。

首次在本任务开展创意研究时，创意作者在提出查询前完成[创意研究 R40 步骤](../creative-sequence-design/SKILL.md#创意研究必读案例)和[视觉研究 R40 步骤](../visual-treatment-planning/SKILL.md#视觉创意研究必读案例)。同一作者对同版资料已完整观看时，按各职责完成理解与对照，不重复播放相同资料。

## 建立全片参考研究地图

按现行文案、原话或事件范围定位各场。某场已有能代表其主要画面需求的素材时，开始该场查询。全片美术与各场演出可以并行探索。一条原片可以承担多处，每处分别写明采用依据。

## 先建立完整视觉研究地图

结合全片内容和现有素材，先列出需要解决的视觉问题，再安排检索。覆盖整片视觉语言、主要场面的完整组织和确有需要的局部运动机制：研究构图与空间、真实素材和文字图形的共同关系、统一美术与跨场连续，再研究具体对象怎样进入、保持、接管和接续。每次查询说明要解决的问题、所属层次、希望观察的关系及会影响本片哪些画面。

三个层次是研究范围，不规定参考卡数量。找不到适用的整体参考时，视觉作者可原创整体视觉系统，再结合适用的局部机制。局部机制已经可用不代表整场研究完成；尚未穷尽的候选可以继续并行。

## 根据当前内容和材料写查询

**一、先想这段给观众什么体验。** 打开本场代表素材和全片可选素材。视频看主体动作和前后状态，静图看整幅和可取的局部。结合本场在整片的位置，想清观众进来时先注意什么，随后在哪一刻会产生期待、看出反差、感到舒展或愿意多看一眼，以及这种感受由什么引起。文案、原话和事件经过用于定位场面并核准内容。素材中的动作、色形、人物反应和景别也可以给出值得发展的观看角度。

**二、找出让这种体验成立的对象关系。** 回到本片素材，找出观众需要跟住谁、拿谁和谁比较、哪一次变化会影响其他对象，或者哪处细节在前后出现时有不同意味。试着拿走一个对象或调换两个状态的先后，判断想要的感受在哪处消失。将这个关系留进查询。人物与环境、动作与反应、局部与整体、影像与字组都可以共同承担这种关系。

**三、把对象关系翻成镜头表达。** 决定先给观众看什么，暂时留住什么，何时让其他对象进入，在哪里揭晓或停留。比较时想清哪些对象需要同屏或在相近状态下先后出现；希望观众感到意外时，先建立能被后一拍改变的预期；希望观众认回主体时，先让其可辨特征被看清。用文字、图形、遮挡或镜头变化引导观看，把具体版式、字形和转场做法留给候选启发。已有明确的画面要求时带入查询。

**四、写成跨题材的自然语言查询。** 保留对象关系、观看先后和最后的感受或发现。将专有题材名换成其他场景也会出现的对象和动作。只写情绪词时，补上引起感受的可见变化。已经写成窗口、列表或按钮布局时，回到上一层，说明这组布局原本想让观众看到什么。同场有不同的观看机会时，可以分别查询，每条集中探索一种表达。用 [R40 的实际查询与教学推导](../creative-sequence-design/references/R40-机器人进厂/角色指令逐段拆解.md#从旁白写出第一轮创意查询)对照怎样从期待、因果或对比推到可查找的画面。

**全片美术查询。** 观察一条片怎样在不同布局、明暗和景别中协调各类素材、背景、花字与重点色。比较候选中不同构图的场面，交回实际时刻和可沿用的美术做法，由视觉作者亲看后选定。

## 取得并比较候选

核对实际 MCP 工具定义。用当前项目的 `search_creative_cases` 提交自然语言 `query`。空查询用于浏览目录，已有编号用于精确定位。对从零选片，读回并比较实际语义候选后再定段。

浏览实际返回的候选，选择表现方法有差异的项目继续查看。需要扩大比较时，按工具实际返回的分页继续。

返回语义任务时，通过 `track_job` 跟进原 `job_id`。任务完成后使用返回的 `readback.tool` 和 `readback.arguments` 读取候选页，再按 `next_offset` 继续。核对检索方式，确认为实际完成的 `semantic_used=true` 结果。主任务代为执行时，将当前页候选、分页信息和诊断交回原创意作者继续读卡、观看和比较。

等待期间的空结果保留为任务尚未完成。失败或结果未知时，沿现有恢复方法读回原任务。使用已返回候选继续探索时，如实记录实际检索方式，并继续接回已发出的有效结果。定段前读回并比较实际语义结果，排队期间先看的原段继续作为候选。

资料版本过期或原编号失效时，按当前库重新检索并读取完整卡，核对实际场面和源时间范围，再更新参考编号、来源指纹及采用范围。

已经发现且仍适用的候选，与后续结果共同比较。标题、摘要和排名用于安排阅读顺序，采用依据来自实际视频及其对本片的适用性。

## 看过视频，再决定选哪一段

对语义检索入围项，用 `read_creative_case` 传入返回的编号和来源指纹，打开 `body` 中的 `## 完整照排指令`，同时取得参考视频和分镜。该指令与创意卡同文件。在仓库中，库根是 `references/motion-cases/skillry/`，索引是库根下的 `creative-index.json`，用库根拼上该卡记录的 `card` 相对路径即可打开正文。

对照排候选，读卡内逐拍摆法、用料、局部采用条件和验证状态，再用读卡返回的 `preview_url` 连续观看原段和必要接点。整片组织要看完整原片。布局可暂停核对，速度、停顿和声画要看连续或带声片段。播放异常时记录受影响范围，处理后补看或改选，其他独立工作继续。只有摘要或旧版创意指令的卡可供研究，继续寻找有完整指令且适配的库内照排底稿。

**先看候选实际给了观众什么。** 找到愿意回看的时刻，指出前一拍让观众注意了什么，哪一个可见细节兑现或改变了预期。精彩处也可能来自稳定构图中人物、环境与文字的呼应，或动作方向恰好接上下一镜。沿观众的视线跟住素材，看文字、图形、遮挡或镜头怎样改变素材与其他对象的关系。优先比较几次变化各有作用、前一拍为后一拍铺垫的素材与动效混编原段。各种片型按实际画面判断。主要看点在控件反馈的片段可作局部动作参考。

**比较有竞争力的演法。** 分别说清各段最精彩的区别，以及会把本场带向什么感受。比较采用另一段时观众会少经历什么。候选带来了更贴合本片素材的表达时，可以更新原先设想，写清实际发现。若候选集中在相似页面和控件，检查查询是否提前规定了界面布局，再回到实际材料，从另一种动作、对照或镜头关系发起查询。整场组织仍然欠缺时，继续找完整场面，已找到的局部动作按实际用途保留。

**用本片素材验证看点。** 用同一批实料试摆有竞争力的原段，沿其实际占幅、取景和层次放入准确中文。靠动作与反应成立，就连看前后状态和停顿；靠多幅素材汇合成立，就看缩小、叠放后能否分别辨认；靠同一对象接力，就检查换景前后能否认回；靠文字和影像配合，就核对字组轮廓与落点。记录原片时刻、使用的文件或源段及实际观察。选换料后仍能呈现本场所需观看体验、视觉表现最有吸引力的一段。两段都适合时，再比较跨场接续与轻量美术适配。

**从看点反推入口，顺着变化找到出口。** 向前回看，找到观众形成预期、辨认主体或看清原有关系所需的起点。向后看到变化得到回应、结果有时间被看清或视线完成接手。试着从下一拍才开始、在上一拍就结束，判断是否仍能获得同样的感受或发现。逐拍对照卡的用料条件和本片实料，按原片源时间标出起止，保留必要的积累、停留或接手两侧。

**局部采用保住选中的理由。** 手头实料只能承担一部分时，单独连看这部分。若它仍能呈现选中它的观看体验，就采用该连续区间，说明入口已经能辨认什么、出口完成了什么、它负责本片哪一处。若截短后看点消失，按缺少的主体、取景、动作与持续时间补材，或改选适配的候选。只借一幅构图时明确标成构图参考，其他范围继续研究。

## 交回具体可用场面

交回每个采用区间的选段理由、最值得复核的原片时刻或连续范围，以及证明本片材料能承接的试摆。附原片入口、卡号、来源指纹、正文路径、实际观看方式和拟用于本片的位置，说明局部采用时的前后接点。尚在研究的参考标为 `study`。

按本片播放顺序交回各主要场面的卡号与正文路径、原片区间、完整演出、关键中途、素材承接条件和前后接点，列出仍待补查的场面。另交全片美术候选及跨场观察时刻。视觉作者亲看并验证素材承接，主导演依照整场对照结果确认采用。 使用[参考与素材迁移](../creative-reference-to-sequence/SKILL.md)进入同一份导演稿。
