# 创意参考检索与观看

## 整片视觉研究先于逐场查询

普通完整解说新片不得直接从单句旁白、单个素材或局部动作开始正式创意检索。

先读取：
- 完整文案及当前版本。
- 主导演提供的整片视觉导演基准。
- 全部代表性真实素材及可用源范围。
- 当前场面及其前后场关系。

先形成整片视觉研究底稿，明确：

1. 整片视觉语言和美术组织需要保持的主要特征。
2. 不同场面之间需要延续、变化、呼应或形成反差的视觉关系。
3. 哪些真实素材具有持续观看价值。
4. 哪些素材可以共同组织成完整画面。
5. 哪些主要场面需要完整创意参考改变原有画面组织。
6. 哪些具体运动关系需要动效机制辅助。

旁白用于定位内容、段落和场面，不要求逐句翻译成画面查询。

研究重心是如何组织真实素材，使画面更有构图、层次、运动、美术和节奏，而不是重新解释旁白。

整片视觉研究必须进入正式创意原稿，不能只在研究记录中填写 covered。

## 二、将整片研究转化为参考研究任务

根据整片视觉研究，形成需要解决的参考研究任务。

每项任务必须明确：
- 研究层次：整片视觉组织、完整场面演出或局部运动机制。
- 当前真实素材的组织状态。
- 希望参考改变的画面组织或视觉发展。
- 参考将影响的场面和相邻画面。
- 必须保持的真实素材主体及身份。
- 本次研究最终要形成的本片视觉结果。

整体视觉组织研究整片的构图、空间、素材组合、排印和美术语言。

完整场面研究从入口到出口的视觉发展，包括主体、布局、状态变化、画面接管、收束。

局部机制研究只解决已经成立的完整画面中的具体动作。

不同层次不能互相替代。

## 根据当前内容和材料写查询

查询必须从本片整片视觉组织需求出发。

去掉厂商、题材和专有名词，保留：
- 画面主体及其关系。
- 视觉中心怎样建立和改变。
- 多份素材怎样共同在场。
- 画面怎样从一种状态发展到另一种状态。
- 前一幅画面怎样影响后一幅。
- 结束时形成什么视觉状态。

不得将查询直接写成预设的窗口、卡片、左右分栏、列表或普通文字动画。

不得只查询某个窗口如何进入、某个文字如何渐显或某个镜头如何缩放，然后将局部结果当作完整创意。

局部动作查询只能补充已经成立的完整视觉设计。

首次在本任务参与创意研究时，按本人职责完成 [首次研究的原速对照](../creative-sequence-design/references/R40-机器人进厂/README.md#首次研究的原速对照)。已在角色入口完成的作者直接用本片材料查询。当前已锁定完整参考而本次只改素材时，读同版本片稿、原片及受影响的映射段。

## 取得并比较候选

使用现有 search_creative_cases 获取候选，按实际返回结果比较。

使用 read_creative_case 读取候选正文、原片入口和分镜。

通过案例库播放器原速观看候选实际采用段及必要前后文。

不得只依据卡片摘要、检索排名、关键词匹配或静态截图选片。

比较候选时，分别判断：
1. 是否提供整幅画面组织方法。
2. 是否提供完整连续场面演出。
3. 是否能够改变本片真实素材的组织方式。
4. 是否能与本片其他参考形成统一视觉语言。
5. 是否能够保持真实素材主体。

如果候选只能解决局部运动，将其保留为局部机制候选，继续寻找完整视觉参考。

拒绝某个候选不代表研究任务已经完成。必须继续解决当前尚未完成的视觉任务。

核对实际 MCP 工具定义。用当前项目的 `search_creative_cases` 提交自然语言 `query`。空查询用于浏览目录，已有编号用于精确定位。对从零选片，读回并比较实际语义候选后再定段。

返回语义任务时，通过 `track_job` 跟进原 `job_id`。任务完成后使用返回的 `readback.tool` 和 `readback.arguments` 读取候选页，再按 `next_offset` 继续。核对检索方式，确认为实际完成的 `semantic_used=true` 结果。主任务代为执行时，将当前页候选、分页信息和诊断交回原创意作者继续读卡、观看和比较。

遇到排队、失败或来源版本变化时按实际状态续查原任务，保留已取得且仍适用的候选。待语义结果实际返回再比较。来源过期时读新指纹和新正文，重新定位受影响的原片区间。

## 看过视频，再决定选哪一段

用 `read_creative_case` 读取候选 ID 与来源指纹对应的正文、原片入口和分镜。需要定位仓库卡时，从仓库根目录的 `references/motion-cases/skillry/creative-index.json` 取出该卡记录的 `card`，相对该索引所在目录定位正文。通过案例库播放器的 `preview_url` 原速连续看原片。研究整片时先看完整作品；借一段时从主体可被辨认之前看到结果交出；借动作时看发起、经过、落定及接回。声画共同起作用时打开原声，快动作需要辨认才慢放或逐帧。只看到构图就只记录构图，速度、声音和尚未辨清的遮挡回到对应时段补看。

拿同一批本片实料比较最有竞争力的候选。靠同一主体跨镜成立的，检查可辨特征；靠累积成立的，看新素材进入时早先的材料能否仍被认出；靠字与影像同场成立的，把准确中文放进目标画幅。向前找到看点如何建立，向后看到结果读清与接手完成。截取后看点消失，调整区间、补材或换候选。

正式采用的参考必须能够支持本片完整视觉单元的演出。

创意参考和动效机制参考可以组合。

多个参考分别说明：
- 设计职责。
- 原片范围。
- 本片对应画面。
- 对素材组织的改变。
- 与其他参考的连接关系。

一个完整参考可以覆盖多个连续场面；多个参考也可以共同构成整片视觉组织。

不得将多个局部机制的演示效果依次排列，冒充完整创意。

完成检索不代表完成迁移。正式交件必须继续使用完整参考迁移方法落实到本片真实素材。

把实际查询、卡或原片来源、实看起止、关键时刻、本片试用的文件和源段，以及选择或放弃的理由写入原研究。只作美术参考时标明色彩、字形或层级的用途。决定采用完整原段时，在本次研究里记下亲眼看到的入口、中途与出口，标出源时刻。创意作者试过本片源段后，把所借的关系和本片演法写入本片稿，逐拍制法见完整迁移专项。

交回每个采用区间的选段理由、最值得复核的原片时刻或连续范围，以及证明本片材料能承接的试摆。附原片入口、卡号、来源指纹、正文路径、实际观看方式和拟用于本片的位置，说明局部采用时的前后接点。尚在研究的参考标为 `study`。
