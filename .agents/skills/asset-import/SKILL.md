# 素材导入与候选判断

## 使用范围

用户提供本地视频、音频、图片或 Mask，或已明确要导入某个本地文件时使用。当前 MCP 只能导入本地路径，不负责联网搜索、下载外部素材或自动登记版权。

## 必须执行

1. 执行 `project-basics`，用 `browse_assets` 检查已有素材与来源哈希。
2. 使用 `import_media` 导入；不得直接写素材目录或 SQLite。
3. 用 `track_job` 等待媒体分析到确定状态，再读回 Asset、元数据、Revision 与失败原因。
4. 只有实际依赖的状态已就绪后，素材才能进入正式编辑；无音频视频可用，但不能用于转写。

## 专业判断

需要 B-roll 或空镜时，先写清用途、主体、动作、情绪、构图、画幅、时长与排除项，再比较候选的相关性、构图、动作衔接、情绪、技术质量和可用时长。

空镜必须承担地点建立、情绪呼吸、真实情境或遮盖必要切口等明确任务，不能只因文案出现一个名词就插入素材。

当前 Asset 没有持久化的版权字段。外部素材只能在用户提供本地文件和来源/授权说明后导入；授权未知时不得报告为可正式交付。

## 按需读取

- 候选需求与排序：`references/acquisition-and-ranking.md`。
- 来源、生成内容与权利边界：`references/provenance-and-rights.md`。
- 去重、就绪与派生任务失败：`references/readiness-and-deduplication.md`。

## 退出条件

受管路径、媒体元数据、处理状态和最新 Revision 可读回；未解决的来源或授权风险已明确记录。
