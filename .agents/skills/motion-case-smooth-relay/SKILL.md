# SIM 群体 → QCI 页面 → 时钟拨针：三段顺滑接力

## 1. 适用场景与表达目标

本案例用三种图形机制练习连续观看：九张 SIM 落在共同平面上，标签引导镜头靠近选中卡；术语、解释与纸页依次接管；同一钟体完成建立、翻面、向前拨针与回拨。标签、镜头和主体在前一动作收势时接上，必要阅读与方向确认则保留稳定。

适合诊断“动作完成了，却还在等下一段”的问题，也适合多段视觉内容的方向接力。三种题材在这里是独立的运动测试，不构成网络术语与时间制度之间的因果故事。新片应按当前讲解选择所需机制，不要求把三种题材全部拼入。

QCI 6、7、8、9 是演示标签，皇冠只标记选中对象 C，不表示真实网络编号的优先次序。自制页面明确标注演示，不提供技术配置或 QCI 到 5QI 的编号映射。时钟使用统一演示时间驱动两根指针，翻面是明确的状态切换。

本案例由 [remotion-production](../remotion-production/SKILL.md) 在构思或修订段落时调用。当前内容、真实旁白、画幅与前后画面由主工作流提供，本例帮助组织段内动作与段间衔接。

## 3. 具体美术设计，以及为什么这样设计

### 3.1 三段各自的材质与共同强调色

| 元素 | 本例的具体设计 | 设计作用 |
|---|---|---|
| SIM 舞台 | 灰绿连续平面，中心偏右亮；银灰卡面、暗金芯片，左上光与右下接触影。 | 先建立可信的物体与共同空间，为群体选择提供依据。 |
| 标签与皇冠 | 接近 `#1ff5a2` 的青绿，微倾斜、窄亮边与克制光晕。 | 标签跟随各卡，皇冠只突出 C；强调的是选择，不暗示编号排序。 |
| QCI 与释义 | 深墨绿底、极粗略斜的青绿主字，下接小一档英文和青绿底中文。 | 大字、英文、中文形成逐层理解，不让三行同样强。 |
| 演示纸页 | 暖白纸、深灰正文、窄投影与正式排版。 | 交代资料环境，随后降对比托住 5QI，保持空间持续。 |
| 时钟 | 浅蓝灰到暖灰粉背景，灰金属钟圈、灰紫浅表盘；翻面后暖铜钟圈。 | 通过同一钟体的材质换面表明状态变化，刻度与轴心维持识别。 |

共享的是青绿重音与克制材质，三段可以从暗产品舞台转向浅纸页和浅色时钟环境。每次转场检查亮度过渡，不能为了统一风格将所有主体压成同一种黑绿大字。

### 3.2 九张卡与跟随它们的标签

本例以 720×660、12:11 画幅设计。SIM 长宽比约 1.26:1，左上裁角，薄灰侧面，暗金接触面占正面中央；单卡未推进时可见宽约画宽 16%。卡面总体向后倾约 45—50 度，卡体、金面、投影和标签服从同一投影。

九卡疏密不均，固定布局如下；具体分区线与厚度写法见完整指令。

| 对象 | 落点（画幅宽高百分比）与转角 | 身份 |
|---|---|---|
| A、B | (24%, 28%)、-35 度；(49%, 28%)、+17 度 | 正面，无标签。 |
| C、D | (62%, 35%)、+30 度；(55%, 41%)、-34 度 | 分别为 QCI 6、QCI 7；C 是选中对象。 |
| E、F | (36%, 46%)、-34 度；(31%, 57%)、+16 度 | E 无标签，F 为 QCI 9。 |
| G、H、I | (65%, 66%)、-24 度；(77%, 68%)、-12 度；(54%, 76%)、+8 度 | G 是无芯片背面，H 为 QCI 8，I 无标签。 |

标签依次为 QCI 9→7→8→6，字高约画高 5%，从短距离上方下降并向右揭示。推进将群体整体放大至约 1.6 倍，把 C 送到中心稍偏右，边缘卡自然被裁切。青绿三尖小皇冠落在 QCI 6 上方，不能用巨大光爆遮住卡体。

### 3.3 术语、纸页与钟体的具体构图

QCI 段的 SIM 位于中央偏右，竖向、略左倾，底端出画；巨大 QCI 位于中下部偏左，宽约画宽 75%。英文“QoS Class Identifier”和中文“服务质量等级标识符”依次降低字号；主字的窄亮边保持轮廓，较弱光晕只辅助强调。一次短电子扫描可作为此例语气，严肃阅读题材可以省去。

三张暖白纸页叠放，中央页宽约画宽 76%、左倾约 4 度，左右露少量后页。主页面使用“网络术语视觉演示”“演示页面 · 非标准原文”及对象、演示标识、本例用途表格，具体全文在完整指令中。主要阅读页标题和演示标记，不要求逐行读完整张表。页面降对比后仍在原处，宽约画宽 80% 的 5QI 接管，右上小字解释“5G QoS 标识符”。

钟面占画高约 88%，中心约 (49%, 50%)，整体轻倾约 -10 度。深灰外侧、金属外圈、窄暗缝和浅灰紫表盘构成厚度，右下露侧边、左上有窄柔高光。十二数字、六十刻度、短宽时针、长窄分针与金属轴处于同一坐标系。翻面前标签“时间示意”、读数 6:10；侧面最窄处切为暖铜圈、“拨针演示”和 1:00，再顺时针快进到 3:00、逆时针回到 2:00。时分针由同一演示时间驱动，分针跨整圈累计角度，时针按比例连续移动。

## 4. 以秒表达的参考节奏、动作交叠与接续

**下表是首版节奏的参考用时，不是必须填满的时间槽。先据此完成设计和实现，再连续观看成片，按实际动作、阅读与前后衔接调整。**

多数用时针对单个动作；同段动作和两次段间转场都有意交叠，不能直接相加得到总长。阅读或运动距离改变后连同后续接点重排，不为赶回某个全局时刻而突然加速。

| 阶段 | 首版参考用时 | 具体动作与接续 |
|---|---|---|
| 九卡落下与压暗 | 落下约 0.65—0.85 秒；启动错开约 0.03—0.10 秒；压暗约 0.5—0.7 秒。 | 首帧已有卡和投影，下落加速，落地只作一次衰减回弹。最后几卡收势时压暗，仍保留物体层次。 |
| 标签、推进与皇冠 | 标签每项约 0.4—0.5 秒、启动间隔约 0.25—0.35 秒；推进约 2.0—2.5 秒；皇冠约 0.35—0.5 秒。 | 第二个标签刚建立，镜头已靠近 C；推进最后约 0.7 秒皇冠接入，皇冠与 QCI 6 清楚约 0.45—0.65 秒后转场。 |
| 第一次横移 | 约 0.65—0.8 秒。 | 旧片向左，新片从右进入；QCI 段主体在进入期间已动作，不重复播放静止开头。 |
| SIM 到 QCI 与释义 | SIM 进入约 1.2—1.5 秒；主字约 0.6 秒；中英文各约 0.3—0.4 秒；完整后阅读约 0.8—1.0 秒。 | SIM 入场后半程主字建立，英文接主字收势，中文约晚 0.25 秒。可选扫描仅约 0.15—0.25 秒且只做一次。 |
| 页面接管与认识 | 进入约 0.9—1.2 秒；进入后约 0.4—0.6 秒开始轻微靠近；标题与标记可读约 0.8 秒。 | 旧对象与释义向左退，纸页同进度从右接上。页面已被认识后开始退暗，不强迫读全部小字。 |
| 页面退暗、5QI 建立 | 退暗约 0.6—0.8 秒；主字约 0.6—0.8 秒；释义约 0.35 秒；可读后约 0.7—1.0 秒。 | 退暗一半时 5QI 已起势，释义在主字收势时接入；读清后启动第二次横移。 |
| 第二次横移、钟体建立 | 横移约 0.65—0.8 秒；钟体展开约 1.0—1.2 秒。 | 时钟在转场中从侧视展开，中心与纵向尺寸连续；主要构图成立后即开始翻面。 |
| 同钟翻面、向前拨针 | 翻面约 1.0—1.2 秒；向前拨针约 1.7—2.1 秒。 | 最窄侧面换配色、标签与读数；翻面结束前约 0.1—0.2 秒拨针已启动，连续由 1:00 到 3:00。 |
| 方向确认、回拨与结束 | 方向确认约 0.2—0.3 秒；回拨约 1.1—1.4 秒；最终读数确认约 0.6—0.8 秒。 | 读清拨快方向再逆转，同步回到 2:00，确认后自然结束。已读清可缩短余量，不删掉必要方向停顿。 |

两次横移是整幅画面的方向接力与短暂混合，不是卡片变字母、字母变时钟。每段保留自身局部时间；代码以当前秒数和 fps 换算事件帧，合成总长扣除实际交叠，不重复添加转场时长。渲染前确定总帧数，预览后可重排并生成修订版。

正常播放若出现“前一动作完成、没有阅读、后一动作未起”的空窗，提前对应镜头或主体；释义读不清则先改善字号与层级，再延长对应可读段。避免所有动作统一倍速或全程微动。已有旁白或用户锁定总长时，通过内部编排、覆盖及后续画面承接，不能自行改短声音或整片。

## 5. 换内容时保留什么、重新设计什么

| 设计层面 | 可以保留的方法 | 需要按当前内容重做 |
|---|---|---|
| 观看任务 | 标签引导推进、页面解释术语、同一物体呈现状态改变。 | 当前段落的因果与讲解顺序，不硬拼网络与钟表。 |
| 主体与美术 | 固定身份、共同投影、不同尺度与材质的主次变化。 | 卡片或其它物体、标签、配色、轮廓、光向和画幅布局。 |
| 段内动作 | 标签未全完镜头已推进，主字收势接释义，翻面收尾接拨针。 | 当前距离、运动体量、读数及局部参考秒数。 |
| 段间接续 | 旧画面退出时新主体已动作，分段时间明确。 | 是否需要转场、方向、交叠范围及前后亮度，不固定套用历史 0.8 秒。 |
| 事实与阅读 | 示意与证据区分，文字清楚后才计有效阅读。 | 真实标准来源、术语、编号含义、单位及严格时间关系。 |
| 合成 | 整段回到前后声画关系中检查。 | 当前人物、字幕、旁白、声音事件与交付规格。 |

例如讲软件流程，可借“对象建立—术语说明—界面状态变化”的接力，重做真实界面和术语；不必保留九张卡、青绿字或钟表。只修一段落卡空等时，采用标签与推进交叠即可，不附加另外两段。

独立指令的近方形画幅与无声输出属于示例。数字人同屏时依据实际人物与字幕重新分配空间；需要全屏接管时接好前后讲解。声音可强调落点、转场或反转中的必要事件，不在每个标签与每根指针经过刻度时机械叠音效。

## 6. 如何根据实际成片检查和调整

先看[SIM 中段](assets/preview-090.png)、[第一次交叠](assets/preview-170.png)、[QCI 后段](assets/preview-330.png)、[时钟段](assets/preview-475.png)建立关键构图预期，再用当前事件帧检查新作品。正常速度连续观看各段及转场，不能只核对终点。

| 检查位置 | 应看到的结果 | 不成立时怎样修正 |
|---|---|---|
| 九卡到标签与推进 | 卡体、影子、标签一起靠近，皇冠属于 C。 | 修正固定身份、共享焦点与投影，调整标签和推进接点。 |
| QCI 到纸页 | 中英文已读清，旧画面退出时纸页已在进入。 | 先解决释义排版与阅读，再调整共同横移，避免先清屏。 |
| 纸页退暗到 5QI | 页面仍可识别但不抢字，释义接着主字收势。 | 分开背景退让和主字对比，提前合适起势或补必要阅读。 |
| 钟体翻面到拨针 | 同一轴心，侧面换状态，展开后文字正常，两针按同一时间前进。 | 校正中心、侧边、内容切换与累计角度，避免镜像、跳针及每圈重启缓动。 |
| 拨快到回拨 | 方向反转清楚，最终共同指向 2:00。 | 保留方向确认短停，校正时分联动，删除读数确认后的空尾。 |
| 两次横移与整段出口 | 新段在转场内已起势，无空底、亮度闪跳或重复开头。 | 校正局部时间、交叠计算和入出画速度，按实际读数与下一画面确定出口。 |

历史对照中，SIM 推进由 181—201 帧改为 60—170，皇冠由 204—216 改为 135—155；QCI 主字由 62—80 改为 30—57，页面由 130—153 改为 92—130，页面退暗 148—175 与下一术语 160—192 交叠；时钟翻面由 129—158 改为 40—80，拨快 75—132 接上翻面，回拨 140—181 前保留 8 帧方向确认。它们是源码定位证据，说明局部重新编排的作用，不能抄作所有作品的标准区间。

历史 SIM 曾改用显式 SVG 投影以处理同帧像素漂移；QCI 的短扫描是设计效果，时钟的方向短停是阅读任务。这些与无用途等待需分别诊断，详见[停顿、掉帧与确定性](../motion-case-library/references/timing-continuity.md)。既有沙箱与重复帧记录不代表新画幅、字体和合成自动通过。

把作品放入真实剪辑，连同前一句、完整动效、后一句及声音检查。需要合成判断的部分先通过既有待审草稿取得证据；区分设计主次、代码实现和人物字幕干扰的原因再修正。将当前完整指令、作品与放置版本、局部事件和全局交叠、实际观察及待处理问题交回 [remotion-production](../remotion-production/SKILL.md) 与主工作流，继续原剪辑任务。
