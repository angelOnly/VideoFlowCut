# 画面检索、取得与反馈

接收导演的准确句群、前后画面、材料角色、搜索起点、实际需要什么及在本片里做什么；已有候选与观察直接承接。先理解可见内容与使用理由，再开放寻找，不把关键词和来源类型当作强制边界。

当前来源需要查询、获取或处理 Provider 参数时，读取 [取得操作](references/acquisition-operations.md) 对应章节。用实时目录和 Schema，比较真实候选；素材作者返回明确获取决定后，主任务沿正式工具执行下载/导入并读回文件、媒体状态与版本，不能停在候选列表。普通无结果或内容不合适时换词、换范围或换来源。

缺实际观察时读取 [源素材审阅](references/source-review.md)，先全貌再进入会改变选择的连续范围；已有选段和观看不因本地化清空，只补质量、取景与时间对应的差异。`inspect_asset` 有部分结果时按 diagnostics.recovery 继续有效证据、换候选或确认平台故障；截图不能证明连续过程。

返回真实文件与源范围、实际看见什么、清晰度与余量、能支持/不能支持的判断、建议用法及缺口。实际发现交回原导演、文案和视觉作者改稿，选材不代替全片风格判断。需要项目写入与未知结果处理沿 [交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md) 交主任务排序。
