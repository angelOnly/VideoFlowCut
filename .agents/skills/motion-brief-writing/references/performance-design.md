# 连续演出：关键中途、动作关系与返修

本页服务已经确定的视觉导演方案与时间编排，深化关键中途、对象响应、速度、依赖和接续；不重新发明或静默替换本片主创意。

本页供制作作者处理首次呈现、关键中途、接点、速度与返修；视觉负责人用它诊断实际作品。依据[整场美术方法](../../visual-treatment-planning/references/art-direction.md#默认设计与整场发展)、采用参考和真实素材选择做法。

## 1. 变化表达什么，什么继续存在

从当前完整观看稿确定主行为：它由哪个实际对象承担，改变什么理解、关注或感受，前后的内容为何相接。材料自身已经有表现力的过程继续使用，额外机制围绕它组织，不用低信息图标替掉可观看材料。

将内容身份、准确文字、部件归属和必要比较依据，与可以变化的距离、姿态、层级及可见范围分开。前者在演出中可追踪，后者用于推动观察和注意。图解中的形式变化不暗示来源没有的事实或物理因果。

读取当前制作简报，并观看所选参考的完整范围。看清这一段从什么画面开始，经过哪些主要变化，哪些动作同时发生，在哪里停稳，最后怎样进入下一段。

将这些过程落实到本片实际素材、文字、图形和背景。从第一版连续作品开始，实现主要对象之间的共同变化。

素材改变大小和位置时，文字、背景、遮挡层与镜头按编排一起响应。前一动作留下的对象和空间继续参与后续动作，视频源时间按实际绑定推进。

对照参考查看运动中途。检查关键对象经过哪里、何时遮挡或显露、何时取得注意，以及画面如何从一个构图变成下一个构图。

对应素材取得并查看后再制作相关范围。素材或源范围改变时，重新核对取景、文字、动作和声音。尚缺运动或连接做法时，由视觉负责人沿[机制入口](../../motion-case-library/SKILL.md)继续查找。

## 2. 先定入口与目标，再设计最危险的中途

先明确入口已有的对象和关系，以及目标状态中新主体与必读内容怎样共场。场景首次呈现可以承接已经建立的空间，也可以逐步显露主体；首次呈现与后续变化共同设计。两端的字形或构图不成立时，连同主要动作一起修改，不让组件挂载替作者决定所有元素同时出现。

接着找最容易丢失主次的时刻：新旧并存、遮挡刚解除、结果开始响应、前景替身接管，或文字第一次能读清。关键中途不一定在时间的50%，也不能由两端位置自动插值代替。

用连续正文交清这个时刻的实际状态：

- 谁仍在场，身份、源过程和比较参照怎样延续；
- 位置、轴心、姿态与投影面积，哪段路径经过画面边缘；
- 谁挡住谁，遮挡解除到什么程度，哪些字此时可见；
- 第一关注是谁，旧重点让出多少对比和面积，附属层怎样支持；
- 速度正在起势、通过、减速、收稳还是穿出；
- 当前声音和源内动作怎样继续，新内容是否已到达所需可读条件。

这些是解决中途问题的观察角度，不要求每镜六栏表。大位移中可暂不摊开小字，到有效投影和字幅后再读；阅读来不及时先改字量、面积、显露与交接，而非把所有动作放慢。

对照过程动词核对对象：移动要抵达接收位置，揭示要通过遮挡解除或观察位置变化，比较要保留共同参照，回收要处理先前对象。粗稿中就实现这些主要过程，次要纹理可稍后精修，静态卡加旁白不能证明连续关系已经成立。

## 3. 连接状态：路径、速度与对象依赖

绘制组件定义对象长什么样；场面逻辑决定对象何时出现、沿什么路径改变、谁跟随、何时反馈、何时让位和怎样接下段。先把本段采用的关键关系分别落到可控制的对象状态，再决定共享哪些组件。主对象与字、影子、承托等附属层依据归属共同变化；需要错峰或抵达反馈的对象保留各自时机，不用一个统一入场进度代替整段过程。

一次观察变化可以共同驱动材料面积、字组位置和解释空间，同时保留对象内部的局部动作。每个动作的结果成为后续状态的依据。素材源时间独立求值，技术块之间沿用连续场面时间。粗排中已经要发生这些关系，细节可继续精修。

明确发起、跟随、显露和接管的对象，再划分共同父层与局部控制。主体改变面积或观察位置时，背景、材料与文字共同响应。文字、图案、边缘和影子随所属对象计算；场面层负责整体观察，对象层负责自身运动，局部层负责显露。同一属性的贡献与计算顺序清楚，前一动作留下的状态能够被后一动作继续使用。

路径落实到接收位置、经过区域、轴心、姿态与投影面积。不同对象依据路程、分量和观看作用安排启动、发力与收势。主体与附属层通过延迟、幅度和速度差形成层次，运动方向与对象归属保持可追踪。

连续过程在阅读处收稳，在通过处保留运动。位置连续与速度连续分别核对；动作结束后留下的对象、空间、比较参照或结果，成为后续演出的实际起点。空间、曲线及源坐标的具体计算沿[素材坐标与时间](../../opendesign-video-production/references/material-space-and-time.md)。

场间切换依据参考和内容选择直接切换、交叠或连续动作，安排前后观看关系。

持续对象跨层或跨作品时，在接管区保持身份、内容、位置、尺度、朝向和源时刻一致；遮挡、字位和视点变化在同一过程中完成。转换到不同观看任务时，也须设计完整的进入与接管。

真实视频独立计算源时间。同源分区使用同一源状态，外框移动、局部 Sequence 或拆件不使素材从头播放。没有可靠跟踪或可分离条件时，调整实际范围或表达，不伪称能力；时钟或定位错误直接修对应实现。

### 按当前对象和作用设计动作性格

依据参考各段的相对用时、运动行程、速度变化、交叠和停顿安排本片节奏。

需要准备的动作先建立预期，需要发力的动作通过速度、尺度或姿态形成明确变化，到达后按参考完成制动、惯性和收势。各阶段是否出现及其力度，由采用过程和对象特点决定。

主体、文字、背景和附属对象按各自作用运动、保持或响应。直接切换、短促动作、交叠、稳定阅读和停顿按参考与当前内容使用。

根据实际配音校准重点出现和读清的时刻。调整启动位置、动作交叠、文字数量和阅读面积时，保留参考中有作用的快慢对比。

一个参考动作已经完成而旁白仍在继续时，由创意与视觉安排后续素材和场面发展。禁止为填满旁白时间而统一拉慢短促过程、重复同一个演示，或用无用途的微动补时。

运动偏弱时，核对行程、加减速、姿态变化和收势。节奏拖慢时，核对重复等待、动作持续时间与后续内容安排。画面拥挤时，调整主次、错开时机和遮挡关系。

普通字幕由独立字幕层执行统一规范。画内文字随当前场面共同编排。

## 4. 从可辨、可读时刻反推声画交接

先依据实际句群或源事件，确定新重点何时可辨、何时必须读清，再反推启动、旧重点退让、内部显露和收势。动作收势可以与阅读交叠，前一重点仍有参照作用时，后一重点可以开始建立。

叠字或拥挤时，先调整对象归属、面积、对比、遮挡与可见区间。需要清场或停顿时，完成相应退出与后续接入，保持准确内容、比较依据和注意关系。

### 补充约束

直接切换、交叠和连续动作按参考与内容选择。

用实际动作和连续观看判断所选效果，参考的关键过程要得到完整实现。

按参考与内容安排对象动作、稳定阅读和停顿。

初稿时间尺度、声音校准和锁定边界按[时机方法](../../effect-timing/SKILL.md#初始节奏与预览修订)执行。

真实声音到达，或正文、语速、停顿与总时长改变后，先重新定位语义落点，检查启动、可辨、读清、回应及前后接管是否仍成立，再按 fps 落帧。只更新段长、统一压缩动画或沿用每段相同比例，不算完成校准；需要时调整动作先后、交叠、阅读面积或连续范围，主要讲述关系改变则回导演与文案。句级证据只支持句级设计，不按字数均分制造词时间。有效阅读、锁定时长与空等处理沿[时机方法](../../effect-timing/SKILL.md#初始节奏与预览修订)。

讲述句群、字幕卡、视觉场面和技术作品是不同单位。一段自然语音可有多张短卡，同一对象可跨句；问题、标签与普通字幕各按作用保持，不同时清空。单行字幕不要求切碎配音、挤字或隐藏内容。动态画内文字在作品内，普通字幕沿 Caption 链，在同一合成里检查。

声音可以预示下一处观察、与动作共同落定、事后回应或保持空间；不必每个运动元素都有独立音效。依赖声音的关键粗稿应有可试听候选。把要同步的动作命名，动画与事件共用当前时序；区分相对视觉的感知偏移、音源内部起音与主攻击，具体换算见[事件与声音绑定](../../effect-timing/references/event-and-audio-binding.md)。

动作收势可与阅读交叠，稳定窗口内源动作也可继续。停留有阅读、比较、反应、情绪或材料欣赏用途就保留；背景粒子或持续漂浮不能替没有发展的第一重点辩护。

短源片可以与前置建立、明确回看、细节解析和接续组成更长段落，新增时间须有观看内容。真实定格使用可追溯且正式登记的源静帧，原创图形可以直接保持状态；回放标清观察用途，不制造第二次事件或自动重复原语音。不冻结、循环、统一变速补满长度。

## 5. 在实际产物中观察并返修

沿[OpenDesign观察与返修](../../opendesign-video-production/SKILL.md#观察与返修)交回实际作品，由视觉与创意对照参考查看。

先看整幅画面和连续变化，核对选中的素材组合、文字动作、背景配合、主要运动和前后连接。参考中需要完成的过程，逐处与本片对应范围比较。

反馈写清实际作品范围、看到的画面、缺失或变弱的表现，以及需要重新安排的过程。制作作者沿同一作品修改，修订后重新查看相同范围和相邻连接。

需要改变选中场面的主要表现时，由创意与视觉共同更新编排。涉及事实、正文和跨段关系的变化交导演协调。实际观察方法、范围与仍待确认的内容照实记录。

| 实际问题 | 优先检查和修改 |
|---|---|
| 主体弱、像等权表格 | 标题是否挤小主体，轮廓、面积、字级与对比是否等权 |
| 两幅画面互不相干 | 对象归属、共同空间、比较尺度与前后参照 |
| 中途拥挤但终帧好看 | 风险中途的投影面积、可见文字、遮挡和主次 |
| 动得顺却发飘 | 发起与跟随关系、姿态变化、加减速分布及收势 |
| 新重点太晚 | 建立、可读与语言的关系，动作先后与交叠 |
| 过冲消失、对象突然停住 | 位置和尺度不要共用裁到 0～1 的透明度进度；连续通过处检查速度 |
| 字或影子落在原地、两种运动相互覆盖 | 修父子归属与局部偏移，分层变换或统一求值，避免 transform 被覆盖 |
| 进入或退出被截断 | 检查挂载窗口、局部时间与交叠，不让文件结尾裁掉动作 |
| 动作后长时间只换字幕 | 查讲述重复、材料乏味或缺后续发展，再改稿、补材或改演出 |
| 薄物像厚块 | 厚度、间隔、边缘与接触影 |
| 源内容跳位或重播 | 父子变换、真实源时钟与拆件映射 |
| 设计照做仍平淡 | 回到观看过程、美术和演出；改变主线时交导演 |
| 稿具体而画面漏层或错裁 | 修源码与绑定，不删除原设计来补写合格依据 |

编排、实现和预览中都可返修：正文准确但不好讲、太密或抢在观察前说完，交原文案与导演改准确句群；缺可剪选择交原素材作者；设计忠实实现仍平淡就改演出；设计明确但遗漏进入、惯性或退出则修源码。不以已经配音拒绝改稿，也不因普通背景换用连带无关文字。原作者交实际修改后，按真实依赖更新声音、字幕、绑定与时序，复看相关范围和接点。静帧不能证明速度、惯性和听感，未知如实保留。

交回同版实际画面与源码、必要参数和素材/字体/声音引用、修改影响与待核范围，并说明哪项观看关系实际发生了改变。首次主要表达及主要对象、事实或跨段关系改变沿[共享交接](../../_shared/PROJECT_REVISION_AND_HANDOFF.md)回导演，纯视觉选择与局部演出由原视觉作者继续；提交、Job 与版本恢复不在本页重复。

## 按需分支：非球体接触、衰减与积累

只有场面需要可信接触或堆积时读本节。对象有长度或不对称轮廓时，先判断哪一端、边或面接触承载面，再决定转动与反弹。接触点、姿态、投影和阴影一起核对，不能当成圆点做等幅直上直下弹跳。

弹起、翻滚与滑动逐渐损失能量。不同初始姿态和接触产生不同收势；落稳对象持续存在，后续对象与它形成可信遮挡、接触和局部堆积。新增对象停下时，空中的对象仍应完成运动，余下滚动逐渐收束，不能突然删物或一帧全定住。

是否需要完整物理模拟取决于表现，简单可控轨迹也可成立。渲染必须支持任意帧重建，固定种子只固定初值，不能修复依赖上一播放帧的模拟；按时间求值或预计算状态的实现与乱序取帧验证见[确定性合同](../../opendesign-video-production/references/hyperframes-contract.md#随机与碰撞的任意帧重建)。数学一致仍需观察接触、遮挡和收势。
