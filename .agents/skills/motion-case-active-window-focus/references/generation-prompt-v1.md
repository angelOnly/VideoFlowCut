# 活动视窗展开与主体聚焦：参考生成说明

根据当前主题选择一段具有实际动作的现实材料，并确定最终要关注的对象。对象可以来自实拍、照片或原创绘制；当前内容若不需要并置，不强行使用多窗口。

入口以一幅有明确主角的画面开始。随后让裁切边缘在画面内移动，露出另一个实际观察区。窗口内视频继续其真实源过程，窗口动画只改变可见范围与空间。使用同一源的多个裁切时保持源时刻一致，并在制作记录说明它们不是独立事件。

将窗口排成有秩序的疏密关系：一个主要窗口与若干较弱侧窗共享基线或方向，顶部或纵向位置有克制错位。主要窗口取得较亮、较清楚的视觉区域。并置建立后，直接进入聚焦，不让一个没有阅读或表演任务的中央模型空驻留。

聚焦不是全组统一放大。主窗口增加宽度、靠近观看位置，侧窗收窄、走向边缘或从其后滑开；近处位移大于远处，形成前后关系。根据当前画幅先以主窗口占有效画宽约半幅至四分之三试排，再用实际主体投影修正，避免只改变空容器宽度。

原创对象与真实素材共处时，先绘制其清楚轮廓、关键细节、侧边和与环境一致的受光，屏幕里只保留本片需要的界面。制作身份说明属于合成语境或记录，不印到设备正文里。真实素材已有可用动作时，让它承担生活感而不是仅作为背景纹理。

主对象认清后，出口交给下一动作：可以让出文字、进入局部、选中真实结果或直接切入另一视角。写清出口投影与源时刻，下一动作可在聚焦收势中进入。时间按实际观看、语言和动作决定，不复制示例秒数。

检查分界移动中主体是否仍可认、源视频是否重播、侧窗是否无意义复制、主对象是否在任务结束后等待、关键文字是否被挤进空位。输出当前场面源码、绑定、命名事件和实际检查结果。
