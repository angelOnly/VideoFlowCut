# 一张为固定工作设计的工位

项目 [1815,2192)，旁白 12–13。选 Universal Robots Robotiq asset_85a895b9-1181-48fe-80c9-a7817ae66896 及 SCAPE asset_85d20053-466f-4751-a404-a41b97d59589。F1815 先看 Robotiq 源约 [12500,18700) ms 的整台蓝关节机械臂、箱和旁边专门的接收治具，不截掉底座。F1889 后用真实源约 [30000,40000) ms 的夹具、接触和落位近景，从可见部件推回固定布局。动作关系补 SCAPE 源 [33000,47000) ms 中同一机位连续跨箱抓放，设备主体和底座保留。左侧落位区和右侧进料区要在影像里同时看见，短字依“固定进料位”“抓取”“接收治具”出现，最多同时保留与动作相关的一组。不要以两套供应商画面拼成同一装置。到“又快又稳”留一个真实重复动作的终点，由工位边缘的横线接往 Atlas 能在通行空间移动。参考实料帧见 ur-kit-sheet.jpg 和 ur-scape-sheet.jpg。

## 同版冻结实料时序

按实际视觉采用的下列镜头边界实施，前述较宽区间用于说明连续原源。

- F1815–1889，源 38600–41067 毫秒，asset_85d20053-466f-4751-a404-a41b97d59589。物料入口、两个箱和夹具建立。纵向裁取 y≤790 的上区，底部英文不能进入成片。
- F1889–1933，源 19000–20467 毫秒，asset_85a895b9-1181-48fe-80c9-a7817ae66896。干净工位全景看机械臂、铝架和正在放件的工装。
- F1933–2009，源 20540–23073 毫秒，asset_85a895b9-1181-48fe-80c9-a7817ae66896。转近传感器和固定架，只取源画左与中部，原右上英文不入构图。
- F2009–2104，源 30000–33167 毫秒，asset_85a895b9-1181-48fe-80c9-a7817ae66896。吸盘竖杆细节取原片 x约160–820，呈独立窄区，不带右侧广告。
- F2104–2192，源 36000–38933 毫秒，asset_85a895b9-1181-48fe-80c9-a7817ae66896。右半工装接住放件源动作，在裁清左面宣传字后，让定位板三个工件槽足以辨认。
