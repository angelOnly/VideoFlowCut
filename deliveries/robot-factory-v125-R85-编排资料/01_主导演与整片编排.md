# 主导演与整片编排

本文件根据[已采用视觉导演稿](制作记录/视觉导演稿.md)、[时间计划](制作记录/时间计划.md)和[实际决策记录](证据/创意与导演决策.json)整理。带引号的决策为留档原文，其余是按交件归纳，不假装是未留存的角色心理或对话。

## 1. 影片任务与主导演主线

- 标题：机器人都能后空翻了，为啥不能进工厂？
- 样式：横屏 1920×1080、30fps，纯解说，真实素材为视觉主体；没有真人或数字人口播。
- 保留用户文案的逻辑：单次 99%、各次独立，连续 100 次全部成功约为 37%；接着解释生产稳定、出错恢复、人工干预，再对比固定机械臂与人形机器人。
- 已留档主线：“实验室机器人后空翻 → 明确假设条件下的连续成功概率 → 工厂现实中稳定和异常处理 → 固定机械臂及工位 → 人形机器人利用现有环境的潜力。”
- 真实来源各异，不能将它们剪成同一个工厂或一段真实故障。37% 是按给定条件计算，不是任何画中机器人或产线的实测；人形机器人的未来能力保留可能性语气。

这条主线的观看组织是：先让后空翻动作吸引注意，再让概率问题和工厂影像共同承担解释；之后用不同现场承接“恢复、人工处理、稳定”，以固定工位作对照，最后让人形机器人画面接过主要视线。导演稿要求不同现场之间保持可辨边界。

## 4. 导演给下游的关键约束

1. 空翻是真实动作，不把数字标在机器人身上冒充实测；假设条件必须可读。
2. 真实素材及工位要能看清，字幕底部留约 180 像素；画面与图形一起组织，不只把视频放进背景卡片。
3. 130 的关系必须保留“旧主体仍在 → 新画面独立出现并保持 → 推进 → 新主体接管”。细节可深化，若需改变主体或这一关系应反馈视觉作者；涉及事实或跨段关系再由导演协调。
4. 134 借鉴的是影像、条件和数字的整体主次；没有核实的原片入场运动由本片自行设计。
5. 声音、普通字幕和播放预览走已有工作台；源码本身不包含最后合成的旁白、音乐和字幕。

创意如何进入视觉稿，以及这些边界后来有没有变成 OD 的具体动作，见[下一份说明](02_创意作者到视觉作者的迁移链.md)和[制作返修说明](03_视觉到OD的制作与返修.md)。
