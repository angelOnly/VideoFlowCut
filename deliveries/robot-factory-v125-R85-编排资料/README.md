## 阅读证据时请注意

“原始记录”表示可找到本片留下的决策、交件或会话；“整理出的编排思路”是按这些材料归纳，不冒充作者未公开的内心思维。创意作者与视觉作者之间的逐字对话未在可用记录中找到；现有证据能追到决策、输入依赖和正式交接，不能补造对话。

参考研究有观察边界：130 顺序检查过 120 帧但未听审，不能等同连续原速声画观看；134 是离散状态观察，入场运动及声音未核实。已生成的 R85 成片经过技术检查和有限的抽帧检查；整片连续声画听审、参考迁移对照及独立复审仍未完成，因此不能写成已通过最终审片。

素材及参考文件均保存在本目录下，文档链接使用相对路径；公开来源的原始地址以文本保存在 [来源地址记录](素材原始来源地址.txt) 和各参考目录中，不是播放所需依赖。
