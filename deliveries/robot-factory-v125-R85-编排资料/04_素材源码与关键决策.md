这份 HTML 是交给 VideoFlowCut 的 managed-hyperframes-4 受管源码，使用视频槽、字体槽和 GSAP；不是双击即可离线完整播放的独立网页。实际预览需要对应 VideoFlowCut 运行时注入视频帧、时间轴和字体，旁白、普通字幕及 BGM 再由项目轨道合成。仅有 HTML 不能还原最终视频；最终视频可直接播放。

作者清单中的视频槽可通过上方素材 ID 对照本目录文件；同一源可能使用多次：yellowA / yellowB 均指黄色机械臂，humanoidA / humanoidB 均指人形机器人。所有源时间和项目帧在作者清单内。字体绑定为 noto-sans-sc-bold 和 noto-sans-sc-regular，本次目录没有单独打包字体或运行时，不能声称该目录已经是可独立导入、重建的完整工程。

## 4. 关键决策清单

| 决策 | 作用和原因 | 可核查材料 |
|---|---|---|
| 保留用户文案及 99%、独立、100 次、约 37% 的前提 | 概率是条件计算，不误写成画面实测 | [导演稿](制作记录/视觉导演稿.md) |
| 真实素材主体、现场身份分开 | 空翻、汽车产线和不同工位各自表达，不拼成一次事故 | [场面交接](证据/视觉交接片段.json) |
| 130-c01 采用一轮接管 | 通过黄臂保持、新画面建立及保持、推进、人形接管建立两种工作环境的关系 | [迁移链说明](02_创意作者到视觉作者的迁移链.md) |
| 134-c02 采用影像与数字整体构图 | 用运动的真实影像、条件与数字共同承载假设概率 | [创意决策](证据/创意与导演决策.json) |
| 032-m09 研究后不采用 | 手机框、扫描和结果 UI 与本片不匹配，且未完整核实速度和音频 | [机制卡](参考原片/032/mechanisms/m09.md) |
| OD 直接制作首版，先提交连续前段 | 把导演稿和参考关系直接落实到可播放可返修的作品 | [首版委托](制作记录/OD首版与返修原始记录.md) |
| 对 R76 调整结果时机和整体构图 | 37% 不提前泄露；100 次、条件、影像在讲述中重新组织 | [两条返修原文](制作记录/OD首版与返修原始记录.md) |
| 服务重启后在同一作品续制 | 延续已冻结首段及有效草稿，修首段、补足后段；失败运行不冒充完成 | [续制消息](制作记录/OD首版与返修原始记录.md) |
| 画面与声音、字幕分轨 | 避免重复嵌字幕，继续使用工作台已有的合成与预览 | [时间线](证据/R85时间线与字幕.json) |

- R83 抽看过 F245、F300、F1105、F1130、F1462；R85 视觉作者实际看过 F245。另归档了 [13 张 R83 源码技术检查帧](证据/源码技术检查帧/)及[检查摘要](证据/R83源码检查摘要.json)，这些帧用于确定性检查，并非完整合成播放或创意验收；以上都不等于连续观看整片。
- 原片 130 与 134 未完成同期听审；130 为顺序抽帧检查，134 为离散抽样。R85 尚缺两条参考的成片对照、整片连续声画听感复核，以及创意、视觉、导演的新一轮独立完整复审。
