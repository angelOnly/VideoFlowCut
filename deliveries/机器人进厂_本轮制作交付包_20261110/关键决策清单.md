# 关键决策与边界

| 决策 | 原因与执行要求 | 证据或状态 |
|---|---|---|
| 全新横屏纯解说，保留全文顺序 | 以观众理解为主，无真人出镜口播。 | 用户本轮要求与[视觉简报](原始视觉简报.md)。 |
| 先动作，后工作，再回到下一件 | 用可见的动作和日常变化回答长期稳定性，而非将难点停留在炫技。 | [导演与各作者编排](导演与各作者编排.md)。 |
| 实拍和假设工位明确分开 | Atlas、Canon、焊装和 Digit 来自不同来源；不得剪成同一台机器人在同一工位的纪实。 | [素材与来源](资料来源说明.md)。 |
| Canon 是固定臂吸头取件 | 真实片段仅作乱序取件参照；碰滑、重抓和转正为示意。 | [制作请求](原始视觉制作请求.md)。 |
| 使用单一目标件及箱体 | 利用空间与接触连续性让观众跟踪从变化到恢复；零件未抬起不穿过箱体。 | [制作请求](原始视觉制作请求.md)。 |
| 概率公式保留条件 | 仅当每次成功率 99%、各次独立时，0.99¹⁰⁰≈36.6%，是全部 100 次都成功的概率，不是实测表现或成功 37 次。 | [视觉简报](原始视觉简报.md)。 |
| 不虚构故障数字 | 自动恢复及人工介入是可能路径，不给缺乏证据的损失或干预率。 | [视觉简报](原始视觉简报.md)。 |
| 尊重成熟固定机械臂 | 焊装画面承担固定流程示例，不说成落后或实拍抓取。 | [视觉简报](原始视觉简报.md)。 |
| 人形的通用性仍待验证 | 换岗训练、续航、维护、停机均是实际成本；不能把潜力当既有普遍能力。 | [视觉简报](原始视觉简报.md)。 |
| Digit 超过十万是企业报告的累计量 | 不推断单台、成功率、无人工干预；正文来源快照未取得。 | [资料来源说明](资料来源说明.md)。 |
| 参考迁移组织方式，不照搬数据 | 局部拉远、锚点转场和数量到比例的方式服务本片语义。 | [导演与各作者编排](导演与各作者编排.md)。 |
| 23 段配音使用段级真实时钟 | 段级对齐不等于逐词或接触瞬间精确；字幕和声音独立于动效源码。 | [时间计划](原始时间计划.md)。 |
| 不把阶段检查当成成片验收 | 抽帧、冻结源码、全片渲染、连续试听和用户定稿属于不同结果。 | 本包记录最终实际检查范围。 |
