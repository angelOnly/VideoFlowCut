# 机器人进工厂：首版视觉导演稿

## 当前范围与交件
本稿覆盖用户锁定的四段正文，横屏 1920×1080、25 fps；从零作品开始，根帧 [0,637)，首版由 OD 制作。真实配音长 25.470 秒，结尾 10 毫秒为整帧取整，不改变语速；完整句段与来源见时间计划。参考和素材路径、实际源段、角色及本片半开帧范围见[素材与槽位映射](../02_关键决策与证据/02_素材与槽位映射.md)。隔离项目建好后，由主任务把每个角色绑定到实际登记的 Asset ID；两条参考的研究决定 ID 也由主任务按真实回执填写。

视觉主线是“惊艳的一次动作，转到工位里的持续可靠性”。画面以真实动作及生产环境为中心，暖白纸感空间承接素材原色，墨黑排印、工业黄用于注意引导；真实素材可占满画面，留白随焦点变化，不把全片固定成左右分栏。普通字幕和配音由项目外层合成，作品内仅有短句和数学表达；不出现参考编号、素材出处或内部制作文字。

## 原片依据与本片改编
创意参考 011-c01：原片 4.700–6.600 秒。我独立查看 4.70、5.06、5.42、5.78、6.14、6.50 秒六张顺序帧：先是 3×3 候选图，石拱图变大并居于主位，随后该图占满画面。保留“多个候选让位、一个主体取得注意并占满”的可见状态关系；本片以黄色机械臂替代石拱图，以其他真实素材作为候选。本片自己设计 16:9 的四画面布局和进入、速度；抽帧不证明原片运动轨迹、原速节奏和同期声。目标成片范围 [58,105)，研究决定 ID 待登记。

机制参考 011-m04：同一原片 10.400–11.800 秒，机制库指纹见映射。我独立查看 10.40、10.68、10.96、11.24、11.52、11.79 秒六帧：圆形区域先露出新的画面，之后新画面占满。保留这两个状态及其先后；本片让控制器画面在 ABB 机械臂画面上的圆形区域中显露，然后取得全幅。圆心位置、速度、遮挡与中文排版由本片设计，不声称还原原片连续运动或音画对点。目标成片范围 [315,350)，研究决定 ID 待登记。

## 完整观看过程
1. [0,70) 从 Atlas 在蓝色台座上的实际画面开始，身体在画面中保持充分空间，能看见起跳前、空中与落地后姿态；标题“机器人都能后空翻了，为啥不能进工厂？”分两行置于不遮挡主体的空域。后空翻不能当作工厂实测，也不把这一动作当作后续机械臂的同一主体。

2. [58,160) 在旧画面仍可辨时引出四块真实素材候选：黄色臂、白色臂、手持控制器、蓝色料箱线。它们分别来自不同场景，画面边界清楚，不连成同一事件。候选稳定一瞬后，黄色臂及其源内动作取得中心，其他候选退到边缘并消失；黄色臂用同一视频槽和连续源时钟发展成全幅。单次假设“99%”与“每次结果互不影响”随焦点建立并留足阅读；不能把 99%写成这台机器的实测可靠性。

3. [160,259) 画面沿黄色臂的实际动作继续，随后白色 ABB 机械臂与料箱画面接管。重点字组从“连续 100 次”发展到“全部成功”，公式清楚写成 0.99 的 100 次方约等于 37%；保持“假设每次独立”的条件可读。37% 只表示一百次全部成功的概率，不表示成功 37 次、不表示工厂故障率。文字、真实材料、留白和色块共同重组，不能把机械臂缩成角落配图。

4. [259,470) ABB 画面先继续，条件文字分别表达“可能自动恢复”和“可能需要人处理”。从 [315,350) 开始在 ABB 图像上开出圆形可见区，显露手持控制器，圆区扩大后由控制器成为观看主体；旧画面、文字和背景随新主体让位。它们来自不同来源，不剪成记录了同一故障的前后镜头，不加入虚构警报。输送线上真实人员和蓝色料箱从 [415,565) 接入，“后续工序可能等待”作为旁白中的条件，不冻结或变速源视频冒充停线。

5. [470,637) 让观众在真实料箱线与已进入的汽车生产线之间看见“稳定工作、处理问题、人工介入”三个判断维度；这些是独立场景的并置，不构成一条被记录的实际因果链。料箱线在 [565,637) 之前自然退出，生产线在同一个视频槽、同一源时间中扩大为收束主画面；简短字组与画面构成可读的最终状态，保留至旁白尾音结束。不得因为填时而循环、冻结或统一变速。

## 素材观察与事实限制
后空翻：抽样见 18.68、19.24、19.80、20.36、20.92、21.48 秒，分别可见台座附近、空中与落地后姿态；不据抽帧声称已验证完整动作速度。黄色臂：0、1.5、3、4.5、6、7.5 秒抽帧可见臂位变化及蓝色构件；3–9 秒拟用，末端与全段连续性仍需首版检查。ABB：36.5、37、37.5、38、40、42.5 秒抽帧可见夹具与料箱，期间景别变化；不能从这些帧判定故障。控制器：0–5 秒逐秒抽帧可见人的手和设备；不知操作者是否控制片中机器人。输送线：32–38 秒抽帧可见人员和蓝箱；不把作业动作称为救援或停线。生产线：0–4 秒抽帧可见蓝色机械臂和车身结构，后续源段未逐帧核看。以上均为离散取样而非连续观看；必要动作、完整取景和同期声由首版及原片进一步复核。

## 保持、可深化、需反馈
必须保持：准确正文及独立假设；真实素材身份、源区间与连续时钟；两条参考上述有依据的状态关系；素材与花字共同承担观看；三处不同工作现场的事实边界；两个参考映射及前后接点。
OD 可深化：字形与字重、局部位置和比例、画面边缘与空间、蒙版、运动曲线、内部速度及精确交叠；只要不改变上述主要关系。每次视频槽的时钟从对应源起点正常推进；候选中使用过的短段在后文重新出现时明确作为不同段落的回看，不伪装成一次连续作业。
发现素材实际动作不足、需要换主体、研究依据不足、过渡遮挡动作或声画阅读冲突，反馈具体素材、版本和成片范围给视觉作者；必要时由主导演决定。首版发布后主任务带同版 Work、Run、冻结版本和可查范围交回，视觉作者与原创意/机制负责人分别对照原片和本片复查。
