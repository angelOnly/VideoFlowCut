## 主导演怎么组织

导演依锁定文案将内容组织为四段：单次 99% 且彼此独立的假设 → 连续 100 次全部成功约 37% → 小失误可能自动恢复，也可能需要人工处理、后续工序可能等待 → 工厂需要长期稳定工作和处理问题。概率为数学假设，不是机器人实测；不同来源的素材不应构成虚假的同一事故。

R42 阶段，导演采用真实后空翻、托盘作业及工厂画面为主体的预排，允许正式制作深化；其依据是离散位置检查，并非完整声画验收。之后接任导演要求 37% 同屏保留 99% 和独立前提，并让“连续 100 次”在结果出现之前已经可见；保持原旁白、托盘素材与源时钟。导演决定基于视觉作者的静帧反馈，记录明确说明接任导演当时没有独立完整观看 R52。详见[决策清单](./记录/角色关键决策.md)。

## 创意作者参考了什么

- [016 原片](./参考/016原片.mp4)、[016分镜](./图片/016分镜.jpg)：局部采样显示单一作品转为多作品并置，前景红白文字带先后出现。作者建议迁移“真实素材分别建立、再共同归拢”的组织关系；不是要求照搬色带和速度。
- [005 原片](./参考/005原片.mp4)、[005机制片段](./参考/005机制片段.mp4)、[005分镜](./图片/005分镜.jpg)：采样中多个示例先建立，页面整体放大模糊后转向厨房。本片的工厂单窗同源扩大是视觉作者自行设计，不能说原参考就是这个运动。
- 后续作者建议托盘实拍承接概率解释，工厂、控制器、料箱先各自建立，再归拢并回到工厂；“托盘动作带出下一画面”仅为待验证建议，不应说已经采用。作者依据的是[016局部采样](./图片/016抽样/sheet-0.png)、[005局部采样](./图片/005抽样/sheet-0.png)和[R52总览](./图片/R52画面总览.png)；完整原速声画研究和成片对照仍未完成。

## 视觉作者如何编排

| 根帧范围（25 fps，结束不含） | 本片画面与思路 |
| --- | --- |
| 0–70 | [后空翻](./素材/后空翻.mp4)与标题建立问题，保留动作空间。 |
| 58–272 | [托盘机械臂](./素材/托盘机械臂.mp4)从右接入，连续承接单次成功率、独立假设、100 次及约 37%；文字在右侧，避免遮挡机械臂。 |
| 263–386 | [工厂蓝臂](./素材/工厂蓝臂.mp4)从左接管，用条件语气呈现失误可能的处理方式，不把正常焊接当故障。 |
| 376–595 | [控制器](./素材/控制器.mp4)由右侧缩放接入，[料箱线](./素材/料箱线.mp4)由下接入；各是独立素材，不制造真实事故因果。 |
| 555–653 | 工厂、控制器、料箱归拢；辅助画面退出，已经出现的工厂窗口连续扩大到全屏，承接结尾。 |

R53 将概率前提放到右侧两行，但 36px 字号在手机上可能偏小；R54 将标签改成 56px，保留“假设：单次成功率 99% / 每次独立·连续 100 次”。R56 合成后的抽样检查发现底部字幕遮住部分托盘，37% 出现的时间与口播仍需连续核对；见[手机宽度检查](./图片/R56手机宽度.png)。
