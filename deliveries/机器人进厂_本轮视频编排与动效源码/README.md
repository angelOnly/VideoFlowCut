# 本轮视频编排与素材交付

本目录整理本次新建视频项目 R140 的现有成果：主导演、创意作者和视觉作者的编排思路与关键指令，画面制作委托、同源返修、当前动效源码、实际素材和每 0.5 秒的带时间分镜。

**直接播放：** [机器人进厂视频 R140](./机器人进厂_视频_R140.mp4)。这是本项目当前可播放的完整预览，与下方 01 目录中的 R140 预览为同一文件内容。

**先读：** [角色关键指令与编排思路](./02_导演创意视觉记录/角色关键指令与编排思路.md)；再看 [关键决策与实际完成状态](./02_导演创意视觉记录/关键决策与实际完成状态.md) 和 [OD实际委托与源码交接](./02_导演创意视觉记录/OD实际委托与源码交接.md)。

- [R140 全片预览](./01_影片与声音/视频预览_R140.mp4)：131.9 秒，横屏，配音与字幕；是预览，不是成功导出的正式成片。
- [分镜总览](./06_分镜/分镜总览.md)：每 0.5 秒取一帧，每张图直接标注视频时间，亦有按页排布的总览图。
- [素材与来源说明](./05_参考/素材与来源说明.md)：含素材文件、来源身份、参考观察边界和使用许可状态。

- [抓取示意源码](./03_画面源码/抓取示意.html) 和 [概率图源码](./03_画面源码/概率图.html)：为当前实际采用作品的固定定义中提取的完整 HTML，保留对应清单和已渲染视频。作品运行依赖受管 HyperFrames 环境；包内并非可直接恢复的完整 VideoFlowCut 项目数据库。
