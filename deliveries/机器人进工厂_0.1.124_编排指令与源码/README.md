## 这份整理的证据边界

- **有直接记录的内容**：角色已登记的决定、导演稿、参考研究结果、OD 委托及交件、最终源码、R61 时间线和审阅记录。可追溯到 [制作决策与审阅记录摘录](./证据/制作决策与审阅记录_摘录.json) 和 [最终导出与复查记录摘录](./证据/最终导出与复查记录_摘录.json)。
- **按现有记录梳理的解释**：为便于阅读，将记录中的意图、时间点、画面和素材关系重新组织成自然语言；不会把这些梳理冒充当时各角色逐句发出的原话。
- **未找到的内容**：主导演、创意作者、视觉作者最初分派时的完整原始对话或逐字提示词。现存记录足以还原其已登记的关键决定和交接内容，但不足以声称还原全部实时思考过程。

此片已经导出，导出技术检查通过；原制作任务记录仍为 **未完成**：整片连续声画复核和参考与成片的连续对照证据不足，四个画面问题虽有定点复查与局部改善记录，仍未按系统要求完成关闭；还有一条第二段素材登记错误。具体见 [审阅状态](./06_关键决策与审阅状态.md)。本次整理没有修改视频项目或重新评价成片。

动效源码是平台受管的 HTML 作品：视频帧、字体由平台注入，普通字幕、旁白及音乐由外层合成。因此，直接双击源码不能当作完整成片预览；使用方式和素材槽对应见 [素材、参考与动效源码索引](./05_素材与源码索引.md)。
