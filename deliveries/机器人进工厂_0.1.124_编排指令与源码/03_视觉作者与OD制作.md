# 视觉作者与 OD：构图、美术、动效和返修

这份说明根据视觉作者登记的决定、[视觉导演稿](./交接原稿/视觉导演稿.md)、[OD 实际委托](./交接原稿/OD实际委托摘录.md)、[OD 交件说明](./交接原稿/OD制作与返修交件说明.md)和最终 [动效源码](./动效源码/robot-factory.html)梳理。这里能说明有记录的设计理由与实际实现；没有保存的逐字讨论，不虚构为作者原话。

## 一、视觉作者拿到了什么，又要解决什么

输入包括主导演的叙事主线和事实边界、十段真实旁白的段级时间、素材作者提供的五条真实视频，以及创意 130 和机制 005 的参考研究。视觉作者需要把它们组织成一份可直接制作的整片导演稿：观众每段看什么、哪些真实画面是主体、怎样从上一段过到下一段、哪些画面关系来自参考、文字放哪、哪些事实不能暗示。

视觉作者在项目记录中给出的主要理由是：先让观众看到真实动作，再理解生产连续性、固定任务和人形潜力的区别。逐帧复核改变了参考归因之后，视觉稿相应更正，而不是沿用“005 原片就是小窗无缝扩大”的初判。

## 二、构图和美术怎样确定

| 设计问题 | 记录中的具体安排 | 这样处理的目的及限制 |
|---|---|---|
| 素材谁当主体 | Atlas、人员、设备、机械臂和搬料画面承担主表达；不是把实拍一直缩成背景小窗。 | 让观众先看到真实动作与生产空间。小窗是接力过程中的临时状态。 |
| 颜色 | 保留素材自然色；近黑、灰白为文字与底色，少量机械蓝和暖色点缀。 | 让不同来源在同一视觉语言下衔接；不靠统一色块覆盖真实素材。 |
| 字体与文字 | 中文无衬线字体，常规与粗体；标题和说明避免负字距，普通字幕由外层合成。 | 文字服务观察和解释，避免逐句都变成卡片，同时给下方字幕留空间。 |
| 概率说明 | 99%、独立、连续 100 次全成功和约 37% 要共同成立；文字在画面空位出现。 | 防止观众误会为机器人实测概率；同时保留真实动作可见。 |
| 多来源画面 | 人员、KUKA 设备、汽车机械臂分窗出现，三项问题作为对工厂整体的提问。 | 可同时展示多种生产语境，但不能让观众误以为某个未经证实的画面正在故障或有人值守。 |
| 末尾人形画面 | 展示机器人、料架和物件的关系，未来文案压缩到上方短条。 | 给头部、上身及搬料动作留空间；“换工位”仍是未来可能性。 |

视觉稿中这些安排是**制作要求**。最终是否做得好，需要看成片连续画面；项目只记录了若干定点帧，不能因设计稿写了“不要遮挡”就宣布全片不存在遮挡。

## 三、两处动效是怎样落实到素材上的

下面列的是最终源码中的根帧时序，不是从参考片猜测出的时序。可对照 [源码](./动效源码/robot-factory.html) 和 [素材槽映射](./05_素材与源码索引.md)。

### 1. Atlas 到人员：130 的小窗接力

1. F0 起 Atlas 画面作为主体；概率说明在左上空位出现，F228 前退出。
2. F228 起，人员／滚筒画面以左上小窗淡入；源码设定位置 x=80、y=96、比例 0.325。
3. F240–264 留出小窗可辨的停留时间。
4. F264–288 同一活动窗口逐渐移动并扩大，F288 后 Atlas 让出主画面。

按记录，视频槽按源时钟正常速度播放，动画改变的是位置、大小、透明度及显隐。这里借鉴的是参考中“先出现且可辨、再成为主体”，不是复制原参考的背景和装饰。

### 2. 多组并置到机械臂：005 与 130 的组合

1. F528–552 人员画面缩到左侧；F552 起 KUKA 设备在右上进入。
2. F588 起汽车机械臂在右下进入；F600–624 给机械臂小窗可辨的时间。此前已出现的画面仍保持活动。
3. F624 起汽车机械臂窗口提前扩大；F636–648 人员与设备窗口逐渐让位，F700 完成接管。
4. 错峰补齐、已有画面保持来自 005 的研究；同一机械臂窗口先可辨再扩大，借的是 130。本片把两种关系连接起来，不能将整个动作都归给 005。

接管后，汽车机械臂继续显示到 F786，再切 KUKA 夹具，F870 切 KUKA 俯视，F948 接 Atlas 搬料。这些源段的具体起止见素材索引。

## 四、OD 收到什么，实际做了什么

OD 首版委托明确写了“你是首版制作作者，不是深化外层已做好的预排”。它收到的是视觉导演稿、时间计划、场面映射、旁白、两条参考原片、参考卡和五条实拍素材；被要求自行深化排版、构图、美术、镜头和素材接力，并先交可检查的开场范围，再沿同一作品完成整片。

OD 留存的交件说明称：它读取交接资料，使用原参考及素材的联系表和解码帧观察，形成单页 HTML 与作者清单；视频槽绑定真实源段，字幕和声音留给外层。它也明确写明：参考原速连续视觉体验和听审没有获得，不能把输入抽样当作看过最终合成。

首个开场作品的 Atlas 20–32 秒和人员 35–52.5 秒源段，超出了当时导演采用清单中的候选范围，平台因此拒绝登记。视觉作者和导演依据抽样调整了采用范围及交接资料，OD 随后沿原作品重新交件并完成整片。这个过程说明**首版由 OD 制作，登记曾被范围不一致挡住，之后通过更新采用范围继续**；不等于没有启动 OD。

## 五、视觉作者怎样反馈，OD 怎样修

| 检查发现 | 视觉作者提出的处理 | OD 在同一作品中的修改 | 已有证据的边界 |
|---|---|---|---|
| 开场概率卡挡住 Atlas 或人员小窗 | 缩小、移开或提前退出；先让人员窗完整可辨再扩大。 | 概率卡移到左上并在 F228 退出；人员小窗调整位置，先停留再接管。 | R56 若干定点帧及最终导出 F181、F265 显示局部改善；未连续复查全过程。 |
| 机械臂接管时前两组过早退出，剩下深色底和小窗 | 前组保持到目标窗开始扩大，或者提前扩大目标窗。 | F624 起扩大，F636 起前组再让位。 | R56 定点帧与最终导出 F650 显示机械臂主体变大；单帧不能证明过程节奏。 |
| 稳定、异常、值守问题紧贴单条画面，可能误指事实 | 改成面向工厂整体的三个通用问题。 | 统一放在顶部问题带；随后又将顶部制作备注改为“工厂需要考虑的问题”。 | R59 的 F625 看到了文字变更；整段语义与连续观感仍待复核。 |
| 结尾大黑卡挡住机器人上身 | 文字移到空位、缩小，保留未来可能性。 | 改为顶部短条，后又将制作备注改为“未来的可能”。 | R59 和最终导出的相应定点帧能看到机器人和物料；中文字幕与源内英文的整段关系仍待复核。 |

这些修改和反馈的原文可查 [OD 实际委托摘录](./交接原稿/OD实际委托摘录.md)。原制作任务中这四项仍是“待完成正式复查”，不能因为本表描述了修正就改称全部通过。
