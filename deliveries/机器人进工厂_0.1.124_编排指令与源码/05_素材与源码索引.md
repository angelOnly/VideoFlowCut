## 五、动效源码及复现边界

- [robot-factory.html](./动效源码/robot-factory.html)：最终 R61 导出所用画面作品的完整 HTML/CSS/GSAP 源码，复制自最终渲染输入，内容未改。其 SHA-256 是 d06113f2f515fe6bfc366042601bd1a3e01a9b98b7caf7fd05b9517fa8f0d7fa。
- [robot-factory.author.json](./动效源码/robot-factory.author.json)：对应作者清单，包含画幅、帧率、时长、视频槽、字体、就绪范围和改动范围。清单中的 assetId 与上表可一一对应。
- [常规字体](./动效源码/字体/NotoSansSC-Regular.otf)和 [粗体](./动效源码/字体/NotoSansSC-Bold.otf)：最终画面使用的项目字体副本。
- 版本对应：R61 导出引用画面素材，由同一动效作品的定义版本生成；该定义所用冻结源码为上述 HTML。导出的最终文件在外层合成了普通字幕、旁白及 BGM。

源码通过 VideoFlowCut 受管的 HyperFrames 运行，GSAP、视频帧、字体、画布时间和字幕／音轨由平台提供。此包保留了源码和所需原始素材，但不是独立播放器或一键重建工程；直接双击 HTML 无法自动完成上述注入，也不能由此判断成片画面。
