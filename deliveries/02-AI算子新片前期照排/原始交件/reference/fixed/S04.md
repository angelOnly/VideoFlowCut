# S04｜先展示三个目的地，再将它们并排收进品牌结尾

作者依据见 [创意照排原稿](../../01-创意照排原稿.md)。仅替换原句的同名标记。

**原片 9000–10000 毫秒**

**9.000–约 10.000 秒。** [racks-c.jpg](../../assets/racks-c.jpg) · 左侧机柜局部 x0–720，保留门框和指示灯满铺，海线从左入，白沙偏右，树叶在右上近层。左下大白粗自己这边，同边留距。极小浅字在画顶，不抢阅读。

**原片 10000–11500 毫秒**

**约 10.000–11.500 秒。** 用亮蓝斜边短过门换[racks-c.jpg](../../assets/racks-c.jpg) · 中段机柜局部 x545–1265，保留网格与线缆，蓝天、天际线及水中倒影占满幅，左下同字号别人那边。再换[racks-c.jpg](../../assets/racks-c.jpg) · 宽视野机房图，自 x90 至 1710，宽窗与竖窗均可辨，保留落水、暗绿岸及暖灰天空，白粗共同场域落在下缘空位。每个镜头自入场至过门完整播放，不用冻结或循环作为实景动作。

**原片 11500–12700 毫秒**

**约 11.500–12.700 秒。** 深蓝背景中把同一批实景分别裁成三个等宽竖卡，在 x4%–96% 并列，同上底线和窄暗缝。每卡左下留对应自己这边别人那边共同场域，比满幅字号小；顶上居中添白色谁先放慢？，一行细粗字。三窗从出现到整体退场同留。采用动态时用各已见镜头的连续可用源段，保持辨认特征；仅作范围小结时允许从三条镜头各抽一帧定格。
