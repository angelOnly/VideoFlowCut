# 主导演如何编排本片

以下依据本轮导演实际回件、角色交接消息及 Revision 101 的时间线整理。引号是回件中的实际表述，分段说明为依据可见结果归纳，不冒称完整思维过程或未记录的观看。

## 总体讲述

用户提供全文，主任务按自然句群保留文案。导演将观众注意力从运动能力转到工作能力：先让人看到后空翻落地，再把视线缩到手、零件和工位，接着用独立概率假设说明连续成功，最后回到真实仓库的下一次搬运。

导演明确要求：“起跳—翻转—落地必须连续读到，落地时留半拍”；从翻转切到操作后，“先看清箱/夹爪/零件，再看原轨迹受阻、换角度和重新完成动作；从看全身改成盯手与零件”。导演把动作是否成功、工作能否长时间运行、以及失误需要多少人力介入作为连续问题。

## 分场关系与采用

1. **落地建立能力。** 用 [Atlas 后空翻开场](../视频/使用素材/atlas-opening-1080p-upgrade.mp4)显示起跳、空中转体和站稳，随后使用慢动作回看。导演实际采用的较清晰底片见 [后空翻原片](../视频/原始参考/atlas-parkour-source.mp4)。
2. **转入工位。** [Figure 工位](../视频/使用素材/BMW_Clip_Wide.mp4)先呈现横持钣金，再接靠近夹具。导演认为失败或调整要有可见依据，因此创意作者用 [抓取原理示意](../视频/使用素材/grasp-8.3s.mp4)明确标识示意。后续 [Atlas 发动机罩试验](../视频/使用素材/atlas-engine-cover.mp4)在成片 21.77—30.33 秒使用源片 83.0—91.57 秒，展示受阻与再调整。此处时间线中的用途文字仍沿用更换素材前的描述，以画面文件和源范围为准。
3. **从一次动作推到连续工作。** 导演要求“从一次成功切到同一搬运循环”，公式写作 0.99 的 100 次方约等于 36.6%，并标出每次独立是前提。视觉作者实现为 [单次概率](../视频/使用素材/probability-single.mp4)和 [连续概率](../视频/使用素材/probability-repeat.mp4)，用 Figure 俯视实拍作背景。导演提出以停机和后工序等待表达影响，实际回件没有证明真实停线，因此使用仓库工作和输送线作为场景，不把实拍描述成故障证据。
4. **回答机械臂为何已经在工作。** [固定工位抓取](../视频/使用素材/pick.mp4)承担机械臂的重复任务，组织来料箱、夹爪和整体工位。画面是视觉引例，不能据此推断片中所有机械臂都无需感知变化。
5. **人形机器人进入现实场景。** 从 Figure 夹具切到 [Digit 搬料](../视频/使用素材/digit-real.mp4)，以通道、抓箱、移动与放箱呈现工位空间。导演明确区分 Atlas 测试和 GXO 仓库的 Digit，里程碑采用 [Digit 数据镜头](../视频/使用素材/digit-milestone.mp4)。
6. **回到下一次。** 先回看 [Atlas 落地](../视频/使用素材/atlas-flip.mp4)，再回到取件和 [Digit 抓起料箱](../视频/使用素材/digit-real.mp4)。导演最后建议还可选择 Digit 空手转回下一箱的镜头。实际 Revision 101 末镜使用源片 7.4 秒起的抓箱动作。

每一镜的精确帧边界和本地文件见 [实际镜头表](实际镜头表.md)。旁白语义段与镜头不总是一一对应。
