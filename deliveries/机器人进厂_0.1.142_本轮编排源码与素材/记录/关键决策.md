# 关键决策与执行差异

| 决策 | 当时依据与实际结果 |
|---|---|
| 全新横屏纯解说 | 项目设置 1920×1080、30 fps；无真人主持，原稿保留并合成中文旁白。 |
| 后空翻完整可见 | 导演要求连续看到起跳、旋转、落地，开场随后慢放回看；最终用了较清晰的本轮取得原片。 |
| 失败与示意分开 | Figure 工位素材本身无法证明工件意外位移，故抓取画面标记“原理示意”；另使用 Atlas 实际受阻调整片段。 |
| 99% 是条件假设 | 将每次独立和 0.99¹⁰⁰≈36.6% 写进概率段，未经证据不归属于任何具体机器人。 |
| 真实故障不凭剪辑虚构 | 提出后工序等待，但取得的 Digit 画面不能证明停线，实际只用其作为真实工位场景。 |
| 区分不同机器人 | Atlas、Figure、Digit 以不同源片和工位切开；Atlas 测试不能充当 Digit 部署实证。 |
| Digit 超十万料箱 | 使用 Agility 里程碑报道及其仓库视频，数据包装前保留实际放箱动作。见 [来源说明](../参考/素材与参考.md)。 |
| 旁白与字幕 | 16 个自然配音段按实际时长拼装；最终 60 张字幕由实际音频识别，再按用户稿校字，逐字内容可与 [旁白](旁白全文.md)对照。 |
| 抓取三阶段 | 原版 12 秒进成片会截断末段，改成约 8.3 秒版本，显示移位、定位、重抓。 |
| 开场与工位素材更新 | 主导演后续找到较清晰后空翻原片和真实受阻调整片段，替换对应镜头；工位镜头的项目用途描述未同步。 |
| 出片和验收 | 插件正式导出要求 OD 冻结回件，草稿要求每个解释场景有就绪主视觉程序或受管作品；两次均拒绝。主任务据 Revision 101 剪点独立渲染最终 MP4。项目完成状态 incomplete，整片作者复核和连续人工听审未完成。 |
| 音频差异 | 项目混音设 +7 dB；独立 MP4 另做响度处理，实测约 -16.8 LUFS、真峰值约 -1.4 dBFS。 |
