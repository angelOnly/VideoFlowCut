# 动效源码和复现状态

- [抓取原理原始源码](抓取原理_原始源码.py)是创意作者本轮实际保存的 Python 文件，内容原样复制。输入是 [Figure 工位宽画面](../视频/使用素材/BMW_Clip_Wide.mp4)，使用 Pillow、FFmpeg、libx264 和 Windows 微软雅黑字体，产生 12 秒 [原始示意](../视频/使用素材/grasp-explainer.mp4)。原代码的字体是系统字体绝对路径，与媒体相对路径无关。代码把结果写到传入的素材目录，复现时先复制输入到可写工作目录。
- [动效制作记录](动效制作记录.md)保存了实际由作者回传的开场滤镜、工位横屏命令、概率和 Digit 动效处理链。原命令在交互式 Node REPL 里执行，除抓取 Python 外，未发现独立源码文件。准确命令有记录的按原参数列出，没有记录完整参数的明确写出，不将处理描述冒充源码。
- [字幕文件](../记录/字幕.ass)为本轮独立渲染实际使用的字幕文件。
- 本轮没有 OD 作品、OD 源码和冻结工程，不能提供对应文件。

抓取示意的成片版本是对 12 秒原始成片做 setpts=0.699*PTS、30 fps 的时间压缩，见 [成片实际使用的 8.3 秒版本](../视频/使用素材/grasp-8.3s.mp4)。它是基于已渲染视频的二次处理。
