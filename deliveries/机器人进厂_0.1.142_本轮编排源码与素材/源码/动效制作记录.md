# 本轮动效制作记录

## 开场：Atlas 原速与慢放

主导演交回本次升级版的实际 FFmpeg 参数。输入为 [Atlas 后空翻原片](../视频/原始参考/atlas-parkour-source.mp4)，输出 [Atlas 开场](../视频/使用素材/atlas-opening-1080p-upgrade.mp4)。原速 44.0—46.5 秒，慢放回看 44.25—46.41 秒，慢放比例 0.65。画布 1920×1080，左侧视频和右侧文字 ATLAS / 后空翻。原处理使用 FFmpeg、libx264、drawtext 和 Windows 微软雅黑常规及粗体。以下是滤镜正文原样记录，字体路径为执行机器的系统依赖。

```text
[0:v]split=2[n][s];[n]trim=start=44.0:end=46.5,setpts=PTS-STARTPTS,fps=30[n1];[s]trim=start=44.25:end=46.41,setpts=(PTS-STARTPTS)/0.65,fps=30,tpad=stop_mode=clone:stop_duration=0.8[s1];[n1][s1]concat=n=2:v=1:a=0,scale=1344:756:flags=lanczos,pad=1920:1080:88:128:color=0x101819,setsar=1,drawbox=x=1508:y=330:w=72:h=4:color=0x74CCAF:t=fill,drawtext=fontfile='C\:/Windows/Fonts/msyh.ttc':text='ATLAS':fontsize=45:fontcolor=0x74CCAF:x=1508:y=370,drawtext=fontfile='C\:/Windows/Fonts/msyhbd.ttc':text='后空翻':fontsize=90:fontcolor=0xF0F4EF:x=1498:y=444,format=yuv420p
```

外层参数为 `-t 6.4 -an -c:v libx264 -preset veryfast -crf 17 -movflags +faststart`。这是作者回传的执行记录，不是原本落盘的脚本。

## 工位横屏

以下是创意作者回传的原 FFmpeg 命令，工作目录为本目录的相邻素材目录，输入及输出采用相对名称。原片 [Sequence_02](../视频/使用素材/Sequence_02.mp4)，输出 [横屏观察](../视频/使用素材/figure-workcell-observation-40-64.mp4)。源 40—64 秒，保持原速，背景为同源暗色虚化。

```sh
ffmpeg -hide_banner -loglevel error -y -ss 40 -i Sequence_02.mp4 -t 24 -filter_complex "[0:v]crop=912:900:594:0,setsar=1,split=2[rawbg][rawfg];[rawbg]scale=320:180:force_original_aspect_ratio=increase,crop=320:180,gblur=sigma=11,eq=brightness=-0.135:saturation=0.71,scale=1920:1080[back];[rawfg]scale=-2:1080[front];[back][front]overlay=(W-w)/2:0,fps=30[out]" -map "[out]" -an -c:v libx264 -preset veryfast -crf 18 -pix_fmt yuv420p -movflags +faststart figure-workcell-observation-40-64.mp4
```

## 概率段

[单次成功率](../视频/使用素材/probability-single.mp4)使用 [Figure 俯视原片](../视频/使用素材/Sequence_02.mp4) 18—31.5 秒；[连续成功概率](../视频/使用素材/probability-repeat.mp4)使用 31.5—41 秒。视觉作者实际采用 crop、scale、pad、drawbox、drawtext、fps 和 libx264。结果数字在第二段约 2.7 秒出现，100 用单独文字绘制上标。两条都写出“每次结果相互独立”。使用微软雅黑粗体。完整滤镜参数与独立脚本未保存，保留的是成品、输入、源范围与作者回件。

## 最终合成

本轮将 20 个已保存的时间线镜头按 30 fps 裁取，统一 1920×1080 后拼接，再叠加 [字幕](../记录/字幕.ass) 与 [旁白总轨](../音频/旁白总轨.wav)，使用 H.264 和 AAC 输出 [最终 MP4](../视频/成片/机器人进厂.mp4)。旁白在独立成片中使用 loudnorm，目标 I=-16、TP=-1.5、LRA=7。每镜源帧与目标帧见 [镜头清单](../记录/镜头清单.json)。这些记录可用于重新建立合成，实际主任务的 Node REPL 脚本未落盘。
