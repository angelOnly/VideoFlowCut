# 关键决策、偏差与核验

| 决策或问题 | 当时的依据与意图 | Revision 84 实际结果 |
|---|---|---|
| 整片主线 | 从一次后空翻转向抓取、异常、长期运行和下一件 | 8 个解释主场面与 20 个实拍切镜，主要叙事顺序保留 |
| 旁白 | 用户提供完整原文，使用合成普通话 | 18 段合成并拼为总轨，47 张字幕对照原稿校正 |
| 取材 | 使用本次新搜官方真实机器人画面 | Atlas、FANUC 和 Digit 画面进入成片 |
| 概率 | 99% 每次成功且独立，100 次全部成功约 36.6% | 35.03–45.40 秒内置四柱图；没有实拍与动态曲线同屏，结果提前可见 |
| 视觉图表问题 | 文字数据相互对应 | 视觉作者抽查指出前两柱高度几乎一样，不能正确体现 99% 和 81.8% 的差距，需在后续修片复核及修正 |
| 延时仓景 | 视觉稿要求采用时标明延时 | 约 54–60 秒使用 GXO 延时，抽样未见延时标注 |
| 十万料箱 | 用官方披露说明具体已发生的作业 | 由普通字幕传达，独立“100,000+”花字没有出现在抽样画面 |
| 源片英文 | 将字幕放入共同安全区 | 部分时段字幕底板与源片 Fully Autonomous 烧录字重叠 |
| OD 动效 | 视觉作者提出的完整方案原拟进入 OD | 运行时版本不匹配，没有本片 OD 正式委托。主任务使用插件原生场景制作 |
| 声音 | 以完整旁白承载讲述 | 无 BGM、SFX、环境声音轨，总混音 +9.5 dB |
| 质量检查 | 保持技术验证与观看判断可追溯 | 完整文件通过解码，导出报告无黑场。导演与视觉作者只做抽帧，连续播放及完整听审尚待完成 |

柱图视觉差异、延时标注、字幕遮挡和提前揭晓为本次档案整理时发现或确认的现存问题。最终视频与项目没有在本轮文档整理中修改。
