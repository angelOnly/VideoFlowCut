# 视觉作者的思路、参考与实际对照

视觉作者把创意作者的动作关系发展成整幅画面。Atlas 前后两部影片提供同系列的全身运动与取件，视觉连贯，同时保留实验环境。工位段用围栏、零件盘和机械臂的真实空间，Digit 段切换到仓库尺度。画面从实验室黑灰、钢色过渡到工位黄和仓储色，字幕统一固定，重点标注放在动作空侧。

## 如何研究和选择

视觉作者初搜了 H1、Apera 与 Agility 候选。收到创意作者的本次检索结果后，选择 [Atlas 后空翻](./素材/视频/atlas-airborne.mp4) 和 [Atlas 抓取](./素材/视频/atlas-hands-on.mp4) 作为开场与拣料主线。作者抽看 Hands On 约 0–29、31–60、79–97 秒的离散帧，导演补充后空翻抽帧。FANUC 和 Digit 的时间段见 [主导演编排](./02_主导演视频编排.md) 及 [实际时间线](./05_最终时间线与声音.md)。

动效机制研究核读了两个候选的正文和分镜，尚未原速连续观看。一个是正在运动的主画面持续保留、同步局部另开；另一个是在固定旁片中线段和端点持续推进。作者借前者解释 Atlas 原片的左感知窗与右侧实体动作，借后者构想机械实拍旁的概率曲线。两个候选只作为局部研究关系，并无本次已取得的原片文件，故此处保留观察范围，不虚构本地参考视频。

## 视觉初稿

[视觉导演原稿](./编排数据/视觉导演原稿.md) 按五组场面给出画面、旁白锚点、源秒和转场。主要意图包括原速完整翻转、料架空间与感知窗并在、FANUC 循环旁生成 0.99 的 n 次方曲线、固定工位接到 Digit 实仓、最后回到抓取下一件。初稿提出给仓库延时注明时间加速，在 Digit 资料上放独立累计数字，遇插入受阻时提示具体工况。

## 对成片的抽帧复核

视觉作者对 Revision 84 全片每 3 秒抽帧，重点段按每 0.5–2 秒抽帧。方法不包含全片原速观看和听审。

- 开场与感知窗延续了主线。字幕与源片右下角的英文烧录文字在部分画面重叠。
- 35–45 秒为全屏四柱图，没有原稿中的实拍与曲线同屏，36.6% 提前出现。作者指出前两根柱的视觉高度过于接近，与 99% 和 81.8% 的差异不相符。
- FANUC 固定工位及 Digit 提箱、移动、归位画面已使用。约 54–60 秒的 GXO 延时抽样未见加速标注。十万料箱由普通字幕传达，未见独立的 100,000+ 花字。
- 末段再看 Atlas 落地，接回操作与下一件。抽帧可见手边黑色部件和转身，物件脱离料架的细节较难辨认。

视觉作者没有收到 OD 委托或冻结作品，也没有在首稿交接时拿到实际旁白帧、素材 ID 和正式冻结的同版制作稿。
