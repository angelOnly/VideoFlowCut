# 动效源码及 OpenDesign 状态

本片最终使用 VideoFlowCut 0.1.141 的原生解释场景、实拍切镜和字幕，概率段使用 DataConclusion 内置图表。此版本没有本片的 OD 委托、Run、冻结作品或 OD 专属源码可交付。

实际发行版执行文件为 [render-entry.cjs](./动效源码/发行实际运行/render-entry.cjs)，附带 [源映射](./动效源码/发行实际运行/render-entry.cjs.map) 和 [发行清单](./动效源码/发行实际运行/manifest.json)。源映射记录了模块来源，但未包含 sourcesContent。该执行文件是实际发行物的打包代码，依赖插件运行环境。

[可读解释场景代码](./动效源码/可读源码/explainer-registry.tsx) 与同目录其他源文件复制自当前仓库，可用于阅读图表、素材场景、字幕和时间线实现。发行源映射指向对应模块名，但本次未证明仓库副本与发行构建逐字一致，因此两者分别保存。

本片专属的参数、状态、切镜源范围、字幕、素材绑定和声音时序保存在 [场景与时间线](./编排数据/场景与时间线.json)。概率场面的 props 是 values 99、81.8、60.5、36.6，标签分别为 1、20、50、100 次全成。代码与参数共同解释本次图表，不能把它称为 OD 原创动效源码。

视觉初稿中的两项机制候选仅核读正文与分镜，没有取得其完整原视频，也没有登记为本片 OD 采用参考。
