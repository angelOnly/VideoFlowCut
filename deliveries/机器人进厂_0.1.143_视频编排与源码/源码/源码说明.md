# 动效源码、素材绑定和修订

本目录保留视觉作者实际交出的 HyperFrames HTML 和 work.json。每个 work.json 的视频槽以项目 Asset ID 标识，通过 [素材ID与相对路径](素材ID与相对路径.json) 查本包实拍文件；受管作品及局部代理通过 [受管画面ID与路径](受管画面ID与路径.json) 查找。项目时钟、画面区间、字幕、旁白与 23 条 Cue 见 [时间线与字幕](../文档/时间线与字幕.json)。

- [r26 首版](r26/film.html) 及 [绑定](r26/work.json)，全长 3372 帧。
- [crop-only](crop-only/film.html) 修正原片残字，使用 124% 裁切。
- [crop-and-readable](crop-and-readable/film.html) 追加 99% 和 10 万+ 的对比修正。
- [clarity-and-finish](clarity-and-finish/film.html) 追加异常条件字和片尾连续交接。
- [conditional-wait](conditional-wait/film.html) 在上一版上将“下游等待”改为“下游可能等待”。
- [refinement-draft](refinement-draft/film.html) 是增强透视与邻项保持的未采用候选。
- [build.mjs](build.mjs)、[build-refinement.mjs](build-refinement.mjs)、[build-clarity-and-finish.mjs](build-clarity-and-finish.mjs) 是作者的构建脚本，[timing-real.json](timing-real.json) 为 18 段实际旁白帧边界和素材 ID。

最终 Revision 177 沿用首版并以局部 Cue 拼接固定版本。修订窗为 [167,251)、[322,417)、[664,805)、[1052,1244)、[1385,1615)、[1615,1721)、[2596,2732)、[2993,3113)、[3282,3372)，最后文字更正覆盖 [1469,1615)。上述均为项目帧半开区间，30 帧为一秒。最终视频是这些片段、字幕和中文旁白经项目合成的结果。

HTML 的 data-vfc-video-slot、字体变量和动画时钟由 VideoFlowCut 受管渲染器注入。直接双击 HTML 不会自动加载视频槽或显示整片。本包保留源码、ID 映射和实际代理，项目特定的渲染环境由 VideoFlowCut 提供。
