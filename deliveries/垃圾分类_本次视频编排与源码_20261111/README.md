## 怎样理解这些记录

- “原指令摘录”来自参与本片的导演回传或本项目已保存的实际制作简报；没有找到逐字原文的地方明确说明。
- “根据成片和记录归纳”是为了讲清编排关系的事后整理，不冒充当时逐字思考记录。
- 原 R101 画面简报、时间资料和交接状态在[原始指令与交接](原始指令与交接/R101_画面演出制作简报.md)；仅为本包改写了文件与资料路径。R104 后续将画面及字幕统一为“二噁英”。
- 资料目录保存本次整理时另行获取的文字或 PDF；它们不等同于制作当时已登记的网页快照。原始站点的协议、域名和路径拆开记录在[来源索引](资料/来源索引.json)，文档内可点击的文件引用均指向本包相对路径。
- [生产运行记录](制作记录/生产运行记录_相对路径.json)保留原决定与未完成状态。记录中的一份气候变化年报原先被误列为 2019 年清运量依据，已在[事实核查](04_关键决策与事实核查.md)中标明并补充有效资料。

五段已采用 HTML、定义和输出画面，以及六段本项目的过程版源码都在[动效源码](动效源码/阅读说明.md)。[文件校验清单](制作记录/文件校验清单_SHA256.json)记录了本包文件哈希及原始素材核对结果。素材、分场视频、声音、图片和字体均在本目录下；原视频及音频候选标注了“未采用”。

## 重要状态

工作台曾出现画面未及时就绪；导出文件相应帧有画面。R104 导出已通过技术预检及音轨解码检查，但整片未完成连续视听审查，旁白发音、自然度、精确声画同步与填埋场切换的连续复查仍未知。OD 交接包已准备，但没有证据表明 OD 实际接收或完成画面深化。
