## 资源、时钟和运行条件

- 作品画布为 1920×1080，25 fps；各场作品根帧从 0 开始，表中全局帧为时间线上的半开区间。
- 引擎记录为 managed-hyperframes-4，依赖 HyperFrames 0.8.1 和 GSAP 3.14.2。源文件本身是单页 HTML、内联 CSS 与 JS，使用由平台注入的 gsap、window.vfc、字体和素材槽位。HTML 中的 SVG 命名空间是标准标识，不是联网素材。
- 图片由 data-vfc-image-slot 绑定，视频槽以 data-vfc-video-slot 在作品根时钟上注入画面；视频正常速度、静音。旁白与普通字幕在作品外层合成。
- [Noto Sans SC 常规](../素材/字体/NotoSansSC-Regular.otf)和[粗体](../素材/字体/NotoSansSC-Bold.otf)已复制。各“定义_相对路径.json”的交付说明提供相对于该文件的字体路径；图片、视频的 managedPath 同样相对于该定义文件。
- 第一场分拣源 8.000–13.480 秒；第二场堆场源 10.000–11.200 秒；第四场为炉排静照；第五场分拣源 13.480–15.880 秒。详细根帧和事件以各定义及索引为准。
- 原 HTML 依赖平台注入，不是双击即可独立重现完整动画的网页；原始渲染运行时未随本包整体复制。已提供五段渲染画面、原始素材、字体、旁白、字幕及绑定，便于阅读、复用或回到相应运行环境重建。定义副本因相对路径改写而不是可直接冒充原始受管哈希的文件；原源码文字保留不变。
