两份作者冻结稿的文字内容沿用原稿，本包把路径改为相对位置。视觉稿是制作前的计划，成片的实际实现详见角色记录。旧稿仅为冻结后对比而摘录，见 [旧创意稿](旧稿对照/创意拆解.md)、[旧视觉稿](旧稿对照/视觉导演稿.md)、[旧换料图](旧稿对照/换料对照-5.png)。

成片由 OD 的 Local Codex 编写源码。内置渲染器报告无法连接桌面端后，主任务读取同一源码，在浏览器中按 30 fps 逐帧定位时间线并编码视频，再加入锁定旁白。提供 [逐帧渲染脚本](浏览器逐帧渲染.mjs) 供技术复查，运行需本机 Node.js、puppeteer-core、Chrome 和 FFmpeg。脚本参数依次为源码目录、帧输出目录、Chrome 可执行文件路径。随后将帧序列与源码包内的 narration.wav 按 30 fps 编码。

最终文件经解码、帧数、画幅、帧率及音轨检查，视频 H.264，音频 AAC 单声道，12.70 秒。原视觉作者原速复看并检查累积关键帧。音频工具未返回可听声音，旁白听感和逐字重音仍需听审。
