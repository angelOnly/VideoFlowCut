# 导演、创意、视觉与 OD 的实际编排

本说明根据同包的原始交付稿、可读取的角色回执、时间计划、冻结源码及 R40 项目记录归纳。下文的“思路”是根据这些材料写出的可核对的决策理由，不是假装逐字还原作者未公开的思维过程。

## 0. 角色到底是谁

当时会话中能找到实际创建并续接的两个专项：/root/creative 和 /root/materials；主任务负责对用户交付方案、组织样片项目和提交 OD。OD 的 Local Codex 在独立作者任务内实现与返修视觉。没有找到本样片单独名为“主导演”或“视觉作者”的代理派发回执。因此下文“导演”“视觉”是按实际工作和产物划分的职责，不声称有两个未证实的独立代理。

## 1. 导演层：怎样组织整段观看

**要表达的问题。** 用户定稿从单次成功率 99% 切入：在每次独立且成功率保持 99% 的假设下，连续 100 次全部成功约 37%；随后由小失误的恢复和人员介入，过渡到长期稳定、固定机械臂工位，以及人形机器人利用既有工作空间的潜力。关键是把“能完成一次”和“能稳定持续工作”的差别讲清楚，同时保留“有机会”“未来也许”的限定。

**时长决策。** 用户最初希望看约 20 秒，但选定的是约 306 字的完整段落。实际旁白是 48.78 秒，制作了覆盖全文的 1463 帧作品；另以 [0,564) 帧导出 18.8 秒预览，恰好覆盖到“后面的工序也可能跟着等”。这不是将 306 字强塞进 20 秒，也不是全主题长片。

**素材驱动。** 重新检索后取得机器人、车厂、机械臂、托盘、控制器和输送线画面；实际样片使用 8 条素材、17 个视频槽。由于原 R118 的旧旁白和画面已占用主时间线，材料专项提出独立样片项目可保留原项目；最终样片使用新项目。源镜头、出处、每槽实际范围见同目录的素材映射表。

**声音与普通字幕。** 旁白按七个自然段合成并使用真实段级时钟；普通字幕由外层 VideoFlowCut 合成，避免和 OD 画内花字重复烧录。R40 还有全片字幕样式和整体 +8 dB 混合增益。最终样片没有配乐或音效。

## 2. 创意作者：怎样找、选和迁移参考

当时实际做三组创意检索，分别围绕“重复后结果变化”“一步异常影响后续”“固定工作与跨场景工作”；另做一组动作机制检索。原始检索句和选择记录见《检索与选择》。检索依据是画面关系，不限定参考片必须是机器人或科技题材。

| 选择 | 为什么能用于这段 | 实际规定的迁移方式 |
|---|---|---|
| 016-c01，重点原片 3.330–10.942 秒 | 不同题材的画面由共同的巨字、黑白红和红线组织成一体，适合串联多个来源的机器人、工厂画面。 | 复现满幅切入独立画框、框内换内容、深浅页面更替、翻卷、红线接续、多画面集合与交叉字带；将主体替换成已取得素材。016-m02 的满幅与小窗内容是切换，不得声称已证实同一素材连续缩回。 |
| 026-m07，原片 10.083–22.017 秒 | 可把抽象概率的变化变成有形的连续过程。 | 圆阵→方阵→扫描→底边释放→散开/短线重排→再次聚合，落成约 37%；机械臂画面、点阵、文字和背景共同运动。点阵不是工厂真实测试数据。 |
| 032-m09，原片 3.875–11.750 秒 | 原题材虽然是闹钟，但其框内活动画面越框接管、缩回和扫描，能够组织机器人操作素材。 | 倾斜框上升转正→同一 Atlas 活动画面扩大全屏→同一画面回收中央、外围退虚→扫描→圆形结果接管并上移→本片的处理分支。 |
| 007-c02，备选 | 单一主体逐步形成多图墙，可供比较“同一主体在不同场景”的编排。 | 未作为最终采用项；当时人形机器人素材来自不同型号，不能伪装成同一台机器人跨工位。包内保留其卡片、片段和分镜供对照。 |

创意专项回执记录了参考的抽帧观察、候选映射、七段真实配音边界的后续校准；未记录对原片的连续原速观看或听审。交给 OD 的完整演出稿和逐项材料清单位于“02_原始指令与回执”。

## 3. 视觉编排：参考、素材和文案怎样结合

以下是实际交接的七段时间规划；“意图/指令”不等于实测已实现。

| 配音段 / 时间 | 导演稿要求的画面和运动 | 主要材料 |
|---|---|---|
| 单次 99%、独立，0–6.410 秒 | 机械臂活动画面开始；按 016 建立画框和大字；026 点群形成圆阵并发展成方阵。 | 黄色机械臂 |
| 100 次全部成功约 37%，6.410–10.370 秒 | 方阵扫描、释放、散开，浅底聚出 37%；保持“100 次全部成功”的含义。 | 汽车工厂机械臂、点阵 |
| 恢复或找人处理，10.370–18.800 秒 | 借 032 将同一活动画面越框放大并收回、扫描；再用抽象节点分出自动恢复和人工处理，素材分窗持续运动。 | Atlas、独立控制器与输送线 |
| 稳定、处理问题与人员参与，18.800–25.470 秒 | 车厂、黄臂、人员及托盘按 016 集合；红白交叉字带与底层画面分别运动。 | 车厂、机械臂、人员、托盘 |
| 为什么机械臂早在工厂工作，25.470–27.940 秒 | 车厂画面接管，大字和主体共同遮挡、过渡。 | 汽车工厂 |
| 固定工位与围绕任务设计流程，27.940–38.040 秒 | 机械臂、托盘、输送线接力；翻卷换底，红线贯穿。 | 黄臂、托盘、输送线 |
| 人形机器人的机会，38.040–48.780 秒 | 不同人形机器人素材集合、改变尺度和接续；保留机会和未来限定，不合成为同一台设备。 | Digit、Figure、Atlas |

美术上明确使用黑、暖白、红；花字承担关键信息并参与构图和运动，不添加“案例”“示意”“来源”等说明素材的小字。普通字幕另合成。用户要求运动有起势、蓄力、落点和接续，但只有实际连续播放才能评价最终动感。

## 4. OD：接到什么，实际做了什么

首轮确实收到项目内可读的完整导演稿、时序、参考原片/卡片/分镜、素材、旁白、受管源码合同和字体能力；首次任务原文见“02_原始指令与回执/04_交给OD的首次制作指令_原文.md”，逐项交付见“09_OD资料逐项交接指令_原文.md”。

交接明确锁定 016/026/032 的主要关系、准确事实、素材角色、旁白和时间；OD 可在这些边界内深化 16:9 美术、取景、字号、运动曲线、速度起伏和实现细节。该边界是当时实际选择，不应由此推断它一定能保证创意质量。

后续两条反馈分别修正绑定对象格式和未绑定的视频槽。基于 R32 抽帧的第三条反馈要求：裁去 Digit/Atlas 原片说明字；修正 620 帧回跳不一致；增强前段视频、点阵、数字的共同编排，减少分流图依赖纯文字；避免把 Atlas 与“出了问题”直接并置暗示已证实故障。

OD 作者记录的实现包括：采用父层取景、取消黑条；为入场设置初态并预求值时间线；让前段画面参与扫描与点阵散开；以同一 Atlas 槽扩张和回收；分支加入独立人员及输送线画面；325 帧改为“对位·调整 / 持续动作”；保持 17 个真实视频槽绑定和完整根时钟。详见原始返修记录及源码。

## 5. 实际检查与限制

- 作者报告参考材料只查看了分镜和按顺序采样帧，未连续观看参考视频流，也未实际试听完整旁白。不能把“指令要求连续观看”写成“已经连续观看”。
- OD 的 syntax 自检返回 canonical_entry_missing 且 checkedFiles: []，不是通过；另做了本地语法和 17 槽绑定核对。
- 之后 VideoFlowCut 对同一最终动效作品的 21 个指定帧做顺序、反向和干净页检查，结果为 exact；这只覆盖该 21 帧，不等于全片连续视觉审查。
- R40 抽查帧改善了字幕对比和位置；开头仍有较小的“假设 / 每次结果互不影响”，与旁白存在重复。抽帧不能证明节奏或参考复现程度达到用户预期。
- 真实旁白与字幕的文本、时间、样式和外层 +8 dB 在项目快照中；全片声音、动态节奏、创意还原及观众认可没有连续声画验收记录。
