# 机器人进厂视频｜制作资料包

这份资料包记录同一部横屏纯解说视频的编排思路、作者指令、素材依据、动效源码和最终成片。文件引用使用本目录内的相对路径。帧范围均采用 30 fps，起点包含、终点不包含。

1. [主导演编排](01-主导演编排.md)——主线、六场、内容与声音取舍。
2. [创意编排](02-创意编排.md)——真实材料如何进入演出，工件、概率与首尾呼应如何设计。
3. [视觉编排](03-视觉编排.md)——构图、连续动作、试摆、回件观察与返修。
4. [制作端指令与动效源码](04-制作端指令与源码.md)——实际发送的创作正文、五份源码及帧范围。
5. [关键决策](05-关键决策.md)——各项决定、理由和对应材料。
6. [素材与来源](06-素材与来源.md)——七份视频、声音及试摆的包内位置。
7. [用户解说原文](交接原稿/用户解说原文.md)、[视觉作者正式六场稿](交接原稿/视觉作者正式整片指令.md)、[实测旁白时间表](交接原稿/旁白实测时钟.md)。
8. [最终成片](成片/机器人进厂.mp4)。

成片为 1920×1080、30 fps、3957 帧，时长 131.9 秒。已做文件解码、哈希和关键画面抽查。创意与视觉作者的阶段观察范围分别写在各自文档中，整片连续听审尚未完成。项目当时的正式收口仍显示不完整，原因包括首轮分段制作委托及未完成的全片声画和责任复核。

源码从最终项目实际引用的五个固定定义中提取，分别保留原始 HTML 和整理后的槽位信息。它们依赖 VideoFlowCut 的帧时钟及视频资源注入，单独打开源码文件不能直接重现完整合成。
