# 项目定位与操作边界

任何 VideoFlowCut 项目读写前，发现当前实际 MCP 工具及 Schema，读取已连接 Runtime 版本；用 `list_projects`、`target_project`、`read_project` 定位真实项目、Revision、Timeline、目标对象、素材与未结束 Job。不凭名字猜 ID，不因用户只改局部就新建整片。

尚无项目时记录这个事实，由导演提出明确建项参数，主任务创建后读回真实版本。恢复原任务优先续接原项目、当前稿和既有负责人。视频创作从 [协调入口](../production-coordinator/SKILL.md) 调度。

不熟悉对象关系或本次操作涉及依赖、就绪、stale 时，读取 [项目模型](references/project-model.md) 对应章节；Project、Sequence/Timeline、Asset、Story、Script、Scene、Cue 与 ExportArtifact 不混用。当前代码存在的能力不等于本会话已发布能力。

实际提交或 Job 恢复时，主任务读取 [写入与恢复](../production-coordinator/references/project-writes.md)。带当前 `base_revision_id`，写后读回版本、目标与影响；异步任务按其真实合同排序。结果未知先对账，不简单换版本或幂等键重放。

剪辑项目通过已发布 MCP 或工作台持久化控件操作，实际操作者按主任务明确的范围和顺序执行，写后读回版本、目标及影响。素材与作品源码按各自受管方式处理，项目事实以正式接口保存的结果为准。暂时连接失败、服务停止与原因未知先只读诊断并按已有授权恢复；只有确认平台/服务自身 Bug 且阻断当前工作才报独立 Repair Ticket。需要修复平台时遵守根 AGENTS 的用户审核与授权边界。返回真实项目事实、输入版本、目标范围、可用与待处理事项；协作沿 [唯一交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。

# 视频生产协调

先用 [项目基础](../project-basics/SKILL.md) 定位当前 Project、Revision、目标对象与未结束 Job；尚无项目就如实交接，不编造标识。主任务负责沟通、事实、真实分派、确定性提交、技术核对与交付。

## 按任务继续

剪辑中的专业决定由 Codex 的导演与专项作者自主完成，包括选材、剪点、节奏、声音采用、试听、审片和返修；不要求用户试听片段、挑选候选或逐项确认后才能继续。用户已要求全权处理时，将该要求随任务交接传递。检查能力不足按[共享交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md#技术检查、辅助审阅与人工定稿)保留具体未知并继续可执行工作，不转交用户补做检查；只有现有授权无法覆盖的任务范围变化或不可推断的必要信息才向用户询问。

完整视频分派导演前，必须先读取 [视频类型路由](references/video-type-routing.md)，综合本次用户要求、完整稿及需求补充、当前项目和明确有效的已有采用决定；关键类型、说话人、原声或改稿权限仍不明时，由主任务向用户询问最小必要问题，未确认前不创建依赖该选择的正式生产任务。类型明确后才分派主导演，并在每次 `spawn_agent`、`followup_task`、接替和结果续接中传递主类型、人物／声音来源、编辑权限、当前范围及真实 Revision。下游不得自行改片型。

完整视频用宿主 `spawn_agent` 启动持续负责的导演，让其读取 [production-director](../production-director/SKILL.md) 并沿已采用类型进入相应主视频流程。完整解说新片真实分派独立的创意和视觉作者，按当前范围完成创意、机制、美术视觉三项判断；局部机械修改判断影响后沿现有控件执行。准备派发、续接或接替时读取 [任务路由](references/task-routing.md)，按依赖和当前名额安排；Skill 数量不等于代理数量。

`visual_explainer` 与 `presenter_motion` 的完整解释沿[主题入口](../_shared/TOPIC_TO_FILM.md)并行共创；完整新制或主要视觉重做接入[创意统筹](../creative-sequence-design/SKILL.md)和[视觉入口](../visual-treatment-planning/SKILL.md)。职责、同一当前稿、范围接回和返修沿[唯一交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)，不为每项规则再创建代理。

实际写入、生成、渲染、审计、字体选择或恢复时读取 [项目写入](references/project-writes.md) 对应章节，核对实时 Schema，按唯一顺序提交并读回版本、影响与结果。主任务只补真实 ID 和无歧义参数，不补创意。结果未知先对账原 Job，不能换幂等键重放。

## 完整视频的持续协作、OD 对接与返修

完整解释视频和主要视觉重构，由一个持续主导演和一个持续视觉作者负责整片；主任务负责真实分派、项目操作、正式提交、反馈投递和结果接回。

### 一、首轮并行分派

主任务建立完整 ProductionRun，读取当前 Project、Revision、用户要求、文案状态和已有材料，分派持续负责的主导演。建项只记录用户确定的主题、画幅、讲述形式、文案权限和明确的创作偏好。「纯解说」「无真人口播」是讲述形式。完整无真人口播解说以主题相关素材组织主画面，禁止整片采用纯图解，禁止自行把连续图解写成项目的默认创作偏好。

按当前输入和导演的初步观看方向并行分派。只有主题时，先用主题开展取材、参考研究和视觉观察；文案作者交回段落骨架后立即同步。

- 文案职责：按[文案状态](../narration-writing/SKILL.md#按用户提供的文案状态工作)起稿、补稿或接续完整原文。主导演可承接完整稿的锁定与交付职责。
- 素材作者：从首轮按主题广搜可剪画面，分批交实际文件、源段和可见内容。按创意与视觉提出的具体角色续搜。
- 创意作者：按导演的主要视觉单元选片、看片、拆解和逐层换料。以原片时刻为索引，交《创意作者拆解交稿》，写出实际素材如何从入口演到出口。每个单元必须落实一条实际采用的主参考，优先完整创意；完整创意无法承接时选能承担主要变化的动效机制，两种皆缺就继续检索。
- 视觉作者：完整解说新片由独立于创意作者的视觉作者实际承接。首轮并行看片、看素材，接到正式创意原文后按同一演出状态复摆；复摆成立后再做轻量美术统一，并将结果写入同稿的《发给 OD 的完整请求》。局部任务按实际范围续接原负责人。

按[首轮分派](references/task-routing.md#首轮分派)，把对应段落和执行顺序直接写进两位作者的任务消息。创意作者先读「沿原片画面逐步换入本片内容」再写本片替换，视觉作者在复摆前实际读取路由所列的换料、复摆、对照及美术段落。读到截断处就补读相应段落。素材后到时，将实际文件和源段续交原作者，并说明应补完的范围。专项补查由原视觉作者接回，素材补搜继续由原素材作者承接。

完整制作采用创意参考时，首轮明确承担声音职责的作者。将创意作者的原声观察、采用区间、画面映射及锁定旁白交给声音作者，安排其在视觉复摆期间复听和取材。声音作者交回声音意图、音源选择及未解决范围，主任务按当前 Revision 办理计划、需求和正式提交。

### 二、当前成果接回与交叉传递

主任务接回的是实际文件、Asset ID、研究决定 ID、来源指纹、源范围、版本和未完成项；不能只记录 Agent 已启动、已返回或 Skill 已加载。

每次接回结果后，按依赖关系交给真正需要它的原作者：

- 创意作者交回逐单元参考研究：按[场面交接](../_shared/SCENE_DESIGN_HANDOFF.md#唯一交接与责任)区分阶段观察和完成换料的正式稿。只有阶段观察时，开放给视觉作者看片，同时把取材条件交原素材作者，取得后由原创意作者补完该场。将完成的《创意作者拆解交稿》原文、可播放原段、关键帧和实际素材源段原样交给原视觉作者，并续接该场复摆。
- 素材作者返回真实素材：将 Asset ID、实际文件、源范围、可见主体/动作、限制和观察结果交给创意、视觉作者和主导演。
- 创意或视觉作者提出补材需求：主任务通过 manage_asset_requirements 创建或更新对应需求，交原素材作者继续搜索；候选和取得结果再交回视觉作者。
- 动效机制研究返回：将机制 ID、来源指纹、运动关系和适用范围交原视觉作者，与创意参考共同深化。
- 视觉作者更新当前稿：交回按同一演出状态核对的复摆、必要的美术适配和对应制作正文。原片层级或本片替换有缺口时，按原片时刻交原创意作者补稿；复摆或美术适配走样由原视觉作者修正。主导演据视觉交件审核整片叙事、节奏、场间接续和用户要求，采用写入项目后沿原作品接续制作。
- OD 首版返回：将同一 Work、冻结版本、Revision、工作台入口和可检查范围交原视觉作者与导演。

专项补查作者与视觉作者直接协作；素材作者与视觉作者直接协作。主任务负责实际转交和对账，不代替专业作者完成判断。所有结果回到同一份当前稿。

### 三、持续共同编排

主导演持续负责整片主线、事实、观看方向和跨场关系。

完整解说新片由独立创意作者承担参考研究、拆解和逐层换料正文。视觉作者负责接回正文、真实素材观察、照排复摆、整片视觉导演稿、轻量美术统一、镜头、机制和连续场面编排，并持续对接 OD。

专项补查有独立作者时直接与视觉作者沟通；素材作者与视觉作者直接沟通素材作用和补搜缺口。主导演持续接收各作者的新发现并协调调整。

初次创作、OD 制作期间的补充工作和返修都使用这套并行分派、结果接回和交叉传递机制，不另设返修路由。不同工作可以多轮往返，不要求严格串行。一个场面需要补搜时，只续接相应素材或创意任务；其他不依赖该缺口的工作继续。

### 四、正式制作准备

主任务接回创意、机制的实际研究决定和视觉作者的导演稿、时间计划、真实参考与素材。视觉作者交出本次决定、受影响范围和实际消费的研究。让独立补搜继续。当前场面的关键资料缺失时，将具体问题和范围交原负责人处理。

主任务按视觉作者实际交回的画面对照及对应正文登记观察、采用范围和未完成项。只有文字草案、读卡结果或局部主参考的单元保留待补，按缺口续接原负责人。资料齐备的单元继续。采用的原片子段须实际承担该主要单元的主要变化，局部参考记录真实覆盖范围。

作者交付、研究登记、导演采用和提交请求存在差异时，交原作者澄清并修改。主任务负责补齐真实项目参数、冻结资料、正式提交和运行对账。

新增场面提交 `start_motion_authoring` 时提供该场的目标与视觉计划，省略 `opendesign_request.prompt`。程序按目标场面从冻结交付取制作正文及资料。通过 `track_job.result.authoring.startRequest.message` 核对实际送出的场面与正文，通过 Run 回执确认接收。已有场面返修提供指向实际范围的返修指令。

采用参考的原片范围可以是实际研究范围内的子段；同一研究决定内同源、连续的观察可以共同覆盖。导演采用前按返回的参考、缺失区间和职责续接原研究负责人及视觉作者，补看或更正关联后重新提交。交付参考与视觉映射仍指向同一实际采用片段。

先用 `prepare_motion_handoff` 固定导演稿、时间和文件清单。主任务以 `visual_design` 登记相同的 `delivery_ref`、交付的输入版本和实际消费的研究。主导演确认后，以 `adoption` 引用该设计和同一清单，再用 `manage_visual_treatment` 的 `action=adopt` 在一个项目版本中写入本次相关计划的采用及素材。通过 `start_motion_authoring` 提交制作委托。新片开工时无须已有 `MotionWork`。

编辑原稿和登记候选期间继续使用已采用的固定副本。导演采用写入项目后，相关制作按新采用接续。若一场的修改改变相邻场接续，视觉作者和导演一并协调。制作中途换稿时，继续接回原任务的阶段作品；待协调范围读取固定版本和原因，沿原制作任务续修。

正式启动会按所选场面的固定清单自动向本机 OD 补传必需文件并核验哈希；传输失败时保留已核验文件，读回原 Job 后继续。

同一作品已有制作任务时，跟踪该任务并接回当前场面，之后用原制作项目、同一作品和 `continue_from_run_id` 提交下一场。完整解说的正式导出以已采用场面全部接回对应冻结作品为准。缺回件时按报出的场次继续原委托，临时本地合成为草稿。

### 五、OD 制作、当前作品接回与同一协作循环

视觉作者负责解释方案及技术可深化范围，由 OD 制作首版。主任务跟踪原正式 Job 和 OD Run。结果未知先对账原请求。收到首个冻结源码并登记采用后，将 Work、固定版本、Revision、Cue、工作台入口及可查范围交回原作者。首次实际画面观察从此处开始。已授权的工作台修改直接保存并原位复查。

完整视频制作收到 OD 固定源码或本地出片后，主任务用 `wait_motion_authoring` 沿原委托读取登记与采用回执。独立回件沿[受管作品登记与采用](../opendesign-video-production/references/submission-and-recovery.md#受管作品生成和修改)接到目标项目范围。接回时按已完成作品核对实际素材、字体和时钟，并对照既有校样检查关键帧及前后接点。交付前用 `read_production_status` 核对本次作品版本、Cue、Revision 和覆盖范围，以 `get_editor_url` 定位该版本，确认工作台实际播放本次回件。声音试听、问题定位、返修复查与正式导出均以该项目里的对应版本为依据。备用 MP4 作为校样记录；仍待接回的作品保留具体缺口和下一项处理。

接回首个冻结作品后，将 Work、版本、已采用 Cue、作品根帧与项目帧的映射，以及实际事件交给声音作者。续接候选试听、正式上轨和同版混合复核。完成完整视频任务时，按计划核对每项声音的上轨或留白结果。任务只做到 OD 首版指令时，交付声画映射和取声方案作为本次结果。

每次接回作品，将播放入口、Work、Run、冻结版本、Revision 和实际范围交回原视觉作者。后续反馈使用视觉作者的具体要求，沿原作品继续并接回复核。

阶段回执的 `rangeMappings` 将工作台的 `projectRange` 与 OD 的 `workRootRange` 成对给出。若问题只在阶段中的较短范围，调用 `wait_motion_authoring`，在 `range_request` 中填写该阶段的 `run_id`、`frozen_version` 和审阅确定的 `project_range`；使用返回的 `requestedRangeMapping.workRootRange`，连同原 Run 和冻结版本向 OD 返修，不用整段根帧代替短段。

工作台产生返修工作单时，使用现有 `read_agent_work_orders`、`claim_agent_work_order` 和 `complete_agent_work_order`，保留原观察 Revision、Finding ID、项目帧范围并尽量关联对应 ManagedMotion Cue。原 Run 运行中使用原冻结版和换算后的根帧反馈；已结束则以新幂等键和 `continue_from_run_id` 续接原项目、作品与制作任务。新版回到工作台，复查同一 Finding 后才能关闭；完成工作单不自动关闭问题。

接回参考对照后立即读取 `read_production_status`。参考 `issue` 已生成必修 Finding，按 `nextActions` 续接视觉作者与原参考研究负责人，交原作品处理；`inconclusive` 按待审范围补看。复查时使用原 Finding ID，不能把一次新的通过观察当作自动关闭。

OD 每次返回当前作品后，主任务将作品交回原作者团队，重新进入本章第三节的同一协作机制。初次创作、OD 制作期间的补充工作和后续返修使用相同的作者角色、职责边界、结果接回和问题回流规则：

- 视觉作者检查真实素材、素材主次、构图、美术、排版、镜头、运动和整片视觉连续性；判断视觉方案本身是否成立，并作为 OD 主要专业对接人整理具体反馈、提出修改要求和复核结果。
- 视觉作者的创意职责对照原始参考检查迁移；发现偏差时，记录原片过程、当前作品差异和应保留的核心关系，并确定修改。
- 素材作者按视觉作者和主导演提出的具体缺口，继续搜索、核实和补充素材。
- 文案作者按主导演协调的范围修订内容、事实和讲述。
- 主导演持续检查整片内容、事实、主线和场间关系，协调优先级、跨场影响和重大导演决策。
- 主任务负责正式反馈投递、Job/Run/Revision/Frozen Version 对账和结果接回。
- OD 根据视觉作者确认的制作反馈，沿原委托和同一 MotionWork 修复实现问题，并返回新的可检查版本。

若是设计本身偏弱，原视觉作者调整当前稿，涉及素材缺口时续接素材作者，主导演检查事实和跨场影响。正式采用的关系、资料或时序有实质变化时，重新准备受影响范围并更新采用。

如果视觉方案本身成立，只是 OD 没有准确实现，视觉作者直接提出实现反馈，主任务投递给原 OD 委托，OD 沿原作品返修，视觉作者复核。此类实现返修不重复走完整创意研究和导演 adoption。

### 六、同一协作循环中的问题责任与最终交付

按问题归属处理，不增加独立审批节点：

- 内容、事实、用户锁定项、主线和场间关系：主导演负责判断与协调。
- 创意参考理解、创意迁移和风格还原：视觉作者承担创意职责并确定本片处理方式。
- 真实素材组织、构图、美术、排印、镜头、运动和整片视觉连续性：视觉作者负责提出修改要求并验收。
- 素材搜索、取得和来源核实：素材作者负责。
- 源码、绑定、时钟、渲染和已采用方案的实现偏差：原 OD 制作作者负责修复。
- 正式反馈投递、Job/Run/Revision/Frozen Version 对账和结果接回：主任务负责。

主导演持续掌握所有问题和返修，协调优先级、跨场影响和是否需要重新采用；但不代替视觉作者与 OD 逐项讨论字体、构图、镜头和运动参数。

导演给出整片专业判断。主任务按用户要求完成当前最终文件审阅，再按[本次范围收口](references/task-routing.md#按本次范围收口)读取完成评估。`incomplete` 时按 `nextActions` 的负责人、范围和关闭条件实际续派，接回观察或修订并复查。仅在同一任务、最终版本、交付文件和要求的范围完成后按整片交付。

## 交回结果

返回当前稿、实际对象与版本、已完成范围、确定缺失、观察未知、原作者续接结果及真实可用文件。技术条件允许时可继续生成预览或导出；已确定的设计缺失、实现遗漏和必需表现未兑现仍由主任务续接原负责人处理，不能以“已导出”结束制作。感知能力不足只保留对应观察未知，其他已授权工作继续，不伪造通过，也不无限盲改。技术输出、创作完成与用户认可分别报告。角色接替、版本和事实传递遵循[唯一交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。

`presenter_motion` 完整解释首轮同步落实人物导演、材料探索与整场视觉责任；人物源返回后继续接回材料、作品、绑定及合成。`vlog` 由事件导演按真实原片决定是否补材和增加视觉工作。收口范围依据本次用户要求确定，整片使用 project，内容范围使用 beats，局部对象修改使用 objects，明确的时间区间使用 frames（结束帧不包含在内）。独立工作台审阅自动以实际观察区间建立 review_only 任务。交付前按任务路由中的“按本次范围收口”读取实际制作状态、处理缺项、调用完成接口并读回结果。

当前范围采用 OpenDesign 时，主任务按[任务路由](references/task-routing.md#视觉派发与接回的完成口径)续接原视觉负责人。创意作者交回参考场面后，将完整采用意见、参考视频、文案和实际素材交给视觉作者，与创意作者共同完成本片编排。

接回视觉负责人写好的制作简报、实际资料路径和完整请求，补齐正式项目参数并提交。实际作品和修订版本继续接回原视觉与创意作者，对照参考检查和返修。

# 任务范围、真实分派与原负责人续接

本页只解决交给谁、交什么、何时接回。项目定位沿[项目基础](../../project-basics/SKILL.md)，正式操作沿[项目写入](project-writes.md)；角色身份、版本和完整交接字段以[共同交接约定](../../_shared/PROJECT_REVISION_AND_HANDOFF.md#代理角色与交接)为唯一依据。

## 按用户实际范围分派

每次剪辑建立或续接实际范围的 ProductionRun，完整解说新片（`full_creation`、`visual_explainer`）真实分派两位独立作者代理，分别承接 `creative_research` 和 `motion_research`、`visual_design`；其他类型按相应路由执行。登记实际 agent、输入版本和使用的方法。局部编辑分别判断表达、动作接点和画面影响，以 `record_creative_decision` 记录三项决定、依据和对象；视觉决定用 `input_decision_ids` 引用本次创意与机制判断。沿用旧决定时填写 `reused_decision_refs` 并写明本次核对依据；多个来源合计覆盖本次判断范围，部分沿用与新增判断按范围分别记录。没有历史决定时查看当前作品后形成判断。

制作前用 `read_production_status` 检查 `preparation`，按缺项续接原视觉作者。正式画面委托必须传 `production_run_id`。工作台局部修改在同一 Run 的准备检查后使用现有控件，保存后读回 Revision。作品返回时分别填写三项 `responsibility_reviews`，引用实际分派与本次判断，说明实际观察和结论；问题引用原 Finding 沿原作品返修，复查确认后关闭。普通字幕单帧只核对静态文字，运动沿用须有本次影响判断。

分派采用 [唯一视频类型路由](video-type-routing.md) 的当前结论；人物专属参考只随 `presenter_motion` 或 `hybrid` 中已确认的人物子范围发给导演／视觉／人物专项。其他类型继续使用原有专业方法。单个图表、实拍或人物窗口变化不是重新路由的依据；收到不匹配的委派时，返回主任务核对，不自行补造路线和对象。

完整视频建立持续负责的[总导演](../../production-director/SKILL.md)；新制或主要重构按[主题工作流](../../_shared/TOPIC_TO_FILM.md)并行启动并按[共同交接](../../_shared/PROJECT_REVISION_AND_HANDOFF.md)保留各项职责与接回条件。局部任务交原负责人。

完整解说默认完成整幅画面与连续观看的设计。导演交清准确内容、真实材料、表达重点与前后关系；视觉作者决定主体、背景、文字和动作怎样共同成立，花字、基础排印、实拍、图形、静止或切镜按本场用途选择。普通字幕独立，出处、原件页码和研究备注不作为新增说明上屏；主任务传同一画面文字规则，不只交“解释这个表”。没有偏好时仍从[整场视觉入口](../../visual-treatment-planning/SKILL.md)直接制作，传递本任务明确要求、用户主动保存的默认及当前设计，未指定部分由导演与作者判断。普通制作使用已整理的本地方法，不派发博主研究，不将本片选择写成用户永久偏好。

完整人物混合解释从首轮交付整场视觉责任，不派成“人物段加花字、无人段做动画”。
交当前完整句群、主要观看任务、实际材料、前后关系、目标画幅和真实锁定项；
人物作为带源时钟与表演限制的视频材料进入同一设计，不预分配不可改变的主画面。
人物源返回后续接原视觉作者；生成视频只完成人物素材。

沿当前口播和分镜派发人物源缺口，不遍历全文语音段生成人物。范围已明确的部分
可以先做，后续增加或改分镜仍走原流程。调用实际发布的 v2 源生成和使用合同，
读回真实素材及当前引用；不重新组织整片主线，也不把旧 Job 的位置覆盖回新画面。
接回真实画面与完整发展、资源和源码、已观察范围及未完成用途。
只有布局名称、颜色、机制编号或人物文件时，继续原任务，不报整场完成。
正文锁定只限制文字与相应声音修改，不减少已委托的取材和整场视觉责任。
人物成为某种窗口后，主要材料的观察、关系发展和交接仍须有实际制作产物；
缺少哪项作用就续接对应作者，不能把完整工作单改写成少量装饰任务。

尚无 Project/Revision 时，把用户需求和真实建项状态交导演形成建项建议；主任务依明确参数创建后读回版本，再交导演确认。探索没有最终 Scene、Beat 或精确时长也可继续，不为交接字段编造对象。

首次接回按当前阶段进行。主题阶段同时续接文案、素材、创意和视觉，将文案初稿、材料与参考发现交给相关作者继续工作。制作前按下方路由接回创意原文，再接回视觉作者确认的复摆、完整简报、实际资料和完整请求，交导演判断主要采用。主任务正式启动 OD 后，接回同版连续作品与源码，交原导演与视觉作者观察和修订。

按当前可用名额真实分派，分别回传文案、素材和视觉作者的三项职责决定。首轮作者并行，有用的发现即时交相关作者。子代理不递归分派。原视觉作者贯穿设计、OD 交接和实际作品返修，OD 编写及修改作品源码。

导演与视觉开始构思关键动作时，就指定持续负责的声音作者，可由职责相邻的现有作者兼任。交当前声音意图、实际动作与旁白约束；有生成需求时接回完整指令，由主任务提交 `submit_sfx_generation`，再把真实候选交回同一作者检查、选段和混音。不因暂无最终动画帧推迟全部选声，也不在提示词或 Job 成功时结束这项责任。粗剪与交付前接回每项意图的采用、留白或未完成结论。

从零创作只交当前准确内容、真实材料、声音字幕与限制，不附同题旧作品布局、源码或历史项目身份。局部修订则必须交当前作品、源码、已认可部分和实际问题范围。隔离试验的禁止联网等限制不继承到普通生产；已知宿主历史注入如实记录，不宣称自然语言禁令实现了严格隔离。

## 完整新制的并行路由

完整新制或主要表达重构，建立一个持续负责的主导演。主导演全程负责整片主线、观看目标、事实边界、跨场关系、创作协调、导演采用和最终整片判断。

### 首轮分派

主导演建立初步方向后，主任务按专业职责并行分派：

- 主导演：production-director，负责整片导演。
- 文案作者：必须加载现有 `narration-writing`，按[文案状态](../../narration-writing/SKILL.md#按用户提供的文案状态工作)起稿、补稿或接续完整原文。
- 真正分派后，在现有 `update_production_run` 中如实登记文案职责 `narration`、`skill_ids` 中的 `narration-writing`；素材作者使用 `asset_sourcing`。分派记录是来源声明，不代替宿主执行或实际加载技能。
- 素材作者：visual-asset-sourcing，围绕主题广搜并交实际可剪素材，按创意及视觉的具体角色补搜。
- 创意作者：读取[创意库](../../creative-case-library/SKILL.md)和[创意统筹](../../creative-sequence-design/SKILL.md)选段并看片。写本片替换前实际读完[沿原片画面逐步换入本片内容](../../creative-reference-to-sequence/SKILL.md#61-沿原片画面逐步换入本片内容)，按该段方法把本片真实素材、源段及文字对应到原片的主要变化。素材未齐先交观察，取得后由原作者把同一场补成带实际替换的演出正文。完整创意无法承接时按[机制库](../../motion-case-library/SKILL.md)查能承担主要变化的原段。
- 视觉作者：从首轮并行参与。正式复摆前接回创意原文和实际素材，实际读取[逐层换料](../../creative-reference-to-sequence/SKILL.md#61-沿原片画面逐步换入本片内容)、[用本片素材复摆所选原片](../../visual-treatment-planning/SKILL.md#2-用本片素材复摆所选原片)、[对照参考检查本片编排](../../visual-treatment-planning/SKILL.md#6-对照参考检查本片编排)和[轻量美术统一](../../visual-treatment-planning/references/art-direction.md#从一条全片美术主参考做轻量统一)的正文，亲自打开相应原片。按同一演出状态复摆并核对，成立后再做跨场适配，按[制作简报](../../opendesign-shot-brief/SKILL.md)写同一场的制作正文，按[机制库](../../motion-case-library/SKILL.md)补查和登记实际采用的机制。
- OD：在视觉方案和正式交付成立后，使用 opendesign-shot-brief 与 opendesign-video-production 完成制作深化。

有多窗并列、素材墙或接管动作的场面，首轮派工附[多素材场面的取材与复摆](../../_shared/SCENE_DESIGN_HANDOFF.md#多素材场面的取材与复摆)。素材作者按实际画面角色交可区分的源段，创意作者在逐层换料中标出延续与接管，视觉作者在关键共存和场间接点确认实际取景可辨，再将绑定写入制作正文。

完整解说新片分别实际启动和登记两位作者。实际派工消息直接点名上列段落、执行顺序和各自的交件。首轮写明每个主要视觉单元必须有主参考，续接实际素材时再指出本场要补完的交件。用 `update_production_run` 记录各自实际 `agent_id`、职责、范围、输入版本和技能；创意和视觉的正式迁移分派均登记实际使用的 `creative-reference-to-sequence`。主任务把完成逐层换料的《创意作者拆解交稿》、原片和对应源段原样转交视觉作者，接回其确认的复摆和冻结请求交主导演。

### 持续接回与交叉传递

任意作者返回当前成果或新发现时，主任务及时接回真实文件、决策 ID、来源、版本和未完成项，并传给需要使用的原负责人。

- 素材作者的真实素材、Asset ID、源范围和观察交给视觉作者和主导演。
- 视觉作者的原片、采用范围、完整研究和正式研究决策交给主导演。
- 视觉作者的素材观察、画面机会和补材缺口交给素材作者和主导演。
- 文案作者把段落骨架、当前正文、锁定项和声画说明交主导演；根据内容影响同步素材、创意和视觉作者，确保各方使用同一当前稿版本。

### 共同编排

### OD 返回后重新进入同一协作循环（与首轮创作共用）

OD 每次返回当前作品后，主任务将同版工作台入口、Revision、Work、Run、Frozen Version 和实际范围交给原视觉作者，并同步主导演、文案作者及受影响的素材作者。文案作者检查当前正文与实际声画表现是否仍匹配；只有发现文案问题且处于用户授权范围内时才修订，不为配合画面而擅自改变锁定原文。首轮创作与后续返修使用相同的职责、结果接回和问题回流方式。

- 视觉作者作为 OD 的主要专业对接人，检查素材组织、构图、美术、排版、镜头和运动，判断视觉方案本身是否成立；需要 OD 修改实现时，整理具体范围、当前表现、目标表现和必须保持的关系，并向 OD 提出反馈。
- 视觉作者对照原始参考检查创意迁移，发现偏差时记录原片过程、当前作品差异及应保留的核心关系，确定修改。
- 素材作者在发现素材不足、身份错误或源范围不合适时，按视觉作者提出的缺口继续搜索、核实和补充。
- 文案作者在内容、事实或讲述需要变化时，按主导演协调的范围修订当前稿。
- 主导演持续检查整片内容、事实、主线和场间关系，协调优先级、跨场影响和重大导演决策。

首次接回按当前阶段进行。主题阶段同时续接文案、素材、创意和视觉，将文案初稿、材料与参考发现交给相关作者继续工作。制作前按下方路由接回创意原文，再接回视觉作者确认的复摆、完整简报、实际资料和完整请求，交导演判断主要采用。主任务正式启动 OD 后，接回同版连续作品与源码，交原导演与视觉作者观察和修订。

首次视觉派发交准确台词、真实素材与源范围、观看目的、目标画幅和前后接口。视觉作者按[视觉设计](../../visual-treatment-planning/SKILL.md)交导演稿、素材映射、主要美术和运动。不得把只有色号和形容词的摘要标为可制作。普通字幕沿统一规范，机械修改直接定位现有作品。

导演与视觉开始构思关键动作时，就指定持续负责的声音作者，可由职责相邻的现有作者兼任。交当前声音意图、实际动作与旁白约束；有生成需求时接回完整指令，由主任务提交 `submit_sfx_generation`，再把真实候选交回同一作者检查、选段和混音。不因暂无最终动画帧推迟全部选声，也不在提示词或 Job 成功时结束这项责任。粗剪与交付前接回每项意图的采用、留白或未完成结论。

## 完整新制的并行路由

完整新制或主要表达重构，建立一个持续负责的主导演。主导演全程负责整片主线、观看目标、事实边界、跨场关系、创作协调、导演采用和最终整片判断。

### 首轮分派

主导演建立初步方向后，主任务按专业职责并行分派：

- 主导演：production-director，负责整片导演。
- 文案作者：必须加载现有 `narration-writing`，按[文案状态](../../narration-writing/SKILL.md#按用户提供的文案状态工作)起稿、补稿或接续完整原文。
- 真正分派后，在现有 `update_production_run` 中如实登记文案职责 `narration`、`skill_ids` 中的 `narration-writing`；素材作者使用 `asset_sourcing`。分派记录是来源声明，不代替宿主执行或实际加载技能。
- 素材作者：visual-asset-sourcing，围绕主题广搜并交实际可剪素材，按创意及视觉的具体角色补搜。
- 创意作者：读取[创意库](../../creative-case-library/SKILL.md)和[创意统筹](../../creative-sequence-design/SKILL.md)选段并看片。写本片替换前实际读完[沿原片画面逐步换入本片内容](../../creative-reference-to-sequence/SKILL.md#61-沿原片画面逐步换入本片内容)，按该段方法把本片真实素材、源段及文字对应到原片的主要变化。素材未齐先交观察，取得后由原作者把同一场补成带实际替换的演出正文。完整创意无法承接时按[机制库](../../motion-case-library/SKILL.md)查能承担主要变化的原段。
- 视觉作者：从首轮并行参与。正式复摆前接回创意原文和实际素材，实际读取[逐层换料](../../creative-reference-to-sequence/SKILL.md#61-沿原片画面逐步换入本片内容)、[用本片素材复摆所选原片](../../visual-treatment-planning/SKILL.md#2-用本片素材复摆所选原片)、[对照参考检查本片编排](../../visual-treatment-planning/SKILL.md#6-对照参考检查本片编排)和[轻量美术统一](../../visual-treatment-planning/references/art-direction.md#从一条全片美术主参考做轻量统一)的正文，亲自打开相应原片。按同一演出状态复摆并核对，成立后再做跨场适配，按[制作简报](../../opendesign-shot-brief/SKILL.md)写同一场的制作正文，按[机制库](../../motion-case-library/SKILL.md)补查和登记实际采用的机制。
- OD：在视觉方案和正式交付成立后，使用 opendesign-shot-brief 与 opendesign-video-production 完成制作深化。

有多窗并列、素材墙或接管动作的场面，首轮派工附[多素材场面的取材与复摆](../../_shared/SCENE_DESIGN_HANDOFF.md#多素材场面的取材与复摆)。素材作者按实际画面角色交可区分的源段，创意作者在逐层换料中标出延续与接管，视觉作者在关键共存和场间接点确认实际取景可辨，再将绑定写入制作正文。

完整解说新片分别实际启动和登记两位作者。实际派工消息直接点名上列段落、执行顺序和各自的交件。首轮写明每个主要视觉单元必须有主参考，续接实际素材时再指出本场要补完的交件。用 `update_production_run` 记录各自实际 `agent_id`、职责、范围、输入版本和技能；创意和视觉的正式迁移分派均登记实际使用的 `creative-reference-to-sequence`。主任务把完成逐层换料的《创意作者拆解交稿》、原片和对应源段原样转交视觉作者，接回其确认的复摆和冻结请求交主导演。

### 持续接回与交叉传递

主任务使用 `prepare_motion_handoff`，传当前 `base_revision_id`、`brief_path`、`timing_plan_path`、`selected_scene_ids`、创意与机制参考和 `scenes`。每个场面给 `sceneId、status、visualRoles、process、preserve、adapt`；采用参考放入 `references`，逐项提供 `kind`（`creative` 或 `motion`）、`id、sourceSha256、startMs、endMs、purpose`。其他按场面使用的声音、美术等资料在顶层 `references` 中声明，并以场面的 `resourceIds` 引用。画面对象写实际用途与 Asset ID；视频使用素材文件的本地范围。工具从项目收集引用的素材，也可在顶层 `assets` 指定来源或补充资料，并返回清单路径、哈希、文件及逐场面缺口。

就绪场面在 `visualRoles` 写明对象、参考作用、具体用法和使用的 `assetIds`，没有素材时用空列表。照片、文字和图形可作为同一对象描述；视频填写相应 `sourceRanges`。`visualPlan` 从导演稿原文摘录 `primaryRoles`、`composition`、`sequence`、`attentionPath` 和 `odBoundaries`，空间关系的 `roles` 引用已登记视觉角色。逐条填写采用的 `referenceMappings`，包括研究决定、参考身份、原片范围、目标角色、处理方法、保留关系和场面内项目时间线半开帧范围 `targetRange`。未就绪场面允许暂缺。导演稿更新后重新准备并采用交付；分别核对参考库指纹和实际文件哈希。

采用的原片片段可位于同一研究决定已观察范围之内；同源连续观察可共同覆盖。场面参考与视觉映射中的采用片段保持一致。采用检查返回缺失区间或研究关联时，交原研究负责人和视觉作者核对，修订交付后再提交。

`composition` 填 `opening、primarySubject、supportingSubjects、spatialRelations、textAndGraphics、ending`，空间关系每项填 `roles` 和 `relation`。`sequence` 按观看顺序填 `purpose、subjects、action、retainedElements、transition`；`attentionPath` 写观看中心变化，`odBoundaries` 填 `locked、adjustable、escalation`。允许为空的对象或可调整项明确使用空列表。设计文字和参考映射中的处理、保留关系须是导演稿中的原文，交付包固定全文和场面摘要并核对一致。

`odBoundaries.locked`从导演稿逐字摘录本场已采用的观看目标，以及必须实现的主要效果与关键关系，写到具体对象和变化。`adjustable`填写制作端可独立深化的参数和实现细节，`sequence`填写完整演出过程。主要关系需要改变时，由视觉作者更新同一稿与受影响交接，涉及内容或跨场影响时由导演协调。

视觉作者用这组具体关系检查阶段作品。已写明而未实现的内容交原制作作者修正，设计本身不足的内容由视觉作者更新当前稿。实际效果结论依据同版作品形成。

主任务先以 `record_creative_decision` 的 `visual_design` 阶段引用候选交付清单。导演确认后，`adoption` 引用该视觉设计及同一 `delivery_ref` 的 `manifest_path、manifest_sha256、scene_ids`，主任务通过 `manage_visual_treatment` 的 `action=adopt` 一次写入相关计划、采用和该计划明确要求进入作品的素材，成功后新采用生效。采用时核对必需素材已在计划范围的交付中；制作启动传对应 `production_run_id` 和 `visual_treatment_ids`，连接器核对制作端真实文件、当前素材与采用稿后发送完整请求。候选登记期间原任务继续；在途换稿后的待协调作品按回执固定版本接回并沿原任务续修。

视觉作者从首次委托开始担任 OpenDesign Cloud 的专业负责人，决定本次制作内容、优先交回的连续范围及前后接点，并编写完整制作请求。请求写清本片目标、具体画面发展、真实素材、参考范围、必须实现的关系、可深化内容和阶段交件要求。

导演稿的 `## 发给 OD 的完整请求` 与逐场正文随稿件一起冻结。新增场面由 `start_motion_authoring` 按目标场面取共用要求和该场原文，主任务省略 `opendesign_request.prompt`。制作作者按实际目标帧执行，打开随包采用的参考原段，复看连续范围和必要接点，再查看本片对应素材。整片稿提供跨场衔接的上下文。

制作期间，原视觉作者直接负责方案解释和设计问题处理。主要构图、素材关系、字组或演出过程存在空白时，由视觉作者补齐当前稿；制作作者依据已确定的设计实现动态源码。已确定设计的实现问题由原制作作者修正。制作端需要改变主要关系时，将具体问题交回视觉作者。视觉作者处理视觉设计，涉及内容、事实或跨场影响时由导演协调。

每次阶段作品返回后，视觉作者打开同版实际作品，按原目标检查素材、美术、构图、文字、运动、阅读状态和接续，写出具体修改要求、需要保留的内容及复查范围。新版返回后，由同一视觉作者检查反馈是否落实。

实际观看的范围和方式照实记录。只读卡片、分镜或部分抽帧时，记录尚未看清的动作和节奏，并继续补看对应过程。文件可读、作者实际观看与作品实现分别按真实情况说明。

先按采用关系明确谁占据画面、谁保持、谁接管、文字与背景如何响应，以及从上一场接什么、向下一场留什么。制作作者在视觉作者确定的关键构图、路径、状态、先后与接续内选择技术实现，深化曲线和具体帧。把所用参考及范围、应交付的画幅和源码约定一并写进请求。

资料无法读取时返回具体文件。素材无法支持某项表现时，指出缺少的动作、画面或持续时间，交原视觉作者处理。指令与参考表现存在影响制作的冲突，或需要改变主要编排时，由创意与视觉共同更新简报。

读[项目源码规范](references/hyperframes-contract.md)及 read_motion_capabilities，
附本轮已经发布的输出约定。规范尚未发布时，可在 OD 制作观察，但不声称已接回 VFC。
明确交回项目中可读取的完整源码入口及作者清单，不假定默认 artifact 就是 HTML 源文件。已发布冻结能力时由作者明确交件、固定源码与清单，主任务按同一冻结身份接回；能力缺失不得声称已经冻结。

## 素材驱动参考迁移的执行要求

本节适用于完整新制、主要视觉重做和需要重新迁移创意参考的场面。

### 1. 先读取完整制作简报

制作作者必须读取 opendesign-shot-brief 形成的完整制作简报。

打开导演稿点名的原片与本片素材，按已采用的导演稿直接制作首版。先交一段包含完整变化、能在工作台连续播放的画面，注明作品版本和帧段。若素材时长、裁切或中文排版会破坏指定效果，指出具体镜头和可行改法，交视觉作者确定后沿同一作品续做。

不能仅凭简报摘要、创意卡编号、关键帧或素材名称开始制作。

### 2. 理解参考与本片素材的对应关系

对照参考原片检查：

- 主要素材如何组合。
- 主体和辅助画面如何安排。
- 文字如何参与构图。
- 背景和空间怎样变化。
- 镜头如何改变观看位置。
- 动作如何接力和共同发生。
- 完整画面怎样形成结果。

同时检查本片素材能否承担简报规定的视觉角色。

不能擅自将真实素材替换为原创图形或其他无关内容。

### 3. 制作首版并深化整场视觉

以当前导演稿、时间计划、参考和真实素材为依据，在同一根时间线上实现完整场面。重点检查下列内容。

- 素材取景、比例与位置。
- 主体和辅助素材的空间组织。
- 中文排版与文字动作。
- 背景、前后层次和视觉中心。
- 镜头运动及主要动作。
- 素材之间的接力、叠放和切换。
- 连续动作的节奏、停顿与接点。

不得将完整场面缩减成单个动作、静态展示或普通标题动画。

### 4. 自主深化，但不改变主要创意

制作作者在视觉作者确定的关键构图、路径、状态、先后与接续内选择技术实现，深化曲线和具体帧。

如果发现原简报无法实现，必须返回具体问题和可替代方式。

不得静默取消素材、缩短主要表现或改变场面含义。

### 5. 及时交回代表性连续范围

第一版具有代表性的连续范围完成后，使用现有阶段交付能力返回同版作品。

日常预览和审阅统一回到 VideoFlowCut 工作台：发布固定源码与作者清单，由主任务接回实际范围和 `editorUrl`。不为日常查看另建播放器或生成 MP4；只有正式交付、离线检查或明确的渲染差异诊断才按需生成媒体。

阶段清单的 `work.creativeBrief` 如实说明已实现的参考关系及对应作品范围、尚未实现的主要设计、对导演稿的偏差、自主深化及需其他作者处理的问题；接回回执中的同名说明。它是作者自述，不代替实际观察；源码、绑定和 Job 成功也不构成视觉通过。

导演、创意和视觉作者可以在其他场面继续准备期间检查该范围。

发现问题后，根据实际问题类型返回对应作者。

主要编排问题由创意与视觉共同修订；素材不足交素材作者；实现遗漏由同一制作作者修订。

### 6. 返修必须保留原委托身份

使用当前已发布的 Run、作品版本和冻结范围提交反馈。

同一 Run 尚在执行时，沿现有反馈机制继续。

原 Run 已结束时，使用现有 continue_from_run_id 续接原作品。

不能为了局部修订重新创建一套互不关联的作品。

### 7. 实际结果检查

作品返回后，原创意与视觉作者对照参考检查完整场面。

导演检查整片发展和前后连接。

不能只检查源码是否存在、文件是否成功生成或 Job 是否 succeeded。

必须区分工程完成、设计兑现和实际观看结果。

## 观察与返修

### 角色对接与返修责任

OD 每次返回的当前作品都重新进入主导演、创意作者、素材作者、文案作者和视觉作者共同使用的同一套协作机制；不创建独立的返修阶段或第二套流程。初次创作、补材、视觉修改和 OD 返修使用同一组作者与同一套问题回流规则。流程只保留当前目标范围制作准入和完整作品最终交付两个正式检查点；各作者的专业判断不另设审批节点。主任务负责正式反馈投递和版本接回。

视觉作者是 OD 的主要专业对接人。你必须将视觉作者作为视觉方案解释、制作问题反馈和视觉验收的直接负责人，不得绕过视觉作者，让主导演逐项决定字体、构图、镜头和运动参数。

#### 视觉作者负责

- 解释当前导演稿、参考决定、真实素材与整场观看关系。
- 指定需要检查的作品范围和前后连接。
- 检查真实素材、素材主次、构图、美术、排版、镜头、运动和节奏。
- 将视觉问题整理成具体修改要求。
- 判断修订是否达到视觉方案要求。

#### 创意作者负责

- 对照采用的原始参考检查创意迁移。
- 指出原片对应过程、当前作品偏差和需要保留的核心关系。
- 与视觉作者共同确认创意类修改方向。
- 对修订结果再次进行参考对照。

创意作者不是 OD 所有制作问题的总对接人，不直接替代视觉作者决定本片最终构图和制作参数。

#### 主导演负责

- 检查内容、事实、整片主线和场间关系。
- 判断修改是否影响其他场面、声音时序或整片方向。
- 决定是否需要重新采用或调整导演方案。
- 持续掌握返修进度并协调优先级。

主导演全程负责整片，但不因此成为所有视觉问题的直接执行人。

#### 主任务负责

正式投递反馈、保留原制作委托身份、对账 Job/Run/Revision/Frozen Version、接回新版本并将同版作品交回原作者。

#### OD 负责

根据视觉作者提出的具体要求修复制作实现、源码、绑定、时间轴和渲染偏差。发现素材限制、技术冲突或原设计无法实现时，先向视觉作者说明问题和可行替代方式；涉及创意迁移时由视觉作者与创意作者共同核对；涉及事实和跨场关系时交主导演协调。

不得静默改变主要视觉主体、素材主次、已采用参考核心关系和场间接续。不得为了制作方便将完整演出缩减为普通缩放、淡入或独立图形说明。

### 接回能够实际查看的作品

首个具有代表性的连续范围完成后，沿已发布的阶段交件能力提交。主任务取得同版作品，将实际版本、范围和声音情况交回原导演、视觉与创意作者。

创意与视觉带着采用参考查看本片对应范围，检查具体素材组织、构图、文字、背景和运动。导演沿粗剪与返修方法判断材料组织、观看发展和前后关系，并组织需要的补材或重新编排。

查看范围应包含所选表现的完整变化及必要接点。实际观察方式、覆盖范围和待确认内容随反馈记录。

创意作者判断选中这一段的吸引力、发现和发展是否做出来。视觉作者检查素材组织、构图、文字、背景、镜头、运动和节奏是否实现。

### 把问题写成能够修改作品的反馈

反馈写清本片哪一段实际出现了什么画面，参考中对应过程怎样表现，什么表现遗漏或变弱，本次需要达到什么结果，以及已经成立、需要保持的内容。明确这次需要重新安排哪些素材、构图、文字或动作。

素材使用不足时，重新安排素材的出现、换位、切换和接力。画面长时间没有发展时，重做这一范围的连续变化。文字失去构图作用时，重新安排它与素材、背景的共同动作。节奏偏弱时，调整行程、用时、动作交叠、发力和停顿。

所选场面需要重新组织时，由创意与视觉共同改写该段编排，再交原制作作者完成。涉及事实、正文和跨段关系的变化交导演协调。

### 将反馈送回同一制作委托

使用实际阶段回执中的作品版本和发布 Run 定位反馈。`steer_run` 的 `run_id` 使用观察版本的发布 Run，`frozen_version` 与该版本配对，影响范围使用作品根帧。由服务定位同一委托当前接收反馈的 Run。

记录反馈 ID、实际范围、具体问题、需要完成的修改和用户锁定项。反馈接收状态、作者处理情况和新版复查结果分别记录。

接收结果未知或轮次不匹配时先读取原委托与反馈记录，按原身份对账。任务已经结束后，视觉作者交回原作品版本、源码、修订范围和保持项；主任务读取当前 Revision 和目标 Cue，以新幂等键调用 `start_motion_authoring`，在 `opendesign_request.continue_from_run_id` 中填写原作品发布 Run，选择 `replace_cue` 或 `replace_range`。需要沿用原作者配置时，传入已核实的 `agent/model/serviceTier`。新 Job 接回修订作品。

同一次修订跨多个 Cue 时，简报交清所有范围并沿用同一 `work_id` 制作一次新固定版本。先采用明确的首个目标，核对该版本的 `readyRanges` 后，主任务用 `manage_effect_cues(action=adopt_work)` 将同一 `work_id` 的当前版本依次采用到其余授权目标。每次读取当前 Revision，接回全部采用结果后复看完整连接；未重新采用的片段继续使用原固定版本。

### 修改后查看实际新版本

# 创意参考检索与观看

由承担创意职责的持续视觉作者执行，结合本片画面判断参考用途。接收主题、用户要求、当前文案和已经发现的材料，通过检索与观看找到值得照着做的具体场面。

首次在本任务开展创意研究时，视觉作者在提出查询前完成[创意研究 R40 步骤](../creative-sequence-design/SKILL.md#创意研究必读案例)和[视觉研究 R40 步骤](../visual-treatment-planning/SKILL.md#视觉创意研究必读案例)。同一作者对同版资料已完整观看时，按各职责完成理解与对照，不重复播放相同资料。

## 建立全片参考研究地图

看完整文案和当前可用的真实素材，按观看目的把全片排成连续镜头组。对每组写明本片范围、观众从哪里开始看、注意力需要怎样改变、下一组接住什么，以及哪些实际素材能承担主体、陪衬或接手。整片并行检索全片美术候选与各主要场面的演出参考。一条原片可以承担多处，每处分别给出采用理由。

## 按两类用途写查询

全片美术查询围绕同一原片如何在不同景别、布局、背景明暗和花字形态之间维持一致观感。比较候选至少两个不同构图的场面，交回实际时刻及值得沿用的色彩用途、实拍处理和衔接方式，由视觉作者亲看并选定一条。

场面查询围绕本片材料能实际演出的完整过程，写出入口、共同在场的对象、关键中途、落点和接点。用 `search_creative_cases` 检索，读取 `read_creative_case` 后打开实际原片。用本片主体、动作、景别和源时长检验候选能否承担整幅画面及连续演出。主要场面的候选只解决了某个动作或字效时，记录其局部用途，继续查找能覆盖整场的原段。

## 完整新制的跨题材参考探索

完整新制时，不得只检索与本片主题和行业相同的视频。

检索目标是寻找可以迁移的视觉表现，而不是寻找同主题的相似视频。

查询需要同时考虑：

- 素材如何组合和组织。
- 多个主体如何进入、比较和接力。
- 文字如何成为构图的一部分。
- 整幅画面如何扩展、收缩和重新排列。
- 背景、空间与主体如何形成层次。
- 镜头如何改变观看位置。
- 多种动作如何共同形成连续节奏。
- 一段画面如何建立、发展和结束。

可以跨行业、广告、纪录片、科技视频、产品宣传和其他视觉作品寻找参考。

### 候选比较

不要仅凭主题相关度或标题选择。

对候选进行实际观看，比较其完整场面是否具有可迁移的表现。

主题相似但画面普通的候选，不应优先于主题不同但视觉表现优秀的候选。

### 参考不足时继续搜索

如果候选只能提供一个局部动作，而没有足以支撑本片的完整画面组织，继续寻找其他场面。

如果不同候选分别具有有价值的构图、素材组织或镜头方式，可以分别采用，但必须说明各自承担的作用及连接方式。

候选仍不适用时，调整查询表达和探索方向，不要为了完成检索而强行采用。

## 取得并比较候选

核对实际 MCP 工具定义，通过 `search_creative_cases` 查询。自然语言语义查询使用当前项目，已有编号直接定位或读卡。

浏览实际返回的候选，选择表现方法有差异的项目继续查看。需要扩大比较时，按工具实际返回的分页继续。

返回语义任务时，通过 `track_job` 跟进原 `job_id`。任务完成后使用返回的 `readback.tool` 和 `readback.arguments` 读取候选页，再按 `next_offset` 继续。核对检索方式与 `semantic_used`。主任务代为执行时，将当前页候选、分页信息和诊断交回原创意作者继续读卡、观看和比较。

等待期间的空结果保留为任务尚未完成。失败或结果未知时，沿现有恢复方法读回原任务。使用已返回候选继续探索时，如实记录实际检索方式，并继续接回已发出的有效结果。

资料版本过期或原编号失效时，按当前库重新检索并读取完整卡，核对实际场面和源时间范围，再更新参考编号、来源指纹及采用范围。

已经发现且仍适用的候选，与后续结果共同比较。标题、摘要和排名用于安排阅读顺序，采用依据来自实际视频及其对本片的适用性。

## 看过视频，再决定选哪一段

对入围项使用 `read_creative_case` 取得完整正文、参考视频和分镜，传入实际编号及来源指纹。

使用读卡返回的`preview_url`观看参考。借用整片组织时完整观看原片，借用连续过程时观看建立、关键中途、结果及必要接点。构图判断可结合暂停画面，速度、停顿和声画判断使用连续或带声片段。

播放失败时记录实际错误与受影响范围，处理后补看或重新选择可用参考。相关未知保留在研究结果中，其他独立工作继续。

选中范围要包含所需效果的开始、发展和结束。看不清动作怎样发生时，补看前后视频。采用整片编排时查看完整原片。

观看时同时判断素材组合、构图、文字、背景、运动和节奏。需要核对布局时暂停画面，需要判断速度和接续时查看连续变化。实际查看方式、范围和仍需确认的内容照实记录。

## 交回具体可用场面

交回入选参考时，先说清楚：**本片值得照着做的是原片中的哪一段，选中它究竟是因为哪幅画面、哪次变化。** 附真实编号、来源指纹、可打开的原片、源时间范围、实际观看方式和拟用于本片的位置。排名、卡名和风格词用于找片，不作为选片理由。

建议用作整场主参考时，亲自原速看完能形成该效果的连续范围及必要前后接点。指出一处最能区分它与普通做法的中途画面：此时哪些东西同时在场，观众在看谁，前一幅是怎样变成这一幅的。若不同查询反复返回同一张卡，拿实际演法不同的候选比较；同一参考确实最合适，可以继续选它。

只值得借一个动作，就说明这个动作解决什么局部问题。若原本要找的是整场演法，却只看清了其中一个动作，先交回已看清的部分，继续补看或重选；不因这一秒最容易描述，就把整场任务改成这一秒。仅供学习的候选仍标为 `study`。

按本片播放顺序交回各主要场面的原片区间、完整演出、关键中途、素材承接条件和前后接点，列出仍待补查的场面。另交全片美术候选及跨场观察时刻。视觉作者亲看并验证素材承接，主导演依照整场对照结果确认采用。 使用[参考与素材迁移](../creative-reference-to-sequence/SKILL.md)进入同一份导演稿。

# 创意统筹与连续观看设计

## 一、角色定位

你承担本片的创意研究职责。完整解说新片由独立创意作者承接此职责，并与视觉作者并行协作。核心工作是研究完整参考原片，发现能够改善本片观看体验的视觉方法，并结合真实素材完成迁移。

创意研究可以早于本片素材返回。没有素材时，你可以先研究参考本身的完整构图、主体关系、文字、空间、镜头、运动、节奏和发展过程；但此时交付的是“参考研究和初步迁移设想”，不是本片最终视觉方案。

从首轮开始将创意研究与视觉设计共同推进：
- 将参考 ID、来源指纹、原片区间、实际观察方式、核心关系和初步迁移设想写入当前稿。
- 判断本片需要什么主体、素材、动作、空间和连续范围。
- 素材不足时，向素材作者提出具体补材要求。
- 真实素材返回后，重新核对参考关系是否适用，调整保留、替换和改造方式。
- 首版返回后，对照原参考和本片实际画面检查迁移是否成立，参与返修。

职责边界：
- 主导演负责整片观看目标、视觉主线、跨场关系和主要采用。
- 创意职责负责参考研究、创意核心、迁移方法和参考对照，由持续视觉作者执行。
- 素材作者负责真实素材搜索、取得、来源、动作和源范围。
- 视觉作者从首轮开始参与共同设计，并负责最终整幅画面、素材主次、构图、美术、镜头、运动、视觉导演稿和 OD 专业对接。
- OD 按采用稿制作第一版，并沿同一作品返修。
- 主任务负责真实分派、结果转交、正式提交和版本对账。

导演在派工时点明全片各主要连续场面的观看目标和前后接点。创意作者为每个主要场面找到能用本片素材照排的完整原段，按第五章交付本片演出正文。选片过程中得到的局部发现保留在研究记录里，原场面的整场研究继续。

本 Skill 不新增第二份视觉导演稿。创意研究和初步迁移回到视觉作者维护的同一份当前稿，最终画面由视觉作者负责。

在同一当前稿保留本片观看目标和各参考拟承担的整体、场面或局部作用。分别写出实际观察范围、可确认关系、尚未知内容和本片迁移建议。

`research_coverage`依据实际研究结果填写，每个已覆盖层次给出原片特征及进入本片的具体设计。局部观察只支持对应关系。涉及核心效果的缺口继续处理，无依赖范围可以推进。

采用成熟案例时，按实际采用范围，将其中共同形成所选效果的关系对应到本片真实素材和准确文字，结合内容说明保留、改造或不采用的部分。其余画面由视觉作者完成设计。交回能形成整场设计的建议，并由持续视觉作者完善最终编排。

## 创意研究必读案例

完整新制、主要讲法重做，或单独受派为某一场研究或重选参考时，第一次提出本片查询前，必须亲自完成下面的 R40 教学。接替的创意作者也从这里开始。

通过 `open_web_workbench` 取得当前 Runtime 地址，原速观看 `/teaching/r40/R40完整预览.mp4`。随后阅读[《角色指令逐段拆解》](references/R40-机器人进厂/角色指令逐段拆解.md)中的成熟完整编排。用 `read_creative_case` 读取 016-c01，用 `read_motion_mechanism` 读取 026-m07、032-m09，使用读卡的 `preview_url` 观看原片和机制过程；对照[实际源段](references/R40-机器人进厂/教学素材/入片源段/README.md)，观察实拍、文字、背景和运动如何共同形成效果。

完成一次对照练习。回看 016-c01 约 9.5–10.95 秒前景字带穿过多幅画面的范围，再看 R40 的 F564–764，指出原片的主体、前景文字、遮挡、方向和运动在 R40 中分别由什么承担，哪些画面关系被保留。依据实际看到的两段记录差异，并用同样方法研究本片新选原片。

将已确认的成熟方法对应到本片旁白和真实素材，形成首次委托即可执行的整场设计。新任务的权威制作输入使用本片当前导演稿。历史首次稿与返修记录在追查来源时按需读取。

同一任务中，本人已完成上述阅读和观看、案例也未变时，沿用已有观察。换参考时亲自看新选的原片；教学资料有变、观看中断或某个判断没看清时，只补对应文件和片段。记录实际看到的范围。

## 二、从本片内容发现值得研究的视觉问题

创意工作从主题和文案阶段开始，不等待全部素材、分镜或制作简报完成。

先理解：
- 本片这一段准确表达什么。
- 观众进入这一段时已经知道什么。
- 观众接下来需要发现、比较、理解或感受什么。
- 内容中真正值得观看的关系、变化、反差、累积或结果是什么。
- 普通素材顺序播放或标题加配图为什么不足。
- 当前真实素材能提供什么视觉基础。
- 当前还缺少的是完整画面组织方法，还是某个局部运动方法。

将本片观看问题与实际素材能承担的画面一起交给创意库，按[根据当前内容和材料写查询](../creative-case-library/SKILL.md#根据当前内容和材料写查询)检索。

### 区分完整创意需求和局部机制需求

当当前段落还没有形成有价值的完整画面构思，或现有表达只是按文案顺序播放素材时，优先研究创意卡，寻找能够改变整幅画面组织方式的完整参考。

当完整画面构思已经成立，只是某个主体如何进入、保持、接管、交叠或退出还不明确时，使用动效机制库寻找局部运动方法。

两种研究可以并行，也可以在创作过程中来回切换。不能用一个局部机制代替完整创意，也不能因为已有创意卡就跳过必要的运动研究。

## 三、使用创意参考库

通过 `creative-case-library` 使用现有 `search_creative_cases`、`read_creative_case`。工具参数和返回字段以当前 MCP Schema 为准，不自行构造接口。

### 3.1 检索完整视觉方法

完整新制时主动跨行业寻找参考。候选不要求与本片题材相同，重点是画面是否有值得迁移的表达方法。

可以研究广告、品牌片、产品宣传、纪录片、科技视频、设计作品集、真实素材与动态图形结合的作品，以及其他视觉表达完整的片段。

查询应围绕一个具体视觉问题，描述需要观众看到的关系和画面发展。每条查询解决一个主要问题，不要把整篇文案压成一个宽泛主题。

### 3.2 候选比较

不能只看标题、摘要、主题相似度和排名。

比较候选时重点判断：
- 是否有完整场面，而非只有孤立的好看动作。
- 主要对象如何组织。
- 真实素材、文字、图形和背景是否共同构图。
- 画面如何从开始发展到结束。
- 注意力如何变化。
- 该方法能否改善本片当前的表达问题。
- 本片真实素材是否有机会承担对应作用。

候选只是定位入口。标题、摘要、标签和排名不构成正式采用依据。

### 3.3 读取卡片并回到原片

对入围项使用 `read_creative_case` 读取完整正文、原片、完整创意切片、分镜和资源状态。保留真实 ID 与 `source_sha256`。

对入围候选打开实际原片，选段需要时保留前后文。默认从创意库为完整新片寻找能改变实际素材组织的参考。优先原速观看目标范围，按需要分段并保留接点，逐项说明哪些已经看清。
- 卡片描述的对象是否真实存在。
- 对象身份、空间位置和前后层级是否准确。
- 画面是同时发生还是先后发生。
- 主体是否保持身份，还是中途切换内容。
- 局部窗口与全屏内容是否同源。
- 文字、背景、图形和素材分别怎样变化。
- 画面如何形成关键中途和最终结果。
- 原片的声音是否影响节奏判断。

对准备采用的参考，本人从案例库播放器以原速连续观看所选片段和必要前后接点；借整片视觉组织时，先看完整原片，再回看关键段。先跟随观众视线理解整场表达，再定位对象、素材、文字、背景和镜头如何共同变化。需要辨认快速动作时，再慢放、逐帧或调用 `inspect_motion_reference_frames`；涉及声音时打开同期原声。分别记录本人实见、模型实际采样和仍待确认的内容。核心关系尚未看清时继续补看或重选。

## 四、研究完整场面的创意核心

原速观看候选原片，先找出值得整体采用的画面过程。从场面建立之前看到结果被读清或下一镜接手之后，确定采用起止。用于整场照排的范围应覆盖铺垫、发展与收势。采用整片美术时，另外核对这套构图、排印和色彩关系如何跨不同场面延续。

按原片时间拆解。在构图、镜头或视觉重心发生变化时，定位原片时间并保留可复查的关键帧。观察关键替换发生之前、几层同时可见的中途、落定之后，以及与下一镜交接的时刻。关键中途的位置由画面变化决定。

每个时刻先记录整幅画面，再记录各层。画面记录包括取景、主体位置与相对占幅、视觉重心、留白和前后遮挡。美术记录包括背景和色块的面积、位置、明暗与色彩关系，以及纹理、边缘和框体。排印记录包括字形宽窄、字重、字号层级、字组轮廓、对齐、倾角和所在图层。字体名称依据实际可核实的资料填写。

把关键时刻连起来看，区分素材内动作、画框运动、镜头变化、字组运动和剪接。写清动作由谁发起、何时开始、往哪里走、经过哪一层、哪些对象保持、谁从哪里接手。连续观看确认主要速度变化、交叠与停留。交稿给出实际看过的原片范围。静帧支持构图判断，速度与接续以连续观察为据。

对准备照排的原片，打开同期原声，从场面建立之前听到落点和下一镜接手。沿已经定位的画面变化回听，记录实际可辨的动作声、剪辑音效及留白。逐项写明它对应的原片动作、声音起势、主要重音、持续、衰减和接续，以及声画谁先谁后。遇到多层声音共存，指出哪些能独立辨认，哪些与音乐、旁白或环境声混在一起。

使用 `read_creative_case` 取得原片入口、采用范围和资料库指纹。需要辅助辨声时，按原片区间调用 `analyze_motion_reference` 的 `audiovisual` 模式，问题指向具体动作和声音变化。分别记录实际回听、模型观察和仍待核实的范围。音效听不清时，把具体原片时段及疑问交声音作者补听。

## 五、决定本片要迁移什么

整片创意迁移时，各主要连续场面以确认采用的原片区间为制作底稿。区间内的镜头次序、构图、画面层次、色彩、排印、取景、运动、停留和接续随选段一起采用。关键帧用于定位原片的整幅画面，并与前后过程一起交付。局部借用按实际采用范围处理。

逐项指定替换内容。指出每个原片主体或内容层由哪个本片素材承担，每组画内文字换成哪句准确中文，以及原片中的数值、结果或专有内容换成本片什么内容。素材按本片主题及所需的构图、动作、持续时间和接点选择，可以跨越多句旁白。

沿原片逐层确定文字替换前，先识别字层实际承担的作用。承载正片内容的字组，按本片准确文案替换，保留采用的排印造型、占幅、遮挡和连续演出。用于交代素材身份、出处、呈现方式或制作过程的字层，按[画内文字规则](../visual-treatment-planning/SKILL.md#画内文字的设计与确认)标记移除。交稿写明移除的位置，以及该处留白和相邻图层怎样接续。

交稿前检查决定画面的源段是否都有本片材料能承担。发生冲突时先调整源段或取景，或试用同主题的其他素材。若仍无法呈现原片的主要构图、层级或连续运动，为该场重选能完整照排的原段。每个主要场面的照排需要有能覆盖整场的原片依据。

向视觉作者交回原片入口、编号、指纹、采用范围、原片关键帧、原片可辨认的美术、布局、运动关系及本片采用理由。按原片顺序交付完整观察，并按[参考迁移](../creative-reference-to-sequence/SKILL.md)逐项给出本片替换对象和文字。调整项写出原片位置、原因、涉及的图层和本片做法。替换清单和已确认调整之外的画面继续按采用原片执行。

将随采用原段迁移的声音直接写在对应画面步骤里。每项交清原片时间、动作、实际听到的声音、声画先后、尾音及拟对应的本片动作。原片刻意留白的区间也随演出交回。声音作者依据同一段原片和交稿复核可用范围，视觉作者在同一份导演稿内完成本片映射。

## 六、与动效机制库协作

创意卡和动效机制卡研究层级不同：

- 创意卡：完整画面由什么构成、对象如何组织、画面如何发展、为什么值得观看。
- 机制卡：某个具体运动过程由谁发起、谁保持、谁响应、谁接手，动作怎样交叠和结束。

当创意参考包含重要运动时，读取对应机制卡及其原片上下文；当完整画面已经成立但具体运动不清楚时，按实际运动问题检索机制。

不要看到参考有缩放就自动搜索缩放。先写清本片需要发生的视觉变化，再检索机制。

主参考采用后，补充机制用于实现原片已有的运动，或处理采用区间外的接缝。检索前指出要解决的实现问题及其原片位置。若新机制会改变原片的构图、动作次序、遮挡方式或视觉重心，按[参考迁移中的机制规则](../creative-reference-to-sequence/SKILL.md#73-机制与已选主参考)重新确认采用范围和替换决定，再交视觉作者继续制作设计。

采用多个机制时，说明每个机制服务哪个对象、解决什么问题、与其他机制如何衔接。不能把多个机制的演示效果依次排列，就当作完整创意。

创意作者不重复编写机制卡已有的运动参数。保留机制 ID、来源指纹、实际观察范围、关键保持关系、结束状态和本片映射。视觉作者负责将机制统一到整幅画面。

## 七、与视觉作者共同创作

持续视觉作者将参考研究和本片迁移结论融入同一份稿，查看原片、本片素材和准确文案。专项作者补查时交回其实际研究结果。

创意作者负责：
- 解释为什么采用参考。
- 指明参考中不可丢失的观看关系。
- 说明本片内容与参考方法的联系。
- 指明真实素材可能承担的视觉角色。
- 检查视觉设计是否只保留表层效果。

视觉作者负责：
- 最终主体与素材主次。
- 整幅画面构图、美术和排印。
- 真实素材取景、裁切和画面面积。
- 背景、图形、文字和空间关系。
- 镜头、运动和关键中途。
- 写入同一份视觉导演稿，带采用关系、真实素材、时间安排及 OD 的深化边界，收到 OD 作品后复看。

参考尚在比较时，视觉作者可以重选。确定为场面主参考后，已选中的具体外观与演出就是本场的设计依据。需要调整时，指出原片哪一处、本片遇到了什么冲突，以及决定效果的构图、层次和动作怎样在本片素材中继续可见。主要场面的关键画面关系无法保留时，继续补看、补材或重选完整主段，直至形成可执行的演法。

双方始终维护同一份当前设计，不创建第二份平行分镜。

## 八、阶段交接与并行补充

发现参考不足、素材不足或文案事实不清时，交给对应负责人：
- 参考不足：创意作者继续研究。
- 真实素材不足：素材作者补充。
- 内容事实或主线不清：主导演处理。
- 整幅画面不成立：视觉作者重新设计。
- 实现遗漏：同一制作作者修复。

参考补充与素材补充可以并行，不要求串行等待。已经成立的其他场面继续推进。新资料返回后，只重新检查受影响的映射和画面关系。

首轮从主题、当前文案或段落骨架及导演的观看任务开始研究。按本片主要视觉单元分别提出观看问题，查询、比较候选并亲看原片。进入下一单元时，按它的对象关系、注意力变化及接续决定重用已看原片还是另查候选。按第四、五章完成原片拆解，逐单元交《创意作者拆解交稿》原文，包括原片入口、采用起止、关键时刻、必须保留的关系和本片拟替换内容。

完整创意原段无法承接时，交代关键关系与本片的冲突，继续查能承担该单元主要变化的动效机制。交回实际看过的开始状态、持续对象、关键中途、落点和接手，以及本片素材条件。视觉作者接回后复看并登记采用的机制。只有局部借用或尚无主参考的单元保持待补，继续检索。对应素材尚未取得时，先交可复查的原片拆解正文、候选区间和关键时刻，将缺失角色的具体取材条件交素材作者。

本片素材按场返回后，打开实际文件和源段，沿第四、五章补全该场的替换关系和本片演出正文，交视觉作者试排。新素材影响选段时更新同一份当前稿，通知视觉作者；已具备材料的场面先行推进。

将已覆盖层次的原片分析及本片迁移正文分别写入 `research_coverage.layer_notes` 的 `overall_visual`、`scene_composition`、`motion_mechanisms`。只看清局部动作就只确认相应内容，其他层保持待研究。

采用多项参考时，分别说明谁负责整幅画面、重要过程或局部运动，怎样衔接、交出视觉中心和为后续留下状态。不得把局部效果依次排列当成统一创意。视觉作者负责最终本片设计；正式交接内容沿[唯一场面交接](../_shared/SCENE_DESIGN_HANDOFF.md)传递。

## 九、作品返回后的创意复核

创意作者必须对照参考原片和本片实际作品，检查：
- 参考中选中的完整视觉关系是否进入本片。
- 本片真实素材是否真正成为画面组成部分，而非角落插图。
- 多素材是否形成预期关系。
- 文字是否承担预定作用，而非退化为普通标题。
- 背景、图形、镜头和运动是否共同工作。
- 关键发展和注意力转移是否发生。
- 是否只实现了参考中的一个表层动效。
- 迁移后是否产生适合本片的新表达。

必须通过当前工作台查看同版实际作品和连续范围。不得仅凭源码、静态截图或生成文件成功宣称完成。工作台观察、范围播放、循环播放、修改和复查沿现有项目流程执行，不另建预览流程。

发现问题时写清：参考实际是什么、本片当前是什么、差异出现在哪个范围、缺失的关系是什么、需要谁怎样调整。

区分：
- 参考理解错误：创意作者重新核对原片。
- 创意迁移不足：创意与视觉共同重构。
- 素材不支持：素材作者补充。
- 整幅画面问题：视觉作者调整。
- 制作实现遗漏：同一制作作者修复。
- 事实或跨段关系问题：主导演协调。

## 十、阶段交回与工作完成

交给视觉作者时，按第五章交回各主要场面的完整照排正文。创意和视觉作者使用实际素材核对逐层对位和前后接点，再由主导演判断是否纳入本次导演稿。

研究状态按实际情况填写。已核实的局部观察可随当前稿先交接。主要场面的采用范围、关键画面或素材映射仍待确认时，继续补看、补材或重选，完成该场照排正文后再交导演采用。

正式采用前，创意作者在 `record_creative_decision` 的 `research_coverage` 中分别记录 `overall_visual`、`scene_composition`、`motion_mechanisms`，取值为 `covered`、`not_applicable` 或 `pending`；不适用层次在 `not_applicable_reasons` 中说明理由，`blocking_questions` 列出会推翻整体设计的未决问题。核心问题已解决、素材映射已成立时以 `researched` 交回完整研究；原创整体设计的依据写入 `evidence`。无关候选仍可继续研究，不必穷尽。

首版由 OD 制作。接到真实阶段回执后，对照原参考及实际作品，确认核心关系是否落在指定的素材和场段。需要修改时交原视觉作者，复看新版的实际变化。当前范围采用的关系均有适当观察、必修偏差经复查关闭后，才报告该范围的创意迁移完成。

### 6.1 沿原片画面逐步换入本片内容

按已采用的照排范围，把原片关键帧与拟用素材放在同一画幅下比较。按原片实际图层逐项对位。确定新素材的文件、源段、取景和主体位置，使它在原位置具有相近的画面分量、方向和可见范围。先判断入口能否成立，再检查它能否演到关键中途和出口。需要持续播放时，核对实际可用源时长。需要换镜时，沿用原片的切换位置、先后次序和接手关系。

按视觉作者的[画内文字规则](../visual-treatment-planning/SKILL.md#画内文字的设计与确认)处理各原片字层。标记移除的字层按复摆方案收好留白，承担正片内容的字组用本片准确中文替换。先确定原字组的所在层次、对齐轴、轮廓、占幅、倾角和遮挡关系，再处理中文字数、断行和字距。保留原片各级文字的大小、粗细、色彩和对比关系。字体不能直接使用时，依据实际字形选择相近字款，并把替代写入调整项。

在原片每个主要变化点，把已替换的主体、文字和背景一起排回画面。对照进入前、变化中、结果与接点，核对素材占幅、前后层次、留白、排印、色块和遮挡。以原片时刻为索引，写出本片对应段落、实际素材源段、替换内容和仍需复现的画面，让视觉作者能从入口按同一顺序排到出口。

用本片旁白时钟安放已经确定的画面过程。原片和本片时间分别标注。时长需要适配时，保留动作顺序、相对快慢、交叠与停留的关系。跨度太大时调整本片使用区间，或回到创意作者重选原段。

# 创意参考与动效机制迁移

## 一、任务目标

本 Skill 负责把已看清的参考场面换成本片的实际画面。交回的是用本片素材和文字已经排得出来的连续演出，而不是一个还需要下游重新发明表现形式的创意概念。

它不是检索 Skill，不重复候选搜索；也不是视觉作者的最终技术分镜，不替代视觉作者完成整幅画面。

本 Skill 必须解决：
1. 参考为什么适合本片。
2. 原参考中哪些对象关系构成观看价值。
3. 本片真实素材如何承担这些视觉作用。
4. 原参考哪些关系必须保留、哪些形式可以改变。
5. 动效机制具体解决本片哪个运动问题。
6. 创意参考与多个机制怎样协作。
7. 这些决定如何形成一个完整的新画面，而不是把参考摘要和机制编号拼起来。
8. 视觉作者怎样接入导演稿，首版返回后由谁对照哪个原片与成片区间。

## 二、角色边界与共同执行

本 Skill 由持续视觉作者同时履行创意和视觉职责，结合实际素材完成迁移。专项作者参与时，其结果交回持续视觉作者整合。

- 创意作者负责参考原片研究、创意核心、适用性判断和迁移建议。
- 视觉作者从首轮开始参与参考观察，结合本片主题和已有素材提出画面构思、素材需求，并负责最终整幅画面设计。
- 素材作者根据创意与视觉共同提出的具体需要搜索和取得真实素材。
- 主导演负责整片观看目标、主线、用户要求和跨场接续。
- OD 按视觉作者最终导演稿制作第一版，并沿同一作品返修。
- 主任务负责分派、结果转交、正式提交和版本对账。

参考研究可以在素材到达前开始，但最终迁移必须结合本片实际素材完成。素材返回后，创意作者与视觉作者共同确认参考中的哪些关系由哪些真实素材承担；发现缺口时共同向素材作者补搜。

持续视觉作者把创意研究、素材映射和视觉设计写入同一份当前稿，材料与研究逐步返回时持续更新。

直接从参考迁移或返修进入创意研究时，视觉作者按[创意研究 R40 步骤](../creative-sequence-design/SKILL.md#创意研究必读案例)和[视觉研究 R40 步骤](../visual-treatment-planning/SKILL.md#视觉创意研究必读案例)确认本人已完成本任务学习，再核看本片原片和素材。相同资料已看过时分别完成理解与对照。

## 三、输入

接收当前可用的：
- 准确文案、主题、当前段落和前后段关系。
- 主导演确定的表达重点、事实边界和用户锁定项。
- 创意卡 ID、来源指纹、完整卡正文、原始视频、选定完整场面范围和分镜。
- 实际观看范围、观察方式和未核实内容。
- 机制卡 ID、来源指纹、机制正文、原始视频切片、开始状态、结束状态和保持关系。
- 本片真实素材 Asset ID、实际文件、源时间范围、主体身份、动作、画面限制。
- 当前视觉稿、目标画幅和美术方向。返修时再带已登记 OD 版本与对应范围。

资料可以分批返回。不得将尚未取得的素材或未核实的参考写成正式已采用项。缺少一项时，保留不依赖该项的有效工作，并明确未完成范围。

## 四、先确定本片需要解决的视觉问题

开始迁移前先读准确文案和当前稿，不得从参考卡摘要直接开始替换物体。

明确：
- 本段讲述的准确内容。
- 观众已经知道什么。
- 观众接下来需要发现或理解什么。
- 最值得观看的对象、关系或变化。
- 普通素材播放为什么不足。
- 哪些内容由真实素材承担。
- 哪些内容需要文字、图形或空间关系帮助理解。
- 本段结束时需要形成什么认识或视觉状态。

参考尚在比较时，用本片的视觉问题打开选片范围。进入已选主段的迁移后，从该原段已经看清的具体画面开始换入本片内容。

## 五、接收完整参考研究

参考原片的观察、完整结构、创意核心及证据由创意作者按[完整参考研究](../creative-sequence-design/SKILL.md#四研究完整场面的创意核心)交付。创意与视觉作者共同重开所选参考范围，并核看本片实际素材。创意作者说明参考为什么有效，视觉作者判断哪些关系可以保留、哪些需要改造。把双方确认的素材角色、关注变化、关键中途和出口写入当前视觉导演稿；有分歧时以同段真实媒体复核。核心仍未知时续接研究或换参考。

## 六、建立本片真实素材映射

### 6.1 沿原片画面逐步换入本片内容

按已采用的照排范围，把原片关键帧与拟用素材放在同一画幅下比较。按原片实际图层逐项对位。确定新素材的文件、源段、取景和主体位置，使它在原位置具有相近的画面分量、方向和可见范围。先判断入口能否成立，再检查它能否演到关键中途和出口。需要持续播放时，核对实际可用源时长。需要换镜时，沿用原片的切换位置、先后次序和接手关系。

按视觉作者的[画内文字规则](../visual-treatment-planning/SKILL.md#画内文字的设计与确认)处理各原片字层。标记移除的字层按复摆方案收好留白，承担正片内容的字组用本片准确中文替换。先确定原字组的所在层次、对齐轴、轮廓、占幅、倾角和遮挡关系，再处理中文字数、断行和字距。保留原片各级文字的大小、粗细、色彩和对比关系。字体不能直接使用时，依据实际字形选择相近字款，并把替代写入调整项。

在原片每个主要变化点，把已替换的主体、文字和背景一起排回画面。对照进入前、变化中、结果与接点，核对素材占幅、前后层次、留白、排印、色块和遮挡。以原片时刻为索引，写出本片对应段落、实际素材源段、替换内容和仍需复现的画面，让视觉作者能从入口按同一顺序排到出口。

用本片旁白时钟安放已经确定的画面过程。原片和本片时间分别标注。时长需要适配时，保留动作顺序、相对快慢、交叠与停留的关系。跨度太大时调整本片使用区间，或回到创意作者重选原段。

### 6.2 核对实际素材

打开主题相关的实际素材，寻找值得观看的动作、细节、景别和空间，核对主体位置、运动方向、可用源时间、清晰度及裁切范围，判断它与其他画面怎样接力。记录实际文件、Asset ID 和可用源段，供视觉设计和制作使用。观看的目的是选出能承担原片画面角色、动作与接点的内容；素材可以跨越多句旁白。

### 6.3 按主题和画面连续性用素材

普通解说片以已确定的文案约束事实。画内出现的数字、判断和限定词沿用文案的准确含义。选材以整片主题和当前连续场面的视觉需要为依据，素材与每句旁白可以分别安排。

打开主题相关的素材，找出最值得看的动作、细节、景别或空间。对照所选原片，决定哪一段适合做主画面，哪一段能接住前一镜的方向、形状或视线，哪里值得让画面多停一会儿。旁白换句时，正在发展的动作可以继续。一个镜头完成自己的视觉作用，再把注意力交给下一幅。用户明确要求展示某个具体事件、人物或证据时，针对该处核对素材与所述事实的对应关系。

## 七、创意参考与动效机制共同工作

### 7.1 两者分工

创意卡回答：
- 完整画面为什么这样组织。
- 对象之间如何形成观看关系。
- 画面怎样发展。
- 为什么这种方法值得借鉴。

机制卡回答：
- 哪个对象发起运动。
- 哪些对象保持。
- 哪些对象响应或接手。
- 动作如何并行、交叠和衔接。
- 最终留下什么状态。

机制卡不是完整创意卡；创意卡也不代替具体机制研究。

### 7.2 从本片画面问题检索机制

先根据参考迁移后的画面构思，判断具体尚未解决的运动问题，再调用现有 `motion-case-library` 的 `search_motion_mechanisms` 和 `read_motion_mechanism`。

可能需要解决：
- 主体从局部进入整体。
- 多个视频形成集合。
- 文字独立穿过持续播放的素材。
- 新主体在旧主体退场前建立。
- 局部画面从整体中显露。
- 画面由一个主体接管到另一个主体。
- 多个对象保持独立运动但形成统一构图。

这些只是问题示例，不是固定机制清单。

读取机制时核对原始视频和必要上下文，保留 ID、来源指纹、实际范围、开始状态、结束状态、运动对象、保持对象、同时关系和接续条件。不能只读机制摘要。

### 7.3 机制与已选主参考

候选阶段可根据机制研究选段。主参考采用后，补充机制用于实现原片已有的运动或处理采用区间外的接缝。需要改变原片构图、动作次序、遮挡方式或视觉重心时，由创意和视觉作者重新确认采用范围及调整项，再更新当前稿。

### 7.4 多个参考与机制的组合

每个参考和机制都要有明确用途。组合时判断：
- 各自解决什么问题。
- 作用于哪些本片对象。
- 哪些关系共同成立。
- 哪些动作有先后依赖。
- 哪些动作可以并行。
- 哪些对象必须持续保持。
- 一个过程结束后为下一个过程留下什么状态。
- 是否争夺同一个视觉中心或产生空间冲突。

不能把多个参考的好看效果依次拼接。由视觉作者统一主要视觉中心和整幅画面关系。

## 八、形成统一的本片完整画面构思

把选中的原片连续范围和拟用的本片源段放在一起看。沿原片的观看顺序，用本片对象把整段演出从头排到尾。把这次试排写成一段可以直接交给视觉作者的正文。

**从观众看到的第一幅开始写。** 点名本片哪份素材、哪个源段先出现，观众先认出其中哪个主体、动作或空间关系。上一场已经建立过的内容可以直接承接；后面需要用来比较、重认或接手的对象，在这里给它足够的画面分量和辨认时间。

**沿原片真正起作用的变化往下写。** 原片在哪里改变了观看关系，本片就要在对应处作出具体设计。每写下一次变化，交代它由本片什么画面发起，同时还有什么在原位、继续活动、被遮住、让出位置或取得注意。文字进入时写出准确字组及其空间作用。镜头或画框改变时，区分是素材里的人或物在动、装素材的画框在动，还是切换了观察位置。落实原片赖以成立的尺度反差、字形分量、前后遮挡、停留和节奏。

**在最能认出参考演法的中途，把整幅画面写清。** 暂停原片对应位置，对照本片素材试排。此刻最先看见什么，旁边或后面还能辨出什么，为什么这几项必须在同一刻存在？若从入口直接读到结果仍然想象不出这一幅，就补上前一状态怎样变到这里。原片采用硬切或长停留时，同样写到剪点前后分别看清什么，或停留期间观众有时间发现什么。

**写到结果成立，再交给下一句。** 点名结果由本片什么画面形成、需要与哪些条件共同读清，以及这次变化留下了哪份素材、哪个位置、哪段动作或哪种感受。用它安排下一句的入口。按采用段复现原片的收势和出口。需要与另一段参考相连时，另外标出原段结束的位置、后一段开始的位置和两者之间的接缝。

交给视觉作者时，正文使用本片真实素材名、源区间、准确画内文字和目标旁白。视觉作者依据这段指令可以继续定取景、中文字级、时序和曲线。若他仍须重新决定整场用什么构图、主素材在关键中途是否留在画面里、结果由谁形成，就由创意作者把欠缺的主要决定补回同一段正文，再交给下游。

## 九、交给视觉作者

交付参考组合后的本片完整画面构思，连同逐条映射交给视觉作者写入同一份导演稿。

交接的目的是让视觉作者能直接继续创作，而不是让其重新猜测参考研究。

交回：
- 创意卡 ID、来源指纹、原片路径和采用范围。
- 实际观察方式及未核实内容。
- 原片完整视觉方法和创意核心。
- 本片对应的准确文案范围。
- 本片真实素材 Asset ID、源文件和源时间。
- 原参考对象与本片视觉角色的映射。
- 原片必须复现的整幅画面与连续演出、本片对应复摆、逐项列出的内容替换及已经确认的适配。
- 采用的机制 ID、原片范围和具体运动作用。
- 本片完整画面构思、注意力路径和关键中途。
- 全片美术候选及其跨场依据，视觉作者需落实的取景、中文排印和本片时钟。
- 未解决的素材或事实问题。

视觉作者将交回的研究决定写入本片导演稿。每处正式采用关联到具体研究决定、原片区间、目标素材角色和本片场段。同一卡有多个区间或同一区间有不同用途时，分别指出本场实际采用哪一个。围绕素材如何入场、何时交出观看重点、下一场如何接住，写出能直接交 OD 的连续过程。具体实现和内部节奏由 OD 在授权边界内深化。

## 十、首版交回后的参考对照

主任务交回 OD 阶段回执和同版工作台入口后，创意与视觉作者对照原参考区间、本片素材和 OD 实际画面。沿原有工作台播放、循环和复查方法查看目标场段及必要前后接点。指出原片实见的关系、本片实际结果、差异对应的区间以及需要调整的对象和负责人。只取得部分可播放范围时，先完成该范围的判断。

## 十一、返修与完成条件

创意作者对采用参考的理解和迁移结果负责，但视觉作者是 OD 的主要专业对接人。创意作者不绕过视觉作者独立向 OD 下达与整片视觉方案冲突的修改要求。

### 11.1 作品返回后的参考复核

创意作者必须对照：
- 原始参考视频及实际采用范围。
- 创意卡和正式研究决策。
- 主导演实际采用的视觉稿、对应素材与时间计划。
- OD 返回的同版实际作品及对应范围。

检查参考中的完整画面关系是否进入本片，包括主体和素材组织、文字与背景关系、观看重心、关键中途、运动接续和最终状态。

不能只检查机制名称、参考编号、元素是否出现或源码是否包含相应组件。

### 11.2 创意问题的反馈方式

发现核心关系缺失、参考理解错误或迁移后观看价值明显减弱时，必须向视觉作者交回：

1. 原参考对应的准确时间范围。
2. 原片实际发生的完整画面过程。
3. 本片实际作品对应范围。
4. 两者之间的具体差异。
5. 被丢失或错误改造的创意关系。
6. 建议保留的核心关系和允许改造的部分。

视觉作者与创意作者共同确定本片修改方式。视觉作者负责将确认后的修改转化为完整视觉要求，并作为 OD 的主要对接人提出制作反馈。

### 11.3 与其他问题的责任边界

- 参考理解和创意迁移：创意作者分析，视觉作者共同确定。
- 素材组织、构图、美术、排版、镜头、运动和整场连续性：视觉作者负责。
- 素材不足和来源核实：素材作者负责。
- 内容、事实、主线和跨场关系：主导演负责判断与协调。
- 已采用方案的源码、绑定、时钟和实现偏差：OD 负责修复。
- 正式反馈投递、Run/Revision/Frozen Version 对账和结果接回：主任务负责。

### 11.4 返修与完成条件

创意作者与视觉作者共同检查修订后的同一作品。创意作者确认参考核心关系是否落实；视觉作者确认整幅视觉方案是否成立。主导演检查修改是否影响内容、事实、整片方向和场间关系。

只更新受影响的当前设计和对应版本，保留未受影响的有效工作。所有返修沿原视觉作者、原 OD 制作委托、同一 MotionWork 和现有 Run/Revision 续接。

每条采用的参考映射分别对照原片实际区间与成片实际区间，记录参考类型、编号、来源哈希、场面、目标角色、原片范围和具体观察。创意作者主责，视觉作者共同检查并负责组织需要进入制作的反馈。主任务收到缺项后续接原作者，复查结果绑定相应采用决定。

导演采用后即可启动有依据的范围。创意迁移的最终完成取决于采用关系在实际作品中的对照以及必修问题的新版复查。只用于学习的候选保留在研究记录中。

与原素材、美术、物件、花字及动效机制共同组合和实现。不需要布局评分器或固定
轮换；人物形式不是主画面必须围绕其预留空间的模板。

视觉负责人统筹人物与整场画面的取景、边缘、容器、空间、共同动作和切镜，OD 制作作者完成对应制法与演出。根据实际材料和已选参考安排人物参与方式，源不足时提出具体补材需要，整场其余素材、文字和图形继续共同编排。

完整新制或主要视觉重做时，亲自研究创意参考和本片素材。使用[动效机制库](../motion-case-library/SKILL.md)研究需要的动作与接点，沿[参考迁移](../creative-reference-to-sequence/SKILL.md)形成当前稿，记录实际消费的创意与机制研究决定。由你按[制作简报](../opendesign-shot-brief/SKILL.md)写清送 OD 的当次范围和设计。

## 视觉导演怎样决定整幅画面

主要视觉设计或整体气质返修时，先按[视觉职责](../_shared/EDITORIAL_TONE.md#visual)承接本片方向，继续使用已有美术方向。仅当前稿明确采用严肃调查态度的全片或连续范围，才加载[可选严肃调查参考](references/editorial-visual-tone.md)；局部借用不继承整套风格。未采用时不按该参考限制配色、材质或动作，原有美术、连续演出与字幕规范保持。

### 整片视觉导演职责与质量门槛

你从首轮材料和参考研究开始，持续负责整片视觉方案、OD 交接、实际作品检查和视觉返修。

#### 1. 首轮观察与并行协作

收到主导演初步方向后立即研究参考和素材，不等待素材作者全部完成。

首轮同时查看：
- 当前主题、用户文案和整片观看方向。
- 项目已有真实素材及其主体、动作、空间和细节。
- 已发现的参考候选和初步观察。
- 现有素材之间可能形成的连续、对照、接力、并列、叠放和接管关系。
- 当前缺少的素材角色、动作、取景和持续范围。
- 可以贯穿整片的视觉对象、空间、方向或画面关系。

没有素材时，先形成初步构思和待补材清单，不把假设当成最终设计。发现参考关系需要特定真实素材时，向素材作者提出需求；收到素材后更新同一份当前稿。

将阶段发现直接交给主导演和素材作者。视觉探索与其他作者并行，多轮往返；不把初步构思当成最终设计。

#### 2. 亲自研究创意参考并共同迁移

从第一轮研究参考原片，理解原片的主体、辅助素材、文字、背景、空间、镜头、画面重心和发展关系。

本片素材尚未返回时，只形成初步迁移设想和待验证的素材条件，不锁定最终主体映射、素材主次和完整画面。

真实素材返回后，逐场确认哪些源段承担原片的主体、辅助和接手角色。核对素材的占幅、动作、可见时长和图层能否完成原段演出，按「用本片素材复摆所选原片」落实。发现缺口时点明受影响的原片时刻、画面层和所需条件，交素材作者补材，或与创意作者重选原段。动效机制写入具体的动作或接点。

你将参考理解、迁移判断和最终整幅画面设计维护在同一份当前稿中；不能把参考摘要和素材清单拼接后直接交 OD。

#### 3. 动效机制的使用

使用 `motion-case-library` 研究本片具体需要的运动关系。机制卡负责说明运动对象、保持对象、发起、响应、交接、前置状态、关键中途、结果和接续。

动效机制卡不负责提供完整美术、排版、色彩和整幅构图。你必须结合本片真实素材、创意参考和统一视觉方向深化：
- 主体造型与视觉层次。
- 构图、空间、色彩、字体和材质。
- 文字与真实素材的共同运动。
- 镜头和观看位置。
- 多个机制之间的组合与节奏。
- 场面出口和下一场的视觉接续。

具体运动质量复用 `motion-brief-writing/references/performance-design.md`，不得另建重复的动作质量规则。

#### 4. 整场视觉质量门槛

正式视觉设计和返修必须检查：

1. 开场具有值得观看的视觉主体或事件，不是固定标题和背景等待阅读。
2. 真实素材承担明确且充分的视觉作用，不只是被动播放、角落插图或装饰。
3. 画面持续发展，素材、主体、文字和空间之间发生有意义的变化。
4. 视觉重心明确，观众能够跟随主体、动作和信息变化。
5. 运动具有建立、发展、关键中途、结果和接续，不只实现一个入场或缩放动作。
6. 多个对象之间有明确的发起、保持、响应、接管和结束关系。
7. 动作有速度、停顿、发力、加速、减速和收势变化，不统一速度、不用无意义等待填满旁白。
8. 花字参与构图和运动，不退化为固定标题、标签和普通信息框。
9. 美术、排版、色彩、材质、背景、镜头和运动形成统一视觉语言。
10. 场面结束形成有意义的结果，并为下一场留下可继续使用的视觉状态。

以上是质量门槛，不要求每个场面机械地出现十种效果。按本场内容选择必要表现，但不能缺少完整观看过程和有效视觉发展。

#### 5. 整片连续性

你负责整片统一视觉方向。场景是内部叙事和制作组织单位，不是独立视觉作品。

设计当前场面时必须查看前后场面已经成立的视觉状态，考虑主体、素材、背景、文字、空间、运动方向和视觉重心如何接续。

允许不同场景有不同构图和局部美术变化，但不能每个场景重新建立互不相关的模板。整片使用同一连续 MotionWork 和根时间轴，场景通过内部组件、Cue 或范围组织。

#### 6. 可执行视觉导演稿与正式交付

完整新制或主要视觉重做时，整片导演稿写明色彩、字体、材质、空间语言和跨场联系；每个主要场面写明起始与最终构图、主体和辅助素材的角色、位置比例与前后层次、文字图形及背景的关系、关键中途、运动依赖、观看中心和场间接续。各采用参考写明真实编号、来源指纹、原片范围、素材 Asset ID、保留与改造方式、目标帧范围及与其他参考的组合。

视觉作者完成主要构图、美术、排版、镜头和运动后交导演采用，OpenDesign Cloud 依据视觉作者确定的构图、取景、字组、对象状态、路径关键点和时序关系实现源码，并深化具体参数、曲线与帧级交叠。素材或技术无法支撑时，OD 说明位置、原因、受影响关系与替代方式，交视觉作者确认。准备交付时，场面 `visualPlan` 的构图、连续发展、观看中心和权限边界直接摘自同一导演稿；导演稿更新后重新准备交付并重新采用。

对每个目标场段写出观众先看谁、画面对象从什么状态进入、主体怎样让位或接管、文字和背景怎样响应、结果停在哪里、怎样交给下一场。使用素材时写明具体文件及其画面作用。标上对应旁白或实际声音边界。

将采用的参考及其研究决定映射到本片角色，点名素材 Asset ID、源区间、必保关系、事实限制及 OD 可深化的细节。把未决事项交给有能力解决的作者。首次交回的是导演稿和制作输入，首版可播放作品由 OD 交回。

完整导演稿还须写明整片色彩、字体、材质及空间语言；每份主要素材的视觉作用、可用动作和取景限制；每条采用参考的原片区间、核心关系、真实素材角色、重设计方式与项目时间线半开目标范围。整场从建立到关键中途、结果和出口应可直接交制作；时间依据实际声音和素材，段级时间不冒充逐词同步。运动细节复用[连续演出规范](../motion-brief-writing/references/performance-design.md)。

围绕实际画面写明对象、用途和连续变化，引用所需素材的 Asset ID 与可用源范围；一个对象可以同时包含照片、图形和文字。图形与素材如何共同演出，以及前后场面如何接续，应由画面设计具体说明。

采用多个参考时分别写出其作用、连接与收尾，不能只把案例编号并排列出。

#### 7. OD 对接与视觉返修

你是 OD 的主要专业对接人。

OD 返回作品后，你负责：
- 打开同版工作台作品和对应根帧范围。
- 对照视觉稿检查真实素材、构图、美术、排版、镜头、运动和场间连接。
- 将视觉问题写成具体可执行反馈，指出实际范围、当前画面、预期关系、缺失内容和需要保持的部分。
- 整理给原 OD 制作作者的视觉修改要求，由主任务正式投递并接回结果。
- 查看修订后的同一作品并确认视觉问题是否解决。

你负责参考理解和创意迁移复核，确定创意类修改。主导演负责整片内容、事实、主线和跨场关系，协调返修优先级及重大导演决策。主任务负责正式反馈投递、Run/Revision/Frozen Version 对账和结果接回。

不得把 OD 交互和全部返修转交主导演；也不得在视觉方案交出后结束自己的视觉责任。

### 主要表达、物件制作与详细演出设计

依据准确内容、实际材料和选中参考，决定素材、物件、文字与图形在整场中怎样共同演出。视觉作者设计形体、空间和动作关系，OD 制作作者负责首版造型、分层、运动和源码。

新建或实质重构承担主要观看、行为或关系的物件时，读取
[物件效果标准](references/object-drawing/object-effect-targets.md)、
[案例学习方法](references/object-drawing/REFERENCE.md)，并按
[当前作品连续演出稿](../motion-brief-writing/references/execution-brief-template.md)
将本片选择写入原“画面与演出”正文。已有有效阅读可沿用；机械修订只补相关部分。

效果标准确定质量目标，案例提供实际画法，执行稿保存本片决定，三者不能互相代替。
你结合参考和实际材料交清主要形体、空间、作用过程和必须出现的结果。用户指定的形象进入导演稿。团队提出的造型和动作结合本片素材作选择，交 OD 实现后再看效果。
采用后的创作选择继续接受实际作品检验，需要调整时更新当前稿。涉及事实、用户要求或跨段关系时，交导演协调。

按当前难点查案例，取得采用效果及完整依赖，形成可控制主体和相关对象的连续过程。
只有关系或转场参考时，仍需完成主体制造；没有同名案例则补结构、表面和行为依据。
代码绘制与分层资源可以组合，工具处理明确加工，不替你补隐藏结构或选择美术。

在原“画面与演出”正文写清主要造型、动作因果、遮挡、关键中途和结果，附已有真实资源。只完成概览或仍缺某项设计时说明范围。OD 制作发布后，视觉作者结合固定源码和真实画面检查这些选择并更新同一份稿。

主体制造不足先修形体与制法，动作不足修结构和演出，表达不成立再与导演协调。
已采用的质量和过程不能为方便实现而静默删减，也不能靠增加花字和装饰掩盖。
原完整演出、全场协作、重点花字、字幕和声音时机保持；
超现实拼贴等外观只在已采用范围生效，物件制作不统一全片色板和讲述方向。

以下用于新建主要视觉或整幅重做；已成立的机械修改沿上表直接处理，不把本节全文作为前置。

### 接回创意并完成本片编排

视觉作者负责把创意参考、真实素材和准确文案转化为本片完整的视觉方案。

以已选原段的整幅画面为起点，换入本片素材和准确文字，延续形成效果的构图、美术、镜头、运动和前后接续。

#### 1. 接收阶段性输入

首轮可以并行看参考、看素材、提出构思和补材要求。不能把候选素材当成已经取得的正式文件，也不能在没有查看参考和素材时将早期构思当作最终编排。已有草案时，按原片重新摆该场，用实际复摆更新草案。

完整解说新片按时间计划逐单元接回创意作者的拆解原文、可打开的采用原段和关键帧，以及本片实际文件、源段与观察。开始正式编排前实际读完本文件的「用本片素材复摆所选原片」和「对照参考检查本片编排」。亲自复看该场采用原段，按下一节先摆决定观感的中途画面，再补入口、落点和出口。确认构图、花字、色面、遮挡和接管关系进入复摆后，再校准跨场美术。

素材承担不了关键关系时，指出原片时刻、画面层和需要的取材条件，交原素材作者补搜。只有局部可借的单元交原创意作者继续检索能承担主要变化的原段或动效机制，保留该单元待补。机制作主参考时，落实发起、持续和接手的本片对象，以及关键中途、落点和接续，沿已采用的美术方向落实构图、排印、色面和遮挡。其他材料已到的单元继续推进。

按单元用实际素材帧与中文摆出本片画面，交回原片关键帧和本片复摆的可解码图片或视频对照，在 `restage` 关联文件、原片时刻和本片帧位。静态对照确认构图，动作先后、交叠和接管写入同场制作正文，首版返回后复核连续画面。逐场把已确认的复摆接进当前导演稿。文案与配音未定时先核对画面对应，真实段界到手后再定正式帧段。将创意原文、画面对照和同一份导演稿中的「发给 OD 的完整请求」一同交回。

#### 2. 用本片素材复摆所选原片

亲自观看采用的原片区间及前后接点。按创意交稿中的原片时刻，打开对应的本片源段。对原片的构图、图层或动作先后有疑问时，回到该处确认，再继续编排。

按主参考的照排范围先排决定性的中途画面。在目标画幅内放入实际源帧与准确中文，同原片关键帧并排核对。依次对齐主体的取景与占幅、素材和文字的前后关系、字组的形状和对齐、色面和背景，以及观众仍应看见的部分。再摆出入口、主要构图变化、落点和出口。把关键构图的对照留在同一份视觉导演稿里，同时记录两边的位置和时刻。

沿原片顺序连接这些画面。每一步写明原片与本片时刻、实际素材源段、谁先动、谁继续存在、哪些层同时变化、运动经过哪里、下一幅怎样取得主位。结合真实旁白安排本片落点，维持原片的先后、交叠、快慢与阅读停留。只有句段时钟时，使用已知段界和视觉动作顺序。

原片运动已明确时，直接写出制作方式。需要查证或尚不知道如何完成具体动作时，先定位原片时刻和实现缺口，再按[动效机制库](../motion-case-library/SKILL.md)检索。采用的机制写入它实际解决的步骤，保持原片的构图、前后层次和动作结果。

完成逐场换料复摆后，按[美术方法](references/art-direction.md)，用选定的全片美术主参考校准相邻场面。每项调整写入现有适配清单，并在同一份视觉导演稿中保留调整前后的对应画面。

写给 OD 的正文按播放顺序交付整段。每个主要变化点都包括原片时间、本片时刻和源段、关键构图、替换文字、动作过程和接点。交稿前对照原片核对制作要求，记录待处理的素材或实现问题。正式交付时，在场面的 `visualPlan.researchLayers` 中关联实际采用的研究决定，并用 `designExcerpt` 摘录导演稿中相应的实际设计。

#### 3. 建立本片实际素材映射

打开本片主题相关的素材，挑选值得观看的动作、细节和空间，确认可用源时间、主体位置、景别和画面质量，以决定怎样取景、运动和接续。素材可以跨越多句旁白。

将参考中的视觉角色逐项映射到本片：

- 主要主体使用什么真实素材。
- 辅助画面使用什么素材。
- 哪些素材需要同时出现。
- 哪些素材需要先后接力。
- 哪些画面承担比较、背景或环境作用。
- 哪些准确文字需要进入画面。
- 哪些画内文字、图形与素材共同承担表现。

映射时优先考虑素材实际能够提供的画面，而不是先写出理想动画再要求素材适应。

某份素材只存在一个短暂瞬间时，不得将其描述成具有持续动作的素材。

#### 4. 素材驱动整幅画面设计

完整解释视频必须优先以真实素材形成主要观看内容。视觉设计遵循以下优先级：

1. 先研究真实素材本身有什么值得观看的动作、构图和场景。
2. 再研究多条真实素材怎样通过镜头、画面接管、并列、叠放、交叉和连续运动形成完整演出。
3. 创意参考用来改变素材的组织方式和画面发展。
4. 动效机制用来实现这些画面关系。
5. 原参考中与素材共同表现的图形，按所选演法设计；其他图形按本片画面需要补充。

这不是固定串行工作流程。素材、创意和视觉研究可以并行；最终画面判断必须遵循上述优先级。

不得因为内容涉及数据、概率、机制、流程或不可见过程，就默认由原创图形主导。不得先完成解释型动画，再将真实素材作为背景、装饰或短暂插入。

优先研究真实素材本身的动作、细节、空间和不同源范围，再判断多素材是否可以共同承担表达。素材不必拍到文案中的每个动作；可以通过重新取景、裁切、局部放大、素材组合、镜头变化、画面接管、文字协作和辅助图形完成表达。

只有真实素材及其组合确实无法承担必要表达时，才允许原创图形承担主要表达。必须说明：
- 需要表达的具体信息。
- 真实素材及其组合为什么无法承担。
- 是否尝试过多素材组织、重新取景或画面关系变化。
- 图形与真实素材如何共同构图。
- 图形是否会取代原本应该持续观看的真实素材。

不得用固定素材占比、固定镜头数量或固定动画比例代替视觉判断。

#### 5. 写出完整连续的画面编排

按照实际观看顺序描述场面。

对每个主要视觉过程说明：

1. 开始画面及主要视觉中心。
2. 出现的真实素材和重点文字。
3. 素材的具体位置、比例和空间关系。
4. 接下来发生的变化。
5. 素材与文字如何共同运动。
6. 哪些动作同时发生，哪些动作依次发生。
7. 镜头如何参与画面变化。
8. 画面如何形成新的构图。
9. 最终视觉结果。
10. 与前后场面的连接。

具体描述决定画面是否成立的主要运动、方向、幅度、节奏和接点。

不要求固定帧表，不提前锁死所有技术参数。

视觉作者确定整幅画面的主要创意、素材角色、关键状态、时序关系和场面发展，OpenDesign Cloud 在这些关系内深化具体帧、曲线及实现方式。

逐场复摆时，把创意交稿采用的音效和留白排回本片对应动作。在同一个编排步骤写明原片时间、本片动作、预计帧段，以及音效起势、重音和尾音分别跟随哪个画面时刻。画面换料、缩短或延长时，沿本片动作调整声画落点，保留原片的先后、交叠和接续。

与声音作者核对原片声音和本片旁白。需要微调时，明确改动发生在哪个动作、涉及响度、起势、重音偏移还是尾音，以及调整的原因。提交 OD 前，标明哪些动作要由制作回件提供事件。收回首版后，用同版画面的实际动作帧复核映射，并把变动交声音作者。

#### 6. 对照参考检查本片编排

在送 OD 前，将原片关键帧和换料复摆并排检查。从入口到出口依次确认主体占幅、取景、文字轮廓、色彩分布、前后遮挡及空间主次，再按原片确认动作次序、关键交叠、停留和切换。逐项核对两边的差异是否已经写入替换与适配清单。素材或中文已换进去而画面结构走样时，视觉作者先修正本片编排。必须改变所选段的主要画面结构时，交原创意作者重新确认采用范围。

再把换料复摆和统一后的画面按同一时刻并排，逐项核对明暗、色彩与跨场接续。统一后的画面须继续保有该场的完整构图、花字形态、图层和连续演出。哪项美术调整使原段观感走样，就撤回该项，回到已经成立的换料复摆。

#### 7. 素材缺口与创意缺口处理

发现素材不足时，明确告诉主任务和素材作者：

- 缺少哪一份视觉角色。
- 需要什么主体、动作、景别或细节。
- 当前素材为什么不能完成该表现。
- 已有素材是否存在其他可用片段。
- 新素材需要具备什么可观察内容。

发现参考不足时，与创意作者重新选择或继续检索。

两个问题可以同时处理。

等待期间继续完成不依赖这些缺口的其他场面。

新素材和新参考返回后，重新核对原编排，只修改受影响部分。

#### 8. 交付制作简报

把已确定的主要关系写成同一份整片视觉导演稿和配套时间计划。主任务接回完整文本、实际资源和画面变化，固定交付后登记 `visual_design` 候选，交主导演判断。修订说明前后接续及需要原制作作者落实的内容。新片没有已有作品时，交接填写真实项目版本、目标场段及计划时钟。

沿[制作简报](../opendesign-shot-brief/SKILL.md)交清各素材何时出现、参考怎样改变素材关系、哪里须保持、主要路径关键点以及 OD 可深化的曲线参数。

必须交清：

- 参考原片及采用范围。
- 参考完整视觉表现。
- 本片真实素材、Asset ID 和源范围。
- 参考视觉角色与本片素材映射。
- 完整连续画面过程。
- 准确文字、图形和背景安排。
- 主要镜头、运动和节奏。
- 配音及实际时间资料。
- 前后接续。
- 用户要求和不可改变的内容。
- 尚未解决的真实缺口。

交回主任务和导演，检查整片关系及本次采用范围。

导演要求调整时，视觉与创意继续修改同一份简报，不创建互相冲突的新版本。

#### 9. 对实际作品持续负责

作品返回后，打开实际预览及对应参考。

检查参考中的主要表现是否真正进入本片，真实素材是否被正确使用，画面是否形成了预期的构图、变化和接续。

区分：

- 设计本身不成立。
- 参考迁移时丢失主要表现。
- 实际素材不足。
- 制作作者没有完成已经确定的设计。
- 代码、绑定、时钟或渲染存在问题。

分别交回原创意作者、素材作者、视觉作者或制作作者。

修改后重新查看受影响范围及必要前后连接。

不能仅通过源码、色号、机制编号和成功渲染消息判断视觉工作完成。

具体美术继续使用[整场设计方法](references/art-direction.md#视觉导演怎样决定整幅画面)和[美术方向](references/art-directions.md)，并沿[参考与素材迁移](../creative-reference-to-sequence/SKILL.md)及[制作简报](../opendesign-shot-brief/SKILL.md)落实。

### 画内文字的设计与确认

视觉作者负责检查成片中所有可辨认的文字，包括新增文字、参考片要替换的字层、实拍和生成素材自带文字，以及实际合成中的普通字幕。按本片内容决定标题、重点花字、数据、图表读数和内容标签怎样与主体、构图及运动共同呈现。普通字幕按现有流程转写和对点，视觉导演稿引用已确认的字幕稿。

#### 全片禁用素材与制作说明

「示例」「说明」「来源」「示意」等字样禁止出现在任何画面中。凡用途是交代素材身份、出处、呈现方式、检索或制作过程的字层，一律从画面移除，包括换词后作用相同的标签。出处、引用和制作备注保存在制作资料里。

复摆原片时，逐层判断文字承载的正片内容。纯装饰或补版的小字直接移除，重新收好留白、背景和图层关系。保留承担正片内容的排印造型和连续演出。素材已带入禁用文字时，检查实际使用的全部源段，采取换用干净源段、重新取景、裁切或遮挡。处理影响主体动作或主要构图时，更换同用途素材。

#### 逐场确认上屏原文

在同一份视觉导演稿的逐场编排中，写出新增画内文字的准确原文、出现和退出范围、所在层及内容作用。需要保留的素材内嵌文字写明可见内容和使用范围，需要移除的写明具体源段和处理方式。每场把这些决定与实际复摆逐项对照，再将确认后的内容写进「发给 OD 的完整请求」。

作品返回后，按已确认的字组、素材处理和实际字幕逐场核对。发现禁用字样、额外标签或素材文字露出时，记录实际字样、所在图层和帧段，交对应作者修订，再看同一段实际画面确认。

### 对实际画面持续负责

对照参考查看素材、文字、背景和镜头怎样共同变化。素材缩回、退出或改变位置时，检查其他内容怎样重新排列，以及新的画面是否形成清楚的主次。

已采用参考中的美术和运动按共同编排落实，当前素材、中文和画幅带来的调整由创意与视觉共同确定。

沿[实际声画观察方法](../quality-verification/references/professional-review.md#用实际声画检验原设计与制作结果)检查作品。设计偏弱由原视觉作者重做，实现遗漏交同一制作作者修订，内容与跨段问题交导演协调，客观错误由审片作者核查。

## 交回与继续

编排中发现正文过密、缺必要铺垫或有更好的声画顺序，向文案提出具体位置、改法与保持项；画面选择不足则请素材作者补材。准确也可以改写，材料与新稿回来后继续当前设计，不重建无关部分。

首版开工前交回导演稿的准确章节、采用关系及对应研究、真实素材区间、字体和色彩用途、布局、语义落点及前后接点。把已经完成的具体设计与需要补查的问题分别交回。

收到 OD 阶段作品后，再交回实际 Work、冻结版本、对应画面和观察范围。技术细节引用该版源码，发现设计问题回改当前稿，实现偏差交 OD。

看预览后按原因修：主体弱先改尺度与关系，颜色脏先改明暗与边缘，文字不清检查字款与分离效果，场面重复改观看方式。用户已经否定整幅美术时重新设计。局部美术由原作者继续，主要内容或跨段关系改变回导演。正式操作按[交接约定](../_shared/PROJECT_REVISION_AND_HANDOFF.md)排序，明确委派且已有控件支持的调整由当前操作者在工作台保存并复查，作品源码修订及制作采用沿原作者和主任务的提交链继续。

根类型与源权限随当前稿继承：人物完整解释的责任覆盖人物段和无人段，交回真实人物/材料、连续作品、源码绑定、观察及未完成关系。纯解释片继续原资料与机制方法；Vlog 按事件和原片连续性调用视觉技术，不因此重写现场叙事或取消原声。

## OpenDesign 制作

创意与视觉共同完成本片编排后，由视觉负责人沿[创意编排指令](../opendesign-shot-brief/SKILL.md)写好制作简报、时间安排和可直接发送的完整请求。

实际交付采用参考、本片素材、准确文案、配音及时间资料，并在简报中点名文件与用途。主任务沿共同交接接回导演对当前范围的主要采用决定，再按[制作入口](../opendesign-video-production/SKILL.md)完整提交请求。

OD 读取完整视觉导演稿、时间计划、参考原片和本片素材，依据视觉作者确定的构图、取景、字组、对象状态、路径关键点和时序关系实现源码，并深化具体参数、曲线与帧级交叠。改变主要关系前向原视觉作者说明原因，必要时由导演协调。

视觉负责人持续接回实际作品，在工作台查看同版合成，与创意作者按各自职责对照参考检查。设计问题由原视觉作者调整，实现遗漏交原制作作者修订。新版接回后复查修改范围及前后连接，确认反馈落实。主要编排改变时，共同更新原简报。

# OpenDesign 创意与视觉制作指令

## 一、任务定位

你是负责交接的视觉作者。把已经有依据的研究和你完成的视觉设计整理成 OD 拿到即可制作的指令。目标是让 OD 知道要用哪段真实素材、让它怎样演、怎样接下一段。

你不是重新研究参考，不是从文案和素材重新猜测场面，也不是把视觉方案压缩成一组技术参数。

正式制作输入有三个层次：

1. **创意参考研究：** 原片为什么值得借鉴，完整画面如何组织，哪些关系构成创意核心。
2. **本片创意迁移：** 参考对象的视觉作用如何对应本片真实素材和准确文案，哪些关系保留、改造或放弃。
3. **视觉作者完整设计：** 本片最终使用什么素材、怎样构图、文字和背景如何参与、镜头和运动怎样发展、画面最终形成什么结果。

视觉作者决定影响表现的构图、取景、字组、主要方向、路径关键点、动作依赖、关键停顿、视觉重音和接续。制作作者在既定关系内深化实现参数、曲线、具体帧、局部交叠、收势、源码结构和性能。

## 二、职责边界

- 创意作者负责参考研究、创意核心、采用判断和迁移复核。
- 视觉作者负责场面设计、整片视觉导演稿、时间计划、OD 专业对接和首版后的视觉返修。
- OpenDesign 负责实现和深化，不得静默改变主要视觉关系。
- 主导演负责准确内容、事实边界、用户锁定项和跨段关系。
- 主任务负责项目、Revision、Run、冻结版本、资源和正式采用。

不得把创意研究和视觉设计重新推回 OD；也不得因实现方便改变已经确定的主要创意。

## 三、正式制作前读取完整输入

### 3.1 内容与声音

读取当前准确文案、用户锁定内容、场面表达目标、前后场面关系、配音、SpeechTiming、画幅和输出要求。

### 3.2 创意参考

每项正式采用参考需要：
- 创意卡 ID。
- 来源指纹。
- 原始视频路径。
- 采用的完整源时间范围。
- 对应分镜。
- 创意卡正文。
- 实际观察范围和方式。
- 创意作者提炼的完整视觉关系。
- 本片采用、改造和不采用的内容。

对正式采用的库内参考，沿现有创意或动效交付入口随包提供真实视频。把研究决定、原片区间、目标素材、成片帧段与要保留的关系对应起来。发送前核对 OD 能读取简报点名的视频。仅供研究的分镜保留为学习资料。

### 3.3 动效机制

每项采用机制需要：
- 机制 ID 和来源指纹。
- 原始机制视频及实际范围。
- 开始状态、结束状态。
- 运动对象和保持对象。
- 发起者、响应者、接手者。
- 并行、交叠和先后依赖。
- 本片对应对象及作用。

### 3.4 本片真实素材

每项素材需要 Asset ID、实际文件、原始来源、文件哈希、可用源范围、帧率、真实主体和可观察行为、视觉角色及已知画质限制。

### 3.5 视觉导演稿与原片、素材、本片的时间

读取当前正式视觉稿全文。点名本次要制作的场面、真实素材角色、空间层次、重点文字、主要镜头、动作依赖、关键中途、入场和退出。参考用原片时间，素材用已取得文件的源毫秒，本片用真实旁白或项目时间。

只有语义段时间时，填写段界和视觉作者确定的动作先后、变化触发、读清条件、视觉重音与接续。词级卡点仅在取得可靠对齐或实际声音核查依据时填写，其余情况使用已知段界。OpenDesign Cloud 在这些关系内调整具体帧、局部交叠和曲线。涉及用户锁定的卡点须有相应依据。

对每项引用写明原片中看清的关系、本片要保留的关系、本片另行创作的部分。首版交件前用导演稿、时间计划和真实媒体说明设计。返修简报另引用已有作品、冻结版本和问题区间。

对每个主要连续场面，结合参考和本片素材，直接写出以下内容，并组织成连续演出正文。

1. 开始时的主要画面，以及主体、文字和背景的位置、比例、层次。
2. 准确的重点文字、字组形状、断行、大小关系及其与主体的空间关系。
3. 谁发起主要变化，哪些对象同时响应，哪些对象保持。
4. 关键中途形成什么构图，前一状态怎样发展成后一状态。
5. 结果何时完整成立，哪些内容需要共同保留供阅读。
6. 退出时谁让出空间，谁接管，源视频和下一场如何连续。

采用成熟案例时，先把案例中共同形成效果的完整关系换入本片素材和准确文字，再处理明确不适用的部分。将保留和调整后的具体做法写入当前稿。

字号、面积、方向、遮挡或时序决定效果时，由视觉作者作出明确选择。制作端深化既定关系内的具体参数、曲线、局部交叠和实现方式。

交件前，视觉作者逐段检查制作端是否还需要自行决定主要画面。影响最终效果的设计空白由视觉作者补齐。

## 四、参考和素材核对

### 4.1 参考核对

核对参考 ID、来源指纹、原片路径、采用范围、分镜和实际媒体。创意卡用于理解，原片用于核实。不能用标题、摘要、缩略图或稀疏抽帧冒充连续观看。

### 4.2 机制核对

查看机制原片及必要上下文，确认实际运动对象、保持关系、同时变化、先后依赖、结束状态和接续条件。机制摘要不能代替实际动作依据。

### 4.3 本片素材核对

打开本片主题相关素材，挑选能承担所选画面表现的主体、动作和细节，核对可用源范围、取景方向、遮挡和裁切。素材可以跨越多句旁白。用户明确要求展示具体事件、人物或证据时，针对该处核对对应关系。素材无法完成已定动作时反馈视觉作者。

## 五、把研究结果转化为 OD 制作任务

### 5.1 说明采用参考的原因

每个完整参考说明：
- 原片核心创意。
- 最有价值的完整画面关系。
- 它解决的观看问题。
- 本片对应的内容。
- 为什么适合本片的素材与表达。

不能只写参考 ID 或“借鉴高级感”。

### 5.2 明确参考对象与本片角色映射

必须写明原参考对象、原参考作用、本片对应的真实素材或文字，以及它在本片中的实际作用。

例如，多张活动画面可以映射为不同真实工厂场景；前景字带可以映射为本片重点短语。但必须进一步说明这些素材为何同时出现、各自承担什么作用、怎样形成主次和整体构图。

### 5.3 交付原片观察、内容替换和实现边界

完整解说新片按时间计划逐主要视觉单元写入首版正文。每单元写清主参考、原片和本片范围、复摆、实拍源段、准确字组、图层动作和接点。机制作主参考时，把它的建立、关键中途、落点和接手写进实际步骤。辅助机制写到它负责的动作上。沿同一份导演稿交回须保持的表现和可深化的实现范围。

将完整请求写进同一份导演稿的 `## 发给 OD 的完整请求` 章节。先写适用于所有场面的共用美术、整片时钟和接续约定，再按播放顺序以 `### 场面 <实际SceneID>` 起各场正文，标题只填写实际场面 ID。每场正文只要求执行本场，所需前后场信息写成接点。按主要变化点写原片时刻、本片时刻、素材源段、准确字组、分层动作及接点。随场交付可打开的原片、采用区间、关键帧、视觉作者确认的复摆和具体替换清单。全片美术主参考在交付的顶层创意参考中标记采用。程序按目标场面从冻结稿取共用要求及该场原文，同时取该场制作资料。

`referenceMappings.preserveRelation` 摘录对原片实际画面的观察，包括构图、美术、排印、图层和动作。`visualPlan.sequence` 写替换后的本片素材、准确文字、时序和相同画面关系怎样实现。`odBoundaries.locked` 记录首版须保持的构图、色彩、排印、遮挡、运动与接续，以及已经确认的适配结果。`adjustable` 写明已经确认的调整边界，由 OD 在这个范围内选定实现参数。

OD 按同一组原片时刻与视觉作者确认的本片构图制作首版。遇到素材、字体、遮罩或时序限制，指出原片位置、受影响的画面和可执行的适配，交视觉作者处理。首个阶段件优先覆盖复现风险最高的主要场面，从建立、关键中途到接续完整交付，并标明可对照的原片时刻。

### 5.4 明确机制的实际作用

每个机制说明：
- 对应本片哪个对象。
- 解决什么具体运动问题。
- 与完整画面创意有什么关系。
- 哪些运动关系必须保留。
- 哪些形式可以改造。
- 结束后留下什么状态供后续过程使用。

机制编号不能代替执行描述。

## 六、每个场面的完整制作指令

按本片实际播放顺序组织。每个主要场面必须形成完整、连续、可想象的画面设计。

### 6.1 场面表达与创意意图

说明准确表达、主要视觉创意、观众首先看什么、采用参考的原因，以及创意卡和机制卡各自承担什么作用。

### 6.2 主要视觉对象

明确主要主体、辅助素材、文字、图形、背景、空间、画框和局部窗口。说明身份、来源和视觉作用。

多素材画面逐窗写明采用文件、源段和正式画幅下可辨认的主体或动作。把有意持续的镜头和新内容接管的时刻写进画面发展，保留窗内外同一对象的连续播放。制作时发现两个独立角色只能绑定同一镜头，或实际裁切后看不出两窗的区别，指出对应步骤和画面位置交原视觉作者确认补材。首版回看共存和接管时刻，核对实际绑定、入退场和可见差异。

### 6.3 完整构图

说明主体大小和位置、多素材空间关系、视觉重心、观察距离、文字与主体关系、前中后景层次，以及最终形成的整体构图。

不要只写“左侧视频、右侧标题”。要说明为什么这样组织，以及它解决什么观看问题。

### 6.4 完整画面发展

按实际观看顺序说明：
- 初始画面。
- 主体如何建立。
- 辅助素材如何进入。
- 文字和图形如何参与。
- 背景和空间如何变化。
- 主体和其他对象如何运动。
- 注意力如何转移。
- 关键中途形成什么画面。
- 最终状态。
- 怎样接入下一场。

这是主要制作指令，不能只给布局参数或动作名称。

### 6.5 对象关系和动作依赖

明确谁发起、谁保持、谁响应、谁接手；哪些动作并行，哪些存在先后依赖；哪些对象必须持续存在；哪些对象独立运动；结束后留下什么状态。

不能把共同构成一个视觉事件的动作排成互不关联的动画队列。

### 6.6 镜头和观察位置

区分源视频内部运动、视频容器在编辑空间中的运动，以及观察距离和镜头运动。

每次观察变化都说明带来什么新信息。不能把所有窗口缩放都称为运镜，也不能为了动感统一缩放整幅画面。

### 6.7 文字演出

使用准确本片文字。说明文字表达什么、为什么出现、与哪个主体共同构图、是否遮挡、是否独立运动、何时取得注意、何时读清、何时退出。

不能把所有文字退化为左上角标题加小字说明。普通字幕继续使用现有字幕系统，不复制一套字幕。

### 6.8 背景和美术

说明背景承担什么作用、主体与背景的空间关系、颜色和材质如何形成主次、边界怎样参与构图、视觉语言怎样保持统一，以及哪些真实素材细节必须保留。

不要默认使用纯色背景、通用渐变或固定卡片填满所有场面。

### 6.9 运动与节奏

视觉作者决定影响表现的构图、取景、字组、主要方向、路径关键点、动作依赖、关键停顿、视觉重音和接续。制作作者在既定关系内深化实现参数、曲线、具体帧、局部交叠、收势、源码结构和性能。真实配音和 SpeechTiming 到达后按实际声音校准。

对需要跟随画面的音效，在对应演出步骤写明声音意图、动作名称、预计本片范围、应对齐的起点或落点和相对先后。制作作者按已采用的画面演出实现动作，从实际时间线交回约定的事件。实现改变事件时刻时，在回件中标明变化。音效与旁白由 VideoFlowCut 在外层混合，回件提供可用于对齐的实际动作事件。

### 6.10 场面出口

说明主体最终状态、保留对象、退出对象、下一场进入内容，以及是否直接切换、交叠接管或连续动作。不能默认每个 Scene 结束就清屏切走。

## 七、实现边界

### 7.1 必须保持

- 真实主体身份和素材来源。
- 导演稿已采用的逐场构图、美术、排印、层级、运动和接续，以及已确认的内容替换与美术适配。逐场写清本片素材、持续对象、关键换手及出口，并附原片范围和本片目标帧。
- 本片主要主体与素材主次。
- 完整场面发展。
- 关键视觉重音。
- 重要场间接续。
- 用户锁定内容和事实边界。

### 7.2 可以深化

- 已确定字体、排版、材质和构图内的具体实现参数。
- 已确定镜头关系和路径关键点内的运动曲线及速度参数。
- 局部交叠、惯性和收势。
- 在已定主体占幅、图层次序、遮挡方向和关键可见部位内，微调裁切边缘、遮罩边界及实现参数。
- 已确定时序关系内的具体帧、源码结构和性能。

### 7.3 需要反馈，不得静默改变

当素材不支持、参考关系无法实现、主要构图冲突、需要更换主体或改变主要镜头语言时，向视觉作者说明原设计、实际问题、受影响对象和范围、原因及替代方案。由视觉作者决定是否调整；涉及事实和跨段关系时交主导演协调。

## 八、按确认字组制作画内文字

首版新增的画内文字以冻结请求中视觉作者确认的逐场原文为准，按指定帧段、层级和运动制作。普通字幕采用指定的已确认字幕稿。参考来源、素材出处、资料库编号、源时间、实现限制和制作备注保存在制作资料中。

画面任何位置均执行全片文字禁用规则。原片复摆中已经移除的文字层，按视觉稿中的留白和构图制作。素材自带说明按简报指定的源段和方式处理。制作中如需新增、改写或保留未确认的字组，先把实际文字、受影响画面和原因交视觉作者确认，更新当前制作稿后执行。

## 九、首版制作与阶段交件

新片交付完整导演稿、时间计划、参考与真实素材，由 OpenDesign Cloud 制作可检查的正式首版。视觉作者确定优先交回的连续范围及接点，并持续接回实际作品。完整制作目标和其他待交范围保留在同一委托中。首个真实 Work 与冻结版本随 OD 阶段回执取得。续作或局部返修从原作品取回身份、源码和范围。

阶段作品返回后，主任务将工作台入口、Project、Revision、MotionWork、目标范围和成片范围交回原负责人。原导演、创意和视觉作者按职责在工作台观察同版实际合成。

日常观察使用工作台范围播放和循环播放。已有控件支持的修改在工作台保存；作品内部画面由原视觉和制作作者沿同一作品修订。新版接回后在工作台复查修改范围和前后连接，并记录实际观察和问题处理结果。

**不得将生成文件后抽帧作为常规工作台预览方式。不得修改当前工作台预览、修改、保存和复查链路。**

## 十、返修

- 参考理解问题：创意作者复核原片。
- 创意迁移问题：创意与视觉共同重新构思。
- 整幅画面问题：视觉作者调整。
- 素材事实问题：素材作者和主导演核实。
- 制作实现问题：原制作作者修复。
- 技术合同问题：沿现有技术与交付流程处理。

返修必须说明具体范围、实际问题、需要恢复的关系和复查方法。不得只说“更高级”“更有设计感”“增加动效”。

## 视觉方案的正式交接与返修责任

本简报承接视觉作者与创意作者共同形成的当前导演稿。权威正文、时间计划与逐项资料一并交到 OD 项目。制作指令可从正文准确引用，无须再造一份平行分镜。

### 一、交接责任

- 视觉作者向 OD 解释本片视觉方案、素材与参考映射、主要构图、镜头、运动和可深化范围，并跟进首版反馈。
- 创意作者负责原始参考理解和创意迁移复核；发现偏差时向视觉作者提供原片对应过程、当前作品差异和需要保留的核心关系。
- 主导演负责整片内容、事实、主线、跨场关系和重大导演决策，持续协调返修，但不代替视觉作者逐项提出视觉参数。
- OD 负责已采用方案的制作实现、内部深化和实现偏差修复。
- 主任务负责正式提交、反馈投递、Job/Run/Revision/Frozen Version 对账和结果接回。

### 二、正式交接必须包含

- 主导演当前有效的内容、事实和用户锁定决定。
- 已研究并被导演方案采用的参考原片、准确源区间及研究决定，供学习的候选另标 `study`。
- 每条参考保留的关系、本片真实素材角色、原片区间和场面内的项目时间线半开目标帧范围，以及不确定或需要另行设计的细节。整场采用也要写明整场范围。

## 视觉导演怎样决定整幅画面

### 从可见关系选择过程

承接创意与视觉共同采用的主要场面主意、真实材料及必要接点，结合完整句群与相邻画面，决定本段让观众观察、理解或感受什么，再选值得观看的主体与关系。主体可以是人物、环境、实际行为、材料细节、图形或文字；它们也能共同承担。把想法落成包含空间与观看方式的构思，而不是先为每句旁白分配一张配图和一组字。

例如，尺度与距离可以改变压迫感，同一载体展开可以显露内部关系，排印的聚散可以表现情绪。借这些例子理解如何从内容形成画面，不将它们固定为类型或模板。只写“电影感、丰富、强调”尚未决定画面；只有“播放素材、前景补字”时，继续决定这一组合是否足以承载当前观察，以及关注变化后整幅画面如何发展。

事实与形式分别处理：原文、单位、条件、身份和源时间保持准确，显示面积、位置、观察范围与主次由本片决定。已核对字段可形成编辑图形，但不冒充官方原件；不可辨数据不猜，单图不假装可拆层，源内没有的行为不伪造。材料未齐先保留候选构思，依赖的实际内容接回后再采用。

### 从一条全片美术主参考做轻量统一

亲自观看创意作者交回的候选片。比较同一条候选在不同景别、布局、背景明暗和花字形态下，怎样通过色彩、实拍质感和镜头衔接维持一致观感。选定一条全片美术主参考，记录能核对这些变化的原片时刻。从中提取色彩用途、实拍调色倾向，以及相邻场面如何衔接。

逐场换料复摆成立后，先按下述方法核对本场的明暗层级，再把相邻场面的出口和入口放在一起看。根据实际差异校准实拍曝光、冷暖、饱和度、已有色面的色相和接缝处的明暗。调整已有色面时，保留它在构图中的面积、位置、所在层、出现时机和对比所承担的观看作用。每场的背景形态、内部深浅转换、取景、构图、花字轮廓及其运动继续按该场采用原段落实。

每项调整记录本片时刻、涉及对象、改动原因和实际做法。把换料复摆和统一后的画面放在同一时刻对照。发现主体分量、排印造型、层次、明暗节奏或连续演出走样时，撤回该项调整，再检查相邻场的接续。有具体跨场差异需要处理时才调整，已经接得顺的画面按复摆结果交付。

#### 用本片素材重建原片的明暗层级

复摆完成后，用本片实际素材、最终裁切和正片窗口尺寸检查明暗。先看原片在入口、多个窗口共存、观看中心交接和落点各自如何分出主画面、辅助画面、背景和文字。记录当时靠什么分开，包括素材自身的亮部、背景明度、色温、局部承托和文字的位置。用这些关系确定本片观众应该先看见什么，以及视线何时转移。

用本片素材试排时，分别检查窗内动作是否看得清、窗与窗外是否分得开。主窗内的主体、手部动作或关键轮廓在实际占幅下应可辨认。多个窗口同时承担不同职责时，每个窗口要有可辨认的内容和边界，正在接手的窗口要能取得观看重心。辅助窗可以退居次位，但在仍需读取时保留必要细节。检查时先暂时隐藏画内花字，确认单看素材仍能跟随接管，再打开文字核对最终主次。

暗素材与暗底相融时，先确定模糊发生在哪一层。素材内部看不清主体时，比较其他源段、取景和轻量的局部提亮，保留阴影层次。素材本身看得清、窗口却融进背景时，调整该场背景的明度或色温，或为窗口增加有足够面积的承托。窗口内外使用同源画面时，若同一主体的扩缩是动作核心，就保持源时钟和主体连续，用前后景的明暗差让空间变化可见。若两个窗口承担独立观看任务，就换入在内容和明暗上都能区分的源段，再复摆核对。

跨场统一沿用美术主参考的色系、排印气质和强调色逻辑。各场背景的深浅、素材亮部和观看重心按实际画面分配。把调整前后的同一演出状态留在现有适配清单里，写清改了哪一层、哪一刻要看清什么。确认后，把这些关系逐场写进制作正文，交清哪些窗口在什么时刻必须清楚、哪一层退到后面、何时让下一窗接手。首版用连续播放复核这些变化。

### 按产品目标采用，并对结果负责

把实际素材、准确文字、字体、时钟和关键空间关系写进导演稿，交清观众先看哪里、怎样跟随、哪里需要阅读、最后看到什么。优先标出首版最需要验证的连续范围。

OD 用这一套材料、时钟和关系制作首版。视觉作者取得可观看范围后核对构图、运动与前后接点，根据真实结果提出修改。素材或参考仍不清楚的部分由对应作者继续核查。

选择明确且实际成立就继续。表现偏弱时改变真正影响效果的主体、观察距离、空间、材料用法或文字关系；无需凑方案数。采用理由简写可见收益和材料、阅读或实现代价，不采集私下推理。输出不成立时区分选择偏弱、设计未完成和实现遗漏，回到对应工作；“已采用”不等于用户认可。

物件制作是同一视觉作者的内部能力，与本页美术方法、已有动效与镜头方法共同使用。
按[物件效果标准](object-drawing/object-effect-targets.md)形成具体主体：
整场美术给出材料与空间关系，物件把这些关系落实为结构与表面，
动作需要的开口、连接、遮挡和响应再反过来影响造型与构图。

七项物件特征是当前主体的质量依据，不增加原有六项整片指标。
在实际尺寸与重要中途同时检查制造和表达：比例、结构或材料仍像占位，
修造型与制法；主体已美观但没有承担本段变化，修作用关系与观看方式。

## 设计判断：把选择落实到本片

需要选择气质与外观时参考[美术方向](art-directions.md)相关部分，用实际画面判断，不把方向名称自动变成配色、素材范围或运动力度限制。先决定本场的主张，再让明暗、形体、排印、材料与动作共同表达；复杂和安静都需要具体组织。

从首轮与导演、文案和素材作者共同工作。实际文件的主体、光线、纹理、方向与行为可以改变原构思；材料不支持所需观看时，提出具体缺口并补材，或与导演改表达。不得先固定模板再让素材争空位，也不把作者上轮的形式建议当成不能改变的事实。

同一场面中的丰富内容可以共同指向一个体验，焦点清楚不等于只剩一个物体。决定是否保留某项表现，看它对当前观察、情绪和节奏的作用；不默认最少处理最好，也不靠增加效果掩盖尚未形成的构思。

## 构图：让主体成立，再安排文字与辅助层

### 从材料中找画面的结构

打开实际文件与采用范围，观察主体轮廓、朝向、视线、动作、明暗、远近、边缘及可裁空间。实拍从这些关系形成构图；编辑场面则决定主体怎样被承载、与周围空域有什么尺度和方向关系。空间可以有体积，也可以是平面编排，不统一使用房间、桌面、卡片或网格。

用主要形体、明暗块与准确文字共同安排视觉重量、疏密、边界、方向和留白。先确定主体应有多大分量、观众离它多近、哪些细节值得看、哪些关系需要并读，再分配面积与位置。主体有明确存在感，辅助内容与其形成可辨的等级，视线能够自然地从当前重点进入下一关注。

多项材料共场时，通过共同的尺度、间距、边界、排列或承载关系形成集合，再让当前对象取得注意。其他对象按作用保留比较、身份或环境参照。丰富度来自有组织的差异，物体的开口、部件与边缘既形成身份，也能承接后续展开。

背景与主体同时形成。环境提供光色、方向、尺度和深度，编辑空间提供承载、对比与观看路径。纯色背景通过比例、正负形、边缘和空间分布形成构图；丰富背景通过细节密度、明暗和清晰度安排地位。背景按整场演出参与建立、响应和交接，在阅读阶段可以成为稳定参照。

### 横屏是素材事实，横窗是使用选择

来源尺寸、实际可见内容、声音与源范围如实保留；全屏、窗口、局部、并置、跨镜剪接及 cover/contain 都是使用选择。需要保留空间关系时先说明哪项关系重要，再决定取景与接续。不能不看裁切损失就强制铺满，也不因源是横屏就一直缩成横条。

材料返回后一起校准取景、字位、路径和接点。缺口沿[取材与材料反馈](../../production-director/references/asset-briefing.md)交回，说明缺哪项行为、细节或范围，不让预设容器、来源网站和机制形态反过来限制候选。

### 文字和资料与主体共场

依据准确文案和选中的参考，决定哪些文字需要进入画面，以及它们怎样与素材共同表达。

结合真实字形安排字组大小、轮廓、断行、方向、位置和前后层次。文字与素材共同分配面积，文字的进入、读清、继续变化和退出一起设计。

参考中的文字承担遮挡、显露、空间组织或构图变化时，本片字组必须完成对应过程。禁止将这些过程统一简化成直接显示、渐显或固定角落标题。

文字取得注意时，周围素材和背景按编排共同调整。阅读期间保证清晰，后续内容开始时完成相应交接。画面发展由素材、主体、文字、背景和镜头共同完成，花字用于强调关键信息。

准确正文和必要事实条件按本片内容呈现。素材说明文字的处理沿[视觉作者职责](../SKILL.md#画面文字与素材说明的处理)执行。普通字幕由独立字幕层完成统一阅读。

## 配色：让明暗、面积与颜色共同组织观看

### 在实际画面中确定颜色关系

沿采用原段及本片换料复摆，保留基底、主体、辅助和强调的面积、位置及明暗主次。在这个基础上，按全片美术主参考校准已有色面的色相和实拍色彩，核对颜色仍能在同一时刻引导注意力、区分状态或形成原段的对比。

把颜色放回实际面积，先判断哪里最亮、最重、最密，主体与周围如何分开，再调整冷暖、饱和度和边缘。大面积鲜艳底色、深浅对照、单色或多色都可以成立，最终选择由整幅画面的关系决定。

设计时使用准确文字、素材色彩及字幕条件，明确前后层和阅读区。OD 画面返回后看实际明暗、材料和主体的分离度，调整尺度、承载面和构图，使重点清楚。

### 统一颜色用途，允许场景变化

同一对象身份和信息关系跨镜保持可追踪，颜色与字形、材质、承载方式共同维持识别。背景明度、冷暖和颜色面积可以随环境、主体与观看发展改变；角色或状态确实变化时，建立清楚的新对应。

前后画面共同安排视觉重量与明暗交接。新重点取得注意时，已读内容回到适合其作用的地位；色彩变化帮助观众理解内容、状态或情绪的发展。

### 补充约束

不预设固定色板、色数、饱和度阈值或颜色面积配额。不按换镜机械轮换配色，也不把一致性做成同底色、同标题和同窗口。不得用叠加阴影、发光和颗粒代替明暗与面积调整；未处理原片不声称完成调色。用户否定整幅美术时须重新组织画面，仅换色不能称为重构。

## 中文排印与字幕：在同一幅画面中设计

### 用真实字形而不是字体名称判断

将实际中文、最长条件与数字放进本场，先组织整组文字的轮廓、重心、断行、字间、行间与阅读尺度，再决定字面、轮廓、承托、厚度或其他造型。字形与编排共同表达语气，文字的大小、方向和空间归属与主体形成联系。

主读、数字、身份标签和必要正文分别形成适合职责的字形、尺度与承载关系，同类职责跨场延续。主读可以大胆并占大面积，标签保持清楚归属，普通字幕完成稳定阅读。强调转移后，已读文字恢复适合其地位的视觉重量。

关键判断处的重点花字，按前文“文字和资料与主体共场”完成。使用本片准确短语，结合参考安排造型、构图和运动。字组可以成为画面的主要内容，也可以与素材共同变化。普通字幕沿全片统一规范呈现。

字太细先核对字体回退、真实字重与面积，字太宽先调整布局、选字款或准确断行。不要横向挤字、用厚影补错误字款，或以 CSS 字重冒充不存在的字体文件。实际绑定和加载沿[组件合同](../../opendesign-video-production/references/hyperframes-contract.md)，指定字体缺失沿[字体与提交操作](../../opendesign-video-production/references/submission-and-recovery.md)；普通设计先用正式可用字款。

### 字幕外观归美术统筹，准确时间归字幕作者

首次将真实字幕放入本片不同背景，确定字体、字号、字重、字色、底板、透明度、圆角、内边距、描边或阴影、位置、行高、行数与框尺寸规则。用实际效果选一套覆盖本片的规范，不逐镜临时换样式。阴影、描边和底板各有作用，不默认全部叠加。

首次决定单行或最多双行等规则，maxLines 是上限，不冒称用户已指定。底板按实际行数向上增高、底部固定，无字幕无底板；不缩放或逐词强调普通字幕。后续明确修订时统一更新全片。

字幕作者负责准确分卡与时序，普通字幕在最终画布独立显示，不参与主画面相机、缩放、旋转、平移或裁切。冲突优先调整主画面；需改语言或分卡时与相应作者协调，不能为塞版面删事实。只承诺实际接口支持的效果，设计为无阴影而仍有黑影须回实现处理，不虚填字段。

## 材质与空间：细节属于对象，而不是通用滤镜

根据主体形态与空间决定边缘、厚薄、表面和光线，并让同类对象沿用可辨认的材料规律。摄影自身的光线纹理可以形成质感；照片、图形、文字及原创形体可以共存，通过一致的附着、承托、排列或空间关系成为整体。造型性格由比例、正负形、轮廓、承载与动作共同形成。

需要体积时兑现光向、厚薄与接触关系。曲面高光随形体，薄片边缘不被渐变画成鼓块；文字、图案、边缘与阴影属于同一物体，随姿态、透视和遮挡变化。接触影按承载面、距离和环境调整，不复制固定黑影；可靠附着不能实现时，由原作者调整形体或观察方式，不让文字永远正对镜头却声称已附着。

用尺度、遮挡、明暗与清晰度建立远近和层级。当前对象取得注意时，相关层依据深度与作用突出、保持或退让。快速变化可以使用运动模糊，阅读与展示阶段恢复可辨状态。平面编排与有体积的空间都须让对象的归属、接触和前后关系清楚。

视频、附着标注与裁切共用正确坐标，固定点只适用于源内相对稳定的目标。全屏转窗口、同源局部、跟踪与持续播放沿[素材坐标与时间](../../opendesign-video-production/references/material-space-and-time.md)落实，不伪称已经跟踪。用户明确不要纯色主背景时落实其要求，原件自身白底不等于必须擦除的缺陷。

## 从美术画面交到连续机制组合

主要行为从观看变化产生，不在固定页面上逐个加入场。决定为什么变、观众跟随什么、读清后注意移向哪里；行为可由源素材、物体、排印、镜头及其协作承担。同一次注意转移中，安排旧参照保持或退出、辅助字让位、新内容取得面积、背景关系延续，不把它们变成互不相关的动作清单。

新旧同时出现时，先安排谁取得注意、谁供比较，再落实路径与时机。载体取得可读空间后再显示需要阅读的内容，避免文字在混叠中抢读；有意使用交叠时以实际观看判断。动作有足够幅度、行程与时间表达所选意图，停顿让关系成立；不以微移敷衍，也不持续扰动已读清内容来维持“有动画”。

沿[机制主方法](../../motion-case-library/references/mechanism-retrieval.md)适配对象、坐标、源时间和阅读连续。各层依照作用响应，源视频保持自己的时钟。OD 首版后视觉作者据实际画面调整设计。

前后画面共同设计注意交接，通过对象、方向、动作、遮挡、空间或视点变化完成连续转换。换观察方式时，先决定观众跟随什么，再安排前场怎样交出注意、后场怎样取得面积和可读状态。视觉重量、尺度、位置与明暗在交接过程中相互配合。

结尾利用已经建立的关系完成最后一次观看。具体动作阶段沿[演出方法](../../motion-brief-writing/references/performance-design.md)设计，真实声音参与时机校准，详细节奏沿[时机方法](../../effect-timing/SKILL.md)处理。

### 补充约束

画面切换按采用参考和当前内容选择。完整实现已采用的主要变化，避免用无关的统一渐显或持续漂浮取代所选过程。

不得先预留固定标题区、素材区和说明区再逐项填空，不给所有短语复制同一种文字包装。平面图形不强加假体积，不用整图模糊冒充景深；纹理、网格、粒子与光影须服务当前对象或环境。

禁止在视频画面中展示解释素材来源、案例属性、示意身份、制作方法或检索过程的说明文字，后期新增、素材自带和参考中此类小字一并处理。视觉负责人将具体处理安排交给 OD，并检查实际作品。普通字幕、重点花字、图表必要文字、内容标签和事实条件按准确内容呈现。具体处理沿[画面文字与素材说明的处理](../SKILL.md#画面文字与素材说明的处理)执行。

## 预览与返修

用实际观看尺寸查看 OD 同版整幅作品和必要前后语境。静帧、连续运动和声音按各自真实观察范围记录。检查最终合成时再观察素材、字体、字幕与声音怎样共同表现。

| 实际问题 | 返回哪项创作工作 |
|---|---|
| 只有花字变化，主体与空间没有承担本段表达 | 重新选择整场构思、材料用法与主要行为，不给现有字继续加效果 |
| 主体被说明挤小或多个对象无序争抢 | 重新分配视觉重量、对应关系、面积与阅读顺序，允许保留有组织的丰富内容 |
| 色彩脏、表面粘连或质感像通用滤镜 | 调整明暗、边缘、材料与承载关系，再确认颜色和细节 |
| 中文细糊、拥挤或花字与主体脱节 | 核对真实字款、字组轮廓与阅读尺度，重新设计文字的作用与归属 |
| 两端成立，中途挤乱或动作像没发生 | 改接管时刻、显露顺序、行程与层次，不把整段统一放慢 |
| 场面反复同构、接续生硬 | 回到相邻范围统筹观看方式、空间与注意交接，不只换色或套转场 |
| 材料不支持所需行为 | 调整真实源范围、补材或与导演改表达，不让动画伪造事实 |
| 具体设计被字体、裁切、父变换或时钟破坏 | 修实现与绑定，保留成立的选择，不反向迎合错误默认值 |

只处理实际问题，不要求逐项填表。原作者接回具体范围与观察，返回真实画面变化；主要内容或跨段含义改变与导演协调。允许改构图、背景、字形和主要动作，保护事实、用户锁定项及无关的成立部分，不用“已采用”挡住重选。当前稿与源码同步，历史修订留在已有记录。

按交付画幅组织主体、路径、中文和负空间，多画幅分别检查。开工前交导演稿中的素材范围、字体、颜色用途、字幕规则及接点。OD 交件后交同版源码引用、实际观察和待核范围。正式操作沿[共享交接](../../_shared/PROJECT_REVISION_AND_HANDOFF.md)和[场面操作](../../scene-planning/references/scene-operations.md)。

# OpenDesign 创意与视觉制作指令

## 一、任务定位

你是负责交接的视觉作者。把已经有依据的研究和你完成的视觉设计整理成 OD 拿到即可制作的指令。目标是让 OD 知道要用哪段真实素材、让它怎样演、怎样接下一段。

你不是重新研究参考，不是从文案和素材重新猜测场面，也不是把视觉方案压缩成一组技术参数。

正式制作输入有三个层次：

1. **创意参考研究：** 原片为什么值得借鉴，完整画面如何组织，哪些关系构成创意核心。
2. **本片创意迁移：** 参考对象的视觉作用如何对应本片真实素材和准确文案，哪些关系保留、改造或放弃。
3. **视觉作者完整设计：** 本片最终使用什么素材、怎样构图、文字和背景如何参与、镜头和运动怎样发展、画面最终形成什么结果。

视觉作者决定影响表现的构图、取景、字组、主要方向、路径关键点、动作依赖、关键停顿、视觉重音和接续。制作作者在既定关系内深化实现参数、曲线、具体帧、局部交叠、收势、源码结构和性能。

## 二、职责边界

- 创意作者负责参考研究、创意核心、采用判断和迁移复核。
- 视觉作者负责场面设计、整片视觉导演稿、时间计划、OD 专业对接和首版后的视觉返修。
- OpenDesign 负责实现和深化，不得静默改变主要视觉关系。
- 主导演负责准确内容、事实边界、用户锁定项和跨段关系。
- 主任务负责项目、Revision、Run、冻结版本、资源和正式采用。

不得把创意研究和视觉设计重新推回 OD；也不得因实现方便改变已经确定的主要创意。

## 三、正式制作前读取完整输入

### 3.1 内容与声音

读取当前准确文案、用户锁定内容、场面表达目标、前后场面关系、配音、SpeechTiming、画幅和输出要求。

### 3.2 创意参考

每项正式采用参考需要：
- 创意卡 ID。
- 来源指纹。
- 原始视频路径。
- 采用的完整源时间范围。
- 对应分镜。
- 创意卡正文。
- 实际观察范围和方式。
- 创意作者提炼的完整视觉关系。
- 本片采用、改造和不采用的内容。

对正式采用的库内参考，沿现有创意或动效交付入口随包提供真实视频。把研究决定、原片区间、目标素材、成片帧段与要保留的关系对应起来。发送前核对 OD 能读取简报点名的视频。仅供研究的分镜保留为学习资料。

### 3.3 动效机制

每项采用机制需要：
- 机制 ID 和来源指纹。
- 原始机制视频及实际范围。
- 开始状态、结束状态。
- 运动对象和保持对象。
- 发起者、响应者、接手者。
- 并行、交叠和先后依赖。
- 本片对应对象及作用。

### 3.4 本片真实素材

每项素材需要 Asset ID、实际文件、原始来源、文件哈希、可用源范围、帧率、真实主体和可观察行为、视觉角色及已知画质限制。

### 3.5 视觉导演稿与原片、素材、本片的时间

读取当前正式视觉稿全文。点名本次要制作的场面、真实素材角色、空间层次、重点文字、主要镜头、动作依赖、关键中途、入场和退出。参考用原片时间，素材用已取得文件的源毫秒，本片用真实旁白或项目时间。

只有语义段时间时，填写段界和视觉作者确定的动作先后、变化触发、读清条件、视觉重音与接续。词级卡点仅在取得可靠对齐或实际声音核查依据时填写，其余情况使用已知段界。OpenDesign Cloud 在这些关系内调整具体帧、局部交叠和曲线。涉及用户锁定的卡点须有相应依据。

对每项引用写明原片中看清的关系、本片要保留的关系、本片另行创作的部分。首版交件前用导演稿、时间计划和真实媒体说明设计。返修简报另引用已有作品、冻结版本和问题区间。

对每个主要连续场面，结合参考和本片素材，直接写出以下内容，并组织成连续演出正文。

1. 开始时的主要画面，以及主体、文字和背景的位置、比例、层次。
2. 准确的重点文字、字组形状、断行、大小关系及其与主体的空间关系。
3. 谁发起主要变化，哪些对象同时响应，哪些对象保持。
4. 关键中途形成什么构图，前一状态怎样发展成后一状态。
5. 结果何时完整成立，哪些内容需要共同保留供阅读。
6. 退出时谁让出空间，谁接管，源视频和下一场如何连续。

采用成熟案例时，先把案例中共同形成效果的完整关系换入本片素材和准确文字，再处理明确不适用的部分。将保留和调整后的具体做法写入当前稿。

字号、面积、方向、遮挡或时序决定效果时，由视觉作者作出明确选择。制作端深化既定关系内的具体参数、曲线、局部交叠和实现方式。

交件前，视觉作者逐段检查制作端是否还需要自行决定主要画面。影响最终效果的设计空白由视觉作者补齐。

## 四、参考和素材核对

### 4.1 参考核对

核对参考 ID、来源指纹、原片路径、采用范围、分镜和实际媒体。创意卡用于理解，原片用于核实。不能用标题、摘要、缩略图或稀疏抽帧冒充连续观看。

### 4.2 机制核对

查看机制原片及必要上下文，确认实际运动对象、保持关系、同时变化、先后依赖、结束状态和接续条件。机制摘要不能代替实际动作依据。

### 4.3 本片素材核对

打开本片主题相关素材，挑选能承担所选画面表现的主体、动作和细节，核对可用源范围、取景方向、遮挡和裁切。素材可以跨越多句旁白。用户明确要求展示具体事件、人物或证据时，针对该处核对对应关系。素材无法完成已定动作时反馈视觉作者。

## 五、把研究结果转化为 OD 制作任务

### 5.1 说明采用参考的原因

每个完整参考说明：
- 原片核心创意。
- 最有价值的完整画面关系。
- 它解决的观看问题。
- 本片对应的内容。
- 为什么适合本片的素材与表达。

不能只写参考 ID 或“借鉴高级感”。

### 5.2 明确参考对象与本片角色映射

必须写明原参考对象、原参考作用、本片对应的真实素材或文字，以及它在本片中的实际作用。

例如，多张活动画面可以映射为不同真实工厂场景；前景字带可以映射为本片重点短语。但必须进一步说明这些素材为何同时出现、各自承担什么作用、怎样形成主次和整体构图。

### 5.3 交付原片观察、内容替换和实现边界

完整解说新片按时间计划逐主要视觉单元写入首版正文。每单元写清主参考、原片和本片范围、复摆、实拍源段、准确字组、图层动作和接点。机制作主参考时，把它的建立、关键中途、落点和接手写进实际步骤。辅助机制写到它负责的动作上。沿同一份导演稿交回须保持的表现和可深化的实现范围。

将完整请求写进同一份导演稿的 `## 发给 OD 的完整请求` 章节。先写适用于所有场面的共用美术、整片时钟和接续约定，再按播放顺序以 `### 场面 <实际SceneID>` 起各场正文，标题只填写实际场面 ID。每场正文只要求执行本场，所需前后场信息写成接点。按主要变化点写原片时刻、本片时刻、素材源段、准确字组、分层动作及接点。随场交付可打开的原片、采用区间、关键帧、视觉作者确认的复摆和具体替换清单。全片美术主参考在交付的顶层创意参考中标记采用。程序按目标场面从冻结稿取共用要求及该场原文，同时取该场制作资料。

`referenceMappings.preserveRelation` 摘录对原片实际画面的观察，包括构图、美术、排印、图层和动作。`visualPlan.sequence` 写替换后的本片素材、准确文字、时序和相同画面关系怎样实现。`odBoundaries.locked` 记录首版须保持的构图、色彩、排印、遮挡、运动与接续，以及已经确认的适配结果。`adjustable` 写明已经确认的调整边界，由 OD 在这个范围内选定实现参数。

OD 按同一组原片时刻与视觉作者确认的本片构图制作首版。遇到素材、字体、遮罩或时序限制，指出原片位置、受影响的画面和可执行的适配，交视觉作者处理。首个阶段件优先覆盖复现风险最高的主要场面，从建立、关键中途到接续完整交付，并标明可对照的原片时刻。

### 5.4 明确机制的实际作用

每个机制说明：
- 对应本片哪个对象。
- 解决什么具体运动问题。
- 与完整画面创意有什么关系。
- 哪些运动关系必须保留。
- 哪些形式可以改造。
- 结束后留下什么状态供后续过程使用。

机制编号不能代替执行描述。

## 六、每个场面的完整制作指令

按本片实际播放顺序组织。每个主要场面必须形成完整、连续、可想象的画面设计。

### 6.1 场面表达与创意意图

说明准确表达、主要视觉创意、观众首先看什么、采用参考的原因，以及创意卡和机制卡各自承担什么作用。

### 6.2 主要视觉对象

明确主要主体、辅助素材、文字、图形、背景、空间、画框和局部窗口。说明身份、来源和视觉作用。

多素材画面逐窗写明采用文件、源段和正式画幅下可辨认的主体或动作。把有意持续的镜头和新内容接管的时刻写进画面发展，保留窗内外同一对象的连续播放。制作时发现两个独立角色只能绑定同一镜头，或实际裁切后看不出两窗的区别，指出对应步骤和画面位置交原视觉作者确认补材。首版回看共存和接管时刻，核对实际绑定、入退场和可见差异。

### 6.3 完整构图

说明主体大小和位置、多素材空间关系、视觉重心、观察距离、文字与主体关系、前中后景层次，以及最终形成的整体构图。

不要只写“左侧视频、右侧标题”。要说明为什么这样组织，以及它解决什么观看问题。

### 6.4 完整画面发展

按实际观看顺序说明：
- 初始画面。
- 主体如何建立。
- 辅助素材如何进入。
- 文字和图形如何参与。
- 背景和空间如何变化。
- 主体和其他对象如何运动。
- 注意力如何转移。
- 关键中途形成什么画面。
- 最终状态。
- 怎样接入下一场。

这是主要制作指令，不能只给布局参数或动作名称。

### 6.5 对象关系和动作依赖

明确谁发起、谁保持、谁响应、谁接手；哪些动作并行，哪些存在先后依赖；哪些对象必须持续存在；哪些对象独立运动；结束后留下什么状态。

不能把共同构成一个视觉事件的动作排成互不关联的动画队列。

### 6.6 镜头和观察位置

区分源视频内部运动、视频容器在编辑空间中的运动，以及观察距离和镜头运动。

每次观察变化都说明带来什么新信息。不能把所有窗口缩放都称为运镜，也不能为了动感统一缩放整幅画面。

### 6.7 文字演出

使用准确本片文字。说明文字表达什么、为什么出现、与哪个主体共同构图、是否遮挡、是否独立运动、何时取得注意、何时读清、何时退出。

不能把所有文字退化为左上角标题加小字说明。普通字幕继续使用现有字幕系统，不复制一套字幕。

### 6.8 背景和美术

说明背景承担什么作用、主体与背景的空间关系、颜色和材质如何形成主次、边界怎样参与构图、视觉语言怎样保持统一，以及哪些真实素材细节必须保留。

不要默认使用纯色背景、通用渐变或固定卡片填满所有场面。

### 6.9 运动与节奏

视觉作者决定影响表现的构图、取景、字组、主要方向、路径关键点、动作依赖、关键停顿、视觉重音和接续。制作作者在既定关系内深化实现参数、曲线、具体帧、局部交叠、收势、源码结构和性能。真实配音和 SpeechTiming 到达后按实际声音校准。

对需要跟随画面的音效，在对应演出步骤写明声音意图、动作名称、预计本片范围、应对齐的起点或落点和相对先后。制作作者按已采用的画面演出实现动作，从实际时间线交回约定的事件。实现改变事件时刻时，在回件中标明变化。音效与旁白由 VideoFlowCut 在外层混合，回件提供可用于对齐的实际动作事件。

### 6.10 场面出口

说明主体最终状态、保留对象、退出对象、下一场进入内容，以及是否直接切换、交叠接管或连续动作。不能默认每个 Scene 结束就清屏切走。

## 七、实现边界

### 7.1 必须保持

- 真实主体身份和素材来源。
- 导演稿已采用的逐场构图、美术、排印、层级、运动和接续，以及已确认的内容替换与美术适配。逐场写清本片素材、持续对象、关键换手及出口，并附原片范围和本片目标帧。
- 本片主要主体与素材主次。
- 完整场面发展。
- 关键视觉重音。
- 重要场间接续。
- 用户锁定内容和事实边界。

### 7.2 可以深化

- 已确定字体、排版、材质和构图内的具体实现参数。
- 已确定镜头关系和路径关键点内的运动曲线及速度参数。
- 局部交叠、惯性和收势。
- 在已定主体占幅、图层次序、遮挡方向和关键可见部位内，微调裁切边缘、遮罩边界及实现参数。
- 已确定时序关系内的具体帧、源码结构和性能。

### 7.3 需要反馈，不得静默改变

当素材不支持、参考关系无法实现、主要构图冲突、需要更换主体或改变主要镜头语言时，向视觉作者说明原设计、实际问题、受影响对象和范围、原因及替代方案。由视觉作者决定是否调整；涉及事实和跨段关系时交主导演协调。

## 八、按确认字组制作画内文字

首版新增的画内文字以冻结请求中视觉作者确认的逐场原文为准，按指定帧段、层级和运动制作。普通字幕采用指定的已确认字幕稿。参考来源、素材出处、资料库编号、源时间、实现限制和制作备注保存在制作资料中。

画面任何位置均执行全片文字禁用规则。原片复摆中已经移除的文字层，按视觉稿中的留白和构图制作。素材自带说明按简报指定的源段和方式处理。制作中如需新增、改写或保留未确认的字组，先把实际文字、受影响画面和原因交视觉作者确认，更新当前制作稿后执行。

## 九、首版制作与阶段交件

新片交付完整导演稿、时间计划、参考与真实素材，由 OpenDesign Cloud 制作可检查的正式首版。视觉作者确定优先交回的连续范围及接点，并持续接回实际作品。完整制作目标和其他待交范围保留在同一委托中。首个真实 Work 与冻结版本随 OD 阶段回执取得。续作或局部返修从原作品取回身份、源码和范围。

阶段作品返回后，主任务将工作台入口、Project、Revision、MotionWork、目标范围和成片范围交回原负责人。原导演、创意和视觉作者按职责在工作台观察同版实际合成。

日常观察使用工作台范围播放和循环播放。已有控件支持的修改在工作台保存；作品内部画面由原视觉和制作作者沿同一作品修订。新版接回后在工作台复查修改范围和前后连接，并记录实际观察和问题处理结果。

**不得将生成文件后抽帧作为常规工作台预览方式。不得修改当前工作台预览、修改、保存和复查链路。**

## 十、返修

- 参考理解问题：创意作者复核原片。
- 创意迁移问题：创意与视觉共同重新构思。
- 整幅画面问题：视觉作者调整。
- 素材事实问题：素材作者和主导演核实。
- 制作实现问题：原制作作者修复。
- 技术合同问题：沿现有技术与交付流程处理。

返修必须说明具体范围、实际问题、需要恢复的关系和复查方法。不得只说“更高级”“更有设计感”“增加动效”。

## 视觉方案的正式交接与返修责任

本简报承接视觉作者与创意作者共同形成的当前导演稿。权威正文、时间计划与逐项资料一并交到 OD 项目。制作指令可从正文准确引用，无须再造一份平行分镜。

### 一、交接责任

- 视觉作者向 OD 解释本片视觉方案、素材与参考映射、主要构图、镜头、运动和可深化范围，并跟进首版反馈。
- 创意作者负责原始参考理解和创意迁移复核；发现偏差时向视觉作者提供原片对应过程、当前作品差异和需要保留的核心关系。
- 主导演负责整片内容、事实、主线、跨场关系和重大导演决策，持续协调返修，但不代替视觉作者逐项提出视觉参数。
- OD 负责已采用方案的制作实现、内部深化和实现偏差修复。
- 主任务负责正式提交、反馈投递、Job/Run/Revision/Frozen Version 对账和结果接回。

### 二、正式交接必须包含

- 主导演当前有效的内容、事实和用户锁定决定。
- 已研究并被导演方案采用的参考原片、准确源区间及研究决定，供学习的候选另标 `study`。
- 每条参考保留的关系、本片真实素材角色、原片区间和场面内的项目时间线半开目标帧范围，以及不确定或需要另行设计的细节。整场采用也要写明整场范围。
- 视觉导演稿、当次制作范围、项目时钟和前后接点。已有作品的修订另交原 OD 项目、发布 Run、固定版本和受影响的根帧。
- 本片真实素材、Asset ID、来源和准确源范围。
- 参考对象与本片视觉角色映射。
- 整片美术、构图、空间、排印和镜头方向。
- 场面完整发展、关键中途、运动依赖和场间接续。
- 动效机制的实际作用和必须保留的关系。
- OD 可以深化的实现细节。
- 不得静默改变的主要视觉关系。
- 未解决的素材、参考或技术问题。

### 三、制作返回后的反馈

OD 返回同版作品后，主任务将工作台入口、Project Revision、MotionWork、Run、Frozen Version 和实际范围交回原视觉作者，并同步主导演和创意作者。

视觉作者负责打开实际作品、检查视觉兑现并向 OD 提出具体修改要求。反馈必须指出实际范围、当前画面、预期视觉关系、缺失或变弱的表现、需要保持的内容和复查范围。

创意作者对照原始参考检查创意迁移；发现核心关系缺失或被错误改造时，将原片对应过程和当前作品差异交给视觉作者，与视觉作者共同确认修改方向。

主导演检查内容、事实、主线和跨场关系，决定是否需要改变整片方向或重新采用。主任务负责正式反馈投递和版本对账。OD 按视觉作者确认的要求修复实现问题，并返回同一作品的新版本。

不得把视觉反馈全部转交主导演；不得让 OD 自行改变主要创意；不得创建平行作品替代原作品。

原片运动已明确时，直接写出制作方式。需要查证或尚不知道如何完成具体动作时，先定位原片时刻和实现缺口，再按[动效机制库](../motion-case-library/SKILL.md)检索。采用的机制写入它实际解决的步骤，保持原片的构图、前后层次和动作结果。

完成逐场换料复摆后，按[美术方法](references/art-direction.md)，用选定的全片美术主参考校准相邻场面。每项调整写入现有适配清单，并在同一份视觉导演稿中保留调整前后的对应画面。

写给 OD 的正文按播放顺序交付整段。每个主要变化点都包括原片时间、本片时刻和源段、关键构图、替换文字、动作过程和接点。交稿前对照原片核对制作要求，记录待处理的素材或实现问题。正式交付时，在场面的 `visualPlan.researchLayers` 中关联实际采用的研究决定，并用 `designExcerpt` 摘录导演稿中相应的实际设计。

#### 3. 建立本片实际素材映射

打开本片主题相关的素材，挑选值得观看的动作、细节和空间，确认可用源时间、主体位置、景别和画面质量，以决定怎样取景、运动和接续。素材可以跨越多句旁白。

将参考中的视觉角色逐项映射到本片：

- 主要主体使用什么真实素材。
- 辅助画面使用什么素材。
- 哪些素材需要同时出现。
- 哪些素材需要先后接力。
- 哪些画面承担比较、背景或环境作用。
- 哪些准确文字需要进入画面。
- 哪些画内文字、图形与素材共同承担表现。

映射时优先考虑素材实际能够提供的画面，而不是先写出理想动画再要求素材适应。

某份素材只存在一个短暂瞬间时，不得将其描述成具有持续动作的素材。

#### 4. 素材驱动整幅画面设计

完整解释视频必须优先以真实素材形成主要观看内容。视觉设计遵循以下优先级：

1. 先研究真实素材本身有什么值得观看的动作、构图和场景。
2. 再研究多条真实素材怎样通过镜头、画面接管、并列、叠放、交叉和连续运动形成完整演出。
3. 创意参考用来改变素材的组织方式和画面发展。
4. 动效机制用来实现这些画面关系。
5. 原参考中与素材共同表现的图形，按所选演法设计；其他图形按本片画面需要补充。

这不是固定串行工作流程。素材、创意和视觉研究可以并行；最终画面判断必须遵循上述优先级。

不得因为内容涉及数据、概率、机制、流程或不可见过程，就默认由原创图形主导。不得先完成解释型动画，再将真实素材作为背景、装饰或短暂插入。

优先研究真实素材本身的动作、细节、空间和不同源范围，再判断多素材是否可以共同承担表达。素材不必拍到文案中的每个动作；可以通过重新取景、裁切、局部放大、素材组合、镜头变化、画面接管、文字协作和辅助图形完成表达。

只有真实素材及其组合确实无法承担必要表达时，才允许原创图形承担主要表达。必须说明：
- 需要表达的具体信息。
- 真实素材及其组合为什么无法承担。
- 是否尝试过多素材组织、重新取景或画面关系变化。
- 图形与真实素材如何共同构图。
- 图形是否会取代原本应该持续观看的真实素材。

不得用固定素材占比、固定镜头数量或固定动画比例代替视觉判断。

#### 5. 写出完整连续的画面编排

按照实际观看顺序描述场面。

对每个主要视觉过程说明：

1. 开始画面及主要视觉中心。
2. 出现的真实素材和重点文字。
3. 素材的具体位置、比例和空间关系。
4. 接下来发生的变化。
5. 素材与文字如何共同运动。
6. 哪些动作同时发生，哪些动作依次发生。
7. 镜头如何参与画面变化。
8. 画面如何形成新的构图。
9. 最终视觉结果。
10. 与前后场面的连接。

具体描述决定画面是否成立的主要运动、方向、幅度、节奏和接点。

不要求固定帧表，不提前锁死所有技术参数。

视觉作者确定整幅画面的主要创意、素材角色、关键状态、时序关系和场面发展，OpenDesign Cloud 在这些关系内深化具体帧、曲线及实现方式。

逐场复摆时，把创意交稿采用的音效和留白排回本片对应动作。在同一个编排步骤写明原片时间、本片动作、预计帧段，以及音效起势、重音和尾音分别跟随哪个画面时刻。画面换料、缩短或延长时，沿本片动作调整声画落点，保留原片的先后、交叠和接续。

与声音作者核对原片声音和本片旁白。需要微调时，明确改动发生在哪个动作、涉及响度、起势、重音偏移还是尾音，以及调整的原因。提交 OD 前，标明哪些动作要由制作回件提供事件。收回首版后，用同版画面的实际动作帧复核映射，并把变动交声音作者。

#### 6. 对照参考检查本片编排

在送 OD 前，将原片关键帧和换料复摆并排检查。从入口到出口依次确认主体占幅、取景、文字轮廓、色彩分布、前后遮挡及空间主次，再按原片确认动作次序、关键交叠、停留和切换。逐项核对两边的差异是否已经写入替换与适配清单。素材或中文已换进去而画面结构走样时，视觉作者先修正本片编排。必须改变所选段的主要画面结构时，交原创意作者重新确认采用范围。

再把换料复摆和统一后的画面按同一时刻并排，逐项核对明暗、色彩与跨场接续。统一后的画面须继续保有该场的完整构图、花字形态、图层和连续演出。哪项美术调整使原段观感走样，就撤回该项，回到已经成立的换料复摆。

#### 7. 素材缺口与创意缺口处理

发现素材不足时，明确告诉主任务和素材作者：
### 画内文字的设计与确认

视觉作者负责检查成片中所有可辨认的文字，包括新增文字、参考片要替换的字层、实拍和生成素材自带文字，以及实际合成中的普通字幕。按本片内容决定标题、重点花字、数据、图表读数和内容标签怎样与主体、构图及运动共同呈现。普通字幕按现有流程转写和对点，视觉导演稿引用已确认的字幕稿。

#### 全片禁用素材与制作说明

「示例」「说明」「来源」「示意」等字样禁止出现在任何画面中。凡用途是交代素材身份、出处、呈现方式、检索或制作过程的字层，一律从画面移除，包括换词后作用相同的标签。出处、引用和制作备注保存在制作资料里。

复摆原片时，逐层判断文字承载的正片内容。纯装饰或补版的小字直接移除，重新收好留白、背景和图层关系。保留承担正片内容的排印造型和连续演出。素材已带入禁用文字时，检查实际使用的全部源段，采取换用干净源段、重新取景、裁切或遮挡。处理影响主体动作或主要构图时，更换同用途素材。

#### 逐场确认上屏原文

在同一份视觉导演稿的逐场编排中，写出新增画内文字的准确原文、出现和退出范围、所在层及内容作用。需要保留的素材内嵌文字写明可见内容和使用范围，需要移除的写明具体源段和处理方式。每场把这些决定与实际复摆逐项对照，再将确认后的内容写进「发给 OD 的完整请求」。

作品返回后，按已确认的字组、素材处理和实际字幕逐场核对。发现禁用字样、额外标签或素材文字露出时，记录实际字样、所在图层和帧段，交对应作者修订，再看同一段实际画面确认。

import childProcess from "node:child_process";

// 仅由后台渲染入口加载。Windows 不会把父进程的隐藏设置传给子进程，
// 因此 Remotion 等依赖的直接 spawn 也必须覆盖；不改变管道、信号和退出行为。
if (platform() === "win32") {
  for (const name of ["spawn", "spawnSync"]) {
    const original = childProcess[name];
    childProcess[name] = function (command, args, options) {
      if (Array.isArray(args) || args == null) {
        return original.call(this, command, args ?? [], { ...options, windowsHide: true });
      }
      if (typeof args === "object") return original.call(this, command, { ...args, windowsHide: true });
      return original.call(this, command, args, options);
    };
  }
  // 同时更新 ESM 命名导出，保证 CommonJS 与 ESM 依赖使用同一启动策略。
  syncBuiltinESMExports();
}
