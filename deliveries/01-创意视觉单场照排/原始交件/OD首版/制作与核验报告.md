## 实现与限制

- 保留稿中白字上段、黄绿下段、冷暖曝光差异、三套满幅次序、短留剪影、九源和尾窗主体。暖边、网点和像素装饰为可编辑代码重绘，不宣称与原片像素级一致。
- 源 WAV 未重配、未变速、未自动增益；响度较低是测得事实，未擅自响度标准化。
- 桌面服务生成入口因桌面应用未运行而失败；最终使用本机已安装固定版本 HyperFrames CLI 完成渲染，实际成片和日志均在本独立项目内，不把失败的托管任务称为成功。
- 视频源声音全部静音，只封装锁定旁白。字幕是独立源层/SRT，但此 MP4 画面里可见的字幕已随画面合成，不包含可切换软字幕流。
- 不对原 VFC 项目执行启动、导入、修改、版本提交或回写；参考和原素材仅供读取。

## 复现

在本机以 Node 运行 tools/reproduce.mjs：复用随包本地素材重新渲染、封装并执行技术核验。需要重新从只读原件派生素材时加 --prepare；此操作只写当前交付目录。依赖本机现有 Node、固定 HyperFrames 安装、FFmpeg 和仓库 background-processes.mjs。脚本通过该隐藏窗口工具启动子进程。

直接打开 MP4 可播放成片。HTML 为可编辑画面源码，须通过本地 HTTP 服务打开；tools/review-server.mjs 提供当前项目的只读本地服务。源层、GSAP、素材、字体、字幕和绑定均随包，不需要联网拉取图像。
