# 受管动画字体

字体为Runtime的只读发行资源。生成动画时不联网下载、不读取系统字体目录、不接受用户路径或字体URL。新增字体需更新目录、文件校验值及发行版本，完成候选验证后部署。

字体来自notofonts/noto-cjk的固定提交`f8d157532fbfaeda587e826d4cd5b21a49186f7c`：Noto Sans SC常规400与粗体700；0.1.62补充Noto Serif SC中粗600与重字重900，用于中文宋／显示衬线候选。原始文件来源记录在`catalog.json`，Sans与Serif许可证分别保存在`OFL.txt`、`OFL-Serif.txt`，字体不做修改或子集化。该版本覆盖简体中文、拉丁文字与常用标点；特定生僻字、其他语种或符号仍须检查字形覆盖，不能把文件加载成功当成所有文字均有字形。

衬线ID为`noto-serif-sc-semibold`与`noto-serif-sc-black`。600、900对应两份实际字体文件，不是给400字体设置CSS假粗体。目录提供候选字款，不声称与未知参考同款，也不保证自然字幅满足具体作品的窄高目标；作者须用实际文字核对字形、墨迹尺寸、纸条字号和镜内放大。不能只因“非同款”停止其它制作，接近字款按采用稿记录实际替代及待复核范围。

字体ID对应一个实际字重。作者使用查询返回的ID建立`fontBindings`，并使用`props.fonts[槽位]`提供的`family`、`weight`、`style`。同一字体多个槽位共享内嵌文件及作品副本。任务固定文件SHA-256，首次组件挂载前明确加载，失败不替换绑定字体。动画位置及运动仍由作品局部帧计算。

本接口仅适用于受管动画，不改变普通字幕的字体合同。未绑定字体的历史作品仍按原有字体栈读取；历史引擎Job重新生成需按当前合同提交新版本。

0.1.63按用户截图中的名称扩充得意黑与猫啃网烟波宋：得意黑使用官方2.0.1的原生窄斜OTF，实际字重400、style为italic；烟波宋使用猫啃网官方1.10原包的E/L/R/M/S/B/H七份TTF，实际字重依次200/300/200/500/600/700/900。R虽然名称为常规，原件OS/2元数据仍为200；平台忠实使用原件，不伪造400。烟波宋明确采用猫啃网开放版本，不冒称为字魂的同名字款。全部原件未经修改或子集化，许可证为OFL-1.1，分别随OFL-SmileySans.txt、OFL-YanBoSong.txt及原始版权NOTICE发行，身份进入Release ID。

0.1.63目录共4个字族、12份实际字体文件；字体和动作不绑定，没有花字或字幕模板目录。加载支持OTF/CFF与TTF/TrueType，后缀必须匹配文件头，单文件最多32MiB；作品副本按真实格式保存并校验哈希。该批原件增加约177MiB发行体积。指定字号、描边、颜色、遮挡与帧驱动动效仍由每次作品源码决定。

0.1.64按用户确认接入E:/字体中的全部22份字体文件，合计新增94373456字节，约90MiB；目录现在共34份实际文件。仅有图片的云峰静龙行书暂不登记。原件来自用户本地目录，用户明确确认已授权，catalog.json记录本地原件URI与用户授权前提，NOTICE-UserFonts.txt保存内部名称、版权等原文；不将它们统一宣称为OFL。发行只更改外部文件名，字体字节和内部元数据不改、不转格式、不子集化。

新增字款为Aa剑豪体、Aa厚底黑、Leefont蒙黑体、Muyao-Softbrush、PF频凡胡涂体、WD-XL滑油字四个地区版本、三极力量体简-粗、三极泼墨体、云峰飞云体、仓耳与墨四份、仓耳舒圆体五份、仓耳非白一份。Leefont原件字重900，其余新增原件均为400 normal；仓耳各份轮廓已有不同粗细，不能因OS/2同为400而合并。实际字形覆盖不同，Muyao与云峰飞云原件缺少示例中间点“·”，实际文案仍须检查，不能用字体回退掩盖缺字。本次不扩展普通字幕轨字体合同，不引入字幕或花字模板。
