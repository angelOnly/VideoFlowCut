# 空格组逐项补标记，旧字划去后圆弧与数值接替

## 运动指令

先建立空格组，再逐项补入标记，按行累积。格组完整后用短线划过原字，新圆弧和数值在旁侧接入，下方字组随后补齐，旧格组仍保留。
