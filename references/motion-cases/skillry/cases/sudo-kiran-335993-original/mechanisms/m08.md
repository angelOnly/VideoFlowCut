# 稳定主字下短行逐字建立，划去原行后新行接续

## 运动指令

保持主字，在其下逐字建立短行，原行完整后画线划过。下方接入新行，附属片和底条最后补齐，短促散片经过后退出，结尾组稳定。

## 组合与调整

保持旧行可追踪，不直接切掉它；附属项按新片需求调整。
