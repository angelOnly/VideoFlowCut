# 平面推近转角后退出，大字接管，外围散片延续

## 运动指令

向完整平面推近并改变观察角度，平面经过后退出，中央大字接管。外围小片继续经过，让前后两组共享持续运动，主字落稳后保持。

## 组合与调整

大字的出现要接在平面退出空间中，外围运动不能盖住主要接点。
