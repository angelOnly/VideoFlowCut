# 103 江面晚霞到楼阁月夜的景观演出

## 适用场景

展示城市或文化空间的时间与情绪变化，在镜头稳定后释放一个灯光重点。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：影像展示、空间导览、品牌展示

- 段落场景：前后变化、重点强调、空间关系

- 原片实见素材：三维、文字、抽象图形

- 动效方法：找到主体后稳定镜头、逐层亮灯引导焦点、同空间光色改变情绪

- 美术特点：冷夜与暖建筑、水面反射连空间、贴边竖诗留中央观景

- 材料要求：需准确地标与文案；真实城市版本需来源明确、构图对应的不同时间影像。

- 迁移代价：程序化景观不能当当地实拍或天文证据，真实昼夜剪辑须保事实边界；原速与声音未认证。

## 推荐观看片段

- 17.00—22.00 秒：楼阁进入并在中央稳定，灯从下层逐次向上亮起，暖倒影随之建立，同构图内改变状态。

## 动效与美术拆解

短片围绕江面与楼阁从晚霞走向月夜。开头城市天际线和太阳，竖排诗句在两侧依次出现；镜头沿水面转视，天空由橙粉转紫，楼阁进入视野并逐层亮灯，月亮在旁侧升起，河灯出现，最后以诗句和印章收束。观看任务是通过景色变化感受诗的空间与时间，不需要大量对象形变。原帖称全部程序生成，本轮资料说明与原片观察分开，画面不作为南昌实景拍摄或天文轨迹证据。

17—22秒密集序列具体显示注意交接：先是偏紫天空、低矮岸线和水纹，约18.1秒楼阁从右边进入，月亮紧随其旁；镜头继续转向，使楼阁接近画面中部，19秒后移动减少。20.5秒先点亮底部建筑与两翼，20.9秒第一层主体亮起，21.2—21.8秒亮度向上层传递。水面倒影随灯色形成暖亮范围，与楼阁垂直对应，亮灯过程在同一构图里建立，不靠放大和旋转同时抢眼。它用‘找到主体—稳定—改变光’把场景观察转成内容过程。

大面积天水颜色从暖粉逐渐进入深蓝紫，地平线和暗岸形成清楚边界。楼阁原先暗轮廓在粉紫天中可辨，亮灯后暖金成为新重心；冷环境配暖建筑既建立夜感又保留主体。水纹是横向细密结构，阁层是逐层横线，倒影将两者关联；诗字竖排与横向景观交叉，位置贴边给中央观赏留白。细字颜色随明暗变化由暗转浅，红印作为尾段小面积重音。水面纹理持续活动，但不需要让文字也不停移动。

可迁移到城市、旅行、文化与氛围片：保持同一空间骨架，用时间、光与镜头方向释放新焦点。真实视频可以使用不同时间拍摄的同构图对照，需承认编辑而不能制造连续时空事实。诗句和地标应核对来源，场景美感不等于文化或建筑准确性。程序化云、水和灯适合可控演出，但材质与动作要共同设计，过多亮粒子会毁掉安静观看。片中昼夜压缩是表现手法，本轮未原速听看，不认证水纹自然度或声音与点灯同步。

本轮依据整片约每秒一帧概览，以及17.000—22.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。

## 实现建议（研究后写，未制作验证）

研究者依据原作观察后写，非作者原始输入，未制作、未渲染验证。用于重新设计相同关系，不承诺复刻原片。

制作一段文化景观的时间变化，先建立水面、岸线、天光和明确地平线；镜头缓慢转向一个已在空间里存在的地标，地标接近稳定构图后才逐层亮灯。环境由暖霞转冷夜，建筑暖光和水面倒影同步对应，诗句沿边缘短竖排逐次出现，阅读阶段镜头减速。用小红印收尾，避免散点光和文字同时活动。若用实拍跨时段素材，应说明是编辑压缩，并核对诗与地标。

实施时先完成关键构图，再制作接续，按真实输出核对阅读、遮挡、对象身份和空间方向。使用绝对时间控制并保存可编辑源码；这些是新制作要求，不能当成已取得的原工程。涉及事实、品牌、人物、数字和素材时需使用本片已核实输入。无声首版先看画面，再依据实际音轨安排声音。
