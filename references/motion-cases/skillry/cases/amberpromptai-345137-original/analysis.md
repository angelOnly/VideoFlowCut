# 079｜中秋水墨画卷、团聚与思念

[原作视频](../../cases/amberpromptai-345137-original/media/original.mp4) · [作者公开输入](../../cases/amberpromptai-345137-original/sources/published-prompt.md) · [来源页](https://skillry.dev/ai-videos/opus-5-5/amberpromptai-345137)

这条约47.5秒中秋解释把整幅水墨山水当作持续展开的画卷。开头山轮廓逐渐染墨，远山、云和月加入，左竖排秋分祭月解释古俗；后段房舍与小人物建立，右竖排月满中秋接团聚，末段转到独处人的墨圈和月饼，把文化由远景历史带回现代思念。它不是快速月相科普，画面主要保持同一山水空间再添加局部内容，文字承担相当部分说明。历史说法未在本轮另查文献。

32—37秒密集段，右侧月满中秋和红印先逐渐淡退，屋、山、月和上方枝仍在。33.4秒左右一笔黑墨弧从左侧天空向下展开，到34.7秒闭成圆；与此同时房舍和山水对比下降，圆内灰人物逐渐变清，坐在一条短横线上，边缘小暖点建立。底文案改到如今我们散落在不同城市，圈的黑度显著高于后场，观众从团聚远景转向一个人的处境。圆不是山体物理变形，而是加在原环境上的聚焦容器，后场变淡帮助新问题取得主导。

奶黄纸底与黑灰墨层占绝大多数面积，远山浅青灰、近山深黑通过浓淡而非厚重阴影分层。月亮近白但周围雾青给边界，红印与枝上少量橙红花成为极少的暖色锚点。竖排黑字按左右交替建立，底部横排小句长期留独立区，避免把说明塞进山群。浓墨笔触既画山也画人物圆窗，材质因而连续；末段月饼仍由细墨圆圈和瓣边画出，中心橙花呼应枝色。大量留白让缓慢描画有可读空间，但底句和浅墨小字在小屏可能太弱。

适合传统文化、节日、诗意叙述和从大环境转到个人的段落。迁移到真实影像时，可把素材统一为低饱和并以墨框聚焦局部，保留原环境而降低对比，不需要每段另换背景。代价是这种轻染、淡退和小字需要较长阅读时间，不能与快节奏事实密集新闻直接共用；墨色“好看”也可能造成证据不清。文化资料须另行核查，原速和配音未听，不能认证旁白落在每笔描画上。
