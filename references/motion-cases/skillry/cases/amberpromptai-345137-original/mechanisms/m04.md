# 圆周逐段描出后圈内小形接入

## 运动指令

从圆周一处开始延长弧线，沿边界绕行并逐步闭合成圈。圈闭合时内部小形由弱到清楚接入，圆圈和小形保持共同位置，后层继续经过。完成后两者一起退弱，接下一局部。
