# 主形升入回调，外围圈点接入并在换层时跃起落回

## 运动指令


起始：主形仅上部露出下缘。

1. 主形由下边界升起，压低伸展后恢复。

2. 中心圈向外扩张、侧框与点错开补入，后层从侧方接替时前景位置延续。

3. 主形随后升起倾斜翻转并落回。

上述镜头变化与局部动作按同一条连续过程推进；写明同时发生的步骤在原场面中交叠，不先完成整段运镜再重演局部。
