# 21. 城市影像与旅行数据：动效与美术拆解

[原作](../../cases/priyansh0327-206409-original/media/original.mp4) · [来源](https://skillry.dev/ai-videos/opus-5-5/priyansh0327-206409) · [作者公开输入](../../cases/priyansh0327-206409-original/sources/published-prompt.md)

将中转等待转成可比较的旅行方案，再从候选进入个人资格条件。城市照片只作卡片身份，主要动画发生在比较维度、选择边框和条件逐条揭示，不能把旅游画面当优惠可用证明。

直接观察的重点区间为 8.000—13.000 秒。8秒浅底建立，8.133秒比较标题出现，8.267—8.6秒三张城市卡自不同高度进入，8.667秒对齐。8.8秒第一行时长进入，9.333秒住宿、9.867秒餐食、10.333秒接送、10.867秒市区游逐行出现。11.067秒中间卡绿色边框建立、随后稍放大，11.733—11.933秒整体推进并模糊；12秒转入深底资格卡，12.6秒第一项条件打勾。比较与选中不是同时瞬间出现，观众先看维度再看推荐。

美术的设计解释：浅天蓝背景呼应旅行，白卡、绿色可用标记与黑标题建立明确逻辑。城市图只占上沿小块，大部留给条件；中间选中项通过边框和尺度变化突出而非更换饱和背景。暗色资格段使白字与绿色结果再次集中。

迁移思考：适合方案比较、新闻多个选项与条件解释。迁移须重新确认维度、缺失项和适用规则，不能照搬所有绿勾。多行条件需要按阅读量给时间，短片中只能展示核心条件，完整条款另留来源入口。
