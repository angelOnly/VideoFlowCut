# 圆块群反复分合，收成竖形后拉长

## 运动指令

让中央圆块群从集中状态分成多个小块，再并回较大主形，继续一次分合变化。末尾将块群收成竖向主形，再沿纵向拉长，给下一竖框提供接管方向。
