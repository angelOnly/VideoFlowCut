# 105 小船穿过运河石桥进入三维山湖

## 适用场景

沿明确行进方向通过桥洞、通道或门槛，带观众从狭窄空间进入开阔景观。

- 原片形态：网页交互演示

- 适用视频类型（迁移建议）：空间导览、影像展示

- 段落场景：跨场景接力、空间关系

- 原片实见素材：三维、文字、桌面界面

- 动效方法：前景跟随对象持续、窄入口释放宽景、出口先预告目标环境

- 美术特点：冷水暖石墙、出口明度引导、倒影与尾流连空间

- 材料要求：需保持方向与前景身份的模型路线或真实行进素材，并核实地点与编辑压缩范围。

- 迁移代价：导航录屏有叠化压缩，不能称全片实时连续或当地实景；环绕须按信息价值删减；原速与声音未认证。

## 推荐观看片段

- 4.00—9.00 秒：轻叠化后小船接近石桥，桥洞包围视野，湖山先从出口显出，船与尾流持续完成穿越。

## 动效与美术拆解

作品跟随一条小船从运河进入湖面，沿水面绕看山、城市与灯光。船、红衣人物、后置蓝色动力装置和尾流始终提供前景身份，镜头多在船后上方，环境从狭窄房屋水道转为开阔山湖。顶部轻小地名与状态栏提示路线，主要体验来自空间变化，不是排版或图形形变。原作者说明剪短了导航录屏，所以它有编辑压缩；本轮不能认证全片每处都是不中断的实时旅程。

4—9秒密集图组看到船沿石砌水道前进，4.9—5.1秒有一处轻叠化，把前方通道接到石桥入口；船仍保持画面下部同尺度。之后桥拱从前方扩大，6.7秒视野已被桥顶和两边墙包围，7.3秒山湖先从出口显露，7.6秒船离开桥，整个画面开放。狭窄拱洞暂时遮挡大环境，却持续保留船与尾流，因此能清楚感受‘通过’而不是只看两张风景切换。叠化是路线压缩手段，应与后面实际可见的穿桥过程分开描述。

美术主调为蓝灰水面、暖米石墙、紫粉山峰和傍晚橙天，暖建筑窗与冷反射使城市夜感渐进。水面占大面积，几何平稳的倒影把建筑与山连接为一个空间，船尾流是小面积持续亮线，给前进方向可视证据。进入桥下环境变暗，出口山峰却明亮，天然构成下个焦点；开阔后山和倒影形成上下对称，船位于下部让画面有主体尺度。建筑和山为示意三维，不是已核实当地实景，地名不能把模型自动变为旅游事实。

可迁移到真实行走、车窗、旅行或虚拟空间：保留一个前景跟随对象，用窄到宽的空间门槛释放下一景，出入口方向必须可理解。实拍组合可使用相同运动方向和前景对象，但需要承认剪辑压缩，避免无端地理连续。相机转向应在离开门槛后再进行，否则同时穿越与大旋转容易迷失；水反射和灯是环境层，字幕只需少量。原片后段较多环绕，主题片应挑能揭示新内容的角度，未新增信息就收束，不必把全部好看的风景转完。

本轮依据整片约每秒一帧概览，以及4.000—9.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。

## 实现建议（研究后写，未制作验证）

研究者依据原作观察后写，非作者原始输入，未制作、未渲染验证。用于重新设计相同关系，不承诺复刻原片。

设计一条有前景主体的路线，从狭窄通道到开阔空间。主体在下中部保持尺度和方向，尾流、脚步或道路提供运动参照；入口先露出，推进时环境边缘放大，出口中提前可见下一景。出门后稳定并减速，再选择一次有意义的转向。暖入口与冷远景分配明暗，文字少且贴边。若素材经过跨地点或时段剪辑，保留编辑身份，不冒称实时连续地理旅程。

实施时先完成关键构图，再制作接续，按真实输出核对阅读、遮挡、对象身份和空间方向。使用绝对时间控制并保存可编辑源码；这些是新制作要求，不能当成已取得的原工程。涉及事实、品牌、人物、数字和素材时需使用本片已核实输入。无声首版先看画面，再依据实际音轨安排声音。
