# 082 桌面插画与角色叙事

[原作](../../cases/jake11moran-825416-original/media/original.mp4) · [作者公开资料](../../cases/jake11moran-825416-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

整片将一次代码协作戏剧化为温暖室内的桌面故事。橙褐色矩形角色在桌后，电脑位于右侧，窗、吉他、花瓶、唱片和图画构成稳定环境。消息用纸飞机及纸张进入，角色以脸部表情、倾斜和起伏回应，屏幕内容从代码到成果再到绿色确认。观众主要跟随‘提出需求—给出结果—被纠正—再次完成’的情绪过程；空间一直相同，使较多往返仍然容易理解，不必每条消息重建一套版面。

20—25秒密集观察特别体现动作因果：纸飞机飞过，角色先惊喜并向上抬起，约21.3秒一把大木槌从右上摆入；21.9秒角色先出现惊讶，22.1秒受压扁平，同时屏幕由图片变为红色文本。随后角色恢复矩形但眼睛变为旋涡，木槌转出正面圆形文字‘WE HAVE TO SHOW ACTUAL MESSAGES’，成为提出纠正的阅读对象。这里不是单纯加入打击特效：巨物的尺寸预告压力，压缩表现受挫，槌面又承担消息，运动、表情与文案形成一条接力。

室内物件很多，但颜色受控。奶油墙面和浅青桌后背景构成亮底，棕木桌与橙角色提供主面积暖色，深蓝显示器给当前工作留一个高对比信息窗口。粗黑轮廓、轻纸纹和略有偏斜的物体构成统一手绘感；主角表情用很少的线段就与复杂环境拉开层级。窗外从月夜到日间再到夜间可见时间跨度，背景变化不会夺走桌面因果。牌匾固定在桌正面，兼作稳定身份，不需要反复播放标志。

可借鉴的是‘固定舞台、多次任务反馈’以及‘道具既做动作又做信息’。适用于教程、服务流程或人物经历，但要让角色动作回应当前消息，避免所有段落都用同一种弹跳。木槌在原片是喜剧隐喻，严肃主题应改为有意义的道具或环境压力。画面小字和圆形槌面文案在概览尺寸较小，本轮只确认内容角色与出场过程，未认证每行小字可读。复杂固定背景要控制运动量，真正重要的消息出现时，让周边动作退让。

本轮依据整片约每秒一帧概览，以及20.000—25.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。
