# 082 · 运动过程总览

## 运动总览

全片先在同一空间中用[推向侧框并逐字填入后退回全貌](mechanisms/m01.md)推向侧框，框内短行逐字建立，再退回完整场面。多次复用[折叠薄片斜入展开成竖片再收折离开](mechanisms/m02.md)，让折叠薄片斜向进入、展开为竖片、保持后再收折退出。

中段[长杆端部下扫触及主形再转角露面退出](mechanisms/m03.md)把长杆端部向下扫到主形上方，再转角露出端面并退出。后续[小片弧线落到上缘后长带顺势铺下](mechanisms/m04.md)让小片沿弧线落到主形上缘，长带顺势铺在原边界附近；第二次入场沿用同一接法。局部小形短暂向外漂动，最后[全幅收为圆窗口再缩至中心退净](mechanisms/m05.md)收小圆窗口并退到空底。
