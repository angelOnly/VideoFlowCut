# 020 · 运动过程总览

## 运动总览

片头 [线段闭合，两侧块向中央汇合](mechanisms/m01.md) 由线段逐步组成闭合轮廓，两侧块汇向中央，字组随后建立。接 [中心标记推近占满局部，字组在其前方接入](mechanisms/m02.md) 推近中央标记成为全幅局部，上下短句错开显出。

下一组主形保持在一侧，[主形固定，旁侧文字逐行累积](mechanisms/m03.md) 在旁侧逐行补齐文字；亮闪后主形回到中央，后层大字接上。随后 [主形收进片面，旁字数值与长条错开建立](mechanisms/m04.md) 把主形收进独立片面，旁侧数字、标签和长条逐项建立。数字与点阵累计段复用内部变化，不为每次输入另建卡。

后段 [竖片按空位错开补入，形成完整一排](mechanisms/m05.md) 分批补成多片竖向集合，再快速换入主字与局部图像。几次短闪接替后主形再次留场，片尾侧方文字与长条按层接入并保持。
