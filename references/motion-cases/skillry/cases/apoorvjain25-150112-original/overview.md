# 049 · 运动过程总览

## 运动总览

开头 [长条逐字输入，末端短形转动后换成完成反馈](mechanisms/m01.md) 在固定长条中逐字输入，末端短反馈转动后换成完成状态，下方字与小标签追加。长条收进新竖框，[竖框内部块面从上到下补齐，长内容上滚继续填入](mechanisms/m02.md) 从上到下补入内部块面，内容增多后上滚让出下部空间。

中段 [同一边界内多个状态原位接替，上小标记列保持](mechanisms/m03.md) 保留同一竖框边界，让内部状态原位接替，上方圆形小标记维持横向排列。[局部小片外提，竖框缩小移向一侧为旁片让位](mechanisms/m04.md) 将局部小片提到框前，再将框缩小移向一侧，[旁侧结果片依次追加，数值与轨迹增长后列表补齐](mechanisms/m05.md) 在旁侧追加数值片、增长轨迹与多行短条。后段局部小条再次接入，旁片逐层增加，最后 [短横片由上到下补成纵列，完整后交给结尾](mechanisms/m06.md) 从上到下补齐短横片纵列，整组退出后回到 [长条逐字输入，末端短形转动后换成完成反馈](mechanisms/m01.md) 的输入长条收尾。
