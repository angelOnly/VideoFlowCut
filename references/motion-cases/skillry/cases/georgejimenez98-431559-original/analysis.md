# 27. 影像卡片与空间球体：动效与美术拆解

[原作](../../cases/georgejimenez98-431559-original/media/original.mp4) · [来源](https://skillry.dev/ai-videos/opus-5-5/georgejimenez98-431559) · [作者公开输入](../../cases/georgejimenez98-431559-original/sources/published-prompt.md)

让观众从设置工具看到视频结果，再看到结果进入发布计划。媒体窗持续作为容器，图形球体只是品牌环境；界面卡和生成影像分清，不把生成结果当真实新闻素材。

直接观察的重点区间为 16.000—21.000 秒。16秒蓝色半透明卡内有故事文本，16.167秒波形条加入。16.917秒图像从卡片下部显出，17.083—17.333秒图像扩到整个卡，旧文字退去，状态换Rendering。18.333秒变Ready，19.25秒白圆从卡后扩展，19.5秒成为浅底新场，原视频窗缩小靠左。19.583秒日期列显出，19.917秒另一视频加入，20.167和20.667秒更多卡片依次填进计划；当前影片由单项结果变成集合的一员。

美术的设计解释：青蓝光与不同大小的球体形成层次，但主卡的亮度和位置更稳定；白文本块与波形先表示过程，影像扩满再表示完成。变浅底后仍延续青色边缘光，日期列和卡片统一尺寸，背景装饰退让。媒体形态转换与底色转换共同承担阶段变化。

迁移思考：适用于素材制作到排期、单个案例到集合、真实采集结果到档案。需要避免流程状态被误认为系统真实执行证据，展示实际产品时应核对界面。外部小球不能持续抢人脸，数据或长标题宜在结果停稳后阅读。

资料身份与实现边界：公开内容是产品功能与工具使用说明，完整提示词未公开；无本轮对应固定源码。本轮公开仓库、详情页与输入核查中，未找到直接对应当前原作的固定源码；不能把Remake技术标签或需求中提及的工具当原作实现证据。本报告只解释可见关系，具体遮罩、曲线、图层及渲染方案若实施，属于新制作选择。核查范围见[来源核查记录](../../cases/georgejimenez98-431559-original/sources/source-check.json)。

本报告实际查看整片约每秒一帧概览，以及关键区间的密集真实源帧；时间来自源PTS。基于带源时间图片序列，未核验原速观感，未试听，因此不认证整体流畅度、音乐拍点、对白连续或声音同步。概览不足以证明其他快速接续；300像素证据单帧中的小字、边缘精度仍需全尺寸核验。
