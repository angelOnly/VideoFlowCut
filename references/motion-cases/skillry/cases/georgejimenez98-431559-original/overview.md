# 027 · 运动过程总览

## 运动总览

开头外围圆形层缓慢漂移，中心小形建立后竖片接入，[活动竖片保持，旁侧虚线范围与短字接入](mechanisms/m01.md) 保留活动片并补入旁侧虚线范围和短字。旧组退去，中心字组建立，[圆形可见范围扩大，新面板从内部接管](mechanisms/m02.md) 从圆形范围扩大揭出新底层与固定面板。

中段 [上方标签顺序切换，下方面板局部换内容](mechanisms/m03.md) 上方短标签顺序切换，下方固定面板接续换内容，内部逐字填入或显示单片。完成长条建立后新竖片接入，[同一竖片逐层填入，再让内部活动图接管](mechanisms/m04.md) 在同一框中逐层建立标题、文本片和活动图像。

后段 [单片缩入横排，后片逐项填满并整体横移](mechanisms/m05.md) 将单框收小，横向补入后框，未完成空位逐项被占据，整排向侧方经过。末尾多条竖向覆盖从不同位置经过，揭出中心标记与长条；外围圆形层恢复漂移，主组最后退去。
