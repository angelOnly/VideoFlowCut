# 24. 美食照片、卡片与流程：后写复现设计指令

状态：研究者后写、未制作验证；不是作者原输入，不是原作源码，也未证明能够逐帧复刻。依据为[拆解报告](analysis.md)及其中列明的源帧证据。

取一组有身份编号的真实照片，先进入发布日历，按顺序增加状态标记。状态建立后让日历线退去，照片按实际数据位置移到趋势布局；先显示轴和单位，再由左向右画趋势线，重点项给短标签。照片身份在重排中保持，图线不穿过图像，白底和绿色状态统一。结束时各资料退场，再建立品牌或结论。没有真实数据时明确示意。

首版实施时先用本片真实内容、素材和画幅重新确认对象关系与阅读量，再拟时间；原片关键区间7—12秒只作观察参照，不强制套用其总时长或品牌。图层、遮罩和曲线可按新工程实现，参数不得标为作者原参数。完成后需原速查看、检查中间帧和全尺寸文字；有声音时另做试听及同步核对。
