# 主形沿底线经过后层分层视差接替

## 运动指令

让主形沿底线持续经过，取景随其前进，后层不同远近的片层以不同幅度反向经过。需要改变后层时从一侧让新区域接入，底线和主形的前进不中断。旁侧小形可在途中加入，加入后与已有组形共享同一轨迹。
