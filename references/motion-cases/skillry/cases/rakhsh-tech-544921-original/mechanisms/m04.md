# 同心圈绕中央变化半径散点外围经过

## 运动指令

围中央建立多层圆圈，中心保持不动，各圈半径以不同幅度扩大和收近，避免所有圈同步变成一条粗边。小点在圈内外分次经过，中央主形继续逐段建立或保持，圈的变化不改变其比例。
