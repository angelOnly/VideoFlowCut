# 笔段累积成形后缩入侧列，新形建立与下方双曲线交叠

## 运动指令


起始：中央只有小点或首段短线。

1. 中央短笔段沿路径累积成形，完成主形缩小进入侧列，新形在中央重新描入。

2. 下方双曲线相位错开持续起伏。

上述镜头变化与局部动作按同一条连续过程推进；写明同时发生的步骤在原场面中交叠，不先完成整段运镜再重演局部。
