# 短笔段按路径累积成完整主形

## 运动指令

先在中央留下短段，从其端部沿折转路径逐步延长。一个部分完成后保持，再在旁侧补下一部分，最后补内部短段，使整体由零散路径累积成完整主形。旁侧小行可在主形接近完整时逐字建立。
