# 081 复现设计指令

研究者依据原作观察后写，非作者原始输入，未制作、未渲染验证。用于重新设计相同关系，不承诺复刻原片。

制作一段竖幅概念类别短片，先把本片五个核心词按内部结构安排。使用暖纸底、墨黑大字、低对比边注；中心只容纳一个当前词。先逐笔建立并给完整阅读，再缩小向右上角记忆列接续；新词沿原中心生成，细线或散点根据该词物性回应。每次收走需保留最后一笔的辨识时刻，禁止两个不相关字直接乱插值。尾段将类别收为总概念，加入一枚小面积色印。不要照搬原词和声音，先核实本片内容，声音另行设计。

实施时先完成关键构图，再制作接续，按真实输出核对阅读、遮挡、对象身份和空间方向。使用绝对时间控制并保存可编辑源码；这些是新制作要求，不能当成已取得的原工程。涉及事实、品牌、人物、数字和素材时需使用本片已核实输入。无声首版先看画面，再依据实际音轨安排声音。
