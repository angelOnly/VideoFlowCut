# 镜头沿多层区向下移动，小圆在层内短斜线上经过

## 运动指令

在多层承载区中让小圆沿每层短斜线经过，镜头同步向下移动。已经过上层向上退出视野，下层进入可见区并接手相同局部运动，末区最后建立。
