# 多侧点沿线汇到中心，后续从另一侧送出并接旁片

## 运动指令

让多侧小点沿已有线向中心汇入，中心保留并接收局部反馈。汇入阶段明确后从另一侧送出后续短线或小点，接到旁片，前连接和来源节点保持。
