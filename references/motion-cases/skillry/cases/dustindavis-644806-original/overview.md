# 046 · 运动过程总览

## 运动总览

开头 [外围短片与小点逐项铺满，中心字接入后片群旋入退出](mechanisms/m01.md) 将散开的短片和小点逐项铺满，中央字组接入，随后片群向中心旋入并退出。中央标记与短字建立，再由圆形覆盖扩张换底。[小点从左片送入一排空槽，逐槽填实并同步更新数值](mechanisms/m02.md) 在新布局中从左侧片送出小点，依次进入一排槽位；各槽逐项填实，左片数值下降，完成边界和短反馈最后出现。

中段 [倾斜竖片由下接入转正，框内圆弧与列表更新后局部外提](mechanisms/m03.md) 从下方接入倾斜竖片，转正后框内圆弧与数值继续变化，列表行增加，局部短片外提。之后 [局部形先建立，字组逐段接上，重复轮廓后层持续经过](mechanisms/m04.md) 让不同形和字组在同一结构中依次接替，后层重复轮廓字持续经过。[大片带倾角进入转正，底部小标签错峰补齐](mechanisms/m05.md) 大片斜向入场转正，底部小标签逐项补齐。末段重用 [局部形先建立，字组逐段接上，重复轮廓后层持续经过](mechanisms/m04.md) 更新大字，数值从初始增加到结果，最终标记、字组与底条建立，短促散片经过后保持。
