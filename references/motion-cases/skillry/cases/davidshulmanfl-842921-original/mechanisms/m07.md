# 框内活动局部向上越出边框，外围层保持

## 运动指令

保持竖框与旁层，让活动轮廓的一部分向上接近边缘，再越出框外，其余部分仍在内部。外框不随局部抬升，局部返回时恢复原先的完整关系。
