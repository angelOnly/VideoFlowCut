# 35. 月相、手机与深色舞台：动效与美术拆解

以月相环、手机功能页、自然光影和左侧递增短句展示服务。手机持续同一位置承担信息对象，场外光影呼应功能氛围，月相环作为重复品牌形状。

直接观察的重点区间为 5.000—10.000 秒。5—5.167秒上一功能页从上部退去，新计数页接入，左侧第二行短句加入；5.167—5.583秒月相点环逐渐在手机周围展开。5.75—6.667秒手机环内数字改变。6.75—7秒手机切到长段文字页，月相环减淡退场，左侧第三行加入。7.917—8.25秒手机切到祈祷时刻页，外部绿暗光换为灰室内光，左侧第四行补齐；9.167—9.5秒下一暖棕页面入场，左侧第五行金色斜体短语补全。每次用同一手机框接续，未见外部照片与界面对象互变。

美术的设计解释：近黑、深绿、暖金光建立安静而精致氛围，白衬线短句依次提亮当前行，旧行减暗仍保留列表。月相环用大小和明暗形成节律，避开左阅读区；手机内自然图像与外部模糊光相呼应，但外部没有要求观众辨识的细节。

迁移思考：适合仪式、读书、自然主题与少量功能段。新闻或高信息讲解需提高背景与界面对比，不能照搬低亮小字；变暗只适合已读旧信息，不应降低当前证据可辨性。月相图形需有题材关联，不能作为所有片的通用装饰。
