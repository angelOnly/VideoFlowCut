# 035 月相、手机与深色舞台

## 适用场景

仪式、读书或自然主题产品用同一手机串联功能和安静收益短句。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：产品介绍、品牌展示

- 段落场景：步骤累积、重点强调、成果展示

- 原片实见素材：照片、手机界面、文字、抽象图形

- 动效方法：同手机换功能页、月相环展开退场、左侧短句递增提亮

- 美术特点：近黑深绿暖金、旧行减暗当前提亮、左文右手机

- 材料要求：需要实际功能页、相关图像和与题材有关的环形品牌符号。

- 迁移代价：低亮小字不适合高信息新闻，月相装饰不应无关套用，当前文字要足够对比；原速观感与声音同步未认证。

## 推荐观看片段

- 5.00—10.00 秒：计数页与月相环接长文页、时刻页，左侧当前短句依次补齐

## 动效与美术拆解

以月相环、手机功能页、自然光影和左侧递增短句展示服务。手机持续同一位置承担信息对象，场外光影呼应功能氛围，月相环作为重复品牌形状。

直接观察的重点区间为 5.000—10.000 秒。5—5.167秒上一功能页从上部退去，新计数页接入，左侧第二行短句加入；5.167—5.583秒月相点环逐渐在手机周围展开。5.75—6.667秒手机环内数字改变。6.75—7秒手机切到长段文字页，月相环减淡退场，左侧第三行加入。7.917—8.25秒手机切到祈祷时刻页，外部绿暗光换为灰室内光，左侧第四行补齐；9.167—9.5秒下一暖棕页面入场，左侧第五行金色斜体短语补全。每次用同一手机框接续，未见外部照片与界面对象互变。

美术的设计解释：近黑、深绿、暖金光建立安静而精致氛围，白衬线短句依次提亮当前行，旧行减暗仍保留列表。月相环用大小和明暗形成节律，避开左阅读区；手机内自然图像与外部模糊光相呼应，但外部没有要求观众辨识的细节。

迁移思考：适合仪式、读书、自然主题与少量功能段。新闻或高信息讲解需提高背景与界面对比，不能照搬低亮小字；变暗只适合已读旧信息，不应降低当前证据可辨性。月相图形需有题材关联，不能作为所有片的通用装饰。

资料身份与实现边界：公开输入为通用15秒Showreel启动句与Mounis产品网址，未提供原素材、品牌参数及修订，属于方向要求，不是完整逐镜头设计稿。本轮公开仓库、详情页与输入核查中，未找到直接对应当前原作的固定源码；不能把Remake技术标签或需求中提及的工具当原作实现证据。本报告只解释可见关系，具体遮罩、曲线、图层及渲染方案若实施，属于新制作选择。核查范围见来源核查记录。

本报告实际查看整片约每秒一帧概览，以及关键区间的密集真实源帧；时间来自源PTS。基于带源时间图片序列，未核验原速观感，未试听，因此不认证整体流畅度、音乐拍点、对白连续或声音同步。概览不足以证明其他快速接续；300像素证据单帧中的小字、边缘精度仍需全尺寸核验。
