# 稳定点阵的局部起伏沿面经过

## 运动指令

保持点阵基本格位，局部点先抬高或偏移，邻近格位随后接上，形成沿面的起伏。已经过局部逐步回到较平状态，另一处继续发起；取景可少量转角，但点阵仍是一张连续面。
