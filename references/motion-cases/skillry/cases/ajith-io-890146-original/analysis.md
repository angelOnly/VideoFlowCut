# 108 几何、粒子与色块组合

[原作](../../cases/ajith-io-890146-original/media/original.mp4) · [作者公开资料](../../cases/ajith-io-890146-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

这段展示片以‘每一帧’等大字开场，经过形状选框、点阵、空间球与线框立方体、彩色轨迹、弧形文字和环线，末尾收为名字。它展示设计技巧范围，观看任务是感知不同介质之间的接续，而非读取技术教程。黑、米白、蓝和黄色阶段由高对比切换建立，每场几乎只有一个主要形态；持续的边角刻度和小参数给它统一的编辑实验室语气。多种几何并不等于有内容的论证，应用时需找到具体关系。

4—9秒密集图组显示红圆保留中心和选框，旋转中变为蓝色圆角方块，再成黄三角、红色花形。5.5秒花形内部细分成密集点，5.7秒底换米白，点散开到大阵列；紅点在黑点阵里构出变形线或区域。7.4秒阵列向透视方向倾斜，7.5秒背景切蓝，白点保持阵列走势，随后收拢为球体、变为环，8.7秒再汇到立方体轮廓。连续性来自中心、点的密度和区域关系，不是所有形态真实同拓扑网格，且换底是直接色场切换。

美术主色面积以一场一色控制，形状阶段色块鲜明，点阵阶段黑白最易比较，空间阶段高饱和蓝承接白点，线框出现后颜色降到两种。点从面成为体，靠透视斜向与重叠说明空间，不能只靠加阴影完成立体感。选框与标注线宽很细，形状是满色，主次清楚；花形细分前边缘仍可认，细分后轮廓作为点群密度而不是粗边出现。整片快段很多，细参数主要是气质装饰，不应当成观众需要逐项读的内容。

可迁移的是从一个明确轮廓拆成同一组元素，再让元素重新表达关系，比如集合、区域、网络或空间。变换必须有语义理由：几何演示里形状变化本身就是内容，知识片则不能仅因好看把图表变成粒子球。大量点阵需要检查压缩和摩尔纹、保证关键形态在真实尺寸下可辨；每秒一帧不能证明快速变化流畅，密集图组也只覆盖这个局部。新制作时可用种子固定元素身份和轨迹，但本轮没有代码证据证明作者如此实现。

本轮依据整片约每秒一帧概览，以及4.000—9.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。
