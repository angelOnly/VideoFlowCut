# 环形填充与列表累积，提示接入后描出重点行

## 运动指令

竖框稳定，圆环分段填入、列表补行和数值增长先完成；上方提示随即加入，再描出列表重点行，保留整体结果。

1. **环形分段填入，列表逐行补齐且数值增加**

保留固定框，让环形按段增加，先段到位后保持。每接入一个后段，下方补一行对应短条与数值，顶部总数继续增加；最后环形与列表共同落稳。

2. **上方短提示片接入，列表中的一行边界随后描出**

在完整结果上方接入短提示片，片落稳后为列表中的一行补出局部边界。其余行与环形保持，提示片和被限定行形成上下联系。

整段结束：提示片突出，一行被限定 保留必要落稳与交接，中间已建立的参照沿用到下一步骤。
