# 041 · 运动过程总览

## 运动总览

开头 [翻转小片持续穿行，短卡错峰加入后中心标记出现](mechanisms/m01.md) 让大量小圆片持续翻转经过，短卡错峰加入，中央标记随后建立。旧集合退去后竖框接管，[角框限定内片，横带下扫后完成标记接管](mechanisms/m02.md) 用角框限定内片，横带从上到下扫过，再接完成标记。

中段 [环形分段填入，列表逐行补齐且数值增加](mechanisms/m03.md) 让固定框内环形逐段填入，下列表分行补齐，数值继续增加。[上方短提示片接入，列表中的一行边界随后描出](mechanisms/m04.md) 在上方接入短提示片，再为其中一行画出局部边界。[数值持续增加，折线分段延长并补齐下方填充](mechanisms/m05.md) 用另一内态接替，在数值增加时逐段延长折线并补填下方区域。末段 [竖框缩小上移，下方字组和底条依次建立](mechanisms/m06.md) 内部换成简洁状态，框缩小上移，下方字组、附属行与底条逐项建立，外围小片继续活动。
