# 114 动态字体与红黑粒子

## 适用场景

围绕一个核心形态展示不同材料或品牌质感，同时保持观看重心。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：品牌展示、影像展示

- 段落场景：前后变化、跨场景接力、重点强调

- 原片实见素材：三维、文字、抽象图形

- 动效方法：同中心延续材料身份、背景退让主体留场、亮闪连接材料阶段

- 美术特点：橙红对黑米白、金属高光与细轨道、暖粒子密度分层

- 材料要求：需稳定主体、每种材质的内容理由与关键构图，真实物性说明另需事实资料。

- 迁移代价：金属到粒子经亮闪，不能当真实材料转化；新闻证据不宜被碎化遮住；原速与声音未认证。

## 推荐观看片段

- 5.00—10.00 秒：格纸散开时橙圆留中心，暗底建立金属团，再以亮闪接暖粒子与旋涡，身份由中心和颜色维持。

## 动效与美术拆解

作品从轨迹与曲线进入MOVE文字、排版线、系统格网、圆与流动金属、粒子旋涡、红黑材质、方块阵列，最后收成名字。观看任务是展示动画语汇的跨度，结构主要由章节而非故事因果形成。下方时间标记、边角坐标与同一橙红重音持续，保证素材形态很多时仍像一件作品。它没有现实视频材料和复杂阅读，不宜把技术界面气质直接当科学解释。

5—10秒密集区间先看到米白格纸上的橙圆和黑色外环，5.67秒格纸分裂为小矩形并向两侧散开，橙圆留在中心，底场转暗。6.17秒圆内出现高光边和体积，6.4秒变为不规则金属团，同时细轨道和小球建立；7.7秒团收缩、表面波纹增多，8秒短亮闪覆盖，8.1秒变为暖色粒子球，随后收为旋涡。橙中心和相近尺寸连接不同材料，格网退场不带走主体，因此换材质也易跟随；金属到粒子通过亮闪，不能宣称真实物体物理融化。

美术强调橙红与黑、米白的面积交替，中央圆先是平面满色，随后靠白高光、暖暗反射和轮廓不规则获得体积；轨道线远细于金属高光，起到空间框架而非第二主体。粒子段用相近暖色，在暗底上保持亮中心和较暗外缘，旋涡从密度层次里可读。格纸段细网格与满色圆形成主次，格子散开时大片米白退场，视觉重量改变得明确。材质复杂后字和线必须减弱，否则每层都高对比会让观众看不出该追哪里。

可迁移方法是保留一种形状和中心，在换材料时延续身份；背景或容器变化应退让，不必所有层一起换。适合材料属性、品牌和设计展示，若讲真实物性需要科学对应，不能把亮闪当材料转化证据。碎格和粒子都是强装饰语汇，应在解释内容需要时才用，新闻片可用相同中心接力但无需分解证据图。固定小字不应承载关键事实，暗底材质还需检查显示亮度。图组显示步骤和空间锚点，不认证全部粒子轨迹、金属真实反射或原速流畅度。

本轮依据整片约每秒一帧概览，以及5.000—10.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。
