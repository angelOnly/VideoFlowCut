# 095 奇幻角色与版面组合

[原作](../../cases/iamtanzil-675031-original/media/original.mp4) · [作者公开资料](../../cases/iamtanzil-675031-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

实际作品是白色编辑式网页头部的录屏或演示：细金蓝色奇幻铠甲角色居中转动，左侧分行大标题、右下短说明先建立主题，中间两张半透明功能卡短暂出现，最后标题移到右侧与左边说明对换。它把已有背景视频与排版动效整合，而不是所有复杂铠甲都由文字动画现场生成。公开需求明确背景视频来自指定URL，并要求滚动控制时间；画面里正反重复显示各阶段，与这种交互语境相符，但本轮没有操作该网页验证滚动实现。

1—6秒密集图组显示角色从正面带蓝色光球逐步转到背面，披风在下半幅运动；左标题一直占据白色边缘。2.4秒左标题减弱，2.93秒两卡从下部显出，卡的图与正文位于角色身前。3.3秒卡已变淡，3.6秒退出，角色转回侧面，4.1秒右标题开始分行建立，到5秒形成稳定构图。每层的进退依赖主体朝向和可用边缘空间，真正持续的是视频人物与顶部导航；卡与文字并没有与铠甲发生几何转换。卡的可见窗口很短，按图组不能认为其中长说明已被阅读。

白底大面积削减奇幻元素常见的暗夜背景，复杂金属铠甲、宝石、蓝披风因而成为主视觉。金色与蓝色是互补的暖冷材质重音，金属细节非常密，外围排版必须稀疏。高对比细衬线大字带来奢侈编辑物的语气，短窄行让字块像竖列，顶部小导航和正文无衬线则功能化。半透明卡降低了遮住人物的压迫，但文字与铠甲纹理叠在一起仍有读数风险；白背景和卡片透明不自动保证阅读。人物放在中央，标题对换而不翻转人物身份，是版面连续的关键。

可借鉴‘视频主体持续表演，文字按空白区接管’，适合手机或产品视频、人物服装与影像展示。需先审素材的每个时间段，看哪一侧真正留白，再编排文字，不能固定套左标题右说明。页面的滚动时长可以由用户掌控，改为固定视频后必须重做功能卡阅读，不能照搬一秒窗口。公開详细输入可作为新实施的规格参考，但资源许可、模型来源和实际代码版本未验证，本轮不承诺一键复现原工程。

本轮依据整片约每秒一帧概览，以及1.000—6.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。
