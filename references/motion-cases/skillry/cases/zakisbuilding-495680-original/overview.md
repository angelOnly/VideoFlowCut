# 032 · 运动过程总览

## 运动总览

开头 [数字与横向点位接力，短闪后交给字组](mechanisms/m01.md) 用点位和数字形成短促推进，短闪后交给 [文字逐组建立，旧行上移退去，新重点放大接上](mechanisms/m02.md) 的文字接力。重点大字落稳后，[竖框上升转正，推近内部轮换后缩回](mechanisms/m03.md) 从下方建立竖框，转正、推近内部轮换，再缩回全框。

接下来 [框内画面向外扩张，越过边界成为全幅](mechanisms/m04.md) 让框内图像越过边界接管全幅，角形定位稳定后，[全幅内容缩回中央竖片，外围底层退虚](mechanisms/m05.md) 又将它缩成中央竖片。两段共享可辨认的内容，扩大和缩回各自可独立取用。片面稳定后 [横带向下扫描，结果圆标放大接管再上移](mechanisms/m06.md) 向下扫描，结果圆标接管、上移，接 [数字累加与点列点亮并行，落稳后补入长条](mechanisms/m07.md) 的数字与点列累计。

最后旧组退出，[中心图形展开后缩成小块，附属文字逐层接入](mechanisms/m08.md) 让细长形展开、缩成小块，标题与逐字长条围绕它建立，再回到小点底层收尾。原片的短闪、文字分组和小图形强调在多处复用。
