# 案例 128｜创意场面

按完整视觉表达划分；边界为抽帧基础上的暂定判断。

- [128-c01｜在同一展台上切换海报，并展开选中作品的说明](c01.md)：0.000—6.900 秒。从纸张作品在展台建立，到不同海报替换及其中一件的说明出现；之后进入另一种环形画廊。
- [128-c02｜从放射状作品集合中选择一件，再回到集合](c02.md)：6.900—14.300 秒。从作品环形集合建立，到选中项目详情和回归集合；14 秒后转为书本页面。
- [128-c03｜让书页本身承担作品浏览与详情展示](c03.md)：14.300—21.000 秒。从深色书本展开到浅色空间里的多份页面示例，之后切换到网格隧道。
- [128-c04｜在有透视的画廊空间里选中作品并展开详情](c04.md)：21.000—33.000 秒。网格空间建立、作品分布、单件详情以及返回同类空间构成一组展示；后续切到产品货架。
- [128-c05｜在产品集合里固定一个展位，再展开单品](c05.md)：33.000—42.533 秒。从多款饮料陈列、焦点产品变化到单品资料页及返回陈列；本地源文件在下一组状态中结束。
