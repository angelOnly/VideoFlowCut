# 031 · 运动过程总览

## 运动总览

开头 [活动框错峰叠入，内部变化与外部稳定并存](mechanisms/m01.md) 将多个活动框错开接入，框内继续变化，外部标题保持；随后收成单框。[固定大框内逐字补齐多行，局部强调随后出现](mechanisms/m02.md) 在固定大框中逐字建立多行内容，局部强调随输入接续。[后层放射展开，前景字组分行建立并放大接力](mechanisms/m03.md) 用后层放射线与前景字组的尺度变化接上下一段。

中段 [竖框内小块落入弧形区，逐步累积](mechanisms/m04.md) 在下方竖框内让小块下落并累计到弧形承载区；之后 [大倾斜片侧下入场，转正缩回后散片退落](mechanisms/m05.md) 让大倾斜片从侧下方进入，转正缩回，周边散片继续退落。[小框逐排填满，满幅后保持边界并持续轮换内部](mechanisms/m06.md) 从一排到多排补齐小框，再让各排内部持续变化。后段重用 [固定大框内逐字补齐多行，局部强调随后出现](mechanisms/m02.md) 输入多行，[下部竖框接入，局部块补齐后指示箭头到位](mechanisms/m07.md) 追加下部竖框和局部指示；最终主字与底部短条建立并保持。
