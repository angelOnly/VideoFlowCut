# 固定大框内逐字补齐多行，局部强调随后出现

## 运动指令

先建立空大框，文字在框内沿行逐字增加，一行之后接下一行；前行完整保留。输入到重点位置时追加局部强调，外框始终不动，让后续内容在已有结构中生长。
