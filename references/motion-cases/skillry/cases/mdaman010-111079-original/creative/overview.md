# 案例 094｜待审场面范围

原片：[数据中心三维系统与设备层级交互演示](../video.mp4)。以下为当前样稿的场面顺序，源时间含起点、不含终点。

| 创意卡 | 原片范围 | 范围与表达 |
| --- | --- | --- |
| [094-c01](c01.md) | 00:00.000–00:22.000 | 从建筑全景转向外部电线，以高亮路径经过变电设备和备用设施，最后抵达建筑入口。 |
| [094-c02](c02.md) | 00:22.000–00:51.000 | 以机房并列机柜建立尺度，收束到一个机柜和抽出的计算托盘，再观察板面。 |
| [094-c03](c03.md) | 00:51.000–01:13.000 | 芯片封装展开为多层板件，内部区域改为计算示意，随后观察范围回到带连接线的机柜。 |
| [094-c04](c04.md) | 01:13.000–01:20.500 | 多排机柜与上方交换设备同时可见，蓝色连接线和局部标签逐步引导观察网络关系。 |
| [094-c05](c05.md) | 01:20.400–01:37.962 | 从机柜与冷热管线并置开始，沿管线观察到屋顶设备、向上排出的热，再回到建筑全貌。 |

按供电路径、机房到机柜、芯片内部、机柜网络和冷却排热的独立观察任务分为五卡；第四、五卡重叠 0.1 秒，保留网络与冷却场面的交接。

观察方式、媒体复用与未确认范围以各卡为准；场面边界仍待审阅。
