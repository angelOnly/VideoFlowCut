# 044 · 运动过程总览

## 运动总览

开头 [中央字组保持，外围倾斜片持续堆叠并放大越界](mechanisms/m01.md) 保留中央字组，外围倾斜片持续堆叠并放大，随后整体退去。[字组分行建立，圆形覆盖扩张后新底层接管](mechanisms/m02.md) 在新空间分行建立字组，再以圆形覆盖扩张换底。[散开小片依次送入空竖框，在固定网格落位](mechanisms/m03.md) 立起空竖框，将散开的小片依次送入框内网格，完整后退虚。

中段主字建立，随后 [竖片列侧向经过，选片转正接管中央，旁片停在边缘](mechanisms/m04.md) 让一列竖片侧向经过，选定片转正接管中央，旁片停留在边缘；每次接管时上方文字原位更新，这一机制在多段重复使用。末段 [标题下小片逐项铺成网格，完整后退虚接上结尾](mechanisms/m05.md) 在稳定标题下方逐项铺成小片网格，完整后整组退虚，短字组与底条分项建立收尾。
