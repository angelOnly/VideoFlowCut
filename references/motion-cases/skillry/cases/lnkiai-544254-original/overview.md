# 047 · 运动过程总览

## 运动总览

开头 [镜头穿过远近散块，保留一个近块转正接管](mechanisms/m01.md) 在有远近的散块空间前进，再保留一个近块，让它转正接管中央。[小点扩成不齐主形，形内字组建立后收回接下一形](mechanisms/m02.md) 用小点扩成不齐主形，字组在形内建立，主形随后收回，再展开下一形。[多个竖框横向接续，局部块填入并连向下一框](mechanisms/m03.md) 将多竖框水平接续，局部块按关联填入并连接到下一框。

中段 [退镜转角，框内小件外提到前层形成分层展开](mechanisms/m04.md) 退镜并转观察角度，把框内小件外提到前层，完整组转成分层展开状态。[竖片列轮转，中央片转正保持，边缘片侧立](mechanisms/m05.md) 让竖片列轮转，中央片转正保持，边缘片侧立。[短片从散开排列成弧，再吸附回横向整行](mechanisms/m06.md) 将散开的短片弧形排列，再回到横向整行。后层密集字面斜铺，镜头沿面前掠，前景短字保持。

后段主竖框与旁字建立，短标签逐项补入。[数值增长后缩小上移，大字由大缩回中央](mechanisms/m07.md) 在散片持续经过时让中央数值增长，完成后数值缩小上移，新的大字由大缩回中央。最后换入新布局，重用 [镜头穿过远近散块，保留一个近块转正接管](mechanisms/m01.md) 的散块活动作为外围，主字、附属行、小条逐项补齐，结束保持。
