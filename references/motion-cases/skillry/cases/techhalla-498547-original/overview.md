# 119 · 运动过程总览

## 运动总览

开头的短行直接切到大行，[字片错开沿竖向进入落稳后下线延长](mechanisms/m01.md)让字片错开从竖向进入，落稳后下方细线和小刻度沿横向建立。下一组排列以[固定行位内快速换片逐行收定](mechanisms/m02.md)在固定行位中快速换片并逐步收定，先到位的行保持，后行继续建立。

[旧行轮廓放大经过前景边界从右向左接管新行](mechanisms/m03.md)先将旧行的轮廓放大经过前景，再以从右向左推进的边界接管为新行。新行内部[主行末尾局部先下沉再回到原基线](mechanisms/m04.md)让末尾局部下沉后回到原位，下方短行复用[字片错开沿竖向进入落稳后下线延长](mechanisms/m01.md)建立，再用[下方短行与下线共同横移上方保持](mechanisms/m05.md)与下线共同横移。

之后一组双行复用[字片错开沿竖向进入落稳后下线延长](mechanisms/m01.md)进入，[主行缩小移到角落框内逐段填充外围标记接入](mechanisms/m06.md)将其缩小移到角落，下方框内逐段填充，外围标记接入；横线扫过框内后切回大行，再次复用[字片错开沿竖向进入落稳后下线延长](mechanisms/m01.md)。末段[短竖片落到侧边起点主行向右累计下线延长](mechanisms/m07.md)让短竖片从上方落到左侧起点，主行从这个接点向右逐片累计，下线延长，最后共同保持。
