# 119 荧光色动态文字海报

[原作](../../cases/techhalla-498547-original/media/original.mp4) · [作者公开资料](../../cases/techhalla-498547-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

作品依次用STOP SCROLLING、AI VIDEO ISN'T EXPENSIVE、BAD PROMPTING IS、WORKFLOWS > WISHES、STEAL THE PROMPT和品牌形成宣传论点。观看任务是抓住少数短句，连续性来自固定黑色舞台、强调色、基线与相同排印力量，而非每段都用同一物体变形。开头实际先出现品牌，与公开输入的冷开场要求不同；中间终端式卡片只营造制作语境，不是可直接执行的完整指令。

10—15秒图组先保持BAD PROMPTING IS和绿色下划线，10.42秒整句向左抹出，10.5秒有短黑场。10.58秒首字带模糊出现，随后字母从下进入，11.67秒WORKFLOWS成行，11.8秒下行粉色WISHES和绿色大于号建立并短停。12.08秒标题缩到左上，中间细框卡片逐步出现keyframes、model等字段，绿色周边标注补齐。13秒绿横线增长，原卡退场，13.17秒STEAL THE PROMPT从下带模糊入场，继承中部位置和绿基线，13.92秒完整稳定至14.33秒。14.42秒向左退出，余下粉色竖线作为下一段接点。

大块黑底留出高对比舞台，厚白无衬线字先负责命题，酸绿承担断言与指向，品红承担对比选项或竖向记号。不是所有词同时荧光，每一拍有一个突出关系；粗字、行数和宽度比微小装饰更决定注意力。WISHES第二行用异色，使比较在读完之前就能看出两侧身份。标题缩角后信息层级暂时改为中央小卡，下一大句占回同一中心，布局改变有主次接力。带模糊的入场强调速度，但清楚状态才提供阅读； tiny绿色标签更像氛围，应避免承载重要术语。

这种方法适合栏目宣传、观点摘要和短促呼吁，可学习‘论点先读稳、缩成记忆、下一对象接管中心’。新闻或复杂解释应增长停留，把来源和限定条件放在可读区域；不要把小终端和强口号当事实支持。中文重字形可能在相同宽度挤压，需要重排而非缩小。亮色大于号只有关系正确时才用，色相应服务信息分组。连续移动与黑场并存，不能称全片无缝。未试听因此不认证120BPM同步，也不能从图片确定具体字体、模糊算法和弹簧参数。

本轮依据整片约每秒一帧概览，以及10.000—15.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。

作者资料核对：公开资料包含详细荧光文字海报输入：固定文案、色板、字体家族、120BPM节奏网格、循环和确定性HTML等；原片开头先有品牌锁定，与输入要求的STOP冷开场不同，不能据输入认证实际时间与工程。 平台列出的“Remake built with”描述复刻版本，不能证明原作技术栈；本案例不声称已有原作者源码。
