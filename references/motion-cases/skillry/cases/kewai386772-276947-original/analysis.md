# 104 几何入口与空间穿越

[原作](../../cases/kewai386772-276947-original/media/original.mp4) · [作者公开资料](../../cases/kewai386772-276947-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

这段画面是万花镜空间网页的交互演示：一个灰金多面体先在黑色页面右侧，面内已经可见金色环与重复空间，点击后镜头进入，镜面复制的环、面板与轮廓填满视野；再退回外壳并切换另一种多面体，内部对象和反射方式改变。观众任务是感知‘一个小外壳容纳巨大内部空间’，纯粹空间体验多于知识解释。左侧标题、底部控件和右下按钮说明页面层一直存在，不能把所有文字叠加都当影片字幕。

2—7秒密集序列先完整看到五边形开口及其内部金环，2.8秒按钮变化并开始靠近；3.1秒开口倾向画面正面，3.4秒边框扩到接近画幅，3.8秒外壳只剩部分亮边，4.1秒观众已在内部镜面空间。中央金环先被持续追踪，之后相机旋转，它向左下离开，其他复制金环从右侧接管。进入前已显示内部内容和明确入口，尺度变化有理由，不是黑场后突然另换一个空间；但图组只能确认可见衔接，不能证明镜面反射算法或真实光学。

黑底、灰金属面与暖金发光线形成窄色域。外壳暗面和亮棱构成可读体积，内部重复对象以大小、遮挡、亮度差形成深度；没有任意多色粒子，复杂感主要来自镜像几何。单个主环比远处复制环亮而大，初段提供唯一观察中心，进入后层次过密会降低对象辨认。页面白标题在深空间上保持可见，但大金环移到左侧时会接近字区，显示文字区域需要单独对比保护，不能仅因初始黑底就一直放心。

可迁移方法是‘先在入口中预告，再沿入口进入’，适合设备窗口、盒中空间、展馆和内容集合的放大。若主题需要讲具体关系，应在进入后安排一段稳定观察，不能所有时间都环绕镜面。镜像丰富度服务氛围时合理，承担真实数量或结构时会造成误解，多个副本不等于多个实际对象。网页演示有用户选择与控件，固定视频应只保留一次有目的的进入和返回。模型生成方式、源码和原速眩晕程度未验证，当前不能承诺镜面空间可直接复用。

本轮依据整片约每秒一帧概览，以及2.000—7.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。
