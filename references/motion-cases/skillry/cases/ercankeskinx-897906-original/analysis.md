# 18. 产品、色卡与页面布局：动效与美术拆解

[原作](../../cases/ercankeskinx-897906-original/media/original.mp4) · [来源](https://skillry.dev/ai-videos/opus-5-5/ercankeskinx-897906) · [作者公开输入](../../cases/ercankeskinx-897906-original/sources/published-prompt.md)

整片依次展示建筑图片选择、录音产品、夜间铁路路线、色样扇和品牌联系页。不同分区题材互不连续，但各自都有明确选择关系，适合学习素材与信息面板的局部配合。

直接观察的重点区间为 18.000—23.000 秒。18秒暗色路线场仍在，18.333—18.533秒左图卡从车厢更换为站台。18.933秒浅色下一页从下沿出现，旧场整体向上，19.467秒退出。19.6秒标题与右色样建立，19.733—20秒色片以底部共同位置扇开。20.8秒黄色片突出到前景、左侧名称同步保持当前项；21.4秒红片替换为前景、22秒绿色、22.133秒紫色。结构是共享扇轴下的选择接力，文字说明与色片对应。

美术的设计解释：色样不是额外背景配色，而是产品本身；页面底色随前景片轻微改为暖黄、粉红或灰绿，帮助突出当前项。扇片底部白标签提供统一基准，厚度与阴影让遮挡顺序清楚；左侧文字稳定、右侧选择变化，避免阅读与比较同时移位。

迁移思考：适合材质、服饰、产品版本及一组图片的比较；新闻中可替换为资料页，但无需模拟色卡。滚动整页转场不是对象变形；题材不相关时只保留分区设计。代价是小标签在视频里难读，应把核心信息提升到稳定说明区，必要时减片数。
