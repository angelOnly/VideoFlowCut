# 案例 134｜创意场面

按完整视觉表达划分；边界为抽帧基础上的暂定判断。

- [134-c01｜用地图定位工地，再让档案照片和数字展示施工规模](c01.md)：4.500—18.600 秒。由街区地图定位建筑，到工地档案、施工组图和数字标记；随后转入一份新的档案与工期说明。
- [134-c02｜让档案原文、关键数字和照片共同解释工作进度](c02.md)：18.600—28.400 秒。从统计文档和每周楼层数据，到多张照片与工时数字并列；随后进入工人人数的新主题。
- [134-c03｜先比较建筑高度，再回到施工层数与完成结果](c03.md)：35.000—55.600 秒。从多座建筑高度并列，到主体建筑层数和工期结果；55 秒后进入署名与结束页。
