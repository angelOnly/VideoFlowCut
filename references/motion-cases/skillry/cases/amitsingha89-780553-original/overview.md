# 014 · 运动过程总览

## 运动总览

开头 [后层缓慢移动，前方字组逐行显出](mechanisms/m01.md) 在缓慢活动的后层上逐行显出文字，换底后右侧网格留场，旁字与数字接续建立。随后 [图块按左右空位逐项建立，配套字随后接入](mechanisms/m02.md) 从左到右补齐三组图块和各自下方文字；同样关系在后面的四片横排与三步图块中复用。

中间 [新布局从侧边推进，旧组沿边退去](mechanisms/m03.md) 让新布局从侧面接管，旧组离开；[两片前后错开建立，旁侧文字与标签累积](mechanisms/m04.md) 在新布局里建立前后交叠的两片，再补旁侧文字和短标签。之后回到逐项横排，末段以 [后层缓慢移动，前方字组逐行显出](mechanisms/m01.md) 建立中心短句与下方长条，完整保持后结束。
