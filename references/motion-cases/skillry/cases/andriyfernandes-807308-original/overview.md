# 076 · 运动过程总览

## 运动总览

全片保持同一横向视野，[双组从两侧进入并随底线小幅起伏](mechanisms/m01.md)让两组承载形从两侧进入，并随底部曲线轻微起伏。两组之间反复使用[小点沿弧线跨越间距落点竖向扩散](mechanisms/m02.md)的小点弧线经过与落点扩散，之后部分落点改用[局部扩张圈带小形升起翻转后回落](mechanisms/m03.md)，从局部扩张圈带动小形抬起、翻转并回落。

两组持续保持来源位置，局部残留层继续活动。末段右组用[一组倾斜下沉附属小形分离落下](mechanisms/m04.md)倾斜并逐步落到曲线下方，附属小形分离回落；左组仍保持，最后整体退弱。
