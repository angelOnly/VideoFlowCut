# 主行保持附属行逐次延长旁小片后接入

## 运动指令

主行与上方小形保持，先在下方逐字延长附属行，再补最底短项。旁侧小片最后从空处接入，完成后所有层共同保持，整体退弱结束。

适合简洁收尾，已有主行不再同步缩放；附属层按阅读先后进入。
