# 球状点组打开中心拉成长螺旋字列围轴绕行

## 运动指令

球状点组先围自身轴转向，字列在其外围绕行。中间点逐渐向周边移开，形成较空的中心，再沿纵向拉开多层点列，使上下接成螺旋。字列继续围共同轴经过，最后逐步退弱，只留螺旋。
