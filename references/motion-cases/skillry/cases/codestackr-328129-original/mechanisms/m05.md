# 曲线标点沿路径移动多排短条错开横移并归齐

## 运动指令

左侧标点沿当前曲线移动，右侧多排短条同时横移，但各排起步和途中位移不同。经过中形成错位，最后停到共同竖向边界；更换曲线路径后重复，短条仍保留原排位。
