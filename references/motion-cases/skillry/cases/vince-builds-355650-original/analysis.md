# 019 人物照片与页面重排

## 适用场景

解释一条网页主张或批注时，把原句、位置和评论保持可追溯关系。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：新闻解读、操作教程、科普解释

- 段落场景：整体到局部、重点强调、前后变化

- 原片实见素材：照片、桌面界面、文章页面、文字

- 动效方法：逐行高亮原句、评论卡保留引用、收窄页面只留重点

- 美术特点：奶油页浅绿底、亮绿高亮、评论卡轻影

- 材料要求：需要真实页面、准确引用范围和实际评论或标明后写的解释。

- 迁移代价：不能用示意评论冒充他人意见，长建议要增加阅读时间，小网页须局部放大；原速观感与声音同步未认证。

## 推荐观看片段

- 13.00—18.00 秒：高亮原句引出评论，网页收窄后原句与评论再并列

## 动效与美术拆解

借同一网页标题贯穿评论、修改、执行与前后对照。人物聚餐照片提供页面内容，但核心叙事是某个具体位置怎样获得反馈，照片不是新闻影像也不是被跟踪的对象。

直接观察的重点区间为 13.000—18.000 秒。13秒标题以绿色逐行高亮，13.533—13.733秒旁侧评论面板出现，原短句被缩为面板顶部引用。14.067—15.333秒新建议逐字填入；15.867秒面板退去，原标题继续保留高亮。16—16.333秒网页大部收走，仅一个窄竖区保留该标题，16.4秒数字钉标出现在其左上；17.6秒评论卡从左上进入，与标题并排，18秒卡片仍在形成。持续对象是原句、引用和位置，而非一张全网页从头平移到尾。

美术的设计解释：奶油色内容页、浅绿操作底与亮绿强调形成三级区域；选中字背后高亮比描边更直接，不遮字轮廓。评论白卡有阴影和细绿边，引用缩图仍保留原句行形，建立可追溯关系。真人照片与界面被分区安排，收窄阶段主动移去图片减少竞争。

迁移思考：适合新闻页面引用、证据聚焦、批注和修改说明。迁移要保留真实原句、位置与上下文，不能用示意评论代替他人真实意见。文字输入较长时需要停稳，界面过小会失去证据意义；应为当前句和评论专门排版而非缩小整个网页。

资料身份与实现边界：公开文件明确只有作者发帖说明，未公开完整提示词；工具名与耗时不能代替分镜或源码。本轮公开仓库、详情页与输入核查中，未找到直接对应当前原作的固定源码；不能把Remake技术标签或需求中提及的工具当原作实现证据。本报告只解释可见关系，具体遮罩、曲线、图层及渲染方案若实施，属于新制作选择。核查范围见来源核查记录。

本报告实际查看整片约每秒一帧概览，以及关键区间的密集真实源帧；时间来自源PTS。基于带源时间图片序列，未核验原速观感，未试听，因此不认证整体流畅度、音乐拍点、对白连续或声音同步。概览不足以证明其他快速接续；300像素证据单帧中的小字、边缘精度仍需全尺寸核验。

## 实现建议（研究后写，未制作验证）

状态：研究者后写、未制作验证；不是作者原输入，不是原作源码，也未证明能够逐帧复刻。依据为拆解报告及其中列明的源帧证据。

选取实际网页中的一条关键原句，先以逐行高亮明确范围，再在邻近空位弹出评论卡，顶部保留原句引用缩图，下方显示解释或修改建议。提交后评论退去，页面其他内容收走，只留原句所在窄区与位置标记；再让评论卡与原句并列，建立反馈对应。后续展示改后结果与改前对照，保留真实引用范围和来源，避免模拟事实。

首版实施时先用本片真实内容、素材和画幅重新确认对象关系与阅读量，再拟时间；原片关键区间13—18秒只作观察参照，不强制套用其总时长或品牌。图层、遮罩和曲线可按新工程实现，参数不得标为作者原参数。完成后需原速查看、检查中间帧和全尺寸文字；有声音时另做试听及同步核对。
