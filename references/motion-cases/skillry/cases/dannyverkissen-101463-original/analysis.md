# 043 食物图片与健康应用

## 适用场景

用于食物识别或商品检测介绍，把手机里的对象照片与对应结果取到外侧解释。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：产品介绍

- 段落场景：整体到局部、重点强调、成果展示

- 原片实见素材：手机界面、照片、文字

- 动效方法：详情先建立再推近、同照片外抽放大、来源对象数据三角构图

- 美术特点：深绿外场与白设备、食物色彩保留、标题退让屏幕细节

- 材料要求：需要高清对象照片、忠实界面裁片及准确对应的结果数据。

- 迁移代价：原片是手机界面结合静态照片，不能作为人物实拍混剪示例，小屏正文需重排；原速观感与声音未核验。

## 推荐观看片段

- 14.00—19.00 秒：食谱列表进入详情、旧标题退出、餐食照片及营养摘要在手机外侧建立。

## 动效与美术拆解

作品以食物实拍照片为中心，把拍照、识别营养、调整份量、记录、食谱、饮水、训练和提问组织成一天的健康使用过程。每段文字很短，手机左右轮换，最后五个界面合成产品集合。食物并非另一个无关B-roll：它出现在拍摄界面、结果和食谱页面，图像提供“这份餐食”的具体身份，数字和控件负责解释。

14—19秒密集序列见到食谱列表先稳在左侧，右边保留两行标题。15.1秒附近手机内页面横向切入详情，餐盘照片成为屏幕上部；标题此时退去，镜头随后靠近，避免同时要求读标题和详情。16秒后一张相同餐食的图像副本从屏幕附近移到右上，营养摘要在右下较晚入场，手机保持在左侧。照片、摘要、原界面形成三角构图；这属于屏幕内容抽取与放大呈现，不能断言它是原页面同一DOM对象。17.7秒亮带经过后回到概览屏，再让饮水标题出现。

深绿背景与白设备、白界面产生大明暗差，绿色只高亮标题关键词和应用主操作。食物本身的红橙、米色和绿色提供丰富细节，所以外部包装不用再增加多种主色。标题用粗无衬线和两三行短句，屏幕细字留在真实界面层，外抽卡片放大“照片—每份数据”的对应。阴影、角度和柔光让手机像产品表面，但照片清晰区域仍是核心；大幅推近发生在文字退让后，展示与阅读有顺序。

最适合借鉴到实物检测、餐食、票据或商品评测：先呈现完整界面，再把当前讨论的实际图片及对应数值取到外侧放大。迁移需要合法可用的原图、准确结果和可分层界面；只用一张模糊截图缩放难以保持正文清晰。五机汇总适合结束时说明覆盖面，不能让每台细节都承担必须阅读的信息。中间连接优点来自材料身份与排版分工，未核验原速速度和音效。
