# 115 图形阵列、节奏与线条

[原作](../../cases/blue-clarity-449603-original/media/original.mp4) · [作者公开资料](../../cases/blue-clarity-449603-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

片段以坐标和落点开场，接大字体‘MOTION IS ALL TIMING’，随后形状变换、蓝色粒子聚字、空间点球、多格能力面板和品牌。它更像设计师能力展示，观众任务是感受时序、组织与形态的区别。全片大量蓝、橙、白和黄，但以阶段分配而非同时填满；边角微小曲线图和标记维持技术演示语言。实际图形不足以认证任何设计工具或计算模型。

6—11秒密集图组显示蓝色圆从中心放大，白黄粒子沿圆周向外扩散，蓝底接管；6.8秒粒子向中心聚拢，7.1秒开始从左边成字，到7.3秒形成CLAUDE，下面黄线保持水平。字形稳定至8秒，然后白黄点重新向右聚集并横移，8.4秒蓝场被阶梯状边缘从左上擦走，暗底空间点球出现。9.7秒球体中心逐步打开成环，10.5秒直接切入浅底多格面板，九个图形窗由小到大排列。不是每一段都同物体变形：聚字粒子有连续密度，点球到面板是明确换场。

字体采用细长粗无衬线，字高大而行数少，蓝底粒子字虽然明亮但边缘颗粒化，稳定后仍比实心字难读。黄线作为地平线式锚点给文字提供基线，空间段细橙黄轨道与深蓝底构成前后层。浅底九宫格里蓝、黄、橙各占几个窗口，窗口间白缝把不同动效隔开，避免彩色图像混成一团。每个窗展示一个规律而不是塞长标题，是集合阶段合理的密度分工；全部窗口同时运动也可能让观众没有唯一焦点。

可迁移‘集合动作集中到一个短词，再退到集合回顾’，适用于品牌、栏目总览和功能集合。聚字需要简单字形及足够停稳，不应把重要句子都写成粒子。九宫格可以表达‘有多种能力’，但无法让观众深入理解九项内容，关键那项仍应从集合里选出放大。粒子数与窗口数量是示意，不能当数量统计。此例可提供平面与空间的注意力交接参考，却不证明能与实拍材料融合；新内容的图片、场景和字体需要另设计。原速颗粒闪烁及同步未核验。

本轮依据整片约每秒一帧概览，以及6.000—11.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。
