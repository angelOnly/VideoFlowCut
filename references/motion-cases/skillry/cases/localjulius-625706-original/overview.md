# 086 · 运动过程总览

## 运动总览

全片反复复用[主框建立后下方短行逐项增强并延长](mechanisms/m01.md)，建立主框并让下方短行逐项增强。中间穿插[全幅短条高低起伏上行建立后圈线划过](mechanisms/m02.md)的横向短条起伏和圈线划过。多个主框接替时，[旧片缩到边缘保持中央主框接替](mechanisms/m03.md)把先前片面缩到边缘继续保留；随后[阵列后层退弱中央斜框放大接管](mechanisms/m04.md)展开多片阵列、减弱后层并用中央框接管。

下一段[左框保持右片接入并连续填入字行](mechanisms/m05.md)在左框旁建立右片并连续填入字行，底部短行继续复用[主框建立后下方短行逐项增强并延长](mechanisms/m01.md)。后段[多个短片沿共同长线依次建立并补下行](mechanisms/m06.md)让多个短片沿同一长线依次建立，结尾[上行先建立下方框带接入再扫下线](mechanisms/m07.md)由上行、下方框带、下线和附属小行形成完整收尾组。
