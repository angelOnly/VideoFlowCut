# 077｜手绘机器人与操作流程

[原作视频](../../cases/mattbean-917572-original/media/original.mp4) · [作者公开输入](../../cases/mattbean-917572-original/sources/published-prompt.md) · [来源页](https://skillry.dev/ai-videos/opus-5-5/mattbean-917572)

这条30秒手绘产品流程片分三步：连接代理、代理填商品页并设置兑换、发布。机器人角色始终伴随流程，前段用电缆连接AppSumo牌，中段黄铅笔逐字段写页，末段同一商品页缩成销售卡盖上红色LIVE章，再回到品牌结论。机器人不是单纯装饰，它承担发起动作和确认完成的角色；页面是手绘示意，不是对真实后台执行的录屏证据。

15—20秒密集段从已填写的大商品页继续完善功能勾选与下方图像。黄铅笔依次到对应字段，完成标记保留，16.3秒后标题补上设置兑换的第二行，16.7秒右侧出现空轮廓卡，铅笔随之写出标签和标题。17秒以后新卡的Codes与Licensing页签建立，18.6秒Licensing涂黄，19秒铅笔向下写地址字段，20秒移向Run test按钮。旧商品页留在左，相关新卡接在右，共同构成同一项任务的扩展；不是把页面变形成兑换工具。

奶白微纸纹底、黑色不齐细线和手写斜体标题提供笔记风格，黄铅笔、步骤圆、按钮和小圆点统一“正在操作”的注意力色。大量纸白留在页外，页面图像也用同样黑线太阳山峰，避免写真图片突然破坏材质。机器人身体白、胸口黄，尺寸小于操作页，让角色亲和而不挡阅读。红LIVE章直到成功阶段才出现，颜色频次少，结果因此突出。网页字段较小，缩略证据不能确认每一地址；迁移到手机需简化字段并增加局部可读尺寸。

适合讲软件如何完成一个用户任务，尤其适合把复杂真实页面先抽成只保留必要字段的图形。核心不是每个字段都自动打字，而是让铅笔、焦点和完成状态一致：动作经过哪里，哪里才有新内容；新工具出现后旧成果保留。真实屏幕混合版本可用原页面截图和外部指示器，但必须标明自动操作示意，防止观众误认实际调用。代价是三步产品片难以讲权限、失败、审核等待等完整业务，发布成功画面也不能被当成产品保证。
