# 沿纵深逐层推进，外层依次让出入口并沿原路返回

## 运动指令


起始：完整结构在远处。

1. 锁定局部沿纵深推进，近层组件向不同方向拉开露出入口。

2. 盖层抬起，格层退让，下方细阵列接管近景。

3. 深入后沿原路径退回整体。

上述镜头变化与局部动作按同一条连续过程推进；写明同时发生的步骤在原场面中交叠，不先完成整段运镜再重演局部。
