# 图块下降、缩小、转正，交叠填入一排小槽

## 运动指令

让窗口、承载区域和下方小槽保持，令第一张图块从左上边界进入，边下降边缩小，轻微倾斜逐渐回到接近竖直。让它跨过中部区域，沿横向同时靠近第一个小槽；接近小槽时逐渐减小位移，落稳后保持。当前块尚未完成下降时，让下一块从上方另一个位置进入，继续缩小并转正，落向下一个小槽。随后从左到右补齐整排，使同一时刻可以同时存在上方进入块、中部下降块和底部已落稳块。最后一块落稳后保持整排，把运动交给指示符或下方小形状。

## 组合与调整

可调整图块数量、上方来路、初始倾斜、缩小比例、小槽间距以及进入间隔。下降、缩小、转正和落槽属于同一连续过程；进入间隔应短于单块完成过程，才能保留交叠。不要在中部区域先停下全部图块，再突然换成一排小图。
