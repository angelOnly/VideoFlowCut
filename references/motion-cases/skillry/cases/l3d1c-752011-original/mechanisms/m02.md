# 角标按行逐项加入，完成的角标留住

## 运动指令

让竖框、图块网格和下方字组保持，按每行从左到右、再向下一行推进的次序，让图块角落的小角标逐项加入。让已经出现的角标留在对应图块上，不因下一角标进入而移动整张图块。随后只补入指定位置，允许某些图块不增加角标。目标集合完成后保持网格，把下一步动作交给图块本身。

## 组合与调整

可调整需要角标的图块范围、出现方向和逐项间隔。完成状态由目标集合决定，不必把所有格子都补满；后续图块要退出时，让角标与所属图块一同处理。
