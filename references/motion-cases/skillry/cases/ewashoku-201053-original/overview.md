# 090 · 运动过程总览

## 运动总览

全片反复以[同一复杂组形放大转角再缩回全貌](mechanisms/m01.md)改变同一复杂组形的尺度与观察角度，下方长条内容通过[纵向长条连续上移固定顶栏保留](mechanisms/m02.md)连续上移。内部段落用[近侧外层退让露出内部并推向局部](mechanisms/m03.md)退让近侧外层，露出内部并推向局部，多个指示从原局部派生。

局部演示依次采用[相邻圆部件围各自轴转动并保留连接](mechanisms/m04.md)的共同轴附近转向与部件相对转动、[连杆绕接点摆动短杆同时收缩再恢复](mechanisms/m05.md)的连杆绕接点摆动及短杆收缩恢复、[杆段沿外套方向滑入再伸回](mechanisms/m06.md)的杆段沿外套方向滑入再伸回。最终组形恢复全貌，[纵向长条连续上移固定顶栏保留](mechanisms/m02.md)继续完成多段纵向经过；[整列前框接入遮住原组后退回原层](mechanisms/m07.md)在原层上接入整列前框并退回原空间。
