# 杆段沿外套方向滑入再伸回

## 运动指令

固定外套的上端参照，让下部杆段沿外套方向向内滑入，露出长度逐步减少，相连末端圆区随杆段移动。到短状态后反向伸出，恢复原露出长度；旁侧组形保持，不同时改变另一套局部。
