# 纵向长条连续上移固定顶栏保留

## 运动指令

让长条内容整体向上经过，顶部小参照条保持不动。上一组的下部逐步越出上缘，下一段从下方进入；每段进入后主形或短行在本段位置逐步建立。需要返看时沿原方向反向经过，不另换一幅长条。

## 组合与调整

可用于任何纵向结构；段落内容不应跟固定顶栏一起漂走。
