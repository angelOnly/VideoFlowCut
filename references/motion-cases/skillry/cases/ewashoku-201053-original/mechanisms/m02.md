# 固定顶栏下长内容上移，下一组在同一区域接替

## 运动指令


保留顶部窄栏不动，让下方长内容整体向上经过；先把前组送出，再让后组从下方进入同一观看区域。后组的上部图形和下部短行共同落位，停止本轮滚动。
