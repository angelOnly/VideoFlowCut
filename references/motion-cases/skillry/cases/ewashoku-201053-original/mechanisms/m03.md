# 近侧外层退让露出内部并推向局部

## 运动指令

先在外层局部建立标记，再让近侧外层退让，内部原位置逐步露出，远侧外轮廓保留作参照。取景随揭示向局部靠近，非目标部件减弱但不乱移；标线从新露出的部件接向旁侧短标。
