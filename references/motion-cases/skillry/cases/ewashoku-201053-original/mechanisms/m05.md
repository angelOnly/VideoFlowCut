# 连杆绕接点摆动短杆同时收缩再恢复

## 运动指令

固定上层支架，下面连杆围稳定接点向上摆动，与之相连的短杆同时沿自身方向收缩。摆动到较大角度后反向回落，短杆逐步伸回，末端圆区沿接点附近的弧形范围往返。
