# 整列前框接入遮住原组后退回原层

## 运动指令

在原层上方接入覆盖主要范围的前框，前框内多行从上向下建立，分隔线随后补齐。原组在后面保留来源位置；前框完成任务后整体退出，原层沿既有位置重新露出并继续纵向经过。

## 组合与调整

无需复现交互产品，把前框当可组合片面；返回时原组不重新入场。
