# 近侧外层让出内部，推进局部后圆部件同轴转动

## 运动指令

外层先退让显出内组，取景推进到局部；相邻圆部件各自绕轴转动，连接仍保持，最后取景回到较完整范围。

1. **近侧外层退让露出内部并推向局部**

先在外层局部建立标记，再让近侧外层退让，内部原位置逐步露出，远侧外轮廓保留作参照。取景随揭示向局部靠近，非目标部件减弱但不乱移；标线从新露出的部件接向旁侧短标。

2. **相邻圆部件围各自轴转动并保留连接**

保留共同支架和各圆部件轴点，让圆部件围自己的轴改变角度，连接部分保持位于原接点附近。视野可沿连接稍移到相邻部件，但每次先保留旧轴参照，再突出新局部；旁标随局部建立。

整段结束：各部件继续转动且接点稳定 保留必要落稳与交接，中间已建立的参照沿用到下一步骤。
