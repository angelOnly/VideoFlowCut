# 中央片边缘伸缩外围片靠近聚合再分离

## 运动指令

保持字行和中央位置，外围小片先靠近中央片，接触附近的边缘伸出并短暂连成整体，再缩回分离。外围片可从字片前后经过，但字行始终保持；相同聚散关系可重复，不每次换一套位置。
