# 117 形状、粒子与数据画面

[原作](../../cases/ghinaiya-nirmal-308943-original/media/original.mp4) · [作者公开资料](../../cases/ghinaiya-nirmal-308943-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

作品以橙球的弹动和覆盖建立节奏，接蓝底重复文字、花形与三角曲线、格网、空间点球、fluid文字和流体团，末段快速排列图表、计数、故障字、环图与隧道后收成品牌。观看任务是浏览视觉能力，橙、蓝和近黑提供跨章节记忆，但许多场面只是剪辑相邻，并非同一物体连续变形。图表数字服务展示，没有来源，不能当真实数据或软件输出证据。

8—13秒图组先见橙紫蓝点球，8.1—8.4秒球顶部打开成环，8.6秒开始扭成纵向结，8.9—9.2秒散为暗点。9.25秒中央小橙点和白色包围出现，9.42秒已换为浅底橙团，随后细斜体fluid与红蓝团建立。中央暖团持续变形，侧团绕字移动，文字部分笔画被遮住。10.75秒黑色滴状边缘从上进入，11.08秒覆盖上部；11.25秒直接切成蓝色柱图，随后白柱图、黄色曲线、彩色立方体、900 frames、GLITCH、环形百分比和方形隧道频繁硬切。真实接续主要在点群与流体各自内部，不能把这五秒全部描述为无缝变形。

美术用面积变化控制章节：点群靠暗底中的密度和亮色半球读出体积，流体段换浅底后橙红块成为视觉重心，细黑字提供静参照。团块遮字有柔软和挤压的感受，却削弱信息读取，所以短词仍能凭整体轮廓辨认，长事实句不适合这样处理。数据段蓝底、白柱和荧光绿重音区分主次，后续图则各自重置颜色体系；这种多样性属于展示目的，若用于解说会让读者反复适应。小计数、边角标记承担气氛，不宜作为必读信息。

值得迁移的是改变形态时维持中心、色相或点群密度，使观众能追到新状态；背景覆盖可提前发出换场信号。需要警惕把‘很多变化’当‘连贯’：知识片可选一个关系用完整过程说明，给图表建立和阅读时间。流体或粒子与实拍结合时应退为遮罩、焦点引导或一个短接续，不能遮住证据主体。大幅色场可支撑品牌情绪，但叙事换场需有内容原因。图组未核验全程快速剪辑观感、百分比真实性、声音拍点和具体模拟方法。

本轮依据整片约每秒一帧概览，以及8.000—13.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。
