# 侧立片展开后越框，内部短线接力增长

## 运动指令

翻开片层先建立承载，前景越框与内部短线增长在同一布局中接力，结果共同保留。

1. **侧立片层翻开，前景轮廓越出框边**

让新片层以近乎侧立的窄面进入，随后转向正面并铺开。片层内部的框先成为新的空间参照，活动轮廓位于框前，局部越出边缘；旧底层在翻开期间退去。正面稳定后，再接入框下附属区域，保持前景、内框、底层的遮挡顺序。

2. **并列短线从固定起点逐步延长**

保持主框位置，让下方并列短线从各自的固定起点逐步延长，终点停在不同位置。先达到终点的线保持，其他线继续增长，最后留下完整的一组长度关系，附属文字再分组接入。

整段结束：短线延伸到各自长度，主框继续保留。 保留必要落稳与交接，中间已建立的参照沿用到下一步骤。
