# 小圆围大圆靠近接入内部小圈逐次增加

## 运动指令

让外围几个小圆沿中央圆周改变位置，逐个向中央边界靠近。接近后外围圆退去，内部从少量小圈开始逐次增加，已有圈保留并改变少量位置。大圆边界保持，下方短值可随增加原位接替。

内部累积与外圈靠近要有先后联系；不推定数量增长的隐藏规则。
