# 方块从上方落入下区并伴随区域增高

## 运动指令

保留外框，在上方逐次送入小方块，方块带少量转角下降到下区。下区高度随落入逐步增加，内部小圈从下方分次升起；方块进入后不在框外停留。停止新增后保持下区，顶部短线缓慢上扬。
