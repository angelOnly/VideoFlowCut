# 084 复现设计指令

研究者依据原作观察后写，非作者原始输入，未制作、未渲染验证。用于重新设计相同关系，不承诺复刻原片。

制作工艺解释，左侧短标题、右侧当前材料或器具、边缘细品牌标注持续。为每阶段选择一个主色和可理解动作，下一主色必须从当前物体、液体或操作入口产生。先让当前对象放大覆盖旧场，旧标题退出，再建立下一器具和真实原料运动，主体被识别后揭示标题。示例局部可用原料表面色接管背景、粒子进入托盘聚拢、托盘退去但粒子保留、中心圆覆盖到下一场。明确这是视觉接续，不能表示未经核实的物质变换。最后成品回到安静浅底，留足品牌与结果阅读。

实施时先完成关键构图，再制作接续，按真实输出核对阅读、遮挡、对象身份和空间方向。使用绝对时间控制并保存可编辑源码；这些是新制作要求，不能当成已取得的原工程。涉及事实、品牌、人物、数字和素材时需使用本片已核实输入。无声首版先看画面，再依据实际音轨安排声音。
