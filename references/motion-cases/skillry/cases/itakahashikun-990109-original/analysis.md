# 084 原料、器具与制作过程

[原作](../../cases/itakahashikun-990109-original/media/original.mp4) · [作者公开资料](../../cases/itakahashikun-990109-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

这条烧酒工艺解释把原料到成品组织为六个视觉阶段：土地与芋、清洗、蒸米与曲、发酵、加料、蒸馏和瓶装。标题基本固定在左，操作对象主要在右，顶边品牌小字与底边细刻度持续提供同一影片的框架。观众先看器具中的状态再读短句，而不是只通过换背景猜阶段；成品瓶在浅纸底收束，回到‘从大地到一滴’的尺度反差。各场使用不同主题色但物体质感与排印语气一致。

7—12秒密集区间包含两次完整交接。中央芋形在7.5秒开始放大，遮住右侧并扩展为紫色全底，左侧旧标题依次退出；8.2秒出现木托盘，米粒从上方落入，沿盘内旋转聚成放射状。标题与托盘不是同时抢入：操作已经被识别后，左侧逐行建立新句。约10秒米粒增亮，盘下出现小标签，11.1秒托盘消失而米粒阵列仍在，随后阵列收缩，中心一个深绿圆迅速扩大，于12秒覆盖整画面。物体的表面色变成背景，背景中的新对象又提供下次颜色入口，这种接力比无关联淡入淡出有空间理由。

金橙、深紫、青绿、朱红、深蓝和米白不是一张同时展开的色表，而是依照工艺阶段分配的大面积舞台。每场只保留一个高对比对象群，明暗形成中心聚焦；芋紫与下一场紫底、发酵青与下一器具关系使换色有来源。日文衬线标题具有工艺出版物的严肃感，金色强调几个关键字，细无衬线辅助文字退居解释。木纹、玻璃和金属给器物不同触感，背景却保持相同柔和晕光，因此不会因换材质而分裂成不同广告。

迁移价值在于‘让当前材料产生下一舞台’，适合制作、供应链、产品工艺和机制解释。需要先核实每一步真实输入输出，不能把芋直接变化成米理解为物质转化；这里是阶段接续，非工艺证据。原片发光阵列也属于表现，不代表真实发酵可见现象。复现时要给动作有用的停稳、标题有清楚的读完时刻，并控制遮挡先退出旧句再进入新句；每个阶段的颜色和物体都要依据本片材料重设。

本轮依据整片约每秒一帧概览，以及7.000—12.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。

作者资料核对：公开页明确缺完整提示词；日文原帖介绍准备Remotion环境及与模型对话的过程，没有完整生产分镜。 平台列出的“Remake built with”描述复刻版本，不能证明原作技术栈；本案例不声称已有原作者源码。
