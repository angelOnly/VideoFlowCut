# 013 拼贴影像、旧纸与字体

## 适用场景

虚构故事或文化评论用书架、锁和剪字引导观众进入下一叙事空间。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：影像展示、品牌展示

- 段落场景：跨场景接力、空间关系、重点强调

- 原片实见素材：照片、插画、文字、抽象图形

- 动效方法：剪字逐词建立、道具覆盖开口、书架转开揭房间

- 美术特点：蓝灰钢笔画、奶白剪纸边、红色情绪重音

- 材料要求：需要可分层插画空间、书架开口、手掌道具和短词剪字。

- 迁移代价：资产种类多且恐怖语气强，不能把虚构人像关联搬到事实报道；原速观感与声音同步未认证。

## 推荐观看片段

- 79.00—84.00 秒：手掌与锁引导书架开口，旧词退去后揭露粉色房间

## 动效与美术拆解

约两分钟的恐怖披萨店拼贴MV，从星空漂浮明信片推进到街道、餐厅、监控、书架与地下空间，再回到初始集合。歌词用报纸剪字和纸条出场；图像多为画作、剪贴人像与道具，不能当新闻或真实事件证据。

直接观察的重点区间为 79.000—84.000 秒。79秒书架居中、前景纸箱遮住下部，剪字逐个构成PLAIN；79.917秒手掌从右进入，到80.167秒靠近架子。81秒链锁道具覆盖书架，手掌与旧文字在81.167—81.25秒退去，接续新剪字。82.583秒锁开始向下退，82.833秒书架向一侧转开，83秒门后粉红色房间露出；83.333秒纸箱退去，镜头开始进入。书架同时是叙事道具和遮挡换空间的边界。

美术的设计解释：蓝灰钢笔线描统一街道和室内，奶白剪纸边、人像黑白照片、局部红色披萨与红酱制造异质组合；星空深底把纸边托亮。逐字纸块的字号和字体不同，粗糙感来自拼贴语法，但主词仍集中成一两行，避免到处散乱。红色大面积章节负责不安情绪，不宜长期叠在密集小字上。

迁移思考：适用于虚构故事、文化评论和档案式拼贴；本例人物面孔、诡异标注不能搬到事实报道制造关联。连续性来自位置、道具和绘画材质，不是单一对象始终变形。资产种类较多、恐怖意象强，迁移到普通知识片需减量并重新选择符号。
