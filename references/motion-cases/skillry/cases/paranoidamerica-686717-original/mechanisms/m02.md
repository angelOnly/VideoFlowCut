# 固定后层中前图逐次接替，底部短条逐字补齐

## 运动指令

保留完整后层，在前层接入一个图块，底部短条沿阅读方向逐字增加。下一图块在前层接替，后层保持，短条在同一承载位置继续更新，形成图到字、再到下一图的接续。
