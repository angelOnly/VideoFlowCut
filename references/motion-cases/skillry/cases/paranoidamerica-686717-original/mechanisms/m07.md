# 罩形前片提起斜转，内部主形由下显露

## 运动指令

保留下部承载面，将罩形前片先向上提起，再斜转到侧上方。内部主形在让出的范围中逐步显露，底层与旁侧文字位置保持，罩片最终离开主要视区。
