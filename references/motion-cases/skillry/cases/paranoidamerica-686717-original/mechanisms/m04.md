# 附属件在竖片前接入，竖片绕侧边打开显出后层

## 运动指令

先在完整竖片前补入附属件，再让竖片绕侧边转开，片面逐步变窄，后层空间显露并接管。转开期间附属件要明确跟随片面还是留在前层，原片可见关系是前件与打开动作接续。
