# 006 · 运动过程总览

## 运动总览

片头小字、标记和名称先后显出，接 [竖框从下方升入，顶部文字逐行接上](mechanisms/m01.md) 从底部建立竖框，顶上字组补齐。[推近竖框内部，活动画面接管全幅](mechanisms/m02.md) 将框内活动画面推近并接管全幅，原活动继续。全幅上 [固定字组内强调块逐项迁移](mechanisms/m03.md) 逐项移动文字强调。

之后换为横向轨道，[轨道横向经过固定竖线，局部条依次亮起](mechanisms/m04.md) 保留中部竖线，让下方图块和文字条向其经过；顶部短句复用逐词建立。换底后 [多列竖片逐格补入，先到者保持](mechanisms/m05.md) 逐格建立多列竖片，接 [大小面板按层级错开接入](mechanisms/m06.md) 在固定位置补齐大小面板。末段重新进入竖框，[内部片收小，进度环增长后接入完成标记](mechanisms/m07.md) 收小内部片并围绕它累计进度，完成标记接入，再退到标记与短行收尾。
