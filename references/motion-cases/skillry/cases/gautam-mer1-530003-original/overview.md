# 006｜原片运动总览

[观看完整原片](video.mp4)

## 运动总览

片头小字、标记和名称先后显出，接 竖框从下方升入，顶部文字逐行接上 从底部建立竖框，顶上字组补齐。推近竖框内部，活动画面接管全幅 将框内活动画面推近并接管全幅，原活动继续。全幅上 固定字组内强调块逐项迁移 逐项移动文字强调。

之后换为横向轨道，轨道横向经过固定竖线，局部条依次亮起 保留中部竖线，让下方图块和文字条向其经过；顶部短句复用逐词建立。换底后 多列竖片逐格补入，先到者保持 逐格建立多列竖片，接 大小面板按层级错开接入 在固定位置补齐大小面板。末段重新进入竖框，内部片收小，进度环增长后接入完成标记 收小内部片并围绕它累计进度，完成标记接入，再退到标记与短行收尾。

## 完整运动段落

以下按原片中的出现顺序引用。建立、内部发展及完成反馈放在同一段中；同时发生的局部动作与运镜写在同一份指令里。不同段之间可以是连续接管，也可以是直接切换，不能仅凭条目相邻认定可直接拼接。重复出现的同类运动采用一次连续代表范围，切片不以逐段无缝覆盖整片为目标。

1. [竖框从下方升入，顶部文字逐行接上](mechanisms/m01.md)：框先入位，字组随后沿上方空位累积

2. [推近竖框至满幅，强调块在固定字组中接力](mechanisms/m08.md)：推近先改变观看范围，满幅落稳后保持活动底层，强调块逐项迁移完成阅读引导。

3. [轨道横向经过固定竖线，局部条依次亮起](mechanisms/m04.md)：竖线保持，图块和条形向它经过

4. [多列竖片逐格补入，先到者保持](mechanisms/m05.md)：按空位连续补入，已有片不重排

5. [大小面板按层级错开接入](mechanisms/m06.md)：先建立上层宽片，再向下补入分区

6. [内部片收小，进度环增长后接入完成标记](mechanisms/m07.md)：内部内容缩小让出进度区，外框保持

切片保留起始准备、必要内部停顿和完成或明确交接；首尾省略无新发展的等待，持续运动不要求人为停住。以上基于真实源帧序列和重点边界核对，不等同于全片连续声画审片。
