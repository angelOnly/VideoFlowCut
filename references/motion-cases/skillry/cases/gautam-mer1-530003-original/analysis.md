# 006 手机中的人物与数字人展示

## 适用场景

展示人物字幕工具时，从编辑器环境进入同一素材的实际效果。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：产品介绍、操作教程、口播混合

- 段落场景：整体到局部、成果展示

- 原片实见素材：人物视频、手机界面、桌面界面、文字

- 动效方法：以人脸为锚点放大界面、框体离场让结果接管、功能短语逐行建立

- 美术特点：黑底竖窗、紫色重音、人脸与标题分区

- 材料要求：需要高分辨率编辑录屏、独立人物视频和真实字幕时序。

- 迁移代价：低清整屏不可无限放大，标题曾靠近脸，字幕逐词同步仍需音频核对；原速观感与声音同步未认证。

## 推荐观看片段

- 6.00—11.00 秒：手机放大后框体退去，同一人物成为主窗口，适合编辑到结果的交接

## 动效与美术拆解

把字幕应用的收益落到一个持续出现的真实人物镜头上。品牌开头后先见手机编辑器，再看视频本身及其字词强调，接着展示时间线、样式集合、多语言与导出。大部分画面是窄竖版内容置于黑色外侧，学习时应分清原内容画幅和下载文件的横向黑边。

直接观察的重点区间为 6.000—11.000 秒。6—7秒手机和上方两行标题稳定；7.067秒标题开始退暗，7.333—8.133秒手机逐渐放大，人物脸保持近似中央，外壳与时间线离开可视区。8.467—8.733秒界面退去，原人物镜头接管竖窗。8.8秒左上出现Listens，9.6秒加Writes，10.267秒粉紫色第三行开始进入。下方字幕同时改变强调词，但未试听，不能认证逐字同步。标题与脸在此区间一度接近，应作为迁移检查点。

美术的设计解释：黑底提供极强留白，紫色连接应用界面和字幕重音；人物衣服的浅绿图案与肤色提供生活感，白字和紫色词构成明确层级。后半段白底样式墙形成亮度对照。手机并不是装饰物，而是建立‘这段人物视频在何处被处理’的上下文，放大后才让效果成为主体。

迁移思考：适合录屏进入结果视频、功能演示进入实际素材的场景。迁移时先固定人脸锚点和媒体裁切，再做界面缩放；不能让标题逐步压到脸上。需要真实高分辨率录屏及独立视频，不宜拿低清整屏无限放大。

以黑底、单一紫色重音展示一段真实竖版人物素材。先把视频置于手机编辑器里，上方给出两行收益；收益退去后以人脸为视觉锚点放大手机，让边框和时间线逐渐离开，接为同一素材的纯视频窗口。随后在不遮脸的区域逐行建立功能短语，下方字幕只强调当前重点。再缩回时间线显示编辑关系，转入样式集合和导出。字幕时间需用真实音频校对，不能按本例截图推定。
