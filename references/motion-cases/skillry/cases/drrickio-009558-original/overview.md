# 005 · 运动过程总览

## 运动总览

开头 [字组逐层显出，旧行上移并被划线保留](mechanisms/m01.md) 让字组逐层建立与上移轮换，再由 [外围圆片围绕中心竖片建立，中心内容原位轮换](mechanisms/m02.md) 建立外围圆片及中心竖片，中心内容在原位更新。随后主标题建立，横框接入，[活动横框稳定，角落标签错开补入](mechanisms/m03.md) 保留活动图像而逐项补上角落标记。

中段进入固定窗口的输入与侧列选择，使用 [指示符到点后展开列表，选中后回到固定面板](mechanisms/m04.md) 移动指示符、展开局部列表并留下选中状态。[集合中选中项突出，其余退淡并交给独立框](mechanisms/m05.md) 将多列图块中的少量项突出，再退让给新的独立框；新框短暂扫描并更新内容。[多个窗口错开接入，局部活动画面扩大接管](mechanisms/m06.md) 连续补齐多个框与下方短条，再让其中活动图像扩为满幅，字组继续建立。

后段回到并置窗口，复用 [指示符到点后展开列表，选中后回到固定面板](mechanisms/m04.md) 的开关与局部更新，接 [多个窗口错开接入，局部活动画面扩大接管](mechanisms/m06.md) 在多个位置补齐面板。[多格面板分批填齐，内部条形与数字持续更新](mechanisms/m07.md) 让内部条形按项增长、计数趋停；最后小标记和大字接入，后层集合退淡，整组减淡收尾。主框内的持续活动和小幅提示不按出现次数拆成新卡。
