# 005 数字人画面与产品介绍

## 适用场景

先比较三种人物视频构图，再进入完整生活应用场景展示收益。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：产品介绍、口播混合、操作教程

- 段落场景：多来源对照、成果展示、跨场景接力

- 原片实见素材：人物视频、桌面界面、手机界面、文字

- 动效方法：并列示例窗口、短遮挡进入使用场景、换镜保留标题锚点

- 美术特点：黑蓝产品舞台、暖厨房影像、白蓝两级标题

- 材料要求：需要等高示例素材、使用场景镜头和可留给标题的画面区域。

- 迁移代价：新场景需重新安排脸与文字，集合并未真实变为厨房，价格与能力不能照搬；原速观感与声音同步未认证。

## 推荐观看片段

- 29.00—34.00 秒：三个构图示例换到厨房人物镜头，左侧标题在镜头更换时保留

## 动效与美术拆解

先提出主持人制作的困难，再显示人像、界面、示例成片与套餐。中段把真人形象从选择列表推进到实际场景，观众任务是理解呈现方式，而不是研究头像自身变形。整体是多个功能展示段落的镜头串联。

直接观察的重点区间为 29.000—34.000 秒。29—31.667秒标题下并排三种构图示例，下方时间线小标签逐个增加，媒体框保持对齐。31.733秒画面放大并模糊，31.933秒亮雾覆盖；32秒厨房人物镜头接管，32.133—32.333秒白色标题逐词出现，32.6—32.867秒蓝色第二行补齐。之后厨房镜头在32.467和33.467秒发生切换，但两行字仍保持左侧位置，人物脸和锅成为右侧与下方焦点。它是示例集合到使用场景的换镜，并非三小框连续变成厨房。

美术的设计解释：黑蓝底和浅青色统一前半产品气质，暗部让白色卡片人脸更突出；厨房段使用暖木与肤色恢复生活感。标题叠在偏暗区域、蓝色第二行对应主卖点，小标签与正文用显著字号差分层。并列窗口先提供比较，满屏场景后提供代入，两种布局承担不同观看任务。

迁移思考：适用于人物工具、拍摄服务、课程与产品的应用展示。参考重点是‘先比较构图，再进入实际场景’，并不是默认给人物加更多图层。实景中须重新确定文字可用区域，浅色背景可补局部压暗。案例里的价格和功能只是原片文案，不能直接迁移为事实。

资料身份与实现边界：公开输入是一般SaaS发布片需求，未列当前素材清单、完整分镜或源码。本轮公开仓库、详情页与输入核查中，未找到直接对应当前原作的固定源码；不能把Remake技术标签或需求中提及的工具当原作实现证据。本报告只解释可见关系，具体遮罩、曲线、图层及渲染方案若实施，属于新制作选择。核查范围见来源核查记录。
