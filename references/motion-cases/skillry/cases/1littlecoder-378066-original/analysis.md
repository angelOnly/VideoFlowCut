# 065｜影院空间、人物与字幕

[原作视频](../../cases/1littlecoder-378066-original/media/original.mp4) · [作者公开输入](../../cases/1littlecoder-378066-original/sources/published-prompt.md) · [来源页](https://skillry.dev/ai-videos/opus-5-5/1littlecoder-378066)

这支广告以寓言式剧场讲同一种声音和一个行动者打破屏幕。开头观众进入环形走廊，主厅里相同黑色人影面对巨大冷脸，橙色持锤人物穿过走廊进入中轴；巨脸不断发布短句，最后锤子命中，冷蓝空间被暖光打开，品牌文字留在黑底。内容采用动画剪影与数字面孔，不是新闻记录或真实人物演出；公开需求给出了既有广告参照，因此学习应抽取对比和动作逻辑，而非当作完全原创故事。

18—23秒密集帧中人物站在走道中央反复转动亮锤，巨脸占上方与背面，座椅人影固定前景。19.2秒短暂切脸部近景，随后回到全厅，20秒附近锤子朝巨脸斜上飞；约20.8秒撞点出现白亮与裂纹，21秒裂纹扩散并形成破口。镜头先贴近碎裂孔洞，孔内由白转暖橙；21.7秒退回原剧场，暖光从破口照入中轴和边缘座椅。原走道、人物和人群保留，结果发生在旧地点，颜色变化因一次具体行动获得原因。

蓝灰冷暗为全场主面积，黑色观众轮廓重复形成秩序，橙色人物和锤迹是最少量但最醒目的活色。中轴透视把行动者、路径和目标对齐，天花板环线、座椅边线和窗框都引向同一个后方中心。巨脸简化且表面有横向屏幕线，人物没有丰富细节，两种处理把权威与个体的关系夸大。破口暖光不仅换背景色，也让地面和人群边缘获得新光，空间因此整体改变。终段细斜体品牌句给激烈动作一段安静尾声。

可借鉴于需要一个明确行为带来环境变化的叙事：先建立秩序和异色行动者，再给可追踪动作，结果沿同一空间展开。用于本项目真实素材时，可用一条现实动作接到图形回应，而非先放爆裂特效再解释原因。代价是人物路径、剪影和目标关系必须可读，过大光晕会淹没命中与后果；仿现成广告的场景与桥段要重新构思。未试听不认证口型、锤击声音或音乐落点，成片是否令人紧张也需原速复核。
