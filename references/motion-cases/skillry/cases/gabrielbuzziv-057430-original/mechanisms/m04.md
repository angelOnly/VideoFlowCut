# 原图局部标框，副本逐项提入旁侧空槽

## 运动指令

先在原片内逐项标出局部范围，再在旁侧建立有空槽的面板。将各局部的副本从来源处提出，依次放入对应槽位，原片继续保留；已填槽不因下一副本到来而移动。
