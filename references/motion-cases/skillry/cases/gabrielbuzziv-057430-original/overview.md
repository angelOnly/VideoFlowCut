# 033 · 运动过程总览

## 运动总览

开场 [小格铺成倾斜集合，选出一排前移后换底](mechanisms/m01.md) 将小格从少到多铺成倾斜集合，随后选出一排前移，外围退淡并换底。[一排小格向竖框靠拢，由新框接手内部内容](mechanisms/m02.md) 让这排小格向新竖框靠拢，竖框接手内部内容。

竖框落稳后 [侧方短条逐项增加，虚线连接到固定框内局部](mechanisms/m03.md) 从侧方逐项追加短条，以虚线连向框内局部。整组推近退场，下一竖片用 [原图局部标框，副本逐项提入旁侧空槽](mechanisms/m04.md) 标出多个局部，再将局部副本填入旁侧面板。最后换入空空间，[空空间分批补齐部件，数值接续后完成反馈](mechanisms/m05.md) 分批补齐各部件，完成反馈出现后用亮闪退出，字组建立并保持。
