# 010 · 运动过程总览

## 运动总览

开头 [点阵中多数项退淡，少量点与数字保留](mechanisms/m01.md) 用数字与点阵从多项中留下少量重点。换底后 [片面错开扇出，再突出其中一片](mechanisms/m02.md) 将片面错开扇出，部分片退淡，再突出一片。中心标记建立后进入横框，[固定框内列表展开选择，旧区域保持](mechanisms/m03.md) 保持框边界，指示符到位后展开、选择、收回局部列表。

随后单框让位给新布局，[竖框与旁片建立，旁片内容接续更新](mechanisms/m04.md) 将竖框和旁侧小片并置，小片内容连续更新；接 [窗口内多条横线依次增长，末端结果留住](mechanisms/m05.md) 从大窗口内逐项增长条形，留下结果与旁侧短标。换入新的并置框后再回到列表，复用局部更新关系。

后段 [纵向句列上下经过，中央行清楚其余退淡](mechanisms/m06.md) 让纵向字列上下经过，中央行清楚，其余行退淡。独立字组建立后，[并列片面逐项接入，底部附属行随后出现](mechanisms/m07.md) 分批补齐并列片面；最终标记与说明接入，旁侧对话片逐条增字，复用逐项累计，不复制每次文字更新为独立机制。
