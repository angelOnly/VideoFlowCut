# 010 手机录音与人物视频窗口

## 适用场景

解释从采集回答到审核评估的流程，让原回答与评价项并列。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：产品介绍、操作教程、科普解释

- 段落场景：步骤累积、条件解释、成果展示

- 原片实见素材：人物视频、手机界面、桌面界面、图表、插画、文字

- 动效方法：三栏保持换转录内容、退旧组建立评分卡、评分条分批进入

- 美术特点：浅粉舞台、洋红状态重音、白卡统一圆角

- 材料要求：需要采集界面、回答片段、转录内容和真实评估规则。

- 迁移代价：手机人物部分为图形示意，评分需核实规则，界面小字不能靠缩屏读完；原速观感与声音同步未认证。

## 推荐观看片段

- 30.00—35.00 秒：录制三栏退去后，人物回答与评分卡建立，条目依次出现

## 动效与美术拆解

一条招聘流程解释广告，先用70人与3人的差距提出筛选问题，再沿设置问题、发链接、手机录制、查看评分和分享结果前进。手机录制阶段实际显示图形人物，不应把该部分叫真实人物录屏；后面的回答窗口才有人像画面。

直接观察的重点区间为 30.000—35.000 秒。30—33.333秒左侧短标题、中央手机和右侧转录卡形成三栏。右卡文字更换，但手机与左标题不动，观众看的是同一步录制的不同输出。33.4秒三栏一起退模糊，33.6秒评分标题在原上方区域建立；33.867—34.267秒宽白卡从下方显出，左为人物回答、右为空评分。34.467秒第一个粉色评分条出现，34.667—35秒后续条依次填入。这是步骤换场，人物窗与评分关联通过并列和顺序建立。

美术的设计解释：浅粉底把白界面与深色标题分开，饱和洋红用于步骤号、重点条与最后品牌整底。手机中的暖橙肤色和蓝色上衣提供与粉底的差异；回答卡里照片恢复细节，评分条仍沿用品牌色。阴影、圆角和统一对齐让不同来源界面形成一致层级。

迁移思考：适用于用户操作到审核结果的说明，不限招聘。迁移要判断人物窗口代表实见材料还是示意图，评分条也要绑定真实规则。文字多且界面小，手机端不能只靠压缩整屏；应局部放大，保证当前步骤一个重点。模糊转场会损失短暂读时，不要在信息未读完时启动。

资料身份与实现边界：公开输入是一般SaaS发布片要求，没有当前招聘素材、完整分镜或源码。本轮公开仓库、详情页与输入核查中，未找到直接对应当前原作的固定源码；不能把Remake技术标签或需求中提及的工具当原作实现证据。本报告只解释可见关系，具体遮罩、曲线、图层及渲染方案若实施，属于新制作选择。核查范围见来源核查记录。

本报告实际查看整片约每秒一帧概览，以及关键区间的密集真实源帧；时间来自源PTS。基于带源时间图片序列，未核验原速观感，未试听，因此不认证整体流畅度、音乐拍点、对白连续或声音同步。概览不足以证明其他快速接续；300像素证据单帧中的小字、边缘精度仍需全尺寸核验。

## 实现建议（研究后写，未制作验证）

状态：研究者后写、未制作验证；不是作者原输入，不是原作源码，也未证明能够逐帧复刻。依据为拆解报告及其中列明的源帧证据。

制作一个从采集回答到评估的流程段。浅粉底上设置左解释、中央手机、右转录三栏，手机内保留真实来源或明确标为示意的素材，切换转录内容时保持框架不动。录制步骤读完后让三栏短暂退暗或遮挡，顶部进入评分任务，宽白卡展开为左人物回答与右评估项。先有评估标签，再分批增长洋红条，最后进入分享页面。确保每步只突出一个操作，避免把示意评分当事实。

首版实施时先用本片真实内容、素材和画幅重新确认对象关系与阅读量，再拟时间；原片关键区间30—35秒只作观察参照，不强制套用其总时长或品牌。图层、遮罩和曲线可按新工程实现，参数不得标为作者原参数。完成后需原速查看、检查中间帧和全尺寸文字；有声音时另做试听及同步核对。
