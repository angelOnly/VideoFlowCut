# 092 · 运动过程总览

## 运动总览

全片从圆柱近景开始，以[圆柱持续转角取景逐步抬到顶部](mechanisms/m01.md)持续转角并逐步抬高观察位置。到顶部局部后，[顶端小片向内翻下开口向上扩散](mechanisms/m02.md)让小片向内翻下，开口接出向上扩散的点与模糊团，进而换到底层更宽的视野。

中段[多张圆薄片绕中央形前后经过并自转](mechanisms/m03.md)让多张圆薄片绕中央形前后经过，中央形继续复用[圆柱持续转角取景逐步抬到顶部](mechanisms/m01.md)；[下部块层逐次加入与原薄片共同经过](mechanisms/m04.md)再从下部加入块状层，与原薄片一起经过。末段[外围层退去后底接替中央形保留并补字行](mechanisms/m05.md)退去外围层并接替后底，中央形保持，结尾字行分段建立；需要外围更丰富时再次复用[多张圆薄片绕中央形前后经过并自转](mechanisms/m03.md)。
