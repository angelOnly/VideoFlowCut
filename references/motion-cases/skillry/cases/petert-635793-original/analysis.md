# 092 饮料罐与明亮产品舞台

## 适用场景

用开罐、倒液或开包装的具体使用动作引出产品的口味与体验卖点。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：产品介绍、品牌展示

- 段落场景：整体到局部、跨场景接力、重点强调

- 原片实见素材：三维、文字、抽象图形

- 动效方法：使用动作引出感官、局部拉远给产品全貌、包装色接管舞台

- 美术特点：黄绿包装与成分呼应、金属高光区分材质、边缘水果留中央标签

- 材料要求：需真实商品或准确模型、符合器物的使用动作及核实的成分和短卖点。

- 迁移代价：原片为合成商品表现，开口结构未作工程认证；水果气泡不可遮住品牌；原速与声音未认证。

## 推荐观看片段

- 6.00—11.00 秒：罐口出现开口和气泡，随后拉远为整罐与柑橘舞台，动作结果接产品卖点。

## 动效与美术拆解

作品是一条虚构柚子汽水竖幅产品广告。开头罐身近景几乎占满画面，先让观众认识黄绿包装与金属罐口；镜头上移展示开罐，气泡出现，随后拉远进入柑橘切片包围的明亮舞台，呈现香气、清爽和碳酸等短卖点，再以完整罐与产品名结束。主体一直是同一套罐形和标签，段落变化围绕一个生活动作展开，比不同瓶图轮播更有体验因果。现实材质是3D或合成表现，非已验证实拍商品素材。

6—11秒密集区间显示罐口从斜侧视逐步转为较正的俯视，约6.97秒黑色开口出现，‘プシュッ’字样和上升白雾建立开罐意象。白圆气泡随后增多，罐口仍居中心；8.7秒罐身开始显出，8.9秒拉远到完整罐，9.0秒发生短暂亮色遮蔽，9.13秒明黄绿背景和多片柑橘建立。罐体尺寸缓缓调整，下方文字补足香气句子。连接点是罐口动作带来气泡和香气，再以拉远给商品全貌和卖点腾出空间；中间亮闪不是物体变形，无法据图组证明真实开罐机械结构。

美术把包装色用作整个舞台的色源。罐身浅黄、标签深绿，柚子切片浅黄白，背景亮黄绿，因此主体与环境属于同一味觉联想。亮底上深绿字承担阅读，金属罐口以强白高光和暗侧面区分材料；前半紫红暗底让银边和冷凝水易显，后半亮底让清爽意象接管。切片沿画面边缘和罐两侧分布，中央标签尽量留空，避免气泡和水果掩盖品牌。字幕区域固定在罐下，镜头完成后才增大文字层级。

迁移方法是‘一个真实使用动作引出一套感官舞台’，适合食品、护理、生活产品。应先取得真实商品或准确模型，动作要符合器物，不能把原片矩形拉片示意当标准罐口。素材混合时可以保留真实开罐或倒液，再让包装主色与成分图形接续，但需重新定遮挡和光。小字号标签不必全部让观众读，必须区分商品本身印刷与广告关键文案。亮闪和泡沫适度即可，过多会削弱产品身份；本轮没有试听，拟声字存在不证明声音配合已通过。

本轮依据整片约每秒一帧概览，以及6.000—11.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。

## 实现建议（研究后写，未制作验证）

研究者依据原作观察后写，非作者原始输入，未制作、未渲染验证。用于重新设计相同关系，不承诺复刻原片。

制作饮料或生活产品短片，先用实际商品近景建立标签与材料，再沿同一主体推进到一个可验证使用部位。动作完成时出现少量符合物性的气泡、雾或液体，再沿同一方向拉远到全貌。将包装的一种主色扩为背景，成分图形沿边缘分布，中央标签和下方短卖点留空；每段只出现一个短主张，动作停稳后再读。结尾完整商品与名称。避免复制虚构口味、标签和夸大参数。

实施时先完成关键构图，再制作接续，按真实输出核对阅读、遮挡、对象身份和空间方向。使用绝对时间控制并保存可编辑源码；这些是新制作要求，不能当成已取得的原工程。涉及事实、品牌、人物、数字和素材时需使用本片已核实输入。无声首版先看画面，再依据实际音轨安排声音。
