# 100 手机到芯片与原子尺度

## 适用场景

用熟悉设备内部的连续推进引出一个微观结构问题或科普片头。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：科普解释、品牌展示

- 段落场景：整体到局部、跨场景接力、空间关系

- 原片实见素材：三维、抽象图形

- 动效方法：中央目标持续推进、重复结构改变尺度、高光遮蔽模型交接

- 美术特点：灰银与棕铜材料分层、彩色小中心导视、密阵列建立微观感

- 材料要求：需准确层级与空间关系，补层名、尺度和过渡理由，宏观实拍与微观示意分清。

- 迁移代价：原片缺连续层名，易只感到越来越小；高光是编辑接点而非真实物理进入；原速与声音未认证。

## 推荐观看片段

- 12.00—17.00 秒：晶体管式结构放大后高光覆盖接材料球格，红白中心保持观察目标，显示尺度接续及其解释缺口。

## 动效与美术拆解

这条约22秒的三维旅程从桌面拆开的手机开始，进入主板中的芯片、彩色模块、规则单元、布线、晶体管，再到球状晶格和中央原子核示意。几乎没有承担解释的标题，观看任务主要是体验熟悉物体内隐藏的尺度层次。开头手机后盖和工具建立现实入口，后段模型密度从矩形阵列到球阵列提高，以相近透视和中心目标维持方向。它不是真实拆机或显微拍摄，物理准确性需要另外核查。

12—17秒密集图组从晶体管样式的灰色结构继续推进。棕色顶块、灰竖片和横向薄层始终保留相对位置，13.5秒出现一串白亮小点横向经过结构，14.3秒镜头靠向材料表面，密集灰球格逐步清楚，上方红白黄球层成为材料分界。15.3秒接触点高光扩大，15.5秒切到更深的灰球晶格，镜头继续靠近中央一个灰色长形部件及红白小球团。高光遮蔽减少了跨尺度模型替换的可见边界；这是视觉接续，不能由图组证明它是一套无换景连续物理模型。

美术前段暖棕桌面承托黑手机，内部绿主板与少量彩色模块区分功能位置。进入细胞式阵列后使用灰银主体和棕铜纵向结构，让几何方向比彩色噪点更突出。原子段灰球的高光与暗缝提供密度和深度，红白中心作为唯一彩色目标，蓝白小光点承担电性或能量联想。大面积反光会减弱连接结构的可见度，需避免用发光遮掉本应解释的过程。原片没有连续尺和层名，视觉震撼强，但观众可能只感到‘越来越小’，难以说清每层是什么。

迁移时可保留同一中心持续推进、重复结构逐步改变颗粒尺度的方法，同时补少量层名、尺度和过渡理由。若讲手机屏幕，不能把后盖内视角当屏幕微观路径；每次从部件到材料都要核实空间关系。适合片头或概念体验，若用于严肃科普应减慢关键边界并区分宏观实拍、结构图解与原子类比。中央目标不断保留有助追踪，但亮闪只是编辑手段，不替代真实材料来源与机制解释。当前图组没有原速观感或全部微观细节认证。

本轮依据整片约每秒一帧概览，以及12.000—17.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。
