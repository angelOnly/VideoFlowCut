# 048 · 运动过程总览

## 运动总览

开头字组分项建立，下方小形从边缘接入。[分散气泡逐项增加，角上数值增长后整组退虚](mechanisms/m01.md) 将短气泡从少到多铺在分散位置，角上数值增加，之后整组退虚并收向中心。字组逐行建立，[竖框侧下接入，原字退弱后新旁字分行建立](mechanisms/m02.md) 从侧下接入竖框，原字退弱，新的旁字补齐。

中段 [框内局部片前提，小标记逐项增加](mechanisms/m03.md) 将框内局部片提到前层，片内小标记依次增加；[框内气泡逐行补入，旁侧列表按同一推进追加](mechanisms/m04.md) 让固定框内气泡分行补入，同时旁侧列表逐项建立。下一竖框接管后，局部下片再次外提。[多个竖框错开展开成扇形，顶部短标签随后补齐](mechanisms/m05.md) 把多个竖框错开展开成扇形群组，上标签逐项补齐。末段群组退出，后层接手，字组与附属条逐项建立，小形再次从下边缘接入保持。
