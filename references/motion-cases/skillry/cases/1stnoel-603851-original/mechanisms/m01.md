# 固定片面小横块逐行累积，旁侧数值后接

## 运动指令

保留片面和小块位置，从上向下逐行改变小横块的可见状态，已完成块保持。填充推进后在旁侧接入数值，让数值增加到稳定结果，再补说明行。

## 组合与调整

不必完全填满，按新材料确定终点。填充顺序与数值可以关联，但不虚构一一对应。
