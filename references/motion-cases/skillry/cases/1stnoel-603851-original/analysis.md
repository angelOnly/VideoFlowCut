# 39. 手机阅读、文字与语音：动效与美术拆解

让读者从整体段落中选择一个陌生词，再看词义和上下文，最后保存。手机保留全文，外部放大词卡负责可读解释，动画服务学习任务而非只做文字装饰。

直接观察的重点区间为 23.000—28.000 秒。23—24.133秒右手机全文与左Tap any word稳定，24.2—24.333秒手机内词义区出现，左侧同词卡同时从淡到清楚建立；手机原文仍保留。25.2—25.6秒左词卡下方加入含同一词的原句，该词暖黄高亮。26.933—27.2秒左上标题改为保存说明，原句退去，词卡下方建立暖黄保存状态；27.2—28秒手机原文与左词卡一起保持。外卡与手机内卡共同内容明确，但不能凭这些帧声称卡从手机位置飞出。

美术的设计解释：奶纸底、黑细衬线和小暖黄高亮接近阅读材料，几乎不增加外部装饰。右手机稳定在约中右位置，左信息区按标题、词卡、句子或状态竖排，阅读层级清楚；保留原文避免解释脱离上下文。

迁移思考：适合术语、新闻句子、产品条款与学习讲解；引用原句必须忠实且可回看出处。短词能放大，长中文术语卡须重新分行，不需复制英文拼写比例。手机文本较小适合建立上下文，关键证据必须另放大，不把整页当一次可读材料。
