# 039 手机阅读、文字与语音

## 适用场景

讲术语、新闻句子或产品条款时，保留全文并放大要解释的局部。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：科普解释、新闻解读、操作教程

- 段落场景：整体到局部、条件解释、重点强调

- 原片实见素材：手机界面、文章页面、文字

- 动效方法：全文与解释卡并置、补原句高亮目标词、保存状态替换说明

- 美术特点：奶纸黑衬线、小面积暖黄、右来源左解释

- 材料要求：需要准确原文、词义或解释、引用范围与真实状态或明确示意。

- 迁移代价：未见词卡飞出路径，不能推断精确移动实现，长中文需改行且关键证据另放大；原速观感与声音同步未认证。

## 推荐观看片段

- 23.00—28.00 秒：全文保留时词卡显出，原句随后加入，保存说明再替换原句

## 动效与美术拆解

让读者从整体段落中选择一个陌生词，再看词义和上下文，最后保存。手机保留全文，外部放大词卡负责可读解释，动画服务学习任务而非只做文字装饰。

直接观察的重点区间为 23.000—28.000 秒。23—24.133秒右手机全文与左Tap any word稳定，24.2—24.333秒手机内词义区出现，左侧同词卡同时从淡到清楚建立；手机原文仍保留。25.2—25.6秒左词卡下方加入含同一词的原句，该词暖黄高亮。26.933—27.2秒左上标题改为保存说明，原句退去，词卡下方建立暖黄保存状态；27.2—28秒手机原文与左词卡一起保持。外卡与手机内卡共同内容明确，但不能凭这些帧声称卡从手机位置飞出。

美术的设计解释：奶纸底、黑细衬线和小暖黄高亮接近阅读材料，几乎不增加外部装饰。右手机稳定在约中右位置，左信息区按标题、词卡、句子或状态竖排，阅读层级清楚；保留原文避免解释脱离上下文。

迁移思考：适合术语、新闻句子、产品条款与学习讲解；引用原句必须忠实且可回看出处。短词能放大，长中文术语卡须重新分行，不需复制英文拼写比例。手机文本较小适合建立上下文，关键证据必须另放大，不把整页当一次可读材料。

资料身份与实现边界：公开输入是一分钟教育视频、产品网址和合成旁白要求，没有详细画面安排或原工程；本轮未试听，不能认证合成语音或逐词同步完成。本轮公开仓库、详情页与输入核查中，未找到直接对应当前原作的固定源码；不能把Remake技术标签或需求中提及的工具当原作实现证据。本报告只解释可见关系，具体遮罩、曲线、图层及渲染方案若实施，属于新制作选择。核查范围见来源核查记录。

本报告实际查看整片约每秒一帧概览，以及关键区间的密集真实源帧；时间来自源PTS。基于带源时间图片序列，未核验原速观感，未试听，因此不认证整体流畅度、音乐拍点、对白连续或声音同步。概览不足以证明其他快速接续；300像素证据单帧中的小字、边缘精度仍需全尺寸核验。
