# 框内旧行列退去竖条从共同底部增长

## 运动指令

保持外框，旧行列先退去，多个竖条从共同底部逐次向上增长，先条接近终点时后条接上。高度不同的条完成后保持，上方短值最后建立，框旁主行不移动。
