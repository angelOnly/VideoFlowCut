# 102 发动机、磁场与标注

[原作](../../cases/stefanostraus-971191-original/media/original.mp4) · [作者公开资料](../../cases/stefanostraus-971191-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

这条录屏围绕两套动力装置做可交互比较：左侧活塞结构、右侧较小的电磁式部件共享一个基座，画面可改变转速、拆开部件、切换观察点；后段转到磁性液体样式的容器。开头近看活塞，随后退到两装置全貌，反复改变参数和展开程度，再重新靠近活塞。它主要展示模拟器能力，观众任务是同时比较原理与操作效果，未必具有广告式单一故事终点。

8—13秒密集图组显示两装置保持固定左右关系，右上滑杆与左上数字面板持续；约9秒左侧上层开始升高，与下层活塞分离，9.4秒间距增大，右侧也显出更多层次。10—11秒展开结构保持，随后11.4秒左右上层回落，两装置在12秒恢复接近初始形态。基座与轴向关系在展开、复合中不变，观众可把拆开的零件对应回原位置。小规模对比画面同时有文字、曲线与机械运动，本轮未逐个读取所有数字，也不依据图片认证同步轴速或能量效率。

深蓝黑舞台和近黑基座让金属活塞亮边显出，左侧红橙内部火光与右侧紫红部件区分作用，标题中蓝色词强化比较关系。小白标签与参数框是功能层，主要聚集两上角，主体在中央下部，因此视线能在数据和物体间往返。模型实际较小，外围面板占比高，有利于操作却可能降低视频解释力度。进入近景后材质的银高光、暗侧面、连杆与曲轴重复节律成为美术重点，而不是随意添加粒子。

可迁移的是在同一空间内保持两对象、一次改变一个条件、让前后可比较。爆炸图要保留共同轴和基准平面，展开距离服从部件关系，不能为漂亮把机械随意飞散。固定视频可删去鼠标等待和多轮滑杆操作，先明示比较条件，再近看各自因果；自由交互和演示录屏不能直接作为严谨性能证明。磁性液体段是另一观察对象，需新建立标题和因果，不能仅因同暗色舞台就视为同一设备接续。本轮只观察图形状态、装配变化和相对位置，未核验物理公式或原速机械节律。

本轮依据整片约每秒一帧概览，以及8.000—13.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。
