# 外围圆点逐项亮起，中央数字增长后引用卡接入

## 运动指令

在固定圆阵中逐项点亮小圆，中央数字同步增长并趋停。结果建立后补入前景引用卡，外围圆阵变模糊退后，数字仍留作上方参照。
