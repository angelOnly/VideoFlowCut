# 009 · 运动过程总览

## 运动总览

开头 [外围卡片错开补齐，中心文字保留后集合散开](mechanisms/m01.md) 将外围卡片逐项补齐，中心文字建立后让集合散开。[小块分别落入固定槽，组合成中心结构](mechanisms/m02.md) 让小块归入固定空位并组合成中心结构，再由 [重复块铺满画面，借覆盖揭出新布局](mechanisms/m03.md) 把重复结构铺成满幅，借覆盖换入下一组。

中段先建立并置小框，[主框保持，旁侧内容片依次接入](mechanisms/m04.md) 保留主框、从旁侧逐项补入内容片。[外围标记绕中心进入，再收拢退去](mechanisms/m05.md) 使外围小标记绕中心进入，再收拢退去，中心留场。接着进入多处大框，[固定外框内轮换排布，拉远后展示集合](mechanisms/m06.md) 在同一边界内轮换不同内部排布；再拉远为满幅集合，前方标题和小形保留。

后段多排短条横向经过。数字段 [外围圆点逐项亮起，中央数字增长后引用卡接入](mechanisms/m07.md) 将外围小圆逐项亮起，数值增长后停稳；前方引用卡建立时外围退虚，最后回到中心字组与小形。片尾小形附近短片散出，作为完成反馈，不另加重复机制。
