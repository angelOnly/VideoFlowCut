# 案例 009：拆解范围与媒体核验

原片约 55.424 秒。样稿将 0–11.5 秒的评价问题与品牌入口、11.5–26 秒的收集与审核、26–41.5 秒的版式与页面前后、41.5–50 秒的群体规模与单条证言分别作为四个完整表达。50 秒以后主要是品牌标识和行动提示，没有单独建卡。

本次查看整片 64 帧总览及四张九宫格；未独立完成连续原速观看和听审，未核实片中评价、数量和功能。四段复用既有创意切片，源片对应帧和切片画面逐帧比对的平均 PSNR 分别约为 50.65、49.73、48.73、49.31 dB；音频相应范围在 8 kHz 单声道比对中相关系数为 0.9989–0.9994，最高相关位置均为 0 毫秒。这是技术一致性核验，不代表声音听审。
