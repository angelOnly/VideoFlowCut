# 009 人物评价与内容墙

## 适用场景

将分散反馈整理到展示模块，再转为有来源的规模总结。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：产品介绍、新闻解读、品牌展示

- 段落场景：步骤累积、集合聚焦、成果展示

- 原片实见素材：人物视频、照片、桌面界面、图表、文字、抽象图形

- 动效方法：扫线显示评价模块、品牌砖块铺满再散开、中央数字依次建立

- 美术特点：灰白与浅青、头像退外围、粗标题配斜体重音

- 材料要求：需要真实评语、头像或视频、对应网页和统计依据。

- 迁移代价：素材墙不证明访客量，砖块需与品牌有关，细小评语要另放大；原速观感与声音同步未认证。

## 推荐观看片段

- 39.00—44.00 秒：评价卡被扫描建立后，青砖遮挡换到头像围边与两组统计

## 动效与美术拆解

将分散的用户评价组织成收集、审核、展示和规模证明的故事。人物头像及小视频是证言入口，网页是承载位置，青绿色砖墙和小吉祥物串起品牌，整片不依赖一直展示完整网页。

直接观察的重点区间为 39.000—44.000 秒。39秒网页中评价区为空；39.333秒青色竖扫线从左侧经过，39.533—39.8秒评价卡依次进入、恢复完整模块。40.067秒底部模块标签切换，41秒青色砖块从下沿上升，41.2秒覆盖整画幅。41.467秒砖块开始散开，41.733秒基本露出头像边框的新场，中央数字随后建立。42.333秒左侧10000稳定，42.533秒第二组数开始进入，43.467秒50000稳定。注意力先从界面关系转为大数字，头像退为环绕语境。

美术的设计解释：灰白底与浅青光保持清爽，黑色粗无衬线承担事实式标题，青色斜体承担语气变化。青砖既是品牌标志的组成，也能大面积遮挡场景，因此转场来自美术物件自身。头像只在外围，中央留白保证数字可读；大量头像只是群体氛围，不与数值逐一对应。

迁移思考：适用于采访反馈、素材档案、案例口碑与新闻资料聚合。借鉴的是碎片到模块再到总览的组织，真实评语、头像授权和统计来源要重新核查。砖墙转场若与内容无关系会显得机械；中文斜体可读性及大小数值间隔需要重做。

资料身份与实现边界：公开输入为一般发布片方向，网站名被占位，缺真实输入资产、实施指令和源码。本轮公开仓库、详情页与输入核查中，未找到直接对应当前原作的固定源码；不能把Remake技术标签或需求中提及的工具当原作实现证据。本报告只解释可见关系，具体遮罩、曲线、图层及渲染方案若实施，属于新制作选择。核查范围见来源核查记录。
