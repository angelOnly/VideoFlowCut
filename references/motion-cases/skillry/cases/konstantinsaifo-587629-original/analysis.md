# 101 聚变装置剖开与实验室交互演示

## 适用场景

先认识完整实验或产品装置，再打开外壁观察一处内部结构。

- 原片形态：网页交互演示

- 适用视频类型（迁移建议）：科普解释、产品介绍

- 段落场景：整体到局部、空间关系、条件解释

- 原片实见素材：三维、桌面界面、文字、抽象图形

- 动效方法：外壁开口允许观察、基座与环境定位持续、内光引导观察焦点

- 美术特点：金属冷色与暖实验室、粉色内腔重音、开口厚度与接触暗部

- 材料要求：需准确装置结构、原理和参数，准备整体与开口模型或注明示意的内部图。

- 迁移代价：腔体发光不能证明温度和性能，控件自由停留需变为阅读段；科学事实需另核实；原速与声音未认证。

## 动效与美术拆解

这是一处实验室中的聚变装置交互演示。球状金属容器站在圆形基座上，之后外壁打开露出粉色发光腔体，镜头贴近内部；侧边文字与参数改变，再转到左侧实验台上的小装置，最后回到整机和实验室全貌。观看任务是认识装置和可操作观察方式，不是一个器物自动变为下一物体的短动画。环境空间持续、设备旋转与剖开是主要关系，控件和说明卡承载了较多知识内容。

3—8秒密集序列里初始金属球体保持完整，3.8秒左侧外壁开始向外退开，4秒开口出现，白亮边缘先提示内部深度，4.2秒粉色腔体可见；4.5秒两侧开口都建立，中间竖向结构仍保留，直到8秒镜头才进一步靠近。打开过程中基座、后景灯、管线不换位，所以能识别同一设备。这是先解除遮挡、再允许局部观察；发光腔体不需要爆炸式飞入，它来自已建立体积内。只凭图组不能确认结构准确或温度变化的物理模型。

银亮金属、深灰外壳、青色电路细线与粉色内光形成设备层次，棕木竖条和暖灯给实验室背景一点生活尺度。圆台黄色环与主设备轮廓呼应，使重心居中；设备开口时前后金属厚度和接触暗部说明外壁有体积。粉色亮面面积一旦增加便会成为最强焦点，因此说明卡需放到旁侧稳定区，不能叠在内部高光上。背景还有壁挂剖面与台上设备，虽丰富，但若全部同亮同动会降低当前观察点的清楚程度。

可迁移‘有上下文的器物开口观察’，适合装备内部、实验流程和产品维修。需要先给整体、开口边界、局部，再看参数或功能；外壳离场应保留装配方向与基座参照。交互环境中可以自由暂停，视频化需要单独规划短文阅读和一次只改一项参数。作者涉及千万度和城市点亮的描述属于来源文本，不能被这段视觉自动认证；聚变教学还需真实科学资料。素材只有外观时可借鉴开口后使用图解，但须清楚声明示意，不能把原片的高光和粉色腔体当现成事实证据。
