# 内部细线围共同局部弯曲绕行并逐次接续

## 运动指令

内部先建立一条弯曲细线，让其围共同局部改变弯曲与倾角。后线错开加入，已有线继续绕行，部分线退弱后新线接上；小点沿线附近经过，外层边界与中央参照始终保持。
