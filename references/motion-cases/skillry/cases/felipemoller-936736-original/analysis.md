# 058｜竖屏消费过程与物体拆解

[原作视频](../../cases/felipemoller-936736-original/media/original.mp4) · [作者公开输入](../../cases/felipemoller-936736-original/sources/published-prompt.md) · [来源页](https://skillry.dev/ai-videos/opus-5-5/felipemoller-936736)

竖屏财务产品片使用三个微缩生活场景展示三种记账输入：市场语音、加油站拍凭证、餐馆打字。每个场景重复标题在上、立体小舞台在中、输入与结果卡在下的顺序，最后汇入完整列表和品牌。观众无需看完整软件操作，只要理解现实消费与记录条目的对应。它包含场景和凭证画面，主环境仍是设计的小模型，不能视为实拍生活素材。

7—12秒密集图见市场记账卡已完成并停在下方；8.4秒附近卡和标题先淡退，舞台继续保持。8.7秒市场架子开始收起，棋盘式地面局部转动、掀起，原来的周围墙面和圆盘范围基本保留；9.1秒加油站棚顶在相同区域建立，随后招牌、泵和小物件补齐。新标题稍后出现，车到站内；凭证卡在概览约13秒才接入。退出、场景重建、下一种输入分成几步，旧消费结果没有与新操作相混。图组支持空间延续，不推断具体三维骨架。

浅紫近白底占大面积，淡黄地砖和灰紫围墙让微缩舞台获得温柔物件感，饱和紫只留给地点标签、数额与产品控件。物件有可见厚度及软影，但主空间不依赖复杂写实纹理；黑短标题与白卡片给立体物体一个清晰的信息上下文。圆盘既是构图边界也是换景参照，观众可见内容换了却仍在同一展示台。底部卡按输入或结果变化而位置不乱。

适合多场景同功能、不同输入方法或同一消费旅程。迁移时先决定哪些是不变底座，哪些是替换布景；保留空间有意义，比每段从空白重新入场更连贯。但市场、加油站、餐馆模型制作成本高，若用真实照片或短视频，可以放在同一圆角视窗，并保留底部实际记录卡对应消费事实。不能把示意金额、凭证照片或演示成功当成真实交易证据；小票细节需单独核验，标题与输入方式也需按实际功能改写。
