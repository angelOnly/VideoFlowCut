# 120 图形角色与数据排版

[原作](../../cases/mtvneo-148436-original/media/original.mp4) · [作者公开资料](../../cases/mtvneo-148436-original/sources/published-prompt.md) · [后写复现设计](replication-brief.md)

作品将橙色太阳形角色贯穿自我介绍、timing与easing、三维弹动、流体、粒子、图表、时间线、像素和品牌落点。观看任务是认识一个角色的多种表现能力，橙色、两只黑眼和放射轮廓在风格切换中保留身份，比每段重新换主角更容易追踪。图表和时间线表现制作语汇，没有真实数据或工程输入可核验；旁白式字样也不能证明使用了相应工具。

5—10秒密集图组先在浅底读timing，5.25秒字母落散并重新排成easing，到5.5秒完成。5.58秒文字向左抹出，角色留在中间；5.8秒脸出现体积与光影，6秒完整三维星落在格地上并投影，6.17秒压扁，6.25秒回升。6.5秒地面退，6.67秒脸变为软团和侧面点，7.17秒重聚星，7.33秒辐射边缘碎成滴，7.42秒暗底从外缘接管，7.58秒粒子放射后再成脸。8.25秒点流转为竖杆，8.5秒柱图建立；8.92秒角色移到水平线上，9.17秒时间线与波形出现，9.33秒向左抹出仅留竖线，随后转浅底轮廓星和蓝色像素星。

美术以角色身份支撑材料变化：平面橙满色、三维暖高光与地面投影、流体边缘和粒子密度都保留脸的重心；到像素段颜色改变但星形及眼睛仍可识别。浅底文字黑且粗，暗底粒子则用亮暖色，最高对比随主材料转移。格地提供体积参照，退出后空间解释让位于流体动作；时间线的灰圆角面板临时充当容器，退场剩竖线减少换场负担。画面大多中央聚焦，边角标签维持技术气氛，短词比长句更符合这种快变化密度。

可迁移‘保留可识别角色，让不同表现方式服务同一主题’，适合栏目主持标志、品牌和功能介绍。解说片应只选与论点有关的材料变化，不要为展示而不断切风格；眼睛、颜色、轮廓至少保留一个稳定组合。实拍融合可让角色指向素材或成为标注入口，但本例不能证明其真实视频跟踪能力。图表需真实数值，波形需真实声音，否则只作为图标。三维压缩和流体不能据画面推定物理模拟。新制作仍需原速观看角色身份、稳定阅读和退出残留，图组尚未认证这些观感。

本轮依据整片约每秒一帧概览，以及5.000—10.000秒的真实源帧密集序列。未原速播放核验流畅度，未试听核验声音同步；其余区间未密集审阅，源帧之间的运动不作逐帧认证。关于绘制对象、缓动曲线和代码组织的说法仅为复现建议，不能据画面证明原实现。

作者资料核对：公开页提供完整高层15秒动效需求：将自己人格化并介绍Opus 5.5，未标节选；没有逐场编排、固定源码或实际参数。 平台列出的“Remake built with”描述复刻版本，不能证明原作技术栈；本案例不声称已有原作者源码。
