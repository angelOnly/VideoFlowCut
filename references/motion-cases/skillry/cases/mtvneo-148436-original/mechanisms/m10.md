# 同底线柱段持续升降上方短项依次累计

## 运动指令

保持每根柱段的格位与底线，各段错开升高或回落，柱顶参照短线随对应高度调整。小形在柱组上方经过，上方短项依次累计，已建立项保持；柱高继续变化时上方布局仍稳定。
