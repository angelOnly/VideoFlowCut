# 038 粉色手机与数据标记

## 适用场景

解释记录服务时，从完成状态接到日历，并把不同记录类别引到页外。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：产品介绍、操作教程、科普解释

- 段落场景：步骤累积、条件解释、跨场景接力

- 原片实见素材：照片、手机界面、图表、文字、抽象图形

- 动效方法：新旧手机叠入交接、日历标记逐行建立、标题与旧组同退

- 美术特点：粉薄荷紫渐变、深衬线配粉斜体、左上标题右下手机

- 材料要求：需要实际日记录与日历界面、准确类别和对应标签。

- 迁移代价：健康预测与已发生记录须区分，原片新旧手机层叠而非同一框变形，小字需核验；原速观感与声音同步未认证。

## 推荐观看片段

- 8.00—13.00 秒：完成弹层接日历手机，三个标记依次建立，再叠入下一用途页

## 动效与美术拆解

从日记录完成转到周期日历，再到音乐用途，以同一手机和淡彩舞台呈现身体记录服务。手机真实外观界面与场外标记关联，小花瓣只补充氛围。

直接观察的重点区间为 8.000—13.000 秒。8—8.4秒完成弹层稳定，8.467—8.8秒新的日历手机从下方前景移上，旧手机和标题淡去，新手机略有倾角后停稳。9.2—9.333秒第一个标记在手机左侧接日历行，9.467—9.533秒右侧第二个标记出现，9.667—9.8秒第三个左标记建立。9.8—12.6秒维持日历、三标记与标题阅读；12.667—12.933秒下一首页手机从右下叠入，旧场减淡，新标题开始出现。不是单个手机内容完全形变，而是新旧手机层叠交接。

美术的设计解释：粉、薄荷绿、浅紫渐变给阶段柔和统一，近黑衬线标题加粉斜体只强调一个词；日历与外标记复用粉/绿语义颜色，帮助指向对应条目。手机偏画面右下而标题左上，给伸出的标记留宽度；窄竖版中花瓣保持小而淡。

迁移思考：适合健康产品、记录页面与数据注释。医学新闻必须区分预测与已发生记录，装饰不应暗示准确性；界面实际文字和外标签需另在全尺寸核验。弱粉字背景适合品牌广告，长正文需加强对比，不能只追求柔。

资料身份与实现边界：公开输入要求利用本地ads视频/截图，并限定JavaScript、Playwright、FFmpeg及产品网址；本地素材未公开，指令很短，缺逐镜头安排，不能由Remake标签认定原作代码。本轮公开仓库、详情页与输入核查中，未找到直接对应当前原作的固定源码；不能把Remake技术标签或需求中提及的工具当原作实现证据。本报告只解释可见关系，具体遮罩、曲线、图层及渲染方案若实施，属于新制作选择。核查范围见来源核查记录。
