# 38. 粉色手机与数据标记：动效与美术拆解

[原作](../../cases/andre-lucaxxs-846347-original/media/original.mp4) · [来源](https://skillry.dev/ai-videos/opus-5-5/andre-lucaxxs-846347) · [作者公开输入](../../cases/andre-lucaxxs-846347-original/sources/published-prompt.md)

从日记录完成转到周期日历，再到音乐用途，以同一手机和淡彩舞台呈现身体记录服务。手机真实外观界面与场外标记关联，小花瓣只补充氛围。

直接观察的重点区间为 8.000—13.000 秒。8—8.4秒完成弹层稳定，8.467—8.8秒新的日历手机从下方前景移上，旧手机和标题淡去，新手机略有倾角后停稳。9.2—9.333秒第一个标记在手机左侧接日历行，9.467—9.533秒右侧第二个标记出现，9.667—9.8秒第三个左标记建立。9.8—12.6秒维持日历、三标记与标题阅读；12.667—12.933秒下一首页手机从右下叠入，旧场减淡，新标题开始出现。不是单个手机内容完全形变，而是新旧手机层叠交接。

美术的设计解释：粉、薄荷绿、浅紫渐变给阶段柔和统一，近黑衬线标题加粉斜体只强调一个词；日历与外标记复用粉/绿语义颜色，帮助指向对应条目。手机偏画面右下而标题左上，给伸出的标记留宽度；窄竖版中花瓣保持小而淡。

迁移思考：适合健康产品、记录页面与数据注释。医学新闻必须区分预测与已发生记录，装饰不应暗示准确性；界面实际文字和外标签需另在全尺寸核验。弱粉字背景适合品牌广告，长正文需加强对比，不能只追求柔。
