# 竖框下片向上展开，内容上滚后换成完成反馈

## 运动指令

先从下方接入竖框，再让框内下片向上展开，原底层同时变暗。下片中的局部标记依次变化，长内容上滚补入后项；末尾清空内容，在原承载区接入完成标记与短行。
