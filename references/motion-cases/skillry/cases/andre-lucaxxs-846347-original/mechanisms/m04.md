# 侧边短柱交替伸缩，内部内容更换时局部活动延续

## 运动指令

在稳定竖框旁接入一组短柱，让各柱交替伸长缩短，保持共同底部附近的位置。框内材料更换、清空并建立新状态时，侧柱继续局部变化，成为段间的持续运动。
