# 080 树木、根系与结构解释

## 适用场景

用于生态或产品内部机制解释，以同一整体为参照逐步增加局部关系。

- 原片形态：固定视频

- 适用视频类型（迁移建议）：科普解释

- 段落场景：整体到局部、空间关系、条件解释

- 原片实见素材：插画、图表、文字、抽象图形

- 动效方法：同树反复局部观察、粗旧结构接细新关系、关系完成拉回整体

- 美术特点：蓝天绿冠棕土分层、粗褐根与细白网、黄流点与独立底句

- 材料要求：需要可信机制、整体结构、剖面范围、路径意义和必要尺度限定。

## 动效与美术拆解

这条约31.6秒科学示意以一棵树为共同参照，依次讲碳与木材、氧、吸水与雨、腐殖质和地下关系、降温、栖息与过滤，最后把单树扩大为森林。主树与土层剖面反复出现，叶、根、云和邻树局部放大，观众看到的是同一系统的多个位置，避免每个知识点都换无关图标。片中的比例、温度差和物质通量属于需核查的科学主张；本轮只研究表达，不认证科学准确性。

13—18秒密集段以根部剖面接树际关系。13秒上一轮雨点结束，橙黄落叶落到地表，13.8秒土表深带出现Humus字；14.2秒右侧邻树渐建立，主树根始终留在原位置。15秒附近The underground network出现，浅色细线从已有根部向四周增加，继续伸向邻树，黄色小点沿部分线位置移动。16.4秒文字先淡退，画面拉远并上移露出两棵树冠，16.8秒Deep minerals, recycled句接入。粗根是基底，细网是新增关系，树冠与根系一起回到整体，前一个局部观察因此有归属。

天蓝与绿冠占上层，深棕到浅棕的水平土层占下层，地表细草是一条固定边界。主根暖褐较粗、网络浅白较细，新增系统通过线宽与明度区分，黄色点提示移动；树冠由深绿外缘与多个亮绿圆斑组成，既保持儿童插画亲和，又与复杂根线形成粗细对比。局部放大保留同一棕根与天蓝，回全景时不需要重认主体。底句用白色衬线小字并有短黄线，不压系统中心，但在浅天底或复杂根图仍需检查对比和读时。

适合机制解释、产品内部结构和以真实对象切片探索的知识片，可迁移为固定一个对象，先看局部，再新增关系，最后拉回整体显示新增部分如何连接。实拍树或产品版本可先给真实整体，再用准确遮罩、剖面与外部线标，而不应将绘制网络误称拍到。代价是这类清楚的几何和运动点容易让观众误以为路径和速度是测量结果；科学不确定、条件与尺度应明确，地下交换尤其不能只用连线代替证据。未试听，不判旁白是否支持全部数值。
