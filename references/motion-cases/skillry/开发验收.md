# 参考库迁入与检索开发验收

本轮把原独立研究目录迁入项目 `references/motion-cases/skillry/`，原目录不再作为运行依赖。120条原视频、逐例拆解、后写复现输入和观察记录均在项目内；媒体仍为原字节，第一条另保留浏览器兼容播放副本。

## 实现与调用链

三位原研究作者分别补齐001—040、041—080、081—120的用途分类，原稿保存在 `catalogue-parts/`。`tools/build_catalogue.py` 校验枚举、唯一编号、来源哈希、片长和观察区间，合并为 `case-catalogue.json`。原片形态、适用视频类型、段落场景、实见素材分列；方法、美术用具体描述，支持短词查询。

网页 `index.html` → `catalogue-ui.mjs` → 共用 `search.mjs` → 索引；项目 `motion-case-library` Skill → `tools/search-cases.mjs` → 同一个搜索模块与索引 → 入围案例正文。无需向量库、外部目录配置或生产Runtime。每页12条，只在需要播放时加载视频。

卡片和详情含用途、材料要求、迁移代价和推荐秒段。片段按钮从源秒点播放并在段尾暂停；再次使用播放器可继续整片。详情保留原片、作者公开输入、来源核查与后写输入的区别。原收藏继续使用同源同名浏览器存储键，未替用户增删选择。

修改入口包括项目 `.agents/skills/motion-case-library/SKILL.md` 及其检索说明、根 `.gitignore`、本目录分类与网页、独立预览服务、维护和验证工具。已有其他任务的代码与Skill改动保持原状。

## 实际验证

- 120条分类通过字段、唯一性、源哈希、片长及密集观察区间检查。
- 120原片合计564720025字节，SHA-256全部与迁移前清单一致。
- 120拆解、120复现输入、120观察记录、120全尺寸帧组齐备。
- 198个交付HTML、3100个本地引用无缺失。
- 共用检索与Skill路由5项测试通过，Skill结构检查通过。
- 浏览器实测“手机 照片”优先返回043，“新闻 对照”优先返回051；增加人物视频条件后051不进入结果。无匹配时显示条件收窄提示。
- 043推荐14—19秒实际解码播放，观察到段尾暂停；001兼容视频也实际播放和暂停，未恢复旧黑屏原片作为默认播放器来源。
- 原收藏显示6条：001、012、060、071、118、119，未写入新选择。
- 本地服务普通/尾部Range返回206，越界Range返回416，目录越界请求返回404。

上述播放验证是播放器功能检查，不是对全部作品的原速美学或声音认证。

## 失败处理与代价

索引加载失败显示本地服务与文件提示；无搜索结果不自动放宽条件；媒体失败提示恢复备份或打开来源；浏览器存储失败提示无法跨会话保留收藏。预览服务仅监听本机8874端口。

文本和工具可随Git保存，视频、采样图片与研究暂存区被忽略。换电脑需另复制媒体和证据；只拉代码不能恢复视频。检索采用透明标签、用途文字和有限同义词，多词用空格分隔，复杂自然语言意图由Skill先归纳再查询。

未取得120条原片的固定对应源码；公开相关工程仍单独注明关系。后写复现输入未制作验证，原研究的原速、声音未专业核验状态保持不变。
