# 创意库参考优化开发记录

## 实际基线与变更

本轮从主分支的现有创意检索、素材搜索和 OpenDesign 制作入口出发。创意自然语言查询通过 Job 执行，完成后使用返回的读回入口和分页；精确卡片读取提供库来源指纹、原片、片段及分镜。素材搜索保留独立会话，候选通过获取 Job 和媒体分析成为可使用的 Asset。现有制作入口继续管理 Run、阶段冻结版本、回执和续修。

没有新增检索服务、素材资格系统或项目场面生命周期。创意语义指令已包含完整视觉组织与跨题材表达，卡片向量文本保留完整正文的主要章节；现有离线协议测试并不能证明真实模型召回效果，因此本轮未修改指令、文本版本或重建索引。

技能源按需求更新并同步至插件副本。完整新制从主题阶段并行探索创意与素材，视觉提前参与，导演持续协调；创意与视觉共同记录参考角色、真实素材映射和完整画面过程，再交当前范围的制作。实际作品由原负责人对照参考复看。

参考打包程序使用项目读回核对素材状态及文件哈希，以素材本地时间核对范围，并在有取得偏移时保留原片对应时间。场面映射、参考原片和简报随请求交付；只属于未就绪场面的资料保留诊断而不阻塞其他就绪范围。必要资料、项目版本、文件或范围不符时，对应场面不能标为就绪；可发送请求必须通过实际文件清单核验。

## 本轮验证

- 类型检查、插件 Skills 同步与插件校验通过；未运行全量测试套件。
- 创意库测试通过了实际索引与媒体读取、正式 MCP 注册、异步 Job、读回分页和缓存身份验证。语义向量由隔离模拟 Bridge 提供，不能据此判断真实跨题材召回质量。
- 素材搜索与获取测试使用独立项目、受控来源及真实媒体分析；范围取得后，检查 Asset 身份、项目读回、源文件哈希、本地与原片时间，再生成交付包。OpenDesign 接收端在隔离 HTTP 服务中模拟，已核对完整请求原文实际传递。
- 打包测试覆盖多个参考、素材 ID 与文件不一致、范围越界、未就绪场面、独立就绪场面、项目快照变化、旧请求清理，以及 WebM 和 FLAC 解码。
- 现有制作测试使用隔离服务检查阶段拒收、修正版、冻结身份、原 Run 续修和结果未知后的恢复；这些测试不代表真实作者已经观看资料或完成作品。

## 尚未完成的验收

尚未在独立制作运行环境完成只有文案、没有参考与素材的新稿冷启动，也没有对照真实成片复核创意迁移效果。真实语义模型的跨题材召回、外部来源的实际搜索获取、制作作者观看与创意效果仍需在隔离项目和独立工作队列中验证。本轮没有部署生产运行环境，也没有修改正式视频项目。
