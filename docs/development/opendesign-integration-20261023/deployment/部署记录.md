本轮安装顺序不当：官方安装发生在旧版队列排空之前，安装器清除了 0.1.99 缓存目录。已在运行的尾段任务 `job_034ca3e8-63e6-4008-9c0c-6ef66b46b786` 成功结束，所属项目自然从 R327 更新到 R328；之后启动的排队首段任务 `job_2c383911-5d51-46a2-acd3-be6a453b6e70` 因旧目录的字体 catalog.json 缺失而失败（`MOTION_FONT_CATALOG_INVALID`）。这不是原视频输入问题，属于本轮部署造成的影响。

原始安装开始基线另存 `snapshot-initial.json`，与正式切换前基线的差异见 `pre-cutover-concurrent-changes.json`。因此“切换前后数据一致”仅指受管 Runtime 切换阶段，不代表整个安装过程没有任务状态变化。失败任务保持失败，未自动重提；新引擎不接受旧 TSX 重新生成，后续制作需要按新 HTML 合同处理原作品。

后续发布应先排空真实运行/排队任务，再执行可能清理旧安装槽的官方安装，不能只在停止 Runtime 前检查队列。
