- 入口与交接：协调入口、类型和任务路由、导演及其主线与粗剪参考、`TOPIC_TO_FILM.md`、`SCENE_DESIGN_HANDOFF.md`；完整人物解释首轮派发整场责任，制作范围与正文／声音权限独立。

保留原 Renderer、人物生成服务、视频绑定、主场面接管和声音分离实现。技术合同没有新建人物镜头枚举，也没有引入露脸或效果数量配额。

## 失败处理与代价

缺资料继续沿现有取材责任；设计弱回原视觉作者，明确设计漏实现才修源码；缺人物源条件按真实能力重选形态。参数、版本冲突、失败 Job、未知结果继续原正式恢复合同，不自动重放。

索引指纹更新使旧选择需要重新核读，旧语义查询缓存需要按新来源重新准备；增加的上下文也会增大候选返回和派生索引。没有改向量输入或添加新的排序配置。
