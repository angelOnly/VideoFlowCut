## 3. 实际调用链与失败处理

共同主线与协调入口 → 视觉入口与唯一美术规则 → 已有示例及选定整片参考 → 机制检索与完整动作核读 → 当前连续演出稿 → 同源受管实现 → 实际预览 → 导演与质量回派 → 原视觉作者修订。

- 无匹配：按实际作用改写查询、补查或原创补足，不虚构命中，不删除必需表现。
- 声音、材料或时长变化：原作者重排阅读窗口、主行为及接点，不只改段长和动画比例。
- 确定设计缺失：继续返修；技术可导出不关闭该任务。
- 观察证据不足：保留实际未知，不写通过，也不无限盲改。
- 工具或任务失败：沿现有 Revision、Job/Run 与恢复合同处理，没有新增失败状态系统。
