## 主要调用链与失败处理

作者按当前内容选择主体 → 条件读取物件参考和具体案例 → 复制必要绘制组件、场面状态和依赖到本片受管 TSX → 使用原作品提交、生成与合成链。

开发复现：`demo-props.json + source.tsx → motionSubmissionSchema → renderManagedMotion → compileMotion / validateMotionSource → Chromium 逐帧 → 确定性复查 → FFmpeg 预览 → 原帧数检查 → 发布案例输出与哈希`。

脚本默认渲染全部案例，也可传一个或多个案例目录名。每次在内容哈希目录下建立独立运行目录，允许同版重复复现；失败保留现场并返回原错误，不替换成临时画面。只有受管渲染成功后才更新案例预览。测试会拒绝源码、参数、视频或关键帧已变化但验证记录未更新的案例。
