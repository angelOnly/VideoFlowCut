# 创意库与连续镜头设计：实施与验证

日期：2026-10-28。范围是平台代码、技能及隔离验证；本轮没有制作正式视频、切换生产 Runtime 或修改已安装插件缓存。

## 实现与取舍

新增 `search_creative_cases` 和 `read_creative_case`。直接消费现有 schema v1 创意索引及完整卡：120 个来源视频中已整理 20 个、87 张卡，82 个独立切片与 5 个原片复用。原索引、卡片、媒体和浏览器未改写。

动效检索原来内置的批量编码、文档/查询缓存、余弦扫描、归并、进展检查点和诊断已提取到 `apps/job-worker/src/library-semantic.ts`。动效与创意各自提供文本、指令、缓存身份和结果适配；保留动效原有分类、混合召回及分析功能。删除原函数中的重复执行代码，没有新建向量服务、数据库表、调度器或第二套 Worker。

创意默认每卡一个向量；编码文本包含标题、摘要、适用条件及三节正文，剔除来源外壳、图链、时间码和统一分析免责声明，保留事实限定。实际本地分词验证最大 710 token，低于现有工作流 8192 token 上限，当前资料无需分块。

新增三项技能：`creative-sequence-design`、`creative-case-library`、`creative-reference-to-sequence`。同步替换协调、主题、导演、文案、素材、视觉、机制、共同交接及 OpenDesign 入口中的直接重复规则。首轮并行明确五项责任；主要创意由创意牵头、视觉共同发展，原视觉作者继续操作 OpenDesign，具体镜头在制作中深化。机制检索按实际缺口进入。

正式调用链：

```text
search_creative_cases
  → 校验当前索引和完整卡
  → 编号定位/分页浏览：直接返回，不调用模型
  → 自然语言查询：冻结模型配置与资料指纹，沿原仓库创建检索 Job
  → 现有媒体 Worker → 创意薄适配 → 共用 library-semantic
  → 原 embedBatch / modelText / libraryCache
  → 全库向量排名 → track_job → 同输入分页读回
read_creative_case
  → 原始完整正文、真实路径与 MIME、源时间和切片坐标、观察边界
```

翻页不进入 Job 身份，复用完整排名。单卡缓存不包含整库指纹；一张卡改变只重算其编码文本变化的向量，其他卡继续命中，模型/工作流/schema/任务说明参与缓存身份。整库快照独立用于拒绝混合资料结果。

## 失败处理与代价

- 缺项目时，精确查读和浏览可用；语义查询明确返回 `PROJECT_NOT_TARGETED`，不虚建项目。
- pending/failed/unknown/cancelled 与正常候选分别返回，不用词法冒充向量结果。失败沿 `retry_media_job` 显式恢复；未知先核对原 Job/Run，不自动换键重放。
- 来源变化返回 `CREATIVE_LIBRARY_STALE`；Worker 完成排名前及工具接回成功结果时核对快照。卡缺失、数量不一致、非法范围和无效索引拒绝读取。
- 媒体缺失逐项说明，保留可读正文。卡内 `../` 先按卡位置规范化，再核对真实路径；不猜媒体文件名。图片依据字节返回 MIME。
- 每次查读核对当前卡片来源，存在全库文本读取成本；当前只有 87 张卡，不增加额外索引存储。首次语义查询需要编码当前资料，后续使用原缓存。
- 当前没有超过模型限制的卡，未提前引入复杂分块策略。排名不验证材料条件、事实适用性或观看效果；完整核读仍由作者负责。

## 实际语义效果

用现有本地 `Qwen3-Embedding-0.6B`，在独立 CPU 进程按现有节点的 document/query 指令、左填充、末 token 及归一化方法编码全部 87 张卡和 5 条自然语言需求，未向生产 ComfyUI 队列提交任务。结果见[真实语义召回](真实语义召回.json)。协议/Worker 与模型效果分开验证，未声称已完成生产 Bridge 联调。

| 查询意图 | 实际结果与判断 |
|---|---|
| 真实工作逐渐积累，理解项目从何而来 | `002-c01` 排第 1，完整指令确实让发起人、起步工作与资料积累共同出现；可借用，须有真实材料支撑 |
| 同一人有多种外观，让观众自己比较选择 | `001-c01` 排第 1，直接符合比较与选择关系 |
| 题材说地图，但要比较多种外观，明确不是历史起点 | 异题材的 `001-c01` 仍排第 1；地图起点卡仍进入 Top-5，题材干扰未完全消除 |
| 不把概率预测演成确定事实 | 首位 `013-c05` 是虚构揭晓，不能据此满足预测限定；本次召回不足，不能自动采用 |
| 小事逐渐留下积累，末尾看清整体 | 首位 `012-c01` 偏向空间探索；有逐项出现候选，但未充分匹配累计关系，需要补充材料角色、改写查询或原创 |

剔除重复分析免责声明后，第一条需求的 `002-c01` 从第 3 上升到第 1。未根据这五条查询新增阈值、标签或复杂权重，不承诺未经校准的准确率。否定/概率及抽象累计仍是已知召回局限，不能用“有向量排名”关闭作者判断。
