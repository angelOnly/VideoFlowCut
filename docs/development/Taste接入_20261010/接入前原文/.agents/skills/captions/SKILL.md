# 字幕、语义分卡与屏幕文字

接收当前实际声音、准确文稿、真实对齐、人物和场面、目标画幅及已有文字。局部纠错或版式修改只处理相关卡；新字幕先按下面的方法确定读法，再按[字幕操作](references/caption-operations.md)生成或修改。专业判断与提交沿[角色交接](../_shared/PROJECT_REVISION_AND_HANDOFF.md)。

## 先分清文字承担什么

普通字幕准确呈现观众听到的语言；画内问题、数值、标签与来源分别帮助定位、思考、比较、指认或核对。需要完整字幕时不能用关键词花字冒称转写；用户要摘要或标题时明确它的角色。

规划主视觉时就把实际字幕放进构图，精确分卡依本版可播放声音。字幕卡是阅读单位，讲述句群是声音单位，场面是观看单位；同一对象可跨句，一段自然语音可有多张卡，换卡不重建画面。

文字各按用途持续：字幕承接当句，问题可跨句，标签跟随对象，来源保留必要上下文。同义文字承担不同作用时可以共存，无作用的重复强调才让位。制作备注不自动进入画面。

## 语义分卡与换行

一张卡应能在短时间理解。保护主谓、否定与对象、数字与单位、专名、条件、因果和转折；连接词单独闪现通常无法完成意思，应与它引出的短语一起读。卡过长会追不上，过短会频繁闪动；按实际声音和字幅调整，不按标点机械切分。

换行保护语义，也照顾视觉重量。数字和单位、姓和名、介词和核心名词尽量不拆，中文标点不独占下一行。单行或双行服从本片采用的布局，不为达成单行而切碎 TTS、缩到难读或非等比挤字。

当前只有 segment_exact 或 sentence_exact 时使用可靠边界，不能按字符平均制造逐词高亮。重分屏所需的 token 证据和合法编辑范围在操作参考中核对；缺精度就保留当前可靠分段或请求补充，不猜切点。

## 稳定字幕、动态文字与强调

人物、素材和动画已有较多变化时，字幕可保持稳定。文字承担主要节奏、画面简单且时间精度可靠时，再使用必要的动态强调。一次卡的主要强调应帮助理解结构，如对比、否定、数字或行动；颜色、字重与运动在本片有一致作用，不把每个重要词都变色跳动。

按当前信息顺序呈现，不能用字幕提前说完需要后置的包袱或结论。不能删掉主观语气或限制条件，把意见改成事实。改字会改变语气、对象或事实时回文稿/语义作者，显示层不另写一个意思。

普通字幕沿现有 Caption 链；跨句问题、跟随对象的标签和动态短语由受管作品实现。两者共享同一版内容，在真实合成里协调，受管文字不会自动让普通字幕避让。单卡显隐和静态位置是否可用，读取实时 Schema 与操作参考，不用透明字、删 token 或遮罩绕过。

## 字形、画幅与阅读条件

用实际文案检查中文缺字、字体回退、笔画、对比、长行及复杂背景；主字幕、说话人和辅助说明保留有限层级。受管字体绑定不会自动控制原生字幕轨，当前字幕可调范围见操作参考。

位置避开正在表达的嘴、手、道具、操作与原文；平台 UI 裁切按交付条件避让，镜内空间随构图决定。字幕位置不划定其他动效的永久禁入区域，也不要求每镜移位。只验证本次要求的画幅；确需横竖多个版本时分别重排字宽、行数和位置，不能简单缩放。

字符数只能提示风险，最终以自然播放能否读完为准。读不完时先减少同时竞争的信息、改善字幅或按可靠语音边界重新分卡；必要延长必须在当前真实边界及工具合同内。可修改旁白回导演与文案协调，字幕作者不自行裁声或改变锁定时长。

多人内容依据真实说话人证据，不从 ASR 猜姓名。身份可以来自明确画面、用户说明或已有标签，未知时用中性归属。

## 在当前合成里复核并交回

检查改动卡及前后卡：文字与声音是否一致，换行是否自然，阅读是否够，强调是否有用，人物、产品、UI 和证据是否被挡。代表帧只能回答布局，背景变化和切换还需连续观察；需要时分别静音看阅读、带声看同步，不把打开播放器称为已听审。

交回准确卡文、布局与强调、时间精度、受影响范围和实际观察。只有当前操作涉及来源链、生成失败或 stale 时才进入[字幕操作](references/caption-operations.md)相应章节，技术来源检查不在创作正文重复。新声音回来后重核对受影响字幕，旧版结论不自动用于新版。
