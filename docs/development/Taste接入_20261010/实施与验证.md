## 调用链与失败处理

`edit_captions` / HTTP → 共享阴影 Schema → `editCaptions` → `applyCaptionFormat` → Revision 中的 CaptionFormat → `CaptionLayer` → `captionTextShadowCss` → Web Player / Render Worker。

`text_shadow:null` 明确关闭；对象 `{offsetX,offsetY,blur,color,opacity}` 指定单层阴影。偏移 -20～20 像素、模糊 0～40 像素、颜色 #RRGGBB、透明度 0～1。省略保留当前值；旧卡从未设置时保留原黑影。局部字号或颜色修改不能覆盖显式无阴影选择。

任意 CSS 字符串、未知字段、越界值会被拒绝且不写 Revision；直接应用层调用也校验结构。字幕源文字、卡边界、语音与 Script 保持。原有版本冲突及未知写入恢复规则不变，不增加自动重试。

共用根层核查结果：当前受管作品路径没有无条件的栏目名或页码；`explainer-registry` 的 Shell 属于明确选用的旧组件模板，未发现它在本次受管路径覆盖场面设计，因此没有泛化删除模板。原生字幕固定黑影是实际发现并修复的覆盖点。
