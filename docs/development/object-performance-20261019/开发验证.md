## 调用与交接关系

当前导演正文 → 同一视觉作者读取视觉／动效入口和执行稿 → 当前详细正文＋同版源码／资源 → 主任务读取实际正文并提交 → 同版输出回原作者 → 独立审阅定位具体缺口。

正式隔离链为 `create_project → import_media → track_job → read_project → submit_motion_work → track_job/read_motion_work → create_scene → manage_effect_cues → import_media/track_job → manage_audio → render_preview_range/track_job`。所有写入使用读回的真实 Revision，图片和声音都经过正式导入，未直接写数据库、伪造任务成功或注入测试 Asset。

## 真实宿主行为回归

本轮使用实际 `spawn_agent`／`followup_task`，不是测试字段模拟委派：

- `/root/visual_regression` 持续负责新场面“单孔冲压”，从导演只给表达与先后开始，读取本次维护源，交回 `visual/current-design.md`、`visual/source.tsx`、原创纸纹与提交说明。主任务实际读取详细正文；初次只返回源码时按探索进度接回，没有把它记为设计完成。
- 该作者为双导柱、冲头、拉簧、纸带、下模与收集盒选择具体形体、材料和层次，将下压、穿透、落屑、复位、前送写入同一过程。没有同名案例时借局部结构与表面方法，未复刻 Token 原片或换标签。
- `/root/handoff_review` 从当前主任务路由、共同交接、专业审阅处理三个独立测试消息，结果在 `review/handoff-cases.md`。这是语义判断回归；给定的阀门代码／帧事实不是实际媒体观察，报告明确保留该边界。
- 实际首版由原作者查看静帧后修订源码，修改纸屑阴影层级、送料后承托和冲头穿透遮挡。原稿与源码另存 v1，未用事后扩写规则冒充制作前决定。
- 独立审阅者先看首版八帧，再读详细稿与源码，独立定位穿透遮挡和纸屑影层级，并核对提交源码、视频身份，见 `review/actual-v1.md`。第二版复核发现遮挡在接触前提前生效，继续同一作者局部修订，没有关闭未解决问题。
- 数量、时长、风格与字体变化由同一作者形成 `visual/variants.md`：双孔联动、10 秒重新分配、暖纸板材料和三个标签位置。该项只完成具体重排判断，未选定真实字体、未实现或生成变体，不能算变体影片验收。

## 失败处理与代价

明确参数问题先核对实时合同：作者首次提出的图片槽 `paperTexture` 不符合实时小写槽名规则，在正式作品提交前由原作者改为 `paper_texture`。没有重试已执行的生成；同源返修作为新作品版本提交。声音关联在换作品后重新按读回事件版本绑定。

真实设计或实现缺失回同一视觉作者，合法源码可继续探索生成。确定缺失与未观察的动态、声音分开；没有效果感知时不编造通过，也不反复盲渲。全量静态链接回归的既有 GIF 缺失保留为未解决项，没有扩大到指定八个文件之外修复参考档案。

本轮增加的是按实际需要读取详细方法和维护具体设计的作者成本，没有新增生产状态、接口或运行时性能开销。构建不等于生产部署；未修改已安装插件、未切换生产 Runtime、未操作正式视频项目、未发布远端。本次开发样片不是正式视频交付或用户定稿。
