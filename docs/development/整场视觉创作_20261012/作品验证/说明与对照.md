日期：2026-10-12。查看 `index.html`；实际文件字节、哈希、尺寸、时长、项目和 Job 信息以 `manifest.json` 及各 `*-result.json` 为准。

## 本次真正做了什么

同一作者沿当前 Skills 兼任导演、视觉和实现，完成三个无风格偏好的微型视觉试作、一个固定内容“简洁”对照，以及一个独立真实旁白/SRT声画开发样本。全部使用独立 `.cache/whole-scene-creative-eval/<案例>/workspace`；没有连接生产 Runtime、ComfyUI 或修改正式视频项目。

这不是干净宿主上下文实验，不是完整视频多作者生产，也不是用户认可。作者已参与本轮平台开发，不能用这几个样本证明所有题材的默认创作质量。前两项仍共享“材料让位、侧边主读”的构图家族，应继续用更广泛材料评价。

## 来源和原声时钟

实际素材来自 `docs/VideoFlowCut_项目方案与参考案例/VideoFlowCut_交付包/.agents/skills/visual-treatment-planning/references/whole-scene-collaboration/input/inputs/` 下的 `客舱源视频.mp4`、`旁白音轨.wav`、`字幕时间.srt`。没有读取交付包旧认可作品源码，也没有重跑旧成片。

客舱源片：1920×1080、25fps、12.885秒；实际查看0、3、6、9、12秒联系表。原WAV：24kHz单声道，30.25秒。原音谈退改签规则，不能贴到“客舱空间”“开发原则”“排队”三项主题，所以三项视觉试作和简洁对照保持无声。

独立声画样本使用源11.2–20.8秒，按项目30fps为源帧 `[336,624)`，映射到样本 `[0,288)`，不变速、不循环、无增益修改。选原SRT第6–9卡，保留原文和原毫秒，正式导入仅传 `offsetMs=-11200`：

1. 11.208–13.958：飞机起飞后，这一班的空座不能留到明天再卖。
2. 14.167–16.333：越晚取消，重新卖掉它的时间越少。
3. 16.458–18.083：这能解释收费设计的一部分，
4. 18.125–20.667：但不等于每笔费用，都恰好是航司的损失。

范围含四句完整文字，头前8ms、句末后133ms余量；此选择来自原SRT与音频文件时钟，不冒称已听审呼吸与切口。字幕帧量化以30fps执行，来源为 user_srt、精度 subtitle_exact，不是 word_exact。

## 实际调用与恢复

基线与简洁对照：正式应用层 `createProject → registerImportedAsset/applyMediaAnalysis（有实拍时）→ submitManagedMotion → runMotionJob → 受管素材与Job读回`。以当前源码的内存MCP列出真实工具并读 `read_motion_capabilities`，引擎实际为 managed-motion-13。

独立声画：同一正式动效路径后 `createScene → createEffectCue → placeNarration → importSrtCaptions → editCaptions(set_global_format) → submitPreview → runPreviewJob → Job读回`。原WAV注册为原音Asset，落入Dialogue，不生成或伪造SpeechAsset。没有直接修改生产数据库。

前两次声画作品分别为960×540和1920×1080，但项目没有显式传横屏，实际默认画布为768×1344，createEffectCue都返回 `MOTION_NOT_READY: 与当前画布匹配的作品版本`，没有提交Cue。第二次前作者误以为默认是1920×1080；读回实际对象后明确 `brief.aspectRatio=16:9`，并在提交前断言项目为1920×1080再生成。属于试作输入和检查错误，没有修改平台或报修工单。旧尝试和完整workspace留在.cache，不装入文档交付。

## 检查与限制

四项视觉试作均完整ffmpeg解码通过，查看关键帧/contact；客舱最初底部说明与素材边缘重叠，修到固定底部后重渲染并查看3.5秒；原则原文条件修回准确摘录并看0.5秒与5.6秒；排队末态修为5/6号保留在窗口开始服务的位置，重渲染并查看5.6秒。简洁对照已查看完整contact，画面和主读清楚。

声画样本的末段接受主任务语义复核，已将可能误导的普遍不等号改为“费用不一定等于航司损失”。正式合成288帧，视频9.6秒，AAC容器9.643秒。已查看每秒1帧contact与0.5、3.5、7.6秒大帧，字幕固定底部且未遮挡主读和示意；开场画内白字“这一班的座位”跨亮窗导致局部对比偏低，作为遗留视觉问题记录，中段淡化有短时双层内容，尚不能据此断定连续观看满意。解码声音与原WAV选段在三处范围的相关系数均大于0.99994，延迟一致为42.667ms，支持没有隐式变速；这是技术核对，不是听审。完整记录在 `声画检查.json`。

关键帧/contact检查可发现遮挡与同时阅读负担，不能替代连续观看、真实听觉和声画同步审阅。本环境未取得真实听觉输入，音色、切口自然度、情绪、听感与完整声画同步仍为待实际复听；不能因为有音轨、解码成功或数值一致就称“听过”。没有进行用户定稿、正式ExportArtifact或生产部署。

交付只含最终作品、源码、关键帧、请求/设计/实际Job与来源记录；完整workspace、数据库、依赖、缓存与原始媒体留在原位置，因此此目录不是离线可重渲染工程。
