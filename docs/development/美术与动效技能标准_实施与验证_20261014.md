## 实施内容

- 美术正文明确视觉性格、构图分量、配色职责、排印关系、材质与空间层次；保留多色、高饱和、深浅底等选择空间，删除气质方向中的具体色板起手建议。特点正文没有新增机制库编号或指定案例名单。
- 原有六项必需表现继续使用；主要动作落实准备与蓄力、发力与冲击、通过、惯性和收势，并明确节奏、主从响应与动作结果的继续使用。
- 完整新制或主要视觉重做的视觉解说片要求每个可见元素实际参与动效，所有场间完成动态交接；阅读期间允许稳定。用户锁定原片与局部机械任务保持原范围。
- 普通字幕保持正式独立字幕链，适用全元素动效要求时统一设计进入、换卡和退出，阅读期间稳定。正式接口不能表达时报告能力缺口，禁止复制进主画面绕过。
- 禁止新增制作性说明、示意或免责角标及重复提醒；必要事实条件由正文、旁白或必要原文准确表达。
- 设计未具体化、实现遗漏、完整实现仍不成立分别回到对应环节；动态观感未知不能掩盖已确认的漏做。

## 主要调用链与失败处理

现有制作入口 → 美术主方法 → 连续演出与当前稿 → 受管实现、独立字幕 → 实际预览与专业返修。文案与画面文字共同引用证据呈现规则；机制适配、导演分镜与素材反馈服从当前作品的动态交接要求。

未形成具体动作先补设计；动作被挂载窗口、时间边界或实现漏项截断时修对应实现；完整实现仍缺乏表现时依据实际观察改演出。不能支持字幕动效的接口须报告实际缺口，技能文本不冒称新增了渲染能力。未完成连续观察的动态或听感保留未知。

阅读页首次生成因默认 Python 缺少 `mistune` 失败，改用已有 Anaconda 环境成功生成，未安装依赖。保留旧文件的原始换行，避免混合换行文件产生无关整段差异。
