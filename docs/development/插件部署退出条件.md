# 插件部署退出条件

安装和服务切换完成后，使用 `npm run plugin:deploy` 作为正式部署的最后一步。只有该命令退出码为 0，且本次回执的 `success` 为 `true`，才能报告部署成功。

切换时记录实际切换时间。在专用验收项目提交一次最小 OD 制作，等待阶段作品接回，然后对接回 Revision 内的一小段实际帧生成预览。记录两个 Job ID，运行：

```powershell
npm run plugin:deploy -- --codex-cli "<Codex 可执行文件绝对路径>" --installed-plugin-root "<本次实际插件安装绝对路径>" --switched-at "<含时区的 ISO 时间>" --smoke-project "<验收 Project ID>" --authoring-job "<制作 Job ID>" --preview-job "<预览 Job ID>" --receipt "<本次新回执绝对路径>"
```

脚本按安装版 MCP 声明逐项核对注册并新建连接，检查 VideoFlowCut 启动器、MCP、Runtime、OD 和两个 Worker，再通过同一连接读回制作回件和预览。预览须使用接回作品的 Revision 和本次发行，且实际文件摘要须匹配。新增 MCP 入口时一并补上功能验收。回执保存预期发行、实测运行状态、制作与渲染结果，失败时记录阻断环节。

本命令负责切换后的验收判定。构建、安装、服务切换、提交验收任务及必要的版本恢复仍由部署操作者执行。独立测试可以先运行 `node --import tsx --test tests/plugin-deployment.test.mjs tests/codex-mcp-registration.test.ts`。
