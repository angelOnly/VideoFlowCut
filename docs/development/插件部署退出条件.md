# 插件正式部署

在 VideoFlowCut 仓库中通过统一命令发布。使用当前宿主的 Codex 可执行文件绝对路径，发布新内容时指定一个新版本，回执使用本机尚未存在的绝对路径。

```powershell
npm run plugin:deploy -- --codex-cli "<Codex 可执行文件绝对路径>" --version "<新插件版本>" --receipt "<本次新回执绝对路径>"
```

命令依次执行发行构建和隔离验证、官方插件安装、宿主入口核对、受管服务切换及正式验收。切换前核对在途任务。已安装同一发行时沿用安装槽；发行内容变化时须使用新版本。更新既有直接登记时保留工作目录、环境和超时。

验收从实际安装入口连接 VideoFlowCut 和 OD，检查两个 Worker 及各端发行身份。随后创建独立的短场面，让 OD 实际制作和发布冻结作品，为该作品生成派生媒体，再从登记媒体后的 Revision 渲染一小段预览。程序核对冻结作品、媒体和场面绑定，并读取各任务及预览文件摘要。验收项目和任务保留给复查。

只有命令退出码为 0、且本轮回执的 `success` 为 `true` 时，才报告部署成功。失败返回非零，并记录失败步骤、已安装发行和已取得的验收任务 ID。服务已经就绪且验收仍在运行时，应报告实际进度。

修复阻断原因后，沿用原回执续接。已经记录的验收 Job 会继续查询；提交回执丢失时用同一幂等键重读制作或预览任务。若任务已明确失败，按回执处理失败原因，重新发起独立的验收轮次。续接前核对仍是原发行。

```powershell
npm run plugin:deploy -- --codex-cli "<同一宿主 Codex 可执行文件绝对路径>" --resume "<原回执绝对路径>"
```
