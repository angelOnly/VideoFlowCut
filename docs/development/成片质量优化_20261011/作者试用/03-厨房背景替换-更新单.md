# 仅替换普通厨房背景——局部更新单

当前完整正文以 `02-当前稿-v2.md` 为准。反馈仅要求换普通厨房背景，保留核心意思和旁白音色；本次不另立新文案版本，不改准确旁白、讲述顺序与凝结解释。该决定基于背景仅承担生活语境，没有新增事实或改变指代。

## 具体需要更新

1. 素材作者提供新厨房背景的实际文件、来源与可用范围，并标明其中有没有冰箱、人物动作、可用现场声。仍可承担开头建立、中段空间延续、结尾回收；不要求新背景演出水滴凝结。
2. 视觉或剪辑作者在实际使用厨房背景的范围替换绑定，按新画面重新确认裁切、构图、主体可辨度、字幕阅读区域、明暗与相邻画面的衔接。变化只发生在这些背景使用处；水珠和白雾材料需求继续沿 v2。
3. 背景里若出现与既有示意重叠的冰箱、人物或高亮区域，调整示意和字幕的位置或背景取景，不因普通背景换用重写台词。新素材原声先核听；若与旁白争抢或与前后不连续，由声音作者调整该背景声范围。
4. 保留 v2 纯旁白和当前音色方向。若正式旁白已经存在，沿用同一声音文件及原时序；本试用没有声音文件，所称“保留音色”只能保留已定的日常亲近成人解说方向，无法确认具体声线。字幕文字不变，必要时调整位置和对比度，不能因新背景时长不同擅自裁声或加速。
5. 拿到素材和预览后连续查看替换范围及前后接点，确认环境衔接、阅读与声音。若仅时长不够，先换新背景可用范围、调整其出入点或补背景；只有真实发现影响核心解释或用户另改目标，才回文案处理。
