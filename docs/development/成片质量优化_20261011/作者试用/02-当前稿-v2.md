# 冰箱开门为什么会起雾——当前声画稿 v2

状态：已根据编辑与首批材料反馈实质改写。首批仅有“厨房环境”的文字反馈，本作者没有收到或观看文件。没有正式项目对象、配音或可播放粗剪。约 45—55 秒为初始尺度，待真实朗读与试排确认。

## 纯旁白

冷玻璃上那层小水珠，水从哪里来？
就来自周围的空气。空气里有看不见的水蒸气，碰到足够冷的玻璃，就会凝结成小水滴。
开冰箱时冒出的白雾，也和这件事有关。
门一开，厨房里的暖湿空气和冰箱里的冷空气相遇。如果局部降温到能让水蒸气凝结，小水滴就会出现在空气里。
这些小水滴悬着，我们看见的就是雾；贴在玻璃上，看到的就是一层水珠。
同样是水滴，一个飘着，一个贴着。
所以冰箱开门会不会起雾，要看温度和湿度有没有凑齐条件。下次看见那团白雾，你就知道：空气里的水，现身了。

## 给素材作者的补材需求

目的从“先拍到冰箱白雾”改为“先让观众认出小水滴来自空气，再接回冰箱”。已有厨房素材继续使用，无需因缺精确特写整批重找。

- 优先级一，对应开头两句：寻找能清楚认出冷玻璃表面水滴的画面。冷饮杯、冷窗或冰箱玻璃均可探索，不锁唯一对象；实际是凝结还是喷洒须从来源和上下文判断。静态水珠可用于辨认结果，若只有静态不要声称拍到凝结过程。若能找到清晰到起雾/起珠的连续变化更好，回传真实变化所需时间。
- 优先级二，对应“门一开……”：寻找日常冰箱开门的连续动作，若有可辨白雾优先。无雾的开门仍可建立冷热空间接触的语境，原理由示意补充。不要为白雾效果改用干冰或烟并宣称同一机理。
- 对首批厨房环境：请补原文件/可访问预览、来源、真实可用范围、镜头是否运动、是否包含可辨冰箱。推荐开头建立、中段空间延续、结尾回收中的一项或多项作用，不要求逐句匹配。背景里没有冰箱也可作为生活语境，但不承担开门动作。
- 分别返回“已经看见的内容”和“仍需补核的解释”，附取得状态与使用条件。若新材料提供更直观的水滴对照，先回可用连续范围，本作者继续调整当前完整稿，不要求硬塞进当前秒数。

## 依据与待核

核心解释沿用 v1 的基础物理常识，没有新增外部已核来源。水蒸气不可见；冷表面可发生凝结；雾是悬浮微小水滴；冰箱开门是否出现可见雾与具体温湿条件有关。未声称所有冰箱每次开门均起雾。删去露点术语不改变核心物理关系。

正式采用前仍需可信气象或物理教育来源核对凝结和雾的定义；素材来源需核对是否存在喷雾、干冰、烟或后期处理。没有测试、数据或温湿度读数，不写阈值数字，也不依据雾判断故障。冷玻璃只是帮助理解的类比对象，不冒称与冰箱白雾来自同一次拍摄。

## 相比 v1 的实际变化与影响

- 开头由“冰箱白雾→露点定义”变成“冷玻璃小水珠→水来自周围空气”，尽早给具体答案。露点从纯旁白全部删除；无需为了保留知识点另补定义。
- 将 v1 后半段玻璃水滴内容移至开头，再把降温成滴关系迁移到开冰箱；“悬浮/附着”的区别接住同一对象，结尾回收“空气里的水现身”。这不是只替换几个语气词。
- 核心意思保留：看不见的水蒸气在条件合适时凝结成小水滴，位置不同呈现不同现象。普通厨房材料继续承担语境、延续和回收；缺特写只改变补材优先级及暂时表达手段。
