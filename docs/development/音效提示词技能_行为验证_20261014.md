## 2. 轻落定：一个小部件吸附到位

### 输入

导演演练要求：

> 一块小的圆角塑料功能块滑入凹槽，在项目第 48 帧停稳，项目是 30 fps。想让人觉得它轻巧地吸附到位，但不要像重物砸落，也不要响成通知铃。旁白正在说“只保留必要功能”。整片声音希望干净、近、短。

### 实际响应

**中文声音设计：** 用小塑料卡扣轻轻扣合的一次短声，给清楚的触感和到位感；主体偏中频，收尾很快。它是设计音效的声源类比，不冒充现场录音。不用低频重击或长铃声来制造强调。

**生成核心参数：**

```json
{
  "prompt": "TrackType: SFX. One isolated small plastic latch snapping gently into place, a clear compact click with a soft midrange body and very fast decay, close and dry recording.",
  "max_duration_seconds": 1,
  "seed": 514801
}
```

**候选与编排交接：** 先取得这一候选；需要比较时再用不同种子生成少量同要求候选。检查是否只有一次扣合、有没有多出的铃声或重低音、尾音是否拖长。第 48 帧是输入指定的画面落定位置，正式采用时仍要读当前作品事件和版本。原音频的可听起音、主要攻击、尾音均未取得，不能把它们填成零。

交给混音作者的是“主要攻击对应停稳”，不是“音频文件从第 48 帧播放”。真实候选回来后按攻击偏移决定片段从哪一帧开始；在旁白中核对是否遮住“必要功能”。本阶段不给固定最终增益，也不新增 AudioCue。

### 反馈演练与实际修订

模拟反馈：

> 两个候选都像金属扣件，有一小段清脆余响；单次动作本身没问题。

本次实际修订保留单次动作与一秒窗口，重点把共振材质改得更明确，不仅更换种子或把音量压低：

```json
{
  "prompt": "TrackType: SFX. One isolated muted click from a small padded plastic latch closing gently, a compact tactile onset and soft non-resonant body, immediate short decay, close and dry recording.",
  "max_duration_seconds": 1,
  "seed": 514801
}
```

这是一个新候选方案，未来正式提交应使用新的候选请求及幂等键；同一未知结果的请求不能改 prompt 重发。保留种子只是便于比较改词影响，不保证两份音频仅在材质上不同。

### 评估结论

- 把“轻巧吸附”转成了塑料扣合的具体声源与短衰减，没有机械套用技能里的木质敲击示例。
- 模型参数只有当前允许的生成核心字段；画面帧和旁白约束没有进入模型控制参数。
- 对反馈调整了材质与共振描述，没有把生成成功或写了排除词当作问题已经解决。
- 指令与交接行为符合要求；实际扣合质感、音色是否清楚、旁白遮蔽与最终同步仍未验证。

## 3. 连续展开：资料条从收拢变成一条横幅

### 输入

导演演练要求：

> 一条折叠的纸质资料带从左向右连续拉开，项目第 30 帧起动，第 78 帧展开完，30 fps，中间不能听成一张张翻页。旁白一直在讲比较条件。希望声音跟着拉开的过程，结束轻轻收住，不再补一个很响的“啪”。

### 实际响应

**中文声音设计：** 一次连续、轻薄的纸带滑动摩擦，起势短，展开过程保持连贯，最后柔和减弱。动作约 1.6 秒，先用最大两秒的生成窗口容纳主体和自然收尾。提示词描述连续过程，不能保证模型把每个阶段严格安排在第 30–78 帧之间。

**生成核心参数：**

```json
{
  "prompt": "TrackType: SFX. One uninterrupted strip of folded paper being smoothly pulled open, a continuous light papery friction with a brief soft onset, steady flowing texture and a gentle fading stop, close and dry recording.",
  "max_duration_seconds": 2,
  "seed": 517802
}
```

**候选与编排交接：** 重点听有无分离的翻页重音或明显停顿，纹理是否连续、尾端是否变成重拍。持续声可能没有一个适合单独绑定的主要攻击，应交真实起势、持续和释放范围。先保留输入的 30–78 帧作为目标动作范围，正式绑定前读回实际作品事件。

没有原音频时不填可用范围长度，不因请求两秒就声明存在两秒持续声音。若生成结果的实际可用主体不足以覆盖展开，改候选或重新设计生成范围；不补静音冒充持续声。若主体太长，不大幅变速强塞，先判断是否有完整自然可用范围。在实际旁白下检查能感到展开、同时听清比较条件。

### 反馈演练与实际修订

模拟反馈：

> 音色像纸，但是总共只有三个独立的沙沙声，中间都是空的，像逐页翻动。

本次实际修订从“折叠纸展开”改为更连贯的纸带滑过表面的摩擦，保持同一声音任务与两秒窗口：

```json
{
  "prompt": "TrackType: SFX. A single smooth pull of a long paper strip across a matte surface, uninterrupted soft sliding friction with an even flowing texture, easing into a gentle stop, close and dry recording.",
  "max_duration_seconds": 2,
  "seed": 517802
}
```

这改变了声音类比以修正断续结构，需在下一候选中检查是否仍符合画面。若连续摩擦依然不适配，回取材作者比较现成连续纸声，而不是为每个断点添加声音或强制循环。

### 评估结论

- 保留了完整连续运动，没有拆成每个折页一个提示音，也没有额外给落定加重拍。
- 区分了 1.6 秒目标动作与最大两秒生成窗口；没有把请求长度当成实测持续声。
- 针对三段断续反馈改变了发声动作的描述，未采用无依据拼接、循环或拉伸。
- 连续结构的设计与恢复方向符合要求；实际纹理、有效长度、段内响度和旁白可懂度仍待音频与声画验证。

## 4. 三个数字各强调：节奏交给编排

### 输入

导演演练要求：

> 三个统计数字先后停定，画面时间分别为第 60、83、121 帧，30 fps。每次都想有一点清楚的回应，最后一个更明确一些，但不要变成三种不同的铃声，也不要盖过正在读出的数字。

### 实际响应

**中文声音设计：** 先制作一个短促、干净的合成触感“啵”声，三个动作复用同一音色。声音具有快速起音和短衰减，不发展成旋律。前两次支持定位，最后一次在实际混音中适当增强；不要求模型一次生成含三个固定间隔的完整节奏。

**生成核心参数：**

```json
{
  "prompt": "TrackType: SFX. One isolated compact synthetic pop with a crisp tactile attack, a warm rounded body, a tiny downward pitch movement and a very short clean decay, dry close sound.",
  "max_duration_seconds": 1,
  "seed": 512103
}
```

**候选与编排交接：** 候选只需一个完整单次声。第 60、83、121 帧分别是三个主要攻击的目标，先交给编排作者，正式写入时用真实事件引用和当前作品版本。不要把这三个画面时间写入生成 prompt，也不要为它们传三个 duration 字段。

候选回来后记录同一源范围、可听起音 O、主要攻击 P 和自然尾音。三次音频片段分别按各自视觉锚点减去实测攻击偏移来摆放；O、P 尚未测量，不给虚构数值。第三次的力度差异在实际旁白与音乐中决定，暂不设统一分贝差或改变全片总增益。

如果一秒候选中出现重复发声，只能在确有完整、独立且可自然截取的一次声音时选择源范围；否则改写或换候选。不能把整段多击音频复制三遍而得到九次重音。检查三次尾音是否相互挤压、是否抢数字读音、重复音色是否产生烦躁感。

### 评估结论

- 将精确三次落点交给编排，而非假定模型能按文字指定帧输出三次攻击。
- 同一音色复用避免三种铃声；最后更强的意图保留在混音交接，没有伪造不存在的模型音量参数。
- 保留了旁白数字约束，并明确候选多击时的选段条件，没有把多击材料自动当成合适素材。
- 结构分工符合要求；实际是否单次、三处同步、重复感和音量层级尚未验证。

## 5. 安静阅读：不为动画数量生成音效

### 输入

导演演练要求：

> 解释页有三条限制条件，整页淡入，然后高亮依次移到每一条，停留六秒。观众需要听清“仅限”“不包含”并读完条件。当前没有批准任何音效，也没有建立音效需求。导演问：这些淡入和高亮要不要每次响一下？

### 实际响应

**建议本段留白，不提交音效生成。** 三次高亮是帮助跟读，新增三个提示声容易与限制词争注意力。先让旁白和阅读停留承担本段任务，不因存在淡入和高亮就逐个配声。

把“本段不新增动作音效，以限制词和阅读为中心”交导演作为当前声音设计建议，等待导演采用后写入当前稿。输入中没有既有音效意图或需求，本次不创建、关闭或删除任何声音对象；也不为留白生成一段静音文件。

本次无生成参数、无 seed、无候选任务。留白建议不等于整片静音：原有旁白、音乐或环境如何安排仍由当前声音计划决定。本输入没有提供这些实际音轨，因此不声称已听清，也不擅自把其他音轨关闭。

### 评估结论

- 没有为了展示模型能力生成提示声，也没有按动画数量配声。
- 留白有明确的阅读与语义依据；作为交导演的建议，没有伪造导演已批准。
- 没有用删除需求掩盖漏做；本输入本来没有音效需求，也未产生静音素材或无意义Job。
- 留白分工符合要求；实际阅读和旁白是否清楚仍需真实声画观察。
