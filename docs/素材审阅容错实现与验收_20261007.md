# 素材审阅容错实现与验收

## 目标与边界

单张预览失败不丢弃其他真实证据；当前候选不可用时继续选材；只有明确的平台故障才报告独立修复工单。范围仅为原素材审阅，不处理动画渲染的浏览器 frame detached 错误。

审阅只生成项目 `cache/source-review` 下的可重建文件，不改变素材状态、采用记录、视频 Revision、Job 或修复工单。平台返回事实与恢复建议，主任务排序正式调用，原素材作者判断换范围还是换候选。

## 本次错误的复现

生产项目只读取原件位置与身份，将视频按原字节复制进独立候选工作区。该视频是25fps，项目是30fps。实际最后可解码帧时间戳为664.160秒；12张概览最后一个采样点为项目源帧19925，约664.166667秒。现有FFmpeg寻帧未得到下一张画面，退出成功但没有输出图片。

旧逻辑在最后一张为空时抛出整个调用错误，前面已成功的11张图片无法回传。新逻辑返回11/12张图片、失败时间点及原因未知的诊断。不能从一次尾部采样失败推断整条原视频损坏，也不能把成功图片当成完整连续观看。

本次不偷偷挪采样位置、不把其他时间的截图标成原请求位置。工作台默认20张概览与MCP显式12张是两份请求，各自如实显示成功数量。

## 实际调用链

HTTP与MCP共用 `inspectAsset`：参数与路径验证 → 素材/范围事实 → 逐张抽图与问题收集 → 连续代理 → 波形与声音分析 → 汇总 `diagnostics` → 工作台展示或主任务分流。

单张素材错误或空输出会记录并继续下一张；明确的平台故障停止剩余处理，但保留已有有效证据。图片、连续代理、波形和分析分别返回；波形成功后声音分析失败不会丢波形。声音分析子进程都结束后才返回。视频连续代理实际解码帧数必须覆盖请求范围，否则不发布为可用代理。

## 返回合同

`diagnostics` 的共享类型位于 `packages/contracts/src/source-review.ts`，服务端与工作台引用同一类型。

| 字段 | 含义 |
|---|---|
| status | complete、partial、unavailable、not_ready |
| requestedFrames / generatedFrames | 请求与成功图片数量 |
| components | contactSheet、proxy、waveform、audioAnalysis 各自的 complete/partial/unavailable/not_requested/skipped 状态 |
| continuousReview | available、unavailable、not_requested；不是审美或正式采用结论 |
| issues | stage、code、owner、message，以及可选detail、失败源时间或范围 |
| recovery | 主任务下一步的恢复建议 |
| sideEffects | review_cache_only；缓存确实写入，不冒称无副作用 |

| recovery | 主任务与原作者的动作 |
|---|---|
| none | 正常继续审阅 |
| inspect_available_evidence | 回传有效证据与缺失位置，原作者判断新局部请求、换范围或换候选 |
| select_another_candidate | 暂不采用当前候选，继续正常搜索/获取，不重放旧下载 |
| report_platform_failure | 停止受影响步骤并报修，其他无依赖工作继续 |
| wait_for_media_analysis | 等待媒体分析，不把尚未就绪标成坏素材 |

缺连续代理的range/dense不得凭截图宣称正式选段审阅通过；缺声音证据不得虚报听审完成。参数错误、非法范围和路径边界仍拒绝，不纳入素材容错。

## 分类与失败处理

空输出或超时归unknown。明确的原文件格式/解码错误归source；原视频解码能力缺失归capability。工具无法启动、受管原件丢失、无写权限、磁盘满、程序异常或平台输出编码不正确归platform。错误依据使用进程退出码、系统错误码、超时标识与有界诊断文本，不仅依赖中文提示字符串。

未能覆盖请求范围的连续代理返回 `SOURCE_REVIEW_PROXY_INCOMPLETE`，原因保持unknown；没有完整连续证据就不提供代理路径。空输出为 `SOURCE_REVIEW_OUTPUT_EMPTY`。剩余错误分类在 `source-review-diagnostics.ts` 集中维护。

缓存只在成功非空后原子发布；失败临时文件清理，不缓存负面结果，不回写Asset状态。正常的新请求可复用已成功图片并重建缺口，但剪辑任务不盲目重放旧失败请求。

## 已知代价

首版不无限重试、不自动重下载、不全量重编码；失败证据需要原作者进一步查看局部或换候选。已有视频时长探测仍可能扫描较长原视频，本次未另建探测缓存。视频短代理增加一次实际帧数核验，换取不把缺尾输出当成完整连续证据。错误分类保持保守，不能证明的原因仍为unknown。
