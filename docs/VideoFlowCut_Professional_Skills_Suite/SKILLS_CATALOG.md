## 逐项目录

### `asset-import` — 素材导入、获取与就绪管理

Import, acquire, deduplicate, localize, and register media assets with readiness, provenance, and editorial suitability checks. Use for user uploads, external stock/evidence assets, generated media, or project library reuse.

- `references/acquisition-and-ranking.md`
- `references/provenance-and-rights.md`
- `references/readiness-and-deduplication.md`

**专业参考：**
- `references/dialogue-continuity.md`
- `references/listening-and-technical-qc.md`
- `references/music-and-emotion.md`
- `references/sfx-and-sound-bridges.md`

- `references/avatar-quality-review.md`
