# Remotion 代码合同

## Props

- 可序列化；
- 有默认值；
- 命名表达内容；
- 允许修改文字、数字、颜色、资产、时长和强度；
- 不把项目 ID 或本地绝对路径写死。

## 时间

使用帧和 VideoConfig；避免依赖真实时间和不确定异步状态。

## 资产

使用受管 Asset，确保 Web Preview 和服务端渲染可访问。

## 确定性

相同 Snapshot 应得到相同输出。随机性必须显式 seed。

## 安全

- 只允许注册组件或通过审查的代码；
- 禁止任意网络请求；
- 禁止访问未知文件；
- 禁止执行系统命令；
- 构建失败时保留原 Revision。

## 验证

组件单测不能替代合成帧和连续播放。
