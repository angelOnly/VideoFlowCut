# 四轮审片

## 1. 只听声音

不看画面，从头到尾听：

- 能否理解；
- 是否像真实连续说话；
- 停顿是否有层级；
- 音乐是否压对白；
- SFX 是否过量；
- 情绪是否突然。

## 2. 静音画面

不听声音，看：

- 主视觉中心；
- 字幕可读；
- Scene 是否像 PPT；
- 是否长时间无变化；
- 是否变化过密；
- 人物和图形是否竞争；
- 空间和动作能否跟随。

## 3. 完整声画

检查：

- 动效与语义落点；
- Cutaway 与口播关系；
- 音效与动作；
- 字幕与主视觉；
- 高低密度；
- 情绪和音乐。

## 4. 首次观众

假设不知道制作过程，回答：

- 前三秒为什么继续看？
- 我知道视频在讲什么吗？
- 中间有没有迷失？
- 结尾回答了开头吗？
- 最后记住什么？
