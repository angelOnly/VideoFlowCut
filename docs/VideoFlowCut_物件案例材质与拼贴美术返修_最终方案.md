## 一、本次范围与固定参考

### 1. 修什么，保留什么

当前差距集中在三处：材料被简化成默认渐变，投影没有随形体和叠放变化，物件缺少与承载面共同构成的画面。只增加噪点、亮边或背景贴纸，不能解决这些问题。

保留六例已经改善的动作顺序、切剪关系、书脊连接、页片身份、容器遮挡和事件偏移。它们是返修基线，不是“不得纠错”的锁定成果；实际输出仍有穿插、接触或连接错误时，仅修相关几何与状态，不通过阴影掩盖。

本轮不改导演、文案、素材、字幕、配音及生产合成流程，不放开受管编译器，不迁入外部视频渲染器。物件能力与风格继续分离：本套案例采用超现实拼贴美术，不强迫其他视频使用该风格。

## 二、统一美术决定：采用什么，不采用什么

**采用“纸面承载＋哑光编辑物件＋少量材料反光”的超现实拼贴。**它不是光滑的三维图标风，也不是所有东西都做成纸片。

| 项目 | 本轮采用的做法 |
|---|---|
| 底材与色彩 | 米灰纸底 `#e9e5d9`，暖白纸面 `#f6f3ea`，墨色 `#0b1615`；橙、芥末黄、砖红和青蓝沿原色板用于物件或当前重点。不要求每例用齐全部颜色。 |
| 表面 | 纸与布偏哑光，石材有大中小尺度层次；金属有窄反射带，陶瓷只有克制的局部反光。不用同一径向高光处理所有对象。 |
| 光影 | 一个场面内，物件、受影面和接触位置的光向相容。书籍采用本方案给定的场景灯光；固定朝向石雕保留原 `HEADTEX` 烘焙的光照。允许不同案例按本场材料安排，不强行重照原石雕以满足另一例灯光。 |
| 边缘 | 纸边略不规则并有薄厚，金属刃口利落，布面有包边，石雕有切口厚度。不可给所有物件统一毛边或深描边。 |
| 构图 | 物件与受作用对象、承载面共同构图。保留现有动作路径，在同一画面中补充空间依据，不统一物件尺寸，不固定“居中物件＋椭圆影子”。 |
| 文字与装饰 | 保留有作用的身份、指认与结果，不以增加花字、胶带、太阳或纸屑冒充美术完成。主体自身与场面关系先成立。 |

以下具体材料和参数是本轮实施起点。精修只调整表现强弱，不要求所有材质达到摄影级写实，也不以纹理数量或公式复杂度衡量质量。

## 三、六例的最终返修内容

路径统一以 `.agents/skills/visual-treatment-planning/references/object-drawing/cases/` 为根。**每例最终仍是一份同源演示，不另做漂亮静态稿后重新实现。**

### 1. `scissors-cut`：保留切剪，恢复金属与纸的区别

修改 `Scissors`、`Paper`、`Motion`，保留 `cutGeometry`、切口保持、释放条件、挂签响应和当前剪切时序。

刀面使用 `gradientUnits="userSpaceOnUse"`，在刀片局部横向范围明确安排浅面、灰面和暗侧；先采用原参考 `x=-16…16` 的反射带尺度，再按当前刀面宽度匹配。刃光限制在实际刃口，刀背使用独立暗面。不得把整条外轮廓描成同样亮的金属边。

握柄保留朱橙本色，仅用宽而轻的明暗形成体积。删除一整圈同等强度的深色装饰描边，暗弧主要出现在连接处与背光局部。挂签恢复撕边、纸厚、悬挂点和轻微偏移影；影子跟随挂签，不固定在屏幕上。

纸带先作为一张连续纸面制作纹理与身份标记。分片只改变裁切区域和后续变换，不能给每片重新随机生成表面；局部剪缝的底色与实际承载层一致，不出现纯色补丁。剪刀接触纸带处补窄而轻的投影，保留“后刃—纸—前刃”的层次。

**完成观感：剪刀仍利落，金属不油腻，橙柄不发光；纸带、切口与碎片属于同一张材料。**

### 2. `magnifier-scan`：保留简洁物件，建立实际观察对象

修改 `Magnifier`、`Motion`，保留搜索、纠偏、确认轨迹及目标位置。

恢复黑镜框、黄铜内圈、淡透明镜片与短高光，不扩成乳白色玻璃饼。投影使用镜框与柄的组合轮廓，不只画镜框圆影；镜体与纸面距离固定时保持一致偏移，已有抬落时才随距离改变。

下方纸面采用有层级的短行、符号与局部标记，目标位置不变。不同信息密度为搜索提供依据，去掉纯“规则点阵控件”的界面感。不伪造真实资料，不新增光学放大功能，不添加无作用的散落纸屑。

**完成观感：观众在跟随一次寻找与确认，而不是看一个图标划过面板。**

### 3. `domino-flip`：保留厚度，恢复印刷表面与接地

修改 `Domino`、`Motion`，保留正反面身份、当前翻落与接地收势。

正面改为固有色，加低强度明暗罩层和固定细颗粒；侧面、顶面由同一固有色派生，不独立随意配色。去掉造成塑料感的强纵向渐变。物件自身的纹理随表面变换，不在屏幕坐标里滑动。

沿现有落点增加明确的承载纸面或窄平台。底部接触影使用紧贴接触边的小范围暗部，投向承载面的方向影按主体轮廓和高度形成；不继续以一个远离底边的固定椭圆代替全部投影。

**完成观感：纸片转成有厚度的印刷物件，落下后确实站住；不改成橡胶弹跳。**

### 4. `cutaway-head`：恢复原石材，不重新设计一种石头

修改 `StoneSurface`、`StoneHead`、`Motion`，保留 `HEAD_PATH`、开口、前缘、内部石阶、骨牌承载及现有镜头。

按原 `HEADTEX` 制作固定朝向的石材表面：主明暗、柔斑、细颗粒、后脑背光、下颌暗部、受光边和切口纹理一起保留。删除替代性的硬边椭圆、无来源装饰裂纹和额外五官线条。保留材料的尺度关系，不以机械凑齐颗粒数量作为验收。

表面烘焙成前后可分层的图集，具体接法见第四节。内部暗腔、石阶和活动骨牌仍实时绘制，不烘焙进图集。石阶顶面、侧面和骨牌接触影按当前承载关系安排。

**完成观感：主体像原参考的粗糙石材拼贴，而非带圆点的绿色矢量头像；推进时纹理和前缘没有错位。**

### 5. `book-open`：布面书壳、哑光纸页、随翻页发展的阴影

修改 `Cover`、`Leaf`、`Book`、`Motion`，保留书脊、`pagePoint` 方法、页身份、正文随页变化和两次翻页顺序。光影具体算法见第五节。

封面直接采用 SVG 的低对比交织纹理，不新增布纹 PNG。纹理以封面局部坐标绘制，再与封面使用同一个投影变换；细包边、脊槽与压印只提供局部层次，不使用玻璃式高光。

纸张采用暖白漫反射与很淡的局部纤维，正反面分别处理。纸内线条、纹理和轮廓共同经过 `pagePoint`，不出现文字跟着翻、纹理留在原地的现象。

移除作为唯一投影的固定书底椭圆，补齐书体投影、翻页投影和书脊／叠页暗部。页块厚度与最后落下的页片相接；必要的页间微小高度偏移从统一表面定义计算，不凭空增加页块。

**完成观感：页面的抬起、弯曲与贴合由光影共同说明；书壳像布面，纸像纸，不再像几片带字色块。**

### 6. `bowl-receive`：半哑光陶瓷与不发光的果实

修改 `Fruit`、`BowlBack`、`BowlFront`、`Motion`，保留现有接触点、滚动和堆叠顺序。

碗身采用宽柔的体积明暗，另加局部窄反光；口沿前后亮度有区别，内壁、底部和圈足有各自暗部。去掉暗—亮—暗均匀横排造成的圆柱亮带。

果实主体和纹理随自身角度转动；受光层在平移后的父坐标内保持本场光向，用旋转后的果实轮廓裁剪，不让整块高光跟着果实旋转。缩小并降低高光，补果实间及果实与碗的接触暗部。保留果实自身颜色，不做统一白心发光球。

**完成观感：碗能承载果实，接触与堆放有重量；陶瓷和果皮的反光明显不同。**

## 四、纹理与受管渲染：本轮采用这一条实现路线

### 1. 只新增两张 PNG，其余材料用 SVG

新增 `object-drawing/textures/`，固定提供：

| 文件 | 内容与使用范围 |
|---|---|
| `paper-base.png` | 按原 `PAPER` 制作 1920×1080 纸底，保留两级斑驳、低对比纤维与轻暗角。六例共用同一资源 ID，缩放到各例设计坐标，不逐帧生成。 |
| `stone-head-atlas.png` | RGBA 图集，含“完整石雕表面及切口”和“前侧遮挡表面”两个区域；来自同一份原表面，位置与裁切完全一致。只供石雕例使用。 |
| `manifest.json` | 记录资源 ID、相对路径、MIME、实际尺寸、SHA-256、生成参数与来源；石雕额外记录两个区域的像素矩形、原局部坐标和已烘焙光照限制。 |

不生成 `book-cloth.png`；书壳织纹、纸页纤维、刀面和陶瓷反光直接使用 SVG。这样避免不必要的刚性图片投影和柔性图片曲面映射，把开发集中到实际缺失的材料与阴影。

新增 `scripts/build-object-drawing-textures.ts`。使用仓库已有 Puppeteer／Chrome 能力，在隔离页面中运行明确摘取的静态绘制函数，复用现有浏览器路径配置，离线输出 PNG 和清单；不导入原视频生产流程、不新增 Canvas 运行时。固定种子、尺寸和来源；先在临时目录齐套生成，再更新纹理目录。原绘制片段作为可审计源保存在同目录的开发脚本中，记录改编范围并保留许可，不依赖每次构建临时抓取网络代码。

纸底以原 1920×1080 尺度生成，不能把原纤维数量直接塞入更小画布导致密度改变。石雕按原 `HB` 范围与 `s=2.4` 烘焙，实际取整后的尺寸写进清单。图集两区域之间保留透明隔离边；前侧区域由同一表面按当前近侧轮廓裁切，不另绘一张可能错色的前脸。

### 2. 图像与 SVG 使用同一个设计坐标，但作为同级图层

现有案例保留 `960×540` 设计坐标。根层使用固定尺寸的定位容器，按当前作品尺寸统一等比缩放并居中；图片、SVG 和阴影共用此容器的变换，不分别执行不同的 cover／拉伸。

石雕内部图层顺序固定为：

```text
纸底 Img
→ 石雕场面共同相机容器
   → 承载面投影 SVG
   → 石雕图集的完整表面区域 Img
   → 内腔与石阶 SVG
   → 活动骨牌及其接触影 SVG
   → 石雕图集的前侧遮挡区域 Img
```

图集取区使用 `overflow:hidden` 的绝对定位容器配合内部 `Img` 的像素偏移；整个区域一起从纹理像素坐标映射回 `HB` 局部坐标。两个区域使用同一比例和原点。图集自身 alpha 负责复杂轮廓，不依赖将 HTML 图片塞进 SVG 裁剪。

只用普通 `Img` 和 `style`，不使用 `effects`、`onError` 回调、`image href`、`foreignObject`、运行时 Canvas 或 CSS 时间动画。动态变化继续由当前帧计算。官方 `Img` 的加载能力不代表当前项目允许它的全部扩展 API，须遵守现有白名单。[实现依据 A、B]

石雕图集已含固定光照，因此本例只保留现有平移、等比缩放和观察推进，不新增三维转头或大角度转身。动态石阶与骨牌光影按图集中已形成的方向配合，不重复叠一套反向整体受光。

### 3. 资源怎样进入案例与正式作品

每例新增 `resources.json`，只声明本例实际需要的“槽位 → 纹理 ID”，不把文件路径写入 MotionSubmission：

```json
{
  "images": {
    "paper_base": "paper_base",
    "stone_head": "stone_head"
  }
}
```

上例只用于石雕；其他五例只声明 `paper_base`。图集区域坐标等绘制参数放在 `demo-props.json` 的普通 `props` 中，并与纹理清单校验。不得在 `props` 手工写 `assets`，不得编造项目素材 ID。

隔离案例脚本读取资源字节，验证后构造 `imageData[slot] = data:image/png;base64,...`，调用现有 `renderManagedMotion(work, output, imageData)`。正式任务则沿现有素材导入取得实际 Asset ID，再写 `imageBindings`，源码始终读取 `props.assets[slot]`。二者使用同一份纹理和绘制代码。

本轮各例仅占 1～2 个图片槽。正式场面合并时共用相同纸底槽位，不按物件实例重复绑定；与真实图片共同遵守当前每作品最多 8 个图片槽的合同，不改上限。[实现依据 A]

缺文件、哈希不匹配或缺少必需槽位时，停止本次案例生成／推荐，给出具体资源名，不静默改用纯色。原视频生产链路不因此增加新的全局阻断。

## 五、书籍光影：明确几何、接收面与绘制层次

### 1. 采用的范围与计算方法

本轮使用插画式 2.5D 光影，不引入三维引擎或完整光线追踪器。保留现有两张页先后翻动、不同时翻动的时序；正在运动的封面或页片投向当时静止的页块、已展开封面或桌面。这些接收面按实际几何表示为平面多边形。

新增同文件辅助函数：`pageNormal`、`shadePaper`、`receiverSurfaces`、`projectShadow`、`drawReceiverShadow`。与物件状态和事件共用当前场面时间，不单独写第二条阴影时间线。

以下数值是本例确定的初始画法参数，输出后允许在同一画法内精修强弱；不将它们变成所有视频的规则。

### 2. 纸面受光

沿 `pagePoint(u,v,turn)` 的相邻采样求切线，再求法线；不要继续用横向宽度绝对值代替受光。

```text
Tu = ∂P/∂u                         // 由相邻采样差求得，边界使用单边差
Tv = (0, 1, 0)
N  = normalize(Tu × Tv)
V  = normalize((-0.204, 0.833, 0.5684))  // 对应当前 project 的观察方向
L  = normalize((0.55, -0.80, 1.30))      // 指向灯光，投影后来自画面右上
Nvisible = dot(N,V) >= 0 ? N : -N
brightness = 0.70 + 0.30 * max(0, dot(Nvisible,L))
```

正面暖白、背面稍暗暖白分别着色，均采用上述柔和漫反射，不增加纸张镜面亮斑。颜色在统一的线性颜色空间计算亮度再转回显示颜色，避免反复用整数色阶产生条带。

每条曲面带两端计算受光，再用连续渐变衔接。优先保留现有 32 条几何带，不用大量新增细分掩盖接缝；移除造成重复暗缝的描边，以很小覆盖余量消除栅格细线，并检查中途自遮挡。绘制顺序按可见面和空间关系组织，不能靠把全部纸页最后盖上解决。[实现依据 C]

织纹与纤维也在物件局部坐标中生成。封面采用一个小尺寸、低对比的交错短线 `pattern`，显式设 `patternUnits="userSpaceOnUse"`；不要给已经投影成屏幕路径的封面直接填屏幕固定纹理。

封面是刚性平面，纹理使用下面的仿射映射，不需要图片扭曲库：

```text
O = project(coverPoint(0,0))
U = project(coverPoint(1,0)) - O
W = project(coverPoint(0,1)) - O
SVG transform = matrix(U.x U.y W.x W.y O.x O.y)
```

在这个 `g` 的局部坐标中画封面、织纹、包边和压印，使用同一映射；厚边仍按自身面绘制。封面内外两面分开，不能把正面纹理或压印简单镜像到背面。页片纤维经过同一个 `pagePoint`；固定种子不随帧重新取随机结果。

### 3. 动态投影

`receiverSurfaces(t)` 从当前书的几何取出桌面、左右可见静止页面和已经展开的封面内面。每个接收面包含平面原点 `P0`、法线 `Nr`、边界多边形和绘制层级，不能另造一组与书体无关的阴影坐标。

对活动物件表面的采样点 `S`，使用背离光源的方向 `D=-L`：

```text
lambda = dot(Nr, P0-S) / dot(Nr, D)
Q = S + lambda * D
```

分母接近零或 `lambda <= epsilon` 时不产生有效投影。只使用交点位于接收面多边形内的正向射线；同一条射线命中多个面时取最近有效接收面，不能让被上层页截住的影子继续穿到桌面。

活动页使用现有条带划成的小三角片投影；跨接收面边界的片先细分和裁切，再按接收面合并为阴影区域。不要把跨越书边的一大块多边形只做透明度渐变。由于当前只有一个活动翻页面，不开发“任意多个柔性物体相互投影”的通用系统。

各接收面先画自身材料，再画落在其上的阴影，之后画更前方的真实物件。阴影先合并成同一接收面的不透明轮廓遮罩，再统一应用透明度，避免三角片重叠处加倍发黑。边缘柔化在局部范围内进行，最终再次裁切在接收面内，不让模糊溢出成为悬空黑雾。

在 `960×540` 设计坐标下，投影初始最大不透明度取 `0.18`；局部遮光物与接收面的距离记作 `h`，软边取 `clamp(0.5 + 0.03*h, 0.5, 5)` 像素。按接收面与距离分小组柔化，远处不与接触边共用一个大模糊值。软边表达大面光源的插画近似，不声称物理精确。

### 4. 接触暗部与书体投影

书脊与页片落定位置单独绘制窄暗部，初始宽度 `1～3` 设计像素、不透明度上限 `0.22`，随实际间距衰减。它不随整个翻页进度无条件变亮变暗。

页片落定后，其高度、页厚和承接位置必须相容。当前平面近似产生悬空缝时，沿已有书脊连接做局部高度修正，不移动整个书脊，也不通过加粗黑影遮住缝。

整本书对桌面的影子使用封面、页块和活动页的实际投影轮廓形成，闭合与展开状态不同；删除固定椭圆作为唯一空间依据。接触暗部和较远投影分别保留，不用一层全局 `drop-shadow` 替代全部关系。

**验收重点：页片抬起时影子偏移并变软，贴近时收紧；书脊和页厚始终成立；没有漂浮黑块、投影穿页、条带接缝或高光贴图滑动。**
