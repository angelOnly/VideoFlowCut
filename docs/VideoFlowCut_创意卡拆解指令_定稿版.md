# VideoFlowCut 创意卡拆解指令与参考案例

> **任务用途：**交给 Codex Worker，从项目已有参考视频中抽取完整、可理解、可迁移的创意卡。不另找新视频，不制作新成片，不修改正式生产 Skills 或生产链路。
>
> **核心目标：**还原一段优秀画面背后的完整视觉设计：创作者选择了什么内容和材料，怎样组织主体、空间、构图、镜头、动作与节奏，这些选择如何共同形成观看价值；换成新内容后，怎样保留这种设计价值并重新创作。
>
> 一张卡保存一个完整场景中的视觉表达方案。场景可以包含多个镜头、素材和表现步骤；划分依据是表达是否完整，不是切镜次数。
>
> 方法正文是通用规范，附录案例只用于说明写法，不规定其他作品的题材、结构、句式或必须采用的视觉技巧。
>
> 原视频共用，创意范围独立确定。创意卡与已有动效机制范围不一致时，从原视频按创意卡范围另切视频，并选取覆盖该范围的分镜；不为共用旧切片改变创意边界。

## 一、任务范围与资料准备

### 1. 任务目标

每张创意卡必须让没有看过原片的后续创作者，能够理解并回答：

1. **原片具体怎样表现？** 画面从什么状态开始，主体和材料怎样进入，经过哪些重要变化，最后形成什么结果。
2. **整段视觉设计怎样组织？** 为什么先出现这个画面，为什么接下来改变观察对象，为什么某份素材要占据主画面，为什么其他元素在这个时刻出现或让位。
3. **创意价值从哪里来？** 具体材料、构图、镜头、动作和顺序如何共同带来观看价值，而不是只说“很有创意、很高级、很丝滑”。
4. **哪些设计值得迁移？** 找到原作真正有价值的设计关系、成立条件和关键依赖，区分不可丢失的核心与可替换的外观。
5. **换成新内容怎样重新设计？** 指令能指导另一个创作者完成新作品的主要视觉构思，而不是只留下一个概念，让下游重新猜整套表现。

创意卡不是旁白摘要、镜头列表、九宫格说明、动效名称集合、风格词汇集合，也不是对作者主观意图的猜测。

### 2. 资料定位与保护范围

先定位项目实际根目录，读取：

- `references/motion-cases/skillry/README.md`
- `references/motion-cases/skillry/case-catalogue.json`
- 对应案例目录中的完整原视频、总览、已有分镜和机制资料。

通过现有索引取得真实案例编号、目录、视频和分镜路径。不按标题猜路径，不从插件缓存复制另一套资料。若本地目录已经变化，沿项目说明定位真实位置，保持原有相对组织方式。

处理范围以当前案例索引或用户指定范围为准，不把教学案例自动加入案例库。现有拆解可以辅助定位，创意分析仍须回到视频及必要声画上下文。

允许新增创意正文、按创意范围截取的视频、必要分镜、派生索引和一份完成记录。原视频、原分镜、已有拆解、编号和原有索引保持不变。不修改正式 Skills、生产流程、播放器，不增加代理、数据库或模型服务。

### 3. 观察资料的优先级

1. **完整原视频：**了解全片结构、场景之间的关系和候选段落上下文。
2. **完整创意片段：**连续观看当前创意单元，确认画面发展、运动、节奏和交接。
3. **必要前后上下文：**确认本段从哪里来、把注意交给哪里，避免误判创意边界。
4. **九宫格与补充分镜：**辅助定位构图、重要状态和关键中途，不代替连续观看。
5. **文案、字幕和声音：**核对声画分工、准确语义、语气和节奏锚点；不能用旁白推测画面中没有出现的动作。

路径存在、文件能打开、抽帧成功，不代表已经完整观看。必须记录实际观看范围、是否原速连续观看、是否听审、哪些信息仍未知。

### 4. 观察方式与可信度

- 完整创意片段至少原速连续观看一遍。
- 对快速动作、遮挡、镜头穿越、画面接管和关键中途，可慢放或逐帧观察。
- 需要判断动作节奏、惯性、连续性、声音配合时，不能只依靠抽帧。
- 如果工具无法连续播放，可分段观察，但分段需要保留重叠上下文，最后核对整体连续关系。
- 只完成抽帧观察，标记 `frame-only`；只看局部，记录准确覆盖范围；未听审不得推断声音设计。
- 不允许把模型生成的画面描述当作已经观看原片的证据。

## 二、怎样划分一个完整场景

### 1. 场景与创意卡的基本定义

“场景”指围绕一项主要表达任务，由相互关联的画面安排构成的连续范围。它可以包含素材替换、视点改变、时间跳转和多次剪切，不要求发生在同一物理地点，也不要求同一个对象始终在场。

“完整”指使这项表达成立的必要内容和画面过程已经包含在范围内，读者能够看清它怎样建立、怎样发展以及完成了什么。完成的可以是信息理解、关系揭示、情绪变化、视觉体验或一个被充分建立的问题，不要求解决全片主题，也不强制出现故事结局。

创意卡记录这个场景中相互配合的整体安排。一个局部步骤有价值，不意味着它需要单独建卡；是否独立，取决于它是否形成了另一项完整表达。

### 2. 完整场景的判断依据

| 判断方面 | 需要确认的实际内容 |
|---|---|
| 表达任务明确 | 可以辨认本段主要向观众提供什么，而不只是知道全片在谈哪个题材。 |
| 画面组织成立 | 素材、人物、文字、空间、观察与声音之间存在可说明的配合方式。 |
| 必要起点齐全 | 范围包含理解主要表现所必需的身份、状态、关系或观察前提。 |
| 关键表现完成 | 对本段起决定作用的变化、对照、显露或形式发展已经发生，必要回应和结果没有被截掉。 |
| 结束位置有依据 | 当前安排已提供主要观看价值，或明确把注意交给下一项独立表达。 |

场景完整不等于必须具有冲突、反转、悬念或因果故事。对于主要提供展示、感受或形式体验的视频，按其实际表现的建立、发展与完成判断，不能虚构一条故事来套标准。

### 3. 实际定位起点与终点

先按顺序了解整条视频的内容和画面发展，记录主要表达任务与画面组织发生变化的位置。此时只标记候选边界，不立即按每次换图或切镜生成卡片。

对每个候选范围，找出主要表达实际成立的位置，以及为了理解这一表达必须保留的前置内容。向前保留必要的场面建立，向后保留使变化看清、关系成立或注意交接所需的内容。

起点以本场必要的画面安排开始建立为依据，终点以本场主要表现完成或明确交接为依据。与本场无直接作用的长尾停留不自动纳入；仍在完成表达的停顿、回顾和重复也不能机械删掉。

源时间只用于定位原片，不是新作品必须继承的时长。固定秒数、字幕数量、已有切片长度、九宫格数量以及工具单次分析上限，都不能决定场景边界。

创意边界先从完整原片判断，随后才检查有没有可复用切片。一张创意卡可以跨越多个已有动效机制切片，也可以只覆盖某个机制范围中的一部分；两类条目无需一一对应。不得从现有机制切片反推、缩短或扩展创意范围。

### 4. 怎样判断相邻部分应合并还是分开

**应保留在同一张卡：**后段仍在兑现前段专门建立的安排；前后共同构成主要观看价值；拆开会失去铺垫、比较依据、变化过程或结果。内部使用不同素材、镜头或技巧，不改变这种依赖。

**可以分成两张卡：**前段已完成自身表达，后段开始另一套可以独立说明和采用的视觉安排；两段可以分别采用；合并反而模糊迁移用途。

这里检查的是使当前创意成立的直接依赖，不是全片所有信息之间的联系。后文引用前文事实，或沿用同一视觉包装，不足以把整片合成一张卡。也不能因为每个内部步骤都能命名，就把整体拆开。

### 5. 防止范围过碎或过大

划分后按视频顺序复看所有范围。若相邻卡片必须相互补读才能解释同一个主要效果，检查是否应合并；若一张卡里存在多套已各自完成、可以分别采用的表达，检查是否应分开。

正式卡片优先选择同一分析层级。不同时将一个整体和它的每个内部步骤重复登记为平级卡片。跨场景的整片组织关系记在该片总览中，内部步骤保留在卡内。

无法确认边界时，补看前后内容并说明疑点。用户限定的观察范围截断必要过程时，不编造收尾，也不将局部材料标为完整场景；记录缺少范围。分批观察不产生新卡。

### 6. 保存场景划分结果

每条视频在 `creative/overview.md` 中记录各卡 ID、实际起止、表达范围、边界依据和正文链接。媒体完成后补充对应切片与分镜入口。内部阶段不另分配卡片 ID。

普通衔接、重复内容或暂未发现独立创意价值的范围可以不建卡，在总览中说明。每条视频的卡片数量由实际表达决定，不设固定配额。

## 三、怎样从完整画面中拆出创意

本节是创意拆解的核心。必须按以下过程完成，但不要把每个子项机械写成表格。最终正文应是一份自然、具体、能够还原作品的分析，而不是问卷答案。

### 第一步：确认内容任务、观众已有信息与材料事实

结合当前场景和必要上下文，弄清：
- 片中实际交代什么内容；
- 观众进入本段时已经知道什么；
- 本段结束时新增了什么理解、信息、期待或感受；
- 旁白、字幕、原始素材、画内文字、音乐和音效分别承担什么；
- 本段的内容任务与全片主题有什么区别。

检查实际使用的影像、图片、文档、界面、图形和文字，辨认哪些属于原始材料，哪些是编辑加工；材料中的行为、状态和内容必须有画面或来源依据。不要把片中陈述自动写成已经独立核实的事实。

**产物：**表达任务、观众进入时已有信息、结束时新增信息/感受、声画分工、材料事实清单。

### 第二步：按时间顺序还原原片，不急着解释创意

依据真实顺序描述场景，不替原片重新编排。说明主要材料的呈现方式、相互关系、画面重点及其变化，保留使整段成立的建立过程、重要中途和结束状态。

每个实际阶段建议还原：
- **时间范围：**原片中的真实起止位置。
- **初始状态：**主体、材料、文字、背景和镜头当前是什么状态。
- **画面变化：**哪些对象进入、离开、移动、变形、被遮挡或显露。
- **关系变化：**变化后对象之间的空间、信息或注意力关系发生什么改变。
- **观众获得：**此时新增了什么可见信息或观看体验。
- **阶段结果：**画面留下什么状态，后续如何承接。

描述应让未看过视频的人能够大致想象原片。对理解有作用的尺度、位置、层次、遮挡、显露、文字配合和观察变化要交代清楚；不影响主要表达的细小参数无需全部抄录。

内容发展与画面发展一起写清，但不要把旁白摘要当作画面描述。单列动作名称也不够，需要说明动作作用于什么、怎样影响其他内容以及形成了什么可见结果。

**本步骤只还原事实，不提前写“为什么好”。**这样后面分析创意时，能区分原片确实做了什么和分析者认为它为什么有效。

### 第三步：还原整段视觉设计——不是逐项罗列元素

一段优秀画面通常不是主体、素材、构图、镜头、动作各自独立发挥，而是创作者做出一系列相互关联的设计选择。拆解必须进一步还原：**这些选择为什么按这个顺序出现，它们如何共同组织观众的观看过程。**

#### 3.1 找出整段的视觉主线

先用一段话回答：
- 这段画面从什么视觉状态开始？
- 观众最初被引导看什么？
- 主要对象/材料怎样逐步成为主角？
- 画面经历了哪些重要状态变化？
- 最后观众看到什么结果？
- 这段画面的主要价值是怎样被画面呈现出来的，而不只是旁白讲了什么？

视觉主线不一定是故事因果。它可以是对象从多到少、局部到整体、浏览到操作、静态到动态、材料到空间、现象到机制，也可以是情绪、节奏或纯视觉形式的发展。必须根据原片判断，不能强行套用“建立—冲突—反转—解决”。

#### 3.2 还原视觉注意力如何发展

按实际过程说明观众的注意力如何被组织：
- 初始注意落在哪里？为什么那里最先出现？
- 什么时候出现新的关注对象？
- 新对象进入时，旧对象是退出、缩小、让位、保留还是变成背景？
- 观众的观察范围有没有从多个对象收敛到一个对象，或从局部扩展到整体？
- 视觉重点转移时，是否有动作、形状、位置、遮挡、颜色或镜头运动作为引导？
- 最终主次关系如何形成？

不要只写“突出重点”“聚焦主体”。要写清具体是什么从哪里变到哪里，谁让位给谁，观众为什么会跟着看。

#### 3.3 还原材料怎样共同参与设计

逐一确认主要素材的角色及变化，不只列出素材名称：
- 哪份材料是主要观看对象，哪份提供上下文、证据、对照或空间？
- 材料是并列出现，还是一份材料引出、覆盖、映射、穿透、承载或接管另一份材料？
- 材料本身是否被重新组织、裁切、放大、分层、变形或移动？
- 材料的真实内容是否决定了构图、镜头或动作方式？
- 一份材料是否在前后阶段承担不同角色？
- 多份材料同时出现时，是否有主次、先后或空间层级？
- 如果把真实材料换成通用图标或抽象色块，画面会失去什么？

尤其注意**素材不是最后才放进去的背景**。拆解应指出素材的可见特征怎样影响创意本身。例如，文档的可读区域决定镜头怎样取景；照片的明暗和空间决定某种变化是否可见；视频中的真实动作可以成为动画接续的依据；物件轮廓和结构可以成为空间设计的主体。

#### 3.4 还原构图与空间怎样服务整段设计

不要只给静态构图贴标签。说明：
- 初始构图怎样建立主体和辅助层；
- 主体面积、位置、比例和视觉重心怎样变化；
- 背景是承载空间、环境、对比还是参与动作；
- 留白、遮挡、重叠、前后层怎样为后续元素预留位置；
- 新对象进入时，原构图如何调整；
- 镜头变化后，主体与背景的空间关系怎样变化；
- 画面结束时形成怎样的整体构图。

如果一段作品从九宫格选择一个图像，随后图像放大成为满幅，再让控制条附着在画面底部，就要说明这是一个从“多对象浏览”到“单对象聚焦”再到“对象与控制共存”的构图发展，而不是分别写九宫格、放大、控制条三个效果。

#### 3.5 还原文字与图形怎样参与创意

区分原始素材中的文字、字幕和后期画内文字。分析文字是说明、证据、主体、空间结构、标记、比较依据，还是动作参与者。

重点说明：
- 文字为何在这个时刻出现；
- 它与真实素材的关系；
- 它是否改变主体的可见面积或主次；
- 它是否被物件承载、遮挡、拆分或接管；
- 它是否只是旁白的重复；
- 图形是否真正参与内容变化，还是纯装饰。

不能因为画面有花字，就认定它具有创意。必须说明花字在整段设计中承担了什么不可替代或有价值的作用。

#### 3.6 还原镜头怎样参与创意

对镜头运动要说明它带来的观看变化，而不只记录“推近、拉远、横移”：
- 镜头为什么从这个视点开始？
- 推近后观众看见了什么原先看不清的细节？
- 拉远后观众发现局部属于什么更大的结构？
- 跟随镜头让观众持续观察哪个对象？
- 穿越或遮挡变化怎样建立新空间？
- 镜头移动与物件运动是否同时发生？各自负责什么？
- 镜头变化是否只是装饰性运镜，还是改变了观众对材料/对象的理解？

如果镜头运动没有带来新信息、空间关系或观看重点变化，就如实记录为视觉修饰，不夸大为创意核心。

#### 3.7 还原动作之间怎样协作

动作不是孤立的动画列表。要找出动作之间的关系：
- 谁发起动作，作用于哪个对象？
- 哪个对象跟随、响应、让位或被接管？
- 哪些动作同时发生，哪些必须先后发生？
- 前一个动作留下什么状态，后一个动作怎样沿用？
- 主动作和辅助动作如何形成主次？
- 动作结束后哪些对象继续留在画面中？
- 哪些动作只是入场/退场，哪些真正改变了画面关系？

对关键动作可补充启动、加速、通过、制动、惯性和收势，但不要把每个小动作机械拆成完整的物理运动阶段。重点是还原它对整段创意的作用。

#### 3.8 还原节奏与观看窗口

分析整段视觉节奏：
- 哪些阶段快速推进，哪些阶段需要稳定阅读或观察；
- 哪些动作交叠，哪些动作需要等待；
- 画面什么时候出现重音，什么时候收稳；
- 是否存在连续发展，还是动作完成后画面等待旁白；
- 停留是否有阅读、比较、情绪或欣赏价值；
- 声音是否参与动作提示、动作落点或情绪节奏（必须真实听审后才能写）。

节奏不是平均切镜，也不是每秒都动。需要说明快慢、强弱、停顿和动作密度怎样服务于整段观看过程。

#### 3.9 汇总整段设计的组合逻辑

完成上述观察后，必须用一段连贯说明回答：

**这段作品不是把哪些效果放在一起，而是怎样通过哪些设计选择，让观众从初始状态走到最终结果？**

至少说清：
- 视觉主线；
- 注意力如何变化；
- 真实材料如何参与；
- 构图/空间如何随内容发展；
- 镜头和动作怎样配合；
- 节奏怎样安排；
- 这些选择之间的先后、依赖或接力关系。

这是本次拆解与“分别分析主体、构图、素材、动作”的关键区别。前面各项是证据，最后必须把证据重新组织成整段的设计逻辑。

**本步骤产物：**“整段视觉设计还原”。它应能解释多个设计选择如何共同工作，而不是重复前面的元素清单。

### 第四步：识别主创意、支撑设计、表面形式与技术实现

不要把所有画面安排都提升为核心创意。一段作品可能只有一个主创意，其他安排只是帮助它成立的视觉手段。

- **主创意：**决定本段为什么值得观看、最有辨识度的设计。
- **支撑设计：**让主创意能够看懂、发展或获得回报的构图、素材、镜头和辅助动作。
- **表面形式：**颜色、字体、装饰、包装、具体道具等，可能值得参考，但不一定是核心。
- **技术实现：**遮罩、曲线、变换、合成等实现方式，本身不自动构成创意。

对主创意至少回答：
1. 原片具体做了什么设计？
2. 观众因此看到了什么、理解了什么、期待了什么或感受到什么？
3. 为什么这项设计比直接展示、普通切换或简单文字说明更有观看价值？
4. 哪些材料特征、对象关系、信息顺序、空间条件或动作响应使它成立？
5. 如果拿掉某个关键对象、动作或镜头，观看价值会损失什么？
6. 哪些只是原作的外观，可以替换？

可用下表帮助分析，但最终正文应自然解释，不要只交表格：

| 设计层级 | 原片具体表现 | 在整段中的作用 | 是否不可缺 | 可替换内容 |
|---|---|---|---|---|
| 主创意 | 具体安排及其发展 | 主要观看价值 | 必须保留的关系 | 外观/题材等 |
| 支撑设计 | 构图、素材、镜头、辅助动作 | 帮主创意成立 | 按作用判断 | 可替换实现 |
| 表面形式 | 色彩、字体、包装、装饰 | 气质或识别 | 通常可替换 | 由新项目决定 |
| 技术实现 | 遮罩、变换、曲线等 | 完成视觉效果 | 不等于创意 | 可换实现 |

核心创意可以是材料关系、空间探索、尺度变化、视觉隐喻、信息揭示、幽默、情绪发展、形式体验或其他方式。不得强制每张卡都有冲突、反转、悬念或故事因果。

### 第五步：解释为什么这样设计，以及观看价值从哪里来

用普通语言解释具体画面安排与观看效果之间的联系。不能只写“使用撕纸效果，所以有创意”，而要说明原材料最初怎样被观众认识，后续动作如何改变材料状态，变化后出现什么新内容，原材料是否继续提供上下文，以及为什么这个过程比直接切换更有观看价值。

不能只写“通过镜头拉远展示整体”，而要说明拉远前观众看到什么局部，拉远后发现它属于什么更大的结构，局部与整体的关系是否因此变得更清楚。

分析必须建立在前面记录的材料、关系、显露顺序或表现过程上。不要用“高级、丝滑、有冲击力、很有创意”等评价词代替原因，也不要只复述视频讲述的主题。

没有作者公开说明时，将创意意图标明为作品分析。预期观看效果不是已经测得的观众反应；不声称推断作者真实思考过程，也不虚构效果实验。

### 第六步：提取可迁移设计方法——必须分清三个层级

迁移的目的不是把原作总结成“空间感”“动态拼贴”“视觉揭示”，而是把原作中真正有用的设计知识分层保存，让后续创作者能在不同任务中选择合适的层级使用。

每张卡都要判断以下三个层级是否存在迁移价值。不是每张卡都必须三层齐全；没有独立价值的层级写“不单独提取”，不能为了填满模板硬造。

#### 6.1 第一层：创意设计方法（回答“怎样构思”）

这是跨题材价值最高的一层。它不复述原作题材，也不只是抽象情绪，而是提炼原作如何把内容转化成值得观看的表达。

分析时按以下顺序推导：

1. **原作要解决的观看问题：**观众原本只会听到/看到什么？原作希望观众进一步发现、理解、比较或感受到什么？
2. **原作采取的创意选择：**创作者选择了什么对象、材料或关系作为表达入口？为什么这个入口比直接说明更有表现力？
3. **创意成立的关键：**观众必须先认识什么，随后发生什么变化，最后获得什么新的认识或体验？是否必须保持同一对象、同一空间、真实证据或前后状态？
4. **可迁移的构思方法：**把上述设计转成新任务也能使用的思考方式，但必须保留条件。例如“让观众先认识一个具体对象，再通过同一对象的可见变化理解某项调整”比“让变化更直观”具体；它仍须限定为新内容确实存在同一对象和可见变化。
5. **不适用条件：**新内容缺少相应对象、关系或前后状态时，不采用这条方法。

创意设计方法必须能指导创作者“如何想出画面”，不能只说“增强代入感”“制造反差”“让表达更有趣”。同时不能把某个案例的具体结构泛化成所有视频的固定公式。

#### 6.2 第二层：视觉编排方法（回答“怎样组织画面”）

这一层保留原作如何安排主体、材料、空间、视线和时间顺序。它比创意原则具体，但不限定新作品必须使用相同物件或相同版式。

逐项提取真正影响观看的组织方法：
- **主体组织：**主体如何建立、取得主位、让位或交接；
- **材料组织：**真实素材怎样被阅读、比较、叠加、穿透、承载、接管或持续保留；
- **构图组织：**多对象与单对象、前景与背景、局部与整体、控制层与内容层怎样变化；
- **镜头组织：**观察范围为何改变，镜头运动带来什么新信息；
- **时间组织：**先建立什么、何时转移注意、何时允许阅读、何时完成结果；
- **连续关系：**前一阶段留下什么状态供后一阶段沿用，哪些变化必须连续可见。

把每项方法写成“适用情形 + 组织关系 + 关键过程 + 结果”，不能只写“多图收敛到单图”“素材与文字结合”。必须解释收敛时谁让位、主体是否保持身份、镜头是否重新取景、前后状态如何对应。

#### 6.3 第三层：具体表现方法（回答“怎样实现动作和镜头”）

这一层记录可直接供视觉作者和动效库检索使用的表现方法，例如：
- 主体保持身份的放大/缩小；
- 周围对象让位、重排或退场；
- 控制层附着在真实素材边缘；
- 参数、滑块与同一画面变化同步；
- 镜头推进、拉远、穿越、跟随或局部取景；
- 遮挡、显露、接管、形状匹配和动作交叠。

但必须写清动作主语、作用对象、前置状态、运动关系、辅助对象、结束状态和适用条件。只记录“缩放、遮罩、弹性、推镜头”没有迁移价值。

具体表现方法通常可以链接到动效机制卡，不要把整套动效机制重复抄入创意卡。创意卡保存“它为什么服务于这段创意、在整段中承担什么作用”；机制库保存“动作如何具体实现”。

#### 6.4 判断适不适合迁移：核对成立条件

对原作主创意逐项检查：

- **内容条件：**新内容是否有相应事实、关系、过程或观看任务？是否会误导观众？
- **素材条件：**是否有能承担相同作用的真实素材？清晰度、可读性、结构和源动作是否足够？
- **对象条件：**新材料能否保持主体身份、比较参照或前后状态？
- **空间条件：**原作依赖的前后层、遮挡、穿越、尺度变化或局部/整体关系能否成立？
- **动作条件：**原作关键动作是否有新对象可以响应？是否有真实或可设计的动作依据？
- **时间条件：**段落时长、旁白和素材时钟是否容纳必要的建立、变化、阅读和结果？
- **表达条件：**迁移后是否仍帮助观众理解或观看，还是只剩漂亮效果？

每项标记为：
- **满足：**当前素材和内容有明确依据；
- **可通过设计满足：**需要裁切、分层、补充素材或改变表现方式；
- **不满足：**缺少必要材料或内容关系，不能硬套。

关键成立条件不满足时，不得只因原卡优秀就强行采用。可以换参考、改用结构迁移、请求补材或放弃该方法。

#### 6.5 选择迁移方式

- **直接迁移：**新内容的材料类型、观看任务和关键关系高度匹配。保留原作主要视觉发展和关键设计关系，替换实际对象、事实内容和外观。
- **结构迁移：**原作核心关系有价值，但原主体、材料或形式不适合新内容。保留必要关系，重新设计对象、空间和动作。
- **组合迁移：**一个主参考提供创意骨架，其他参考只补充具体动作、镜头或接续缺口。必须写清主参考决定什么、辅助参考补什么、两者怎样构成同一连续表达；禁止按案例顺序拼接。
- **不迁移、重新原创：**原作条件不匹配或参考无法改善当前表达。原创不是失败，硬套才是失败。

#### 6.6 完成“原作—新作品”的设计映射

每个被采用的主参考都必须完成映射。不要只写“原作的纸张对应新作品的报告”。

| 原作中的设计要素 | 原作具体作用 | 新作品对应内容/素材 | 新作品如何承担该作用 | 保留/改造/放弃 |
|---|---|---|---|---|
| 创意目的 | 原作给观众什么观看价值 | 新内容的观看任务 | 是否仍然有意义 | … |
| 主体/材料 | 原作谁/什么承担主要作用 | 当前真实素材 | 如何成为画面主体或证据 | … |
| 关系/顺序 | 对象、信息、空间或动作关系 | 新内容的对应关系 | 如何重新建立 | … |
| 关键变化 | 原作什么变化带来价值 | 新对象发生什么变化 | 如何使变化可见 | … |
| 镜头/编排 | 原作如何改变观察 | 新素材的观察目标 | 怎样发现或比较 | … |
| 结果 | 原作最后留下什么 | 新作品结果 | 怎样形成并接续 | … |

映射目标是找到新素材能够承担的视觉行为，而不是给素材分配静态角色。同一份素材可能在不同阶段承担主体、证据、空间、动作源和结果等多个角色，必须说明具体用途。

#### 6.7 用删除/替换测试检查迁移是否空心

1. **删除关键关系：**去掉原作最重要的材料关系或动作，观看价值是否明显改变？如果没有，可能只迁移了表面形式。
2. **替换真实素材：**把新作品素材换成任意图标、色块或通用视频，方案是否仍完全一样？如果是，素材尚未真正进入创意。
3. **去掉参考名称：**删掉卡片ID和参考描述，只看本片方案，是否仍能看出它保留了原作的有效设计方法？如果不能，只是口头引用了参考。
4. **换一个题材：**方法是否仍能在满足相同条件的另一类内容中成立？如果不能，需把适用范围写窄，而不是硬说它具有普遍性。

这不是评分表，而是定位迁移是否空心的检查方法。

### 第七步：把迁移结果写成完整创意指令

创意指令必须让接手者知道：这段新作品采用什么主意、为什么适合、需要什么材料、画面怎样发展、哪些关系不能丢、哪些形式可以自由变化。

指令至少应包含以下信息，但不要求机械使用固定句式：

1. **适用内容：**当前段落要表现什么类型的内容或关系。
2. **主创意：**本片具体采用什么视觉表现，而不是“参考某案例”。
3. **材料选择：**应选择什么真实材料，材料的可见特征为什么适合。
4. **材料作用：**每份重要材料在画面中承担什么作用，是否随过程改变角色。
5. **核心关系：**哪些对象、信息、空间或动作关系使创意成立。
6. **完整发展：**从入口到结果，画面按什么逻辑发展；中途变化怎样引出下一阶段。
7. **镜头与动作：**哪些镜头观察、动作协作和接续关系需要保留。
8. **节奏与观看：**哪些地方需要快速推进、稳定阅读、比较或停留。
9. **迁移边界：**哪些是必须保留的功能，哪些外观和技术实现可以重做。
10. **失败条件：**缺少什么素材或事实条件时应改变方案或放弃。

**指令必须具体到创作决策，但不必写死实现参数。**它需要决定“让哪份材料做什么、怎样发生、为什么这样发生”，不需要决定每个像素的位置、每帧坐标、具体CSS曲线或所有美术参数。

不要将指令写成：
- “参考某案例，做出高级感”；
- “通过空间变化制造层次”；
- “素材与动效自然结合”；
- “让画面更有创意、更丝滑”；
- “使用某机制完成转场”。

这些句子没有告诉下游真正要设计什么。

应将原作关键关系和新素材映射写进同一份指令，不要把“创意方法”“适用条件”“完整讲法”重复写成三段同义话。

### 第八步：回原片复核

核对原片还原是否准确、设计关系是否有画面依据、核心创意是否提取正确、迁移方法是否保留关键价值、失败条件是否合理。不要用自评打分代替复核。

原片效果、拆解是否准确、新题材迁移是否有效是三个不同结论，分别记录。只完成观察和拆解的，标记为“原片拆解”；没有实际新题材制作测试，不标记为“已验证迁移”。

## 四、创意卡最终包含什么

来源信息、视频入口与分镜置于正文前。正文保留三项主要内容，避免重复维护同义章节：

| 正文部分 | 必须讲清的内容 |
|---|---|
| **1. 原画面具体怎样设计** | 场景内真实使用的材料、组织关系、完整发展及结束方式；整段视觉注意力如何变化；素材、构图、镜头和动作如何共同工作。描述必须能与原片对应，不是旁白摘要。 |
| **2. 为什么这样设计，好在哪里** | 主创意、支撑设计、观看价值、成立条件及关键依赖。解释具体选择如何产生观看价值，不夸大效果，不冒称作者自述。 |
| **3. 可直接使用的创意指令** | 将适用条件、材料选择、必须保留的关系、主要安排、完整过程、可调整部分和失败条件写成一段完整方法。指令应能指导新作品创作，不只提供灵感。 |

三部分分别负责还原原片、解释价值和指导新任务。相同事实可以为不同部分提供依据，但不将同一套可迁移方法重复写两遍。

### 1. 卡片元数据

```yaml
---
id: "<实际案例编号>-c01"
case_number: <实际案例编号>
title: "<能够说明主要讲法的名称>"
summary: "<完整表达方式的简要概括>"
use_when: "<适用的内容与材料条件的简短检索提示>"
video: "<相对于本卡的完整原视频路径>"
start_ms: <创意范围在完整原视频中的实际起点>
end_ms: <创意范围在完整原视频中的实际终点>
clip: "<相对于本卡的完整创意切片路径；允许引用范围一致的已有视频>"
storyboard: "<相对于本卡的真实分镜路径>"
frame_times_ms: [<所引用分镜各格对应的原视频时间>]
---
```

正式文件将占位内容替换为核实结果。正文中保留实际作品名称、源时间范围、完整原片与创意切片链接、嵌入分镜，以及观察方式和未确认范围。标题与摘要只负责让人认出讲法，不强制压成特定句式。

`video` 始终指完整原视频；`clip` 指便于直接观看本张卡的完整片段。范围恰好是整条原片时，两者可以指同一文件。存在可复用的已有切片时，`clip` 指其真实路径，不要求一定存在一个新的 `creative/c01.mp4`。

`start_ms`、`end_ms` 与 `frame_times_ms` 全部以 `video` 为时间基准，范围采用起点包含、终点不包含的约定。切片内部播放从零开始，切片内时间等于对应源时间减去 `start_ms`；不能把源时间直接当作切片播放器时间。


## 五、创意范围、视频切片与分镜的独立生成和复用

### 1. 完整原片共用，片段按创意范围独立确定

完整原视频是共用来源，不复制、不覆盖、不移动，也不重新编码它。创意卡始终保留原片路径与本卡源时间，以便复核上下文。

**创意卡不必与动效机制使用同一段视频。**两者的分析单位不同，原有机制片段的起止不决定创意片段的起止。先按第二节确定完整创意范围，再判断是否存在内容与范围一致的文件。

每张完成的创意卡应有可以直接观看其完整范围的视频入口。没有合适的现成切片，就从完整原片按该卡范围生成新视频，默认保存为 `creative/c01.mp4` 等。新切片是具有独立分析范围的必要产物，不视为重复保存整条原视频。

不能为了省去新切片而拆碎一张创意卡、拉长卡片范围、只链接一个局部机制片段，或者要求读者自行拼看多个短片才能了解完整创意。

### 2. 什么情况下复用，什么情况下另切

| 实际情况 | 处理方式 |
|---|---|
| 已有切片来自同一原片，起止边界与本卡一致，内容、顺序、画幅、原速和原声均可用 | 直接引用已有切片路径，不再复制同内容视频。 |
| 创意范围跨越多个机制切片，或与已有切片部分重叠 | 从完整原视频截取这一整段，生成独立创意切片。 |
| 创意范围位于一个较长机制片段内部，或现有片段缺少创意的必要开头、发展或结尾 | 按创意自身范围重新截取，不调整创意边界迁就现有文件。 |
| 本张卡恰好覆盖完整原视频 | 直接把原片作为观看入口，不重新导出一份同内容视频。 |
| 原片不可用，或无法核对已有切片来源和边界 | 记录具体缺口；不把无法确认的局部切片标成完整创意，也不宣布该卡媒体已完成。 |

是否复用依据实际媒体和源范围核对，不按文件名相似、时长接近或画面内容相似判断。只有实际起止落在同一源帧边界，才视为范围一致；涉及编码或时间精度差异时，核对实际首尾帧并记录结果，不把“大致包含”算成一致。

**不把多个旧机制切片拼接成创意切片。**旧片段可能删过停留、缺失连接或带有重叠，拼接容易改变原片顺序、节奏与声音。需要新范围时直接回完整原片截取，保留该范围内所有实际变化和必要停顿。

### 3. 新切片的生成与核验

按核定后的起止范围截取，保持原速、原画幅、内容顺序与原有声音。不额外添加标题、字幕、音效、淡入淡出、补帧或黑场，不把内部平静范围删成快剪。

边界需按源视频实际帧时间核定。不能为了使用快速关键帧拷贝而随意扩大或截短范围；需要准确截取时，仅对新切片做必要编码，完整原片和既有机制切片保持不变。

检查切片可解码、首尾与原片对应、主要过程完整、声音未错位。时长应与实际选定范围一致；音视频编码粒度造成的尾部差异如实记录，不能将缺少关键画面当作允许误差。

创意边界修订后，只更新受影响的创意切片、分镜、正文和索引，不覆盖被复用的旧机制文件。若修改后不再满足复用条件，建立新的创意切片并更改引用。

### 4. 九宫格按创意整体选帧，不依赖旧切片的分镜

先确认创意范围和主要过程，再选分镜。默认一张3×3九宫格，按源时间从左到右、从上到下排列。选帧要覆盖场面建立、重要关系变化、关键中途、完成状态和必要交接，具体分配由内容决定，不机械等间隔采样。

每格保留原画幅和有用的边缘信息，时间标记不遮挡内容。只使用真实源帧，不重绘、不补造状态；清晰度应支持辨认主体与关键文字。九格是展示方式，不是九个镜头或九张卡。

已有图片来自同一原片、能够覆盖本卡完整主要过程、顺序与时间可核对且清晰度足够时，直接引用原路径。仅来自同一视频或同一机制，不代表分镜适用。整片64宫格可以辅助定位，不能冒称某张创意卡的局部分镜。

没有适用图时，从原片选取属于创意范围的帧，新增 `storyboards/creative-c01.jpg`。九格不足以说明重要过程时，可追加必要分镜，不靠拆卡或删阶段迁就版式。其他文档需要同一张图时也引用这个文件。

复用图没有时码时，可回源片核定后将时间记入卡片，不必仅为加时码复制图片。旧分镜使用切片内时码的，应核对其来源起点并换算为原片时间，不能直接沿用为 `frame_times_ms`。

### 5. 视频与图片分别判断是否复用

视频能否共用与分镜能否共用是两次独立判断。可以引用已有切片而新做九宫格，也可以新切视频而引用已经完整覆盖同一创意的分镜，不要求二者必须成套复用或成套新建。

共享原则是“同一个实际文件只保存一份”，不是“两个库必须使用相同的分析范围”。部分重叠的切片允许各自保存，不为去重把不同创意压到相同边界。

生成前检查已有文件与引用，避免重复导出相同范围。临时定位切片、密集抽帧和中间单图放在工作目录；正式创意切片与最终分镜属于长期产物，不能按临时文件删除。

## 七、批量处理与完成检查

逐片完成观察、创意范围确认、正文拆解、切片复用判断或生成、分镜选择、原片回查，再更新派生索引与完成记录。实际处理范围以当前索引为准，不因旧文档中的数量描述省略或虚增条目。

中断后根据记录与实际文件继续，复用有效成果，不重建相同切片与分镜。卡片采用稳定ID；修订范围时同步核对该卡的媒体引用、总览和索引，避免同一含义留下重复版本。无须新增数据库或独立媒体服务。

### 1. 拆解质量验收

| 检查项 | 合格标准 | 不合格表现 |
|---|---|---|
| 场景完整 | 保留必要建立、关键变化、结果和接续 | 只截取一个动作或效果 |
| 原片还原 | 未看过视频的人能理解完整画面发展 | 只有旁白摘要或镜头名称 |
| 整段设计 | 解释多个设计选择如何共同组织观看过程 | 只分别列主体、构图、素材、运镜 |
| 材料参与 | 说清素材的真实特征和画面作用 | 素材只是文件名或背景配图 |
| 创意判断 | 区分主创意、支撑设计、表面形式、技术实现 | 把每个动效都称为创意 |
| 价值解释 | 说明具体选择为何带来观看价值 | 只用“高级、丝滑、有冲击力” |
| 成立条件 | 说清必要材料、对象关系、动作和顺序 | 只提抽象概念 |
| 迁移可用 | 新作者知道如何映射、保留、替换和何时放弃 | “参考某卡，自由发挥” |
| 观察可信 | 连续观看、抽帧、听审和未知范围如实记录 | 抽帧冒充完整观看 |

### 2. 用未参与拆解的人验证卡片

选择一名未参与该卡拆解的视觉作者，只给他卡片正文、片段和分镜，要求其回答：
- 原片的主创意是什么？
- 整段画面如何发展？
- 哪些材料承担了关键作用？
- 哪些关系不能丢？
- 换成新题材时需要什么材料和条件？

如果他只能复述题材，或者必须重新观看原片才能猜出主创意，说明卡片没有拆透。如果他能理解原作，却无法将方法用于新内容，说明迁移指令仍然抽象。

不以卡片字数、表格数量或术语数量作为质量标准。拆解质量看能否还原设计和指导迁移。

### 3. 迁移验证状态

- **原片拆解：**已完成原片观察与分析，但没有新题材测试。
- **迁移试用：**已将方法用于一个不同内容，记录实际方案和遇到的问题。
- **已验证迁移：**已完成新题材作品，并确认核心设计关系在新材料中成立。
- **不适合迁移：**原作本身有价值，但适用条件过于特殊，当前库中只作为理解案例保留。

不得把原片拆解完成直接标记为已验证生产方案。

### 4. 交付检查

- 场景保留必要依赖，没有因局部技巧拆碎，也没有仅凭题材相同合并整片。
- 边界来自完整创意的建立与完成，不是迁就已有机制切片。
- 正文能够区分原片事实、设计分析和迁移建议。
- 主创意有具体画面依据，不是风格词或动作名称。
- 整段视觉设计说明了注意力、材料、构图、镜头和动作如何共同工作。
- 成立条件、关键依赖、可替换部分和失败条件清楚。
- 每张完成卡都有完整原片引用、核定源范围、可观看的完整片段入口和覆盖主要过程的分镜；缺少则标记未完成。
- 复用切片确实范围一致；新切片首尾、时长、声音与原片对应。
- 所有路径能解析到实际文件；源时间与切片内时间正确区分。
- 原片、原机制资料、旧分镜和旧切片未被覆盖或移动。
- 卡片、总览、派生索引与完成记录一致，未完成范围和观察限制如实说明。

最终交付创意正文、完整原视频引用、按创意范围可直接观看的切片、相应分镜、派生索引和一份完成记录。允许媒体路径复用，不允许用不完整片段代替。

## 八、后续怎样使用这些卡片

根据当前文案、真实材料和需要解决的表达问题选择候选。读取完整卡片、创意切片与分镜；需要上下文时回到完整原片。核对创意指令中的适用条件，再将原片中的材料作用映射到当前材料，不能只替换人名、文件名或素材ID。

采用时保留让创意成立的关系，重做受新内容影响的安排。同一卡内的步骤作为整体理解；组合不同卡片时，确认前一段的结果能够支持后一段的起点，再统一主次、空间、声音与必要交接。

把具体采用内容、真实素材和必要参考交给现有制作流程，不只传卡片编号。本文件仅规范创意参考资料，不据此新增生产环节。

## 附录一：完整创意卡示范——先选中画面，再让控制直接改变它

本例根据用户提供的011-c02拆解内容整理，用于展示如何将“整段视觉设计逻辑”写进创意卡。它不是对原片重新核验的报告；观察状态沿用提供内容中的说明：本轮抽帧观察，未原速连续观看或听审。因此，动作节奏和声音相关结论不超出已有证据。

### 来源与范围

- 原案例：库内011，twoclipping，画内名称 `develop.`。
- 来源页：https://skillry.dev/ai-videos/opus-5-5/twoclipping-496100
- 原片范围：00:00.000—00:10.200，起点包含、终点不包含。
- 原片：`../video.mp4`
- 创意片段：`c02-restudy.mp4`
- 分镜：`../storyboards/creative-c02-restudy.jpg`
- 观察方式：全片每0.5秒源帧；7.5—11.5秒每0.1秒观察操作与交接；未原速连续观看或听审。
- 未确认：声音内容与画面同步感、界面真实可操作性、素材生成方式。

### 1. 原画面具体怎样设计

开头在暖白底上放大号黑色“develop.”，下方小字为“from screen to wall.”。约0.5—2秒，文字收去，黑点、黑色胶囊形与“Develop”按钮先后形成；指针接近按钮。约2—3.5秒，黑色区域呈现光圈叶片般的线条，圆形开口里先出现暗处橙红门洞及小人物，随后成为较大的圆角图片。名称、可操作入口和内容以形状接续，并非三张分离的标题卡。

约3.5—5.5秒，周围的图片陆续出现，形成紧凑的九图集合：人像、风景、运动与科幻画面各有不同颜色和构图。橙红门洞图留在集合中央。指针转到右侧石拱门风景，目标图片扩大，其他图退让、重新排布；石拱门取得主要面积并在约6秒接管全画面。此前的集合说明“它来自可选内容”，放大则把观看任务从浏览多张图转为仔细看这一张。

约6—7.5秒，满幅图保留草坡、石拱门、蓝天与飞鸟；画面里短暂显出较淡的“relax”字样，之后视点靠近草坡和拱门。图片本身一直占据主要面积，尚未出现整页编辑器或密集参数。

7.5—8.6秒，透明圆角操作条在画面下方建立。指针到心形图标处，心形从空心变实心；随后指针转向右侧调节图标，原图标组让位，操作条展开为“Golden hour”调节条。面板可见下方的画面，界面没有把被操作的主体遮住。

8.6—10.2秒，滑杆从左端向右增长，数值由0增加至100；与此同时，蓝天逐渐转为暖色，光源在石拱门内变得明亮，草坡与天空整体获得夕照。拱门、山坡和花草位置持续可认，改变的是光照观感。约9.8秒数值到100，随后仍保留结果与控制条。范围止于10.200秒源帧起点，此时调整结果已展示，之后的界面退场与圆形换图交给下一张卡。

这些图片、按钮和指针是原视频中可见的材料；不能确认它们来自实际软件录屏、动画样机还是其他制作方式。调节值表示原片界面显示，不代表经过测量的真实光照参数。

### 2. 整段视觉设计是怎样组织的

这段不是“图片库、放大、操作条、滑杆”四个效果的简单串联，而是连续收敛观众注意力，并逐步建立“对象—控制—结果”的关系。

首先，品牌字样转成可操作入口，再通过形状相似的开口引出真实图片。抽象品牌名没有停留在标题层，而是成为进入内容的入口。随后多张图片同时出现，建立可选对象集合；当指针选择石拱门图片时，其他图片退让，目标图取得全画面。这个放大不是单纯强调图片，而是把观众从“浏览一组候选”带入“观察一个确定对象”。

目标图取得主画面后，构图没有立即被完整编辑器覆盖。操作条以轻量、半透明方式附着在画面下方，使控制入口和被控制对象同时可见。随后操作条从多个图标收敛成当前调节项，观众的注意从“可以做哪些操作”进一步收敛到“当前正在改变什么”。

最后，滑杆的数值变化与同一幅图的光照变化同步出现。石拱门、草坡和天空持续保持身份，观众可以直接比较变化前后的状态；画面不是换成另一张夕阳照片来假装参数生效。控制条没有盖住主要变化区域，参数到达终点后也保留结果，给观众时间看清作用。

因此，这段的整段设计逻辑是：**从抽象入口进入内容，从多对象浏览收敛到单一主体，再让控制与主体共存，最后让控制变化直接作用于同一主体。** 画面每次收敛都减少当前需要理解的对象数量，同时保留完成下一步所需的上下文。

### 3. 主创意、支撑设计与成立条件

**主创意：**让调整的价值直接发生在观众刚选中并认识的画面上。观众先知道被调整的对象是什么，再看到控制项，最后直接看到同一对象发生变化。

**关键支撑设计：**
- 图片集合与选中放大：建立选择前提，并把浏览任务转为单对象观察。
- 控制条附着在画面下方：控制与结果同时在场，但不夺走主体面积。
- 多图标收敛为单一调节条：将注意集中到当前操作。
- 参数与画面同步变化：建立控制值与视觉结果之间的直接对应。
- 结果保留：让观众确认调整后的状态，而不是在变化完成时立即切走。

**材料成立条件：**
- 被调整的图片必须有稳定、容易辨认的主体；
- 调整前后必须能保持同一主体身份；
- 画面中要有足以表现该参数变化的区域；
- 变化不能只改变无关细节，必须让观众能看见效果；
- 控制界面不能遮住主要变化区域；
- 如果要表现连续调节，参数变化和画面变化必须能建立可信对应。

石拱门素材适合这一演出，不只是因为它是一张漂亮风景图：固定的石质轮廓提供前后对应，门内天空为亮光变化留出明显位置，前景草坡又能显示整体光色变化。若换成没有明显明暗层次、主体频繁改变或无法保持前后对应的图片，调节结果就不容易被看清。

**可替换形式：**品牌字样、圆形开口、具体图片题材、玻璃操作条、图标、字体和配色均可按新项目重做。不能丢失的是：先建立被操作对象；控制与对象共存；操作和结果直接对应；变化后保留足够的结果观看时间。

### 4. 可直接使用的创意迁移指令

当需要展示某种控制、调整或操作究竟带来什么效果时，先选取一份能清楚显出变化、且调整前后仍保持主体身份的真实材料。若内容确实包含选择步骤，可以先用少量有差异的候选建立选择场景；目标对象被选中后，让其他候选退让，使目标取得足够的观看面积。若本身没有选择过程，就直接建立目标，不为套用案例强行添加图库。

先让观众看清未调整状态，再把必要控制放在不会遮挡变化区域的位置。控制界面应围绕当前对象组织，而不是先铺满整个编辑器；多个入口可以在操作发生时收敛为当前需要的控制项。操作触发后，让指针、数值或控制位置变化与同一对象的画面结果在同一时段建立对应。逐步变化必须保留稳定主体和可比较参照，不能借换图冒充参数作用。到达目标状态后保留足够的结果观看时间，再移走控制或接下一项独立表达。

材料题材、面板外观、控制方式、配色和构图可按新内容调整，但必须保证控制改变什么、结果出现在哪里、前后哪部分仍是同一个对象都清楚。若实际功能只能产生离散结果，就据实表现切换并保留前后对照，不虚构连续调节；若没有可信的变化关系，则采用普通作品展示，不暗示这是可操作功能演示。

**本例的迁移价值：**多对象到单对象的视觉收敛；控制界面与真实对象共存；操作与结果同步对应。这三项可以被不同内容分别采用，但只有在新素材具备相应条件时才适用。

本卡为原片视觉拆解，尚未验证新题材迁移效果；动作连续性与声音设计仍需原速观看和听审后确认。
