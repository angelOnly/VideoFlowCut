## 调用链、失败处理与代价

`read_motion_capabilities`查询目录 → `fontBindings`声明槽位 → 目录/格式/SHA-256校验 → Worker准备原件 → 浏览器首次挂载前加载 → `props.fonts`注入 → 帧驱动自由绘制 → 完整作品与字体副本校验。

加载兼容OTF/CFF和TTF/TrueType，后缀必须匹配文件头；单文件上限32MiB。缺失、未知字体、变更、损坏、格式不符与加载失败明确报错，不偷偷换字体或登记半件Asset。作品缓存按原格式保存，旧OTF缓存路径保持可读。

新增八份原件共185544372字节，约177MiB。目录共四个字族、十二份实际文件；文件数不是不同字族数。保留原件使发行较大，但不引入字体转格式、改名元数据或子集构建流程。

正式切换前必须完成独立候选工作区与独立端口验证。安装通过宿主官方插件安装入口完成，不手工覆盖已安装缓存。切换后使用全新MCP连接核对Release ID与API、媒体Worker、渲染Worker健康；原剪辑任务仍须重新连接，修复任务不代它确认或修改视频项目。
