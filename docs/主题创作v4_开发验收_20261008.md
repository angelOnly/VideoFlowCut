## 主要调用链与失败处理

主题输入 → 主任务真实分派导演与相关作者 → 当前完整草稿和粗分镜 → 素材反馈及共同改稿 → 同一视觉作者深化美术、中途与源码 → 导演统筹 → 主任务按原 MCP 合同提交 → 当前预览回原作者 → 修订与专业审片。

`creativeBrief` 继续承担现有摘要职责；全文使用现有消息或附件，`CreativeDecision.evidence` 保存引用，不增加 `fullCreativeScript`。MCP 回归先检查 `isError` 并保留原始文本，再解析 JSON；参数拒绝不能被 JSON 解析异常掩盖。该测试证明平台引用保存与文件往返，不证明所有宿主传递永不截断。

缺全文或表达接替退回原作者；输入变更先交差异，不仅更换 Revision。普通搜材未命中继续探索，素材审阅按现有 recovery 分支处理；未知写入和实际工具故障保持原报障、对账及禁止盲重试合同。字体选择、来源许可、安全和正式项目唯一写入规则保留。

## 真实宿主行为试验

实际调用 `spawn_agent` 创建 `/root/v4_director_trial`、`/root/v4_motion_trial`，再用 `followup_task` 把新版声音范围交回原动效作者。这里记录真实调用与返回；不以本文件替代宿主记录。每位接收者自行读取角色入口和完整原指令；只有动效作者查看了一张明确标记的历史静帧。

| 方案反例 | 输入与实际返回 |
|---|---|
| 一次搜材失败后取消全部真实过程 | 主题“手机照片为什么占满空间”，普通查询未命中，无平台错误。导演没有取消全部素材或报修，返回文件信息、视频播放、多拍挑选及存储页四项具体搜索范围，并说明个别镜头仍缺时怎样改稿 |
| 只有“移入、放大、淡出”的弱稿 | 给定“旧的关注需要让位，新安排才看得清”。动效作者返回完整 M1：旧板与新板交叠、首次露字、最大交叠、通过速度、稳定阅读、源时钟和出口；暂定尺寸均标记为夹具设计 |

| 只有静帧 | 查看归档 `f0520.jpg`。返回“有新旧交叠和局部竞争风险”，明确不能判断持续多久、源重播或声画同步；没有登记当前作品动态、听审、首次观众或用户批准 |
| 已采用共同参考但提供无关模板 | 导演没有采用“五产品扇形展开”做全片，返回围绕相册格子、真实文件信息与占用归属的完整候选正文和粗分镜；没有复制直播案例外壳 |

M2 可复核的具体差异：第一句群增加0.5秒、第二句群增加0.3秒，入口分别后移0.6和1.1秒，结尾后移1.4秒。原作者把新板完整建立试排为5.08秒，在第二句群5.2秒前留0.12秒设计余量；这些是新设计而非音轨实测。它同时保留5.2–7.6秒稳定阅读是否足够有内容的待审问题，未用漂浮遮掩未知。

导演返回完整候选稿 D1 与六段粗分镜，并删除原稿未经核实的“清理即可”。这些输出支持本轮文字行为判断；没有实际手机材料、生成声音或新动画，不能登记新主题成片通过。
