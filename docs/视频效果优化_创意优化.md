## 0.2 统一职责原则

本次恢复的是 0.1.92 的视觉作者完整创作责任，不是恢复旧时代所有代码都由一个 Agent 手写。

- 主导演：准确内容、讲述主线、材料需求、主要采用和跨段关系。
- 素材作者：发现、获取、核实真实素材，返回可用范围和观察结果。
- 创意作者：研究完整视觉参考，提炼可迁移的创意方法。
- 视觉作者：唯一持续负责整幅视觉创作的人，负责把真实素材、文案、参考转化为完整画面，并对预排、OD 制作结果和返修负责。
- OpenDesign 制作作者：在视觉作者已经确定的主要画面方向上深化美术、构图细节、运动、时序和源码；发现主要设计问题时反馈，不静默重做。
- 主任务：负责分派、资源、项目写入、版本、Run、冻结、采用和正式合成，不代替专业角色做视觉决定。

视觉作者是视觉创作负责人；OD 是实现与深化作者。 两者不是互相替代，也不是让视觉作者只写文字、OD 从头重新创意。

## 1.2 流程解释

- 素材、创意、文案和视觉从首轮即可并行，不设置“先完成 A 才能开始 B”的僵硬串行依赖。
- 视觉作者必须从真实素材返回初期就参与，不得等完整分镜冻结后才开始视觉工作。
- 导演持续协调，不是等所有作者交完稿后一次性审核。
- 已经具备素材、参考和内容条件的场面可以先推进；其他场面继续补材和研究。
- 视觉作者在 OD 之前必须完成主要画面设计，并在当前作品中形成可连续检查的预排。
- OD 阶段返回后，由同一个视觉作者继续检查和返修；不得在制作阶段丢失原视觉负责人。
- 正式项目写入、MotionWork、Run、冻结、采用、Cue 和合成继续走现有链路。

```
2. 哪些内容可以由真实素材直接承担。
3. 哪些内容需要多个真实素材共同表达。
4. 哪些关系可以通过取景、放大、镜头变化、画面接管和重新构图呈现。
5. 哪些内容确实无法由真实材料表现，需要原创图形或示意。

视觉作者负责：

- 真实素材观察和画面机会判断。
- 完整场面创意与视觉组织。
- 参考迁移、美术、构图、排印、背景和镜头。
- 主体、真实素材、图形和文字的共同运动。

导演不替视觉作者决定每个镜头的布局、色彩、字形、运动参数；视觉作者也不擅自改变事实、用户锁定项和整片主线。

导演检查视觉作者交回的完整画面方案和实际预排，而不只检查文字分镜。

采用前检查：

- 本场实际使用的素材及其可观察内容。
- 真实素材在整场中的视觉作用。
- 创意参考对构图、观看距离、文字和运动的影响。
- 原创图形承担的具体内容及必要性。
```

```
## 五、沿真实观看机会组织场面

先找观众能够看到的真实对象、行为、关系和变化，再决定画面如何发展。

一个场面可以由单段真实视频、多段视频组合、真实视频与文字共同构图、真实视频与辅助图形共同表达，或在确实没有适用真实材料时由原创图形承担主要表达。

判断时区分：

- 素材实际拍到的行为。
- 通过取景、放大、裁切和镜头可以重新组织的内容。
- 需要编辑图形解释的关系。
- 真实素材没有提供、不能冒充实拍的假设行为。

“有差异”不自动等于双卡片；“有过程”不自动等于流程图；文案中的动作不自动等于一段独立动画。

## 六、形成同一份当前声画稿

当前稿写清：

- 准确句群、事实和用户锁定项。
- 真实素材、源范围和已观察内容。
- 本段入口、主要观看对象和主行为。
- 哪些对象、环境、声音或比较依据持续存在。
- 关注如何从当前对象转移到下一对象。
- 画面已经表达什么，语言还需补充什么。
- 出口由什么接住。
- 尚未核实的素材和创意缺口。

简单镜头短写，复杂连续范围展开。不要另建一份与当前稿重复的分镜、视觉清单或技术参数表。

## 七、采用与返修

导演检查准确内容、主线、材料充分性和跨段关系。视觉作者检查实际画面。创意作者检查参考迁移。素材作者处理补材。

视觉作者必须在实际作品中形成可检查的预排，不能只交文字分镜。导演采用主要内容与跨段关系，不替视觉作者完成构图和动作设计。

预排或 OD 作品返回后，先看实际画面，再判断：

- 内容或主线问题：导演与文案。
- 素材缺口：素材作者。
- 参考迁移不足：创意与视觉。
- 画面构思偏弱：视觉作者。
- 已确定设计未实现：OD 制作作者。

所有修改回写同一份当前稿，保持有效版本和真实观察范围。
```

## 6.1 架构验收

## 6.2 画面验收

- 真实视频不是只作为背景或短暂插入。
- 真实主体的构图、观看距离、取景、放大和接管真正参与画面发展。
- 文字、背景、画框、线条和图形与真实素材形成统一构图。
- 主体和空间有明确变化，不是只有标题和图形在动。
- 创意参考的核心视觉关系能够从实际画面辨认。
- 不再默认采用标题卡、编号步骤、流程图和说明卡片组织所有场面。
- 原创图形只承担真实素材无法直接表达的必要内容，不因制作方便替代主要真实素材。

- 真实视频源时钟正确，容器变化不导致重播或跳时。
