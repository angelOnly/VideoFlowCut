# 动效机制检索优化：实施与验收

日期：2026-10-09。

已为项目内120个案例的744条运动机制补齐统一检索分类，并接通只读 MCP、按需加载 Skill 和网页候选比较。网页承担浏览与预览，当前 Codex 承担自然语言理解、候选核读与组合判断。

## 完成范围

分类分为10大类：建立与累积、排列与重组、聚焦与展开、覆盖与揭示、替换与接管、形变与分合、路径与连接、触发与反馈、环绕与往复、回收与退出。每条机制另有动作、入口状态、出口状态、保持条件和连接锚点；没有证据的条件留空。

五种查找方式已实现：

| 方式 | 输入与结果 |
| --- | --- |
| 自然语言分阶段 | 将连续需求拆成几段运动描述，分组召回候选 |
| 已有状态与保持条件 | 依据当前画面、要保持的关系和禁止动作缩小范围 |
| 相似机制 | 从已有编号查找近似演法，同时返回动作与关系差异 |
| 前后接续 | 用出口与入口状态召回前段或后段，说明重合条件和连接缺口 |
| 候选比较与恢复 | 保存候选顺序和采用项，通过网页链接恢复供 Codex 核读 |

机制页保留标题、完整分镜、摘要顺序，提供分类与条件筛选、分页和候选入口。比较页支持排序、移除、采用和复制恢复链接；宽屏双列、窄屏单列，复用已有分镜，不生成图片副本。

筛选联动补充：`mechanism-filters.mjs` 复用查询结果，按其余条件计算每组选项数量；无匹配的新选项禁用，同组可替换，已选项可逐项移除。保持条件与来源案例收进“更多筛选”。旧链接或关键词仍可能没有结果，此时给出最少解除条件的恢复方案和真实数量，用户点击后才应用；候选清单保持不变。文字查询只缓存当前一次，切换条件和翻页不重复召回。

## 文件与主要调用链

- `references/motion-cases/skillry/cases/*/mechanisms/*.md`：机制正文与分类唯一来源；同名 JPG 为机制分镜。

- `mechanism-index.json`、`mechanism-search.mjs`、`selection.mjs`：派生索引、共用查询与候选链接协议。
- `tools/library-store.mjs`、`apps/server/src/motion-library-tools.ts`：安全读取正文和分镜，注册 `search_motion_mechanisms`、`read_motion_mechanism`。

- `tests/motion-mechanism-search.test.mjs`、`tests/motion-library-tools.test.ts`：检索、恢复、安全边界和真实 MCP 协议回归。

调用链为：当前作者读取 Skill → 理解需求并调用搜索工具 → 共用查询读取有效索引 → 按编号读取少量入围正文及分镜 → 在当前声画稿中记录采用项与连接改造 → 实际制作和预览。网页修改通过候选链接显式读回，不另建同步服务。

去除原先以大量自由表述的“变化目的”作为主要筛选的方式；旧链接仍可辅助定位。没有逐机制注册 Skill，也没有在 docs 中维护第二套可执行技能。正文、检索索引与网页共用一份数据来源。

## 失败处理与已知代价

过期索引、未知编号、越界路径、库外链接和缺图明确报错，读取失败不创建 Project、Revision 或 Job。候选链接存在失效条目或来源变化时保留告警，不静默覆盖采用判断。自然语言否定先交 Codex 判断约束作用的层级，不把“外框别动”扩大成禁止全部内部位移。没有匹配时可调整表述或软条件，不能自动放宽用户硬条件。

采用本地词表、同义词和文本排序，没有引入向量库或外部模型服务。代价是候选仍需 Codex 核读；状态重合只能提示可连接性，实际连续观感必须制作和预览后判断。

本次分类依据已有机制描述、起止和关系，前10例另外核对分镜；没有重新连续观看120条视频。测试通过不代表全部语义检索正确，也不代表新片的美术或运动观感通过。

研究、截图和临时验收报告保留在被忽略的 `.local-archives/motion-retrieval-upgrade/`，正式参考库不依赖这些文件。
