# VideoFlowCut：导演参考与素材协作完整实施文档

**实施目标：让导演根据讲述和画面构思提出准确的素材需求，让素材作者找到、取得并交付能够实际使用的内容，再由文案、视觉与动画共同完成视频。**

本文是交给 Codex 的完整实施要求。按本文整理现有 Skills 和相关获取逻辑，完成测试与项目现有的插件同步；不需要拼接其他方案，也不需要用户逐段提供修改位置。

**阅读与执行：** 第1—8章是完整工作方法；[第9章](#skills-implementation)提供10个文件、17处修改的完整 Skills 正文；第10—11章说明代码配合、同步与验收。正文和文件实施内容一起交给 Codex。所有“直接写入”内容都包含在本文，不附另一套替换片段包。

本任务涵盖指定案例的参考方法、导演的取材方法、相关角色的完整协作、素材取得后的使用，以及应清除的通用限制。唯一教学案例是 `motion-case-attention-programme` 中的《02｜时代变化、直播等候与节目安排》。文中案例事实来自其 `references/original-input.md`；教学请求与实施要求是据此形成的方法，不是原作者的搜索日志或已经验证的新成片。

> **导演把“这段内容需要怎样的画面”说具体；检索对来源和材料保持开放；材料回来后，当前稿和实际画面一起完善。**

## 1. 整个任务怎样运作

### 1.1 工作主线

```text
当前主题、讲述与已有材料
        ↓
导演、文案、视觉共同构思声画草稿
        ↓
导演写出具体取材请求
        ↓
素材作者寻找、比较，并推动取得
        ↓
实际材料回到导演、文案与视觉
        ↓
更新讲述、取景、构图和前后接点
        ↓
深化动作、声音与字幕，制作实际片段
        ↓
观看当前作品，按具体问题修改并完成全片
```

指定案例从第一次相关构思开始参与。它帮助角色理解内容、材料和演出怎样相互配合，不是等动画开始编码以后才打开的效果清单。

草稿与取材之间可以往返。前期先确定值得寻找的内容，不必等全片所有机位、动作和时长都定完；实际素材回来以后，再落实与它有关的裁切、主体位置和源内动作。已经有材料的部分可以继续制作，仍然缺少的内容同时推进。

### 1.2 每个角色负责完成什么

| 角色 | 实际工作 | 应交回的结果 |
|---|---|---|
| 导演 | 选择观看过程，把讲述与画面构思转成具体取材请求；统筹材料反馈 | 当前声画草稿、明确的取材请求、吸收素材后的采用决定 |
| 文案 | 与导演共同组织讲述；根据实际材料改变措辞、顺序和声画分工 | 准确全文、对应观看过程、需要一起调整的句群 |
| 视觉与动画作者 | 前期帮助明确可见细节；随后基于实际材料完成造型、构图与演出 | 材料用法、关键构图、动作中途、声音接点和实际作品 |
| 素材作者 | 根据导演的请求寻找、比较、取得并选择可用范围 | 文件、实际内容、已选范围、具体用法和有价值的新发现 |
| 主任务 | 完整传递创作结果，调用工具，处理实际返回，续接相关作者 | 实际获取与生成结果，而不是一直停留在下一步计划 |
| 审片作者 | 查看当前片段是否完成原本的讲述与画面任务 | 能定位到内容、构图、中途或实现的具体修改意见 |

角色围绕同一份当前声画稿工作。素材不能只有链接，视觉不能只有风格词，动画不能只有效果名，导演不能只返回“通过”。也不需要因此新增一批代理或再建一套项目数据库。

## 2. 指定案例怎样参考

### 2.1 案例入口与资料身份

案例目录为：

```text
.agents/skills/motion-case-attention-programme/
├── SKILL.md
├── references/
│   ├── original-input.md
│   └── transfer-guide.md
└── assets/
    └── preview.mp4
```

插件副本对应 `plugins/videoflowcut/skills/motion-case-attention-programme/`。执行者从当前实际存在的目录读取，不把文件名相同当成已经读过，也不把路径存在当成已经观看过。

`original-input.md` 保存具体案例的原始任务。它负责提供真实的讲述、取材、美术和演出依据，保持原样。`SKILL.md` 负责说明怎样使用这份资料；`transfer-guide.md` 负责教授本文件第3—5章的具体推导方法。

本任务已指定这个案例，直接使用它，不重新挑其他案例替代。原指令里的独立新建要求、人物、游戏、颜色、字体、坐标和时长属于该作品，不自动成为当前新任务的要求。没有采用该案例的普通任务，仍依靠角色自己的专业方法完成制作。

### 2.2 导演先通读，再把相关章节连起来看

原稿第2.1节说明“要找什么”，第6、7节说明“取得以后怎样进入画面”。导演必须连着理解，才能知道哪些细节真正值得要求。

| 正在作出的决定 | 原指令阅读范围 | 要落实到当前作品的内容 |
|---|---|---|
| 整段为什么这样发展 | 第1.1—1.2节与第7节 | 当前讲述、具体例子、发展顺序及画面的作用 |
| 哪种椅子材料适合 | 第2.1节椅子行、第6.1节、第7B节 | 主体为什么需要整体可辨，如何与等候关系共场 |
| 哪些直播范围能接住浏览 | 第2.1节直播与浏览行、第6.2节、第7C节 | 不同内容怎样有差别，同一页内哪些区域需要对应 |
| 节目身份图怎样选择 | 第2.1节身份图行、第6.3节、第7D—7F节 | 图像如何与身份板、纸条及观察过程共同构图 |
| 候选与设想不同如何处理 | 第1.2节、第2.2—2.3节 | 台词、源范围、构图和接法怎样随材料改变 |
| 动作与声音如何配合 | 第3节、第5.4节、第7—9节 | 当前讲述下的建立、交叠、阅读和接管时机 |

只读搜索表，容易把关键词照抄成筛选规则；只读动画部分，容易先把场面完全定死，再让素材来填空。正确做法是先理解整段意思，再配对读取与当前问题相关的取材和演出。

### 2.3 参考贯穿工作，但不重复灌入全文

**第一次草稿与取材前**，导演通读原指令，与文案、视觉作者一起理解完整发展。学习结果直接用于当前草稿和取材请求，不另交一份学习心得。

**提出某项素材需求时**，导演和相关视觉作者对照上述对应章节，说明为什么需要某个主体、细节或材料关系。素材作者收到的是已经写清的请求，必要时再查该案例的相应内容。

**材料返回时**，导演、文案和视觉一起使用第1.2节和第2.3节的方法更新当前稿。已经读过的部分不因一次任务续接全部重读。

**制作与审片时**，使用与当前问题有关的造型、动作、声音和实际作品资料。需要判断真实演出时查看案例成片；只有指令或静帧可读，就按实际观察范围判断，不补写没有看见的连续效果。

### 2.4 学完以后必须交出什么

参考后的直接成果是：本片配合哪段话、要看见什么、细节为什么重要、相关材料怎样对应、准备接到哪里，以及怎样开始搜索。

一句“参考本例，做得丝滑”没有完成这项工作。把整把椅子、手机或纸条换一个名字，也没有完成方法迁移。导演需要重新作出属于当前内容的选择，并允许实际材料改变选择。

## 3. 导演提出准确取材需求的六个动作

本章是导演的实际写作方法，不是交给用户填写的问卷，也不是每镜都必须填满的长表。简单场面写成短段落即可；复杂的材料关系再展开说明。

### 3.1 读完整意思，决定画面要补充哪一层

先读本段准确句群及前后内容，决定画面提供的是具体行为、空间、细节、比较、情绪，还是一次观看过程。不能只把旁白中的名词提出来当作搜索任务。

本例的“观众是路过直播间的”，讲的是当前内容随时会被下一条内容接替。它不是要求拍一个路人经过房间。导演应先写出画面意思：**原来的内容仍在进行，下一条不同内容已经出现，关注随之转移。**

这一句话先明确了需要表现的关系，后面才知道要找什么内容。画面可以帮助理解，也可以承担幽默、气氛和形式美感，不要求每一句都增加事实或更换一份素材。

**本步成果：用一句具体的话说明这段画面准备完成什么。**

### 3.2 把抽象意思变成候选里能看见的内容

从画面意思继续找可辨认的主体、行为、状态和差别。

“表现等候”仍然抽象；在本例中，中央主体暂离、空椅来到前景、原来的等候关系仍在，才是可以观看的内容。“表现内容更替”也不是找几张直播封面，而是找到几段容易认出差别的活动画面。

导演要写出当前已经选定的画面方向，同时允许适合该方向的其他内容。前期还没看到的行为写成希望寻找的内容，不写成已经存在的源片事实。

**本步成果：下游知道在候选中究竟应该寻找什么，而不是只知道视频主题。**

### 3.3 从使用方式倒推真正重要的细节

同一对象在不同画面里，需要的细节不同。椅子只在背景里出现时，不一定要看清脚轮；椅子需要作为完整主角来到前景时，整体轮廓、椅背、扶手和座面才变得重要。

导演每写一项具体要求，都要能说明：**这个细节怎样影响本次画面？**

重要的是整体能否辨认、主体是否可取景、某个部位是否参与变化、周围是否能与文字或其他对象组合。尚未决定的颜色、机位、文件形式或网站，不因“也许更好”就变成必须满足的条件。

因此，先说“需要能把这把椅子整体看清，准备让它成为前景主角”，不要先规定“必须某网站的透明PNG”。来源可以变化，视觉作者也可以根据实际材料决定取景和处理方式。

**本步成果：每个重要细节都有使用理由，既具体，又不把候选空间限制死。**

### 3.4 把有关系的材料成组提出

不要按每句话分别找一个文件。先判断本场材料之间需要怎样对应。

本例手机浏览包含两种关系：**不同页面之间要看出内容变化；同一页面里的游戏和人物区域仍然对应同一份直播**。若只分别派“找游戏画面”和“找人物视频”，取回的材料可能无法组成当前场面。

椅子与已建立的直播身份、节目身份图与纸条，也需要在同一请求中说明怎样一起使用。这里要求的是表达中的对应，不是强制全部来自同一来源。

一个长视频可以提供多个范围，一份剪辑成片也可能提供环境、主体和细节。不按下载文件数决定材料是否充分。

**本步成果：下游取得的是能共同完成一段画面的材料，而不是各自相关、组合起来却不成立的文件。**

### 3.5 说明相近内容怎样也能用

导演给定明确的内容目标，也应说明允许比较的其他表现。

空椅可以来自直播暂离画面，也可以来自能看清整体的椅子展示内容。它们不是完全相同的用法，但都可能帮助这一段表达“人离开了，等候仍在”。具体怎样接入，由候选回来后重新决定。

这些方向是备选思路，不是要求同一素材同时满足全部特征。二创、回放、评测、图片或其他媒介中的契合内容，都可以进入比较。

候选比原设想更贴合时，导演与文案、视觉修改讲述和接法；不能只因文件容易下载就偏离正在讲的事，也不能为保住第一版构图而拒绝所有替代。

**本步成果：素材作者知道目标不变时可以怎样继续寻找，也可以把更好的发现带回来。**

### 3.6 给搜索起点，不把搜索词当边界

查询由前面的主体、行为、细节和材料关系生成，而不是从整段旁白机械抽词。

本例可以从“直播 暂离 空椅”“电竞椅 整体 展示”“直播 回放 摄像头”“PUBG 经典 头盔 衬衫”等线索开始。这些是到达目标内容的途径，不是证明某种查询必然有效的配方。

素材作者根据返回结果继续调整：内容缺少什么，就改变相应对象词、动作词、来源或同源范围。导演不指定每一条查询都必须运行，也不把几个备选方向合成一组必须全部命中的过滤条件。

**本步成果：请求给得出实际搜索线索，同时保留专业检索的调整空间。**

## 4. 导演应该交出的取材请求

### 4.1 沿用案例中的四列结构

案例第2.1节采用以下结构。当前视频可继续使用，准确句群与必要上下文放在表前。

| 材料角色 | 搜索起点 | 实际需要什么 | 在本片里做什么 |
|---|---|---|---|
| 当前材料在这段的作用 | 当前主体、行为、可见特征形成的线索 | 可在候选里辨认的内容，以及确实影响使用的细节 | 怎样配合讲述、已有画面与下一镜 |

材料之间需要对应，就写在同一行或紧接的说明中；简单镜头用两三句话即可。四列表是组织表达的方法，不新增平台字段，也不要求为了填表制造精确秒数和机位。

### 4.2 一段完整请求的写法

> 配合【当前准确句群及前后内容】，本段准备让观众看到【具体主体、动作、状态或差别】。请寻找能承载它的内容，重点看【因本次用法才重要的细节与材料关系】。画面准备【怎样接已有内容及下一镜】。相近内容能完成同一件事，也带回比较。搜索可从【具体线索】开始；合适候选继续取得，并带回可用范围与接入建议。

这不是让下游自行填写的空表。导演发送时应已经换成本片真实内容。只有“原创、图解、高级一点、不要实拍”这样的分类或形容词，不构成取材请求；导演应在派发前完成上述具体表达。

### 4.3 三个示范的阅读方式

以下示范只来自指定案例内部。每例先说明原指令的依据，再给出据此重新组织的教学请求和材料反馈方法。请求不是历史搜索消息，反馈也是工作示范，不表示已经取得对应素材。

## 5. 指定案例中的三个完整推导

### 5.1 空椅：材料为什么需要成为完整主角

**原指令怎样组织**。第1.1节把主播暂离和椅子笑点放在“住在直播间”的关系中；第7B节让中央身份暂离，但入口、人群和光锥继续存在；第6.1节要求椅子整体可辨，并取得前景。

**取材要求怎样推出来**。这不是家具介绍。椅子需要让观众认出暂离后的空位，同时和仍在的等候关系共场。因此，第2.1节才写到整体形态和主要部件，而不是随便找一个直播截图中的模糊角落。

**导演交给素材作者的请求：**

> 配合“主播暂离，观众还在等，连椅子都像在直播”这段话，寻找能让空电竞椅成为画面主角的材料。希望能辨认椅背、扶手和座面，整体形态适合接到已经建立的直播关系前方。我们要让人感到人离开了、等候还在，不是在介绍椅子参数。
>
> 直播暂离、回放、集锦中的空座位，以及能清楚表现椅子整体的其他图片或视频，都可以比较。可先从“直播 暂离 空椅”“电竞椅 整体 展示”等线索找起。带回可用范围与接法；有更适合直接使用的完整画面，也一并说明。

**找到材料以后怎样继续**。完整椅子图片可按实际轮廓安排前景；空座位直播片段若已经把暂离表现清楚，可以先直接使用，再接其他画面。材料带来的差别要回到当前稿：文案是否需要换措辞，视觉是否需要改变取景，原来的等候参照怎样保留。

不能只给新Asset ID而保留不合适的旧裁切，也不能因为没有预想中的文件形式，就认定椅子材料无法找到。

### 5.2 直播浏览：不同内容有差别，同一页内有对应

**原指令怎样组织**。第1.1节从“路过”发展到划走、下一条内容和持续有活的压力。第2.1节要求不同的浏览范围，第7C节让这些内容在同一手机里更替，第6.2节说明同一直播的游戏和人物区域怎样共同存在。

**取材要求怎样推出来**。观众要先认识眼前内容，再认出换了另一条。素材之间必须有可辨差别；当一条源片同时提供游戏和人物区域时，区域与时间要作为一组交回。不同源之间不要求同人同景，同源内也不能随意拼错时刻。

**导演交给素材作者的请求：**

> 配合“随手划走，下一个视频、下一个直播间接上来”的讲述，寻找一组能辨认出内容变化的游戏直播范围。它们准备在同一个手机中先后出现，每段里有事情继续发生，几次更替之间能从人物、动作或场景看出差别。
>
> 某条内容同时有人物和游戏时，把对应区域及源范围一起带回，便于当作一整页安排。回放、片段、集锦、二创或其他合适内容都可以比较，同一长视频也可以提供不同范围。先从当前讲述中的直播身份、游戏和回放特征展开查询，交回能形成这次浏览的组合，不只给一串页面。

**找到材料以后怎样继续**。横屏源有人物小窗且确实有用时，再根据实际区域重排内屏；人物区没有用，就不为了复制案例强行分屏。几个范围差别不明显，先找同源其他内容或一个互补候选。若现成浏览画面更贴合，也可以重新选择整体接法。

**进入动画时怎样接**。游戏、人物及必要标签随所属页面一起移动；换页不把上一人物留在原地。主字与手机共场时，先让内屏有内容可辨，再安排阅读重点。具体源时间、位置和阅读间隔以本片材料和声音决定，不沿用案例坐标。

### 5.3 节目身份图：从后续构图反推要找什么

**原指令怎样组织**。第2.1节提出PUBG身份图，第6.3节让图像与身份板、欢迎语组成一组，并为后续纸条安排空间。第7D—7F节从“随时被划走的压力”转入节目安排，图像不是一个独立闪过的海报。

**取材要求怎样推出来**。既然图像要参与后续共同构图，选择时就要关注能认出的主体、环境及可调整的空间。具体人物位置与纸条位置可以根据实际材料一起变化，而不是先定死空位再筛掉全部不合机位的候选。

**导演交给素材作者的请求：**

> 配合从“随时会被划走”转到“节目提前安排”的讲述，寻找能够清楚建立本段游戏身份、适合与身份板和步骤共同出现的内容。重点看人物主体和环境是否可认，取景后怎样安排步骤与观察；它会接在身份板下方，而不是单独闪过。
>
> 本段内容身份来自原稿的PUBG，可从该游戏的经典人物、头盔、衬衫和环境等可见特征开始搜索。宣传画、视频和相关剪辑中的合适画面都可以比较。带回可用内容及构图建议，实际材料回来后再决定主体、纸条和观察路径的位置。

**找到材料以后怎样继续**。视觉作者先用取得的图像与当前文字共同排布。主体偏右时可以调整步骤的位置，不必只因不符合最初的左侧构图就退回。画面本身适合保持时，靠组内比例、遮挡、文字和观察形成发展，不需要让海报不断漂浮。

**进入动画时怎样接**。原例在讲述进入压力时让旧内容退让，新身份组同时开始建立。需要学习的是语言与交接相互承接，以及板、文字、图像作为一组参与运动；当前作品重新决定具体时机。相关原指令见第3.2节与第7D—7F节。

## 6. 素材返回后，怎样共同更新当前稿

### 6.1 素材回传要更新讲述与画面

每份准备采用的内容，需要带回实际文件或可访问入口、已经观察的内容与范围、对应的取材请求，以及准备怎样使用。已经确认的源范围继续保留，尚未观察的内容明确留作待查，不编造时间点。

导演把它放回原来的句群和前后画面，作出具体选择：直接使用、调整取景、改变接法、改写某句，或者补充某项材料。选择写入当前声画稿，再交原文案与视觉作者继续。

### 6.2 文案随材料修改，但不把内容删空

原指令第1.2节同时强调了两件事：措辞可以随材料调整，完整论述不能因此退成空泛介绍。

在本例中，熟悉的房间、暂离笑点、随手换走、下一条内容和节目压力是一条发展。素材不能支撑某种具体描述，就调整该描述或更换表现，不应把整段压成“观看方式发生变化，所以要优化内容”。

画面已经让人看见的过程，不再额外念一层相同说明；需要语言解释的关系、评论和判断仍然写清。改稿后，字幕、语音和画内文字一起使用准确全文。第一版配音不自动把草稿锁定。

### 6.3 视觉与动画不只替换文件

新材料可能改变主体比例、背景关系、文字位置、遮挡、中途路径和声音。作者应一起调整这些关系，不是只将旧绑定换成新文件。

先在当前材料上把主角、取景和文字做好，再安排关键中途。新旧同时出现时，决定谁取得第一关注、谁仍留下参照、哪些动作要交叠。需要阅读时给出稳定条件，结束后接下一段，不为填满估计时长增加空等。

已有合适画面、组件、模板或模型可以使用，缺少的部分再补做。演出设计服务这段内容，不要求全部资源从零制作，也不因使用了现成素材就放弃美术选择。

### 6.4 当前声画稿保留什么

下面是实际交接的书写结构，不是新增API。简单场面合成短段落，复杂场面按需展开。

```text
本场内容：准确句群与相邻内容。
观看过程：开头看到什么，随后发生什么，最后接到哪里。
取材请求：材料角色、搜索起点、实际需要什么、在本片里做什么。
当前材料：实际文件、已选范围、具体可见内容及准备采用的用法。
共同构图：主体、文字、空间关系，以及需要保持的身份和参照。
完整演出：主要动作、关键中途、遮挡、阅读和新旧交接。
声音与字幕：准确讲述、源声用法、字幕及画内文字的分工。
当前决定：材料怎样改变了讲述、取景、构图或接点。
下一动作：继续取得、修改、制作或查看什么，由谁完成。
```

制作备注不自动变成画面文字。参考材料中的例题、工具参数和归档信息，也不当作当前视频必须展示的内容。

## 7. 各角色的实际工作方法

本章写的是相关角色在生产任务中的工作正文。详细导演方法与案例教学分别由第3—5章提供，相关Skills应链接同一份教学，不在每个文件里重复塞入整篇文档。

### 7.1 案例入口：让阅读直接服务当前制作

**负责文件：** `motion-case-attention-programme/SKILL.md` 与其 `references/transfer-guide.md`。

当前任务采用本例时，从首次构思与取材开始使用。先理解原指令的完整发展，再将取材表与对应造型、演出配对阅读。导演参考第1、2、6、7节形成当前需求，文案重点处理第1.2节与第7节的发展，视觉和动画按实际问题深入第3—8节，声音与审片结合第9节。

学到的结果直接进入当前准确句群、观看过程和取材请求。阅读章节与示例帮助作选择，不构成所有作品都必须使用某种物体、字体、材质和时长的要求。

原始输入与案例成片保留历史身份。制作当前视频时使用当前资料、工具和声音，合适的已有资源可以复用；案例输入里的旧任务命令不作为现在的执行指令。未采用本例的任务正常使用专业方法独立创作。

### 7.2 导演：在派发前形成准确请求

**负责文件：** `production-director/SKILL.md`。

导演与文案、原视觉作者共同形成声画草稿。指定本例时，直接读取案例入口及导演参考方法，完成内容、取材和演出的对应理解，再将第3章六个动作落实到本片。

每次请求都从准确句群开始：决定画面补什么，写出可看见的内容，从用法倒推重要细节，说明材料间关系、前后接法和可替代方向，再给必要搜索起点。探索阶段不要求终版分镜，但要有具体观察目标。

画面没有想清时，由导演与视觉作者继续构思，不发“原创、图解、高级一点”等标签让下游猜。已经想清的普通取材，不因所有美术细节尚未定完而等待。

候选回来，导演决定实际采用范围，并与文案、视觉更新同一份当前稿。查询方式、来源类别、文件形态与制作方式不代替内容判断。可以使用直接剪辑、局部观察、组合、复用或适合本片的新演出。

局部取景、曲线和排印由原作者完成；主要画面含义、句群发展或跨场关系变化回导演协调。采用意见写明当前怎么做，不只回复“整体通过”。

### 7.3 文案：与材料共同完成一次讲述

**负责文件：** `narration-writing/SKILL.md` 及现有写作方法。

文案读取导演当前观看过程与相关材料，在草稿阶段共同选择具体例子和讲法。参考本例时，重点理解熟悉房间、空椅、内容更替如何推动评论，而不是把“时代、压力、安排”列成几个知识标题。

写准确全文与粗画面过程，让语言承担需要说明的关系、态度和判断，让画面承担能够被看见的过程与细节。不要在第一句把后面准备揭示的内容全部说完，也不机械要求每段都有反转。

实际材料回来后，按具体差异修改措辞、顺序和停顿，必要时重写对应句群。保留真正有价值的发展，不为了适配一个不合用的素材删空论述。源内容只支持到哪里，准确表达就到哪里，不把二创中的解释变成未经确认的原话。

修改后交完整当前正文和画面关系，说明声音、字幕或下一镜需要同时调整的部分。不让下游拼接零散改稿留言。

### 7.4 视觉与动画：先参与取材，再完成可落地演出

**负责文件：** `visual-treatment-planning/SKILL.md`、`motion-brief-writing/SKILL.md` 及现有美术动作教学。

草稿阶段读取当前句群与画面意图，主动向导演说明真正影响取材的细节：主体哪部分应可辨，哪些材料要对应，怎样与文字共同构图，哪处变化需要连续看到。建议由导演纳入一个当前请求，不另向素材作者发出互相冲突的条件。

指定本例时，将第2.1节与相关第6、7节一起看。学的是物体为何取得前景、不同内容为何需要区别、图像为何要与后续纸条共同考虑，不是照搬某个固定版式。

材料回来后，用实际对象和准确文字选择比例、字形、颜色职责、取景与空间。先安排入口、重要阅读状态及最容易拥挤的中途，再连接完整动作。需要附着的字、边缘、阴影和源内容随所属对象；同源多个区域保持时间对应。

动作时机根据当前讲述确定。新主体什么时候该被看见，旧主体什么时候该让位，阅读从何时成立，哪些动作可以交叠，都要写成本片的实际演出。不让主字、主体、背景和说明同时争第一关注，也不把所有对象排队做独立入场。

可以使用适合当前表达的素材、模板、组件与模型。普通设计选择由原作者完成，主要表达改变交导演；完整深化结果正常回导演统筹后继续实现。作品不成立时分别改内容、美术、中途或实现，不统一加阴影、粒子和弹性。

### 7.5 素材作者：找的是画面，不是文件标签

**负责文件：** `visual-asset-sourcing/SKILL.md`。

读取导演准确句群、相邻画面和具体取材请求，理解主体、动作、细节和材料关系，再组织查询。请求里的搜索词是起点，实际采用依据是内容能怎样进入当前场面。

在已有项目材料与实际可访问的来源中寻找。原拍、报道、评测、体验、回放、集锦、二创，以及不同媒介中的契合内容均可比较。先发现合适内容，再选择取得方式，不按题材固定网站或素材形态。

相关材料成组考虑，不同需求也持续推进。某一类已经有可用候选时，进入取得或选段，同时补其他仍空缺的部分；不反复搜索同一类来代替整片覆盖。

根据候选缺少的内容调整搜索：缺主体就改变对象词，缺过程就改变动作词或查看同源前后，缺细节就寻找相近内容或其他表现。更好的发现连同具体用法交导演，不只报告“主题相关”。

选定有希望的候选就推动实际取得。在线已看过并选好的范围跟随文件继续使用；此前没看清的内容在本地完成第一次选段。某一局部不合适，先看同源其他范围或当前其他用途，不能直接推成整条无用。

获取失败时继续其他候选或来源；获取结果不明先查原任务状态，不重复下载。生产取材的成果是材料和用法，不是一组建议链接。有限尝试仍有缺口，说明实际影响与已做的替代，交导演继续组织对应场面。

### 7.6 主任务：让创作选择变成真实执行

**负责文件：** `production-coordinator/SKILL.md`。

首次把当前需求、真实项目状态、指定案例入口、原指令和参考方法交给原导演。说明导演需要交当前声画草稿与具体取材请求，而不是案例阅读报告。专业选择由相关作者负责，主任务不代写创意，也不压缩已经形成的设计。

素材分派保留准确句群、前后画面、材料关系与使用建议，不缩成几个主题词，不把“可比较”改成“必须满足”。相关资料一次交清，只有新的实际缺项才补读。

素材作者已经作出明确获取决定时，按当前工具实际执行。需要的候选ID、项目状态等技术标识由正常读取补齐，不让素材作者猜；没有新的创作选择，不重新启动一次整片审批。

工具返回后续接原作者：成功就交文件、实际媒体信息和已选范围；失败就处理具体错误并继续其他候选；未结束就保留任务标识。某个下载正在运行时，可以查下一份材料，不必让所有研究都等待。对项目结果的保存仍按实际依赖顺序进行。

文案、美术和动作的完整结果都回当前稿。下一步能执行就调用，不把“后续可以下载、可以查看、可以制作”反复当成阶段结果。

### 7.7 审片作者：检查表达是否真的被保留下来

**负责文件：** `quality-verification/SKILL.md`。

先看当前讲述、采用材料与实际片段是否一致。导演要求的主体、变化与材料关系是否还在，还是因为素材没取得就静默换成了另一种普通画面。

区分问题所在：内容已经变了，回导演和文案；主体比例或共同构图不成立，回视觉；中途遮挡与关注混乱，回动画；文件、坐标或源时钟走样，交相应实现处理。反馈写具体发生了什么、哪里改变以及预期看见什么，不只说“更高级”。

已经完成的观察与选段继续使用，只补当前需要的核对。没有实际观看或听审的部分如实记录，但不能把记录未知当成反复重做全部工作的理由。技术可导出与作品已完成专业定稿分别报告。

## 8. 制作中不再设置的通用限制

本章给实施 Codex 清理活动指令与相应逻辑使用，不作为每条素材任务的新检查清单。要求最终工作方式一致，不是在原限制后面追加一句“可以灵活处理”。

### 8.1 创作指令只保留内容与使用要求

| 要消除的通用做法 | 完成后的工作方式 | 主要涉及位置 |
|---|---|---|
| 用“原创、图解、高级一点、不要实拍”直接派素材任务 | 导演在派发前写准确句群、可见内容与用法 | 导演、主任务、场面交接 |
| 按真实事件、生活情境、产品等类别固定查询入口 | 按本段需要的内容开放发现，再选择取得方式 | 素材作者、导演取材方法 |
| 因为是二创、报道、评测或其他媒介就先排除 | 根据实际内容、已有包装和当前接法比较 | 素材作者与相关采用说明 |
| 抽象内容默认交纯动画，或默认不需要找素材 | 由实际讲述与候选选择画面和实现方式 | 导演、视觉、素材作者 |
| 每个需求必须填满固定时长、景别、机位、留白等长清单 | 只说明本次表达确实需要的细节及理由 | 素材方法、派发模板 |
| 所有场面先判原创或复用，或要求资源一律从零制作 | 允许使用合适的素材、模板、组件与模型，缺少部分再补做 | 案例使用说明、视觉与演出交接 |
| 每份素材都重复安排原创性、许可证明和安全审查任务 | 不把这些列为导演取材和内容检索的逐项创作步骤 | 活动角色指令与教学说明 |
| 找到候选后只回复“建议下载”，等待一次新的普通审批 | 在同一次生产任务中继续取得并处理结果 | 素材作者、主任务 |
| 下载本地文件后清空已经完成的观看和选段 | 承接来源、范围和用途，只核对真实差异 | 获取回传、观察与采用关联 |

账户访问、用户明确要求、真实文件可读性及必要的事实对应不因此取消。来源和原始范围保留，是为了不剪错对象和上下文，不是把原作者首发当成每份材料的前置条件。

历史原指令保持不变；这里整理的是现在执行的工作方法。阅读原案例时不把它那次任务的具体条件重新复制到下游。

### 8.2 下载逻辑应支持正常取材

**时长与尺寸由程序取得**。候选缺少这些信息时，可以在取得文件后使用现有媒体探测补齐。时长不再作为通用下载准入条件，短文件按实际用途剪辑，不因初步分镜的估计时长自动淘汰。用户确实要求的完整连续动作，由最终选段与剪辑满足，不靠伪造时长或补空白实现。

**画质按实际用途选择**。正式素材不固定封顶720，也不默认取可用规格里最小的一份。结合目标画幅、裁切需要与源文件质量选择；源只有较低质量时如实使用或另找，不要求所有材料一律4K。

**长文件与片段都可处理**。正常整文件获取继续支持；需要取得已定位范围时，完善范围取得及原片时间与本地时间的对应。一个文件可以提供多个镜头，不因总长较长就直接排除。

````markdown
## 导演提出需求的六个动作

以下是导演的实际写作方法，不是交给用户填写的问卷，也不是每镜都必须填满的长表。简单场面写成短段落即可；复杂的材料关系再展开说明。

### 读完整意思，决定画面要补充哪一层

先读本段准确句群及前后内容，决定画面提供的是具体行为、空间、细节、比较、情绪，还是一次观看过程。不能只把旁白中的名词提出来当作搜索任务。

本例的“观众是路过直播间的”，讲的是当前内容随时会被下一条内容接替。它不是要求拍一个路人经过房间。导演应先写出画面意思：**原来的内容仍在进行，下一条不同内容已经出现，关注随之转移。**

这一句话先明确了需要表现的关系，后面才知道要找什么内容。画面可以帮助理解，也可以承担幽默、气氛和形式美感，不要求每一句都增加事实或更换一份素材。

**本步成果：用一句具体的话说明这段画面准备完成什么。**

### 把抽象意思变成候选里能看见的内容

从画面意思继续找可辨认的主体、行为、状态和差别。

“表现等候”仍然抽象；在本例中，中央主体暂离、空椅来到前景、原来的等候关系仍在，才是可以观看的内容。“表现内容更替”也不是找几张直播封面，而是找到几段容易认出差别的活动画面。

导演要写出当前已经选定的画面方向，同时允许适合该方向的其他内容。前期还没看到的行为写成希望寻找的内容，不写成已经存在的源片事实。

**本步成果：下游知道在候选中究竟应该寻找什么，而不是只知道视频主题。**

### 从使用方式倒推真正重要的细节

同一对象在不同画面里，需要的细节不同。椅子只在背景里出现时，不一定要看清脚轮；椅子需要作为完整主角来到前景时，整体轮廓、椅背、扶手和座面才变得重要。

导演每写一项具体要求，都要能说明：**这个细节怎样影响本次画面？**

重要的是整体能否辨认、主体是否可取景、某个部位是否参与变化、周围是否能与文字或其他对象组合。尚未决定的颜色、机位、文件形式或网站，不因“也许更好”就变成必须满足的条件。

因此，先说“需要能把这把椅子整体看清，准备让它成为前景主角”，不要先规定“必须某网站的透明PNG”。来源可以变化，视觉作者也可以根据实际材料决定取景和处理方式。

**本步成果：每个重要细节都有使用理由，既具体，又不把候选空间限制死。**

### 把有关系的材料成组提出

不要按每句话分别找一个文件。先判断本场材料之间需要怎样对应。

本例手机浏览包含两种关系：**不同页面之间要看出内容变化；同一页面里的游戏和人物区域仍然对应同一份直播**。若只分别派“找游戏画面”和“找人物视频”，取回的材料可能无法组成当前场面。

椅子与已建立的直播身份、节目身份图与纸条，也需要在同一请求中说明怎样一起使用。这里要求的是表达中的对应，不是强制全部来自同一来源。

一个长视频可以提供多个范围，一份剪辑成片也可能提供环境、主体和细节。不按下载文件数决定材料是否充分。

**本步成果：下游取得的是能共同完成一段画面的材料，而不是各自相关、组合起来却不成立的文件。**

### 说明相近内容怎样也能用

导演给定明确的内容目标，也应说明允许比较的其他表现。

空椅可以来自直播暂离画面，也可以来自能看清整体的椅子展示内容。它们不是完全相同的用法，但都可能帮助这一段表达“人离开了，等候仍在”。具体怎样接入，由候选回来后重新决定。

这些方向是备选思路，不是要求同一素材同时满足全部特征。二创、回放、评测、图片或其他媒介中的契合内容，都可以进入比较。

候选比原设想更贴合时，导演与文案、视觉修改讲述和接法；不能只因文件容易下载就偏离正在讲的事，也不能为保住第一版构图而拒绝所有替代。

**本步成果：素材作者知道目标不变时可以怎样继续寻找，也可以把更好的发现带回来。**

### 给搜索起点，不把搜索词当边界

查询由前面的主体、行为、细节和材料关系生成，而不是从整段旁白机械抽词。

本例可以从“直播 暂离 空椅”“电竞椅 整体 展示”“直播 回放 摄像头”“PUBG 经典 头盔 衬衫”等线索开始。这些是到达目标内容的途径，不是证明某种查询必然有效的配方。

素材作者根据返回结果继续调整：内容缺少什么，就改变相应对象词、动作词、来源或同源范围。导演不指定每一条查询都必须运行，也不把几个备选方向合成一组必须全部命中的过滤条件。

**本步成果：请求给得出实际搜索线索，同时保留专业检索的调整空间。**

## 请求写成什么样

### 沿用案例中的四列结构

案例第2.1节采用以下结构。当前视频可继续使用，准确句群与必要上下文放在表前。

| 材料角色 | 搜索起点 | 实际需要什么 | 在本片里做什么 |
|---|---|---|---|
| 当前材料在这段的作用 | 当前主体、行为、可见特征形成的线索 | 可在候选里辨认的内容，以及确实影响使用的细节 | 怎样配合讲述、已有画面与下一镜 |

材料之间需要对应，就写在同一行或紧接的说明中；简单镜头用两三句话即可。四列表是组织表达的方法，不新增平台字段，也不要求为了填表制造精确秒数和机位。

### 一段完整请求的写法

> 配合【当前准确句群及前后内容】，本段准备让观众看到【具体主体、动作、状态或差别】。请寻找能承载它的内容，重点看【因本次用法才重要的细节与材料关系】。画面准备【怎样接已有内容及下一镜】。相近内容能完成同一件事，也带回比较。搜索可从【具体线索】开始；合适候选继续取得，并带回可用范围与接入建议。

这不是让下游自行填写的空表。导演发送时应已经换成本片真实内容。只有“原创、图解、高级一点、不要实拍”这样的分类或形容词，不构成取材请求；导演应在派发前完成上述具体表达。

## 空椅、直播浏览与节目身份组：三个完整示范

### 空椅：材料为什么需要成为完整主角

**原指令怎样组织**。第1.1节把主播暂离和椅子笑点放在“住在直播间”的关系中；第7B节让中央身份暂离，但入口、人群和光锥继续存在；第6.1节要求椅子整体可辨，并取得前景。

**取材要求怎样推出来**。这不是家具介绍。椅子需要让观众认出暂离后的空位，同时和仍在的等候关系共场。因此，第2.1节才写到整体形态和主要部件，而不是随便找一个直播截图中的模糊角落。

**导演交给素材作者的请求：**

> 配合“主播暂离，观众还在等，连椅子都像在直播”这段话，寻找能让空电竞椅成为画面主角的材料。希望能辨认椅背、扶手和座面，整体形态适合接到已经建立的直播关系前方。我们要让人感到人离开了、等候还在，不是在介绍椅子参数。
>
> 直播暂离、回放、集锦中的空座位，以及能清楚表现椅子整体的其他图片或视频，都可以比较。可先从“直播 暂离 空椅”“电竞椅 整体 展示”等线索找起。带回可用范围与接法；有更适合直接使用的完整画面，也一并说明。

**找到材料以后怎样继续**。完整椅子图片可按实际轮廓安排前景；空座位直播片段若已经把暂离表现清楚，可以先直接使用，再接其他画面。材料带来的差别要回到当前稿：文案是否需要换措辞，视觉是否需要改变取景，原来的等候参照怎样保留。

不能只给新Asset ID而保留不合适的旧裁切，也不能因为没有预想中的文件形式，就认定椅子材料无法找到。

### 直播浏览：不同内容有差别，同一页内有对应

**原指令怎样组织**。第1.1节从“路过”发展到划走、下一条内容和持续有活的压力。第2.1节要求不同的浏览范围，第7C节让这些内容在同一手机里更替，第6.2节说明同一直播的游戏和人物区域怎样共同存在。

**取材要求怎样推出来**。观众要先认识眼前内容，再认出换了另一条。素材之间必须有可辨差别；当一条源片同时提供游戏和人物区域时，区域与时间要作为一组交回。不同源之间不要求同人同景，同源内也不能随意拼错时刻。

**导演交给素材作者的请求：**

> 配合“随手划走，下一个视频、下一个直播间接上来”的讲述，寻找一组能辨认出内容变化的游戏直播范围。它们准备在同一个手机中先后出现，每段里有事情继续发生，几次更替之间能从人物、动作或场景看出差别。
>
> 某条内容同时有人物和游戏时，把对应区域及源范围一起带回，便于当作一整页安排。回放、片段、集锦、二创或其他合适内容都可以比较，同一长视频也可以提供不同范围。先从当前讲述中的直播身份、游戏和回放特征展开查询，交回能形成这次浏览的组合，不只给一串页面。

**找到材料以后怎样继续**。横屏源有人物小窗且确实有用时，再根据实际区域重排内屏；人物区没有用，就不为了复制案例强行分屏。几个范围差别不明显，先找同源其他内容或一个互补候选。若现成浏览画面更贴合，也可以重新选择整体接法。

**进入动画时怎样接**。游戏、人物及必要标签随所属页面一起移动；换页不把上一人物留在原地。主字与手机共场时，先让内屏有内容可辨，再安排阅读重点。具体源时间、位置和阅读间隔以本片材料和声音决定，不沿用案例坐标。

### 节目身份图：从后续构图反推要找什么

**原指令怎样组织**。第2.1节提出PUBG身份图，第6.3节让图像与身份板、欢迎语组成一组，并为后续纸条安排空间。第7D—7F节从“随时被划走的压力”转入节目安排，图像不是一个独立闪过的海报。

**取材要求怎样推出来**。既然图像要参与后续共同构图，选择时就要关注能认出的主体、环境及可调整的空间。具体人物位置与纸条位置可以根据实际材料一起变化，而不是先定死空位再筛掉全部不合机位的候选。

**导演交给素材作者的请求：**

> 配合从“随时会被划走”转到“节目提前安排”的讲述，寻找能够清楚建立本段游戏身份、适合与身份板和步骤共同出现的内容。重点看人物主体和环境是否可认，取景后怎样安排步骤与观察；它会接在身份板下方，而不是单独闪过。
>
> 本段内容身份来自原稿的PUBG，可从该游戏的经典人物、头盔、衬衫和环境等可见特征开始搜索。宣传画、视频和相关剪辑中的合适画面都可以比较。带回可用内容及构图建议，实际材料回来后再决定主体、纸条和观察路径的位置。

**找到材料以后怎样继续**。视觉作者先用取得的图像与当前文字共同排布。主体偏右时可以调整步骤的位置，不必只因不符合最初的左侧构图就退回。画面本身适合保持时，靠组内比例、遮挡、文字和观察形成发展，不需要让海报不断漂浮。

**进入动画时怎样接**。原例在讲述进入压力时让旧内容退让，新身份组同时开始建立。需要学习的是语言与交接相互承接，以及板、文字、图像作为一组参与运动；当前作品重新决定具体时机。相关原指令见第3.2节与第7D—7F节。

## 材料反馈如何继续改变当前稿

### 素材回传要更新讲述与画面

每份准备采用的内容，需要带回实际文件或可访问入口、已经观察的内容与范围、对应的取材请求，以及准备怎样使用。已经确认的源范围继续保留，尚未观察的内容明确留作待查，不编造时间点。

导演把它放回原来的句群和前后画面，作出具体选择：直接使用、调整取景、改变接法、改写某句，或者补充某项材料。选择写入当前声画稿，再交原文案与视觉作者继续。

### 文案随材料修改，但不把内容删空

原指令第1.2节同时强调了两件事：措辞可以随材料调整，完整论述不能因此退成空泛介绍。

在本例中，熟悉的房间、暂离笑点、随手换走、下一条内容和节目压力是一条发展。素材不能支撑某种具体描述，就调整该描述或更换表现，不应把整段压成“观看方式发生变化，所以要优化内容”。

画面已经让人看见的过程，不再额外念一层相同说明；需要语言解释的关系、评论和判断仍然写清。改稿后，字幕、语音和画内文字一起使用准确全文。第一版配音不自动把草稿锁定。

### 视觉与动画不只替换文件

新材料可能改变主体比例、背景关系、文字位置、遮挡、中途路径和声音。作者应一起调整这些关系，不是只将旧绑定换成新文件。

先在当前材料上把主角、取景和文字做好，再安排关键中途。新旧同时出现时，决定谁取得第一关注、谁仍留下参照、哪些动作要交叠。需要阅读时给出稳定条件，结束后接下一段，不为填满估计时长增加空等。

已有合适画面、组件、模板或模型可以使用，缺少的部分再补做。演出设计服务这段内容，不要求全部资源从零制作，也不因使用了现成素材就放弃美术选择。

### 当前声画稿保留什么

下面是实际交接的书写结构，不是新增API。简单场面合成短段落，复杂场面按需展开。

```text
本场内容：准确句群与相邻内容。
观看过程：开头看到什么，随后发生什么，最后接到哪里。
取材请求：材料角色、搜索起点、实际需要什么、在本片里做什么。
当前材料：实际文件、已选范围、具体可见内容及准备采用的用法。
共同构图：主体、文字、空间关系，以及需要保持的身份和参照。
完整演出：主要动作、关键中途、遮挡、阅读和新旧交接。
声音与字幕：准确讲述、源声用法、字幕及画内文字的分工。
当前决定：材料怎样改变了讲述、取景、构图或接点。
下一动作：继续取得、修改、制作或查看什么，由谁完成。
```

制作备注不自动变成画面文字。参考材料中的例题、工具参数和归档信息，也不当作当前视频必须展示的内容。

## 视觉与动画继续怎样参考

视觉按原指令第4—6节，将实际字体、主体比例、取景与文字放到同一画面中选择；动画按第3、5.4、7、8节，将动作与当前讲述对应，安排中途、交叠、阅读和源时间。声音与审片结合第9节查看真实作品。需要进一步编排时，由同一视觉作者使用 [完整演出方法](../../motion-brief-writing/SKILL.md)，导演统筹后继续实现。

例如手机交到节目组，学习的是新内容在旧物退出中建立，而不是抄原秒数；同源分区学习的是游戏与人物区域的对应，而不是抄原ROI；镜片学习的是同一状态中的局部观察，而不是所有主题都加一个圆。

当前结果是否成立，需要看实际作品。未观看或未听到的范围保留未知；原指令的初排与旧片认可不替代本片的真实结果。
````

````markdown
## 从讲述与画面构思提出准确取材需求

导演在每次派发前，先与文案、原视觉作者把当前这段需要的画面说清。已采用指定案例时，读取 [导演参考与取材方法](../motion-case-attention-programme/references/transfer-guide.md)，将原文第2.1节与对应第6、7节一起理解；未采用参考时也按下列方法完成具体选择。

以下是导演的实际写作方法，不是交给用户填写的问卷，也不是每镜都必须填满的长表。简单场面写成短段落即可；复杂的材料关系再展开说明。

### 读完整意思，决定画面要补充哪一层

先读本段准确句群及前后内容，决定画面提供的是具体行为、空间、细节、比较、情绪，还是一次观看过程。不能只把旁白中的名词提出来当作搜索任务。

本例的“观众是路过直播间的”，讲的是当前内容随时会被下一条内容接替。它不是要求拍一个路人经过房间。导演应先写出画面意思：**原来的内容仍在进行，下一条不同内容已经出现，关注随之转移。**

这一句话先明确了需要表现的关系，后面才知道要找什么内容。画面可以帮助理解，也可以承担幽默、气氛和形式美感，不要求每一句都增加事实或更换一份素材。

**本步成果：用一句具体的话说明这段画面准备完成什么。**

### 把抽象意思变成候选里能看见的内容

从画面意思继续找可辨认的主体、行为、状态和差别。

“表现等候”仍然抽象；在本例中，中央主体暂离、空椅来到前景、原来的等候关系仍在，才是可以观看的内容。“表现内容更替”也不是找几张直播封面，而是找到几段容易认出差别的活动画面。

导演要写出当前已经选定的画面方向，同时允许适合该方向的其他内容。前期还没看到的行为写成希望寻找的内容，不写成已经存在的源片事实。

**本步成果：下游知道在候选中究竟应该寻找什么，而不是只知道视频主题。**

### 从使用方式倒推真正重要的细节

同一对象在不同画面里，需要的细节不同。椅子只在背景里出现时，不一定要看清脚轮；椅子需要作为完整主角来到前景时，整体轮廓、椅背、扶手和座面才变得重要。

导演每写一项具体要求，都要能说明：**这个细节怎样影响本次画面？**

重要的是整体能否辨认、主体是否可取景、某个部位是否参与变化、周围是否能与文字或其他对象组合。尚未决定的颜色、机位、文件形式或网站，不因“也许更好”就变成必须满足的条件。

因此，先说“需要能把这把椅子整体看清，准备让它成为前景主角”，不要先规定“必须某网站的透明PNG”。来源可以变化，视觉作者也可以根据实际材料决定取景和处理方式。

**本步成果：每个重要细节都有使用理由，既具体，又不把候选空间限制死。**

### 把有关系的材料成组提出

不要按每句话分别找一个文件。先判断本场材料之间需要怎样对应。

本例手机浏览包含两种关系：**不同页面之间要看出内容变化；同一页面里的游戏和人物区域仍然对应同一份直播**。若只分别派“找游戏画面”和“找人物视频”，取回的材料可能无法组成当前场面。

椅子与已建立的直播身份、节目身份图与纸条，也需要在同一请求中说明怎样一起使用。这里要求的是表达中的对应，不是强制全部来自同一来源。

一个长视频可以提供多个范围，一份剪辑成片也可能提供环境、主体和细节。不按下载文件数决定材料是否充分。

**本步成果：下游取得的是能共同完成一段画面的材料，而不是各自相关、组合起来却不成立的文件。**

### 说明相近内容怎样也能用

导演给定明确的内容目标，也应说明允许比较的其他表现。

空椅可以来自直播暂离画面，也可以来自能看清整体的椅子展示内容。它们不是完全相同的用法，但都可能帮助这一段表达“人离开了，等候仍在”。具体怎样接入，由候选回来后重新决定。

这些方向是备选思路，不是要求同一素材同时满足全部特征。二创、回放、评测、图片或其他媒介中的契合内容，都可以进入比较。

候选比原设想更贴合时，导演与文案、视觉修改讲述和接法；不能只因文件容易下载就偏离正在讲的事，也不能为保住第一版构图而拒绝所有替代。

**本步成果：素材作者知道目标不变时可以怎样继续寻找，也可以把更好的发现带回来。**

### 给搜索起点，不把搜索词当边界

查询由前面的主体、行为、细节和材料关系生成，而不是从整段旁白机械抽词。

本例可以从“直播 暂离 空椅”“电竞椅 整体 展示”“直播 回放 摄像头”“PUBG 经典 头盔 衬衫”等线索开始。这些是到达目标内容的途径，不是证明某种查询必然有效的配方。

素材作者根据返回结果继续调整：内容缺少什么，就改变相应对象词、动作词、来源或同源范围。导演不指定每一条查询都必须运行，也不把几个备选方向合成一组必须全部命中的过滤条件。

**本步成果：请求给得出实际搜索线索，同时保留专业检索的调整空间。**

### 将推导交成可执行的请求

在请求前保留当前准确句群和必要的相邻画面，说明本段需要看见什么、哪些细节真正影响本次使用、材料之间怎样对应、怎样接已有画面及下一镜，以及可以比较哪些相近内容。复杂关系用“材料角色｜搜索起点｜实际需要什么｜在本片里做什么”四列，简单镜头用两三句话，不要求填空或新增平台字段。

发送给素材作者的是这些内容已经填好的请求，不是“原创、图解、高级一点、不要实拍”等标签，也不是一份让下游自行猜主题的空表。网站、来源类型、素材形态和制作方式不是通用取材条件。确实影响本段含义或使用的细节，说明理由即可。

### 用材料更新同一份稿

接到实际材料后，明确哪些范围直接使用、哪些改取景或切口、哪些改变接法、哪些需要文案改写。当前讲述、画面、素材与下一动作在同一份稿里更新，不只追加网页链接或回复“整体通过”。

普通选段、查询与局部设计由原作者继续；改变主要讲法和跨段关系时由导演协调。保留当前主题和有效发现，接纳更合适的材料，不为保住第一次构图而把所有候选排除，也不因一个文件容易取得就改讲另一件事。
````

````markdown
## 6. 把关键中途写成可执行决定

先读导演当前句群、已选材料和视觉构图，确定本段究竟在演什么，再安排属性变化。案例已采用时，按 [案例入口](../motion-case-attention-programme/SKILL.md) 阅读原指令第3、5.4、7、8节；需要的是它的行为组织、主次和阅读方法，不是默认沿用手机、镜片或旧坐标。

### 先设计最容易混乱的那一刻

找到新旧主体并存、材料解除遮挡、图像接到文字组或下一份内容取得前景的时刻。先写清这一刻的位置、可见面积、姿态、第一关注、仍要保持的参照和阅读条件，再把入口与出口连接起来。“中间进度50%”不是中途设计本身。

### 把关联对象作为同一件事来编排

明确谁发起、谁跟随、谁显露、谁接管，哪些需要保持身份和对应。相互关联的对象可以有不同延迟、速度与收势，不要求一条曲线控制所有东西，也不为了丰富而强制错相。

在本例直播浏览中，当前页的游戏、人物区域及必要源内容一起移动，下一页进入时仍各自播放。若本片也使用同源分区，区域共享源时刻；若人物区没有用途，就不为了复制案例增加它。文字、边缘、阴影与图像跟随所属对象的变换。

### 从需要读清的时刻反推交接

先决定新重点何时应被看见、主要内容何时需要读清，再安排旧重点退让、新对象建立和收势。源片自身的动作继续发展，不因外层对象移动而重新播放或被拉成另一个时间。

原指令在压力句开始时交出手机，在持续有活的讲述进入时让节目组已可看。可学习它的新旧交叠：旧主字退让与手机离开期间，新板面和图像就开始建立。当前片段按本次声音安排，不机械等待旧对象全部退完，也不照抄旧秒数。

### 分开处理路径、速度和画面主次

先把注意关系设计成立，再确定路径与速度。路径连续不代表速度合适；一段一段使用相同缓动也不等于连续观察。需要观察多个相关细节时，安排明确路径，在需要读的地方减速，经过不需阅读的部分继续前进。起点和结束可以停稳，中途不无故每到一个点都重新启动。

本例镜片观察来自同一节目组的同一状态，保持放大内容与外部位置对应。这种方法只有本片需要局部观察时才使用，不要求每场都有镜片。

### 写成可实施演出，并按具体问题返修

返回准确讲述、当前材料及源范围、入口构图、关键中途、主要阅读状态、对象依赖、相对动作时机和出口。当前材料会影响裁切、字位、遮挡、路径或声音时一起更新，不能只换Asset ID。

中途乱而结束帧好看，先改中途面积、可见内容和主次；新内容建立晚，改事件先后和交叠；动作顺却发飘，改主动与跟随、姿态和速度分布；字或源画面跳位，查父子变换和源时钟。不要把所有问题都改成更大的弹性或更慢的动作。

适合的素材、模板与组件可以用于实现，缺的部件再补做。原作者继续采用现有 [执行稿模板](references/execution-brief-template.md) 和具体教学完成实际片段；局部参数自主修订，主要讲法与跨段变化回导演。没有实际观察过的动态与声音，不以设计说明代替结果。
````

## 11. 怎样验收

### 11.1 导演的方法是否真正落地

| 验证情境 | 必须看见的实际结果 |
|---|---|
| 提供本例关于“路过直播间”的句群 | 导演请求可辨的内容更替，而不是只搜索“路过、压力、时代” |
| 提供主播暂离与椅子笑点 | 导演说明空椅为什么需要成为主角、哪些细节影响当前取景，而不是只报“电竞椅图片” |
| 提供节目身份组与安排段 | 导演把身份图与后续文字、纸条和观察一起考虑，提出可用内容和构图关系 |
| 候选提供不同来源或媒介中的契合内容 | 依据实际画面比较，并说明接法，不按来源类型先拒绝 |
| 素材与预想机位或构图不一致 | 导演、文案和视觉作出具体调整，当前稿中能找到相应变化 |
| 已有同源材料可以提供多个范围 | 保留对应关系，组合使用；不按每句各下载一条 |

采用这个案例不等于复刻它的外观。验收应检查请求是否具体、材料是否贴合、当前选择是否成立，不用椅子、手机、绿色或固定动作出现多少次评定通过。

### 11.2 获取是否真正持续到可用结果

| 验证情境 | 必须看见的实际结果 |
|---|---|
| 候选页面缺少时长或尺寸 | 正常取得后自动探测，无需人手补猜数值 |
| 正常短文件 | 可以取得，按当前用途安排范围，不被通用最短时长挡住 |
| 在线已经看过并选定范围 | 本地文件取得后承接原范围与用途，不从头重复一轮选材 |
| 某个局部不合适 | 先检查邻近范围、同源其他内容或当前其他用途，不自动否定整条文件 |
| 一个来源获取失败 | 继续其他有希望候选或来源；不只写换源计划 |
| 一项下载正在进行 | 其他无依赖的查询或资料准备实际发生，返回后继续处理原结果 |
| 源文件提供更适合的高质量规格 | 获取选择不被固定720或默认最小尺寸限制 |
| 按源范围取得片段 | 正确记录原片范围和本地时间对应，后续剪辑不会从错误位置开始 |
