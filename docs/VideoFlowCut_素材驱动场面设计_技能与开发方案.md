## 1. 当前存在的问题：缺的是生成场面的能力链

### 1.1 已经确认的现象与证据

这里讨论的是本次提供的《AI 能力与决定权》制作包、参考视频及核对过的代码。制作包中的原始协作消息有部分加密内容，不能据此声称读到了所有原始对话；画面观察和审片记录也不能冒充完整实时声画观看。

| 已确认的情况 | 对应依据 | 对改造的含义 |
| --- | --- | --- |
| OpenDesign 实际收到了真实图片、网页、官方图、两条 4K 语境视频及真实声音资料。 | 制作包 `03_OpenDesign实际请求/visual-run-02-request.json`。[P1] | 不能把问题归结为“没有给素材”。需要检查素材进入了哪个动作、承担什么观看作用。 |
| 原视觉简报已有动作因果、材料质感、空间与物件等质量要求。 | `02_导演与制作记录/视觉创作简报.md`；现有物件、演出与审片方法。[P2][R3][R4][R8] | 再增加“高级、连贯、有真实感”等目标词，不能补足目标到场面的转换方法。 |
| 主要解释动作较多由“任务稿、计算组件、授权闸门、钥匙”等通用对象承担。真实材料较多承担报道证据、语境和窗口展示。 | `06_动画历史版本/od-v1/adopted-visual.md`、最终动画源码及正式采用记录。[P3] | 这些对象并非天然错误；问题在于没有充分利用当前 AI 事件中特有的操作、产物、反馈和现实限制来生成主事件。 |
| 后续请求明确要求保留“现有已成立的任务稿/授权闸门/钥匙贯穿”。 | `03_OpenDesign实际请求/visual-run-03-request.json`。[P1] | 第一稿中尚待验证的讲法被过早固定，后续修订更容易停留在布局、大小、遮挡与绑定。 |
| 现有技能会要求“先看到什么、发生什么、表达什么、怎样接续”，但“怎样从未知文案和材料产生这个事件”仍主要依赖模型临场发挥。 | `opendesign-shot-brief`、`story-and-shot-design` 与机制检索方法。[R1][R2][R5] | 交接格式已经存在，缺的是生成交接内容的程序性知识。不能用一份漂亮的交接案例代替这项能力。 |
| 现有审片已经会问动画是否基于素材发生，还是同题素材与独立模型交替播放。 | `quality-verification/references/material-integration-review.md`。[R8] | 审片问题本身不够；需要把发现对应到“补事实、换材料、重构主事件、修实现”的具体处理方法。 |
| R153 的独立审阅记录主要是 29 个不同时间点的静帧及 4 个同点原尺寸复核，连续动态与声音仍有未知。 | `02_导演与制作记录/review-r153-independent.md`。[P4] | “采样中未发现新的必修问题”不等于动作连贯、声画配合和整片效果已验证。 |

据此，本次诊断是：**事实研究、素材发现、场面构思和动作实现之间，还缺少一段明确、可执行、能被复用的方法。** 现有环节各自做了一部分正确工作，但真实材料尚未充分成为主要事件的来源。

这不是对每一个图标、示意图或抽象物件的否定。参考片同样使用图标、角色化对象和抽象表达。区别在于：这些对象是否具有本段专属的身份、任务、行为与后果，是否让观众看见了一件与内容有关的事情，而不只是看见几个表示名词的元素移动。

### 1.2 四种必须区分的缺口

1. **不知道现实中发生了什么。** 只知道结论，没掌握实现结论的行为、条件、中间产物和限制。
2. **知道事实，但没有把事实转成观看事件。** 能复述机制，却仍只能想到图标、标签、箭头。
3. **有场面想法，但材料没有真正参加。** 画面分成“真实材料展示”和“另起一套模型演示”，两者只共享主题。
4. **构思成立，但美术与演出没有实现。** 对象结构不足、动作没有准备与反馈、层次与源时钟不一致、接点断开。

前面三项由本次新增技能重点补足；第四项继续使用项目已经具备的物件、美术、演出、空间与时钟方法。实际作品可以同时存在几项问题，应按具体原因返修。

## 2. 本次方案的设计依据与取舍

### 2.1 为什么新增一个核心技能

新增 `scene-concept-design`，中文职责为“从内容与素材构思场面”。它处理一项完整、可复用的工作：

> 在没有人工提供完整分镜的情况下，理解本段实际关系，寻找真实对象与材料中的表现机会，选择有意义的创意操作，形成可实现、可继续深化的场面构思。

仅修改旧技能的几句要求，会继续把最困难的转换交给模型自己猜。把现实研究、构思、素材连接各拆成新的代理，又会增加交接而切断持续创作。因此采用“一个能力技能 + 按需方法资料 + 教学案例”，由现有导演、素材作者、视觉负责人共同使用，不新增角色和审批链。

### 2.2 为什么同时保留目标、方法、案例与验证

| 层次 | 实际回答的问题 | 只有这一层会怎样 |
| --- | --- | --- |
| 可观察的效果要求 | 什么样的结果算成立？ | 容易变成“高级、有质感、连贯”的形容词。 |
| 创作方法 | 面对这类内容和材料，先做什么，再根据什么作选择？ | 如果没有目标，可能正确执行了步骤，却没有改善观看效果。 |
| 教学案例 | 这套方法面对具体输入怎样推进，为什么放弃另一种讲法？ | 如果只看最终镜头，容易模仿表皮；如果只学一个题材，容易形成固定模板。 |
| 同一套效果复核 | 实际作品是否兑现了先前要解决的观看问题？ | 如果只检查字段、绑定和源码，无法判断表达是否有效。 |

案例需要展示可核查的设计依据和关键取舍，不要求模型提供内部思维过程。教学的重点是输入条件如何影响选择、操作怎样改变对象与观看结果，以及条件变化后怎样重做。

### 2.3 为什么不能把“想象力”写成固定招式

“竞争就打斗”“迭代就转圈”“复杂系统就粒子网络”会迅速变成另一套模板。可以教授的是创意操作的做法：改变观察位置、利用对象原有功能、把关系转成事件、让比较发生在同一任务中、安排预期与真实条件变化。最终采用什么，必须由本段的关系、对象结构、可用材料、语气和制作能力共同决定。

例如，产品对比是否适合打斗，取决于产品能否以其真实形态或功能完成有意义的攻防；仅仅让两个产品图互撞，并不能自动获得原片的想象力。

### 2.4 为什么必须给 OpenDesign 方法，而不只给结果约束

VFC 外层读过技能，不表示 OpenDesign 已经读过。必须把本场适用的方法、案例关键段、真实资源和准确限制实际传到 OpenDesign 可读取的位置，并在制作请求中说明用途。不能只发送“请按素材做高级动效”。[R5][R6]

同时，不要求外层在调用前解决全部造型、机位、部件层级、运动曲线和逐帧时序。外层提供内容根据、可见事件的起点和必要边界；OpenDesign 用同一套方法深化或替换初步构思，并负责具体美术、镜头、演出与实现。需要事实或主线改变时再返回原负责人。

### 2.5 为什么先补技能与交接，不先重建数据系统

现有 `MediaObservation` 可以承载事实、位置、范围与未知；`VisualTreatment` 可以记录采用素材、主要关注和叙事用途；当前声画稿、附件、实际 OpenDesign 请求与既有资源绑定可以承载较长的创作正文。[R9][R10]

当前没有证据表明，必须先增加新的“现实图谱”“场面数据库”或评分服务，模型才可能完成这项工作。第一阶段应把方法写实、让入口确实加载、让 OpenDesign 实际收到，并以陌生任务检验。只有出现现有数据契约无法表达的具体需求，才提出相应字段修改。

## 3. 要达到的效果与能力边界

### 3.1 以可观察的作品特征定义目标

| 特征 | 在作品里怎样观察 | 不能用什么替代 |
| --- | --- | --- |
| 内容具体 | 能指出本段究竟是谁、对什么对象、在什么条件下做了什么，或观众正在经历哪种明确感受。 | AI 字样、Logo、同题 B-roll。 |
| 素材参与 | 承担主要表达的材料，其真实结构、位置、行为、细节或状态改变进入了主事件。 | 文件已传入、画面角落出现过。 |
| 变化有意义 | 变化让条件、关系、结果、限制或感受变得可见；删去关键动作会损失理解或体验。 | 同样的信息不断换位置、缩放或装饰性弹跳。 |
| 对象有可信身份 | 造型、材质、使用方式与本段对象相符；简化和夸张仍保留关键识别与功能。 | 给通用色块贴上专有名词。 |
| 过程可读 | 起点、重要中途、结果与必要反应能被看清；快慢服务信息和情绪。 | 首尾两张正确静帧、毫无作用的长驻留。 |
| 关系连续 | 前后对象、空间、源时间或概念状态有可理解的承接；转场改变关注而保留必要参照。 | 同色背景、相同转场插件。 |
| 画面有组织与丰富度 | 不同材料和层次有作用分工，细节、全貌、活动、界面、声音等共同推动观看。 | 素材数量、固定占比或同时塞满屏幕。 |

这些特征与项目已有美术、动作和整场设计要求共同使用，不要求每一个镜头表现同等数量的变化。完整作品要有发展与层次，局部镜头可以安静、留白或停留。

### 3.2 “真实感”的具体含义

本方案将真实感落实为四种可以设计和检查的对应：

- **所指真实**：身份、来源、事实限定和具体事件不混淆；通用素材不冒充指定现场。
- **行为可信**：物件的动作来自其功能、结构、受力或约定明确的表达；夸张有可理解的依据。
- **空间与时间可信**：遮挡、接触、比例、视角、源时刻和前后状态一致，或者以清晰方式完成转换。
- **生活与工作经验可信**：使用者遇到的步骤、阻力、结果和情绪符合当前资料，而不只符合抽象概念。

真实感不等于全部实拍，也不等于禁用平面、角色化、超现实或幽默。对于情绪、记忆、主观观点，真实的对象细节与感受之间的联系可以承担真实性；不能强行补成机械因果或伪造经历。

## 4. 方法如何前向产生场面

以下是工作依赖，不是要求每场新增一组表单。简短任务可以在当前稿的一段中完成；遇到缺口时回到相应步骤。

| 工作 | 做什么 | 形成什么可用结果 | 什么情况需要回退 |
| --- | --- | --- | --- |
| 确定本段任务 | 从原文提取观众要理解的关系或要经历的感受，保留限定。 | 准确的表达问题。 | 文案含义不清或事实互相矛盾。 |
| 补足现实过程 | 按任务类型查行为、条件、中间产物、限制、真实感官细节；只查影响场面选择的未知。 | 有依据的对象、状态与关键环节。 | 主要动作依赖未经证实的步骤。 |
| 观察材料机会 | 看材料真实呈现的对象、部件、区域、行为、可见变化与制作限制。 | 哪些材料能承担哪个变化；缺什么资源。 | 只有相同名词，没有可用表现内容。 |
| 生成观看事件 | 用关系到状态的转换，再选适用的创意操作。 | 有入场、主事件、必要中途与结果的初步构思。 | 只能写出风格词或通用转场。 |
| 选择并校验可做性 | 检查内容收益、素材关联、关系准确、资源与实现路线；需要时比较真正不同的讲法。 | 可继续制作的场面方向及重要取舍。 | 构思要求不存在的视角、部件或性能。 |
| 形成创作简报 | 将上述结果写成观众的观看过程，保留事实和资源约束，开放艺术细节。 | OpenDesign 可用的内容与创作起点。 | 把摘要、字段标题或理想效果当完整正文。 |
| 制作中发展 | OpenDesign 继续利用对象与参考方法深化美术、运动、镜头和接续。 | 实际作品及主要采用决定。 | 实现变成另一套无关图形，或具体方案暴露新的事实缺口。 |
| 按同一特征复核 | 看实际材料与动作是否完成原观看任务，按问题回派。 | 有定位、有修改目标的反馈。 | 只有技术通过或意图复述。 |

整个过程允许材料改变初步构思，也允许 OpenDesign 找到更好的表现。创作的依赖关系需要被保留，具体画面不必在上游全部定死。

### 5.2 加载原则

- 完整视觉创作和主要场面重构时，导演与持续视觉负责人读取新技能。原文锁定仍可研究现实与设计画面，锁稿不授权改写正文。
- 只有裁切、错字、字幕或参数等机械局部修改时，不重新启动整套场面构思。
- 素材作者按实际问题读取 `reality-and-materials.md`，观察可用对象和变化，继续沿已有素材流程搜索、取得与记录。
- 视觉负责人按当前缺口读取方法与案例，不把全部案例作为每场必读材料。
- OpenDesign 接收本场适用的方法内容与真实资源；VFC 的技能路径不能直接充当 OD 已注册技能 ID。
- 现有 `story-and-shot-design`、物件、美术、演出、机制库和空间时钟方法继续使用。新技能负责补足生成主要场面的前半段。

```markdown
# 从内容与素材构思场面

由现有导演、素材作者与持续视觉负责人共同使用本方法，不新增代理。
导演确定准确内容、表达目的、主线与跨段关系；素材作者提供真实发现和文件；
视觉负责人提出场面构思并负责实际效果；OpenDesign 深化美术、镜头、动作与实现。

## 先明确本段要完成什么

读取当前准确正文、前后内容、受众、已有材料、用户锁定项及有效声音依据。
用具体语言说清观众需要理解的关系或经历的感受，保留事实限定和不确定性。
区分事件、机制、比较、观点与情绪；不要把所有内容改写成因果流程。
不要从图标、色块、转场名称或预设隐喻开始。

完整锁稿仍要研究现实、观察材料和构思场面；正文改写与顺序变化继续遵守授权范围。
已有有效研究、素材观察与创作决定直接复用，只补影响当前场面的缺口。
从现有业务入口进入本技能时，完成当前缺口后回到原环节；
不因参考文件之间相互引用而重新启动整套流程。

## 工作方法

1. 找到决定本段画面的现实信息。问清谁或什么对象处于什么条件，发生什么行为，
   产生什么状态、产物、限制或感受。遇到中间环节不明，按
   [现实与材料方法](references/reality-and-materials.md)查到足以判断画面的程度。
   不用常识臆补指定产品、机构、实验、人物动机和事件细节。
2. 实际观察可能采用的材料。识别其对象身份、结构、行为、可见细节、可用范围与限制，
   把事实观察、设计建议和未知分开。找出能承担主要表达的动作机会；
   氛围、语境与节奏材料可以承担辅助作用，不要求每份素材都演示机制。
3. 把内容关系转换成可见状态差异。确定变化前观众能认出什么，
   什么动作或条件使关系显现，变化后多理解了什么；情绪任务确定感受怎样发展。
   按[构思方法](references/concept-methods.md)选择适用操作，不按抽象名词套动画。
4. 用实际对象与材料生成场面。选择对象能做的动作、可看的区域或可利用的空间关系，
   让这些具体条件影响构思。原创演出可以先提出待制作动作，再核对对象结构、
   必要资源和可实现路线，不要求原素材已经包含同一动作。
   不能把原创动作当作已发生事实，或让素材作者为虚构事件找证明；
   依赖不足时补制作资源、调整动作或改变表达。
5. 检查可做性。按[素材进入动作](references/material-to-action.md)判断采用原源行为、
   局部观察、图层分离、内容接管、结构重建或明确示意等路线。
   指出真正影响采用的依赖；具体坐标、层级、曲线、机位和时序在制作中深化。
6. 选择有观看收益的方向。比较它是否具体、准确、可读、有材料依据且可完成。
   只有主要取舍仍不确定时，比较真正不同的讲法；不规定每场候选数量。
   保留有效简单表达，不为了显得有想象力加入无关戏剧。
7. 将采用方向写进同一份当前声画稿与创作简报，交 OpenDesign 制作。
   作品回来后按本页的效果特征检查；发现主要事件不成立时允许重构讲法。

以上步骤是工作依赖，不是新增表单、逐镜审批或独立样片前置。
材料、内容或制作发现可以让你回到前面的相应步骤。

## 把构思写成观看过程

说明观众从什么具体对象、材料或情境进入，主要发生什么事情，
哪一处变化使内容或感受成立，结果怎样接入下一段。
交清采用素材及用途、重要事实限定、必要资源条件和前后承接。
简单场面一段即可；复杂场面补关键中途与角色关系，不逐项填满无关栏目。

对每个承担主要表达的材料，能回答它提供了什么不可随意替换的内容、结构或动作。
替换成任意同题图片后表达仍完全一样时，检查是否只把材料当装饰；
这是诊断线索，不是禁止语境材料、图解、照片或抽象表达。

区分必须保持与可以发展：事实、身份、用户锁定项和必要内容关系必须保持；
初步物件、构图、材质、具体拍法、运动机制和转场可由 OpenDesign 发展或替换。
不要因第一版已经生成，就把尚未验证的隐喻和对象体系称为已成立。

## 让 OpenDesign 同时得到目标和做法

沿 [场景创作简报](../opendesign-shot-brief/SKILL.md)与
[实际制作](../opendesign-video-production/SKILL.md)交付本场资料。
将当前准确正文、主要事件、真实资源、必要方法及参考关键段实际交到 OD 可读位置，
在请求中说明用途。不要假定外层已读的方法会自动继承。
不要把本技能名写进只接受 OD 已注册 ID 的 skill/skills 参数。

让 OpenDesign 用材料中的真实结构与行为继续发现更好的演法，
保留内容含义和材料身份，更新主要采用决定；涉及事实或主线变化时返回导演。
先前采用的技术契约、源时钟、声音、资源绑定与正式渲染责任保持有效。

## 用同一套效果特征复核

观察实际作品：内容是否具体，主要材料是否参加事件，变化是否推进理解或感受，
对象是否保留可信身份，关键中途是否可读，前后关系是否延续，层次是否有作用。
与原有物件、美术、演出和材料审片方法共同判断，不以字段齐全、文件成功或配色统一代替。

事实不明回导演与素材研究；材料不足回原素材作者；主要事件不成立回导演和视觉共同重构；

给出真实版本、区间、观察事实和修改目标，保留已成立部分。
未连续观看、未听音或无法可靠核实的范围写明未知，不能伪造通过。
```

```markdown
# 现实理解与材料机会

## 导航

1. 按表达任务确定研究对象
2. 找到缺失的现实环节
3. 把问题变成检索与观察动作
4. 判断研究何时足够
5. 从材料中发现可演的内容
6. 把观察交回共同创作
7. 证据或资源不足时继续哪里

## 1. 按表达任务确定研究对象

先识别当前问题，不先找表现风格。一个段落可以包含多种任务。

| 任务 | 优先弄清什么 | 优先取得什么 | 不要擅自补什么 |
| --- | --- | --- | --- |
| 已发生的事件 | 主体、时间、行为、先后、结果及仍有争议的部分 | 原始报告、现场资料、当事人记录、可核实报道 | 内部操作、人物动机、未公开因果 |
| 机制与流程 | 输入、操作者或系统、实际操作、中间产物、判断条件、反馈与失败 | 官方说明、论文、操作演示、界面与原始图 | 未记载的模块、数据内容、自动化程度 |
| 产品或方案比较 | 同一任务、相同或不同条件、比较维度、各自结果与代价 | 规格、同条件测试、实际操作与结构资料 | 无依据的胜负、速度、排名和使用效果 |
| 观点或抽象判断 | 论点指向的具体情境、支撑实例、适用边界及反例 | 明确标注性质的实例与证据 | 把隐喻当事实、把单例当普遍规律 |
| 情绪、记忆与经验 | 叙述者视角、实际对象、习惯、感官痕迹、时间与空间关系 | 用户材料、真实场所、物件细节、原声与授权叙述 | 未提供的创伤、亲属关系、死亡、动机与回忆 |

不要要求情绪片证明一个技术机制，也不要用气氛素材代替专业事实。

## 2. 找到缺失的现实环节

对决定画面的句子，先用具体对象改写其关系，不改动原稿含义。
例如“能力提升”仍不足以构思：需要知道是哪项工作、输入是什么、
谁做了什么、怎样判断更好、改善发生在哪个范围。

采用以下追问，直到主要关系可以由可观察对象承担：

- 谁或什么系统在行动？所指身份是否有依据？
- 操作的真实对象是什么：代码、表格、工件、文件、消息、空间、身体动作还是别的？
- 行动前后到底什么不同？中间是否有必要的检查、传递、等待、失败或选择？
- 哪个条件允许变化发生？哪个条件使它停下？
- 结果是什么，什么没有因此改变？比例、尺度与时间范围是什么？
- 观众需要看见哪一环，才不会只听到结论？

只展开影响理解或场面选择的环节。不要为了“充分展开”研究整个行业史，
也不要把所有细节都塞到画面上。主事件所依赖的一条关键环节仍未知时，
标出未知并继续查；背景细节未知可以不画。

对于情绪内容，把上述追问改成：谁在看、什么熟悉动作或痕迹仍在、
什么发生了变化、观众何时意识到、哪些信息应留白。

## 3. 把问题变成检索与观察动作

每次检索先写清缺口以及答案会影响哪个设计选择。
例如“需要知道系统怎样判定候选结果可用，以决定是画人工挑选还是自动检测”。

按缺口选择查询：

- 查机制：对象名称 + 官方说明 / 方法 / evaluation / workflow / demonstration。
- 查实际操作：产品与功能名称 + 原始演示 / 操作录屏 / 输入与结果。
- 查事件顺序：事件名称 + 首发报告 / 时间线 / 原始声明。
- 查物件结构：准确型号 + 多视图 / 部件 / 拆解；结构资料与艺术参考分开。
- 查生活语境：活动、场所、参与者与可观察动作，不把预设镜头写成唯一检索条件。

使用原始来源核实技术与事实；普通画面仍可广搜，先找有用的活动、对象和场景。
阅读原文的相关上下文，核对演示中的真实操作与显示结果，记录重要限定。
搜索摘要是线索；下载到视频、拿到截图或听说有某功能，都不证明已看清相关行为。

观察一段视频时先了解整体，再看可能采用的连续范围及必要前后文。
只有短暂动作、精确切口或目标位置影响采用时，补足必要密度。
检查是否实际看见了步骤，还是根据台词推测；不把预期分镜写成素材观察。

## 4. 判断研究何时足够

满足以下条件即可进入构思与制作，不等待收集所有资料：

- 主体和主要行为有可追溯依据；事件与通用情境素材已区分。
- 关键状态变化与必要限定可以说明；决定主事件的未知已解决或明确避开。
- 至少有一种能够支持当前讲法的材料或诚实的原创示意路线。
- 当前制作所需的资源条件可判断，新的资料不会只是增加同义信息。

来源冲突会改变场面含义时，保留冲突并交导演处理；不要让模型选一个更好画的版本。
用户锁定正文与核实结果冲突时，报告具体句子和依据，不用动画悄悄改变事实确定性。

## 5. 从材料中发现可演的内容

对有希望承担主要表达的材料，从以下角度实际观察：

1. 身份：什么对象，真实来源是什么，能否指认当前事件或只能提供一般语境。
2. 形态：轮廓、部件、接口、开合、边界、层次、空间与可见文字。
3. 行为：正在输入、生成、传递、折叠、承受、停止、等待、比较还是发生别的变化。
4. 状态：前后有什么差异，哪些变化是连续可见的，哪些只有结果照片。
5. 关注机会：哪个真实细节值得靠近，哪里可以建立整体参照，什么能接到下一关注。
6. 制作条件：清晰度、画幅、可用源范围、遮挡、背景、透明性、可分离性与声音。

由观察产生机会，而不是先固定效果再套材料。例如：

- 页面中已有“候选—测试—保留”的关系，可以沿实际区域建立过程。
- 产品有真实开合结构，可以让这一动作承担尺寸或使用状态的变化。
- 一段操作中结果出现后仍留有其他未处理对象，可以利用持续参照解释重复。
- 房间中实际存在褪色边界、磨损和空位，可以通过观察距离组织记忆与缺席。

这些只是操作方式。每次都要以当前素材确实存在的内容为依据。

对主要材料写清三句话即可：
“实际看见……；这可能承担……；若要这样做，还缺/需确认……。”
第一句是观察，第二句是设计建议，第三句是条件，三者不要混在一起。

## 6. 把观察交回共同创作

沿现有素材记录与声画稿交付真实文件或资产、有效范围、可见发现、用途建议和重要未知。
不要只交下载链接、标签和“适合科技感”的评价。
材料尚未取得时标为候选，不能写成 OpenDesign 已收到的资源。

素材作者可以建议新的主要讲法，导演决定内容采用，视觉负责人继续发展具体场面。
研究结果不要求全部上屏；来源、限定和内部备注保留在记录中，按内容需要决定展示。
素材面积、全屏或局部位置由当前设计决定，不把推荐构图变成永久条件。

## 7. 证据或资源不足时继续哪里

| 缺口 | 继续动作 |
| --- | --- |
| 只找到同题材画面 | 保留有用语境用途，继续寻找实际行为、产物或界面；也可采用有依据的原创示意。 |
| 主要因果没有依据 | 继续查原始说明或缩小解释范围，不能用动画补成事实。 |
| 只有照片，没有实际动作 | 设计细节观察、状态并置或明确的重建，不给照片编造已发生的运动。 |
| 只有外观，想表现内部动作 | 查结构与所需资源；不足时改外部可见行为，或把模型明确作为解释。 |
| 材料细节看不清 | 换源、换区域、收窄主张；生成的高清细节不能称为原件放大。 |
| 有材料但无法完成主事件 | 改变讲法或补关键资源，不用装饰性运动填补缺口。 |
| 情绪材料少 | 从已有对象、空间、声音和观看顺序发展；不要虚构人物经历增加戏剧。 |

继续复用已有素材取得、源范围、权限与审阅方法，不创建新的材料准入流程。
```

```markdown
# 从关系产生观看事件

## 导航

1. 先把含义转换成状态差异
2. 方法一：改变观察位置与尺度
3. 方法二：让对象用自身功能行动
4. 方法三：把关系转成有结构对应的事件
5. 方法四：让比较发生在同一任务中
6. 方法五：组织预期与条件变化
7. 选择、组合与资源检验
8. 形成简报并保留创作空间

## 1. 先把含义转换成状态差异

提取原稿中真正要表达的关系、条件、结果或感受，不以名词列表代替。
写清“开始时什么状态—什么操作或观察使差异出现—结束时观众多知道/感受到什么”。
这不是让所有镜头都演示机械过程，而是找到观看的变化依据。

| 内容关系 | 可尝试的可见变化 | 必须核对 |
| --- | --- | --- |
| 重复、负担 | 完成一个对象后，其他真实对象仍保留相同未完成状态；再次执行同一动作 | 是否确实不能同步；重复次数有无依据 |
| 选择、迭代 | 候选产生不同结果，经实际标准筛选；被保留的结果进入后续过程 | 标准、选择者与反馈方式，不能虚构自动化 |
| 边界、许可 | 对象在某条件下可以做一件事，遇到另一条件时等待、受限或改变路线 | 边界实际属于什么权限或机制，不一律画实体门 |
| 依赖、协作 | 前一对象的具体产物成为后一对象可识别的输入，状态因此改变 | 是否真实依赖、是否同时发生 |
| 规模、比例 | 从局部进入整体，显示局部的实际占比与未改变部分 | 分母、单位与时间范围 |
| 竞争、资源分配 | 同一目标或有限条件下，不同对象作出各自真实行为，结果发生差异 | 争夺关系是否存在；不能把并行发展画成直接攻击 |
| 观点与例证 | 先观察一个可核实情境，再以对照或范围变化显出观点的适用边界 | 单例不证明普遍规律，隐喻不是证据 |
| 熟悉、离别、记忆 | 熟悉动作、物件或声音保留，环境或关系改变；观众逐渐发现差异 | 叙述者与资料授权，避免编造额外经历 |

表格提供转换入口，不规定画面模板。先依据当前内容确认状态，再选择下面的方法。

## 2. 方法一：改变观察位置与尺度

适合：局部和整体、表面和隐藏条件、个体和系统、熟悉和重新发现。

操作：

1. 找出两个有内容联系的观察范围，例如真实界面中的局部结果与整套任务。
2. 判断观众先看哪个更容易建立兴趣或理解；不要默认总是先全景再放大。
3. 选一个持续参照：同一对象、局部轮廓、字段、空间位置或声音。
4. 让观察转移揭示先前看不到的关系；变化来自看见了更多或看见了另一面。
5. 在新范围内完成理解或感受，不把放大本身当作主要事件。

资源与制作：确认真实区域、清晰度和裁切范围。采用同源局部、镜头/裁切变化、
空间展开或明确示意；整体与局部在转移中保持可认出的对应。

失败征兆：镜头运动很大，但新画面没有新增关系；放大后主体、文字与参照一起丢失。
退路：减小转移、换更有信息的局部、保留整体参照，或改为并置比较。

## 3. 方法二：让对象用自身功能行动

适合：产品、工具、界面、真实流程中的产物，以及有明确使用习惯的生活对象。

操作：

1. 列出本对象实际能做的少量动作：打开、折叠、输入、验证、输出、承载、遮挡等。
2. 对每个动作问：完成这个动作，会显出本段哪项内容或限制？
3. 选择能把意义带出来的动作，而不是只因为它容易制作。
4. 让对象的形态、部件或内容参加过程，安排必要的准备、响应和结果。
5. 若采用角色化，让“性格”来自功能与使用代价；保留真实结构和事实边界。

资源与制作：外部整体动作可从真实视频或可分离主体开始；内部动作需要相应部件、
多视图、模型或可合理表达的视角。屏幕内容与机身分层时，保持位置、透视与遮挡对应。

失败征兆：换成任意矩形仍然成立；产品只在起点和终点出现，中间动作属于无关符号。
退路：选择更贴近对象的动作，或缩小表现范围；没有必要时使用真实演示即可。

## 4. 方法三：把关系转成有结构对应的事件

适合：抽象关系本身难以看见，而一个具体活动能保留其关键结构。

操作：

1. 抽取必须保留的关系：谁有目标，谁控制什么，什么条件允许或阻止变化，结果是什么。
2. 从真实活动中寻找同样的关系结构，例如交接、排队、筛选、接力、协作、争夺或绕行。
3. 对应原关系与活动中的对象和动作，检查每一项映射是否必要、是否准确。
4. 明确类比到哪里停止：活动中有但原内容没有的敌意、意志、胜负或因果不要带入。
5. 让当前素材中的真实对象进入活动，优先用它们自己的形态与行为承担关系。
6. 检查观众是否会把演出误读成真实事件；必要时通过视觉语言或简短措辞表明是解释。

例如，“共同推进”不自动意味着比赛；“多家独立发展”不自动意味着互相攻击；
“受某条件约束”不总是实体门。活动的结构必须来自原内容。

资源与制作：确认活动需要的姿态、接触、前后层次与反馈可以实现。
选择平面拼贴、物件演出、界面或三维模型等合适形式，具体形式由视觉与 OD 深化。

失败征兆：先挑一个炫酷场面，再把名词贴上去；观众记住打斗却无法理解比较维度。
退路：删除无依据的关系，减少角色化，返回真实操作或同条件对照。

## 5. 方法四：让比较发生在同一任务中

适合：产品、方案、前后版本、流程或条件差异。

操作：

1. 明确比较的具体问题，排除未经支持的“谁总体更强”。
2. 选择能暴露差异的同一任务、输入或限制，注明实际不相同的条件。
3. 确定双方/前后版本实际要做的动作，以及可观察的结果或代价。
4. 设计共同参照，让观众看到差异怎样产生；可同时、接续或匹配观察，不强制分屏。
5. 有取舍时呈现条件变化，让优势与代价各自成立；没有依据不制造反转。

资源与制作：优先取得可比条件下的操作或测量。只有结构事实时可以比较结构，
不能从几张产品图推导运行速度和体验结论。概念性任务应明确是示意。

失败征兆：两个 Logo 对撞后宣布胜者；动画时间差被当作真实性能差。
退路：缩小比较维度，补真实条件，改为外形/流程对照，或者取消胜负表达。

## 6. 方法五：组织预期与条件变化

适合：代价、例外、认知修正、隐藏限制、幽默和情绪发展。

操作：

1. 找出观众依据前文可以合理形成的预期，不编造一个无人相信的稻草人。
2. 让动作或观察先建立这个预期，保留足够识别时间。
3. 引入资料中确实存在的条件、限制、代价或空间变化。
4. 让同一对象或持续参照对变化作出可读响应。
5. 用响应后的状态完成意义；必要时回到原问题，避免只做惊吓或无关包袱。

情绪场面可以由熟悉细节的重新解释形成变化，不要求制造惊讶。
事实内容不能为了反转先误导观众，再把更正当作戏剧效果。

资源与制作：利用原材料中的等待、反馈、开合、空位、限制或声音变化。
没有相应记录时，采用明确的解释形式，不伪装成现场反应。

失败征兆：条件由作者凭空添加；反转很强但改变了事实；段末结论与前面行为无关。
退路：缩小预期、提前给必要限定、改成平实对照或保留自然观察。

## 7. 选择、组合与资源检验

从当前关系和材料选择操作，可只用一种，也可在同一主事件中组合。
组合要有依赖，例如先用产品开合建立变化，再换观察尺度显示它占用的空间。
不要把几种操作依次播完来增加动效数量。

判断一个方向是否值得采用：

- 去掉标签后，对象和行为是否仍对当前内容有帮助？
- 关键动作带来了什么新的理解、情绪或比较？
- 当前素材对该动作有什么具体贡献？
- 是否改变事实的范围、条件、关系或确定性？
- 所需资源是否已具备；缺少部分有没有诚实而可行的替代？
- 前一范围留下的对象或关注怎样进入本场，本场结果怎样继续？

主要取舍不确定时再比较不同方向。比较观看收益、准确性和可实现性，
不按“最复杂”“最像参考”“最容易渲染”单独决定。
已有明确而有效的简单方案可以直接制作。

## 8. 形成简报并保留创作空间

将采用方向写成可见的观看过程：入口、主要对象、变化与关键中途、
内容含义、材料作用、结果与出口。按需说明资源条件和重要取舍。

固定事实、对象身份、用户要求和必要关系；把初步动作/构图标成可发展的起点。
不在没有必要依据时指定所有部件、父层、路径、镜头数、精确时长或弹簧参数。
OpenDesign 可以提出更合适的表演，只要保留当前任务的意义与真实性。

出现新的资源条件时重新推导相关步骤，不只替换原方案中的图片地址。
```

```markdown
# 让素材实际参加动作

## 导航

1. 先确定材料在主事件中的作用
2. 六种制作路线
3. 制作前只交清必要依赖
4. 向 OpenDesign 传递方法与资源
5. 制作和返修时检查什么

## 1. 先确定材料在主事件中的作用

对承担主要表达的材料，写清以下关系：
“这份材料中的这个实际对象/区域/行为，参加这个变化，使观众看见这个含义。”
如果只能写“与文案相关”“增加科技感”，继续观察、换用法或改其为辅助材料。

允许证据、主事件、语境、氛围、节奏与情绪等不同用途。
不要要求所有材料都运动，也不要要求真实原件始终占据主画面。
主要关系可以由编辑图形承接，但必须有可理解的材料对应和表达依据。

## 2. 六种制作路线

### 路线 A：利用原素材已经发生的动作

适用：材料已包含输入、打开、移动、生成、响应或其他需要的行为。

做法：

1. 选择包含准备、关键动作与结果的真实源范围，保留必要前后余量。
2. 确认观众能认出操作对象与变化结果；不足时先建立整体或补局部观察。
3. 让新增图形作用于实际行为，例如揭示关系、保持参照、比较前后状态。
4. 原动作结果成为后续画面的输入或关注，不随窗口退出全部清空。

依赖：真实源时间、方向、可读区域、必要声音与遮挡情况。
不足时：换范围或来源；不能通过循环、冻结或虚构延长冒充更长的原始行为。

### 路线 B：进入材料里的真实区域

适用：文档、网页、界面、产品细节、图表等已有可识别区域。

做法：

1. 建立对象身份和整体参照，选择与本段关系相关的实际区域。
2. 在整体与局部之间转移关注，保留同一对象的轮廓、位置或内容对应。
3. 在局部完成读数、观察、比较或解释，再从该结果接到下一范围。
4. 局部不足以支撑主张时换源或改讲法，不把生成细节称为原件放大。

依赖：源区域与原件尺寸、清晰度、裁切可行性；需要动态跟随时核对真实运动。
实现：沿[素材坐标、裁切与源时钟](../../opendesign-video-production/references/material-space-and-time.md)
处理源坐标、裁切和共同变换，
不要只缩放整个画布来假装进入某个细节。

### 路线 C：把真实对象分离为能参加事件的层

适用：真实物件、产品、人物或文档需要进入新的解释场面。

做法：

1. 明确必须保留的身份特征、轮廓与内容。
2. 判断整体主体能否从背景分离，动作是否需要单独部件。
3. 取得或制作必要图层，安排共同空间、接触、遮挡、投影和材质反馈。
4. 用对象本身的结构和作用完成主事件，结果保留可辨身份。

依赖：干净主体、必要分层、多视图或重建资源。
限制：只有一张正面图，不能假装已有真实背面或内部零件。
合理的平面/有限视角动作可以直接使用；大角度转动或内部开合需要相应资源与依据。

### 路线 D：让屏幕、页面或产物的内容接管下一场

适用：屏幕里的结果、纸上的内容、操作产物需要变成后续主要对象。

做法：

1. 先让观众在原载体中认出具体内容。
2. 找到可保持的身份线索：文字片段、轮廓、排列、颜色关系或位置。
3. 通过可理解的离开、展开、延续或视角转移，让该内容进入新的表达空间。
4. 在交接期间保持载体与内容的对应，不用一个不相关的通用图标替换。
5. 接续后让内容继续做下一件有意义的事，而不只换成标题卡。

依赖：准确内容、可用分辨率、必要抠取或重绘、载体与局部的变换关系。
限制：编辑摘录或重绘必须保持准确，不能伪装成原网页真实布局或真实操作结果。

### 路线 E：根据真实结构重建可操作对象

适用：需要表现的动作无法由现有平面材料合理完成，但结构资料足以支持重建。

做法：

1. 说清需要重建的理由：哪个动作、视角或空间关系是当前表达必需的。
2. 取得对应结构、部件关系与识别细节，区分可靠信息与艺术简化。
3. 选择成本合适的平面分层、有限三维或完整模型，不默认复杂建模。
4. 让可动部件与功能对应，保留接触、遮挡和动作限制。
5. 明确呈现性质：这是重建或解释，不能把补出的细节当实拍事实。

依赖：足够结构依据、必要素材和实际制作能力。
不足时：换外部可见动作、换视角或缩小讲法；不能把缺失资源转嫁成“高级一点”。

### 路线 F：用有依据的编辑图形接续解释

适用：现实机制不可直接拍摄，或抽象关系用图解更清晰。

做法：

1. 从已核对的材料提取必要关系、数据或状态，不复制无关视觉细节。
2. 选择能保留领域身份的表示：真实产物形态、界面结构、工作对象或明确符号。
3. 在原件与图解之间建立对应，再按关系安排变化。
4. 保留事实限定与范围，区分示意和实际测量。
5. 结果回到当前任务、产物或后果，避免停在无意义循环。

依赖：准确关系、数据与必要展示文本；实际数值、性能和排名不能由动画节奏推导。
这条路线允许抽象、平面和符号，不要求给所有概念套写实外壳。

## 3. 制作前只交清必要依赖

先判断采用方向是否有合理实现路线，交清影响成立的条件：
准确材料、身份、源范围或目标区域、需要的部件/视角、必要内容与前后承接。
不要把每场都变成完整工程规格；布局、图层实现、镜头、路径、速度与细节在 OD 中深化。

资源不充分但不影响探索时可以先做当前作品的合理预排，明确哪些是临时表达。
主要动作依赖不存在的资源时，应补材或改讲法；不把临时占位当最终效果交付。

## 4. 向 OpenDesign 传递方法与资源

在现有项目和请求机制中提供：

- 准确正文、表达目的、可见事件与必要前后关系。
- 本次真实可读的素材、声音、来源对应及有效范围。
- 本场适用的上述制作路线和必要方法，不整库复制。
- 有帮助的案例关键段与参考范围，并说明可借鉴的关系或动作。
- 必须保持的事实与用户条件，以及可发展的初步构思。

方法文本可以作为项目中的可读文件，或直接进入制作请求；实际文件位置按工具返回确定。
在 prompt 中点名读取用途，不能只给 VFC 私有路径或不存在的文件。
OD 内部 skill/skills 参数只使用实际列出的已注册 ID。

需要具体制法时，读取
[物件结构与制作方法](../../visual-treatment-planning/references/object-drawing/REFERENCE.md)、
[动作中途与演出方法](../../motion-brief-writing/references/performance-design.md)或
[素材坐标、裁切与源时钟](../../opendesign-video-production/references/material-space-and-time.md)
中的相关部分，并把本场采用方法的必要正文和依赖实际交给 OD。
只传路线名称，不能代替这些具体做法。

要求 OD 从真实资源继续深化和改进演法；如替换初步方案，仍说明材料怎样参加主事件。
准确意义改变时回导演，视觉细节与实现按现有持续制作流程自主修订。

## 5. 制作和返修时检查什么

看真实画面中的完整关系：材料建立、动作开始、关键中途、阅读与结果、下一关注接住。
确认主事件实际发生在材料的对象、内容或可追溯的解释关系上。

发现问题时按原因处理：

- 只有同题小窗口：重新安排主事件与材料角色，或明确保留为辅助用途。
- 动作只靠通用图标：回到对象的功能、产物与实际操作寻找表现机会。
- 材料与新空间断开：建立身份与状态交接，保留必要参照。
- 设计正确而局部漂移：修源坐标、裁切、共同变换或时间映射。
- 对象显得轻薄或虚假：沿物件和演出方法修结构、材质、接触、准备与反馈。
- 主事件不成立：重构讲法，不只加转场、阴影或镜头晃动。

连续运动、声音与精确接点按实际观察能力检查；静帧不证明这些内容已经通过。
```

```markdown
- 共同记录可辨认，界面布局不完全相同。

- 若属于前后审批，主事件改为同一申请经历不同权限与状态，不再重复录入。
```

```markdown
2. 图纸展开，任务所需空间扩大。
3. 产品本身没有被赋予新能力，但其作用与任务之间的关系改变。
4. 在可比条件下观察另一份材料，通过同一任务理解不同结果。

5. 可强调已有任务区域或覆盖边界，不通过后期明暗修改制造性能结论。
6. 同时比较、连续接续或匹配动作由材料决定，不强制分屏。
7. 没有测量依据，不标精确照度、面积或性能数值。

只有产品照片时，可表现外形；不能据此推导光照分布。需要相应资料或实际演示，
或者在允许改稿时收窄比较内容。

让比较发生在同一张桌子的任务变化中：先建立中心阅读，再让真实图纸展开，

如果主题改为工艺欣赏，应围绕结构和细节观察，不强加胜负。
如果两产品共同协作，应改为互补作用和共同结果，不能只换“合作”标签保留对抗。

## 验收

如果换成任意两个产品仍能原样使用，检查是否遗漏了当前功能与材料。
```

```markdown
- 两个机位并不完全一致，不能假定像素级重合。

同一桌子的特征连接时间；普通动作使习惯可感；当前空缺回应已建立的期待。

## 怎样生成场面

先确定感受关系：过去某动作在这里完成；现在地方仍可辨，但动作不再发生。
留恋来自熟悉行为的缺席，不只来自空桌面。

采用两个操作：

1. 以稳定空间承载时间差，保留实际桌角、灯或视线关系。
2. 先建立具体动作，再让当前状态中的缺席被感知。

无需让桌子人格化，也无需让照片绕桌飞行。这里的情绪发展由原文与材料共同决定。

## 选择与放弃

不以漂浮照片代替日常行为，它可能只增加装饰。
不把人物突然抹掉，这容易引入消失、死亡或魔法的含义。
保留普通动作、空间对应与必要停留，使情绪依附于具体细节。

## 实际制作路径

1. 核对两份材料共同可辨的空间特征。
2. 在旧素材中选择完整的小动作，保留动作前空间、接触和之后的短暂停留。
3. 以共同物件、视线方向、匹配构图或声音等接到当前状态，按素材选择方法。
4. 不强行扭曲不同机位以伪造一镜到底。只能对应桌面平面时，其他立体对象分别处理。
5. 当前状态给足认出空间和发现动作缺席的时间，不以微动填满。
6. 旧声可用于清晰的主观记忆表达，但非同期声音不能伪装成原始同期记录。
7. 光线、构图、材质关系、镜头和声画衔接由视觉与相应声音负责人持续深化。

## 得到的创作简报

从旧素材里一个完整而有辨识度的日常动作进入，让观众记住桌角、台灯或其他真实参照，
再接到清空后的同一张桌子。保持空间识别和必要停留，让动作没有继续被感知。
不添加原文之外的人生事件。根据机位条件选择匹配构图、声音延续或其他接续，
无需强行做成一镜到底。

- 文案变为“终于开始新的生活”时，重新选择动作方向、声音和出口，表现新的可能。

情绪是否依附于生活细节？空间连接有无依据？观众感到具体习惯的缺席，
还是只看到伤感滤镜？有没有新增未经支持的经历？机位接续是否可信？
```

```markdown
# AI 的进展怎样从工作过程里被看见

## 教学身份

本例利用公开机制作为事实起点，其后场面是教学构思，尚未据此制作或验证。
没有实际取得的代码、评测日志、界面和素材，都不能按已到位资源描述。

事实入口：Google DeepMind 于 2025-05-14 发布的
[AlphaEvolve 官方说明](https://deepmind.google/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/)。
本例只采用其中的基本关系：提出候选程序，经自动评价，评价与保留的结果影响后续探索。
这不证明任意 AI 系统都使用相同机制，也不等于系统可以不受外部条件地无限自我提升。

## 输入问题

假设当前文案需要解释：“它提出不同程序，判断哪些有效，再继续寻找更好的方案。”
目标是让观众看见工作对象与筛选关系，而不只是听到“迭代”。

需要查清的内容包括：当前文案究竟在指哪个系统、产物是什么、
怎样判断结果、哪些信息能回到后续过程，以及需要保留什么限定。
若要讲某一具体应用、性能数据或真实运行结果，应继续取得对应原始依据，
不能从这个总流程自动补出。

## 假定的制作条件

假设已取得官方说明的合法可用原件或准确摘读，并已核对关系。
没有取得真实运行界面或完整评测记录。普通写代码录屏可以提供工作语境，
但不能称为该系统的运行现场。

由此可见：本场可使用准确原件建立所指，然后制作清楚表明性质的编辑示意。
不能把写代码 B-roll 当作候选生成与评价的直接证据。

## 从关系到具体对象

把“循环”展开成观众需要辨认的工作状态：

- 正在处理的是程序方案，不能只是一张名为“任务”的通用纸片。
- 不同候选需要在过程里保持可辨身份，否则观众不知道比较了什么。
- 评价要产生可读反馈，否则筛选只像任意淘汰。
- 后续探索要与先前结果有可辨关系，否则只是重复出现新窗口。

这些是教学表达需要，不是宣称已观察到某个真实界面的具体样式。
没有真实代码与数值时，可用明确的示意性程序片段、版本标识和结果类别，
避免伪造可执行源码、评分数值和准确实验日志。

## 选择创意操作

先用“对象自身功能”让程序作为被运行与判断的工作产物；
再用“结果接入下一过程”让筛选后的状态实际影响后续观看。
需要说明作用范围时，才改变观察尺度进入更大任务，不默认飞向一片芯片宇宙。

放弃仅用三枚图标围成循环：它表达了一般流程，却没有让程序和反馈成为具体关注。
也不把模型演成自带意志的角色来制造未经支持的自主目标。

## 可实施路径

1. 从实际可读的原件或准确内容建立身份与关系，使用其真正相关区域。
2. 通过保留名称、结构对应或具体产物身份进入编辑解释空间。
3. 为候选建立可辨差异，让评价反馈对应到同一候选，保留结果与后续的联系。
4. 使用足够的阅读和观察时间，让重要中途成立，避免一闪即过的假日志。
5. 不把教学示意的布局、速度、颜色、数量和数值表述成真实运行记录。
6. 如果找到真实可用演示，重新观察其操作与状态，允许它改变当前场面。

造型、构图、候选的呈现形式、空间、镜头、运动与结果交接由 OD 深化。
具体制法可组合原件局部观察、内容接管与有依据的编辑图形，不必预定一种容器。

## 得到的创作简报

先从已核对的原件建立本段所指，再进入明确的编辑示意，让程序候选、评价反馈和
后续探索之间的关系被看见。候选应保持可辨身份，结果要与后续有实际联系。
不要用通用任务卡替代全部工作对象，也不要把示意界面或数字冒充运行记录。
请从真实资源继续发展更有效的观看方式，保持事实范围与产物关系。

## 迁移与验收

如果换成一次性回答、人工审批的助手或没有自动评价的流程，重新确定主事件，
```

```markdown
# iPhone Duo：学习功能怎样成为动作

## 来源、观察范围与身份

参考作品：[《【何同学】能折！但代价呢？iPhone Duo 首发体验》](https://www.bilibili.com/video/BV1XynB6EEiM/)，
作者“老师好我叫何同学”。

附近的产品对峙及相关动作。页面跳转时点存在偏差，该范围仅用于寻找内容，
不是精确剪辑点。未据此完成全片连续声画审阅，也未取得原作者的脚本、工程或创作日志。

以下把“画面观察”与“教学分析”分开，不声称还原了作者真实创作过程、软件或提示词。
正式借用具体演法前，应重新观察实际采用的完整动作和前后连接。

## 观察到什么

在相关画面中，手机作为可辨认的产品身体进入共同的桌面空间；
折叠形态、屏幕内容等参加动作，而不只是两个同样矩形贴不同名字。
相关画面还把屏幕中的卡片/钱包内容带入更立体的演出空间。
桌面、物件、光影与遮挡为运动提供共同环境。

这些观察支持“产品与功能参加事件”的判断，不足以证明每个动作对应何种真实性能，
也不能据某个漂亮镜头推断全部特效的制作方式。

## 怎样把观察转成可学习的方法

不要只记“手机 PK 可以打一架”。先分解：

1. 主体有什么独特结构：当前产品为何不是任意盒子？
2. 哪些功能或内容真的成为动作：身体、屏幕、卡片各做了什么？
3. 动作怎样产生互动：一个行为发生后，其他对象与空间如何响应？
4. 连续性靠什么保持：身份、接触、遮挡、方向、光照还是重复的场所参照？
5. 哪些含义属于艺术化表达，不能当作产品真实能力？

由此可提取的创作操作是“用自身功能行动”“有结构对应的关系事件”
以及“载体内的内容接管新的表达空间”。这是一种教学分析，不是作者意图的事实声明。

## 在新项目里怎样向前使用

假设拿到陌生产品文案，先不决定打斗：

1. 核实这次实际在比较、解释或欣赏什么。
2. 找到产品确有的开合、显示、输入、承载、连接等功能和使用限制。
3. 取得能表现这些结构或行为的材料。
4. 选择哪个功能可以让本段关系被看见，再决定是否需要角色化事件。
5. 若产品间确有可表达的对抗结构，再考虑攻防；若是互补、并行或条件适用，另选事件。
6. 核对动作需要的分件、视角、屏幕内容、接触与空间条件，在实际能力内深化。

例如只有正面产品图时，整体位移可能可以实现，折叠内部或大角度转动则需要额外资源。
这时应补资源或换可成立的观察方式，不能靠“像参考那样高级”跳过制作条件。

## 怎样使用具体制作参考

主要事件确定后，再查需要的具体机制：物件相互响应、屏幕局部接出、
折叠部件演出、接触阴影、连续视角或其他实际难点。
沿已有机制库与物件方法观察完整过程及依赖，按新对象重新映射。
借鉴方法不等于复制原片的全部角色、布局、节奏或专属镜头。

## 验收

新作品的动作是否仍来自当前对象的具体功能与结构？
内容关系是否因动作更清楚？材料是否真正进入事件？空间和过程是否可读？
如果只剩两个产品图互撞，说明复制了表面活动，还没有迁移生成方法。
```

### 8.4 素材专项观察怎样调用现有能力

已有观察足够时直接复用。只有某个部件、行为、状态或遮挡影响构思且尚不明确时，才发起针对性复核。

当前 `analyze_media` 的工具说明明确：`depth=review` 时，`input.context` 是发送给模型的专项问题；`index/discovery` 的 context 只作用途备注，初看保持盲观察。[R14] 因此不能在 `depth=discovery` 时把一段创作问题放进 `input.context`，就宣布该素材已按问题完成分析。本文未认定当前作品曾经误用这一字段。

可在 `depth=review` 时放入 `input.context` 的问题正文如下；实际目标、范围、模态和其他参数以实时 Schema 为准：

```text
请只依据本次实际可观察的材料，说明与当前场面有关的对象和变化。
1. 哪些主体、部件、文字或界面状态可以辨认？
2. 原素材里实际发生了什么动作，动作前后分别是什么状态？
3. 哪些特征可以在取景或转移关注时持续作为同一对象的参照？
4. 当前范围中有什么遮挡、清晰度、视角或动作完整性的限制？
5. 哪些是直接观察，哪些需要其他资料核实，哪些无法判断？
请给实际范围和必要定位，不按预计分镜补造操作，不把静态图描述为连续动作。
```

观察结果中的源范围、覆盖和未知继续沿现有记录保存。模型返回可以补具体观察，但不冒称人已连续观看，也不自动为素材赋予使用资格。

### 8.5 怎样让 OpenDesign 实际获得技能

这是本方案必须落实的一项运行行为，不能只在 VFC 技能树中放入新文件就结束。

**按既有制作流程执行：**

1. 续接当前视觉负责人，确定本次 OD 项目和当前有效稿。新作品使用实际创建返回的项目 ID，返修复用现有项目和源码。
2. 从新技能中选本场真正需要的方法。通常是对应创意操作、材料制法及一个有帮助的案例片段；不规定固定份数。
3. 将方法正文与必要依赖交到 OD 实际可读取的位置。只传 `SKILL.md`，却让其中链接指向 OD 不存在的 VFC 私有目录，不算交付。
4. 一并交付准确正文、材料观察、真实媒体、声音、事实限定、前后关系和运行契约。候选链接与已取得媒体分清；VFC 资产与 OD 文件对应保留。
5. 在 `start_run.prompt` 中明确每份资料的用途和创作任务。`skill/skills` 参数只使用 `list_skills` 实际返回的 OD 已注册 ID。
6. 保存完整请求和实际响应；普通返修使用既有新 requestId 规则，同一未知结果先读原 Run，不重放未知提交。
7. 接回实际源码与资源，沿原正式渲染、绑定和预览流程继续。作品观察与返修检验方法是否兑现，文件可读和 Run 成功只能证明相应技术状态。[R6]

**建议的内容组织：** 可以在 OD 项目中使用“当前简报”“事实与材料观察”“本场适用方法”“参考说明”四类文本，也可以合并。名称是内容组织建议，不是新增工具参数或平台固定文件名；使用实际写入成功的位置。

**可直接使用的制作请求固定指令部分：** 下段与本次实际正文、文件位置、资源清单及现有运行契约共同发送。不能只发送下段空指令。

```text
请依据本次准确内容、真实材料、场面起点与适用方法，完成当前作品的美术、镜头、连续动作和实现。

先读取请求中逐项列出的资料：事实与材料文件用于确认真实身份、过程、范围和资源条件；
当前简报说明表达目的、主要事件与前后关系；方法资料教你怎样从对象与材料继续构思，
以及怎样让材料进入动作；参考案例用于借鉴操作，不提供本片事实。

先判断本段真正要让观众看见或感受什么，再利用材料中的实际主体、结构、行为和状态
发展场面。每个主要变化应推进当前含义或感受。主要材料应兑现其被采用的作用，
不要默认保留一个来源窗口，再让无关通用物件完成全部解释。

初步场面允许改进或替换。保持准确含义、来源身份、用户锁定项、必要条件与前后关系；
具体造型、构图、材质、镜头、路径、曲线、内部时长和转场由你设计。
使用适用的方法和案例，不要求每种方法都出现，也不复制案例的题材、数据和布局。

原素材已有行为时组织真实源过程；只有静态结构时按其条件设计；
需要不存在的视角、部件、动作或细节时，补相应资源或改变讲法，明确示意与重建的性质。
不要把原创界面、生成细节或通用工作视频冒充指定事件的真实记录。

继续执行本轮已经发布的源码、资源、源时钟、声音及正式输出契约。
制作中保存实际采用的主要设计与必要时序，说明资源缺口；
交回对应版本的作品、源码和资源。未实际观察的动态与声音保留未知。
```

这段指令没有替模型预写一个好结果。生成结果所需要的具体操作来自第 6 节方法正文和本次实际资料，制作方仍要完成关系转换、材料匹配与艺术深化。

## 9. 怎样验收：验证会生成，而不只是会执行案例

### 9.1 分开验收两层能力

**第一层是构思能力。** 在没有人提供完整分镜、最终主事件和全部对象映射时，模型能否从陌生内容与资源条件产生有依据的场面。

**第二层是实际兑现。** OpenDesign 是否收到所需方法与材料，是否在当前作品里让主体行为、材料结合、关键中途和前后关系真正成立。

漂亮的创作简报不能代替第二层；执行人工写好的复杂分镜，也不能证明第一层。能够复现第 6 节案例只说明能执行教学答案，尚不能说明方法已经迁移。

### 9.2 用什么输入验证

开发期选择未出现在教学案例中的任务，覆盖当前最需要补足的机制、事实/比较与情绪/观点差异。测试范围按实际缺口确定，不把数量变成每片配额。

**提供：** 用户目标、准确内容或可探索主题、实际资源、可用工具、已有声音、用户锁定项、已知事实与仍需研究的问题。

**不提供：** 人工完整分镜、指定的最终主事件、指定必须采用哪一种创意操作、预先做好全部素材到动作的映射。

使用假想练习时明确事实与材料是题设；使用实际媒体时要求观察原件。两种测试可以分别检验方法推导和实际材料能力，不能相互冒充。

### 9.3 验证步骤

1. 保留可比基线：相同或可解释差异的模型、用户约束与资源条件；已有有效基线可复用。
2. 启用新方法，让现有角色自行研究、观察、构思和制作，记录有用依据与主要采用。
3. 检查主事件是否来自内容关系与材料条件。不要用过程文本的长度、字段数量或“看起来想得很深”评价。
4. 查看实际 OD 请求和可读输入，确认必要方法、媒体与边界确实进入制作。
5. 观察同版作品中的完整主行为与前后接点。需要判断动态时使用实际连续范围；静帧只支持静态结论。
6. 改变一项会影响设计的内容关系或资源条件，查看受影响场面是否真正重构。
7. 定位失败环节，修改相应方法并针对性复验。不要马上补上完整分镜，再把成功归功于技能。

所有开发验证在隔离环境中进行，沿现有正式接口和项目规则，不占用或改写生产作品状态。[R11]

### 9.4 输入变化应导致什么变化

| 输入变化 | 合理适应 | 失败信号 |
| --- | --- | --- |
| 连续操作视频变为静态照片 | 重排可见状态、改为明确编辑解释或补资源；不再声称看到原始动作。 | 保留原动作叙述，只替换媒体地址。 |
| 新素材出现独特结构或行为 | 它可以改变关注、主事件或接续；不适用则说明实际原因。 | 无论素材是什么，都塞进原来的小窗口。 |
| 竞争变成协作 | 重做共同行动、依赖与结果，保留仍有效的视觉语言。 | 只改标签，继续碰撞、淘汰和胜负。 |
| 预测变为已发生，或反向改变 | 更新证据、语态、画面确定性与必要限定。 | 继续表现成同样确定的现场事实。 |
| 局部改善与整体改善的关系改变 | 重审作用对象、比例、整体参照和结论。 | 只改数字，仍暗示相同的整体变化。 |
| 只有通用工作画面，缺指定事件记录 | 保留语境用途，补事实或采用明确示意。 | 将通用 B-roll 当作该机构、实验或人物的现场。 |
| 原创动作需要缺失的侧面或分件 | 补制作资源、采用有限视角、调整动作或换表达。 | 既不补资源也不改动作，用提示词假定条件已存在。 |
| 真实声音比初步构思短 | 重新安排信息释放和关注，删去重复的视觉动作；必要时协调授权范围内的内容。 | 冻结、无意义微动、同时堆满细字或擅改锁定原音。 |
| 情绪目的由留恋变成期待 | 从实际动作、声音与空间重选感受发展和出口。 | 完全沿用原伤感节奏，只换结尾文案。 |

反事实检查是发现当前弱点的方法，不是自动否决标准。例如，一个准确的通用关系图解本来就可跨领域使用；一条氛围素材被替换后主事件不变，也可能完全合理。关键是它声称承担的作用是否真实兑现。

### 9.5 验收标准与失败回派

| 能力 | 通过需要的实际依据 | 未通过时修改哪里 |
| --- | --- | --- |
| 现实理解 | 关键对象、操作、条件与后果能对应输入或来源，未知未被画成事实。 | `reality-and-materials.md` 的问题展开、资料选择与停止条件。 |
| 材料观察 | 采用了材料真实结构、行为、文字区域、空间或声音条件。 | 素材观察问题与回传方法；必要时补源。 |
| 场面生成 | 有具体观看事件，主行为由本段关系与材料产生。 | `concept-methods.md` 的操作、适用条件、反例和迁移。 |
| 创意有效 | 创意改善了发现、比较、行为或情绪发展，未歪曲关系。 | 重新选择操作与主事件；避免只加装饰。 |
| 可实施 | 主要动作有真实材料或明确的资源制作路线，依赖与未知清楚。 | `material-to-action.md` 的资源条件与制法。 |
| 交接有效 | OD 实际拿到内容、方法和资源，并保有合理设计空间。 | 请求正文、文件可达性、依赖与边界。 |
| 作品兑现 | 真实预览中主体、主行为、中途、参照、接续与阅读成立。 | 按事实、构思、美术、演出、实现分别回派。 |
| 条件适应 | 输入关系或资源变化后，受影响设计相应改变，未受影响部分保留。 | 返回实际失效的研究、构思或制作步骤。 |
| 独立启动 | 陌生任务不用用户补完整答案，也能形成可继续制作的场面。 | 不能以某一局部动画成功抵扣；继续修上游方法。 |

不设置新的自动审美分数服务。每项判断附可核查依据、实际覆盖和未完成部分。没有观察到的动态与声音继续保留未知，不通过更改记录字段制造通过。

### 9.6 本文完成后仍必须做的生产验证

本文提供的是可落地的方法和指令，能够静态检查文本、链接、职责和契约一致性，也可以做限定条件下的构思迁移练习。要确认用户关心的“高级、连贯、素材丰富且衔接自然”，仍必须在真实素材、正式声音、实际 OpenDesign 请求与最终画面中观察。

正式验收不能停在“新增了技能”“提示词变长了”“模型给出更详细的分析”或“样例镜头实现了”。验收目标是：**面对陌生内容和真实材料，这个项目能够自行产生具体场面，并把这些场面制作成实际成立的观看过程。**
