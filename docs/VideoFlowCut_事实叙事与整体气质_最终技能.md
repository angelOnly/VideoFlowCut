## 一、共享技能：沿已有方向形成整片表达

文件：`.agents/skills/_shared/EDITORIAL_TONE.md`

本页补充既有导演、文案、视觉与审片的共同判断，用于主要表达设计或相应返修。它不指定统一风格，不改视频类型、既有偏好入口或专业制作流程；局部机械修改继续原任务。各作者只读取与当前职责相关的内容。

<a id="selection"></a>

### 先沿用本片方向，不由题材自动选风格

**视频类型决定制作路线，表达方向决定讲法与感受，具体视觉参考提供做法。三者不能互相替代。**

视频类型继续采用现有 project.profile 的 presenter_motion、visual_explainer、vlog、hybrid，由原类型路由（`.agents/skills/production-coordinator/references/video-type-routing.md`）管理。本页不重新分类，也不将任一类型绑定为严肃调查。

讲述与美术继续分别使用已有讲述方向（`.agents/skills/narration-writing/references/expression-patterns.md`）和已有美术方向（`.agents/skills/visual-treatment-planning/references/art-directions.md`）。轻松有梗、温暖陪伴、悬念探索、理性爽快、奇趣卡通、沉浸叙事均保持可用；两者可以协调组合，也可以按内容采用其他具体做法，不要求同名一一对应。不要复制这两份方法另建一套分类。

当前明确要求优先；已有项目没有改风格要求时，保留当前有效采用。新片未明确的部分承接用户主动保存的默认，仍未确定的部分由导演根据内容、受众、参考与材料自主选择。无需新增问卷。只把本片选择写进当前稿，不回写为永久偏好。

是否包含真实事件、风险、数据、人物或科技内容，均不足以自动选择严肃调查。事实准确与表达轻松、温暖或明快不冲突。没有指定风格，不等于默认严肃调查；单段有紧张目标，也不等于全片需要统一压暗。

#### 严肃调查参考的使用范围

只有当前稿明确采用了严肃调查的呈现态度，并说明是全片还是某个连续范围，才读取[可选的严肃调查视觉参考](#investigative-profile)。采用可以由用户提出，也可以由导演在现有授权内作出；不能覆盖用户已确定的其他方向。

只借用其中的资料定位、光线、空间或其他局部做法时，说明借用内容与适用范围，保持本片原方向；不同时继承该参考全部配色、运动和声音倾向。采用范围结束后按已设计的衔接继续，不把局部选择扩散到其他段落。相关作者只读取已选范围，不要求所有作者预读可选风格全文。

<a id="principles"></a>

### 从参考提炼的共同特点

这些特点约束内容与表达的关系，不指定观众必须紧张、不安或震惊。具体感受由本片已采用方向决定。

| 特点 | 在本片中怎样落实 |
|---|---|
| 内容有分量 | 真实主张有可追溯依据；材料和细节让内容具体起来。纯形式表达按其观看价值设计，不强制每个镜头出现报告或新闻。 |
| 观看持续发展 | 让行为、关系、论述、观察或形式有实际发展；前面形成的结果和参照在仍有用途时继续影响后面。 |
| 感受有依据 | 通过可看、可听、可理解的内容与变化支持本片感受，不用情绪形容词替代设计，不用夸大事实补刺激。 |
| 强弱服务内容 | 根据当前作用安排重点、阅读、反应和接续，让对比有意义；不统一加粗、加速、加声，也不统一减弱。 |
| 材料丰富且有作用 | 材料提供不同的观察、语境、细节、趣味或解释价值；不按下载数量、媒介比例或唯一机位收口。 |
| 整体态度一致 | 素材姿态、颜色面积、材质、空间、排印、运动与声音相互支持；统一的是表达关系，不是全片同色、同速、同布局。 |

<a id="director"></a>

### 导演：采用什么方向，为什么这样呈现

与文案、素材、视觉和声音从起稿阶段共同工作。在现有声画稿开头，写清本片表达重点、已采用的讲述与视觉方向、希望提供的观看感受，以及支撑这种选择的内容或形式。不另建风格状态表，不只抄方向名称。

对关键范围，明确观众先看什么、值得继续观察什么、哪些变化或细节承担表现、结果怎样被看清，以及如何接到下一关注。语言、真实材料、图形、排印和声音可以分别或共同成为主表现，按本段作用采用。

具体做法由原专业作者深化，导演判断组合是否符合本片方向。局部有新材料或更好的构思时允许调整；改变主要含义、全片气质或跨段关系时回到同一稿共同确认，不为每个参数增加审批。

当某项结果仍在影响后文时，后续保留这种影响；当内容需要轻松、舒展、收束或转向时，也应真实完成变化。不要把未解决的压力强加给所有段落，亦不要用漂亮转场掩盖尚未处理的前后关系。

真实判断的力度与证据匹配；来源、观点、本片分析和未知清楚区分。表达可以有观点、有情绪，不能通过删除必要条件或捏造行为实现。用户锁定的文字、声音与编辑范围继续保护。

<a id="writing"></a>

### 文案：按已选方向组织内容与口吻

继续使用原写作方法与本片所需的讲述方向，不从“事实驱动”推导出调查口吻。选择能够建立认识的事实、行为、细节和关系，说明重要判断的依据；情绪词、程度副词和口号不能代替内容。

安排语言与画面的先后：需要先看清的内容不抢先讲完；需要先说明的条件也不故意隐藏。使用明确主语、动词与指代，让理解、趣味、体验或判断真正向前发展。普通背景与气氛材料不必逐句证明知识。

准确性是共同底线，幽默、温和、直接、俏皮或沉浸的讲法由本片选择。不要把所有方向都改成悬念开场、风险升级和开放式问句结尾，也不要把所有句子削成短促判断。

交付原有完整文稿与声画说明，把关键语句需要的画面前提和强调位置写在对应段落。纯旁白与制作说明分开，不新增情绪报告。实际素材带来更好的讲法时向导演反馈，锁定稿件则先在允许范围内协同画面。

<a id="visual"></a>

### 视觉作者：让本片方向落实到整幅画面

先使用本片已采用的美术方向（`.agents/skills/visual-treatment-planning/references/art-directions.md`），再在实际画面中共同决定主体、材料、颜色面积、光线、字形、观看距离与运动性格。方向用于提出选择，不自动变成固定色板、素材筛选或动作参数。

把配色落实为背景与主体的明暗、相邻颜色的面积和用途；把材质落实为真实轮廓、边缘、表面与必要的光影；把运动落实为对象怎样变化、如何响应、在哪里读清与接续。采用图形化、平面或卡通表现时按其本身逻辑完成，不强制全部实体化或摄影化。

明快颜色、强排印、弹性、夸张和轻巧动作不是通用缺陷。它们是否适合，要看本片方向、对象和实际观看作用；同样，低饱和、低亮度、慢镜头和少效果也不是通用优点。完成度继续沿原有美术和连续演出规则判断。

原件承担阅读时定位相关内容并保留必要语境；真实过程承担观看时保留行为与空间；形式承担感受时把细节、变化和节奏做完整。材料可以共同呈现或接续，既不统一小窗，也不强制全屏。

同一视觉负责人持续完成美术、演出、源码和返修。复杂主体继续按既有参考方法保留造型、部件、遮挡、中途和响应；普通字幕、重点花字、源时钟及已采用表现照常交接。气质调整改变具体选择，不作为删减已验证能力的理由。

只有符合本页选择规则时才加载可选的严肃调查参考。未采用时不按它限制彩度、材质或动作；只采用局部方法时也不更换整片气质。

<a id="support"></a>

### 素材与声音：执行本片的具体选择

导演在原有完整声画稿中交清所需材料的用途和声音作用。素材继续开放探索，候选不必单独承担整段表达；题材相关、身份正确或文件可用不等于本段适用。核对实际姿态、行为、细节、源范围和声画语境，再由原作者选择用法。

声音作者继续原配音、取材、生成和混音方法。根据本片方向安排讲述重点、环境、音乐、动作声及强弱变化；不因加载共同方法就统一低沉、低密度或取消轻快声音。声音的回应与收束应配合实际过程，不能提前关闭尚在发展的关注。

同一句话到来时需要看见什么、哪次声音支持哪项变化、何时可以离开画面，仍写在现有段落中，依真实声音、源范围与作品事件校准。只有相关范围变化才续接对应作者，不增加额外交接体系。

<a id="review"></a>

### 审片：按本片采用的方向判断，不按统一风格打分

先记录实际作品的观看印象，再对照当前稿的采用方向与适用范围。共同特点检查内容和观看关系；视觉气质检查只使用本片真正采用的标准。不能因为作品明快、可爱、温暖或有弹性，就按严肃调查标准判错；也不能只因暗色、冷光和低饱和就判好。

检查内容是否提供本片所需的具体感受、关键变化或细节是否有观看空间、局部表现是否支持整体方向。局部借用只检查采用项，不把参考全文当成隐含要求。缺少方向说明时先读取当前稿与已有决定；仍缺失就向原负责人补齐，不能由审片者默认套严肃调查。

返修定位到内容选择、素材适用性、视觉与声音用法、实现遗漏或相互配合。已实现但不合适时改具体选择；不要为通过新检查降低原有动作、字幕和声音标准。专业判断不冒充已经测得的观众反应。

气质检查并入原专业审阅（`.agents/skills/quality-verification/references/professional-review.md`）：按同版实际覆盖复用证据，保留作者、导演与独立审阅者的责任区别；不逐层重复整片观看。局部返修核对受影响范围和必要接点，旧观察不得改记为新版。未看、未听的范围如实保留未知，不新增统一导出门禁。

<a id="investigative-profile"></a>

## 二、可选视觉技能：严肃调查

文件：`.agents/skills/visual-treatment-planning/references/editorial-visual-tone.md`

**本页不是全局默认，也不是新的第七种视频类型或固定表达方向。** 先按[方向选择规则](#selection)读取本片当前稿。只有已经明确采用严肃调查态度的全片或连续范围，才使用对应规则。主题真实、出现风险或属于解释片，不构成自动启用条件。

只借资料定位、光线或空间等局部做法时，仅在当前稿指定范围执行该做法，不同时套用整套配色、材质、运动和声音倾向。未采用或与用户现有方向冲突时，继续原美术方向，不以本页作审片标准。

本页提供可直接制作的风格细节，支持冷静、可信、有现实分量的观察与解释；不要求运行时再阅读外部仓库。沿现有美术、动效、素材、声音和审片 Skills 实现，不替换其专业能力。以下各节都受上述范围约束。

### 1. 先形成同一部作品，再设计不同场面

在已采用范围内，把环境明暗、主体材料、重点颜色、字形语气和运动性格写成当前作品的实际选择。统一这些关系，而不是把每个场景做成相同背景、相同标题区和相同容器。

原件阅读、真实环境与原创图形可以交替成为重点。改变表现载体时，至少保留本片已建立的文字气质、明暗关系、观看方向或材料承接中的有效联系；不要在每次切换时重新介绍一套独立包装。

设计采用前同时检查画面初态、主要变化中的状态与相邻画面。局部配色漂亮、某个主体精致，不代表它适合整片。

### 2. 配色：先安排明暗与面积，再安排强调色

大面积承载面以中性或低至中彩度的颜色建立稳定环境。根据实见材料确定偏冷或偏暖、明或暗，保留可辨的中间层次；不要用统一压暗掩盖层次不足，也不要把冷色当成严肃的自动证明。

区分环境色、材料本色、信息标记与事件强调。环境先退后，主体和关键内容获得清楚对比；高彩度、高亮度或大面积色面具有更强的注意作用，应用在本片真正需要改变关注的位置。相邻的多个彩色面不能长期等权争夺注意。

强调通过对象本身、局部标记、光线或有明确用途的色面发生。整幅高彩度背景只有在它确实承担当前表达且与前后态度连续时才采用，不把它当作所有结论的默认包装。颜色含义与对象身份保持一致，但同一颜色不必在每场占据相同面积。

原件的白面、实拍的本色、真实标识和对事实有意义的颜色应保持可辨。适配时优先处理外围承载、明暗和层级；不能为了统一风格把资料染到难读，或改变素材中具有意义的颜色。

在实际缩小观看尺寸下检查主体与环境能否分开、关键内容是否仍突出。单纯降饱和不是修复方案；颜色冲突也可能来自面积、边缘、材料与层级。

### 3. 光线与材质：让主体有出处、有重量

真实影像优先承接其实际光向、环境色与空间；原创主体先确定可解释的主光方向和环境填充，再分配亮面、转折面、暗面、接触阴影和必要反射。同场对象的受光、投影和空间归属应当相容。

材质通过轮廓、边缘、粗糙度、反射范围和明暗过渡被辨认。厚度、开口与连接部位参与造型，也支持后续动作；不要只在平面标签上加一层阴影就视为具备实体感。写实程度依内容决定，图解同样可以有清楚而成熟的形体。

自发光、辉光、颗粒、纸纹与扫描感只用于当前材料或环境所需要的质感。光效不要让所有对象看起来都在被隆重展示；纹理不要成为另一层持续抢读的运动，更不能降低证据文字清晰度。

既有二维、图像部件和视频素材可以建立空间分量，不强制三维建模。需要的视角、分层或运动超出现有资源时补足实际资源或重选制法，不假装整张图具有未知的内部和背面。

### 4. 材料与构图：让观众接近事情，而非停在展示页外面

从当前值得观察的内容决定主体面积和观看距离。需要看清行为、细节或原文时提供足够画面；需要理解空间或相互关系时展开观察范围。保持必要参照，不以统一全屏或固定小窗替代判断。

证据展示沿“认出来源与语境、定位有关内容、看清其意义”的实际需要组织，可合并已有前提，不固定每次重来。准确原句与必要解释保持对应，去掉无关页面部分但保留影响判断的条件；外语材料的中文解释不得改变原意或冒充原文。

照片、视频、原件与图形保留各自有用的形态和观察方式。采用共同光向、边缘逻辑、字形及空间关系使它们成为一体，不强制每份材料使用胶带、撕边、圆角卡或调查桌。

多个对象同时存在时，用尺度、前后、明暗与疏密安排观看顺序。留白应当为观察、运动和关系服务；大面积空底配小主体，也不能因为排版干净就判为有分量。

候选的姿态、表情、动作、机位和环境气氛应支持其当前用途。身份或题材正确仍可能不适合这一段；可以改用其他真实范围或载体，不修改原人物反应来迎合预期情绪。类比与环境素材允许使用，但不能剪成事实证据或本人经历。

### 5. 排印：明确判断，不把所有内容都包装成口号

选择真实可用、结构清楚的中文字形，依主读、辅助解释与来源信息建立稳定层级。重点字可以大胆、有力度，但其轮廓、断行、面积和出入应服务当前内容，不凭情绪词自动占满画面。

重要判断已经具备观察或论述基础时，再让排印完成聚焦、对照或收束。原件阅读与主体行为正在承担主要表达时，文字提供必要指认和解释，不覆盖关键部位，也不把整句旁白重复做成第二套主画面字幕。

标题、标签与画内文字随当前观看发展组织，不因技术分段固定增加页眉、页码、章节标记和角落说明。普通字幕沿原有统一规则制作，不导入外部风格的字幕条、字体文件或固定停留秒数。

### 6. 运动与镜头：保留完整动作，改变动作性格

主动作具有准备、发力、经过、响应与收势；哪部分需要重量、阻力、速度差或余波，由对象与当前事件决定。沿现有方法设计关键中途、部件跟随、遮挡和接管，不把严肃做成僵硬，也不把高级简化为少动。

过冲、回弹、挤压与抖动按材料与表达采用，而非同一套弹性套在全部对象上。重点之间保留对比，不让每次出现、每次转向都达到同样幅度和速度。已采用的复杂主体结构与动作不能因气质校准而删掉。

镜头改变观察位置应带来具体内容或关系：把难辨内容看清、跟随过程、发现联系、展开范围或重新理解尺度。已有主体运动承担观看时，相机可以稳定支持；不在每条素材上重复无目的推进。

变化留下的对象、结果和必要参照延续到后续。场间连接继承当前有效的动态交接要求，以本片实际内容完成，不导入外部默认硬切、固定帧率或全片按音乐拍点切镜。

初稿时序用秒和语义关系，落地按真实旁白与源事件校准。阅读、辨认、动作响应和收势需要实际空间；删减重复解释与竞争层来提高效率，不统一加速或拉长等待。

### 7. 声音：维持同一态度，让变化被听见

把当前采用的声画稿交给原声音作者。讲述保持自然、清楚且有重心，语调随观察、解释、质疑与判断变化；可信不等于毫无起伏，不用恐惧语气代替事实分量。

环境、配乐和动作声形成相容的距离、材料与空间。持续关注可通过音色、密度、持续范围与声画先后发展，不只靠越来越响；重要变化可以共同强化，但不让每个入场都成为孤立音效重音。

声音的收束依据当前结果与后续问题。尚未解决的内容不被不合适的胜利式收尾提前关闭，解释段也不自动变成情绪重置。选择退让或留白应有听觉连续性，避免突然全轨消失像技术故障。

具体声源、起音、攻击、尾音、增益与避让沿现有能力取得和校准。原声身份保持，不伪造现场；实际试听未完成时，不把声音计划或波形判断写成听感通过。

### 8. 用实际画面作最后选择

在现有预排或成片的已采用范围中检查：第一眼是否看向重要内容；明暗、材料、姿态与排印是否形成同一态度；强色与运动是否把重音给了真正重要的变化；资料与主体是否可观察；前后场面的情绪是否在内容需要处继续或改变。

同时对照已采用的整体参考与本片稿，不以“暗、冷、低饱和”作为通过条件。参考帮助判断完成度，不能替本片决定事实、题材或固定剧情。

构图和颜色由静帧辅助判断，动作与声音回到连续声画。设计已完整实现但整体类型或分量仍不合适，应由导演与视觉作者重选；不追加无关装饰，也不只改一个色号就结束返修。

本检查并入既有专业审阅，按实际覆盖与修改范围执行；不因为采用该风格新增一次完整渲染、整片观看或审批。

node .\videoflowcut-tone-kit\apply-editorial-tone.mjs --apply
