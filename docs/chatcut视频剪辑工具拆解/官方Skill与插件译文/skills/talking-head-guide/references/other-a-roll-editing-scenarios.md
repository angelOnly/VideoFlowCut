# 其他 A-roll 编辑场景

#### 精彩片段提取

精彩片段提取不是把内容剪得越短越好，而是根据用户标准选择最有价值的口述内容。

规则：

- 先确定精彩片段标准：观点、结论、故事、情绪、冲突、教程步骤、数据点或特定主题。
- 每个精彩片段都应能独立理解。不要删掉理解它所需的主语、铺垫、问题或结论。
- 如果周围上下文是理解某句有力短句所必需的，不要只保留那一句。
- 如果用户要求特定主题，删除其他主题。如果用户要求“最好”或“最精彩”的时刻，优先考虑信息密度和表达力度。
- 提取精彩片段后，通常还应清理保留片段，让最终结果更完整。

#### 重组

重组表示改变口述内容顺序，不表示可以随意拆开句子。

规则：

- 先确认目标结构：按时间、按主题、按问题、结论前置、教程步骤或短视频节奏。
- 移动完整语义单元：完整句子、观点、回答或步骤。
- 不要把一句话拆开，让前半句出现在一个位置、后半句出现在另一个位置。
- 移动内容后，检查 `so`、`but`、`next`、`this` 等连接词是否仍然成立。
- 如果用户要求大幅重组，但没有指定目标结构，编辑前先确认。

#### Hook / 短版本

Hook / 短版本工作的目标，是让开头更有吸引力，或把长内容压缩成更短但仍完整的版本。

规则：

- 优先从原素材中提取 Hook：有力观点、结果、冲突、问题、反直觉陈述或情绪强烈时刻。
- 如果必须生成新 Hook 或新旁白，先和用户确认方向。
- 制作短版本时，不要只按照时长裁切。先确定要保留的主线：问题、核心观点、关键原因和结论。
- 短版本可以删除示例、重复和铺垫，但必须保留支撑观点所需的逻辑。
- 如果用户给出目标时长，尽量匹配。如果时长与语义完整性冲突，说明取舍。

#### 目标文稿 / 文稿对齐

目标文稿 / 文稿对齐表示根据用户提供的文稿、目标段落或期望内容裁切最终口述内容。

规则：

- 目标文稿是主要约束：优先保留与目标含义匹配的内容。
- 自然的口语化改写可以接受，但不要包含目标没有要求的周围内容。
- 如果源素材有多个相似版本，选择最完整、自然且最符合目标的版本。
- 如果目标顺序与源顺序不同，可按需重排，但要移动完整语义单元。
- 如果目标文稿省略了源上下文，应遵循目标。除非没有这些内容会导致结果无法理解，否则不要增加很长的周围上下文。

#### 构建版本、精彩片段和节选

精彩片段、短版本、节选、Hook、重组以及制作多个版本，都是文字稿内容任务：通过 Script（`read_script` → 编辑 `timeline.md` → `apply_script`）驱动，绝不能通过查找时间戳并手动放置源片段实现。

- 根据内容来源选择起点。基于当前 Timeline 制作版本：裁切或重排 `timeline.md` 并执行 `apply_script`。需要独立 Timeline 的版本（用户要求分开的 Timeline，或希望每个版本可独立编辑/导出）：对 `manage_timelines` 使用 action=duplicate——副本会带上内容和 Script，因此可以立即执行 `read_script` → 裁切 → `apply_script`。从 Library Asset 全新构建：对 `manage_timelines` 使用 action=create，添加源 Asset，然后通过 Script 驱动。
- 要引入当前剪辑中已经不可见的源内容（Hook 句、另一个版本需要的片段），读取 `library/<filename>.md`，把所需 `[sN]` 行复制到 `timeline.md` 中应在的位置，然后执行 `apply_script`。这就是通过 Script 把源内容放到 Timeline 的方式。
- 在同一个 Track 上制作多个版本：按照版本顺序，把每个版本的全部 `[sN]` 片段依次列入 `timeline.md`，一个版本接一个版本，然后只执行一次 `apply_script`。复用就是重复——同一个 `[sN]` 片段可以出现在多个版本中，重复该行就会再次播放对应源范围。
- 绝不能用 `find_transcript` 查找时间戳，再用 `edit_item` / `split_item` 放置口述内容。如果你正在把文字稿 Segment 转换为源帧或秒数范围，说明已经离开正确编辑表面——回到 Script。`edit_item` / `find_transcript` 只用于与文字稿无关的放置，例如 MG 叠层和 B-roll 视觉时序。

**根据请求检查每个版本。** 组装某个版本、精彩片段或节选后，从头到尾重新读取结果，确认所有要求的句子都存在、顺序正确，并且没有夹带额外源内容。完成前修复遗漏、重复或顺序错误的内容。
