# ChatCut UI 与功能

## 项目入口与控制台

登录后，ChatCut 会打开编辑器。如果用户已经有项目，会打开最近更新的项目，同时项目控制台可用。如果用户没有项目，ChatCut 会创建一个空项目并打开编辑器。

- **新建项目**——在项目控制台中，用户可以点击 **新建项目** 创建另一个空项目。
- **场景快捷项/卡片**——在新的或空的 AI 对话中，用户可以选择工作流起点：
  - **Seedance 2.0**（仅限 ChatCut Pro）——根据文本描述生成 AI 视频片段。
  - **应用宣传片**——为应用或网站创建精致的宣传视频。
  - **URL 转广告视频**（Seedance 2.0，仅限 ChatCut Pro）——粘贴产品链接，生成 UGC 风格的短广告视频。
  - **MG 动画**——根据文本或图片参考生成动画视觉元素。
  - **口播剪辑**——上传口播素材；Agent 会选择最佳片段、剪掉填充词、收紧节奏，并添加 MG 动画。
  - **讲解视频**——提供一个主题（也可以提供自己的媒体）；Agent 会使用 AI 旁白、画面和背景音乐创建完整讲解视频。
    选择场景后，会在 AI 输入框中插入一条起始提示词。用户可以在发送前编辑它。

## 编辑器布局

编辑器有五个主要区域：

### AI 面板

与 AI 助手对话的区域。用户可以在输入框中通过 @ 提及 Timeline Item 和 Asset，准确告诉 AI 要修改什么。也可以附加文件，作为 AI 的上下文。

面板底部：

- **模式切换器**——有两种模式：
  - **Agent**——完整的 AI 编辑助手。AI 会读取消息、理解上下文并执行编辑任务。
  - **Video Gen**——直接视频生成模式。输入会直接发送到视频生成管线，不经过 AI 对话，因此消耗更少积分。
- **Agent 设置**——从 Agent 模式选择器旁边的控件打开。设置包括：
  - **思考模式**——开启或关闭 Agent 的额外推理。
  - **MG 动画质量**——为 MG 动画生成选择速度、平衡或质量。
  - **生成自动允许**——控制当前项目中，MG 动画、视频生成和图片生成是否可以跳过重复的积分确认提示。如果用户在积分确认提示中选择了“允许此项目中的所有……”，对应开关会在这里启用。若要为当前项目关闭它，使用 **Agent 设置 -> 生成自动允许 -> MG 动画 / 视频生成 / 图片生成**。
- **生成确认卡片**——在 MG 动画、视频生成或图片生成开始之前，AI 聊天中可能会显示一张审批卡片，其中包含 **允许**、**允许此项目中的所有……**、**拒绝** 和一个调整字段。它会显示在 AI 聊天区域中，靠近输入框。如果卡片消失，可能是已经被回答、取消或超时；询问用户是否重试，或从 Agent 设置中开启自动允许。
- **+ 按钮**——上传参考文件（图片、视频等），把它们包含在消息中。
- **Skills / 技能（书本图标）**——打开聊天输入框下方的 Skill 选择器。用户可以选择预设 Skill 或自己保存的 Skill，使用可复用工作流指导 AI 处理当前消息。保存的 Skill 归用户所有，可以跨项目复用。选择器还包含 **将此编辑流程保存为 Skill**，它会插入一条提示词，请 AI 帮助记录当前工作流。
- **选择按钮**——切换选择模式。开启后，用户可以通过以下方式引用内容：
  - 点击时间线或“素材库”中的 Item，引用特定片段/Asset。
  - 在预览画布中拖动矩形框，引用一个屏幕区域。
  - 点击时间线标尺上的某一点，引用特定时间。
  - 在文字稿面板中选择文本，引用一段语音。
    选中的引用会作为 @ 提及添加到输入框中，让 AI 准确知道用户指的是什么。
- **发送 / 停止按钮**——发送消息或停止正在执行的任务。

### 中央——预览

视频预览画布。显示当前播放头位置的时间线实时预览。下方提供播放控件。

### 素材库、Library 与文字稿面板

这些标签页共用一个面板组（与 AI 面板分离）：

- **素材库**（ZH：“素材库”）——用户的媒体池。显示上传、录制、导入和生成的媒体。用户可以把 Asset 从这里拖到时间线上。**上传** 按钮会打开 **文件...**、**文件夹...** 和 **从手机...** 选项。
  - **生成进度：** 当 AI 生成任务（视频、图片、音乐等）正在执行时，它们会显示在素材库中，并带有进度指示器。用户可以在这里查看生成仍在运行还是已经完成。
  - **生成失败：** 如果生成失败，素材库会在 Asset 卡片上显示失败状态。用户可以让 AI 重新生成。
  - **文件夹：** 用户可以创建文件夹来整理 Asset。
- **Library**——内置预设/特效/Asset，可以与用户自己的 Asset 分开浏览。
- **Templates**——启用时显示模板浏览器。
- **文字稿**（ZH：“文字稿” / ES：“Transcripción”）——用于口播/访谈素材的文本编辑面板。用户通过编辑文本来编辑视频：
  - 选择并删除不需要的词语/句子，把它们从时间线中移除。
  - 拖动文本段，重新排列视频顺序。
  - Agent 编辑时，结果会在这里实时预览——删除内容显示为删除线——用户可以在这个面板中微调。
  - 文字稿跟随活动字幕/源 Track。如果没有设置特定源 Track，则使用第一个包含视频或音频的 Track。

### 顶部栏

从左到右：

- **主页图标**——打开项目库/控制台。
- **项目名称**——项目所有者可以点击标题文本改名。非所有者可以查看名称，但不能改名。
- **共享与成员**——项目名称旁边的按钮，用于共享项目和管理成员。
- **撤销 / 重做**——撤销或重做编辑操作。
- **工作区菜单**——显示或隐藏面板：AI、素材库、Library、文字稿和时间线。还包含 **重置为默认布局**，用于恢复默认布局。
- **版本**——保存和恢复项目快照。
- **导出按钮**——打开包含五个标签页的导出面板：
  - **视频**——导出为 MP4。选项：分辨率（1080p / 720p / 480p）、帧率（24–60 fps）、导出范围（完整时间线或所选区域）。
  - **音频**——仅导出音频，格式为 MP3。
  - **图形**——把每个 MG 动画分别导出为带透明背景的 ProRes 4444 `.mov` 文件（仅限 ChatCut Pro）。
  - **字幕**——导出字幕。
  - **XML**——导出 NLE XML 文件；包含 MG 动画时，也可以把它们分别渲染为 ProRes 4444 文件。
- **积分余额**——显示用户当前积分余额。它属于用户个人资料菜单的一部分。
- **用户个人资料菜单**——下拉菜单会显示用户邮箱、当前套餐（免费版或 ChatCut Pro）及积分余额，并提供 **升级** 按钮。菜单项包括语言、皮肤、邀请好友、反馈、键盘快捷键、积分记录、桌面应用、Agent 插件和退出登录。订阅和支付操作位于 **积分记录** 中。

### 播放控件（时间线上方）

- **分割工具**（快捷键：C）——在播放头位置分割片段。
- **吸附开关**（快捷键：Shift+M）——拖动时间线 Item 时启用/禁用网格吸附。
- **播放 / 暂停**（快捷键：Space）
- **时间显示**——当前位置 / 总时长。
- **缩放控件**——放大/缩小时间线，以及用于显示完整时间线的“缩放以适合”。
- **宽高比**——更改画布尺寸。预设：16:9、9:16、1:1、4:3、3:4。
- **字幕**——启用自动字幕，并选择内置字幕样式（例如 Plain、Netflix、TikTok）。可见的内置目录会根据当前字幕语言调整；保存的自定义样式仍然可用。
- **全屏**（快捷键：`）——进入全屏预览模式。

### 时间线（底部）

一个项目可以包含多条 Timeline（序列）——例如一个长版本和一个短宣传版本。活动 Timeline 从时间线标尺上方的下拉菜单选择；切换下拉菜单会替换可见 Track 和片段，而 Asset Library 仍然共享。

时间线会显示活动 Timeline 的所有 Track 和片段。视频 Track（V1、V2……）在上方；音频 Track（A1、A2……）在下方。用户可以：

- 拖动片段重新定位。
- 拖动边缘裁切片段。
- 使用播放头（黄色标记）浏览视频。
- **标记入点/出点区域**——按 **I** 标记入点，按 **O** 标记出点，按 **X** 清除区域。导出时可以使用选中的区域，只导出视频的这一部分（在导出面板中选择“区域”作为导出范围）。

每个 Track 都有控件：可见性开关（眼睛图标）、音频开关（扬声器图标）和删除（垃圾桶图标）。
