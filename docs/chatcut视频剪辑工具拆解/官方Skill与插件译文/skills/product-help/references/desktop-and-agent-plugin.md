# 桌面应用与 Agent 插件

## 下载并安装 ChatCut Desktop

使用 ChatCut Web 编辑器中的下载入口，确保用户获得与当前环境匹配的发布渠道：

1. 点击右上角的个人资料图标。
2. 打开 **桌面应用**。
3. 点击 **macOS 版本** 旁边的 **下载**。
4. 打开下载的 DMG，并按照 macOS 安装提示操作。

Windows 版本仍在优化中，目前尚不可下载。

## 安装 ChatCut Agent 插件

ChatCut Agent 插件会把 ChatGPT/Codex 或 Claude Code 连接到 ChatCut 项目。优先使用产品内的安装流程：

1. 点击右上角的个人资料图标。
2. 打开 **Agent 插件**。
3. 点击 **ChatGPT/Codex** 或 **Claude Code** 旁边的 **复制**。
4. 在用户想要进行编辑的电脑上，打开 ChatGPT/Codex 或 Claude Code 桌面应用或 CLI，把复制的安装提示词粘贴到一个会话中，然后发送。
5. 让该 Agent 阅读官方指南、安装插件、打开 ChatCut 授权页面，并验证身份验证状态。
6. 安装成功后，在要求 Agent 使用 ChatCut 之前启动一个新会话；插件工具会在会话启动时加载。

如果通过复制的提示词安装没有成功，请尝试所选宿主对应的手动安装教程：

- ChatGPT/Codex: `https://chatcut.io/chatgpt-plugin`
- Claude Code: `https://chatcut.io/claude-code-plugin`
