# 积分与 ChatCut Pro

## 什么是积分

积分是 ChatCut 中所有 AI 功能使用的货币。每当 AI 处理一个请求时，都会消耗积分。

**会消耗积分的操作：**

- AI 对话——与 AI 聊天，让它编辑和完善你的视频
- AI 生成——创建视频、图片、MG 动画、音乐或旁白

**不会消耗积分的操作：**

- 浏览和预览项目
- 手动编辑（在时间线上拖动、裁切、调整 Item）
- 导出视频
- 上传媒体文件

## 积分如何消耗

积分消耗分为两种类型：

### 1. 对话

你发送给 AI 助手的每条消息都会消耗积分。消耗量取决于：

- **任务复杂度**——包含许多修改的多步骤编辑任务，比简单问题消耗更多。
- **对话长度**——一次会话中的对话越长，AI 处理的上下文越多，每条消息的成本也会增加。
- **项目规模**——包含更多片段和 Track 的大型项目，需要 AI 读取更多上下文才能理解。

提高积分使用效率的建议：

- 请求要具体、清晰，以减少来回沟通。
- 对无关任务开启新的项目/会话，保持上下文较小。

### 2. 生成

每项生成任务都会独立消耗积分。大致费用如下：

| 功能                                                   | 大致费用                          |
| ------------------------------------------------------ | --------------------------------- |
| AI 视频生成                                            | 每个 5 秒片段约 3 积分            |
| AI 图片生成                                            | 每张图片约 0.2–0.6 积分           |
| MG 动画生成                                            | 每次生成约 0.1–0.3 积分           |
| AI 音乐生成                                            | 每首歌曲约 0.12 积分              |
| AI 旁白（文本转语音，包括克隆音色）                   | 每秒音频约 0.08 积分              |

这些只是大致费用——实际费用可能会根据复杂度和输出略有变化。

**重要：** 只有生成成功后才会扣除生成积分。如果生成失败，不会消耗积分。

对于 MG 动画、视频生成和图片生成，在 Agent 开始执行会消耗积分的生成之前，用户可能会在 AI 聊天区域看到确认卡片。选择 **允许此项目中的所有……** 会仅为当前项目开启对应的 **生成自动允许** 开关。若要稍后在该项目中关闭它，请从 AI 面板底部、**Agent** 模式选择器旁边打开 **Agent 设置**，然后打开 **生成自动允许**。

## 查看余额与使用记录

当前积分余额显示在右上角用户菜单区域、个人资料头像附近。打开个人资料菜单可以访问升级以及积分/账单选项。

要查看积分使用记录，请点击个人资料图标 → **积分记录**。对话框会按天、按类型或以完整明细显示当前积分、订阅状态和使用记录。

根据用户的问题，引导其查看相应页面：

- **我还剩多少积分？** 查看 **积分记录** 顶部的可用余额。
- **我用了多少积分？** 使用 **按天** 查看每日总计，或使用 **按类型** 查看按功能分组的总计。
- **上一个操作用了多少积分？** 在 **明细** 中查看最新的负数交易。同一行还会显示该笔扣费后的余额。
- **一次付款增加了多少积分？** 引导用户进入右上角头像菜单 -> **积分记录**，查看顶部的 **积分** 表格。仅凭支付金额无法推断结果，因为所选产品、计费周期和促销可能不同。
- **如何订阅或购买更多积分？** 使用右上角头像菜单 -> **升级** 订阅 ChatCut Pro。已订阅用户可以在出现该按钮时使用 **积分记录** -> **购买积分**。

不要根据任务描述、美元金额或大致生成价格估算准确的实时账号数值。应提供上面的导航。购买会增加积分；购买本身不是积分消耗。

## 支付方式

ChatCut Pro 结账支持银行卡和支付宝。

- 使用银行卡或支付宝支付的 ChatCut Pro 月度套餐会自动续订。
- 使用银行卡支付的 ChatCut Pro 年度套餐会自动续订。
- 使用支付宝支付的 ChatCut Pro 年度套餐覆盖一个年度计费周期，不会自动续订。
- 对于积分包，以结账页面为该次购买可用支付方式的权威来源。

当用户询问 ChatCut 是否支持支付宝时，应直接回答 **支持**，并在相关时解释月度与年度续订方式的差异。不要因为这个问题把用户引导到客服。

## 管理订阅

打开右上角头像菜单 -> **积分记录**。在 **积分记录** 对话框中，使用 **订阅** 区域：

- **更换套餐** 会打开升级对话框，并显示可用套餐。
- **取消订阅** 会安排在界面显示的当前周期结束日期取消。在此之前付费功能仍然可用。
- **恢复订阅** 会在计划取消生效前撤销取消。
- **管理支付** 会打开支付方式管理；付款逾期时会显示 **更新支付方式**。

取消订阅不会产生退款。对于退款请求或错误扣费，在提供上述相关自助步骤后，使用头像菜单中的 **反馈**，或发送邮件至 team@chatcut.io。

## ChatCut Pro

### 免费版

- 注册后获得积分。
- 可以使用核心 AI 编辑功能。
- 某些高级功能（例如 Seedance 2.0 视频生成和 ProRes 导出）需要 ChatCut Pro。

### ChatCut Pro

ChatCut Pro 是应用中显示的付费订阅。它包含积分并解锁高级功能。**升级到 ChatCut Pro** 对话框会显示当前积分、价格、折扣和结账方式，因此准确价格应以应用内对话框为准。

**ChatCut Pro 功能包括：**

- Seedance 2.0 视频生成
- MG 动画透明背景导出（ProRes 4444）
- 所有 AI Agent 编辑能力
- MG 动画生成
- AI 图片生成
- AI 音乐生成

**积分有效期：**

- 订阅积分有效期为 2 个月——如果本月没有用完全部积分，它们会结转到下个月。

### 积分包（附加购买）

用户需要额外积分时，可以购买一次性积分包：

- 积分包会显示在 **升级** 对话框或 **积分记录** 流程中。
- 常见积分包大小为 100、200、400 和 800 积分。
- 积分包价格会在应用内结账时显示。
- 购买时应以结账或账单 UI 确认积分包有效期。

## 如何升级

1. 点击右上角的个人资料图标。
2. 点击套餐/积分余额旁边的“升级”按钮。
3. 查看可用套餐和积分选项。
4. 完成支付。

## 如何购买积分包

1. 点击右上角的个人资料图标。
2. 选择 **积分记录**。
3. 点击积分区域中的 **购买积分**，或打开 **升级** 并切换到积分包视图。
4. 选择积分包并完成支付。
