# 导出

只有在用户要求渲染、下载或最终独立交付物时才导出。审阅检查点通常应保持为可编辑的 ChatCut 时间线。

使用当前工具 schema 调用 `submit_export`。根据项目状态和用户意图确认目标时间线、范围、分辨率、编码器和格式；不要猜测非活动时间线。记录每一个返回的 `renderId`。

使用 `track_export` 查询状态。它是渲染任务跟踪器；不要对导出任务使用生成/转录用的 `track_progress`。当工具支持查询项目最新导出时，使用其最新渲染选项，不要猜测 ID。

渲染完成后，返回它的 `downloadUrl`。在 Claude Code 中，把完成的文件下载到不会发生名称冲突的本地路径，并提供路径、本地文件预览链接和简洁的渲染元数据。在 Codex 中，通过宿主正常的文件/链接交付方式提供完成后的下载 URL。不要把仍处于 queued 或 running 状态的渲染宣称为已经交付。

导出字幕或 NLE XML 时，使用对应的 `submit_export` 格式，并报告不受支持或被丢弃元素的警告。交付带透明背景的 MG 动画时，使用当前 manifest 暴露的专用 MG 导出工具，并跟踪返回的渲染 ID。

如果云端渲染因为媒体不能被远程读取而受阻，在用户允许上传时使用 `asset-import`。否则应报告阻塞原因；不要在没有用户意图的情况下在本地压平或替代该编辑结果。
