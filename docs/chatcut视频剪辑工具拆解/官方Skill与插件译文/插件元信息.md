## 它怎样连接 ChatCut

官方 README 声明，插件通过 ChatCut 托管的外部 MCP 服务连接，由宿主完成账号授权。基础 Skill 进一步说明：

```text
账号授权
→ 当前会话加载 mcp__chatcut__* 工具
→ 以当前 manifest 为实际工具合同
→ Project、素材库和 Timeline 由 MCP 读写
→ 浏览器编辑器显示同一项目状态
```

这不是“把 ChatCut 安装到本地并直接操作数据库”。官方 Skill 明确要求通过 MCP 读写 Project，不要猜测隐藏 ID 或直写数据库。

## 为什么不在这里重建 MCP 配置

ZIP 的 `plugin.json` 指向 `./.mcp.json`，但压缩包没有包含该文件，也没有包含它提到的一部分图标和辅助脚本。因此本目录只保留阅读资料，不把缺失片段补写成看似可安装的配置。

真正要判断“此刻有什么工具、参数叫什么、是否能调用”，应查看当前会话实际加载的 MCP manifest 和工具返回，而不是本页。
