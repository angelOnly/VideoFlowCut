# 实际采用设计整理：v3 / 最终交付R72

**文件身份：本轮依据原始记录和最终源码整理，不是当时完整导演稿的原件。**原包没有独立 `adopted_brief.md` 全文。可直接验证的文字是[原始输入](original-input.md)、最终固定输入中的 [creativeBrief原文提取](submitted-brief.md) 和[生产报告](../source/production-run.json)。本文件把三者的关系说明清楚，不补造未保存的代理对话。

## 1. 内容如何采用
报告 `creativeDecisions` 的 story 记录选择新的 visual_explainer 作品，保持时代变化、熟悉入口、椅子比喻、随手换走、节目压力与提前编排。semantic 记录说三句群旁白实测26.280秒、788帧，按164个 provider token 重分21张单行卡，并纠正“滑”“录”两处识别字。记录同时说明保留“像、可能、不少、往往”等限定。

因此：原输入的完整评论是内容基线，不应在资料中直接重命名成最终配音逐字稿。最终WAV可听，最终字幕在MP4中可见，但原包未给完整 Caption Program/最终脚本文本及对齐文件。本轮没有对音频重跑ASR生成一份冒称原稿的文件。

## 2. 实际固定输入
| 项目 | 实际值与来源 |
|---|---|
| 画布与帧数 | source.json：768×1344、30fps、788帧 |

| 内部场面 | Motion.tsx：x32/y163/w480/h436，普通白字幕底带x32/y600/w480/h60 |

| 普通图内字 | fontBindings.body：noto-sans-sc-bold |

所有数值属于历史作品，不是新增引擎默认。原生字幕字体不受 work.fontBindings 自动控制；源码只画白带，实际文字由原生Caption轨合成。

## 3. 实际场面如何连续发生

### 人群与暂离
`Opening`先呈现时代两行文字；`People`在同一舞台里建立多排人群、三入口和中央光锥。leave事件164帧仅改变中央头像状态，左右仍存在。chair事件239帧对应摄影椅取得前景，代码从事件前6帧开始，外围缩小5%左右但保留归属。

### 手机与四字
phone事件284帧触发设备进入。四个 `pages` 让四个源区间在同一屏幕里接续；同一页的游戏和人物区调用相同视频槽，不各自另起源时钟。effect事件334帧触发四字演出；字的位置保持读序，显现延迟分别0/3/8/5帧，对应实际顺序“不、能、场、冷”。13—14帧的归正过程与手机靠近重叠。

### 手机到节目
主字从pressure−3开始退，手机从pressure=505开始下沉。board=512和art=517在phoneEnd=528之前已经启动，新的灰板、头像和图片在旧手机退场中接入。两者并不声称是同一实拍镜头的像素变形，联系来自当前论述。

### 节目与镜片
plan=585触发纸条和点线，lens=587紧接进入，lensSettled=609进入阅读状态。纸条每4帧错时、主要动作12帧；镜片先在画外部分可见，收至216直径、1.42倍率后沿阅读点移动。`Observer`以同一f重画 `Programme`，不含Observer自身。

## 4. 原作者补充了什么
原输入已写主体、美术和主要运动，但最终作者仍作了本批材料特有的选择：
- 四页游戏与人物ROI分别填入 `props.pages`，并针对A/B后续修订；
- 椅子摄影的外轮廓及气杆两侧孔洞写入 `RealChair`；
- 五张纸条最后一条用22px而非其他条25px，保留镜内字幅；
- 最终长度跟随实际26.280秒声音，而不补到输入估计的29—33秒；
- 原生字幕黑字叠在作品白带上，不用本作品重复绘制整条字幕。

这些来自source.json与报告，不能全部归功于原始提示词，也不能在新任务中照抄ROI或轮廓。

## 5. 最终合成与修订的边界
报告记载R49首次完整预览；v2修摄影椅背景轮廓；v3只改A/B游戏取景，C/D、字体、事件和声音等保持。小包仅保留v3源码和最终视频，v1/v2旧源码与R49视频未附，因此报告的历史过程有文字证据，但本轮不能逐字重建它们的原文件。

音频记录采用完整旁白主导，不用BGM和三个候选音效家族。响度目标与最终检测见原报告，不能把“加更多音效”总结成本次成功原因。最终影像接受少量摄影椅背景残余，机器连续动态和原生听审范围仍按原记录保留；用户后来的认可另见 user-feedback.md。

## 6. 这份整理能用于什么
它让新作者理解实际输入怎样落成源码，并把“输入已有”“作者补充”“预览修订”分开。它不替代原始源码，也不是一份已经在新主题上通过的教学生成指令。新作品从实际材料重新设计，经正常链路生成和检查。
