# 从这条成功片迁移到没有参考的新主题

本页是新增教学方法，不是旧视频的生成输入。尚未产生对应的新主题结果。

## 先分开三个层次
一是内容方法：真实材料怎样提供一个可跟随的问题、比喻、例子或变化。二是设计方法：按这个内容决定哪些主读值得出现、对象怎样持续、什么地方需要观察。三是实现方法：根时钟、已登记字体、投影、遮罩、连续曲线。新片需要重新完成前两层，再选择复用第三层的哪部分。

## 迁移不是把大司马换成另一个人
如果新题材是某款工具如何让用户找到一条重要结果，可能适合“同一对象保持→一处条件取得前景→回到真实结果”的关系，不一定需要手机、椅子、四字或五条步骤。必须先取得实际操作和页面，不因教学假设就编一个命中结果。

在候选片里，导演先依据实见操作确定值得讲的过程；文案保留实际条件和结果；视觉作者看真实界面里的相对位置与主次，决定直接剪接够不够。若需要动画，才把选中项从原位置带近、让非重点退让、把结果接回后文。具体坐标和时间由新材料决定。

这是一条构思路径示例，未渲染，不要求下游照成某款产品演示。

## 每种方法都有不适用情形
| 方法 | 有效前提 | 不适用时怎样办 |
|---|---|---|
| 对象持续 | 有一个实际对象或解释载体需要跨句保持 | 多处独立事件可清楚切镜，不强造同源 |
| 四字/短语表演 | 存在值得汇聚的判断，字体和空间适合 | 普通描述不升格成巨型花字 |
| 同源多窗 | 原件内多个区域都对当前内容有作用 | 只保有用区域，不为了上下分窗重复人物 |
| 镜片/近景观察 | 具体细节需要看清，上下文有价值 | 已经可读或没有细节时不用放大镜 |
| 逐步关系展开 | 原文或材料支持顺序/关系 | 不足时改稿或直接观察，不补造因果 |
| 稳定字幕区 | 主视觉复杂且当前版式合适 | 人物全幅等场景可另定字幕布局 |

## 新主题的最小产物
由同一视觉作者写当前内容、材料、准确文字、字体与颜色角色、完整中途、真实语义时机和出口。使用 [motion-brief-writing](../../motion-brief-writing/SKILL.md)，不是复制这例所有像素。导演统筹后实现，关键状态使用当前真实素材和代码渲染，不另画理想化概念图。

## 要检验的是能力，不是文件是否存在
用给定完整分镜检验执行；用主题与固定材料检验自主设计；只给主题自主选材检验整条生产。三种测试分开。新输入、新稿、新代码与新视频一起保存，旧例的用户认可不抵扣新片的实际查看。

内部修订仍属于一次生产任务。看到源主体被裁掉时改源几何；只有静态图看不清时补实际范围；设计实现了仍平淡时回内容和美术判断，不能一律加特效或扩大提示字数。
