# 视频美术技能接入包

这次交付的是已经编写好的 **VideoFlowCut 视频美术适配技能**。

先打开 `02_完整阅读.html`。前半部分保留分析思路，后半部分说明接入，最后可以连续读到两份实际技能的完整正文。

准备接入时，在 VideoFlowCut 项目中让 Codex 读取本包的 `03_发给Codex.md`。Codex 需要核对当前本机文件、复制提供的技能、合入已经写好的接线、同步插件和验证。

## 提供了什么

- `payload/.agents/skills/visual-treatment-planning/SKILL.md`：完整美术入口。
- `payload/.agents/skills/visual-treatment-planning/references/art-direction.md`：完整专业方法。
- `01_分析与接入说明.md`：一个完整文档；阅读版与它同正文。
- `tests/check_package.py`：只读文件与链接检查，不自动安装。

## 没有做什么

没有修改用户仓库或正式项目，没有重新生成影片。本包接入后的实际效果仍需验证。包内没有运行时或素材副本；它接入既有 VideoFlowCut，不独立渲染。

## 怎么放

把本包解压到项目外或项目的文档工作区，不直接把整个包拖到全局 Skills 目录。接入目标只取 `payload/` 内对应文件；不要覆盖整个 `.agents/skills/`。其他源码、参考、字体和案例目录都保留。
