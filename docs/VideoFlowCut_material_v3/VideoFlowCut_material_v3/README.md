# VideoFlowCut 素材驱动动效增量方案 v3

先阅读 **plan.html** 或 **plan.md**：前半部保留完整原因分析和实际参考对照，后半部是具体改法。确认后把本目录交给开发Codex读取 **CODEX_IMPLEMENT.md**。

- patches/：26项准确原文和替换正文，manifest.json是唯一应用清单。
- repo-overlay/：18个按仓库路径组织的新方法、案例材料分支及开发数学示例。
- apply_changes.py：默认只读预演，--apply才写本机仓库；不提交Git、不部署、不操作视频项目。
- verify_changes.py：只读检查本次新增连接及状态。
- review_assets/、clips/、evidence/：前次分析的真实图片、静音截段与源码定位，不是新生成动画。
- validation/：实际完成的包级与数学检查；全库历史媒体缺失导致既有检查前后都失败，见主文档说明。

本包是已接入V2.1之上的局部深化，不需要重新安装V2，也没有历史方案目录。原有案例与其他生产规则保留。新材料分支未生成新片，状态不会借旧片升级。

正常生产仍由用户只给主题，团队自行完成研究、素材、稿件、分镜、声音与成片；样片时长/帧数/静音/风格不作为默认。
