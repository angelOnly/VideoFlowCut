# VideoFlowCut 创意卡拆解指令（通用版）

## 任务目标

从参考视频中拆出真正值得学习的创意，而不是写视频摘要、镜头清单或动效名称。

一张创意卡应让没有看过原片的创作者理解三件事：

1. **原片怎样设计：**画面用了什么素材，主体、构图、空间、镜头、动作和节奏怎样组织。
2. **为什么这样设计：**这些选择如何共同形成观看价值，哪些关系是创意成立的关键。
3. **怎样迁移到新内容：**哪些设计方法值得借鉴，新内容需要具备什么条件，换成新的素材后应该怎样重新设计。

用户或任务可能只提供独白文案。拆解参考视频时，不要假设新作品必须沿用原片题材、画面或动作；目标是提炼可迁移的设计方法。

---

## 一、确定完整的创意单元

一张卡对应一个完整的视觉表达单元。它可以包含多个镜头、多个素材和连续的画面变化，不等于一个镜头、一个动作或一句旁白。

先理解完整视频，再确定当前单元的起点和终点：

- **合并为一张卡：**前后画面共同完成同一项视觉表达；后续仍在发展前面建立的安排；拆开会失去必要的铺垫、比较、变化过程或结果。
- **拆成不同卡：**前一项表达已经完成，后一项开始了新的、能够独立理解和迁移的视觉安排。
- 不按切镜次数、字幕句数、素材数量或固定时长划分。
- 不为迁就已有动效机制切片而改变创意边界。

拆解前应了解必要的前后上下文，并连续观看完整创意范围。抽帧和分镜可以帮助辨认构图、对象和关键状态，但不能单独证明动作连续性、运动节奏或声音设计。没有实际观察到的内容要注明未知，不能猜测。

---

## 二、怎样从完整画面中拆出创意

这是整张创意卡最重要的部分。分析时不要停留在“画面出现了什么”，而要不断追问：

**为什么这样安排？这些安排怎样互相配合？观众因此看到了什么、理解了什么或感受到了什么？**

### 1. 先还原原片：画面实际怎样发展

按原片真实顺序描述，不要先总结创意，也不要用旁白摘要代替画面描述。

重点还原：

- **入口：**最初出现什么？观众第一眼看到什么？主体和材料怎样建立？
- **发展：**哪些素材、人物、文字或图形进入？画面发生了哪些变化？
- **关键变化：**什么对象取得主导？什么对象退出、缩小、让位、保留或接管？对象之间的关系发生了什么变化？
- **镜头变化：**观察范围、视点、景别或空间怎样变化？变化后观众看到了什么新内容？
- **结果与交接：**最终形成什么画面状态？这一段如何完成，或如何把注意力交给下一段？

描述必须具体到对象、状态和关系。例如“目标对象在原位置扩大，周围对象缩小并重新排布”比“突出主体”更有用。

只记录原片可观察到的事实。没有证据时，不猜作者意图、具体技术实现、素材来源或软件真实性。

### 2. 还原整段视觉设计：这些选择怎样共同工作

优秀画面通常不是几个独立效果的堆叠，而是一系列互相配合的设计选择。拆解时必须把它们重新连起来，说明整段画面怎样组织观众的观看过程。

#### 2.1 视觉主线与注意力变化

先弄清这段画面从什么状态开始，经过哪些重要变化，最后走到什么状态。

具体分析：
- 观众最初被引导看哪里，为什么？
- 主要对象如何建立，何时成为画面主角？
- 新对象出现时，旧对象如何处理：退出、缩小、让位、保留还是转为背景？
- 观众的观察范围如何变化：从多对象收敛到单对象、从局部展开到整体、从外部观察到进入细节，或其他形式？
- 每次注意力转移由什么具体变化引导？
- 画面最终把观众的注意力留在哪里？

不要只写“突出重点”“聚焦主体”，要说明具体对象怎样变化、谁为谁让位、观众为什么会跟着看。

#### 2.2 真实素材如何参与创意

逐一辨认重要素材，并分析它在画面中的实际作用：

- 它是主体、证据、对照、空间、承载物、环境，还是动作来源？
- 它是被阅读、观察、比较、操作、拆分、穿越、覆盖、映射还是接管？
- 它在画面开始、中途和结束时分别承担什么作用？
- 它自身的形状、结构、颜色、明暗、纹理、内容或运动，是否决定了构图和表现方式？
- 它是否与其他素材发生关系？这种关系如何变化？
- 如果换成普通图标、色块或无关素材，画面会失去什么？

不要只写“用了图片、视频、文档或界面”。要解释为什么这份材料适合，以及它的真实特征如何成为创意的一部分。

素材不是创意确定之后才放进去的配图。很多时候，创意正是从素材的形态、结构、内容、动作或可变化属性中产生的。拆解要识别这种相互决定的关系：内容决定需要什么材料，材料的特征又反过来启发画面如何设计。

#### 2.3 构图与空间如何服务表达

不要只给画面贴“居中构图”“层次丰富”“空间感强”等标签。要分析构图如何随整段发展：

- 主体、背景和辅助元素怎样建立主次？
- 主体的面积、位置、比例和视觉重心怎样变化？
- 留白、遮挡、重叠、前后层和空间深度分别承担什么作用？
- 新对象进入时，原有构图如何调整？哪些对象让位，哪些继续保留？
- 镜头或对象变化后，局部、整体、主体和背景之间的关系发生什么变化？
- 画面最终形成怎样的构图状态？

重点不是描述某一帧“长什么样”，而是解释构图如何参与画面发展。

#### 2.4 文字与图形如何参与创意

区分原始素材中的文字、普通字幕和后期添加的画内文字。分析文字或图形究竟承担什么作用：

- 是补充说明、事实证据、视觉主体、空间结构、标记、比较依据，还是动作参与者？
- 为什么在这个时刻出现？
- 它与真实素材之间是什么关系？
- 它是否改变了主体的面积、位置或视觉层级？
- 它是否被承载、遮挡、拆分、变形或接管？
- 它是否只是重复旁白，或者只是装饰？

不要因为画面有花字或图形，就直接认定它有创意。要说明它对整段表达起了什么作用。

#### 2.5 镜头与动作如何协作

镜头和动作不应被拆成孤立的技术名称。要说明它们怎样改变观众的观察和画面关系。

**镜头方面：**
- 为什么推进、拉远、横移、跟随、穿越或改变视点？
- 运动后观众看到了什么此前看不到的内容或关系？
- 镜头运动与物件运动是否同时发生？各自承担什么作用？
- 镜头变化是否改变了观众对主体、材料或空间的理解，还是仅作为装饰？

**动作方面：**
- 谁发起动作，动作作用于什么对象？
- 其他对象如何响应、跟随、让位或接管？
- 哪些动作同时发生，哪些必须先后发生？
- 前一个动作留下什么状态，后一个动作如何沿用？
- 动作只是让元素进出画面，还是实质改变了材料、对象或空间之间的关系？
- 动作完成后，哪些对象继续保留，成为下一阶段的基础？

只写“缩放、平移、遮罩、弹性、推镜头”是不够的。需要解释动作的对象、关系、目的和结果。

#### 2.6 节奏如何组织观看

分析整段的快慢、强弱、动作密度和停留：

- 哪些阶段快速推进，哪些需要稳定观看或阅读？
- 哪些动作交叠，哪些需要等待或让位？
- 画面何时形成重音，何时收稳？
- 动作完成后是否还有无意义的空等？
- 停留是否让观众有时间观察、比较、理解或感受？
- 声音是否参与动作提示或节奏组织？只有实际听审后才能判断。

不要求每秒都有动作，也不要求平均切镜。停留可以是设计的一部分，关键在于它是否服务于观看。

#### 2.7 总结整段设计逻辑

完成上面的观察后，必须把它们重新组织成一段完整解释：

**这段作品通过哪些关键设计选择，让观众从初始画面走到最终结果？**

说明视觉主线、注意力变化、真实素材的作用、构图与空间变化、镜头和动作的配合，以及各阶段之间的先后、依赖、响应或接力关系。

这一步是整段创意拆解的核心。前面的主体、素材、构图、镜头和动作分析只是依据；必须解释它们如何组合成一个完整的视觉表达，不能只把各项分析并排列出。

### 3. 找出主创意：不要把所有效果都叫创意

将原片中的设计大致区分为：

- **主创意：**决定这段为什么值得看、最有辨识度的设计。
- **支撑设计：**帮助主创意成立的素材安排、构图、镜头、动作和节奏。
- **表面形式：**颜色、字体、装饰、道具、界面皮肤等，通常可以替换。
- **技术实现：**遮罩、变换、曲线、合成等实现手段，本身不等于创意。

判断主创意时，回答：

1. 原片做了什么关键选择？
2. 这个选择让观众看见、理解或感受到什么？
3. 它为什么比直接展示、普通切换或单纯文字说明更有观看价值？
4. 哪些素材特征、对象关系、信息顺序或动作依赖使它成立？
5. 如果删掉关键对象或步骤，创意会失去什么？
6. 哪些外观可以替换，而不影响核心价值？

不要用“高级、丝滑、有冲击力、有创意”等评价词代替解释。分析的是作品呈现出来的设计效果，不是猜测作者真实想法，也不是声称观众已经被测试证明。

### 4. 提炼可迁移的方法

迁移不是照搬原片，也不是把它抽象成“空间感”“反差”“视觉揭示”等口号。需要提取原作中换了题材和素材后仍可能成立的设计知识。

每张卡根据原片实际价值，提取以下三个层级；没有独立价值的层级可以不写，不要为了填满而硬造。

| 层级 | 要提炼的内容 | 需要说清楚 |
|---|---|---|
| **创意设计方法** | 原作怎样把内容转化成值得观看的表达 | 适用什么观看任务、关键创意选择是什么、什么条件下成立 |
| **视觉编排方法** | 主体、素材、构图、空间、镜头和时间怎样组织 | 对象关系、注意力变化、先后顺序、关键接续和结果 |
| **具体表现方法** | 可借鉴的动作、运镜和视觉机制 | 动作主语、作用对象、前置状态、运动关系、结束状态和适用条件 |

迁移时按以下思路推导：

1. **找出原作成立条件：**它依赖什么内容、真实素材、主体身份、空间关系、动作或前后状态？
2. **映射新内容：**新作品中哪份真实素材能承担原来的作用？它具体怎样参与画面？
3. **决定迁移方式：**
   - **直接迁移：**新内容的材料和关键关系匹配，保留主要设计关系，替换题材与外观。
   - **结构迁移：**原作关系有价值，但原主体或材料不适合，保留关系，重新设计对象和表现。
   - **组合迁移：**一个主参考提供创意骨架，其他参考只补充具体表现缺口，不能机械拼接案例。
   - **不迁移：**条件不匹配或无法改善表达，放弃参考，重新原创。
4. **说明迁移边界：**哪些关系必须保留，哪些形式可以替换，缺少什么条件时应调整或放弃。

判断迁移是否空心，可以问：如果把新作品的真实素材换成任意图标或色块，方案是否仍完全一样？如果是，素材没有真正进入创意；如果删掉参考名称后只剩普通动画，说明只是引用了参考，没有迁移设计方法。

### 5. 写出可供新作品使用的创意指令

创意指令不是原片摘要，也不是“参考某案例”的提醒，而是将提炼出的设计方法转成新任务可以使用的创作依据。

指令应说清：
- 适用的内容和观看任务；
- 值得借鉴的创意设计方法；
- 新作品需要什么类型的真实素材，以及素材承担什么作用；
- 必须保留的对象关系、信息顺序或变化条件；
- 画面应如何发展，关键阶段怎样接续；
- 可借鉴的构图、镜头和动作方法；
- 可以自由替换的外观，以及不适用时的调整方式。

指令要具体到“选择什么对象、让它承担什么作用、画面关系怎样变化、为什么这样安排”，但不需要锁死新作品的题材、具体物件、颜色、固定秒数、像素坐标或技术参数。

## 三、创意卡输出格式

正文只保留三部分：原片还原、创意价值分析、可迁移指令。不要把分析写成冗长问卷，也不要为了填满字段强行编造原片没有的设计。

```markdown
---
id: "<案例编号>-c01"
case_number: <案例编号>
title: "<具体创意名称>"
summary: "<完整表达方式概括>"
use_when: "<适用内容与素材条件>"
video: "<完整原视频相对路径>"
start_ms: <源片起点>
end_ms: <源片终点>
clip: "<完整创意片段路径>"
storyboard: "<真实分镜路径>"
frame_times_ms: [<源片时间点>]
---

# <创意卡名称>

来源：<案例名称、作者/来源、链接>
范围：<完整原片起止时间>
观察方式：<连续观看、抽帧、慢放、听审等真实状态>
观察限制：<未确认的声音、技术、素材来源等>

![创意分镜](<真实路径>)

## 1. 原画面具体怎样设计
<按真实顺序还原入口、发展、关键变化、素材关系、构图、镜头动作和结果，并说明整段视觉组织。>

## 2. 为什么这样设计，好在哪里
<说明主创意、支撑设计、整段组合逻辑、观看价值和成立条件。>

## 3. 可直接使用的创意指令
<提炼创意设计方法、视觉编排方法、具体表现方法、适用条件和迁移边界。>
```

## 四、必要的媒体约定

- `video` 指完整原视频；`start_ms/end_ms` 是本卡在原片中的范围，起点包含、终点不包含。
- `clip` 指本卡完整范围的可观看视频。已有切片只有在源范围完全一致且内容、画幅、原速和声音可用时才复用；否则从完整原片截取，不拼接多个旧机制切片。
- 默认使用3×3真实源帧分镜，覆盖入口、重要变化、关键中途和结果；复杂动作可补充分镜，不为九宫格删减必要过程。
- `frame_times_ms` 使用完整原片时间。切片内时间 = 原片时间 - `start_ms`。
- 沿用项目现有目录、卡片编号和 `creative-index.json`，不新建数据库。修改正文后按现有脚本更新索引；不得覆盖原片、旧机制或旧分镜。
