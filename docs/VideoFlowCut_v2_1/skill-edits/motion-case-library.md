## 主题片按观看任务选例

完整片从主题、材料和正文开始，由导演决定场面，再由同一视觉作者读相关案例。历史案例与 [r92混合场面案例组](references/r92-family-index.md) 并存；入口不是题材关键词，也不是固定播放顺序。

只想理解整片组织时读完整案例；正在设计某次选择、揭示、局部观察、关系展开或物体与大字接管时读对应局部案例。先读该例SKILL.md及其generation-prompt-v1.md，再按记录核对原片和源码的实际范围；各例都有独立验证说明。

r92视频是历史观察记录，新教学指令是从中归纳的可迁移写法，未由该教学指令重新生成的效果不能登记已验证。保留已知标签和局部节奏问题，学的是能成立的对象关系，不复制问题、秒数、配色、静音或固定结尾。

迁移后交回当前场面完整执行稿：本片主体、真实材料、造型、文字、变化路径、声音与有效时间均重新决定。无需为了用库而凑多窗、公式、SIM或无缝变形；没有适用例时自主创作。案例作为设计参考，不建立新的硬编码效果Registry或替代导演的模板状态机。
