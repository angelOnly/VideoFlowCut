## 内容完成后交棒，而不按预留槽位等待

主题驱动原创采用 [按观看任务完成度编排时间](references/pacing-by-completion.md)。导演、文案、配音和视觉共同形成节奏；当前估计、首轮TTS结果或样例秒数不成为全片固定长度。

每次主要关注写清：开始可辨认、当前任务何时完成、下一重点最早何时能进入、实际何时接管。阅读从达到有效尺寸和无遮挡时开始，可以与收势交叠。保持理由可以是阅读、比较、真实过程、反应或情绪；背景微动不自动提供保持理由。

主体任务已经结束时，先合并重复建立、缩短无用等待或过慢推进，再重排交叠和场界。语言重复或妨碍真实过程时，交原文案作者改写并由配音/字幕同步，不把一侧的首次输出当永久边界。

素材从长实拍换为照片/原创模型时重新核对这四个时间。任何改动明确传播到作品、源范围、字幕、声音事件、相邻接口和旧审阅。时间判断用秒描述，按本次fps落到帧；实际连续观感仍通过本版预览验证。
