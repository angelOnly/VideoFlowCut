## 主题驱动整片的默认生产正文

只有主题时，导演先自主给出讲述角度、目标观看经历、内容规模、发布画幅和声音方向，随后组织团队完成完整视频。使用 [主题到成片方法](../_shared/TOPIC_TO_FILM.md)；这些是导演的工作产物，不是向用户索取的前置参数。

先写三句连续方向：入口让观众看什么；过程中哪些发现或体验值得跟随；结尾兑现什么。同步交素材负责人核实关键主张、探索实际过程；由 narration-writing 返回完整解说与句群声画稿。材料不足时改变可得载体、讲述角度或准确表述，不提前固定一个图标贯穿全片。

用完整稿和实际材料形成 [场面执行正文](../_shared/SCENE_DESIGN_HANDOFF.md)。每场明确入口、第一重点、主要可见变化、准确文字、实际材料、声音分工、出口及大约秒数。素材类型不是场面结构，字幕句号不是强制切镜，单件作品预算不是整片长度。

在相邻场面上比较主体轮廓、尺度、明暗、观察方式和阅读负担。连续采用“素材摆好＋标题出现＋等待”而没有内容理由时，在深化前重写具体观看过程。运动可以服务理解，也可以服务表演、气势、细节与审美；不用每个动作必须新增知识的单一标准。

从 motion-case-library 先读索引，按当前观看任务选择真正相关的一例或少量互补例。完整案例用于组织方法，局部案例用于某个变化关系；角色、配色、时长和历史剧情重新为本片决定。没有合适案例时自主设计，不能把整片变成案例串烧。

取得视觉作者完整深化稿后，按全文统筹主体、美术、文字、声音与接点，返回统一采用稿；不能只回复“方案通过”。当配音、素材替代或实际运动改变节奏时，主动组织原作者调整句群、表演或画面，时间服务当前内容，不留无意义等待。

交回可写入现有对象的参数和真实版本。首次向用户交付前，同一任务内完成必要渲染检查和可修问题处理，不要求用户逐镜审批或提供专业动画指令。
