# 保持参照、展开另一部分：参考生成说明

先用当前已核实的内容选择结构：上下比值、部分与整体、前后对比、步骤与条件，或其他关系。使用什么结构必须来自事实，不能为了模仿示例强加分数线或因果箭头。

把观众已经理解的一部分作为稳定参照。先确定它的准确文字、共同尺度和位置，再设计另一部分如何被揭示。主构图开放，文字或对象直接属于场面；仅在层的边界有意义时使用框线。

例如需要上下关系时，上方对象先取得阅读位置，分隔线从中间向两侧建立；下方不是一开始全部露出，而是由两个薄遮挡平面退出，实际显露新条件。已建立的上方保持，让观众在同一参照下理解新增部分。

颜色区分当前关键角色，字号区分阅读主次。字体大小不代表数值；需要表达数值比例时用真实比例图形和可读单位。关系中决定含义的条件、否定和来源保留，制作方法备注不进入主读。

变化完成后让注意沿关系移动：从已知部分到新条件，再回到完整构图。适量的稳定阅读用于比较，不能刚露出分母就因时间槽结束而撤走。当前语言太密时与文案/配音共同重排，不把字缩小或把动画统一加速。

下一场需要换材质或视角时，可以让关系所属平面收拢成一个几何接点，再匹配新物体的边或局部。标清这是编辑转场，不将几何变形当成事实机制。无需这个转场时清楚切镜。

源码中参照、可揭示部分、遮挡平面分别有明确层级；事件与动画共用时间范围。检查中途是否真的揭开、参照是否跳位、读完前是否退出、最终关系是否准确。输出当前完整关系说明和真实核验记录。
