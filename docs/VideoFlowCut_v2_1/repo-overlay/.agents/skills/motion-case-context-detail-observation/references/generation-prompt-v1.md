# 整体到局部观察：参考生成说明

先明确一个真正值得看的局部：读不清的刻度、产品部件、真实操作区域、结构连接或原文关键行。局部必须对当前讲述有作用；不因观察圈效果可用而随意找一个位置放大。

真实素材清晰且有局部细节时，先显示足够的整体让人定位；圈内与圈外取同一源时刻，通过裁切中心和倍率把目标送到可辨认尺度。圈的位置随真实对象适当跟随，外围降对比但保留整体参照。倍率以取得的新细节为准，而不是完成预设数字。

只有整体画面可用而需要概念解释时，清楚切入本次原创结构，由其完成局部观察。先设计壳体轮廓、侧边、关键连接与共同光源，再复制同一结构的局部投影到观察窗口。标明合理的示意身份，不将绘制细节说成实拍放大。

局部靠近时，整体、圈边、投影和标签共同构图。观察圈达到可看清的位置后留必要辨认，目标细节清楚就向下一步让路，不一直缓慢放大同一简单形状。标签贴近真实部位，完整字幕保持自己的阅读区域。

出口可让局部窗口向一侧退为参照，开放新的解释空间；也可沿目标边缘直接匹配切镜。持续到下一场的窗口保留同一对象和时钟，解释图与真实源信息区分。

素材不足时自主采用清楚照片、另一可用设备观察或已明确的原创结构。类型替代后同步需求和源范围，并重排观看时间；不能只贴一个小图标加标题来替代原本的局部发现。

交付中标明采用“真实同源”“资料图片”还是“原创结构”分支，保存裁切与投影关系、源时刻和实际检查范围。原记录支持哪个分支就只声明哪个分支。
