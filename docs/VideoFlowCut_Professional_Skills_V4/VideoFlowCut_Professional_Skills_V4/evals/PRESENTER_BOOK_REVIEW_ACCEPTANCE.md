# 《快乐的死》Presenter 验收

## 目标

验证专业 Skills 是否真正改变哲学读书口播，而不是把 11 种 Effect 全部展示一遍。

## 预期导演方向

- 人物与语言是主锚；
- 开头问题建立观看承诺；
- 个人感受和价值判断保留人物与停顿；
- “钱与自由”“以后不断后退”等机制可用 Remotion 解释；
- 城市、海、下班看天、读书和散步只在具体生活体验时使用 B-roll；
- 字幕稳定；
- 音乐温和且在坦白和结论处退让；
- 有安静区和少量高点。

## 不应出现

- 为覆盖 Registry 使用 ProductFan、CommentCloud、FullScreenMeme；
- “自由”直接配海边而没有语义任务；
- 每句一个卡片；
- 全程动态逐词字幕；
- 全程 BGM 和入场 SFX；
- 人物原声与 OmniVoice 双声。

## 必须保存的报告

- 已加载 Skill/Reference；
- SemanticUnit 与 Story 决策；
- Visual Treatment，包括不加效果的范围；
- Effect 与 Cutaway 选择/拒绝理由；
- Preview Evidence；
- 五轮 Editorial Review；
- 最终 Revision 与 Export Job。
