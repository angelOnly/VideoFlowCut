# 真实视频 A/B 验收

对同一素材生成三个版本：无专业 Skills、当前 V2、V4。保持模型、MCP、素材和目标不变，只改变 Skills。

## 评价维度

- 主线是否不同；
- 是否保留完整语义和自然停顿；
- Effect 数量、类型和密度是否与内容匹配；
- 是否有明确安静区；
- B-roll 是否具体而非关键词联想；
- Scene 是否持续和渐进，而非逐句卡片；
- 字幕是否可读且不争抢；
- 声音是否有层级；
- 用户能否复述核心；
- V4 是否记录拒绝方案和“不处理”决定。

## 四套素材

1. 哲学读书口播：预期克制、人物信任、少量解释 Scene。
2. 促销人物口播：预期数字、产品、CTA 和恢复段。
3. 视觉解释片：预期大 Scene 内渐进、证据与解释分工。
4. Vlog：预期事件、反应、自然声和克制包装。

## 通过标准

V4 不要求效果最多，而要求选择最能服务观众任务。至少三名观看者在不看计划时，对 V4 的理解清楚度、自然性或观看意愿给出可观察提升；没有提升时回到具体 Skill 和案例，而不是继续增加文本长度。
