# V4 设计说明：单文件专业 Skill

## 设计原则

每一个 `SKILL.md` 必须在不读取同目录其它文件的情况下，完整回答：任务本质是什么、要看哪些证据、有哪些相似但不同的情形、怎样比较候选方案、怎样执行、错误选择会造成什么观看感受，以及如何用真实画面和声音验证。

列表只用于确定性步骤和最后防漏。导演、美学、语义、节奏、字幕、声音和动效知识以连续解释和完整案例为主体。

## 允许独立存在的共享文件

只有真正跨 Skill、且会独立变化的内容保留在 `_shared`：当前代码能力、共同导演方法、证据边界、Project/Revision 合同、质量交付门禁和来源说明。

## 不再拆分的内容

角色、目光、手势、Mask、口型等都属于 `avatar-performance` 的完整任务；人物信任、AttentionCurve、层级、Cutaway 和审片都属于 `presenter-motion-director`；它们不再拆成几行一个文件。

## 内容验收

不再按文件数量或关键词计数。给 Skill 一个新场景，它必须能解释：为什么选择、为什么拒绝另一方案、预期观众反应、当前能力边界和真实验证。
