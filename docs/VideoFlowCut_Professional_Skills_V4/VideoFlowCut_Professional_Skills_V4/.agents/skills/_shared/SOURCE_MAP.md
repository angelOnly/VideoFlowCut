# V3 知识来源与边界

V3 同时使用四类来源，但它们承担不同责任。

ChatCut 的官方 Skills 和调研文档用于学习专业工作流怎样被写清楚：先判断任务类型，再处理主线，然后处理包装，最后用真实项目、真实合成和最终文件验证。特别重要的是口播 Skill 对 Cleanup、Highlight、Restructure、Hook 和 Target Script 的区分，以及 Motion Graphics Skill 对 Design Map、Settled Frame、代表性样例和批量一致性的要求。

旧 DavinciVideoMcp 中的导演、视觉、声音、文字和素材理解 Skills 提供更完整的导演知识：观众承诺、事实时间线、观看时间线、故事脊椎、信息账本、节拍链、视点、内在节奏、听觉视点、注意力竞争和反事实比较。V3 只吸收这些专业方法，不保留 DaVinci、Resolve、旧 EditPlan 和旧服务合同。

VideoFlowCut 当前代码决定哪些对象、字段和 MCP 可以真正执行。Skill 不得为了知识完整而覆盖实际能力边界。

参考视频用于提炼 Presenter Effect Grammar、AttentionCurve、人物前后景、Cutaway、Scene Grammar 和渐进式变化。参考视频不是组件清单，也不是可以直接复用的成片素材。

书籍和影视研究只能被编译成可观察证据、判断理由、候选方案、观众影响、失败模式和验证。概念名称本身不算知识落地。
