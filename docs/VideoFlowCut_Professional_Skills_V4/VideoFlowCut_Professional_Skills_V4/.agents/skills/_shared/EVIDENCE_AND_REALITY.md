# 证据、来源、推断与未知

专业剪辑首先要知道自己实际看见和听见了什么。文件名、自动摘要、关键词匹配和单张截图只能提供候选，不足以支撑高影响决定。证据应尽可能回到 Asset、源时间范围、原话、动作、环境声、页面或数据。

任何陈述都应属于四类之一：素材直接可观察事实、用户明确说明、基于多项证据的专业解释，或尚未确认的未知。只有前两类可以作为事实写入成片；专业解释要保留推断性质；未知不能因为剪辑需要一个漂亮结论而被补造。

外部素材的“可访问”不等于“可用于交付”。项目应保存来源、作者、许可和署名。生成视频可以表达情绪、环境或抽象说明，但不能冒充历史档案、法规、新闻、投诉、真实产品页面或人物当时的行为。

证据不足时，Skill 应说明最小缺口：需要看哪个范围、听哪一句、确认哪个来源，以及新证据会改变哪项决定。不要为了显得严谨而重复分析整条原片。
