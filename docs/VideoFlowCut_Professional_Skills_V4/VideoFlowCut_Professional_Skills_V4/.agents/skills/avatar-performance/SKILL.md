# 数字人物表演与生成边界

> **V4 单文件原则**：本 Skill 已内置完成该任务所需的核心专业知识、案例、失败模式和验证方法。除项目级 `_shared` 合同与 `docs/asr接入.md` 等真正共享资料外，不依赖同目录 `references/`。


## 数字人物不是一段带嘴型的视频

一个可用的 ActorPerformance 同时包含声音、口型、目光、表情、身体、构图和与画面对象的关系。技术上可以播放的人物视频，如果每个段落都重新回到中性微笑、眼神没有目标、手势和台词无关，仍然会破坏信任。

当前 VideoFlowCut 能登记已有或预生成的人物视频、Mask、SpeechAsset 和 audioMode，但尚未完整接入外部 Avatar Provider、姿态锚点和局部生成控制。因此本 Skill 的主要模式是 plan 和 review。只有实时 MCP 真正提供 Provider 调用时，才进入 execute。

## 先决定人物与观众的关系

专家、朋友、教师、主持人、体验者和品牌代表的表演不同。专家需要清晰和克制；朋友式叙述需要自然停顿和亲密距离；主持人可以更明确地指向画面；体验者的反应本身是证据。角色决定直视镜头比例、手势频率、语速和笑容强度。

如果角色不清楚，Avatar 很容易落入默认“微笑播报”，所有内容听起来都像广告。

## 声音先于人物生成稳定

人物生成应绑定最终 SpeechAsset 和 Script Revision。当前项目有 `use_source_audio`、`use_dialogue_track` 和 `muted` 三种声音所有权。使用 OmniVoice 替换人物原声时，Actor 视频必须静音；人物视频已经包含最终旁白时，不再叠加 Dialogue。

声音仍会变化时，不批量生成人物段落。否则任何文本修订都会使口型、表情和手势失效。

## 表演规划怎样写

重要段落需要写清语义任务和表演关系，而不是只给“自然一点”。例如：

> 这段是个人坦白，人物先直视镜头，提到“我以前也这么想”时轻微低头，结论前保留停顿；手势不需要指向对象，因为下一拍才进入全屏解释。

促销段则可能是：

> 这段用于展示数量，人物在“送出”前打开双手，产品在手势完成后进入，目光短暂看向产品，再回到镜头完成 CTA。

当前 Provider 无法控制这些细节时，应记录降级，例如固定构图 + 右侧安全区，而不是假装人物和图形正在互动。

## 目光、表情和手势

目光决定观众跟谁建立关系。直视适合承诺、结论、坦白和 CTA；侧看可以引导旁侧对象，但要和对象出现时机一致；长期固定会僵硬，频繁漂移又会失去信任。

手势应有准备、主相位和结果。一个指向下方的 CTA 手势如果在箭头出现后才开始，就像人物追赶动画；产品从手中出现时，手势和对象应共享空间逻辑。没有姿态证据时，使用普通安全区比制造假互动更专业。

## 情绪连续与 Uncanny Valley

数字人物最常见的问题不是单帧不真实，而是段落之间情绪重置。前一句刚在坦白，下一句突然恢复标准微笑；上一段人物前倾，下一段突然坐直；嘴型和声音结束时间不一致。这些跳变会被观众感知为“不是同一个连续的人”。

修复顺序应从上游开始：Script 和 Speech 是否自然，表演要求是否合理，是否需要局部重生，Scene 是否可以在跳变处使用有意义的 Cutaway，最后才考虑 Mask 和后期。不能用大量 B-roll 长期掩盖生成不连续。

## Mask 和前后景

Mask 需要检查头发、手指、快速动作、半透明边缘、帧率和时间同步。边缘不稳定时，Rear FX 会持续闪烁。降级顺序是增大图形距离、改到左右安全区、减少穿插、改普通 Overlay、切全屏，最后是不使用。

## 审查

先单独看人物视频，检查口型、目光、手势、段间连续和角色；再放回合成画面，检查前后景、字幕和 Cutaway。一个漂亮的合成不能修复人物表演错误，一个自然的人物也可能被错误图形毁掉。

## 表演规划与角色关系

同一句“你可以试试看”，教师式人物会保持清晰和低手势，朋友式人物可能轻微前倾，促销主持人则会配合明确 CTA。角色关系先于动作清单。

目光也不是装饰。人物直视镜头时，观众感觉自己被直接对话；人物看向侧面时，观众会预期那里出现对象。若对象没出现或方向不一致，画面会显得排练失误。规划时把目光、对象和语义事件写在一起。

---

## 口型、连续性与 Uncanny Valley

口型错误不仅是嘴与音节不同步，还包括句尾嘴型继续运动、爆破音没有对应闭唇、相邻段嘴型和呼吸突然重置。连续播放比抽单帧更能暴露这些问题。

Uncanny Valley 常来自多种轻微不一致叠加：眼神固定、嘴型略慢、表情一直微笑、手势重复、段间姿态跳。不要只在最后加滤镜；先修声音和表演，再考虑 Cutaway 和合成。

---

## Mask、空间互动与降级

产品从人物手里出现，需要手势、Mask 和对象路径都可靠。当前只有静态空间锚点时，最好把产品放在人物旁边的安全区，避免伪造手部互动。

Mask 不稳定时，后景文字穿过头发和手指会持续闪烁。专业降级不是隐藏警告，而是改变视觉方案。普通 Overlay 虽然少一层空间感，却比失败的前后景更可信。

## 当前工具

使用 `read_actor_performances` 和 `manage_actor_performance` 登记现有人物、Mask、SpeechAsset 和 audioMode。当前没有 `submit_avatar_job`，不能调用或报告已自动生成 Avatar。

## 最终检查

- 角色关系明确。
- SpeechAsset 和 Script Revision 稳定。
- audioMode 正确。
- 目光、表情和手势有内容动机。
- 相邻段情绪与姿态连续。
- Mask 状态真实，降级明确。
- 未实现能力没有被描述成已执行。
- 人物单独和合成都经过审查。
