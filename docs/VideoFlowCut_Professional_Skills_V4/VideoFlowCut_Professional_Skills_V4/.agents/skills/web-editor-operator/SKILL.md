# Web 工作台操作与真实画面验证

> **V4 单文件原则**：本 Skill 已内置完成该任务所需的核心专业知识、案例、失败模式和验证方法。除项目级 `_shared` 合同与 `docs/asr接入.md` 等真正共享资料外，不依赖同目录 `references/`。


## Web 的价值不是“另一种调用 MCP 的方法”

MCP 擅长结构化读写，Web 的独特价值在于让 Agent看见最终组合：人物、字幕、Effect、B-roll、层级和声音在同一时间如何竞争。很多错误在数据上完全合法，例如产品 Effect 位于正确 Scene 内、时间范围也正确，但稳定帧挡住了人物的眼睛；这种问题只有真实合成能发现。

进入 Web 前先通过 `get_editor_url` 或 `focus_editor_object` 获得稳定地址。对象定位至少使用两个证据确认，例如 URL 中的 effectCueId 与 Inspector ID 一致，Timeline 和 Scene 卡也同步高亮。不要根据屏幕位置说“左边那个面板”，因为布局可能变化；使用对象名称和可访问标签。

## 四阶段观察

任何动画都不只看稳定帧。进入前要看到原画面和人物动作；运动中要检查路径和竞争；稳定状态要检查信息是否能读懂；退出时要看是否给下一事件让路。随后播放进入前一句到退出后一句，因为局部效果可能正确，放回语义后却抢早、拖晚或破坏人物反应。

对重要决定比较三种状态：当前方案、最小修改和禁用效果。A/B 比较的目标不是找更“炫”的版本，而是判断哪个版本更快被理解、更保护人物、更符合风格、注意力成本更低。

## 怎样做微调

调整优先级从内容和主体开始。先确认文字、素材和叙事目的正确，再保护脸、嘴、手、证据和字幕，然后调整布局、阅读时间和运动，最后才处理阴影、Glow 和材质。装饰无法修复错误内容和错误构图。

只有当前数据模型能持久化的属性才可以通过 Web 修改。若界面只是临时 CSS 或 Canvas 状态，不能报告项目已更新。提交后读回新 Revision 和 Inspector 值，渲染新的 Preview。

## 声音与连续播放

Web 审查不应只看静态图。对字幕、Cutaway、CameraPunch 和音效，播放完整范围；对声音问题切换为只听模式；对视觉层级静音播放。若当前 Web 不支持某种检查，可以通过 `render_preview_range` 和下载预览完成，但必须记录实际检查的范围。

## 四阶段与连续播放审查

动画进入前的画面决定它是否有必要。如果人物已经通过眼神和字幕把结论说清，动画的预进入可能只是额外干扰。运动中间最容易出现遮挡和路径冲突；稳定状态决定观众最终记住什么；退出决定下一拍是否顺畅。

审查一个 EvidenceCard 时，进入前确认人物正在引用证据；运动中检查卡片是否穿过脸；稳定时确认来源、重点和限定条件可读；退出时确认观众回到人物后不会失去上下文。随后播放完整语句，检查证据是否在引用之前出现，或在人物已经进入下一个观点后仍停留。

---

## 空间微调与 A/B 比较

空间微调首先保护信息，再追求平衡。若右侧产品挡脸，可以比较：保持当前但缩小、移到人物另一侧、改成全屏 Cutaway，以及完全不使用产品。选择标准包括人物是否仍是主视觉、产品是否可识别、字幕是否安全、进入路径是否自然。

A/B 不是只看两张截图。两个版本都应在同一上下文中播放。一个版本的稳定帧可能更漂亮，但进入过程过慢；另一个版本运动更短，却更符合一句话的节奏。必要时把“无效果”作为第三个候选，因为它经常揭示效果是否真的增加理解。

---

## 完整推演：用户说“这个数字挡脸了”时怎样操作

不要直接拖动对象。先确认用户看到的是哪个 Sequence、Revision 和 Preview，再定位对应 EffectCue。播放数字进入前、运动中、稳定和退出四个阶段，确认问题到底是固定位置挡脸、运动路径穿过眼睛，还是人物在该帧临时前倾。若只是稳定位置不合适，可以在 Inspector 调整当前数据模型支持的 spatialAnchor 或布局参数；若问题来自人物姿态变化，而系统没有姿态级锚点，则不能通过某一帧的临时位置假装整段都安全，应改用更保守的右侧安全区、降低尺寸或切换全屏处理。

写入后必须读回新 Revision，并连续播放完整语句。只看一张修改后的截图不足以证明问题解决，因为数字可能在进入或退出路径中仍然经过人物脸部。

## 最终检查

- 对象和 Revision 定位一致。
- 观察了进入、运动、稳定和退出。
- 播放了前后语句，不只看截图。
- 重要修改比较了 A/B/禁用。
- 修改持久化为新 Revision。
- 没有使用 DOM 临时样式绕过项目状态。
- Preview Evidence 已记录。
