# 语义连续性与 A-roll 内容编辑

> **V4 单文件原则**：本 Skill 已内置完成该任务所需的核心专业知识、案例、失败模式和验证方法。除项目级 `_shared` 合同与 `docs/asr接入.md` 等真正共享资料外，不依赖同目录 `references/`。


## 先判断任务，不要把所有请求都当 Cleanup

语音编辑至少有五种不同任务。Cleanup 的目标是移除错误、口癖、重复尝试和无意义停顿，同时保持原有意思和说话者个性。Highlight 是从长素材中选择最有价值的完整时刻。Restructure 允许重排完整思想，让论证或故事更清楚。Hook/Short Version 需要从真实素材中提取一个能够被后文兑现的开场。Target Script 则是按用户明确指定的文稿或范围进行匹配。

这些任务的边界不同。开放式 Cleanup 中，边界不确定时应保守保留完整思想；Target Script 中，用户明确只要某句话时，应该精确裁到目标范围，不能为了“完整”顺便保留同一个候选中的其它内容。若不先确定任务，同一条规则会同时导致过度保留和过度删除。

## 标点句不是完整思想

FunASR 的 `TranscriptSentenceCandidate` 只是候选。语言的真正结构可能跨标点：前提和结论、问题和回答、转折的两端、列表和总结、设置和包袱。相反，一个很长的 ASR 句子也可能包含错误重启和完整重录。

例如：“我以前一直觉得，只要赚够钱就能自由。后来我发现，不对，真正缺的是时间。”这里“后来我发现”不是独立结论，“不对”标记一次自我修正，“真正缺的是时间”依赖前面的旧信念。将每个标点候选独立处理，会破坏对比；全部保留为一个单元，又会把错误重启也当成最终表达。专业判断应建立两个 SemanticUnit：旧信念及其上下文，以及修正后的结论，并明确 contrast/dependency。

## 什么叫完整思想

完整思想不是语法上有句号，而是观众能知道谁在说什么、为什么、与前后有什么关系。删除后要检查：主语是否丢失，代词是否仍有指向，因果是否只剩结果，转折是否只剩“但是”，列表是否缺少类别，问题是否只剩回答，例子是否失去它证明的观点。

一句话可以很短却完整，例如“我拒绝了”。也可以很长却仍是一个思想，例如一个完整的“虽然—但是”结构。判断单位来自意义，不来自字数。

## 重录并不是“最后一遍最好”

说话者常会多次尝试同一观点。错误重启通常可以删除，但早期尝试可能包含后续没有重复的铺垫、限定或情绪。两个完整重录要比较准确性、完整性、自然度、画面、声音和前后衔接。最后一次可能更准确，却因为人物低头、环境噪声或语气僵硬而不适合。

不同重录中的残缺部分不能拼成说话者从未完整说过的新句。可以保留一个完整前提，再接另一次完整结论，但必须确认语法、语义、语气和事实关系自然，并记录这种跨 Take 组合。

## 重复可能是修辞

重复不一定是错误。人物说“我一直在等。等钱够，等工作稳定，等生活终于开始”，重复的“等”建立节奏和主题；删除会削弱结构。判断重复的功能：是否只是无意识口癖，是否在递进，是否建立情绪，是否在结尾回环开头。

## 停顿不是统一长度的空白

停顿可能是卡顿、呼吸、思考、转折、情绪、包袱后释放或观众理解时间。专业处理不是把所有停顿压成 200 毫秒，而是听它对前后关系做了什么。

人物说“我后来才意识到……我真正想要的不是更多钱”时，省略号前的停顿可能让自我认识落地。若删除，句子更快，却更像事后准备好的结论。相反，人物在普通解释中寻找词语的三秒卡顿，保留会让信息速度停滞，可以缩短到自然呼吸。

## Hook 与重组

Hook 要从真实内容中建立问题、结果、冲突或反差，并在后文兑现。把一句结论提前并不自动成为 Hook；若观众不知道人物是谁、结论针对什么，强句也会悬空。重组时建立信息账本：提前一句会泄露什么，需要补哪个最低坐标，原来的反应是否仍属于这个结果。

短版本不是按比例删除。先保留故事脊椎，再判断每个例子和解释是否承担独特功能。同一观点有三个相似例子时可以只保留最具体、最有情绪或最能证明的一例；前提、转折和结论不能因为“不够炸”被一起删掉。

## 当前执行方式

先 `read_script` 读取 TranscriptSentenceCandidate、当前 SemanticUnit、Script 和 SpeechSegment。形成完整语义后，用 `apply_semantic_units` 写入 candidateIds、kind、dependencies、上下文、重录组、置信度和 pauseBefore。再用 `apply_script` 选择最终顺序。

如果源是已经生成的数字人口播片段而不是长原始 A-roll，仍然要判断段落顺序、是否有重复观点、段间逻辑和停顿，但不能假装能从片段内部做帧级口型切割。代码能力不足时保持计划并说明边界。

## 只听声音审查

视觉包装之前完整听一次。试着复述视频的核心；说明每一段为什么接下一段；记录哪处像机器拼接，哪处虽然语法正确却没有推进，哪处停顿承担情绪。只有声音主线成立，字幕和视觉才有可靠锚点。

## 详细案例

人物先说：“很多人都说，有钱就自由。其实我以前也是这么想的。”随后停顿，再说：“但我后来发现，如果每天的时间都不属于自己，钱只是让你更有能力继续等待。”

错误的短视频处理可能把“有钱就自由”单独前置成大字 Hook，删除“我以前也是这么想的”，再快速接结论。这样虽然更短，却把人物从共同经历者变成居高临下的说教者。更好的处理保留“我以前也是”，因为它建立人物与观众的关系；停顿保留但适度缩短；结论作为转折后的第二 Beat，再交给视觉解释。

## 五种 A-roll 任务与边界

Cleanup 只修缺陷，不重写观点。Highlight 选择完整高价值时刻，允许省略大量背景，但不能切断所选时刻。Restructure 允许改变顺序，需要检查事实时间线和人物知情。Hook/Short Version 允许前置结果和压缩结构，但必须兑现。Target Script 以用户明确文本为最高边界，不因开放式完整性规则而额外保留无关内容。

同一素材可以产生不同版本。课程 Cleanup 可能保留完整解释；60 秒 Highlight 只保留一个核心论证；短视频 Hook 可以把结果前置；Target Script 则严格匹配品牌批准文稿。不能把一个版本的规则偷渡到另一个版本。

## 案例：完整思想、重录与停顿

原始表达：

> 我觉得真正的问题是……其实不是钱。等一下，我重说。很多人以为有钱以后就会自由，我以前也这么想。但后来我发现，如果时间一直不属于自己，钱只会让你更有能力继续等待。

第一段“我觉得真正的问题是”是不完整重启，应删除。第二段“其实不是钱”虽然是完整短句，却失去前提；若单独作为 Hook，会制造夸大。完整重录从“很多人以为”开始，包含共同信念、人物关系、转折和结论，应作为主要版本。

“我以前也这么想”看似可以压缩，却建立人物和观众处于同一立场。哲学口播中保留它通常比更短更重要。转折前的停顿若源音频自然，可保留少量，帮助观众从旧信念转向新结论。

---

## Hook、重组和短版本

一个强结论只有在观众知道它回应什么时才有力量。“钱只会让你更有能力继续等待”可以做 Hook，但需要紧接最低坐标，例如“我以前相信赚够钱就能自由”。若只抛结论，观众可能把它理解成反金钱口号，而不是关于时间所有权的论证。

短版本先保留故事脊椎：信念、矛盾、转折和结论。例子按独特功能选择，不按原素材平均压缩。重组后必须检查反应镜头和代词是否仍属于新顺序。

## 声音切口审查

文本边界正确，不代表音频切口自然。切口可能落在辅音尾、呼吸中间、背景噪声变化或人物动作开始后。检查切点前后至少一秒，听 Room Tone、呼吸和句尾。若当前代码只能按整段数字人片段组装，记录能力边界，不假装已经完成源内精剪。

只听声音时，不看字幕和画面，让耳朵暴露机械拼接。若某个切口只能靠 B-roll 和音乐遮盖，先判断是否应修主线根因。

## 最终检查

- 任务模式明确。
- SemanticUnit 是完整思想而非标点句。
- 重录选择有证据，未拼造句子。
- 因果、转折、指代、问答和列表完整。
- 停顿根据功能处理。
- Hook 由后文兑现。
- 完整只听声音自然、可复述、有推进。
- 修改已经生成新 Revision 和 ImpactReport。
