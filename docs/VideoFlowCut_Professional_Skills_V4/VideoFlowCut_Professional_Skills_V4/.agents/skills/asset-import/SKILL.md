# 素材导入、角色与来源

> **V4 单文件原则**：本 Skill 已内置完成该任务所需的核心专业知识、案例、失败模式和验证方法。除项目级 `_shared` 合同与 `docs/asr接入.md` 等真正共享资料外，不依赖同目录 `references/`。


## 导入不是复制文件

一个媒体文件进入项目后，系统还不知道它在成片中扮演什么角色，也不知道是否有权使用、是否可解码、是否适合当前画幅。`import_media` 只完成受管复制和媒体分析；专业导入还要给 Asset 角色、来源、许可、标签和使用限制。

A-roll 是主叙事或主表演，不是“所有视频素材”。B-roll 用于具体化、遮盖切点、建立环境或情绪；Evidence 用于证明主张；Cutaway 是已经计划离开主画面的素材；Style Reference 只用于提炼视觉语言；Generated Visual 必须保持生成标记。错误角色会让后续自动选择完全偏离，例如把参考视频或 Mask 当人物主轨。

## 来源和权利

本地路径不能证明授权。外部素材至少登记 Provider、来源页面、作者、许可、署名和 rightsStatus。`unknown` 可以作为候选和研究参考，但不应进入正式交付；`attribution_required` 需要在最终描述或片尾满足署名；`restricted` 和 `rejected` 不能被“技术上能下载”覆盖。

生成素材适合抽象说明、环境和创意过渡，但不能冒充真实证据、历史档案、新闻、法规、投诉或人物当时的行为。

## 素材是否真的适合

B-roll 相关性不能只看关键词。旁白说“自由”时，海边可能只是文化联想；若观点讨论的是工作占据时间，日历、夜间办公和不断后移的计划更具体。先写清素材任务：观众需要理解、相信、感受、定位还是行动。再评估主体、动作、情绪、构图、画幅、可用时长、运动方向和前后镜头。

导入后检查真实缩略图和媒体元数据。标记脸、文字、Logo、产品、动作路径和安全裁切区域，供 Cutaway 和 Depth Composition 使用。相同哈希不重复导入；代理、缩略图和派生文件保留来源关系。

## 当前代码边界

当前 MCP 支持 `browse_assets`、`import_media` 和 `update_asset_metadata`，支持 Role 和 Provenance，但没有完整联网候选搜索和自动下载工具。需要外部素材时，可以先形成 Asset Requirement；取得本地文件后再正式导入。不要在 Skill 中调用不存在的 Provider 工具。

## 素材角色、来源和使用边界

角色描述素材在当前项目中的职责，而不是文件的客观类型。同一段城市视频可以在一个 Sequence 中作为 B-roll，在另一个版本中作为开场主画面。角色应随用途明确记录，但源 Asset 和 Provenance 不变。

Evidence 的门槛高于普通 B-roll。它不仅要相关，还要可回源、可读、保留条件和否定。一个网页截图若裁掉标题、日期和来源，可能失去证明能力。Style Reference 则相反，它帮助分析色彩、节奏和构图，但不自动拥有复用原画面的权利。

## 案例：相关但错误的 B-roll

旁白说“我想要自由”，搜索引擎返回海边、公路和山顶。这些画面与“自由”语义相关，却可能与当前论证无关。若前文在讲工作、存款和不断推迟生活，真正的视觉问题是时间被占用和选择被延迟。海边会把具体问题变成泛化励志。

只有当人物讲到真实远行、身体感受或环境转换时，海边才成为具体经验。若当前任务是解释机制，使用日历、排班、待办和“以后”不断后移的 Remotion 场景更准确；若当前任务是建立人物信任，继续保持人物可能最好。

## 完整推演：一段“下班后抬头看天空”的 B-roll 怎样进入项目

旁白中出现“下班路上，我偶尔会停下来看看天”。系统不能只因为文本里有“天空”就下载一段漂亮云海。首先要判断当前 Beat 的功能：它是在提供生活经验和情绪呼吸，而不是证明事实，也不是解释一个机制。因此候选画面应当包含下班后的城市关系、人物短暂停下的动作、黄昏或夜色，以及能够与前后人物口播自然衔接的镜头运动。纯旅游航拍虽然画面漂亮，却会把一个普通人的生活经验改写成旅行广告。

选中候选后，素材还不能直接进入 Timeline。需要确认它是否已下载到项目受管目录，视频能否解码，竖屏裁切后人物和天空是否仍成立，是否存在水印、品牌或陌生人物肖像风险，以及当前许可是否允许正式交付。完成这些检查后，它才从 AssetCandidate 变成正式 Asset，并被标记为 `b_roll`。最后在真实 Preview 中验证：Cutaway 的长度是否足够识别“下班—停下—抬头”的动作，人物旁白通过 L-cut 是否仍维持关系，回到 Presenter 时姿态和情绪是否自然。

## 最终检查

- Asset 状态 ready，失败原因已处理。
- Role 与实际用途一致。
- Provenance 和 rightsStatus 真实。
- 外部素材不是临时 URL。
- 受保护内容和可用范围已观察。
- 导入不被误描述成已放入 Timeline。
