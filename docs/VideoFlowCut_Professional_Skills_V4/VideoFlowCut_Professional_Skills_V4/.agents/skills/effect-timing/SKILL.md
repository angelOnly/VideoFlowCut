# 动效时机与运动句法

> **V4 单文件原则**：本 Skill 已内置完成该任务所需的核心专业知识、案例、失败模式和验证方法。除项目级 `_shared` 合同与 `docs/asr接入.md` 等真正共享资料外，不依赖同目录 `references/`。


## 动效时间不是“台词开始到台词结束”

一个视觉事件通常包含预期、动作、落点、稳定和释放。产品可以在“送出”之前轻微预进入，让观众准备看对象；数量在“70 台”落音时完成；CTA 在完整行动语句期间保持。若所有效果都在 Segment 开头淡入、Segment 结束淡出，它们虽然同步，却没有表达语言结构。

当前 EffectCue 支持 `semanticAnchor` 和四种 relation。`anticipate` 用于预示；`land_on` 让稳定状态在关键词或结果落地；`react_after` 用于笑点、失败和人物反应之后；`hold_through` 用于完整解释、证据或 CTA。选择 relation 应写叙事理由。

## 不同语义有不同节奏

数字效果通常先建立容器，再在数字落音完成，单位和语境要一起可见。对比先让 A 被理解，在转折词处 B 进入，同屏后再显示差值。因果先出现起点，关系在“因为/所以”之间建立，结果在结论落地。列表逐项出现，最后形成整体；一次全部展示会让旁白失去引导。

证据时机最容易做错。页面应先建立来源和上下文，再聚焦目标段落，最后高亮。直接切到放大的半句，会让观众不知道证据来自哪里。笑点则相反：包袱前保持克制，落点后短促反应；提前 Meme 会告诉观众应该笑，破坏期待。

## 阅读时间是动效的一部分

动画完成后必须给观众识别和理解。复杂 UI、文档和图表需要更长稳定状态；短结论可以更快。若读不完，优先减少信息、分阶段或延长 Scene，不通过缩小字体塞下全部内容。

## 当前时间精度

`segment_exact` 只能可靠定位完整 SpeechSegment。句中某个词的落点可以通过调整 Segment、真实 Preview 微调或未来 word_exact 获取。不能按字符均分。若手工通过 Preview 确认帧，应记录这是编辑校正，不是 ASR 事实。

## 冲突

同一时刻检查人物手势、字幕换卡、CameraPunch、另一 Effect、Cutaway、音乐重拍和 SFX。多个峰值重叠时，延后、减弱或删除次要事件。强效果并不需要所有通道一起强调；有时声音保持稳定，视觉落点反而更清楚。

## 运动句法

运动起点和终点应对应信息状态。推近从环境到细节，拉远从细节到关系，横移适合发现和并置，停住是句号和阅读。Spring、Blur 和旋转不是默认高级感。对象质量、情绪和语义决定 Easing。

当前 Runtime 对 enterPreset、settlePreset 和 exitPreset 的消费仍有限，因此 Skill 可以规划运动语言，但执行后必须以真实 Preview 为准，不声称任意 Preset 已完整实现。

## 完整案例

“这次送出 70 台平板”：产品在“送出”前预进入，人物手势完成时展开；背景数字在“70 台”落音稳定；产品和数字保持到句子完成；CTA 下一拍进入。若产品、数字和箭头同时在第一个词出现，观众无法建立顺序。

“声音和脸完全对不上”：包袱前保持人物，句尾落下后 CameraPunch 和短反应进入，持续不足一秒，再恢复。若变脸从句首开始，观众会提前知道笑点。

## 按语义功能设计时机

数字要在上下文中被理解，不能只计数。比较需要先后和同屏阶段。因果需要路径和结果。列表需要累计。证据需要建立来源。CTA 需要完整行动窗口。笑点需要期待和反应。

时机设计的目标是让视觉帮助语言组织，而不是给每个词配一个动作。一个句子只选择一个主落点，其余变化服务这个落点。

---

## 无词级时间时怎样安全工作

segment_exact 提供段落起止，不提供句中词。可以把效果绑定段首、段尾和完整段落，或通过真实 Preview 手工校正一个重要落点。不能根据字数估计每个词。

若一个段落包含多个需要独立落点的概念，优先重新设计 SpeechSegment 或降低效果密度，而不是制造假精度。

---

## 运动句法、阅读和冲突

动画像语言一样有短语。预进入是准备，主动作是动词，Settled Frame 是名词和结论，退出是交接。没有稳定状态的持续漂浮，很难让观众记住信息。

阅读时间和运动时间相互竞争。复杂文字不要在移动中阅读；人物关键表情不要被大幅运动覆盖。冲突时先保护第一注意目标，再延后次要动作。

---

## 最终检查

- Effect relation 与语义关系一致。
- 时间精度真实。
- 预进入、落点、稳定和退出有理由。
- 观众有阅读时间。
- 同时只有一个主峰值。
- 声音和人物动作没有冲突。
- 真实 Preview 检查了进入、中间、稳定和退出。
