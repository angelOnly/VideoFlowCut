# 旁白生产与表演连续性

> **V4 单文件原则**：本 Skill 已内置完成该任务所需的核心专业知识、案例、失败模式和验证方法。除项目级 `_shared` 合同与 `docs/asr接入.md` 等真正共享资料外，不依赖同目录 `references/`。


## TTS 成功不等于旁白成立

OmniVoice 可以生成音色相似的音频，但一条旁白是否自然，还取决于 Script 分段、语速、重音、句尾、停顿和相邻段关系。若把每个标点句独立生成，模型会把每句都当成完整结论，最终听起来像一串短广告；若分段过长，局部修订代价又很高。

SpeechSegment 应围绕完整可朗读思想建立。问题和回答、转折、列表项、情绪变化、CTA 和 Scene 边界可以形成段落；主谓、否定与对象、数字与单位、设置与包袱不应被拆开。

## VoiceReference

参考音频应清晰、单人、低噪，时长和情绪适合目标角色。它必须登记为本地 VoiceReference，并保留授权说明。当前接口没有远端 Voice ID，不能把本地对象描述成 Provider 账户中的永久音色。

## OmniVoice 调用

OmniVoice 工作流接收参考音频和待合成文本，内部自动转写参考内容。每次调用仍需动态读取 Workflow Detail；生成结果下载为本地 Asset。项目按真实音频时长组装 SpeechAsset，形成 `segment_exact`。这只说明每段起止准确，不说明句中每个词准确。接口当前对应参考音频和合成文本，且输出为音频文件，详见项目 `docs/asr接入.md` 的 OmniVoice 章节。

## 表演地图

生成前为重要段落写语气关系：这是铺垫、反问、坦白、解释、结论还是 CTA；重音落在哪里；停顿是呼吸、转折还是情绪；句尾是开放还是收束。复杂视觉解释时，旁白可以稳定，让注意力给画面；个人坦白时，应保留自然呼吸，不用音乐和快速字幕替代情绪。

## 四轮回听

第一轮对照文本，检查漏字、专名、数字和否定。第二轮不看文本，判断语气是否像真人表达。第三轮连续听相邻 Segment，检查音色、响度、语速和情绪是否重置。第四轮放回人物和画面，检查口型、字幕、Cutaway 和音乐。

局部问题只重生受影响 Segment。若所有段落都显得机械，根因可能是 Script 分段和表演地图，而不是需要反复生成同一文本。

## 语义分段与表演地图

同一句文字可以因为分段不同产生完全不同的表演。“我以前以为，只要再赚多一点钱，我就有资格休息”适合作为一个完整思想。若拆成“我以前以为”“只要再赚多一点钱”“我就有资格休息”，每段都会重新起音和收尾，削弱自我反思。

表演地图不需要复杂表格，但要说明相邻关系。例如前句是坦白，语速下降；下一句转入机制解释，语气变得清楚；结论前保留短停顿。这样生成和后续视觉才会共享同一节奏。

---

## 四轮回听与局部重生成

文本对照能发现事实错误，却发现不了机械语气；脱离文本能听见真人感，却可能忽略专名；相邻段回听能发现音色和情绪重置；声画回听能发现人物嘴型和字幕不一致。四轮互相补充。

局部重生成前先判断根因。一个词读错，修文本和单段；段落都像播报，修改分段或标点；音色跳变，检查参考范围和长度；画面口型错位，问题可能在 Avatar 而不是 Voice。

## 完整推演：为什么“每句话都生成得很清楚”仍会像机器

一段旁白被拆成六个 SpeechSegment，每段单独试听都发音清楚，但拼接后听起来像六次独立开场。问题通常不在音质，而在表演关系：每段都从中性语气开始、每个句尾都完全下落、段间停顿一致，前一句没有把情绪和语法交给下一句。

修复时不要先给所有连接处加更长淡化。先回到 Script 和表演地图，判断哪些句子属于同一论证、哪些是转折、哪一句需要保留期待。可以合并过短 Segment，或者改写标点与停顿，使上一段句尾保持未完成感，下一段承接而不是重启。重生成后要连续试听至少前一段、目标段和后一段。只有音色、语速、情绪、响度和句尾共同连续，SpeechAsset 才真正可用。

## 当前工具

使用 `manage_voice_references` 登记参考声音，`submit_voice_synthesis` 提交 pending/stale Segment，`read_speech_asset` 和 `read_speech_timing` 读回，必要时 `rebuild_speech_timeline` 修复旧 Revision。Actor 原声与 Dialogue 由 `ActorAudioMode` 二选一，不能同时可听。

## 最终检查

- VoiceReference 可用且授权说明存在。
- SpeechSegment 是完整可朗读单位。
- 所有生成段落和 Script Revision 一致。
- 相邻段连续自然。
- segment_exact 被正确描述，没有逐词假精度。
- Dialogue 唯一，人物原声没有重复播放。
