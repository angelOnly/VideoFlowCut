# Vlog、事件与镜头导演

> **V4 单文件原则**：本 Skill 已内置完成该任务所需的核心专业知识、案例、失败模式和验证方法。除项目级 `_shared` 合同与 `docs/asr接入.md` 等真正共享资料外，不依赖同目录 `references/`。


## Vlog 的主线不在文字稿里

人物口播可以先问“观众最终听到什么”，Vlog 则必须先问“素材中真实发生了什么”。一段 Vlog 可能没有完整旁白，真正推动观看的是人物去哪里、尝试什么、遇到什么变化、怎样反应，以及环境怎样从一个状态进入另一个状态。如果只按文件顺序拼接，片子会像素材记录；如果先套三幕剧，又会把普通生活剪成不存在的冲突。

因此，本 Skill 的任务不是把所有漂亮镜头选出来，而是从有限证据中发现一个真实、可兑现的观看脊椎。它可以是“第一次带猫去陌生环境，猫从紧张到开始探索”，也可以只是“一个安静下午从准备咖啡到读完几页书”。故事规模可以小，但每个镜头要让观众更清楚地理解事件、空间、人物或情绪。

## 先恢复事件地图

处理实拍素材时，先建立事实时间线：地点、人物、动作、声音、选择、结果和反应。文件创建时间、镜头编号和相邻顺序只是证据，不必然代表真实发生顺序。需要区分：建立空间的镜头、动作准备、主动作、结果、反应、细节、过渡和纯氛围。

例如“做饭”不是一组食物特写。真正的事件可能是准备食材、发现少了配料、临时更换方案、完成、试吃和反应。若只保留最漂亮的锅中画面，观众看见的是成品广告，不是经历。相反，如果没有阻碍和选择，就不要虚构“危机”，可以诚实地剪成过程观察和感官体验。

## 镜头的功能比镜头的漂亮程度更重要

每个进入主线的 Shot 应承担至少一种功能：建立、行动、细节、反应、证据、转场、节奏或气氛。相似的三个远景不因为都好看就都需要；一个技术不完美但真实捕捉人物反应的镜头，可能比稳定空镜更有叙事价值。

选择时比较：这个镜头新增了什么？如果删掉，观众会失去空间、动作、情绪还是只是少看一张漂亮画面？如果相邻镜头完成相同任务，保留更清楚、更有动作、声音更好或与下一镜头关系更强的一条。

## 动作连续性不是机械 Match Cut

观众需要知道动作从哪里开始、向哪里发展、最后发生了什么。切点可以在动作中制造能量，也可以在动作前后保留观察，但不能随意跳过导致方向和结果消失。

例如人物推门进入房间：外景手碰门把、门开始打开、内景人物进入。三个镜头不一定都保留，但若直接从走近门切到室内已经坐下，观众会感到时间被省略；这种省略可以是有意压缩，也可能让事件失去抵达感。选择取决于当前节奏和这次“进入”是否重要。

空间连续性同样服务理解。人物向画面右侧离开，下一镜头从右侧继续移动，通常更易跟随；有意改变方向可以表现迷失、转场或新空间，但要提供重新定位的线索，如地标、声音、全景或人物视线。

## 反应镜头是事件的一部分

行动只有结果，没有反应，情绪常常无法落地。猫第一次接触水、人物试吃食物、朋友听见消息、旅行者看到目的地，这些反应可能比动作本身更能说明价值变化。反应必须真实属于该事件，不能从别处借一个相似表情制造假互动。

不要为了节奏把所有停留都删掉。事件后的短停顿、呼吸、环境声和目光让观众有时间感受变化。高密度 Montage 后保留一个较长镜头，往往比继续切更有力量。

## 自然声建立现场

Vlog 的声音不是背景装饰。脚步、门、风、水、餐具、猫叫、空间混响和人物呼吸会告诉观众自己在哪里。音乐可以组织段落和情绪，但若它从头盖到尾，画面会失去现场感。

先建立自然声地图：哪些声音属于动作，哪些建立空间，哪些可以作为声音桥，哪些是噪声。J-cut 可以让下一空间的声音先出现，L-cut 可以让上一动作的余音延续。不要给没有现场来源的画面随意添加“真实环境声”并让观众误以为同期录制。

## 蒙太奇不是按 BPM 填满镜头

音乐蒙太奇可以由乐句、能量和动作组织，但 BPM 只是证据。每个 Cut 仍应服务动作、空间、情绪或视觉关系。快节奏不等于每拍一切；有时连续动作跨越多个拍点更顺畅。画面内部已经有强动作时，不必再在音乐强拍硬切。

蒙太奇结束应有目的：抵达、完成、疲惫、发现、反应或进入新阶段。没有结果的快速素材堆积会让观众只记得“很忙”。

## 当前代码能力与执行边界

当前 VideoFlowCut 已定义 `VlogMontageScene`，但还没有完整的 Shot Detection、Event Clustering、自动 Source Range 选取、自然声编辑和多机位 MCP。现阶段本 Skill主要用于 plan 和 review：建立事件地图、镜头功能、候选顺序、声音计划和验收标准。只有实时 MCP 能实际创建、裁切和移动对应 Item 时，才进入 execute；不能因为 Scene Type 存在就声称 Vlog 自动剪辑已经完成。

## 一个边界案例：安静读书下午

素材包括烧水、倒咖啡、翻书、窗外下雨、猫跳上桌、人物摸猫、继续阅读。错误做法是把每个动作压成一秒，配高节奏音乐和地点文字，试图制造“精致生活”。但这组素材的价值可能是松弛和时间感。更合适的版本用烧水声音引入空间，保留咖啡蒸汽和雨声，猫出现成为事件变化，人物反应形成轻微情绪峰值，最后回到阅读。镜头不需要很多，但动作、声音和反应构成完整经历。

## 从素材恢复事件地图

Vlog 的第一遍工作不是选“最好看”的镜头，而是建立一条不会撒谎的事实地图。记录每个素材实际可见的地点、人物、动作、声音、结果和反应，并标出时间关系是否可靠。文件顺序可能来自导出、下载或多设备拍摄，不能自动当作真实顺序。

事件地图可以按“状态—行动—变化—反应”整理。状态说明人物或空间原本怎样；行动说明发生了什么；变化说明结果或新信息；反应说明这件事对人物或氛围有什么影响。没有显著变化的素材也可以形成观察式段落，但要承认它的功能是气氛、坐标或过程，而不是假装存在戏剧冲突。

建立地图后再寻找故事脊椎。好的脊椎通常很简单：去一个地方、完成一件事、第一次体验、等待某个结果、与某人相处、从忙碌进入安静。它必须由素材中的真实动作和反应支撑。若素材只覆盖结果，没有过程，就不能剪成完整挑战；可以做回顾、展示或感受型版本。

每个候选段落都应回答：它让观众知道了什么？建立了哪个问题？产生了什么变化？下一段为何继续？无法回答的片段可能只是素材库候选，不必进入主线。

## 镜头功能、动作与空间连续性

镜头功能包括建立空间、承载动作、展示细节、提供反应、证明结果、连接时间和制造呼吸。同类功能过多时要取舍，不按拍摄成本或画质自动优先。

动作连续性关注准备、主相位、结果和反应。可以省略其中部分，但省略应产生明确的时间压缩，而不是让动作凭空跳变。切在动作中通常增加流动感；切在动作前后可以强调决定或结果。选择由叙事压力决定，而不是固定“动作点切”。

空间连续性依赖方向、入口、出口、视线、地标和声音。如果刻意改变方向或跨越空间，要给观众新的坐标。观众迷失不是艺术感本身；迷失只有在内容需要时才有价值。

反应镜头必须真实属于当前事件。不能从其它时间借用表情，让人物仿佛回应了没有发生在那一刻的事情。真实内容中，事实和信任优先于剪辑便利。

## 自然声、音乐和蒙太奇节奏

自然声提供空间、材质和动作的证据。先判断哪些声音必须听见：门打开、水倒入杯子、交通从远到近、猫叫、人物呼吸。音乐进入后，这些声音仍可以在关键动作处浮现，让画面不失去现场。

音乐 Spotting 不从“全片要有 BGM”开始，而从段落需要什么开始。准备和移动可以用音乐组织，坦白、等待和反应可能需要音乐退让。音乐变化应对应阶段或价值变化，不要每个转场换歌。

Montage 可以依据乐句、动作形态、颜色、方向和能量建立关系。不是所有切点都卡鼓点。强动作和强音乐同时达到峰值时，观众可能过载；有时让画面在拍点前启动、拍点落定，或者保持一个长镜头跨过拍点更自然。

结尾要让蒙太奇兑现：到达、完成、失败、疲惫、惊喜或安静。若只把素材按节奏播放完，观众不会形成事件记忆。

## 两个 Vlog 案例

### 安静下午

素材中的核心不是“咖啡、书、猫”三个关键词，而是时间从准备进入安静、又因猫的出现产生轻微变化。版本可以用烧水和雨声建立空间，倒咖啡承担过程，翻书进入稳定状态，猫跳上桌成为变化，人物摸猫是反应，最后回到阅读。音乐只在中段轻入，猫出现时不必配夸张音效。

错误版本会把所有镜头剪成精致 Lifestyle 广告，加入大量标签和快速切换，破坏安静主题。

### 旅行抵达

素材包括收拾、车窗、下车、走路、第一次看到海、人物停下。真正峰值是“看见海”和人物反应。前面的快速 Montage 可以压缩路程，但到达前应逐渐减少切换，保留声音和视线，让峰值有期待。若一开始就大量展示海景，抵达失去兑现。

## 最终检查

- 主线来自真实事件、问答或情绪变化，没有补造冲突。
- 每个 Shot 有功能，重复漂亮镜头被取舍。
- 动作、空间、方向、视线和反应可跟随。
- 自然声与音乐有层级，现场没有被完全覆盖。
- 蒙太奇有进入、发展和结束，不是素材展台。
- 包装克制，字幕和 MG 不替代真实镜头。
- 当前能力只支持计划时，报告明确写为 plan/review。
