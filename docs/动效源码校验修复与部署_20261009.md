## 问题与实现

原校验器把 JSX 属性名称 `top` 当成变量引用，再因其不是局部运行时绑定而拒绝。现在仅将 JSX 属性名称节点排除出全局引用检查，继续遍历属性值；`top={window.top}`、未绑定简写、展开中的全局读取、事件与 HTML 注入仍被拒绝。原聊天的整片源码只读提取后无需改名即可通过校验。

源码拒绝使用 `MotionSourceValidationError` 保存代码、行列、节点、片段及纠正依据，不自带副作用或重试许可。提交层仅在创建 Job 前的源码校验边界包装为 `MotionSubmissionValidationError`；MCP 映射为明确的 validation/none/correct_input，HTTP 返回400。未知异常仍保守处理；运行阶段错误保留失败 Job，不能按参数纠正重放。

主要调用链：`validateMotionSource → MotionSourceValidationError → submitManagedMotion 的提交前边界 → MotionSubmissionValidationError → toolError → MCP/HTTP`。Worker 的 `compileMotion → validateMotionSource` 不经过提交层包装。
