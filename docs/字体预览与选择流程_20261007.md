# 工作台字体库与主任务控制的选择流程

## 功能与边界

0.1.65增加左侧“字体”入口，展示发行目录中的34个实际字款。支持名称搜索、实际文案、字号调节、深浅背景、最多3款放大对比、推荐候选置顶与理由、复制选择。浏览和复制均不写视频；用户需在聊天明确确认，由主任务续接原视觉作者修订并提交。没有新建字体代理、字幕模板、固定动效或字体选择数据库，也未扩展普通字幕轨字体编辑合同。

0.1.66按用户要求压缩默认列表：示例仅“字体 Aa”，字号由36减半至18，字号范围12–72，预览区最小高度由115减至58，并减小内边距与行距。用户自定义和导演推荐的实际文案不截断、不替换；长文字仍自然换行。大图对比入口保留，短示例不代替实际文案验收。

职责唯一：主任务查询目录、组织预览、等待选择和排序正式执行；原视觉作者负责推荐与选择后的排版/动作；导演负责整体方向，仅跨段冲突时协调；用户决定最终字款。未回复不默认采用首选，只暂缓依赖字体的画面，继续无依赖工作。理想字体未收录不报告修复工单；已有原件损坏和加载失败仍按平台故障处理。

## 调用链

`read_motion_capabilities` / `GET /api/motion/capabilities`查询目录 → 原作者提供最多3款及真实文案/理由 → 主任务调用`get_editor_url(project_id,panel="fonts",font_preview=...)` → 工作台按需获取原件并使用FontFace真实排字 → 用户复制选择并在聊天确认 → 主任务followup_task续接原作者 → 完整采用稿与源码的fontBindings → 既有Worker首次挂载前加载和帧驱动渲染。

推荐链接的font_preview包含text（最多120字）、expected_font和purpose（可选）及candidates（1–3项，每项font_id与reason）。候选必须去重且来自当前目录。URL仅带浏览上下文，不代表审批或自动采用；损坏参数显示明确提示，已退出目录的候选不会生成卡片。切换项目删除旧推荐上下文。实际采用与预期差异复用creativeBrief和创意决策记录，最终按预期字体去重提示替代和可选扩充，不要求先扩充才交付。

## 只读字体接口

`GET /api/motion/fonts/:fontId/file?sha256=<目录哈希>`只按登记ID获取发行原件，共用现有路径边界、32MiB文件限制、OTF/TTF文件头和SHA-256校验。真实原件类型分别返回font/otf或font/ttf；成功响应按内容哈希缓存，设置private/immutable与nosniff。未知ID返回404，旧哈希返回409要求刷新，原件损坏返回500；错误不缓存，不暴露任意路径读取入口。接口不创建Project、Asset、Job、Revision或Repair Ticket。

浏览器先等待真实FontFace加载完成才显示样本文字，不以系统黑体占位冒充字款；失败显示单卡片错误并禁止复制该卡片选择。可见卡片和对比区共享加载，最多两路并发，读取超过15秒明确超时；面板卸载取消队列和读取，仅删除自己注册的字体对象，不影响其它页面字体。保留完整原件，因此大字款第一次预览仍有等待和浏览器解析内存开销；不承诺关闭面板后浏览器内存立即归零。原件可能缺生僻字/符号，首版不自动解析完整字符覆盖，实际文案仍须观察。

## 未登记字体的窄纠正分支

submit_motion_work仅捕获发生在createJob之前的MotionFontUnknownError，返回code=MOTION_FONT_UNKNOWN、stage=validation、sideEffects=none、safeToRetry=true、recovery=select_registered_font及selectionRequired=true。这表示进入预览与用户选择流程，不是立即重试原输入，也不报告工单。选择确认后修订完整输入，使用已登记ID正常提交；失败前没有占用幂等键。其它校验、执行失败、网络超时和结果未知不开放此恢复分支。原件格式、内容哈希、固定绑定、缓存及渲染加载校验保留。
