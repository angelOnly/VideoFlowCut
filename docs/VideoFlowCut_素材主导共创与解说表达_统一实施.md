# 第一部分｜问题不是少一个搜索动作，而是生产顺序与决定依据错了

## 一、这次要明确纠正什么

前一份素材方案仍强调“让材料公平参与”“原模型与素材比较”“不必强制采用视频”。其中不应强用每份下载文件的判断仍成立，但它没有充分承接用户已经明确的成片目标：**这条视频路线必须以素材完成主要剪辑，不是图形讲完后允许插几份材料。**[D1]

两者必须分清：

| 判断层 | 正确含义 | 不可偷换成什么 |
|---|---|---|
| 整条任务路线 | 主要观看由实际素材承载，文案和动画围绕它组织 | 导演觉得模型更容易，就把整片改成文字与图形 |
| 单个候选选择 | 这份材料可不采用，可换源、换范围、重新寻找 | 放弃一个候选，就取消整项素材工作 |
| 局部表现 | 抽象关系可以暂由图形、排印或模型表现 | 每个段落都认定抽象，整片只留一张法规图 |
| 技术状态 | 文件、绑定和时间能够正确执行 | 技术能导出，即证明素材主导与观看目标已完成 |

素材主导不等于所有素材必须是摄影视频，也不等于每个画面永远铺视频。用户文件、外部视频、照片、录屏、图像和可实际使用的既有视觉内容，都可按文本与观看作用参与。**检索不统一添加“实拍”“生活影像”、固定机位、画幅或风格词。**

同样，不能把为了本次页面临时生成的票卡、条形图等重新命名成“素材”，或者把一份法规截图的存在当成整条材料主导已经完成。判断的是实际主体、过程和观看发展由什么承担，不是文件扩展名或Asset数量。

导演在这个目标内决定具体内容与表达；它有选材与编排权，没有未经用户改变任务就取消素材主导的权力。这是业务路线与本轮明确需求，不是放进根`AGENTS.md`的审美禁令。

## 二、为什么素材作者必须从第一轮参加

### 2.1 “允许早期搜索”不等于“早期已经有工作责任”

当前主题方法已经写了共同创作，但导演入口仍先与文案和视觉发展草稿，再进入取材；根规则又写“导演到达具体阶段后”提出专项。协调者按这个顺序工作时，素材作者容易在主要内容和图形都已经安排之后才得到任务。这里说的是指令结构造成的风险，不将它推断成所有历史任务的实际时序。[G2—G4]

这会产生连锁效应：先写解释稿，视觉据此画模型，配音给出总长，再要求素材作者寻找一个能“插进去”的片段。即使下载很快，材料依然来晚了——不是晚在网络时间，而是晚在决定已经做完之后。

### 2.2 素材不是对文案逐句配图的执行者

素材作者的早期工作会带回文案尚不知道的具体内容：可见行为、值得比较的差异、现成的表达对象、有用的声音、与主题贴合的画面联系。它们能够改变开头、解释顺序、比喻和结尾。没有这些输入，文案容易只在已有知识目录内组织句子，美术也容易只在同一套文字板内改善排版。

素材作者不需要等完整文字才有工作。初始主题、观众线索、用户要求、已有文件和导演的暂定问题已经足够形成第一轮找法。第一轮发现回到共同稿后，再针对更明确的句群继续检索。

### 2.3 共同开始，也不等于四个人各自完成一份答案

初始职责需要共同启动，反馈也必须及时。四个作者并行到最后才汇报，会得到四份互不依赖的成果，仍然不是共创。

导演、文案、素材与视觉沿同一份当前稿工作：素材返回一个能够改变画面的发现，就续接当前导演、文案与视觉；文案更新一处主要关注，就把对应差异续接素材作者。**不用等待整条搜索或全文全部结束。**兼任同样遵守这个回传顺序，不强制增加人数。

## 三、目标流程：材料与稿件一起长出来

```text
用户主题、明确要求、已有文件
                 │
      主任务建立同一轮工作责任
                 │
      ┌──────────┼──────────┐
      │          │          │
  导演与文案    素材作者    视觉作者
  初步关注、    从主题和    观察已有材料的
  可改开头与    当前内容    表现机会、空间与
  发展          直接找材    可实施范围
      │          │          │
      └──── 首批实际发现回同一稿 ────┘
                 ↕
       材料、准确文字、主画面共同形成
                 │
    已具备材料的连续范围先做声画粗排
                 │
       对应范围正式配音／必要改稿
                 │
  美术深化＋机制混合检索与组合＋声音
                 │
       当前源码实现、实际预览与返修
                 │
     整片交付；未具备材料的范围并行续接
```

这张图是业务依赖，不是必须四个代理、固定几轮搜索或新增审批。素材取得仍有网络时间，但依赖这些材料的主画面不会在等待期间先被其他形式占满并自动定稿。

### 3.1 第一轮具体交什么

| 责任 | 一开始可以拿到什么 | 首次需要交回什么 |
|---|---|---|
| 导演 | 用户主题、受众与用途线索、已有材料 | 初步关注、观看回报、当前内容问题；不是完整检索规格 |
| 文案 | 同一主题与资料、导演的暂定方向 | 可修改的开头与发展，指出哪里需要实际材料决定；不是预先定稿 |
| 素材作者 | 同一主题、初步问题、已有文件；不要求已有全文 | 内容查询、值得使用的发现与范围建议，可能的主要画面与未解决内容 |
| 视觉作者 | 已有材料、初步关注与持续返回的发现 | 材料怎样形成主体和连续观看；早期试形不是最终页面 |
| 主任务 | 当前授权、实际工具与项目状态 | 真实分派、及时获取与回传、无依赖工作的推进；不代写创意 |

只有内容仍有不可化解的歧义时，才问用户。没有选风格、没有精确秒数、没有Scene ID，不是任务缺失。

### 3.2 哪些事先做，哪些等相关材料

研究事实、试写开头、检查工具、研究轮廓和已有材料，可以共同开展。涉及某份素材的主体、裁切、源内动作、字位、几何关系与主要画面采用，必须依据该材料实际内容。**这是一项输入依赖，不是一项“审阅通过”资格。**

按连续范围推进：一段的主要材料到达，就在这一段形成可运行粗排和准确稿；另一段仍继续寻找。既不“全片全部下载齐再动手”，也不“素材没来先把所有图形画完”。

### 3.3 声音为什么也要调整时机

先有能与材料共同成立的句群与粗排，再生成该范围正式配音。粗排可以使用临时读稿和估计秒数；不要求完整动画、正式声音或审片先通过，避免产生“先配音才能粗排、先粗排才能配音”的循环。可以早期试音和读稿，但不把试音时长升级成全片不能改变的边界。声音回来用于校准，而不是用来证明材料再也放不下。

已有声音时，材料通常先在同一时间内承担主画面、替代临时模型或与解释共场；并不是旁白、视频、图形都要单独加一段时长。确实要改稿时控制重配范围和自然衔接，真实用户锁定项保持。原配音成本是取舍，不是永久否决材料的理由。

## 四、素材主导怎样落到选择与完成状态

### 4.1 导演仍负责采用，素材作者不是另一个导演

素材作者需要理解相关整段内容，才能推荐范围和用法，但不独立改整片主张。最终采用和主要编排由导演承担，原文案负责准确语言，视觉与剪辑作者细化具体切口、取景与动作。已确定的来源和范围直接续接，不逐文件新增审批。

### 4.2 找到材料后，不只问“插在哪里”

先看材料本身能够让观众看见和感受到什么；在当前时段里用它形成主要画面，再确定图形补充什么、语言减少或补充什么、前后怎样接。备选是正常创作，不要求每份材料做四种固定方案。

材料不合适可以不用，但原先需要的画面工作不会一起消失。换范围、换源、改讲法都属于继续完成当前任务；整片纯图形只能在用户明确改变任务后成为另一条路线，不能作为“获取已经努力过”的自动回退。

### 4.3 如何避免把新要求变成新的硬指标

不设最低视频条数、面积比、时长比、来源数和下载次数。也不按某类媒介认定好坏。判断主要材料有没有在实际画面中承载观察和发展，文案是否由此获得具体内容，动画是否与其结合。

这项要求属于导演采用与成片说明，不把辅助分析、截图覆盖或模型分数重新作为使用前提。即使技术可导出，也要如实说明材料主导要求尚未完成；不能把“可导出”写成“用户目标已实现”。

# 第二部分｜保留上一版的导演自主定向与解说能力，并接到首轮素材共创

## 五、导演自主定向，工作台只保存主动设置的默认

六种方向与五个维度都由导演根据内容判断，不让用户生成前选择。用户只给主题即可；有自己的稳定取向时，在工作台主动保存默认即可。这里继承上一版结论，不恢复选择问卷。[D2]

| 内部方向 | 主要解决的观看问题 | 在素材主导路线里的使用 |
|---|---|---|
| 轻松有梗 | 交流感、具体感和记忆点 | 以材料中的观察、预期和结果发展，短评论落在已有内容上 |
| 温暖陪伴 | 理解处境、给回应空间 | 从具体材料和选择出发，声音亲近，不虚构经历 |
| 悬念探索 | 让问题与发现持续推进 | 尽早交一层回报，随实际材料展开下一问，不隐瞒必要事实 |
| 理性爽快 | 信息紧凑但不读说明书 | 材料中的有效差异和推导居前，术语按需要进入 |
| 奇趣卡通 | 抽象关系更易理解 | 物件轮廓、比例、排印与动作配合素材，不要求复杂角色长剧情 |
| 沉浸叙事 | 跟随观察与过程 | 材料自身发展、环境与声音成为观看基础，不用慢匀速假装沉浸 |

这些不是六选一分类器、六套固定模板或六份独立Skill。导演可组合方法，不必命名预设。素材主导是任务路线，不因选择“理性”就退回纯模型，不因“卡通”就限制素材必须卡通。

| 维度 | 导演统筹 | 专业作者深化 |
|---|---|---|
| 讲述口吻 | 亲近、直接、评论、探索或温和的程度 | 准确台词、长短句、幽默位置和声音表演 |
| 视觉语言 | 当前材料适合的对象与形态语言 | 轮廓、字形、配色、材质和构图 |
| 运动性格 | 准备、力度、惯性、跟随与收势的方向 | 实际机制、曲线、路径、交叠与时机 |
| 背景关系 | 材料、网格或分层空间怎样支撑观看 | 真实透视、取景、阅读空间与前后接续 |
| 声音气质 | 旁白、源声、音乐和落点的主次 | 具体音色、停顿、音乐和音效 |

优先顺序为本任务明确要求、用户主动保存且适用的默认、导演当次判断。导演决定写进当前稿和已有CreativeDecision，不自动写成用户偏好。工作台默认变化只影响以后新任务，已有项目和在途生成不静默重解释。没有默认或只设置一维，其余照常自动判断。

## 六、文案学习已经整理为方法，不每次学习博主

本节继承上一版对柴知道、差评君可读文本与用户提供字幕的提炼，不新增推荐名单，也不声称本轮重新观看或统计了两个账号。这里的“参与式解释”“观察式评论”是为项目命名的通用方法，不是原作者官方分类；原文、作品题材与个人身份不复制进技能。[D2]

### 6.1 参与式解释：先有一次观察与发现，再知道原因

柴知道的既有分析支持一种可借鉴的表达关系：先让观众面对可认出的对象或差异，有一次低负担的判断，再解释它为什么成立。一个解释留下真正未解的问题，下一层知识因而有出现理由。术语用于命名已理解的关系，不先组成词典。

项目直接使用的方法是：选择实际材料能支持的观察，尽早给第一份理解回报；让材料中的变化和比较承担画面，语言补原因与意义。没有素材时不能假装观众已经看见，更不能只把问题做成一个大标题。它不要求主持人出镜或复杂角色动画。

### 6.2 观察式评论：从可感受到的行为，走到条件与后果

差评君的既有分析强调熟悉的操作、困惑或意外结果，用行为对照建立记忆，再追问条件、成本或选择空间如何影响后果。评论在观众已看见或已理解依据后出现，结尾回到人的判断，不止停在知识名词。

项目直接使用的方法是：从当前材料选择具体行为、结果或细节，让观众理解发生了什么；有依据再解释关系，以短评论概括落差。不能借用外部作者的第一人称测试、采访、经历和口头禅，不能把强烈立场当证据。

### 6.3 两类方法怎样共同写一份稿

| 写作动作 | 具体要完成什么 | 与素材协作的落点 |
|---|---|---|
| 找观看理由 | 当前受众关心什么，看完得到什么 | 主题提出问题，材料提供具体进入点，二者互相修订 |
| 尽早给第一份回报 | 一处差异、一个误会或一个可理解关系 | 让它真的可见，不把所有答案拖到片尾 |
| 原因推动下一问 | 只深入当前还没解决的部分 | 新材料可改变解释顺序，不能只给旧稿加来源 |
| 准确类比 | 对应参与者、动作、作用与结果，再回本体 | 用可追踪的材料或对象降低理解成本，不每段换故事 |
| 有依据的评论 | 已有发现后的短回应、落差与后果 | 语气由导演定，不强塞梗，不编心理与实测身份 |
| 声画分工 | 画面演变化，语言补关系与意义 | 素材作者、文案与视觉在同一稿里决定，不逐句配图 |
| 结尾回扣 | 回答已经展开的关注，形成认识或选择 | 早先的材料、对象或对照带着新理解返回，不突然列新清单 |

共鸣不等于每句都喊“你是不是也”，也不意味着所有题材都讲生活故事。严肃内容仍应具体且值得关心，轻松内容也要有发展。没有实际观众数据，不以这些方法保证完播率。

## 七、全文怎样写、怎样改，避免又变成口号

先写当前准确旁白和对应的主要观看关系，表达依赖未取得的材料时明确暂定，材料作者继续探索。首批素材回来就改主语、动词、例证、顺序和画面任务，不等完成一份定稿再改。真实信息的条件在影响理解的位置说明，不把研究备注集中铺在开头。

观察与过程应当让观众看到变化；术语在能够整理当前关系时引入。原理已经说清就向后推进，发现没有新信息就删并或重排，不机械制造反转。画内文字只承担当前主读，普通字幕转写实际语言，不能把整段再复制成另一套巨大文字。

口语化是让每句有清楚的主语、动词、指代与关注，不是只加语气词或把所有句子切短。幽默可来自合理预期和实际结果、准确比喻、贴合内容的反应；没有贴合的笑点就直白、亲近，不为模板编造材料。

全文检查与实际声画检查分开：稿上重音不表示真实表演已经完成，静帧也不表示动态顺畅。素材、正文与当前声音在连续范围里试排；画面已说明白但声音还在复述，就改语言；观众未看清而声音进入下一层，就调动作、信息释放或停顿。

结尾必须使用前面已经展开的关系回答开头，不能突然追加需要新证据的新命题。不成立时回中段补缺，不能用口号与提醒掩盖断线。第十三节包含完整文案入口与完整方法，可直接替换对应两个文件，不再引用旧接入包作为必需输入。

# 第三部分｜美术、动效和返修服务材料主导，不另起一套页面

## 八、干净画面、背景与动作怎样共同落实

### 8.1 去掉自动制作提示，保留准确内容

“示意、示例、图片来自网络、非当事”等不根据素材元数据自动变成角标、印章和页脚。主任务、文案、美术、证据方法和共享稿都不再将内部记录当展示文本，删除旧文字后取消无用底框并重排。

来源仍沿现有provenance、SourceManifest与交付说明保存。必要假设和改变结论的条件在相关讲述或真正需要的原文中自然交代，不把假设冒充实测，不把解释画成官方原句。真实署名或必须披露的要求另行满足，不与模型自行添加的提示混同；这不是用全局字符串替换删除来源原图里的文字。

### 8.2 美术先看材料，再决定造型与排印

材料带来的主体、空间、明暗、动作和可读区域决定构图。Taste方法继续用于需求理解、具体设计与定向修订，不预选一套颜色再为所有段落画同一种容器。字幕外观归美术统筹，准确分卡与时间归字幕作者，实际平台支持的阴影、底板与字体才是输出依据。

卡通质感可由物件比例、轮廓、正负形、材质、接触影和动作性格形成，不依赖复杂角色表演。它不能把素材撤掉后仅给旧说明板加圆角。导演根据内容判断程度，用户明确偏好继续承接。

### 8.3 背景是空间关系

材料可直接承载整幅画面；透视网格需要地平线、尺度、对象接地点和观察位置一致；分层空间靠遮挡与不同深度响应支持主读；插画与拼贴围绕当前材料的实际内容组织。不要把背景等同“纯色底上加一层纹理”。

本任务对非纯色主要背景的明确要求继续保留在当前稿与美术方法，不写进根`AGENTS.md`。纯色可以是底层、物体表面或短连接，原件自带白底也不必擦除。材料不足不能靠网格替代全部主要内容。

### 8.4 运动不是给每个元素换一条easing

| 环节 | 实际设计工作 |
|---|---|
| 准备与蓄力 | 重心、方向或形体短暂准备，给动作发起一个可感知缘由 |
| 发力与通过 | 主方向取得速度，位置、姿态与路径共同发展 |
| 冲击与惯性 | 到达时有分量，必要时越过或滞后，附属层与主物有关系 |
| 回正与读清 | 余动衰减，信息在合适时机稳定，不让字幕和所有层一起弹 |
| 接管与离开 | 新重点在旧重点仍有参照时进入，按需要延续方向与速度 |

这些环节按实际内容选择，不要求每个字凑齐。素材源时间不跟随装饰曲线任意重播；真实数据不因过冲产生错误数字。需要越过的位移、姿态与有界透明度分开处理，不能先把所有进度裁成0到1再期待惯性。

机制混合检索继续围绕主行为、协作、观察与连接召回，由当前作者结合整段重选；首次词法结果与后续语义Job读回要分清。动作性格影响候选比较和适配，不转成所有查询必须同时符合的风格标签。多个机制可顺序、并行、嵌套与交叠，共同服务一项清楚的关注，不只是首尾串行。[D1][D2]

```markdown
## 按连续范围推进，不等全片齐备

某个连续范围的主要材料已经取得并能够据其实际内容工作，就先把材料与文本接成粗排，再深化该范围。尚缺材料的范围继续找，其他可推进内容照常执行。依赖源细节的几何与动作在看见材料后确定；素材尚未到达时的图形试作只保留为候选，不先占据最终画面。

将当前实际文件、推荐／采用范围、需要持续的内容和未完成用途写回同一稿。主要采用由导演确定，采用方向内的精确切口、构图和声画接点由原作者继续；只有主要含义或跨段关系变化再协调。

## 直接使用与正常内容判断

已有同源选段下载后直接承接。未选定范围在实际播放器、代理或可选分析中定位；这是剪辑工作，不提交满覆盖证明或审核资格。文件、类型、源身份和时间范围由执行层核对，辅助分析缺失不判定内容不可用。

真实内容和当前讲述不符时明确改稿、换材或重新取景。普通配图不承担未经承诺的事实证明；原文和本片解释不混淆。来源和内部备注保存在现有记录，不自动做成“示意、示例、网络来源”等角标。

## 原负责人怎样续接

缺材料或可用范围回素材作者；主要讲法回导演与文案；材料合适但画面不成立回视觉；源时间、绑定与读取错误回对应实现和操作方法。停止一个候选后继续处理原用途。交接使用现有全文、对象引用与变化范围，不让接收者从留言拼最终稿。
```

### 13.6 文案方法：完整保留参与式解释、观察式评论与表达修订

**目标文件：** `.agents/skills/narration-writing/references/writing-methods.md`  
**操作：** 整文件替换该文件。完整新正文如下；不覆盖其所在目录。

**写入正文：**

```markdown
# 从完整观看草稿到逐次改写

新稿沿下文从内容发展到台词；已有稿只进入当前问题。准确全文与对应画面说明保存在同一份稿里，材料和试排反馈也改回这里。方法不要求固定句型、反转数量或每段候选配额。

## 从主题找到可展开的关注

从首轮与导演、素材、视觉共同接收主题、受众线索、已有资料和用户明确要求；没有完整稿也可以试写，素材作者同时开始探索。承接导演当前表达方向与持续返回的实际材料。未指定风格时按导演本轮决定写作，不停下来让用户选预设；普通制作直接使用本页方法，不重新搜索博主或分析参考作品。

先找一个观众已有的认识、能辨认的现象或正在意的选择，确定看完将得到哪项具体解释或判断。把知识题目改造成值得追问的问题，而不是只改成疑问句。题目需要的前提可以直接交代；不以藏住必要答案或夸大风险来制造悬念。

写开头时同时确定可以尽早交给观众的第一份回报：看见一处差异、弄清一个误会、认识一个具体关系，或得到一个有根据的判断。先让内容向前走，再引出尚未解决的部分；不要只写有趣开头，把整个答案留在最后。共鸣可以来自经历、好奇、选择或观察，不强迫每个题材配一个生活故事。

判断本段主要需要解释原理还是理解现象。前者安排观众先观察或作简单比较，再知道原因；后者先还原一个行为及其困惑，再追到影响它的条件和后果。同一篇稿可以结合两种写法，不套固定段数、反转次数和口头禅。

与导演、素材、视觉写出实际旁白及粗画面关系：由哪份已取得或正在探索的材料建立关注，先看什么，语言补什么，下一问为什么产生。初稿可提出材料方向，依赖未取得内容的句群和画面保持可改，不先给整段排满独立图形。只有用户明确锁定的内容不可任意变动。已有材料带来更好的进入点时改当前稿，不让第一次构图成为所有候选必须符合的规格。

## 材料怎样推动台词与改稿

素材作者是首轮共创者，不是等文案完成才接任务。主题和初步问题足以开始寻找；文案有新内容即同步相关范围，素材有可用发现即回到当前稿。完整朗读稿、正式配音和主要画面根据两边结果形成，不将文案先写完当作素材开始的条件。

每份值得采用的材料要带回可写入正文的主语、动词、细节、对照或新的发现。先确认它能回答当前问题的哪部分，观众怎样通过它获得理解或感受，再决定语言补什么。不是给既定观点补链接，也不是先在纯图形里讲完，再额外插几秒。

取材请求给主题或相关准确句群、前后关系和要完成的表达。素材作者负责展开查询、来源与材料方向；导演和文案不提前锁定机位、物件组合、媒介或唯一场景。材料可以只承担当前的一项作用；事实依据另按实际主张核实，不把所有配图都要求成论证证据。

本路线以实际材料构成主要观看。材料回来，改准确正文与观看顺序：事实或条件变化先改意思，源内没有的行为不硬写，已有过程讲得清楚就减少重复解释，更好的范围或原声交导演重排。图形补足关系而非占满每个段落；原候选不适合时继续寻找或调整讲法，不能把材料工作整体删除后沿用原稿。

已有来源、用途和范围直接承接，不另设素材资格。引用、作者说明、本片推断与未知分清；不把照片写成持续动作，不把未见情绪和动机当成事实。推荐与主要采用分开，素材作者提出建议，导演确定主线与采用，文案负责准确地整合到全文。

交回完整新稿和受影响的配音、字幕、材料与接点，不只在留言里补几句；同一连续范围的材料可用后就共同粗排，不必等待整片全部齐备。

## 比较、过程与信息顺序

让解释接住观众刚看到的东西。需要辨认差异时，先交一个可以实际观察的比较，保持同一对象、尺度或条件；观众能辨出变化后，旁白再指出原因与意义。信息应当在画面里可辨，不假装在远小于阅读所需的时间里让观众完成测试，也不要求观众真的点击后才能继续。

把原因写成参与者、动作和结果：谁处理什么、哪项条件改变、什么被保留、结果如何得到。名词是给已理解的关系命名，不是讲解的起点。术语在它能解决当前问题时再出现；专业查找与紧急操作可以直接给答案，不刻意绕远路。

当观众可能想到一个简单办法时，先公平说明它为什么合理，再用已经核实的约束指出它还解决不了哪部分，顺势引出下一层。不存在这个约束就不编一个障碍；已经足够回答问题就收束。各段的推进来自问题真的向前，而不是连续使用转折连接词。

准确类比要对应参与者、动作、作用与结果，优先用一个可以继续追踪的熟悉关系来降低理解成本；指出对应关系后回到本体，保留当前必要的差别。不把类比当作新证据，也不为每段更换比喻造成新的解释负担。

过程与比较不自动对应流程图或双卡片。先决定观众需要看见怎样的改变，再与视觉选择实际载体。画面可直接呈现的部分少复述，语言补条件、联系和意义；单位、尺度、否定和结论依据保持准确。

每个已完成的小解释可以引出一个实际未完成的问题、应用或判断。段落可以是观察到原因、原因到后果，也可以是直接结论后的核验；不要求全部写成固定的问答链。

## 从具体观察写出有依据的评论

先承认观众可能感受到的困惑、麻烦或期待，再展开解释。亲近感来自看见对方关心的事，不是每句都称呼观众，也不是凭空声称所有人都有相同感受。

从材料里选择能表现这层问题的一个动作、结果、原话或细节，先让观众理解发生了什么。再追问什么规则、选择空间、成本或激励使这个行为产生；有依据才连接行为与原因。个人观点用观点的口吻表达，不把解释假说包装成已证实因果。

用对照突出关系时，让两边比较同一件事，并通过行为及结果把不同说清。重点不只是两个形容词或两块等权卡片，而是观众能够跟随的变化。关系较复杂时继续用原对象或同一观察维度推进，不任意增加新人物和新故事。

评论落在观众已经看见和理解的内容之后，概括其中的落差或代价。轻松可通过准确而稍有意外的措辞、短反应和图形表演形成；论证仍需由内容承担，不靠强烈态度替代。遇到严肃或敏感内容，亲近和关切可以保留，不必插入笑点。

解释完机制后回到人会怎样选择、体验或判断，让原因与后果闭合。人物的内心没有依据时只说明可见行为和可能解释；第一人称经历、实际测试与采访不得借用外部作者的身份。

## 旁白、画面与文字共同完成表达

文案同时写准确旁白与主要画面关系，说明观众在哪个材料、动作或对照中得到新信息。画面负责可以被看见的变化，语言补充条件、因果、态度与意义；必要转写或无障碍描述可以重复，不让短暂漏看就无法理解。

写稿可短暂使用反问、可验证的猜测或预期，引导观众注意具体变化。新结果先达到可辨状态，再说出发现；不要在画面还没建立时把答案讲完。若信息必须由旁白先交代，明确这种顺序的作用，不机械要求所有解释都先看后说。

关键名词尽量有可持续追踪的对象、材料或关系。它的下一次变化接住前一句，而不是每说一句就新建一个全屏板块。文案写到变化与接续，美术决定造型、字位、背景与材质，动效进入制作后据此组合机制。

普通字幕承接准确语言；画内主读只承担当前重点，不把整个段落再抄成一套巨大字幕。画内重音与画面反应共同完成理解，不能用逐行显字替代本该发生的过程。

生产备注、来源信息与内部分析留在记录，不自动写成角标、印章或页脚。会改变理解的假设、适用条件在相关讲述中自然说明；引用原文和编辑解释保持区别，不把事实边界删掉来换取干净画面。

## 改口语与句子的工作

自然连读全文，检查一句是否只有一个清楚的关注、代词是否指向明确、动词能否被理解，拆开必须回想才能听懂的长句。保留必要限定和有意义的长短变化，不统一切成碎句。让一句提出的关注在下一句被接住，不只是把书面连接词换成语气词。

幽默落在当前内容的预期与结果、明显的反差、准确类比或短暂回应上。笑点与信息同时起作用，读完后仍知道正在解释什么。没有好笑且贴合的内容时，直白、具体、亲近即可；不强加粗口、流行梗或作者专属口头禅。

解释较密时，安排一个短的发现、反应或判断，让观众消化刚获得的信息，再往下推进；它必须接住前面的内容，不能成为无关的活泼插曲。用词、停顿和轻重按导演本轮表达方向调整，不因严肃就退回公文口吻，也不因轻松就增加无依据的断言。

连续许多句只定义、限定或纠正时，回到问题、可见材料和实际推进，删并、移动或补写对应关系。只更换问号、感叹号和配音情绪，不算完成内容改写。具体声调与节奏以真实音频判断，稿上重音标记不是效果已经实现。

## 在实际声画中调整节奏

整片决定哪些过程值得展开、哪些背景压缩；段落安排必要前提、变化和反应；句群调整呼吸和信息落点。先用秒给初始尺度，说明时间用于说话、操作、阅读或体验，不平均分段或补满旧案例长度。

自然读稿后，必要时与实际材料、当前声音和关键动作试排。若画面已完成、旁白还在复述，改台词；若画面未看懂、语言已讲下一项，改动作、句群或停顿；不同层争抢注意就重排分工。真实动作或源声可以接管，稳定阅读不必同时漂浮背景。停留有用途就保留，背景微动不能证明时间有效。

正式配音采用该范围经过材料共创的当前稿。更早的试音与读稿可用于判断语感，不自动把全片时间锁死。材料后来提供更好表达时，先与导演、视觉在原语音时段替换临时图形、重排共场与接管；仍需改稿时提交准确新句群，协调必要范围的重配、字幕和画面。重配成本是取舍，不是把材料退成插播的理由。用户明确锁定声音或时长时在该边界内重排，不擅自裁声或变速；字幕短卡不等于多个独立配音文件。

## 段落接续与结束

把相邻段落首尾放在一起读：下一段接住哪个未解问题、对象、结果或感受。没有联系就重排或明确转题，不用过桥套话伪造因果。需要跨句持续的材料和动作在同一场面继续，字幕卡、文案段落和输出文件不互相规定边界。

结束时回到开头建立的那项关注，说明观众现在能够解释、识别、选择或重新理解什么。回答使用本片已经展开的关系，不在最后追加需要另一段论证的新主张，也不把结尾做成三个抽象口号。

原先出现的对象、差别、问题或措辞可以带着新的理解再次出现，形成回扣；不照抄前文整段，也不强制重复同一句。观点范围与依据一致，证据只排除一种可能时不宣称已查清全部原因。

导演检查整稿时，核对开头是否尽早给出有用内容、中段是否持续改变认识、评论是否有依据、结尾是否兑现。单独读稿成立后，再放回实际声画；观众数据未知时，不用标题、文案评分或参考作者成绩保证完播。

## 按缺失的观看作用返修

开头只有夸张问题，没有具体对象或回报，补能被认出的材料与第一层回答；中段只是知识目录，重排成观察、原因和后果的实际联系；类比热闹却更难懂，减少对应物并回到本体；笑点脱离问题，删掉或改成紧贴当前发现的回应；画面只有文字，把该由材料或对象表现的变化交回原视觉作者共同重构；结尾失去方向，回到开头承诺及已展开的结果。

修订交回完整的新稿和真实变更，说明配音、字幕、材料及相邻场面哪些受影响，不要求接收者从多段留言拼稿。主要论述和跨段关系由导演决定；素材作者持续提供材料与范围建议，原文案负责具体写法，视觉与声音负责各自实现。普通改稿不新增用户逐项批准。

这些方法用于直接创作，不以读取博主资料或填写研究报告为前置。只在用户明确要求研究新参考，或维护方法时再分析外部作品；正常任务仍需核对本片事实与搜索所需材料。

## 操作归属与能力结论的边界

第一人称操作只用于确实为本片执行并留有证据的操作。采用外部作者录屏或测试时按其来源描述所见，不能把他人的操作写成“我试了”；实际操作、作者说明和本片推断分清。

一次成功只支持相应条件下的结果；一次失败可描述实见提示，不能据此猜原因或断言所有相近功能都不支持。没有承诺某项能力，与证据证明能力不存在不同；需要更强结论就补依据，否则收窄台词。
```

```markdown
本路线的素材主导要求必须在成片里可见：实际材料承担主要观察与表达，文案和动画据其内容发展。仅有规则截图作证明、片头一闪或小角落视频，不自动等于材料已经主导；整片纯文字与图形不满足这条任务路线。这个判断属于作品要求，不增加素材资格、下载配额或固定面积比例，也不让系统自动为审美作通过判决。

未采用某份候选并非错误，检查的是它原来的材料用途是否仍被接住，以及替代是否确实维持材料主导。只有“动画已完成”“配音没有额外插播时间”不能充分解释整段材料退出；回导演与原视觉在同一时段重组，必要时原文案改稿。材料本身不合适回取材，材料合适却没用好回使用方，主要讲法不成立回导演。

文案检查首个回报、参与式解释、观察与后果、准确类比和结尾回扣；艺术与动作检查实际材料上的构图、准备、发力、跟随、读清和接管。返修保留已经有效的表达，不通过删除材料或交叠来消除所有复杂度。

静帧只支持相应时刻，动态与声音按真实观察范围说明。无法验证时保留未知而非伪造通过；能够生成文件与满足用户创作要求分别报告，不把不确定性变成使用素材的准入门槛。
```

## 十四、先验证流程真的改变，再判断作品效果

### 14.1 文本与入口检查

检查根AGENTS是否只剩路由、执行和异常处理；不含字体风格、来源／示意角标、画面类型、动画密度、卡片、配色和采用效果的固定规定。业务入口里应明确素材主导，不把这项目标在简化根文件时一起删掉。查找其余AGENTS、插件副本及路由引用，清理相同旧指令的活动副本；历史文档只作记录，不批量毁掉档案。

### 14.2 可自动验证的程序行为

| 验证输入或时机 | 预期行为 |

### 14.3 必须通过任务过程观察的行为

给普通主题和可实际读取的材料，不提供成品分镜、固定颜色和完整查询。第一轮应看到素材作者基于主题工作，而不是等全文后补位。材料分批返回时，依赖它的主要画面和准确句群据此形成；能够工作的范围先粗排，未到达范围继续探索。

不要只验证“素材作者被启动”——还要看到其发现回到稿件、画面和正式使用。也不要只看生成文件里有一个videoBindings：材料应当承担主要观看内容。只有法规图片或背景一闪而主体仍是整片文字板，不能凭计数通过。

已有旁白时，观察导演与视觉是否尝试在同一时段使用材料，而不是再次只比较多插几秒。具体材料真不适合可以换，但整项素材主导要求不能被静默取消。测试不设置固定镜头数或人为凑齐的媒介比例。

### 14.4 文案、画面和返修的实际结果

先读全文，检查关注、首个回报、原理推导、评论依据和结尾回扣；再看正常速度声画，判断这些内容是否真的由材料和动画共同呈现。严肃与轻松都要有发展，不以形容词、作者名气或数字评分代替内容。

检查主要动作是否有合适的准备、发力、惯性和读清，背景是否参与空间与持续关系；具体问题回原作者。一次叠影修复应在保留有效材料和交叠作用的前提下改善，不通过取消它们来降低难度。技术一致性、静帧构图、连续运动和音频分别说明已观察范围。

自动文本检查与程序回归可以证明规范、状态和接口正确；只有实际任务与观看结果才能支持工作方法和成片效果判断。没有真实发布或用户实验，不宣称完播率已经提升。
