## 推送异常的外部证据

此前推送首先被本机Git LFS锁检查阻断；当前两条分支均没有LFS指针文件，仅保留已安装的LFS钩子。本次只在推送命令中关闭锁检查，不修改全局配置或禁用其他钩子。

关闭锁检查后，远程完成对象解析但返回 `Internal Server Error`。10月7日查询GitHub官方状态API，返回 `Partial System Outage`；未解决事故名称为 `Incident with Git Operations, Pull Requests and Actions`，受影响组件包含Git Operations。事故链接：https://stspg.io/96smrcth8bpg 。该证据支持远程服务事故判断，但不把它当作本地整合正确或推送成功的证明。

推送以远程分支实际hash为准；结果未知时先查询引用，不强推、不删除分支、不为了服务错误改写代码。
